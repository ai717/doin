字族章节

四章二十四关，每关一组甲骨与本字。点任意一关即刻开始。

进度、星级与最佳用时都会自动保存。

怎么玩

  1. 看甲骨字形像什么，猜出它对应的今天汉字。
  2. 先点一张甲骨卡，再点一张本字卡；顺序反过来也可以。
  3. 配对正确会拉出朱砂溯源线，并播放这个字三千年的字形演变。
  4. 配错只会轻轻抖一下，不扣分、不重来，可以继续尝试。
  5. 整关全部配对即通关；误配 0 次三星，1 至 2 次二星，其余一星。
  6. 用时只作记录，没有倒计时；呼出选关或切到后台时会自动冻结计时。
  7. 方向键在卡片间移动焦点，Enter 选择，Esc 取消，R 重开本关。
