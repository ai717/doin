## 2 · 平台品类空白与立项建议

- **玩法空白区（优先立项）**：
  - 动作 / 跑酷 / 平台跳跃类目前较少；
  - 极简体育 / 反应射击类目前较少；
  - 文字解谜 / 极简经营模拟类为零；
- **品类饱和预警**：
  - “益智/经典”已有较多款，新立项除非是极高知名度的经典 IP，建议探索新的题材或创新交互机制。

## 3 · 封面配色避坑（视觉排重）

门户首页卡片墙追求色彩斑斓、百花齐放，新游戏封面需避开已饱和色相：
- **已饱和色相（谨慎/避开）**：
  - 蓝紫系（3 张：tetris-neo / orbit-sort / Gravity-Echoes）
  - 青绿系（2 张：sudoku / freecell）
  - 玫瑰粉（one-line）、天蓝（klotski）、亮青柠（jigsaw）、草绿（snake-orchard）、暖橙金（gold-miner）
- **推荐优先选用（未被占用）**：
  - **橙红、纯明黄、靛蓝/深青、暖棕/古铜、绯红、紫红**。
