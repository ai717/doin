## 2 · 平台品类与立项建议

- **不强制唯一性（允许且欢迎玩法同类/撞车）**：
  - DOIN 是开放多元的小游戏门户，同一种玩法（如连连看、推箱子、消除、弹珠等）完全可以有多种不同美术题材（如国风、赛博、极简）、关卡形态或手感变体；
  - 核心在于每款游戏具备**独立且出色的桌面端舞台美学、舒适的操作手感与健全的数学规则**；
- **平台灵感拓宽区**：
  - 动作 / 跑酷 / 平台跳跃类；
  - 极简体育 / 物理反弹 / 射击反应类；
  - 文字推理 / 极简经营与调度类。

## 3 · 封面配色避坑（视觉排重）

门户首页卡片墙追求色彩斑斓、百花齐放，新游戏封面需避开已饱和色相：
- **已饱和色相（谨慎/避开）**：
  - 蓝紫系（3 张：tetris-neo / orbit-sort / Gravity-Echoes）
  - 青绿系（2 张：sudoku / freecell）
  - 绯红系（2 张：link-up / pair-link）
  - 玫瑰粉（one-line）、天蓝（klotski）、亮青柠（jigsaw）、草绿（snake-orchard）、暖橙金（gold-miner）
- **推荐优先选用（未被占用）**：
  - **橙红、纯明黄、靛蓝/深青、暖棕/古铜、紫红**。
