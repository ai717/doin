# 候选卡模板（Candidate Card）

> 每次调研输出按此格式组织。最终交付建议用 Markdown 表格或卡片清单，
> 保证用户一眼能对比挑选。编号 C01…Cn 稳定，供用户回引。

## 1 · 单条候选卡字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 编号 | ✅ | C01 / C02 … 稳定编号 |
| 游戏名 | ✅ | 中文名 / 英文名 / 建议 slug（kebab-case） |
| 来源 | ✅ | 历史经典 / 经典脑洞 / 流行趋势 / 潜力创新 之一 |
| 一句话玩法 | ✅ | ≤ 30 字，讲清玩家干什么 |
| 差异化 | ✅ | 与 DOIN 现状/历史错位在哪（说清"为什么不是换皮"） |
| 潜力判断 | ✅ | 5 维度打分（可玩/差异/可开发/复玩/风险），总分 /25，附一句结论 |
| 参考来源 | 趋势类必填 | 搜索 URL 或"经典原型：X" |
| 优先级 | ✅ | ★ 推荐首选 / ☆ 备选 |

## 2 · 输出格式示例

```
## 候选清单（2026-09-21 · 第 N 轮）

### ★ 首选
| 编号 | 游戏 | 来源 | 一句话玩法 | 潜力(5维总分) | 差异化 |
|---|---|---|---|---|---|
| C01 | 星际弹幕 / Star Blitz / `star-blitz` | 潜力创新 | 太空飞船躲避弹幕并反击，能量连击驱动大招 | 21/25 | 全站唯一弹幕射击；每日轨道复用生态 |
| C02 | … | … | … | … | … |

### ☆ 备选
（同上表）

## 本轮已避开（记录差异）
- 已上架：xxxx（29 款）
- 已策划：watermelon-2048 / sokoban / fire-ice
- 历史已推：第 N-1 轮推荐过 xxxx → 本轮未重复
```

## 3 · 交付要点

1. **首选不超过 3 个**——推荐过多等于没推荐；用 ★ 标出"最该立项"的 1–3 个并给一句理由。
2. **每个候选一句话"为什么值得做"**，放在差异化列。
3. 末尾固定给"本轮已避开"清单，让用户看到差异性是刻意保证的。
4. 附下一步流转：选一个 → 用 `doin小游戏开发策划书` 技能立项策划 → 拍板 → 开发或 `doin外包小游戏开发` 发包。
