## 0. 一句话与原则

**打开就能玩的数独。提示会讲为什么。**

V1 只做一件事：让人在手机或电脑上，安静地完成一盘唯一解的经典 9×9，并且愿意明天再来。

六条原则（开发时遇到分歧，以这些为准）：

1. **心流高于留存花招。** 无广告、无弹窗推销、无强制失败。
2. **提示是老师，不是作弊码。** 先指区域、再讲技巧、最后才填数字。
3. **难度按技巧分级，不按挖掉多少格。**
4. **手机是第一屏。** 桌面只增强（键盘、更大盘），不另做一套。
5. **默认像纸笔。** 标冲突，但不因三次错误判负。
6. **引擎可带走。** 生成 / 求解 / 提示必须与 UI 解耦，供以后 App、变体复用。

## 2. 目标与非目标

### 目标（V1 做完必须成立）

- 任意时刻打开，3 秒内能开始一盘可解的 9×9。
- 每盘 **唯一解**，逻辑可解，不必猜。
- 手机单手可玩：格子与数字键好点、不易点错。
- 中途离开再回来，盘面、笔记、用时都还在。
- 有「今日题」，形成每天一题的节奏。
- 卡住时，提示能让人 **学会下一步**，而不是只看到答案。
- 无障碍：对比度足够、可减弱动画、键盘可完整操作。

### 非目标（明确不做）

- 广告、内购、看广告换提示 / 续命
- 账号、云存档、多设备同步
- 杀手、Thermo、对角线等变体
- 4×4 / 6×6、大盘 16×16
- 锦标赛、好友、排行榜
- 打印、PDF
- 社交分享强制回流（可有「复制成绩」但不依赖）
- 教学课程体系（图鉴是第二期）

## 3. 用户与场景

**主用户：休闲解题者（约 80%）**
通勤、睡前、会议间隙。要「今天来一题」、错了马上知道、不要被打断。

**次用户：进阶玩家（约 20%，决定口碑）**
要唯一解、要候选、要关自动检查、要键盘、要提示讲 Naked Pair 而不是填 7。

**关键场景**

| 场景 | 行为 | V1 如何接住 |
|---|---|---|
| 第一次打开 | 不懂规则，想试试 | 可跳过的 30 秒引导；默认简单 |
| 通勤 8 分钟 | 单手、可能被打断 | 自动存档、暂停、大点击区 |
| 卡住 2 分钟 | 不想弃局，也不想被剧透 | 三级提示 |
| 第二天回来 | 想接着习惯 | 今日题 + 连胜 |
| 桌面晚间 | 想用键盘认真做一盘困难 | 全键位、数字优先模式 |


## 5. 页面规格

### 5.1 首页 `/`

首屏只做三件事，禁止长文 SEO 堆在棋盘下。

1. **今日题卡片**
   - 标题：今日题 · 8月28日
   - 状态：未开始 / 进行中 / 已完成（显示用时）
   - 主按钮：开始 / 继续 / 再看一眼
   - 连胜：🔥 3 天（无连胜则不显示火焰）
2. **继续上次**（若有未完成的自由局）
   - 「继续 · 中等 · 12:04」
3. **新的一局**
   - 五档难度按钮，上次所选档有标记

页脚极简：怎么玩 · 设置。不要品牌故事。

### 5.2 对局 `/play` · `/daily`

**手机（390×844 为基准）**

```text
┌─────────────────────────────────┐
│  ←  简单          12:04  ⏸     │  顶栏 48px
│      今日题（若是每日）          │
├─────────────────────────────────┤
│                                 │
│         9×9 棋盘                 │  尽量大
│                                 │
├─────────────────────────────────┤
│  撤销  擦除  笔记  提示          │  工具 56px
│  1  2  3  4  5  6  7  8  9      │  数字盘，含剩余数
└─────────────────────────────────┘
```

**桌面（≥900px）**

```text
┌──────┬──────────────────┬──────────┐
│ 信息 │                  │ 数字 1–9 │
│ 难度 │      棋盘         │ 撤销擦除 │
│ 用时 │                  │ 笔记提示 │
│ 进度 │                  │ 剩余数字 │
└──────┴──────────────────┴──────────┘
```

顶栏信息：难度、计时（可在设置隐藏）、暂停。  
今日题在难度位置显示「今日」而不显示档位名（档位在完成后的结算里出现）。

### 5.3 统计 `/stats`

- 墨点、当前连胜、总完成局数
- 分难度表：完成数、最佳时间、平均时间、无提示通关数
- 印章墙：14 枚，未得的仍显示名称与条件
- 今日题日历（当月）：完成 / 未完成。点过去的日期 **不能补做**（避免刷题）；只展示状态。

### 5.3.1 局分、墨点、印章

对局里不跳分。完成后结算：

`局分 = 难度底分 + 时间奖励 + 干净奖励 + 今日奖励`  
失败 = 0，不加墨点。

| 难度 | 底分 | 基准用时 | 提前每 10 秒 | 时间上限 |
|---|---|---|---|---|
| 入门 | 40 | 5 分钟 | +1 | 20 |
| 简单 | 70 | 8 分钟 | +1 | 25 |
| 中等 | 110 | 15 分钟 | +1 | 30 |
| 困难 | 160 | 25 分钟 | +1 | 35 |
| 专家 | 220 | 40 分钟 | +1 | 40 |

干净：无错 +25，无提示 +35，两项都有再 +15。今日题 +20。  
墨点 = 累计局分，只增不减。本机保存。

14 枚印章：第一笔、今日、干净、盲解、五档、三日、七日、满月、十局、五十局、百局、墨浓、新纪录、入门飞。无锦标赛、无排行榜、无季节活动。

### 5.4 怎么玩 `/how-to`

短、可滚动、有示意：

1. 每一行、每一列、每一宫 1–9 不重复
2. 已知数字（粗体）不能改
3. 笔记用来记候选
4. 提示分三步，不会立刻剧透

不写历史、不写「发明于 1970」。

### 5.5 设置 `/settings`

见第 11 节。即时生效，不必「保存」按钮。

## 6. 核心玩法规则

- 盘面 9×9，分为 9 个 3×3 宫。
- 部分格子为 **已知**（given）：加粗、不可改、不可擦。
- 玩家填 1–9，使每行、每列、每宫均含 1–9 各一次。
- 每题 **恰好一个解**。生成失败则丢弃重来，绝不把多解题交给玩家。
- 笔记：一格最多 9 个候选，以宫内小 3×3 排布（位置固定：1 左上 … 9 右下）。
- 填入确定数字后，若开启「自动更新笔记」，则该行/列/宫及本格笔记中的该数字被清掉。

**完成判定：** 81 格全填且无冲突（等价于与唯一解一致）。触发结算，计时停止。

**挑战模式（默认关）：** 累计 3 次「确定数字填错」（填了与解不同的数字；改笔记不算）。第 3 次后本局失败，可「再来一局」或「查看正确盘」（查看后本局不计胜）。

## 7. 棋盘交互

### 7.1 选中与高亮

选中一格后同时：

- 该格强调（描边或底色）
- 同行、同列、同宫浅底
- 盘面上所有 **相同确定数字** 高亮（若本格已有数字）
- 若开启「高亮相同笔记」，其它格中相同候选也淡亮（设置项，默认开）

冲突：某确定数字在行/列/宫重复 → 这些数字用冲突色。已知格冲突只可能来自玩家填的其它格，已知格本身不变红。

### 7.2 两种输入模式

| 模式 | 行为 | 默认 |
|---|---|---|
| **格子优先** | 点格 → 点数字，填入该格。适合偶尔填。 | 手机默认 |
| **数字优先** | 先锁一个数字（数字盘保持选中），再点格即填该数。适合扫数字。 | 桌面可切；设置记忆 |

数字盘在数字优先下，当前锁定数有持续选中态。再点同一数字可取消锁定。

### 7.3 数字盘

- 1–9，每键下方或角上显示 **剩余个数**（9 − 已确定出现次数）。
- 剩余为 0 时该键变淡，仍可点（用于改错）。
- 长按数字（≥400ms）：进入笔记，给当前格开关该候选（仅格子优先时）。

### 7.4 工具

| 工具 | 行为 |
|---|---|
| 撤销 | 撤销上一次填数字 / 改笔记 / 擦除。无限。 |
| 重做 | 撤销后可重做。新操作清空重做栈。 |
| 擦除 | 清当前格的玩家数字或笔记。已知格无效。 |
| 笔记 | 开关笔记模式。开时点数字是开关候选，不是填入。 |
| 提示 | 打开提示面板，见第 8 节。 |

笔记模式开启时，笔记按钮为「按下」态，数字盘视觉改为小数字，避免误填。

### 7.5 键盘（桌面必须）

| 键 | 作用 |
|---|---|
| ← ↑ ↓ → | 移动选中格（到边不再绕回，避免迷失） |
| 1–9 | 按当前模式填入或记笔记 |
| 0 / Backspace / Delete | 擦除 |
| N | 切换笔记模式 |
| Z | 撤销（Ctrl/Cmd+Z 同样） |
| Shift+Z / Ctrl+Y | 重做 |
| Space | 暂停 / 继续 |
| H | 请求提示 |
| Esc | 关闭面板；暂停中则继续 |
| Tab | 不在棋盘内循环焦点到工具，保证可访问 |

### 7.6 暂停

- 计时停止。
- 盘面模糊或遮罩，数字不可见（防偷看）。
- 中央：「继续」。
- 切到后台（`visibilitychange`）自动暂停。

### 7.7 手势与触控

- 单击选格；再单击同一空格不取消选中（避免误触丢选中）。
- 无双击手势（易误触）。
- 最小点击区：格子随宽度拉伸，数字键 ≥ 44×44px，工具 ≥ 44px。
- 不与浏览器手势冲突：棋盘区域 `touch-action: manipulation`。

## 8. 提示系统（差异化，P0）

提示 **永不看广告**。每用一次，本局标记「借助提示」，该局不计入「无提示最佳时间」。

### 8.1 三级，由弱到强

玩家点「提示」后，系统计算「当前盘面下一步最小技巧」。同一局面重复点提示，**升级**，不换到另一处：

| 级 | 名称 | 玩家看到 | 盘面 |
|---|---|---|---|
| 1 | 看这里 | 「先看第 4 行」或「先看中间这一宫」 | 高亮该行/列/宫，**不填、不标具体格** |
| 2 | 讲为什么 | 「隐性唯一：这一宫里，5 只能放在这里。」含技巧名 | 再高亮目标格（及构成该技巧的相关格） |
| 3 | 填上 | 把该格填入正确数字，短暂闪一下 | 等同玩家填入，进入撤销栈 |

面板文案按钮：

- 1 级后：「还是不懂」（升到 2）「我自己来」（关闭）
- 2 级后：「帮我填上」（升到 3）「我自己来」
- 3 级后：自动关闭

### 8.2 V1 必须识别的技巧（按难度上限）

实现时用同一套检测器既做 **评分** 也做 **提示**。名称对玩家显示中文，括号内为内部 id。

| 中文名 | id | 最低出现档 |
|---|---|---|
| 显性唯一 | `naked-single` | 入门 |
| 隐性唯一 | `hidden-single` | 入门 |
| 显性数对 | `naked-pair` | 中等 |
| 隐性数对 | `hidden-pair` | 中等 |
| 区块删减 | `pointing` | 中等 |
| 显性三数组 | `naked-triple` | 困难 |
| 隐性三数组 | `hidden-triple` | 困难 |
| X-Wing | `x-wing` | 困难 |
| XY-Wing | `xy-wing` | 专家 |
| Swordfish | `swordfish` | 专家 |

若当前盘面需要的技巧超出本题难度上限（理论上不应发生，视为生成器 bug），提示仍应能给出，并在内部打日志。

**入门 / 简单题禁止出现中等及以上技巧才能解的步骤。**

### 8.3 文案模板

```
显性唯一：这格只剩 {n}。
隐性唯一：在{行|列|宫}里，{n} 只能放在这格。
显性数对：这两格都只能是 {a} 和 {b}，所以同{行|列|宫}其它格不能再是它们。
隐性数对：在{行|列|宫}里，{a} 和 {b} 只出现在这两格。
区块删减：{n} 在这一宫里只出现在同一{行|列}，所以这{行|列}的其它宫不能再填 {n}。
X-Wing：{n} 在第 {r1}、{r2} 行只出现在第 {c1}、{c2} 列，构成 X-Wing。
```

语气：短、肯定、不卖萌、不用「哎呀你看」。

### 8.4 无招可指

盘面已满或只差玩家未发现的冲突：提示改为「这行有重复的 {n}，先改这里。」不升到填答案（挑战模式失败除外）。

## 9. 题目生成与难度

### 9.1 硬性质量

1. 满盘是合法数独（行/列/宫 1–9）。
2. 挖空后 **唯一解**（求解器计数 = 1）。
3. 可用第 8.2 节技巧序列解完，**不许猜测、不许暴力唯一剩下的二分搜索**（专家档若要用到未列出的高级链，V1 直接丢弃该题）。
4. 评分 = 解完所需 **最高技巧等级**，不是已知格数量。

### 9.2 五档

| 档 | id | 最高技巧 | 体感 | 首次玩家 |
|---|---|---|---|---|
| 入门 | `intro` | 显性唯一为主，可少量隐性唯一 | 3–6 分钟 | 引导结束后可推荐 |
| 简单 | `easy` | 隐性唯一 | 5–10 分钟 | **默认** |
| 中等 | `medium` | 数对、区块删减 | 8–20 分钟 | |
| 困难 | `hard` | 三数组、X-Wing | 15–40 分钟 | |
| 专家 | `expert` | XY-Wing、Swordfish | 30 分钟+ | |

已知格数量只作生成时的 **初筛**（入门大约 40–45 个已知，专家大约 22–28），最终以技巧评分准入。

### 9.3 生成流程（引擎，无 UI）

```text
1. 生成满解（带约束的随机填充 / 洗牌）
2. 对称或非对称挖空至目标区间
3. 唯一解检验；失败则回退或重挖
4. 用技巧求解器评级
5. 等级 ≠ 目标档 → 丢弃重来
6. 输出：81 个格子 { given, value } + 解 + 难度 + seed
```

生成放在 **Web Worker**，主线程出「正在出题…」骨架盘，禁止卡住点击。超时（如 2s 仍无题）换一种子重试，并对玩家保持静默（不要报错，除非连续失败）。

### 9.4 种子

- 自由玩：`crypto.getRandomValues` 生成 seed，写入存档，可复盘。
- 今日题：`daily-{YYYY-MM-DD}` 经哈希得到 seed。同一天、同一时区规则见第 10 节，全用户同一盘。

引擎接口（实现必须遵守，供以后多端）：

```ts
type Difficulty = "intro" | "easy" | "medium" | "hard" | "expert"

interface Puzzle {
  seed: string
  difficulty: Difficulty
  givens: number[]        // 81, 0 = 空
  solution: number[]      // 81, 1–9
}

generatePuzzle(difficulty: Difficulty, seed?: string): Promise<Puzzle>
ratePuzzle(givens: number[]): Difficulty | "invalid"
nextHint(board: Cell[], solution: number[]): Hint
```

## 10. 今日题

- 每天一题。日期按 **本地时区** 的日历日（不要 UTC，避免晚上切题）。
- 难度：**中等**（让多数人「要认真，但当天能做完」）。
- 同一自然日不可换题。做完可「再练一局」→ 跳到自由玩，不覆盖今日记录。
- 未做完跨日：昨日进度保留在「继续上次」，今日题是新的一盘。
- 连胜：连续自然日完成今日题。中断归零。同一天重复打开不叠加。
- 完成后结算：「今日用时 14:22 · 提示 1 次」+ 连胜。

不提供补做昨天。日历只是徽章。

## 12. 统计与存档

无账号。键名：`jiugong.v1`。

**记什么**

- 分难度：完成局数、总用时、最佳时间（仅无提示局可刷新「无提示最佳」；有提示另记「最佳（含提示）」）、无提示完成数
- 今日：最近完成日期、当前连胜、最长连胜
- 当前自由局、当前今日局（进行中）

**不记**
- 失败局（挑战模式失败不进完成数，可记「中断/失败次数」但 V1 不展示）
- 个人身份信息

**存档时机：** 每次填格 / 改笔记 / 暂停 / 切后台，防抖 ≤ 300ms。  
**兼容：** 顶层 `version: 1`。以后升级写 migration，禁止静默丢档。

## 13. 对局生命周期

```text
新局 → 生成中 → 进行中 ⇄ 暂停 → 完成（结算）
                              → 放弃（确认后回首页，不记胜）
挑战模式：进行中 → 失败（可再来 / 查看解）
```

**新局确认：** 若当前有未完成进度，弹层：「开始新的一局？当前进度会丢失。」主按钮「开始」，次按钮「继续当前」。

**结算层**

- 「完成」
- 用时、难度、提示次数（0 则写「未使用提示」）
- 若刷新该档最佳：标明「新纪录」
- 主按钮：再来一局（同难度）
- 次按钮：回首页
- 今日题结算主按钮：回首页（看连胜），次：自由玩

**进行中进度条（可选，不挡盘）：** 顶栏用时旁可显示已填 / 81，不要做成游戏化经验条。

## 14. 视觉与品牌

### 14.1 性格

纸、墨、留白。不是糖果休闲、不是赛博霓虹、不是忍者贴纸。  
像一页好稿纸，数字是唯一的装饰。

### 14.2 色（设计令牌）

**浅色**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F3EEE4` | 页面 |
| `--board` | `#FFFBF4` | 盘面 |
| `--ink` | `#1C1917` | 已知数字、主文字 |
| `--player` | `#1D4E89` | 玩家所填 |
| `--note` | `#78716C` | 候选 |
| `--line` | `#1C1917` | 宫粗线 |
| `--line-soft` | `#D6D0C4` | 格细线 |
| `--wash` | `#E8DCC4` | 行/列/宫高亮 |
| `--same` | `#C7D6EA` | 相同数字 |
| `--conflict` | `#B42318` | 冲突 |
| `--accent` | `#9A3B2F` | 主按钮、今日火焰（朱红，少用） |

**深色：** 背景 `#161410`，盘 `#221F19`，已知 `#F5F0E8`，玩家 `#7BA3CC`，冲突 `#F97066`。对比度正文 ≥ 7:1，数字 ≥ 4.5:1。

### 14.3 字体

- UI：系统字体栈，`ui-sans-serif, "PingFang SC", "Noto Sans SC", sans-serif`
- 盘面数字：等宽、字重已知 700、玩家 500、候选 400。`font-variant-numeric: tabular-nums`
- 不要用装饰性书法做 1–9（识别性第一）

### 14.4 棋盘线

- 宫界：2.5–3px 实线
- 格界：1px
- 圆角：盘面整体 4–8px；格子不要各自圆角（会像麻将）

### 14.5 动效

- 填入：轻微缩放 80→100%，120ms
- 完成：宫或整盘一次轻快闪白，不要烟花 3 秒
- 冲突：数字轻颤一次，不要持续闪
- `prefers-reduced-motion`：全切瞬时

### 14.6 声音

V1 无声。以后加也必须默认关。

## 17. 边界与错误

| 情况 | 处理 |
|---|---|
| 生成超时 / 连续失败 | 静默换种；5 次仍失败则提示「出题失败，点一下重试」 |
| localStorage 满或禁用 | 可玩但刷新丢失；设置页提示「无法保存进度」 |
| 存档 version 不认识 | 不覆盖；当新用户。不要把新结构写入旧键导致读崩 |
| 今日题跨日打开进行中的旧今日 | 旧盘降级为自由局「继续上次」，新今日独立 |
| 玩家填满但有冲突 | 不触发完成；冲突色已足够 |
| 点已知格再点数字 | 无操作、无震动惩罚 |
| 挑战模式第 3 次错误 | 失败层；撤销不可在失败后把局救回（失败已定） |
| 辅助技术 | 每格 `aria-label`；选中用 `aria-selected`；数字盘为 `radiogroup` 或 toolbar |
| 超窄屏（宽 < 340） | 工具改单行图标、数字盘不换行挤压棋盘；棋盘优先保证正方形 |

## 19. 技术约束

- 网页单体，手机 + 桌面同一套 UI。
- **引擎纯 TypeScript，不引用 DOM / React。** 可单测：生成唯一解、评级、提示三级。
- 生成与评级在 Worker。
- 状态：内存 + `localStorage`。不上数据库、不上登录。
- 离线：静态资源可缓存；生成器在前端，断网可自由玩。今日题若已生成过可继续；全新打开且无网时用已缓存的当日 seed 算法仍可生成（算法在本地）。
- 不引入游戏引擎（Phaser 等）。棋盘用 DOM 或 Canvas 皆可，**优先 DOM**（无障碍、选中、笔记更简单）。
- 性能：交互（选格、填数）< 16ms；专家生成争取 < 1.5s。

模块划分：

```text
src/engine/     生成、求解、评级、提示   ← 无 UI
src/game/       对局状态机、撤销、存档
src/components  棋盘、数字盘、提示面板
src/routes      页面
```

## 22. 验收用例（抽检）

1. 清空存储打开 → 看到今日题 + 简单标记；3 秒内能开局。
2. 入门盘仅用显性/隐性唯一可手解；提示第 1 次不高亮单格数字。
3. 填错数字出现冲突色，对局不结束。
4. 开挑战模式，错 3 次失败；关设置后新局不再失败。
5. 笔记模式下填候选，切回填入模式填确定数，相关笔记自动消失。
6. 刷新页面对局仍在，用时不倒退、不暴增。
7. 手机宽 390：棋盘正方形、数字键不溢出、无横向滚动。
8. 键盘 1–9、方向键、Z、N 可打完一盘入门。
9. 同一天两个浏览器（无同步）今日题盘面相同（同系统日期）。
10. 完成今日 → 连胜 +1；次日再完成后 +1；隔一天归 1。
11. 专家题生成期间 UI 可暂停、可返回，不白屏。
12. 深色模式数字对比清晰，冲突不是唯一下色相线索（同时有图标或下划）。
