游戏玩法与操作指南

【目标】同时操控火人（Ember）与冰人（Tide），两人必须同时站到各自颜色的出口门前才能通关。

【元素相克】火人免疫岩浆、遇水即亡；冰人免疫寒水、遇岩浆即亡；墨绿毒液对两人均致命。

【机关联动】站上压力板开门；双色门只放行对应角色；同步压力板需两人同时踩下；传送门成对互传；冰人可在冻结点按 K 冻结水面/岩浆 3 秒，火人可点燃藤墙开路。

【双人操作】火人：W 跳 / A D 左右；冰人：↑ 跳 / ← → 左右。

【单人操作】Tab 切换当前控制角色（被切换角色原地待命）；方向键移动 + ↑/空格 跳跃 + K 冻结。

【宽容容错】任何角色死亡会原地回到本关起点重生，已收集宝石保留，只影响三星评价。

【星级评价】每关 5 颗宝石（2 红 + 2 蓝 + 1 中立）：全收集且零死亡 = 三星；全收集 = 二星；通关 = 一星。
