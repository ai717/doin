## 1 · 创意概念与核心乐趣

- **游戏名称**：见缝插针 / Pin Circle / 建议 slug：`pin`（备选 `pin-circle`）
- **一句话玩法**：找准旋转齿轮的狭窄空隙，单键射出针头扎入圆盘，严防针头互撞，一气呵成清空弹夹！
- **核心乐趣与卖点**：
  - **5 秒上手的极简魔性节奏（Hypnotic One-Tap Rhythm）**：
    规则简单到极致——屏幕点一下，针头飞上去，插满就过关，碰针就爆炸。极简的单键机制却带来极高浓度的专注心流，指尖跟着轮盘的自转节奏起舞，让人一开局就停不下来；
  - **白热化的缝隙心跳预判（Microsecond Gap Anticipation）**：
    随着圆盘上的既有针头越来越多，原本宽敞的圆周被切割成一条条逼仄的“生死一线天”。看着仅剩几度的微小空隙呼啸而过，在零点几秒的瞬间果断松开扳机，针头破空而入扎中空隙的一瞬，带来无与伦比的战栗爽感；
  - **热门重构：告别粗制劣造与弹窗广告（Elegance Reimagined）**：
    市面上的同类爆款（如远古的《aa》或泛滥的微信小游戏版）普遍存在画面极度简陋单调（纯黑白死板线段）、插屏广告横飞的痛点。本作重塑为**精密机械钟表工坊质感**，黄铜齿轮、蓝钢指针、金石入木脆响与流光火星，带来脱胎换骨的视听盛宴；
  - **阶梯分明的 23 关机械工坊（5/4/4/5/5 递进结构）**：
    从平稳匀速自转，到逆向钟摆、呼吸式脉冲变速、突发骤停顿挫、乃至双轨同心圆轮盘，层层递进挑战人类动态视力极限。
- **核心循环**：
  ```
  凝视中央旋转圆盘的转速与空隙 → 单键轻点 (空格/触屏) 射出前导针头
       ↑                                                      ↓
  下一关卡 / 挑战更高难度工坊 ← 待射针头全部清空安全扎入 ← 针头精准入槽 (清脆金石交鸣 + 连击加成)
       ↓ (针头间距重叠碰撞)
  针尖剧烈撞击产生火星 → 慢动作微定格 → 0.2s 瞬时秒重开
  ```

**我们要借鉴的成熟机制**：
1. **角度投影与碰撞角阈值模型（Angular Collision Detection）**：
   - 设圆盘当前旋转角为 $\theta(t)$，新针扎入瞬间的角度为 $\alpha_{new} = \pi/2 - \theta(t) \pmod{2\pi}$；
   - 遍历圆盘上所有已存在针的角度 $\alpha_i$，若存在 $|\alpha_{new} - \alpha_i| < \Delta\theta_{safe}$（安全夹角阈值，约 $8^\circ \sim 12^\circ$），立即判定碰撞失败；
2. **丰富的旋转动力学曲线（Rotational Dynamics）**：
   - 匀速顺时针 / 逆时针；
   - 正弦变速摆动：$\omega(t) = \omega_0 + A \sin(\Omega t)$；
   - 脉冲突变：匀速旋转中随机产生 0.2 秒的极速冲刺或急停反转，制造惊险刺激；
3. **单键即开即玩与极速复位**：
   - 任何地方点击即射，碰撞后无任何繁琐结算弹窗，0.2 秒内圆盘瞬间重置，让“再来一把”成为条件反射。

**本作的差异化微创新（拒绝无聊黑白线段）**：
1. **精密钟表工坊美学（Horology Clockwork Diorama）**：
   - 将枯燥的黑圆重构为一枚精致的**镂空黄铜机械擒纵大齿轮**，表面刻有复古罗马刻度，中央有轻盈摆动的避震游丝；
   - 待射针头设计为微缩的**蓝钢指针/镀金发条针**，尾部带有柔和的流光微粒；
2. **连续盲插连击奖励（Combo Burst）**：
   - 若在圆盘旋转一整圈之内连续射入 3 支以上针头且未失误，触发金色 `COMBO x2 / x3` 光环，得分翻倍并伴随递增的清脆编钟音阶；
3. **23 关五大钟表章节（5/4/4/5/5 梯度结构）**：
   - 钟表学徒 ➔ 逆向摆钟 ➔ 蒸汽齿轮 ➔ 电磁风暴 ➔ 精密天文仪，关卡 100% 具备数学可解性与安全缝隙裕度。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与核心几何体**：
  - **中央旋转齿轮（Master Gear）**：
    - 半径 $R = 80\text{px}$ 的黄铜雕花齿轮，固定在舞台中央 $(X_0, Y_0)$ 自转；
    - 关卡初始自带 $K_0$ 根预设针头（均匀或非均匀分布在圆周上）；
  - **待发射针阵列（Pending Pin Magazine）**：
    - 垂直排列在齿轮下方 $Y = Y_0 + 220\text{px}$ 处的队列；
    - 每根针标有递增序号（例：`1 ~ 12`），最前方的针头悬停在待发击发槽；
  - **飞行弹道**：
    - 针头垂直向上飞行距离约 120px，飞行时间极短（约 0.06s），带有类似射钉枪的干脆击发感。
- **玩家合法操作**：
  1. **发射针头（Launch Pin）**：
     - 鼠标左键点击屏幕任意位置 / 触屏轻击 / 键盘【空格键】按下：
     - 最前端针头瞬间向上飞射扎入齿轮圆周，成为齿轮的一部分同步自转；
  2. **快速连射（Rapid Fire）**：
     - 支持极短的输入缓冲（80ms），允许高手在宽敞间隙内一口气“哒-哒-哒”连续打出多根针；
  3. **瞬时重开（Instant Restart）**：
     - 碰撞失败后，屏幕微闪，按【R】或再次轻点屏幕即可 0 延迟秒速重开。
- **胜利与失败判定**：
  - **通关胜利（Clear）**：底部待射弹夹全部清空、最后一枚针稳稳扎入圆盘且无碰撞发生！
  - **终结仪式感**：
    - 齿轮发条爆发出耀眼的金光波纹，所有针头散发金色粒子并向外如烟花般绽放；
    - 弹出精致的齿轮铭牌，展示通关用时与连击评级；
  - **单局失败（Fail）**：
    - 射入的针头与圆盘上已有针头的角间距 $< \Delta\theta_{safe}$（碰撞）；
    - 碰撞处迸发出炽热的金属撞击火花，圆盘骤停 0.2 秒微颤，宣告失误。
- **数学可解性与 100% 公平保证**：
  - 每关的待射针总数 $N$ 与初始针数 $K_0$ 严格受控：$(N + K_0) \times \Delta\theta_{safe} \le 360^\circ \times 75\%$，保证圆周上**至少预留 25% 以上的安全绝对冗余空间**，绝无数学不可解的绝望死局。

### 操作与手感细节

- **打击感与声学微雕**：
  - 击发瞬间：弹簧击锤释放的清脆“啪”声；
  - 命中扎入：根据连击次数播放递增音阶的“铛——！”金石交鸣入木声（C5 ➔ D5 ➔ E5 ➔ G5 ➔ A5）；
  - 碰撞失败：沉闷短促的金属撞瘪碎裂声 + 屏幕 3px 瞬时微震；
  - 齿轮自转：背景带有极微弱、富有机械质感的“咔嗒、咔嗒”擒纵滴答声，强化时间流逝的沉浸感。

### 关卡模式编排（23 关五大钟表章节：5/4/4/5/5）

1. **第一章：钟表学徒（Apprentice Horologist · 5关）**：
   - 平稳匀速自转（正向/反向），待射针 6~10 根，安全缝隙宽绰，熟悉击发手感；
2. **第二章：逆向摆钟（Pendulum Reverse · 4关）**：
   - 顺时针旋转 3 秒后平滑减速并反向自转 3 秒，考验在反转交替节点的变向预判；
3. **第三章：蒸汽齿轮（Steam Piston · 4关）**：
   - 脉冲式周期变速（慢速巡航 ➔ 突发加速半圈 ➔ 恢复慢速），带有呼吸般的蒸汽动能感；
4. **第四章：电磁风暴（Magnetic Tempest · 5关）**：
   - 假动作急停顿挫（转速突然归零 0.4 秒随后瞬间暴冲），高密度狭窄缝隙（待射针 14~18 根）；
5. **第五章：精密天文仪（Celestial Chronometer · 5关）**：
   - 终极试炼：非对称变速曲线、超窄角间距极限穿透，针尖上的芭蕾舞，通关荣登“制表大宗师”！

### 目标与评价体系

- **单关三星标准**：
  - ★ 齿轮合璧：成功清空弹夹扎入所有针头；
  - ★★ 行云流水：达成一次 4 连以上不间断连击；
  - ★★★ 钟表大师：全关无一次险情擦边（所有落点均位于缝隙黄金居中 50% 区间）。
- **无尽模式（Endless Mode）**：
  - 拔出关卡限制，每插满 8 针自动消解并释放一圈金色光环，转速随机提速，记录个人最高插针数纪录。

## 4 · 美术风格与视觉氛围（复古机械钟表工坊，拒绝网页仪表盘）

- **题材与视觉关键词**：**黄铜发条 · 蓝钢指针 · 机械擒纵 · 珍珠母贝 · 沉浸深邃**
  （不做单调惨白的网页，不做廉价粗劣的黑白火柴棍；呈现为如同透过放大镜凝视一块百年传世机械怀表的镂空机芯）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Clockwork Heart Arena）**：
    - 垂直居中的黄铜大齿轮，带有精细倒角金属高光与镂空游丝转动；
    - 下方排队待射的蓝钢发条针泛着幽蓝微光，尾部有精致的圆润配重环；
    - 背景深邃墨绿至玄黑渐变，若隐若现雕刻着古老的星轨与天文刻度盘；
    - 顶框内嵌复古黄铜挂牌：收纳【返回首页】、【关卡选择】、【无尽模式】、【音效】与【语言】；
  - **左侧状态翼栏（HUD Left Wing · 弹夹指示计）**：
    - 竖直排列的刻度发条柱：实时展示剩余待射针数（例：`REMAIN: 4/12`）；

  - **右侧雷达翼栏（HUD Right Wing · 转速声纳仪）**：
    - 动态转速表（Tachometer）：实时弧线指示当前齿轮的瞬时角速度与旋转方向（CW 顺时针 / CCW 逆时针）；

  - **移动端适配**：
    - 舞台等比自适应竖屏，全屏幕任意区域单指轻点均可精准击发，下方留足拇指操作盲按区。

- **色彩与材质**：
  - **主色调**：高贵深青黛 `#0f141c → #080b10`，衬托出耀眼的贵金属质感；
  - **中央齿轮**：古典黄铜金 `#d4af37 → #aa820a` 搭配精雕罗马数字；
  - **针头材质**：烤蓝冷钢 `#4a90e2` 配明亮镀金针尖；
  - **动效降级**：在 `prefers-reduced-motion` 开启时，碰撞火花与屏幕震颤关闭，齿轮保留纯粹平滑自转。

- **封面设计提案（assets/covers/pin.webp）**：
  - 严格遵循 3D 软胶质感、单一居中主体（60-75% 无文字）、彩色渐变背景、漂浮微粒标准；
  - **主体物件**：一枚带有精美软胶齿轮纹理的黄色立体圆盘，上方已整齐插着数枚红白相间的小圆头针，正下方一枚带有金色飞行尾焰的软胶大头针正笔直向上疾速飞射，即将稳稳扎入圆盘两根针之间的狭窄空隙中，接触点爆出一圈小巧可爱的金色微粒光环；

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **碰撞安全判定容差（核心手感定调）**：
   - **方案 A（舒适微弹容差，强烈推荐）**：碰撞角阈值设为 $\Delta\theta = 9^\circ$，并在极其微小的擦边时允许微小吸附弹开，保证爽快连射心流；
   - **方案 B（绝对严苛物理硬碰）**：只要两针边缘重叠哪怕 0.5 像素立即暴毙，硬核受虐流；
   - **方案 C（双难度模式）**：普通工坊（方案 A）+ 硬核大师（方案 B）。

2. **连续连射（Rapid Fire）上限限制**：
   - **方案 A（允许极速连点，推荐）**：允许玩家根据手速在 0.3 秒内快速打出 3~4 针，只要时机预判准确即可一口气清空大缝隙，极具高手爽感；
   - **方案 B（固定最小发射冷却时间）**：强制每针之间间隔 0.25 秒冷却，杜绝连点“抽奖”。

3. **首发模式优先级**：
   - **方案 A（23 关精选关卡为主 + 无尽模式，推荐）**：首屏直接进入关卡挑战，通关打卡成就感强；
   - **方案 B（以无尽冲分模式为主）**：首屏一打开就是无尽轮盘，关卡作为分支模式。
