## 1 · 创意概念与核心乐趣

- **游戏名称**：舷窗防线 / Starport Siege / 建议 slug：`invaders`（单个简短纯英文单词）
- **一句话玩法**：在观测舱舷窗后横向滑动炮台，迎击不断横移下压、越打越快的外星阵列，守住房顶不被压到底线。
- **核心乐趣与卖点**：
  - **阵列压迫感（Formation Pressure）**：这是 1978 年街机真正的灵魂——一整片外星阵列像一块会呼吸的墙，整齐地"咚、咚、咚"横向挪动，每打掉一只，整片阵列的移动节拍就快一档。玩家不是在面对"几个敌人"，而是在和**一整块不断加速的集体**抢时间。最后剩三两只时那近乎癫狂的鼓点，是全游戏史最早也最有效的"心率设计"；
  - **俯冲与迎击（Dive & Head-On）**：阵列会不定时派出个体脱离编队俯冲扑向炮台。俯冲中的敌机可被**迎面击落**——在它冲到头顶前一瞬正面命中，触发双倍分数、专属爆裂音与屏幕微震。玩家从"被动躲"变成"主动引诱它下来再打脸"，这是本作对经典的最大手感升级；
  - **抢在临界线前清场（Race the Line）**：阵列每清空一行就整体下压一格，压到底部临界线即防线失守。舷窗下沿那条红色警戒线会随阵列逼近而逐渐充能发亮，玩家永远能一眼读出"还剩多少余量"，紧张感是可视化的、可计算的，不是随机的惊吓；
  - **火力节奏管理（Heat Management）**：主炮同屏最多 2 发、连射积热，过热锁定 1.1 秒并喷出泄压蒸汽。这条约束把"无脑按住不放"变成了"点射—观察—点射"的节奏博弈；而长按蓄力释放的**轨道炮**能一发贯穿整列，是留给高手的翻盘窗口；
  - **母舰悬赏（Mothership Bounty）**：每隔几波，巨大的母舰从舷窗外缓缓横掠而过，击落它掉出随机大奖（经典 300 分的现代重制）。那几秒钟是战场节奏的呼吸口，也是赌一把的诱惑。
- **核心循环**：
  ```
  炮台走位 + 点射（管理过热槽）
        ↓
  击落个体 → 阵列整体加速 → 阵型收紧、压迫感上升
        ↓
  敌方俯冲（躲 / 或迎面击落搏双倍）  母舰掠过（赌一次大奖）
        ↓
  清空整波 → 阵列整体下压一格 + 下一波新编队登场
        ↓
  守住临界线至全部波次结束 → 战报结算（命中率 / 最高连击 / 三星） → 下一关
  ```

## 2 · 经典标杆与对标参考

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Space Invaders（Taito 1978）** | 街机 | 阵列横移下压、单发子弹、掩体侵蚀、越打越快 | 定义了固定屏射击品类；残敌越少节奏越快的动态难度是教科书级设计 | 阵列集体行进节拍、越打越快的加速曲线、掩体逐发侵蚀、母舰横掠悬赏 | 单发子弹过于憋屈、无成长、纯无尽无终点、画面 2 色极简陋 |
| **Galaga（Namco 1981）** | 街机 | 编队入场动画 + 俯冲攻击 + 双机合体 | 敌机脱离阵列俯冲是本作"Dive & Head-On"的直接祖先 | 俯冲个体化、被俘母舰机制、编队入场演出 | 难度曲线跳变生硬 |
| **Galaxian（Namco 1979）** | 街机 | 敌机脱离阵列自杀式俯冲 + 彩色星舰 | 首次让"阵列"不再是死板方块 | 俯冲轨迹的弧线美感、旗舰护航机 | 无掩体、无节奏管理 |
| **Missile Command（Atari 1980）** | 街机 | 守底线 + 多目标拦截 | "守住房顶/底线"的紧张感原型 | 临界线预警、拦截的优先排序决策 | 纯防守无进攻爽感 |
| **Space Invaders Extreme（Taito 2008）** | DS/XBLA | 经典阵列 × 连锁连击 × 音乐节奏同步 | 验证了"经典阵列 + 现代连击反馈"完全成立 | 连击倍率、命中反馈层级、Wave 编排制 | 音乐同步过强导致玩法依赖 BPM |
| **DOIN 站内 space-defender** | 本站 | 横向卷轴射击（飞船自左向右推进、可自由移动） | 异质品类：它是"推进式空战"，不是"固定阵列下压" | 仅共享太空题材与射击手感层的打磨标准 | 玩法核心完全不同，本作不可做成卷轴，必须固定屏阵列 |

**我们要继承的成熟机制**：
1. **残敌驱动的加速（Remnant-Driven Tempo）**：阵列行进间隔与存活数量反相关（55 只 → 0.9s 一步，剩 1 只 → 0.12s 一步）。这是 1978 年的原创天才设计，必须原样保留并做出听觉表现（心跳鼓点同步）；
2. **掩体（水晶屏障）逐发侵蚀**：敌我双方火力都会在屏障上啃出缺口，玩家可以利用自己啃出的洞做射击窗口，也可以躲进去。掩体是动态的战术地形，不是静态装饰；
3. **入场编队演出**：每波敌阵不是凭空出现，而是从舷窗外上方以队形滑入，给玩家 1.5 秒读阵型的时间（经典 Galaga 遗产）；
4. **单屏固定 + 明确临界线**：失败条件只有一个——阵列压过临界线或船体被打穿。没有模糊判负。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **迎击机制（Head-On Kill）**：经典作品里俯冲敌机只能躲；本作允许玩家在俯冲敌机进入"冲刺直段"时正面命中，触发双倍分数 + 专属爆裂音 + 冲击波微震，并在火控台上点亮一枚迎击徽记。把"威胁"转化为"机会"，这是本作最重要的新增乐趣；
2. **过热槽 + 蓄力轨道炮（Heat & Railgun）**：把 1978 年"同屏一发"的硬件限制，重设计为**有反馈、可管理、可交换**的资源：点射、连射、过热泄压；长按蓄力则消耗热量换取一发贯穿整列的轨道炮。同一条槽同时承担约束与爆发；
3. **敌种职能化编队（Role-Based Formations）**：不再是三排同质的像素章鱼。八种敌种各有职能（护盾兵正面免疫需绕侧、分裂母体击落分裂、幽灵兵周期隐形靠雷达条读位、蜂群无人机脱离阵列绕飞），每 4 关一个母舰关做节奏反转；
4. **观测舱舷窗视窗（Porthole Framing）**：整场战斗发生在**一块厚重金属舷窗外的深空**里——玻璃有反光与刮痕、法兰环有铆钉、窗外有行星弧与星野，炮台在舷窗下沿的滑轨上。玩家不是"看一张画布"，而是"透过舷窗亲眼看着它们压过来"，压迫感被物理化了；
5. **战报制评价体系**：每关结束不给干巴巴的分数，而是给一份「战报便签」——命中率、最高连击、迎击次数、船体残余、用时，并换算为三星。"守住"本身才是评价指标，不是刷分。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素

- **舞台（舷窗外深空）**：横向矩形视窗（建议 16:10），顶部为阵列活动区，中部为交火区，底部为炮台轨道 + 三座水晶屏障 + 红色临界线；
- **炮台（Turret · 底部轨道）**：玩家控制的舰载炮台，宽度约占舞台 12%，仅可左右移动（不可上下、不可射击斜角），这是品类灵魂，不改；
- **外星阵列（Formation）**：5 行 × 11 列起手（可按关卡编排变化），整体横移；撞到视窗侧边则整体下压一格并反向；
- **水晶屏障（Barricade ×3）**：位于炮台与阵列之间的三座半透明晶体掩体，敌我火力均会侵蚀出缺口；
- **临界线（Red Line）**：舞台底部倒数第二格，阵列触及即防线失守；
- **母舰（Mothership）**：周期性从视窗顶部横掠，血量条独立于阵列，可被击落换取随机大奖；
- **舰载火控台（Console · 舷窗下方）**：过热槽、船体完整度、连击倍率、当前强化与暂停拨杆全部内嵌在这条金属凹槽面板上。

### 3.2 核心规则与判定

1. **射击与弹药**：
   - 主炮同屏最多 **2 发**在飞（在经典"1 发"上放宽一档，保证手感顺滑但不失紧张）；
   - 每发积热 `0.16`，热量满 1.0 → **过热锁定 1.1 秒**，火控台喷出泄压蒸汽并禁止开火，冷却后归零；
   - 不开火时热量以 `0.5/s` 回落，鼓励点射节奏；
2. **蓄力轨道炮（Railgun）**：
   - 长按 ≥ 0.6 秒蓄满（炮台聚能光环 + 升频嗡鸣），松开释放一道贯穿光束，**穿透一整列所有目标**；
   - 消耗 `0.4` 热量；热量 > 0.6 时无法起蓄（防止无脑连发轨道炮）；
3. **敌种与职能（8 种）**：

| 敌种 key | 中文 / 英文 | 血量 | 行为特征 |
|---|---|---|---|
| `enemy_grunt` | 甲虫兵 / Grunt | 1 | 基础个体，随阵列行进 |
| `enemy_crusher` | 蟹钳兵 / Crusher | 1 | 俯冲概率 ×3，冲刺直段更长（迎击窗口最大） |
| `enemy_squid` | 乌贼兵 / Squid | 2 | 横向摆动幅度大，射击更精准（会预判炮台位移） |
| `enemy_swarm` | 蜂群无人机 / Swarm | 1 | 被击落后同伴会 2~3 只结队脱离阵列绕飞俯冲 |
| `enemy_bulwark` | 护盾兵 / Bulwark | 3 | 正面免疫伤害，仅侧翼/背后或轨道炮贯穿可破 |
| `enemy_splitter` | 分裂母体 / Splitter | 2 | 击落后分裂为 2 只小体继续行动 |
| `enemy_phantom` | 幽灵兵 / Phantom | 2 | 周期隐形，仅在顶部威胁雷达条上显影 |
| `enemy_mothership` | 母舰 / Mothership | 20 | Boss：横掠顶部，三阶段（护盾 → 召唤增援 → 能量扫射） |

4. **俯冲与迎击**：
   - 阵列每 2.5~5 秒（随波次递减）派出 1 只脱离编队，沿弧线俯冲扑向炮台；**同屏俯冲敌 ≤ 2**；
   - 俯冲敌进入"冲刺直段"（最后 0.45 秒、轨迹变为直线且机体拖出火线）时，玩家主炮正面命中即判定 **迎击（Head-On）**：双倍分数 + 专属爆裂音 + 冲击波微震 + 火控台点亮徽记；
   - 俯冲敌撞到炮台或落到底线：船体 -1；撞到屏障：屏障侵蚀且敌机销毁；
5. **胜负判定**：
   - **胜**：本关所有波次的阵列清零（母舰关需击落母舰）；
   - **负**：船体完整度归零（初始 3 格），**或**阵列任一成员触及临界线；
   - 波次间有 1.5 秒入场演出与短暂休整，休整期热量快速回落。
6. **无死局保证**：
   - 关卡编队**全部为人工编排的确定性布局**，不使用随机生成，天然可通关；
   - **安全窗口硬约束**：同屏俯冲敌 ≤ 2，且俯冲落点之间必须保留 ≥ 1 个炮台宽度的安全站位区间，玩家永远有路可走；
   - 敌弹速度恒低于炮台最大移速的 0.8 倍，理论上均可规避；同屏敌弹总数上限 12 发；
   - 水晶屏障只削弱不封堵：任意时刻至少保留 2 条可射击通道；
   - 所有临时强化（散射 / 护盾 / 缓速 / 磁轨）**仅正收益**，绝不产生降低可玩性的负面状态；
   - 随机游走测试断言：俯冲调度器在 1000 步内不会产出封锁整条轨道的落点组合。

### 3.3 掉落模块（临时强化 · 限时 8 秒）

| 模块 key | 中文 / 英文 | 效果 |

| `mod_spread` | 散射 / Spread Shot | 主炮变为三向散射（热量增速 +30%） |
| `mod_shield` | 折射护盾 / Refractor | 炮台获得 1 次免伤，命中时反弹一圈能量波 |

### 3.4 操作与手感

- **鼠标（桌面首选）**：鼠标在舞台区横向移动，炮台带轻微阻尼跟随（不 1:1 硬跟，保留惯性手感）；左键点击 / 按住射击，**按住 ≥ 0.6s 起蓄轨道炮**；
- **键盘**：`←` `→` 或 `A` `D` 移动，`空格` 射击（长按蓄力），`P` 暂停，`R` 重开本关；
- **触控（移动端）**：手指在视窗下半区横向滑动，炮台跟随；点击射击，长按蓄力；
- **输入缓冲（Input Buffering）**：过热锁定期间按下的开火指令缓存 0.25 秒，解锁瞬间自动补发，杜绝"明明按了却没打出去"的憋屈感；
- **误触容错**：炮台到边界做弹性软限位；新一波入场的前 0.8 秒无敌；被击中后 0.6 秒无敌闪烁。

### 3.5 模式编排（拒绝"无尽 + 每日"三件套套路）

本作乐趣在**关卡编排的成长与手感打磨**，因此**刻意不做每日挑战**（本作没有每日解密属性，硬塞只会稀释关卡设计）：

1. **战役 · 星港围城（Campaign · 核心模式，12 关）**：
   - 每关 3 波编队，关内波间仅短暂休整；**第 4 / 8 / 12 关为母舰关**（母舰三阶段战）；
   - 敌种逐关解锁：1-3 关基础三型 → 4-6 关引入护盾兵与蜂群 → 7-9 关引入分裂母体与幽灵兵 → 10-12 关混合编队 + 双母舰；
   - 通关结算给出**战报便签**与三星，解锁下一关；
2. **生存演习（Survival Drill · 无限波次）**：
   - 从第 1 关配置起步，波次无限递增（密度、速度、俯冲频率逐波提升，第 10 波起周期性插入母舰）；
   - 目标是刷新**个人最远波次**与**最高连击**，不做三星，纯手感试炼场；
3. **战术训练场（Training Range · 3 个教学关）**：
   - 无死亡、无失败，专门练习「迎击判定」「轨道炮贯穿」「屏障利用」三个专项，附带即时命中反馈教学。

### 3.6 计分与反馈体系

- **击落基础分**：Grunt 10 / Crusher 20 / Squid 30 / Swarm 15 / Bulwark 40 / Splitter 25 / Phantom 50 / Mothership 1000；
- **连击倍率**：连续命中不落空，每 5 次命中 +0.2（上限 ×4.0）；落空一发或船体受损则清零；
- **迎击奖励**：双倍基础分 + 每次迎击额外 +50；
- **阵列崩塌奖励**：清空整行 / 整列 +200；整波清场 +500；
- **母舰悬赏**：随机 50 / 100 / 300 三档（致敬经典）；
- **三星评价（战役每关）**：
  - ★ 通关本关（保底）；
  - ★★ 命中率 ≥ 70% 或最高连击 ≥ 20；
  - ★★★ 船体零损伤通关（且用时 ≤ 关卡目标时间）；
- **存档口径**：关卡解锁进度、每关三星、战役最高分、生存最远波次与最高连击（Key 统一 `doin.invaders.v1`）。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词

**深空观测舱舷窗（Orbital Porthole）**、**舰载火控台金属凹槽（Console Bay）**、**冷青玻璃反光（Cold Glare）**、**行星弧与星野（Planet Arc & Starfield）**、**1978 街机心跳鼓点（Arcade Heartbeat）**。

### 4.2 专属视窗物理隐喻（严禁左右双翼 / 严禁机顶木梁 / 严禁右侧 SaaS 卡堆）

整局游戏是**一整块舷窗**——玩家站在空间站观测舱里，隔着厚厚的复合玻璃看着外星阵列压过来。所有 UI 都是这块舷窗的物理部件，而不是贴在页面上的卡片：


1. **舷窗框（DOM + CSS 3D）**：厚重金属法兰环用多层 `box-shadow` + 圆锥渐变做拉丝高光，一圈真实铆钉（`radial-gradient` 小圆 + 内阴影），玻璃层用一条斜向半透明白色渐变 + 一两道细刮痕做反光，**玻璃反光固定在框上、不随 Canvas 内容移动**，这是"隔着玻璃看"的关键；
2. **威胁雷达条（舷窗内上沿）**：一条嵌在窗框里的细长扫描带，实时显示剩余敌数、母舰接近警报、幽灵兵的隐形位置。它不是"卡片"，是舷窗的仪表条；
3. **舰载火控台（舷窗下方一体熔铸）**：过热槽（物理液柱）、船体完整度（三格能量块）、连击倍率（数码管跳字）、当前强化（限时倒计时环）、暂停拨杆——全部是**实体微浮雕按键/液柱**，按下有 `translateY(2px)` 下沉位移；可读性标记禁用硬边描边圈，改用无边界径向柔光；
4. **战报便签**：关结算不是居中弹窗，而是一张被金属夹夹在火控台右沿的战术便签（微微翘起 + 投影），写命中率、最高连击、迎击次数与三星。弹层与页面物理上属于同一台设备；
5. **移动端（≤768px）**：舷窗收为竖向，火控台压缩为底部一条；底部严格预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，防止 Banner 广告遮挡炮台操作区；
6. **沉浸氛围**：窗外深空为墨蓝→近黑径向渐变，行星弧占画面下 1/4 边缘，缓慢浮动的星际尘埃微粒；舷窗四角有轻微暗角（vignette）；整体拒绝死白死黑大平铺。

### 4.3 立体质感与渲染路线裁决

- **路线：Canvas 2D（舞台内容） + DOM/CSS 3D（舷窗框与火控台）**，**不引入 Three.js**。
  - 理由：本作是固定屏 2D 阵列射击，无真三维空间变换需求；Canvas 2D 足以承载 60+ 实体、粒子与光束，秒开零发热；
  - Canvas 负责：星野视差、敌阵列、弹幕、屏障侵蚀、粒子爆裂、轨道炮光束、母舰；
  - DOM/CSS 3D 负责：舷窗法兰环与玻璃反光（`perspective` + `rotateX` 微倾 + 多层阴影）、火控台凹槽与实体按键、雷达条、战报便签、语言/音效控件；
  - HUD 与弹层 100% 留在 DOM 层，语言切换原地热更新，绝不触碰 Canvas 游戏状态。

### 4.4 粒子与反馈质感

- **击落爆裂**：6~10 片与敌机体色匹配的碎屑 + 一圈径向柔光冲击波（`radial-gradient` 渐隐至透明，禁用硬边描边圈）；
- **迎击（Head-On）**：额外叠加一圈白色冲击环 + 屏幕 0.12 秒微震 + 时间轻微顿帧（60ms），火控台迎击徽记亮起；
- **阵列行进**：整片阵列每一步伴随一次极轻微的同步位移与低频鼓点，视觉与听觉同拍；
- **临界线告警**：阵列逼近时，红色警戒线从不透明→呼吸式充能发亮→最终闪烁，同时舷窗暗角加深；
- **过热泄压**：炮台顶部喷出白色蒸汽粒子（噪声驱动的横向漂移），火控台过热槽液柱转为橙红并抖动。

### 4.5 声效风格与材质音色规划（严禁单音蜂鸣器，严禁 C-E-G-C 琶音）

| 音效 | 合成方案（WebAudio 程序化，零音频文件） |
|---|---|
| **阵列行军心跳（灵魂音效）** | 失谐双锯齿振荡器（相差 8 音分）+ 低通滤波 + sub bass 层；每步一记沉闷"咚"，**节拍随残敌数从 0.9s 缩到 0.12s**，音高同步微升。这是本作的听觉标识，绝不可省 |
| **主炮发射** | 带通滤波白噪声"嗤"（2~4kHz 扫频）+ FM 短促上滑音（载波 880→1320Hz），等离子感，不做 beep |
| **蓄力轨道炮** | 升频嗡鸣（三角波 120→900Hz + 轻微失谐层）+ 释放瞬间低频下潜 Kick（60Hz sine + 快衰减） |
| **命中敌机** | 噪声 buffer 经 bandpass（中心 2.5kHz，Q=6）快速衰减 = 金属外壳崩裂；叠一层 FM 高频玻璃碎点 |
| **迎击爆裂** | 失谐双振荡器 + 短促波形整形失真 + 60Hz Kick，明显比普通击落更重更"爽" |
| **敌机俯冲** | 多普勒下潜音（pitch envelope 从 700Hz 滑到 180Hz）+ 呼啸风噪（低通噪声） |
| **母舰掠过** | 环形调制感的 AM 颤音"呜—呜—"（载波 220Hz，调制 6Hz），持续到被击落或离场 |
| **屏障被侵蚀** | 低频闷响 + 颗粒噪声短促叠加（像晶体被啃掉一块） |
| **过热锁定** | 泄压蒸汽：白噪声经低通从 6kHz 扫到 800Hz，配两声警告滴 |
| **船体受损** | 下降两个半音的双音（铜管质感，见 FM 合成），配合红色闪屏 |
| **关卡通关** | 五声音阶上行琶音（非 C-E-G-C），用 FM 木琴音色，收尾一记舰载汽笛 |

### 4.6 封面设计提案（遵循 `docs/COVER-STYLE.md`）

- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体占画面 62%~70%——**一只 3D 软胶质感的经典外星侵略者**（圆润触手、微透胶质高光、脚下带一小圈悬浮光晕），正面朝向观众，略带俯冲前倾姿态；
- **配色（避让站内已密集色相）**：背景走 **100~110° 黄绿→正绿径向渐变**（站内该段基本空白，仅 reversi 占 125°，可安全区隔）；主体外星侵略者用 **305~315° 品红软胶**（与背景形成强互补，站内仅 memory-duel 占 321°）；漂浮粒子用青色与暖黄点缀；
- **氛围**：深空星点 + 缓慢漂浮的晶体微粒，主体下方一道柔和的舷窗冷光反射，整体 3D 软胶、明亮讨喜、一眼认出"太空侵略者"。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 项进行拍板：

### 拍板项 1：主炮约束的强度（决定本作的核心手感）

- **选项 A（过热槽 + 同屏 2 发 · 推荐默认）**：在经典"1 发"上放宽一档，靠过热槽约束节奏。既保留 1978 的紧张感，又不至于让现代玩家觉得憋屈；
- **选项 B（严格致敬：同屏 1 发，无过热）**：最纯粹的复古手感，但现代休闲玩家大概率会觉得"打不动"；
- **选项 C（同屏 3 发 + 过热槽更宽松）**：火力更爽快、更偏现代射击，但"越打越快"的压迫感会被稀释。

### 拍板项 2：关卡编排规模

- **选项 A（12 关战役，第 4/8/12 关母舰关 · 推荐默认）**：约 25~35 分钟通关，敌种逐层解锁，节奏最完整；
- **选项 B（8 关精炼战役，第 4/8 关母舰关）**：约 15~20 分钟，上线更快，但后 4 种敌种的登场空间被压缩；
- **选项 C（16 关长线战役）**：内容最厚，但开发中后段容易出现编队重复感。

### 拍板项 3：视觉基调

- **选项 A（深空观测舱舷窗 · 推荐默认）**：金属法兰舷窗 + 玻璃反光 + 舰载火控台，把"阵列压过来"物理化为"隔着玻璃亲眼看着"，压迫感最强，且完全避开站内换皮模版；
- **选项 B（复古 CRT 街机台）**：1978 致敬到底——曲面 CRT 显像管、扫描线、琥珀色荧光，复古味最足，但容易与站内其他复古题材撞脸；
- **选项 C（霓虹赛博深空）**：青蓝/品红霓虹 + 电子粒子，现代感强，但会与 space-defender 的太空科幻调性部分重叠。
