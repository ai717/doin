## 1 · 创意概念与核心乐趣

- **游戏名称**：猜数字 / **Number Hunt**（中文副标：**声呐围猎**） / 建议 slug：`guess`
- **一句话玩法**：心里藏一个数，你投下猜测，声呐只回一句"大了 / 小了"，把包围圈收紧到命中为止。
- **核心乐趣与卖点**：
  - **收网的爽感**：抽象的"二分查找"被翻译成看得见的动作——一条横贯舞台的声呐扫描带，每猜一次，被排除的那一半就熄灭沉入暗水，可行区间像渔网一样肉眼可见地勒紧。最后剩一格时的"瓮中捉鳖"是全局最爽的一瞬。
  - **逼近的心跳**：除了大小，回波还带**温度**（冷 / 温 / 烫），可行区间的光色随距离由青蓝转琥珀再转珊瑚红并脉动——玩家不用读数字也能"感觉"到自己有多近。
  - **噪声下的判断**：从第 2 章起，猎物会跑、回波会撒谎、浊流会让探测静默。玩家不再机械折半，而要**交叉验证、怀疑自己的信息**，这是本作真正的智力乐趣所在。
  - **一击定音的仪式**：命中瞬间整条声呐带全亮、回波锁定音上行三连、目标数字从暗水里浮出定格、气泡与光屑喷发，星级徽章阶梯弹出。
- **核心循环**：看区间 ➔ 拨号投浮标 ➔ 回波偏左/偏右 + 温度反馈 ➔ 包围圈收窄 ➔ 噪声干扰制造怀疑 ➔ 再投 ➔ 锁定命中 ➔ 拿星级进下一关。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **《公牛与母牛》Bulls and Cows（1970 年代，中国俗称"猜数字 1A2B"）**：最经典的猜数字原型，反馈是"几位数字对且位置对 / 几位对但位置错"。它证明了**"少比特信息 + 多次推断"**这个心智模型能撑起完整游戏。
  - **Mastermind（1970，珠玑妙算）**：同上体系的商业化巅峰，确立了"有限次数 + 每次反馈必含信息 + 严格无死局"的三段式骨架。
  - **经典教学版"Guess the Number"**：1–100 猜数，只回 Higher / Lower，7 次必中——几乎每个程序员的第一个游戏，认知门槛为零。
  - **现代 Numberle（Wordle 的数字变体）**：把"大小反馈"搬进 Wordle 的三色格体系，证明了**大小/命中反馈放在现代 UI 上依然有强成瘾性**。
- **它们最受认可的机制**：
  - 每次反馈必须**严格携带信息**（不允许"无关痛痒"的空反馈）。
  - **有限次数**制造压力，且次数必须够用——经典版本给的次数恒 ≥ 二分最优步数 + 余量。
  - 反馈是**离散、无歧义、一眼可读**的（大 / 小 / 中）。
  - **死局归零**：目标先定、反馈恒真，绝不存在"猜不出来"的局面。
- **我们要继承的**：
  - 「目标先定 + 反馈恒基于真值」的诚实骨架；
  - 「机会次数 ≥ 信息论最优步数 + 安全余量」的预算铁律；
  - 大 / 小 / 中的三态离散反馈，一眼可懂。
- **我们的差异化微创新**：
  1. **把二分可视化**：同类游戏几乎全是一列历史记录文字，本作把**可行区间本身**做成主舞台上的发光带，收网过程成为主角。
  2. **温度维度**：在"大/小"之外叠一层连续的距离感（冷/温/烫），让逼近有情绪曲线，而非只有布尔量。
  3. **受控噪声三件套**（漂移 / 谎灯 / 浊流）：这是本作最大的创新——**经典猜数字之所以无聊，是因为信息永远诚实、二分永远最优**。加入**有界且可推理**的噪声后，玩家必须动脑判断"这条回波能不能信"，智力密度直接上一个台阶。
  4. **声呐题材**：把"大 / 小"翻译成"回波偏左舷 / 偏右舷"，甚至用**声像左右声道**播报方向——听觉本身就携带信息，这在同类里是全新的。
  5. **桌面双栏声呐舱 + 实体拨盘机台**，不做"输入框 + 提交按钮"的网页表单。
- **品类排重**：门户已有 `number-klotski`（数字华容道，空间推盘）、`winmine` / `minesweeper`（逻辑推理），本作是**纯信息论推断 + 受控噪声**，心智模型完全不同，填补"猜数字"这一最大众经典品类的空白。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

- **盘面构成**：
  - 主舞台一条**横向声呐扫描带**，左端为范围下界、右端为上界（如 1 → 100），带上有均匀刻度。
  - 带上的**可行区间**以暖色渐变发光带呈现；已排除区间熄灭为暗水（保留极暗刻度，让人看得见"被砍掉多少"）。
  - 玩家每次猜测在带上留下一枚**声呐浮标**（小圆点 + 垂直刻度线），浮标按投掷顺序编号。
  - 右上角的**猎物幽灵信号**：只在水面下微微游走（存在感），不泄露具体位置。
- **合法操作**：
  - 在拨盘上输入一个**在范围内的整数**（重复猜同一个数视为无效，不消耗机会）。
  - 按「发射」投出浮标，立刻得到回波。
- **回波（核心反馈）**：
  - **方向**：目标比猜测**小** → 回波打向左舷（猜测右侧全部熄灭）；**大** → 右舷（左侧全部熄灭）。
  - **温度**：|目标 − 猜测| ≤ 5 → **烫**（珊瑚红 + 脉动）；≤ 20 → **温**（琥珀）；其余 → **冷**（青蓝）。
  - **命中**：回波正中央，直接胜利。
- **胜利 / 失败**：
  - 胜利：猜中目标数字。
  - 失败：机会（鱼雷）耗尽仍未命中。失败不惩罚——可原地重开本关（目标重掷），保留星级记录中的最好一次。
- **无死局保证（硬性）**：
  - 目标数字在开局即固定，全部回波都基于真值派生（即使"谎灯"也是**确定的规则**而非随机欺骗，见下）。
  - **机会预算公式**（开发端必须实现并写入关卡表自检）：
    `B = ceil(log2(N)) + 2 × 漂移回合数 + 2 × 谎灯次数 + 浊流静默次数 + 2（安全余量）`
  - 三种噪声全部**有界且可推理**：
    - **漂移**：目标每回合位移 ±k（k ≤ 3），且**只在玩家投出浮标之后**发生，位移量在回波日志中不给明示，但玩家可从"上一次的区间边界失效"反推。
    - **谎灯**：每局有固定 1 次回波方向倒置；**永不出现在第 1 回**，且倒置当次的温度反馈仍为真（玩家可用温度交叉验证方向，形成"哪次是谎"的推理闭环）。
    - **浊流**：带上存在 1–2 段固定雾区，落在雾区内的猜测**不给方向**（静默），但仍给温度、仍消耗机会；雾区位置在关卡开始时就以视觉浓雾明示（不是隐藏惩罚）。
  - 开发端需额外写一个**对抗式最坏情况求解器**（目标取最坏、噪声取最坏，穷举/搜索玩家的必胜策略），验证每种关卡配置在 B 次内**必然存在命中路径**；不满足则自动上调 B 并报警。

### 3.2 操作与手感

- **输入**：
  - 机台上的**七段数码拨盘**（大号，居中），点击数字键盘或直接用物理键盘 `0–9` 输入；`Backspace` 退格，`Enter` 发射。
  - `← / →` 微调 ±1，`↑ / ↓` 微调 ±10，长按连跳 —— 让"贴着边界微调"这一高频动作不痛苦。
  - 移动端：拨盘下方一排**实体软胶数字键**（0–9 + 退格 + 发射），底部保留 ≥68px 安全留白。
- **操作缓冲与容错**：
  - 快速连按数字不丢帧（输入在下一帧统一提交）；`Enter` 在回波动画播放中被按下则**缓冲**，动画结束自动执行最后一次。
  - 超范围 / 重复猜测 / 空输入：**不消耗机会**，机台轻抖 + 短促低鸣 + 拨盘边框一瞬泛红，输入内容保留不清空。
  - **唯一"非法操作必执行"铁律**：任何在范围内且未猜过的数字，发射后必须真实执行，UI 不得拦截。
- **机台道具（题材化，非通用提示键）**，每关限量：
  - 「**声呐探针**」：回报目标的**奇偶**（消耗 1 次机会）——便宜但信息少，用于噪声关做交叉验证。
  - 「**扫描线**」：直接点亮目标所在的**半区**（消耗 2 次机会）——救急大招，每章限量 1 次。
  - 「**回溯**」：撤销上一次猜测及其回波，**不消耗机会**，每关限 1 次（对应经典撤销栈）。

### 3.3 模式与内容编排（章节关卡制，不做无尽冲分）

**5 章 × 6 关 = 30 关**，每章引入一种新机制，第 6 关为本章综合考：

| 章节 | 名称 | 范围 | 新机制 | 机会 B |
|---|---|---|---|---|
| 1 | 静水试航 | 1–100 | 纯方向 + 温度（教学） | 10 |
| 2 | 暗流涌动 | 1–200 | **漂移**：目标每回合 ±2 | 12 |
| 3 | 谎灯回波 | 1–150 | **谎灯**：恰 1 次方向倒置（不在首回） | 12 |
| 4 | 浊流深潜 | 1–300 | **浊流**：1–2 段雾区，落入静默 | 14 |
| 5 | 猎王之境 | 1–500 | 随机组合上述 2 种 | 16 |

- 每章第 1 关为"教学关"：机制首次出现时用一次**高亮演示**（例如谎灯关先演示一次"两次回波互相矛盾 → 其中一次是谎"）。
- 不做"每日挑战 / 无尽冲分"——本作乐趣在**推理质量**，不在重复刷量。
- 全 30 关通关后解锁「**盲猎**」：关闭温度提示，只给方向，作为给高手的额外 6 关。

### 3.4 目标与反馈体系

- **核心指标是「用了几次机会」，不是得分。**
- **星级**（以理论最优 `ceil(log2(N))` 为锚）：
  - 三星：步数 ≤ 最优 + 1（1–100 关即 ≤ 8 步）
  - 二星：步数 ≤ 预算 B − 3
  - 一星：预算内完成
- **反馈仪式**：
  - 命中：声呐带自命中点向两端**波浪式全亮** → 回波锁定音（上行三音合成）→ 目标数字从暗水中放大浮出定格 → 气泡 + 光屑喷发 → 星级徽章阶梯 delay 弹出 → 若破个人最佳，加「最佳猎手」徽章。
  - 失败：鱼雷管最后一枚熄灭 → 声呐带缓慢暗下去，目标数字以幽灵轮廓浮出（"它一直在那儿"），给出「再猎一次 / 返回章节」两个实体键。
  - 数值动效：剩余机会、当前步数使用街机数码字体 + 弹性 Bump；温度转"烫"时机台轻微脉动（受 `prefers-reduced-motion` 约束）。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：**深海声呐猎潜 · 幽蓝霓虹 · 湿冷金属机电 · 探照灯暖光 · 复古仪表盘**。
- **沉浸舞台规划（严禁老旧网页排版病）**：
  - **顶边一体化机台横梁**：返回门户（左端船锚徽标）、章节名匾额、音效拨杆、中英切换、规则卷轴 —— 全部内嵌在一条带铆钉与磨砂金属质感的横梁里，**绝不在屏幕四角散落浮动按钮**。
  - **桌面端（≥900px）双栏**：
    - **左（主舞台约 1.6fr）**：横向声呐扫描带占据视觉中心，带上是可行区间发光带、浮标刻度、雾区浊流；下方是**湿冷金属操作台**：大号七段数码拨盘（居中）+ 实体按键排（发射 / 回溯 / 声呐探针 / 扫描线，微浮雕、hover 浮起 2px、按下扎实下沉）。
    - **右（猎手舱约 0.9fr）**：一体化**潜水舱舷窗**造型面板，内嵌三块信息：① 关卡匾额（章节 + 关号 + 目标范围）；② **鱼雷存量管**（剩余机会，竖排弹药，亮一枚是一枚，最后一枚转红并呼吸）；③ **回波日志卷轴**（滚动记录，方向用左右箭头 + 冷温烫色点，谎灯回合带极细杂讯纹）。
    - 主舞台 `max-height` 约 `calc(100dvh - 120px)`，整页不滚动；舞台宽度 ≤1100px，两侧为广告安全留白。
  - **移动端（≤768px）**：单列 —— 声呐带在上（压缩为半幅），拨盘与数字键在下方操作台，底部留 `max(68px, calc(16px + env(safe-area-inset-bottom)))` 安全间距。
  - **沉浸背景**：深靛→墨青的环境渐变，两团缓慢 drift 的冷光晕（探照灯感）+ 极细 SVG 噪点 + 柔和暗角；**拒绝死白底**。
- **色彩与质感**：
  - 主色：靛蓝 `#0b2545` / 声呐青 `#3ddad7` / 琥珀 `#ffb347` / 珊瑚红 `#ff6b5b`（烫）。
  - 可行区间带 = 由中心向两侧渐隐的**径向柔光渐变**，末段 `alpha → 0`，**绝对不打描边圈**（遵守平台红线：主体不描轮廓，靠柔光 + 明暗 + 脉动托出）。
  - 按键：湿冷金属 + 边缘高光 + 微浮雕；悬停 `translateY(-2px)`，按下 `translateY(2px)` + 咔哒音。
- **音效（WebAudio 程序化合成，零外部文件）**：
  - 投浮标：低频入水"咚"带短混响。
  - 回波：短脉冲，**用左右声道声像表达方向**（小 = 左声道、大 = 右声道），听觉直接携带信息。
  - 烫：脉冲变密且叠一层轻微上升音高。
  - 谎灯回波：脉冲里混入一丝噪声毛刺（听得出来"这条不对劲"，但不确定是哪条）。
  - 命中：上行三音 + 气泡尾音。
- **封面设计提案**（640×640，遵循 `docs/COVER-STYLE.md`）：
  - 居中主体（占 60–75%）：**一枚 3D 软胶声呐浮标**——半球形软胶顶 + 底部环形回波振子，球体表面高光饱满、边缘圆润倒角，球体内部透出一束探照灯暖光。
  - 背景：青绿 → 深靛的竖向渐变，周围漂浮 3–5 枚半透明软胶气泡与两圈极淡的同心回波柔光。
  - **零文字**（不出现数字、问号或任何字符）。

## 5 · 制作人拍板与开放探讨

1. **题材方向**：
   - **A（推荐）深海声呐猎潜** —— 幽蓝霓虹 + 金属机电，"大/小"译成"回波偏左/右舷"，还能用左右声道播报方向，题材与机制咬合最紧。
   - **B 赛博金库破解** —— 明亮暖橙 + 全息密码轮，"大/小"译成"继电指示灯"，观感更轻快、更大众。
   - **C 复古雷达站** —— 军绿磷光 CRT + 扫描线，怀旧硬核，视觉更冷。
2. **噪声机制的编排节奏**：
   - **A（推荐）循序渐进**：1 章纯教学 → 每章只加一种噪声，玩家逐个学会"怎么对付它"。
   - **B 高压猎场**：从第 3 关起就混合漂移 + 谎灯，全程高压，硬核但可能劝退新手。
