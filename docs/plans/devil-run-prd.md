## 1 · 创意概念与核心乐趣

- **游戏名称**：恶魔迷途 / Devil Run / 建议 slug：`devil-run`
- **一句话玩法**：操控一只小方块奔向终点门，但脚下的地砖、头顶的天花板、甚至重力本身都会在你起跳后才翻脸。
- **核心乐趣与卖点**：
  - **“死亡即教学”的极致快失败循环（Learn-by-Dying）**：这是一款**零惩罚**游戏——死一次只花掉 1～3 秒，回本关起点、立刻可动。**陷阱位置永远固定**，所以每一次死亡都不是白死：它给你一条确凿的新信息。玩家的成长曲线不是“手越来越稳”，而是“脑子里的地图越来越全”。这就是本作让人放不下手柄的根源——**从“这游戏耍我”到“我知道你下一步要耍什么”的认知翻转**；
  - **反预判的心理喜剧（Anti-Expectation Comedy）**：本作的敌人不是怪物，是**你自己的经验**。游戏先教会你“地板能踩、门能进、重力向下”，然后逐关把这些常识当笑话讲出来——你踩过的砖突然消失、你快要摸到门时门直接跑路、你跳起来的一瞬间上下颠倒。笑点来自**预期被精确击碎**，而不是血腥或恶意；
  - **几何极简的“一眼就懂”（Readable at a Glance）**：黑白几何色块风格——小方块是你、亮色门是目标、红色是危险、灰砖是地面。零教程、零文字、零语言门槛，任何国家的玩家打开就知道怎么走，天然适合病毒式传播；
  - **体量极轻但执念极深（50 微关卡 × 可收藏钥匙）**：单关平均 15～30 秒，一口气能连打十几关；但每关藏一枚**蜡烛（可选隐藏收集品）**，想要全收集必须主动走进陷阱的嘴里。主线 15 分钟可通，全蜡烛可能要几小时；
  - **天然的“你行不行”社交货币（Brag Loop）**：死亡次数会被记账。当朋友说“这游戏简单”，你只要说“几关？死几次？”——结算页的**死亡计数与蜡烛收集**就是最好的下战书的筹码。

- **核心循环**：
  ```
  看见终点门 ➔ 起步奔跑（此刻一切正常，信心满满）
       ↑                                        ↓
  重生（≤0.4s）➔ 记住陷阱位置             触发陷阱（地砖塌陷 / 尖刺弹出 / 门飞走 / 重力翻转）
       ↑                                        ↓
       └───────── 发出“啊？？”的一声笑 ◄─── 方块被压成纸片 / 掉进虚空
                                                     ↓
                        认知升级：“原来这块砖是假的” ➔ 用新知识重跑本关 ➔ 过关
                                                     ↓
                        进入下一关 ➔ 游戏立刻教下一课（且往往与刚学的相反）
                                                     ↓
                        收集到蜡烛 ➔ 第 5 关结算“恶魔印章” ➔ 想继续 / 想回头刷全收集
  ```

**我们要继承的成熟机制**：

1. **陷阱工具箱全谱系（Trap Toolkit）**：不做只靠“地板塌陷”一招吃到死。地砖塌陷、尖刺弹出、天花板坠落、假砖、假门、移动终点、重力翻转、反向操作、弹簧过冲、隐形尖刺——十余种陷阱构成**关卡设计词汇表**，每关只在其中挑 1～2 个做主戏，保证 50 关全程有新鲜感；
2. **“先承诺、后翻脸”的触发器模型（Commit-Then-Reveal）**：所有陷阱都在玩家**已经投入动作、无法反悔**的那一刻才发动。玩家踏进触发格 → 地砖才塌；玩家起跳 → 天花板才掉。这是幽默感的来源——**游戏不是比你手快，是等你交出决定**；
3. **固定位置的可记忆性（Deterministic Traps）**：同一关的陷阱位置、触发条件、发动时序**永远一致**。这既满足平台“杜绝死局、杜绝纯运气”的铁律，也是本作从“恶意”升级为“幽默”的关键——**玩家永远可以靠记忆通关**；
4. **极速重生（Instant Respawn）**：死亡到可控 ≤ 0.4 秒，无白屏、无加载、无死亡动画拖沓。这是 IWBTG 与 Level Devil 共同验证过的成瘾性命脉；
5. **成熟平台手感三件套**：**动量继承**（跑动跳带前冲）、**Coyote Time 土狼时间**（离台后 ~90ms 内仍可跳）、**跳跃预输入缓冲**（落地前 ~120ms 按跳不吞键）——极简操作也必须跟手，否则“被耍”会变成“被卡”；
6. **无文字教学（Language-Free Teaching）**：零文案、零教程弹窗，第一关用最朴素的几何布局教会“跑、跳、进门”，后续所有规则都靠关卡自身演示。天然适配全球玩家与全站 i18n 体系。

**本作的独特魅力与微创新（拒绝无聊照搬）**：

1. **“恶魔印章”关卡评价体系（Devil Seal）**：**不算总分，只发印章**。每关结束显示三枚可点亮的印章 —— **通关印**、**蜡烛印**（找到隐藏蜡烛）、**无伤印**（零死亡通关）。印章是**永久点亮**的（拿到就保留，不可被覆盖），鼓励玩家在轻松通关后回头精修。五个小关组成一个小节点（详见 §3.5），节点全印章点亮时盖上一枚**大恶魔印章**；
2. **隐藏蜡烛（可选深度）**：每关藏一枚暗红色小蜡烛，**位置永远放在陷阱的必经路线上或陷阱的嘴里**——想要拿到它就必须主动走进已知的恶意里。这让“我已经通关了”和“我通关得很体面”成为两件不同的事，用最低的实现成本提供最长尾的重玩驱动；
3. **“第二次是喜剧”的关卡编排法（Comedy of the Second Time）**：本作明确 **75% 的死亡必须发生在第一次**。因此关卡编排遵循“**新陷阱主关 ➔ 同陷阱变体关 ➔ 复合关**”的三明治节奏——玩家第一次被耍会“啊？”，第二次会笑，第三次就能熟练破关。**幽默必须有节奏，不能连续惊吓**；
4. **恶魔的“回声”与死亡纪念碑（Death Ledger）**：死亡时会在地面留一枚淡淡的**小恶魔脚印**，本关重跑时脚印仍在，第 5 次死亡时地面会出现一个小小的、笑话你的恶魔表情。它把“你死了多少次”变成可见的舞台道具，把挫败感转成一种自嘲的游戏性；
5. **蜡烛竞速（可选的第二层玩法）**：不做无尽冲分、不做每日挑战。取而代之，每关记录**本机最佳通关用时**与**最少死亡次数**，可选开启“蜡烛跑”——在不死的前提下拿到蜡烛通关才算“全清”。这是给老玩家的纯度挑战，而不是给所有人的分数绑架。

## 3 · 玩法规则与交互说明

### 3.1 场景构成

- **舞台**：单屏**固定镜头**的矩形关卡（视口约 20×12 单位，与一格地砖尺寸成整数比），关卡不滚动、不缩放，玩家一眼看全整张图——**看全图才有“预判”可言，预判才有“被背叛”的乐子**；
- **主角**：一只纯色小方块（约 1 格宽 × 1.2 格高），可左右移动、单段跳。无攻击、无技能、无道具（除隐藏蜡烛）；
- **场景元素**：
  - **地砖**：可踩的实心格，灰色平涂带上下倒角；
  - **终点门**：亮色拱形门框，进入即通关。**门的位置是关卡的“剧本”，可以跑、可以藏、可以变假**；
  - **尖刺**：红色三棱三角，接触即死；
  - **虚空**：关卡边界外，坠落即死；
  - **蜡烛（隐藏）**：暗红色小蜡烛，触碰即收集，不影响通关判定；
- **初始状态**：小方块总在关卡左侧固定出生格，**面向右方**（永远暗示“目标在右边”，而本作最爱做的就是让这句话不成立）。

### 3.2 玩家合法操作

- **移动**：`←` `→` 或 `A` `D`，加速度式移动带摩擦减速（不做瞬时变速，避免“被耍”与“手感差”混为一谈）；
- **跳跃**：`space` / `↑` / `W`，单段跳，高度与滞空时间固定（**不设可变跳跃高度**，因为本作的生死判定必须让玩家能凭记忆精确复现）；
- **重生**：`R` 键随时手动重开本关（不消耗任何东西）；
- **移动端**：屏幕下缘左右两个大号实体按键台 —— **左侧方向键台（◀ ▶ / 左右切为两块）**、**右侧跳跃大按钮**，全部 ≥ 44×44pt 且互相间隔 ≥ 12pt，支持多点触控（按着左移同时起跳是基本操作，绝不能吞第二个触点）；
- **触控防误触**：跳跃键上滑不触发、长按不连跳、边缘 8pt 死区不响应，避免移动中被误触重生或跳跃。

### 3.3 陷阱工具箱（本作的关卡设计词汇表）

这是本作真正的“游戏内容”。**每关只在下列工具箱中挑 1～2 个作为主戏**，严禁单关堆叠三种以上，否则会从幽默滑向恶意。

| # | 陷阱名 | 发动逻辑（先承诺后翻脸） | 幽默来源 |
|---|---|---|---|
| 1 | **塌陷地砖** Collapsing Floor | 玩家踩上后 **0.15～0.3s** 才塌，给你“来得及”的错觉 | “我踩上去了……诶？” |
| 2 | **弹出尖刺** Pop-Up Spikes | 走进其**上方格**时才弹起，非预设位置常驻 | 你跳过去的那一秒它才长出来 |
| 3 | **坠落天花板** Falling Ceiling | 起跳瞬间整块天花板脱落砸下 | 跳得越高，砸得越响 |
| 4 | **伪装地砖** Fake Tile | 与普通砖**完全同款**，一碰即碎，无任何音效预警 | 你根本不知道该信哪块砖 |
| 5 | **消失平台** Vanishing Platform | 玩家离开后才消失，回头路没了 | 你的退路是自己踩没的 |
| 6 | **弹簧过冲** Spring Overshoot | 踩上弹簧后被弹得**远超预期**，正好飞进尖刺 | 它其实很“帮忙” |
| 7 | **假门** Fake Door | 进入后立即消失，或弹出尖刺，或把你弹回起点 | 胜利就在眼前，然后没有然后 |
| 8 | **移动终点** Running Door | 见玩家靠近就滑走，追两步才停 | 猫抓激光笔 |
| 9 | **重力翻转** Gravity Flip | 踩上特定格 → 上下颠倒，天花板变地面 | 你得重新学走路 |
| 10 | **反向操作** Reversed Controls | 穿过特定区域后左右颠倒（有明显的视觉标识） | 你的手和你的眼开始吵架 |
| 11 | **隐形尖刺** Invisible Spikes | 只在玩家距其 **2 格内**才显形，有 0.3s 的显形到激活窗口 | 你有 0.3 秒可以反悔 |
| 12 | **传送错位** Misaligned Portal | 传送门出口位置随机偏移一格（**在 3 个固定候选位中确定性轮换**，非真随机） | 你落进了隔壁那条沟 |

> **红线：所有陷阱必须确定可复现。** 候选位轮换要走确定性序列（`mulberry32` 注入种子），同一操作序列必然导致同一结果。**绝不允许“同一操作两次结果不同”的随机致死**——那是恶意，不是幽默，也直接违反平台“杜绝纯运气死局”的铁律。

### 3.4 胜负判定与容错

- **通关条件**：小方块进入终点门的判定框，唯一且明确；
- **失败条件**：接触尖刺 / 坠入虚空 / 被天花板压中 / 触碰致死地形——任一触发即死亡；
- **死亡处理（极致宽容）**：
  - 死亡 → **纸片压扁/碎裂动画约 0.25s** → 本关起点重生，**重生到可控 ≤ 0.4s**；
  - **不扣分**（本作没有分）、**不重置已收集的蜡烛本关状态**（本关内重跑保留已捡蜡烛？→ **不保留**：蜡烛仅在本关一次性通关过程中有效，死了就重新捡，否则蜡烛会失去“必须从陷阱嘴里抢”的紧张感；但**已盖下的恶魔印章永久保留**）；
  - **不重载页面**、不闪烁白屏、不打断音频上下文、不弹出任何对话框；
  - 死亡时只在关卡内留下一枚**淡色小恶魔脚印**（本关重跑保留），第 5 次死亡时多冒一个**嘲讽小恶魔表情**（纯视觉，不带文字）；
- **无死局与可解性保证（平台铁律，必须落实）**：
  - 50 关**全部手工精编**，陷阱以**纯数据声明**（触发格 + 目标格 + 延迟时序 + 复活后是否复位）；
  - 每关必须内置一条**黄金路径重放校验**：开发端录制一条通关输入序列，在确定性种子下重放必须复现通关；这条测试进单元测试套件；
  - **陷阱复位一致性**：死亡重生后所有陷阱必须复位到关卡初始状态，绝不允许“陷阱已经用掉了所以这关变得不可解”或“陷阱没复位导致玩家必经之路已被堵死”的情况；
- **永不卡死**：单屏固定关卡、无移动机关追踪玩家、无需要“等的时机”才能通过的窄缝设计，保证玩家永远可以立刻重跑而无需等待。

### 3.5 模式与内容编排（依玩法特质定制，不套“无尽冲分 + 每日挑战”三件套）

**主线 · 恶魔的十个印记（50 微关卡 = 10 节点 × 5 关）**

这是主菜，评价用**恶魔印章（见 §1 微创新 1）**，不用总分。

| 节点 | 名称 | 引入的陷阱（每关 1～2 个） | 教学与幽默重点 |
|---|---|---|---|
| **1** | **蜜月期** | 无（前 3 关全部安全） | **先建立信任**。这 5 关故意一个陷阱都不放（或只在第 5 关放唯一一个最经典的塌陷地砖）。玩家在“完全放松”的状态下被第一次背叛，笑果最大化 |
| **2** | **脚下的谎言** | 塌陷地砖、伪装地砖 | 教你“地面不可信”。第一次要求玩家**主动跳着走** |
| **3** | **头顶的恶意** | 弹出尖刺、坠落天花板 | 教你“垂直方向同样危险”。跳跃从享受变成赌博 |
| **4** | **看得见的骗局** | 消失平台、弹簧过冲 | 明牌陷阱，考验借力打力与路线规划 |
| **5** | **终点的把戏** | 假门、移动终点 | 第一次把“目标”本身变成对手，心理落差最大的一节点 |
| **6** | **颠倒世界** | 重力翻转 | 整节点一场“重新学走路”的演出，天花板变成唯一的地面 |
| **7** | **左右为难** | 反向操作 | 手眼打架，全场最“喜剧”的一节点 |
| **8** | **看不见的刀** | 隐形尖刺 | 从“记忆位置”升级到“记忆时机”，最考验观察的一节 |
| **9** | **空间错位** | 传送错位（确定性轮换）+ 复合陷阱 | 前 8 类陷阱的两种组合，难度峰值 |
| **10** | **恶魔的毕业考** | 全工具箱混编 | 5 关总复习，每关 3 层陷阱嵌套，通关即盖满全部十枚大恶魔印章 |

- **节奏规则（硬性编排准则）**：
  - **每节点第 1 关必为单陷阱主关**（新机制的纯净教学），**第 3 关为变体关**（同一陷阱换个角度耍你），**第 5 关为节点小考**（本节点陷阱混合 + 蜡烛藏在最阴的地方）；
  - **严禁连续三关都是高难度**。任何一关的**首次通关平均死亡次数超过 8 次**，即判定为设计过载，必须拆掉一层陷阱或延长触发窗口；
  - 每个节点内至少保留 **1 关“纯跑酷关”**（无陷阱，只有几何美感与爽快节奏），作为喘息与奖励——**没有喘息的受虐是折磨，有呼吸的受虐才是喜剧**。

**蜡烛跑（可选挑战层）**

- 每关一枚隐藏蜡烛，位置**永远在陷阱的必经路径或陷阱嘴里**；
- 结算页显示“**不死且拿到蜡烛**”才算完美记录（本机保存，无上传无排行）；
- 全 50 枚蜡烛集齐 → 解锁最终关卡的**“恶魔的镜子”结局装饰**（纯视觉彩蛋，无新玩法）。

**每日挑战：不做。**

> 本作的核心乐趣是**固定关卡的精修与记忆**——玩家反复重跑同一关，追求零死亡与蜡烛。每日换盘会直接摧毁这种“肌肉与记忆的精进感”，且与“陷阱固定可记忆”这个立身之本相冲突。取而代之的是**蜡烛跑与印章收集**，这是本作自己的长尾。

**双人对战（体量允许时的加分项，不作为首版必做）**

- 同一设备分屏轮转或同屏竞速：两台小方块同时起跑，**先到门者得分**，5 局 3 胜；
- 陷阱对两人**独立触发、互不干扰**（不做“一人踩塌把对方害死”的设计，避免变成互相伤害的僵局）；
- 这是 Level Devil 已验证的成熟模式，实现成本低、社交传播力强，建议作为**首个迭代版本**的内容（见 §5 拍板项 3）。

### 3.6 目标与反馈体系

- **核心目标指标**：不是得分，是 —— **恶魔印章（3 枚 / 关）**、**通关用时**、**本关死亡次数**；
- **关卡内即时反馈**：
  - 移动：方块带轻微挤压拉伸（跑动时略微前倾，起跳瞬间纵向拉伸），落地有轻微下压回弹；
  - 陷阱发动：**必须先给一个 0.1～0.2s 的可辨识前兆**（地砖裂痕、尖刺脚下的红点闪光、天花板落灰）——前兆让玩家“看懂了但来不及”，这才是幽默；完全无预兆是恶意；
  - 死亡：方块被压成纸片并碎裂成粒子（**不播放大音量惊吓音**，而是一记滑稽的“啵”），屏幕不震；
- **通关反馈仪式**：进门 → 门内亮起光晕 → 方块被光吸入门中并缩放消失 → 结算板从上方落入，逐枚点亮印章（每枚点亮配一声上行清脆音，印章落下有实体“盖章”音）→ 印章点亮时轻微弹跳；
- **节点完成仪式（每 5 关）**：整块关卡舞台**反转成恶魔配色一瞬**（黑底白线转白底红线），一枚大恶魔印章重重压下并带动屏幕微震，短暂 0.3s 后回正——这是本作唯一允许的“盛大”时刻，因此格外有重量。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：**黑白几何剪纸（Paper-Cut Geometry）**、**软胶玩具质感**、**红色是唯一的危险语言**、**地狱橙红微光边缘**、**极简撞色**。

- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**
  - **整屏是一座“恶魔的游戏机台”**：中央是固定镜头的关卡舞台本体，四周是**深色几何构成的机台框体**（黑底 + 细白色几何网格纹理 + 边缘一圈缓慢呼吸的橙红光晕，暗示“这是一台来自地狱的机台”）；
  - **禁止四角浮动按钮**：返回首页 / 音效 / 语言 / 帮助，全部收进**机台顶边一条内嵌状态槽**——做成机台顶部的**铭牌凹槽**造型，上面刻“恶魔迷途 · 节点 3”，像街机顶部的金属招牌，与框体熔铸而非漂浮；
  - **禁止右侧 SaaS 卡片堆**，HUD 全部实体化为机台部件：
    - **左翼 · 印章台**：三枚当前关卡的印章凹位（灰 → 点亮），下方一枚大印章槽显示本节点 5 关的完成度。造型是**一块嵌进机台的暗色石牌**，印章是凹进去的压印；
    - **右翼 · 死亡碑**：本关死亡次数做成**一台老式机械计数器**（黑底白字，数字翻动时带机械滚轴动画）——这是本作的灵魂部件，不要做成一个寒酸的文字标签；其下方是“本关最佳用时”与蜡烛状态（一枚暗红小烛图标，点亮/熄灭）；
    - **底部 · 操作台**：一条窄的实体操作条（重开本关 `R` / 选关 / 音效），嵌在机台下沿，桌面端**不贴屏幕底边**；
  - **桌面端（≥900px）**：**关卡舞台居中（本体宽度 ≤ 720px，4:3 或 16:10）**，两侧飞翼为左印章台 / 右死亡碑；**≥1200px** 时两翼展开为完整部件，900–1199px 收为贴舞台侧缘的窄条；**左右屏幕边缘与底部边缘严禁放置任何关键按钮与核心 HUD**，为未来广告位留出安全区；
  - **移动端（≤768px）**：转为**竖排掌机**——顶边铭牌槽（内嵌印章三枚与死亡计数器，压成一行小图标）+ 关卡舞台 + 底部实体按键台（左侧左右键台 + 右侧跳跃大按钮）；主容器 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，**绝不让按钮贴底被 Banner 广告压住**；按键台本身是掌机面板的一部分，不是浮在画面上的半透明圆片。

- **色彩与环境氛围**
  - 主调：**近黑深灰的机台底色 + 舞台内的白/浅灰几体块 + 唯一的高饱和红（危险）+ 唯一的暖黄（终点门）**。**红色在本作中是唯一的危险语言，必须严格独占**——任何非致死的装饰都不允许用红；
  - 终点门用**暖黄 → 蜜橙**的柔光渐变，门框带呼吸脉动（`createRadialGradient` 无边界柔光，**严禁描边圈**）；尖刺是**哑光的猩红**，不发光（发光的危险会显得“可亲近”，而本作要它一眼就可怖）；
  - **主角辨识靠柔光与明暗**：小方块本身是浅色平涂 + 上下倒角，其“我在哪”靠**脚下的一圈无边界径向暖光**与**呼吸脉动**来托出，绝不用描边轮廓，也不套光环圆盘；
  - 环境：舞台外**橙红光晕缓慢呼吸**、机台网格线有极缓慢的明暗流动、偶尔有一两粒暗红余烬粒子从下往上飘；**禁死黑**——机台底色是深灰而非纯黑，舞台内有微弱的纸质纹理与四角暗角，保证投影仪/低质量屏幕上仍能看清全部几何边缘；
  - **动效降级**：`prefers-reduced-motion: reduce` 下 —— 粒子静止、光晕呼吸停止、印章落下改为直接出现、屏幕微震取消、方块挤压拉伸改为固定尺寸。

- **音效氛围（WebAudio 程序化合成，零素材）**
  - 底噪：极低音的**低频嗡鸣**（略带失谐的两音叠加，营造“地狱机台在运转”的不安感），音量压到几乎听不见；
  - 移动：几乎没有音效（保持干净），仅落地有一记轻“嗒”；
  - 跳跃：短促上扬的方波“哔”（约 440Hz → 660Hz，60ms）；
  - **陷阱发动**：一记**木琴式的下行三音**（玩家一听就知道“我又上当了”），而不是刺耳警报——这是本作的“笑点音效”，必须滑稽；
  - 死亡：一记闷响的“啵” + 纸片碎裂的细碎噪声（不惊吓、不刺耳，配合压扁动画）；
  - 蜡烛收集：清脆的单音风铃（高音，干净明亮）；
  - 进门通关：暖场三音上行琶音；
  - **印章盖章**：一记扎实的低频“咚”（带短促的纸张摩擦音），节点大印章则是更重的一记并带 0.3s 的低频拖尾。

- **封面设计提案**（遵循 `docs/COVER-STYLE.md`，并同步登记色相表）
  - 3D 软胶，单一居中主体：**一只圆角软胶小方块，正惊恐地从一块正在塌陷的地砖上跳起，脚下裂开的黑缝里伸出一簇猩红小尖刺**；方块带明显的挤压拉伸动感（下半身被拉长），表情以两点极简的眼睛构成惊恐；
  - 背景：**靛蓝/深青 → 紫红**的明亮渐变（**靛蓝/深青为封面登记表未占用色相**；**避开**蓝紫、青绿、天蓝、绯红、玫瑰粉、明黄、蜜橙，这些已被现有封面占用），四周漂浮 3～4 粒橙红余烬粒子；
  - 主体占比约 **68%**，左上主光、投影短软，橙红余烬与主体形成撞色；
  - 无任何文字 / logo / 角标，640×640 WebP，右下角水印清干净；
  - 备选：**橙红 → 暗红**背景（与“恶魔”母题最贴合，但必须确保背景有色不暗、不沦为死黑）；若整墙看后与 `fire-ice`、`candy-drop` 等暖色系封面挤在一起偏重复，则回退到靛蓝/深青主案。

## 5 · 制作人拍板与开放探讨

1. **陷阱的“前兆”给到什么程度？（决定本作是幽默还是恶意）**
   - **A（推荐）· 有前兆的幽默**：所有陷阱发动前给 **0.1～0.2s 的可辨识前兆**（地砖裂痕、尖刺脚下红点闪光、天花板落灰、假门轻微抖动）。玩家会经历“我看懂了但来不及”的会心一笑——这正是 Level Devil 之所以是“好笑”而非“可恨”的分界线；
   - **B · 零预兆的硬核**：完全不提前兆，纯凭记忆硬吃。初见杀最狠、爽点最刺，但会让相当一部分玩家判定为“这游戏在整我”，与“传播力极高”的目标相悖；
   - **C · 渐进式**：前 3 个节点用 A（有前兆），后 7 个节点用 B（零前兆）。难度曲线最平滑，但实现上要做两套陷阱参数，且会让前期的“信任建立”与后期的“背叛”显得不一致。

2. **蜡烛收集的定位？（决定本作有没有长尾）**
   - **A（推荐）· 硬核可选收集**：每关一枚蜡烛，位置永远在陷阱的必经路线或陷阱嘴里；死了就重捡。主线 15 分钟可通，全蜡烛可能要几小时。**用最低实现成本换来最长尾的重玩驱动**，且结算页的“不死 + 拿到蜡烛”天然就是老玩家的炫耀资本；
   - **B · 不做收集，只做印章**：印章只保留“通关印 + 无伤印”两枚。更简洁纯粹，但玩家在通关后基本没有理由回头——本作体量只有 50 关，没有长尾就会很快被玩完；
   - **C · 蜡烛作为解锁钥匙**：集齐某个节点的 5 枚蜡烛才解锁下一节点。强制玩家必须直面陷阱，深度最高；但会让“卡在某个陷阱贪不到蜡烛”的玩家彻底卡关，与“零挫败快速循环”的核心体验直接冲突——**不推荐**。

3. **首版是否包含双人对战？**
   - **A（推荐）· 首版不做，列为第二迭代**：先把 50 关单机主线的陷阱手感、快速重生、印章系统打磨到经得起老玩家检验（这是本作的地基，任何地基不牢的附加模式都是浪费）。双人作为已验证的成熟模式（Level Devil 的 5 局 3 胜），在首版上线后作为内容更新推出，还能带动一波二次传播；
   - **B · 首版就做双人同屏竞速**：社交传播力最强、话题性最高，一台设备两人开跑非常适合聚会场景。代价是关卡要额外做一次双人可行性校验（两人同屏跑，陷阱触发互不干扰的边界情况要逐个测试），工期与测试面显著增加；
   - **C · 不做双人，改做“幽灵对跑”**：单人模式下可挑战**自己本关最快通关的影子**（幽灵方块与你同屏跑，轨迹由本机最佳记录重放）。实现比双人轻得多（单机、无网络、无账号），又能提供“打赢自己”的长期驱动力，非常契合本作“精修同一关”的玩法骨相。

**默认建议：1A + 2A + 3A**——先用**有前兆的幽默**把“被耍”做成会心一笑而非可恨的恶意，这是本作能否达成“传播力极高”的生死线；用**硬核可选蜡烛**给仅 50 关的轻体量补上长尾；最后把双人推给第二迭代，让首版的全部工时砸在最关键的**陷阱手感与重生流畅度**上。
