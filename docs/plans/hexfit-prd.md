## 1 · 创意概念与核心乐趣

- **游戏名称**：六边蜜筑 / Hexfit（副标：蜂巢满行消除 · 三轴连击）/ 建议 slug：`hexfit`
- **一句话玩法**：把随机蜜蜡块填进蜂巢棋盘，凑满任意一条蜂房行就蜜流消除——消得越多、连得越狠，极限倍率 2¹⁸ 蜂王浆金标！
- **核心乐趣与卖点**：
  - **蜂巢 ≠ 方格的三轴空间（Hex Space · 用户点名核心）**：六边形网格每个格有 **6 个邻居**（方格只有 4 个），满行沿 **0°/60°/120° 三条轴**任意方向成立——填放时"这一格会连成哪条行"的空间直觉完全不同于方格消除，是全新的脑力形态；
  - **随机块与满行消除的即时推演（Place & Clear）**：每次拿到随机蜜蜡块，扫一眼棋盘找"能消的位置"——留缝、搭桥、一次消多行，每一步都是对蜂巢结构的即时推演；
  - **满行消除 4/4/4/4 连击翻倍（Row Clear ×2 · 用户点名核心）**：一次放置同时消 N 行，倍率 **2^(N−1)**（1 行 ×1、2 行 ×2、3 行 ×4、4 行 ×8 四档）；消 4 行即进入**蜜流狂潮**，此后连续放置即消再 ×2 连乘，**极限 2¹⁸ = 262144 倍蜂王浆金标**——一次巧妙的四连消可能直接翻盘；
  - **三轴共鸣的连击美学（Tri-Axis Combo）**：同一块同时补完两条轴的行、蜜流从两个方向同时涌出——蜂房瞬间"亮蜜"的满足感是方格游戏给不了的；
  - **网格形态差异化补位（Honeycomb Gap）**：DOIN 62 款中全是方格系（2048、picross、数独等），本作以**蜂巢网格 + 三轴满行**的差异化网格形态补位，且蜂巢本身就是最天然的题材。
- **核心循环**：
  ```
  观察棋盘找可消位置 ➔ 放置蜜蜡块（占格/补行）➔ 三轴满行检测（0°/60°/120°）
       ↑                                                    ↓
  蜜流消除（蜜流粒子·音阶）← 连击 +1 · 倍率 ×2 爬升 ← 满行 N 行（4/4/4/4 档位）
       ↓（无满行 / 连击中断）                          ↓（消 ≥4 行）
  新随机块入队（hex-bag 确定性）                    蜜流狂潮 · 目标 2¹⁸ 金标
       ↓（棋盘放不下）
  本局结算（消除数/最高连击）➔ 章节星级 / 双人胜负 ➔ 再来一局
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Hex FRVR（2014 Web）** | Web | 六边形棋盘、六连块填放、满行消除 | 蜂巢填放消除的祖师级原型，规则极简 | 六边网格棋盘、三轴满行、块队列 | 纯无尽生存、无连击倍率反馈 |
| **Hexa Puzzle / Hexa Blast（移动爆款）** | 移动 | 给定块填六边盘、满行消除 | 蜂巢消除在移动端的国民级验证 | 块形状设计、满行消除爽感、消除后下落 | 广告驱动、无章节目标 |
| **Block Blast / Blockudoku（方格爆款）** | 移动/Web | 方格盘填块、满行/满块消除 | 填放消除的连击与布局艺术 | 连击倍率与残局目标设计 | 方格 4 邻域（本作异质：六边 6 邻域） |
| **Tetris（1984）** | 街机/全平台 | 下落拼块、满行消除 | 行消除与堆叠博弈的百年范式 | 满行消除、块队列确定性（7-Bag） | 重力下落节奏（本作为自由放置） |

**我们要继承的成熟机制**：
1. **蜂巢网格与三轴满行（Honeycomb & Tri-Axis Clear）**：六边形棋盘，满行沿 0°/60°/120° 三条轴任意成立，满行即消除、上方块沿纵轴下落——Hex FRVR 验证过的核心；
2. **确定性块队列（Seeded Bag）**：块形状队列用确定性 **hex-bag**（形状种类有保证、可注入种子），杜绝连续同形堵盘的玄学；
3. **放置合法性校验（Valid Placement）**：块必须全部落在空位上且不越界，无合法位置即本局结束——规则透明、无 `alert()`；
4. **连击倍率反馈（Combo Multiplier）**：一次放置消多行的倍率奖励与连击反馈——Block Blast 类爆款的成瘾引擎；
5. **固定步长确定性逻辑（Deterministic Logic）**：120Hz 纯函数帧步进、种子注入、同种子重放一致、格数守恒可断言（本策划案的核心契约）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **三轴共鸣消除（Tri-Axis Resonance）**：一次放置可同时补完两条甚至三条轴的满行——多个方向的蜜流同时涌出，视觉与音效多通道共鸣，这是蜂巢区别于方格的核心奇观；
2. **满行消除 4/4/4/4 连击翻倍（Row-Clear Quadruple ×2 · 用户点名）**：单次消 N 行倍率 2^(N−1)（四档 ×1/×2/×4/×8），消 ≥4 行触发**蜜流狂潮**（后续连击 ×2 连乘），**极限 2¹⁸ = 262144 倍蜂王浆金标**——把"一次消 4 行"做成整局翻盘时刻；
3. **章节残局编排（Staged Riddles）**：蜂巢消除少见地采用章节目标制（给定块序 + 目标消除数/连击/特定轴行），配 solver 可解性校验——可背板、可测、有成长线；
4. **共享棋盘双人蜂战（Shared-Hive Duel）**：同一蜂巢棋盘轮流放置，占位即博弈——你占的格子就是对手缺的空位；
5. **蜂房酿蜜原生视窗（Honeycomb Craft）**：蜂巢既是网格形态又是题材——木框蜂箱、蜜蜡块、蜜流、蜜罐计分全原生，全站无同款视窗。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（蜂巢棋盘，俯视 2D）
- **蜂巢棋盘（Honeycomb Board）**：六边形网格，**半径 4（共 61 格）**，每格为正六边形蜜房（3 轴向：0°/60°/120°）；
- **蜜蜡块（Wax Pieces）**：由 1~5 个正六边形组成的蜜蜡拼块（二连、三连直线/弯角、四连方形/菱形、五连蜂簇等，8~12 种形状）；
- **块队列（Piece Queue）**：顶部展示下一块（可选展示下 2 块）；队列由确定性 hex-bag 生成（形状种类均衡、种子可注入）；
- **蜜罐计分（Honey Jar）**：消除的蜜以"蜜滴"计数入罐——普通消除计分、连击翻倍时蜜流加倍、2¹⁸ 金标入"蜂王浆金罐"；
- **采蜜黑板（Chalkboard）**：墙面粉笔黑板记录章节目标、最高连击、蜜罐总量。

### 3.2 判定与计分规则（核心契约：满行消除 4/4/4/4 → 2¹⁸）
1. **放置（Place）**：从队列取一块，点击棋盘空位落子（块可旋转 60°、可拖动到任意合法位置预览）；必须全部落在空位上，否则不可放置；
2. **三轴满行检测（Tri-Axis Row Clear）**：每次放置后，沿 **0°/60°/120° 三条轴**扫描——任意一条轴上出现**连续满格行**即消除（该行所有格清空，计 1 行）；
3. **重力下落（Gravity）**：消除后，行上方所有块沿纵轴下落填补空位（确定性顺序），下落稳定后再次满行检测（级联消除）；
4. **满行消除倍率（用户点名公式固定）**：
   - 一次放置（含级联）消除 N 行，本波倍率 = **2^(N−1)**：1 行 ×1、2 行 ×2、3 行 ×4、**4 行 ×8（四档 4/4/4/4）**；
   - 每消除 1 行基础 100 分，单行得分 = `100 × 本波倍率`；
   - **消 ≥4 行触发蜜流狂潮**：此后每次"放置即消"连击 +1、倍率再 ×2（连乘），中断（放置未消）则狂潮结束、倍率回 1；
   - **极限蜂王浆金标（2¹⁸）**：倍率封顶 **2¹⁸ = 262144 倍**（"218"金标）——单行爆出 26,214,400 分，触发金罐演出（蜜罐爆闪 + 金蜜喷泉 + 全场暖光）；
5. **胜负与评级**：
   - **经典生存（Survival）**：块队列用尽或棋盘放不下任何块即本局结束；结算 = 消除总数 + 最高连击；
   - **章节残局（Campaign）**：每关给定块序与目标（消除 ≥ N 行 / 单次消 ≥ 3 行 / 达成 ×16 倍），投块数用尽未达成 = 失败可重试；
   - **同屏双人蜂战（2P Duel）**：共享棋盘轮流放置，消除为自己计分，先达目标分（或对手放不下）者胜。

### 3.3 模式与内容编排（拒绝套路化三件套）
- **单人章节残局（Hex Campaign，主打）**：**4 章 × 6 关 = 24 关**，评价体系 = 星级（目标达成 / 剩余块数 / 最高倍率），绝不做无尽冲分：
  - 第 1 章·蜜房入门：标准蜂巢盘 + 基本块序，目标累计消除 10 行；
  - 第 2 章·三轴共鸣：引入多轴同时满行目标（单次消 ≥ 3 行），学三轴读盘；
  - 第 3 章·蜜流狂潮：目标触发一次狂潮（消 ≥ 4 行）并达成 ×16 倍；
  - 第 4 章·蜂王金标：目标单局倍率触达 ×256（2⁸）以上，收官演出；
- **经典生存（Survival，街机向附加）**：无限块队列、纯满行消除冲高消除数与连击，蜜流速度随连击升级；
- **同屏双人蜂战（2P Duel）**：共享棋盘轮流放置——你占的格子就是对手缺的空位，占位博弈 + 消除博弈一体（见拍板项 3）。

### 3.4 无死局与公平保证（数学可解性）
1. **块队列公平性**：hex-bag 确定性生成，形状分布均衡（每袋含全部形状各 1~2 个），杜绝连续同形堵盘的运气死局；
2. **残局可解性校验**：每关目标跑 **solver 确定性搜索**——断言存在一条合法放置序列达成目标（含消除级联），不满足即重新生成关卡；solver 结果写入测试断言，每次重跑复核；
3. **三轴检测确定性**：满行检测、级联下落、连击倍率全部为纯函数可测逻辑，无随机判消；倍率恒为 2 的幂次且 ≤ 2¹⁸；
4. **确定性契约**：块队列、蜜流粒子、机关触发全部走确定性种子；同种子 + 同输入序列逐帧一致，支持自动化验证；逻辑引擎测试包含 ≥1000 步随机放置游走（状态机不崩、格数守恒、三轴检测正确、倍率断言）。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **桌面鼠标（主路径）**：
  - **取块**：点击队列中的块 = 拾起（悬停预览落位）；**拖动** = 移动预览；**滚轮 / 右键** = 旋转 60°；
  - **放置**：松开左键在合法空位 = 落子；非法位置松手 = 块回弹队列（不消耗、不计失误）；Input Buffer：落子 60ms 窗口接受，连点不吞指令；
  - **预览辅助**：悬停时以柔光高亮"该块落下后将补完的三轴行"（弱提示，不代算最优）；
- **键盘**：`1/2` 切换队列块（取块），`←/→`（或 `A/D`）移动预览，`↑/↓`（或 `W/S`）上下移动预览，`R` = 旋转 60°，`空格` = 放置，`Esc` = 取消拾块/暂停/退回弹层；
- **移动端（触控）**：点队列块拾起、拖动到棋盘放置、双指旋转或点击旋转钮 60°；非法落位回弹；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡放置区；
- **手感调优**：蜜蜡块"噗"的软蜡落位；满行瞬间蜜流"咕噜"涌出 + 蜜滴迸溅；连击每 +1 蜜流音阶上行、蜜罐蜜面上升；2¹⁸ 金标慢镜 + 金蜜喷泉 + 全场暖光。

### 4.1 题材风格关键词
**蜂房酿蜜工坊（Honeycomb Craft）**、春日花园、木框蜂箱、琥珀蜜蜡、暖阳光晕、花粉微尘、蜂蜜金光。

### 4.2 专属视窗物理隐喻（严禁左右双翼模版）
本作不是"网页里嵌个方块消除"，而是一面**木框蜂箱里的蜂房酿蜜墙**：


1. **蜂箱即全部**：蜂巢棋盘嵌在木框蜂箱里，块队列、蜜罐、操作条全部是蜂箱与工作台的原生元素（蜜蜡质感、木纹、蜂蜜滴），**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **蜜流消除奇观**：满行消除不是"行消失"——琥珀蜜流从被消行两端涌出、蜜滴迸溅落入蜜罐，多轴同时消除时蜜流多向共鸣，金标时金蜜喷泉；
3. **采蜜黑板**：章节目标、连击、蜜罐总量写在墙面粉笔黑板上，蜜面上升有蜜滴动画；
4. **环境氛围**：春日花园晨光 + 花粉微尘粒子 + 蜜蜂飞影（慢速飘过），拒绝死黑/死白大平铺；返回、音效、语言收纳进蜂箱顶框一体化状态条；
5. **移动端（≤768px）**：蜂箱压缩为竖持视角，块队列与操作条收折为蜂箱下木质工具条，底部严格预留广告安全避让区，绝不遮挡放置区。

### 4.3 立体质感与渲染路线裁决
- **裁决：纯 Canvas 2D 蜂巢棋盘舞台 + DOM/CSS 3D 木框蜂箱框体**（不做 Three.js）：
  - 蜂巢网格、蜜蜡块、蜜流/蜜滴粒子、三轴高亮 → Canvas 2D（六边形网格绘制 + 深度柔光），120fps 秒开零发热；
  - 蜂箱立体感（木框厚度、蜜罐玻璃、采蜜黑板、花园光晕）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/记分/弹层全部严格留在 DOM 层；
  - 理由：六边网格为平面二维结构，俯视 2D 即可完整表达，无真 3D 视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **蜜蜡落位（Wax Place）** | 软蜡"噗"——温润不刺耳 | 柔和低频 + 短噪声瞬态，软质包络 |
| 2 | **蜜流消除（Honey Flow）** | 琥珀蜜流"咕噜"滑落，黏稠丝滑 | 噪声缓冲 + 低频咕嘟 sweep，随消除行数音高上行 |
| 3 | **蜜滴迸溅（Honey Pop）** | 蜜滴"啵啵"多枚短音 | 多个短 FM 玻音（木琴质感），密度随行数 |
| 4 | **蜂鸣氛围（Bee Hum）** | 花园蜜蜂低嗡，随连击强度升调 | 失谐锯齿波 + LFO 抖动，轻微 |
| 5 | **连击音阶（Combo Scale）** | 连击每 +1 蜜流音阶上行 | FM 木琴五声音阶逐级上行 |
| 6 | **蜂王浆金标（Royal Jelly 2¹⁸）** | 金罐爆闪——金色大七和弦 + 蜜喷泉琶音 | 失谐双振荡器下潜 + 上行琶音 + 高频暖光扫频 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体，占画面 65%~70%——一堆**3D 软胶琥珀蜜蜡六边形块**堆成小蜂塔，顶端一块正被抽出悬空，琥珀蜂蜜从塔身缓缓滴落、拉出透亮蜜丝；
- **背景与氛围**：暖金黄至蜜橙的平滑径向渐变背景 + 花粉微尘与虚焦光斑，蜜蜡软胶质感饱满温润、高光闪亮——一眼传达"蜂巢酿蜜 + 满行消除"的双重气质。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：模式配比？
- **选项 A（章节残局 + 经典生存 + 双人蜂战三轨 · 推荐）**：单人章节残局（4 章 × 6 关 = 24 关）为主打，经典生存与同屏双人蜂战为附加——目标成长、街机爽感、派对博弈三种乐趣齐备；
- **选项 B（章节 + 生存双轨）**：只做单人章节与经典生存，最聚焦、开发量适中；
- **选项 C（纯章节残局）**：只做单人章节，最轻量。

### 拍板项 2：棋盘规模与行消除方向？
- **选项 A（半径 4 · 61 格 + 三轴满行 · 推荐）**：61 格蜂巢盘 + 0°/60°/120° 三轴满行消除，空间层次与读盘压力均衡；
- **选项 B（半径 5 · 91 格 + 三轴满行）**：更大盘面、更长局，生存模式更耐玩但单局偏长；
- **选项 C（半径 4 · 仅单轴满行）**：只沿纵轴满行消除，规则最简、上手最快（向方格玩家平滑迁移）。

### 拍板项 3：同屏双人蜂战形态？
- **选项 A（共享棋盘轮流放置 · 推荐）**：同一蜂巢盘轮流放置，占位即博弈——你占的格就是对手缺的空位，攻防一体；
- **选项 B（各自棋盘竞速）**：双人各一张同种子棋盘，比谁先达成目标消除数，纯竞速无干扰；
- **选项 C（不做双人）**：纯单人体验。
