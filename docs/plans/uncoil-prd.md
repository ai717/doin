## 1 · 创意概念与核心乐趣

### 一句话玩法

> **开局你就是一条盘踞满屏的长蛇，吃掉"蜕身丸"一节节缩短，在被自己困死之前把全身走完。**

### 核心乐趣与卖点

贪吃蛇五十年的本能是「**越长越强，越长越挤，最后被自己挤死**」。《Uncoil》把这条曲线整个翻转：

| | 经典贪吃蛇 | 倒退贪吃蛇 Uncoil |
|---|---|---|
| 长度趋势 | 越来越长 | 越来越短 |
| 主体压力来源 | 未来会变挤 | **此刻就挤到极限** |
| 玩家身份 | 收割者 | **清扫者 / 逃脱者** |
| 情绪曲线 | 紧张 → 暴毙 | **窒息 → 顿悟 → 松开** |
| 身体语义 | 你的资产，也是你的债 | **一堵会随着你的移动而变形的活墙** |

真正的爽感不来自"吃"，来自三件事：

1. **延迟满足式的空间顿悟**
   你想让蛇头落到第 3 行第 5 列，但那一格此刻被自己的第 37 节身体占着。你不能冲刺，只能耐心绕路、让尾巴一 tick 一 tick 地把那段身体撤走，然后在它空出的那一瞬间滑进去。**「等待自己的尸体让路」**——这是本作独一无二的核心快感。

2. **几何清扫的掌控感**
   开局密不透风的网格，随着每一次成功的吞食，可视空间肉眼可见地"松弛"下来。那种从窒息到呼吸顺畅的松开感是这个游戏的情绪主引擎，可以用镜头呼吸感（背景光晕随剩余长度收缩/扩张）做成独特的视听反馈。

3. **零惩罚的从容烧脑**
   没有倒计时，没有随机暴毙。撤销无限次，死不罚分。玩家处在极度放松又能极度专注的状态——这是现代解谜（而非街机）最理想的心流区间。

### 核心循环

```
观察现状（我还有几节？哪几段身体正压着我要去的地方？）
   ↓
规划 3–8 步（先往左两格把尾巴甩开才够钻过去）
   ↓
执行 → 听见"骨节脱落"的清脆反馈 → 目测空间松弛了一圈
   ↓
吞下蜕身丸 → 尾巴一次脱 3 节 → 脱力后空出新走廊
   ↓
下一颗丸在他处"孵化"（光点聚合动画）→ 重新进入规划
   ↓
（死亡分支）头四周全被自己占死 = 困毙 → 屏幕暗下来、播放"石化"演出 → 一键撤销继续思考
```

## 2 · 经典标杆与对标参考

### 成熟标杆原型

| 标杆 | 时代 / 类型 | 它最成熟、最受认可的东西 |
|---|---|---|
| **Blockade**（Gremlin, 1976）→ 诺基亚《贪吃蛇》(1997) | 街机 / 掌机始祖 | **正交网格 + 固定 tick + 输入缓冲 + 自碰撞**。身体的每一节都是不能穿的音障——这条规则五十年没改过，因为它完美。 |
| **Snakebird**（Noumenon Games, 2015） | 现代独立解谜 | **★ 最贴近本作的标杆。** 蛇身长度会变（吃果实变长，吐出缩短），蛇本身既是角色又是地形又是重物；纯关卡制、无限撤销、零失败惩罚。它证明了"长蛇 + 空间解谜"是一条被验证成功的成熟品类。 |
| **Snake-in-the-Box / 最长诱导路径问题** | 数学 / 图论 | **本作的数学基底。** 在超立方体或网格图中找"不自我相邻的最长路径"。本作的每一关，本质就是一个「蛇在盒子里」的可解性命题。 |
| **Baba Is You / Stephen's Sausage Roll** | 现代硬核解谜黄金标准 | **界面哲学**：不弹 "Game Over" 羞辱玩家，死亡只是"状态不对"，随时 Z 键撤销回去。 | 

### 我们要继承的成熟机制

- **固定步长 tick + 输入缓冲**：来自 Blockade/诺基亚。玩家在两帧之间连按两次方向，第二次不能丢失，必须进队列（否则高速操作时手感会"漏掉输入"）。
- **禁止 180° 直反向**：经典铁律。防止玩家一个手滑就撞上自己的脖子。（注：长度 ≤ 2 时应放开限制，否则会锁死。）
- **无限撤销 + 重置**：来自 Snakebird / Baba Is You。这是现代解谜的入场券，不是可选项。
- **「连续软体」平滑插值**：现代 web snake 的标配。格子数据是离散的，渲染必须补间；相邻两节之间用地砖 48 % 半径的圆角关节连接，让长蛇看起来是一条连续的软体而不是一串方块。

### 本作的独特魅力与微创新

1. **反向目标（Reverse Goal）**：不是"活下去"，是"**把自己消耗掉**"。玩家第一次意识到"我的胜利条件是我的消失"时，会产生强烈的认知冲击——这是本作的传播钩子。
2. **动态单一目标（Rolling Pellet）**：盘面上**永远只存在 1 颗可见的丸**（或 1 主 + 1 备选）。吃掉一颗，下一颗才在别处"孵化"。这让视线永远聚焦，画面永远干净，彻底区别于经典贪吃蛇"满地食物"的杂乱观感，也让每一关的节奏像**一连串精心编排的追光点**。
3. **"长度为 routes 的瓶颈＝压力可视化"**：把抽象的解谜压力翻译成一个看得见、可以在 ui 上放大的数字「剩余节数 / Remaining Coils」。每一关的胜利就是这个数字归 1 的过程。
4. **「困毙」取代「撞死」**：本作**唯一的失败形式是头部四周被自己的身体封死**。这跟主题的贴合度是 100 %：你不是被敌人杀死，你是被自己的过去堵死。这是一个有哲学重量的失败演出，值得专门做一套"石化"动画。

## 3 · 玩法规则与交互说明

### 3.1 盘面与物件

**舞台网格**：正方形棋盘，尺寸随关卡变化：教学 7×7 → 常规 9×9 / 11×11 → 终章 13×13。四周边界**为墙**（不可穿越）。

**实体清单（全部 ≤ 6 种，保持干净）**

| 实体 | 英文 key | 说明 |
|---|---|---|
| 蛇头 | `head` | 蛇的第 1 节，唯一的移动驱动者 |
| 蛇身节 | `coil` | 蛇的第 2…L 节，全部是障碍（对自己也是） |
| 蜕身丸 | `pellet_shrink` | 吃到后长度 -= `delta`（关卡数据配置，常见 2 / 3 / 4 / 6） |
| 巨蜕丸 | `pellet_mega` | 视觉更炸的变体，减量大（常见 5 / 6 / 8），常用于破局点 |
| 岩层 | `wall_bedrock` | 静态障碍。**永远不消失**，是本作唯一的"外部"压缩源 |
| 回环门 | `portal_pair` | 成对出现。头踏入 A 门 → 从 B 门射出，同 tick 完成。（第 4 章引入） |

**后续章节可预留**（视制作人对内容量的期待决定是否启用，默认**不启用**，先保证核心扎实）：
`amber_pellet`（琥珀丸：吃到后 -2，但在当前尾巴位置留下一块永久琥珀障碍 —— **用空间换长度的取舍机制**）。

### 3.2 核心规则（唯一权威定义）

蛇表示为位置序列 `[p₁, p₂, …, p_L]`，`p₁` = 头，`p_L` = 尾，相邻两节正交相邻，且**同一时刻互不重叠**。

**每个 tick 的结算顺序（必须严格按此顺序，这是"追尾合法"的关键）：**

```
1. 计算后继格 q = p₁ + direction
2. 【合法性】q 必须是界内、非岩层（portal 除外）
        且 q 不得被 [p₁ … p_{L-1}] 占用
        —— 注意：允许 q == p_L（尾巴这一 tick 同时离开）
3. 【生死判定】若四个方向全部非法 → 困毙（Entombed）
4. 执行移动：新蛇 = [q, p₁, p₂, …, p_L] 的前 L' 节
        · q 不是丸 → L' = L       （头进一，尾出一）
        · q 是丸   → L' = max(1, L - delta)  （头进一，尾出 1 + delta 节）
```

> **设计要点（必须在开发端钉死）**：第 2 步排除了尾巴 `p_L`。
> 这是本作能不能玩的生死线——开局蛇几乎占满全盘，如果禁止追尾，99 % 的关卡会在第 1 步就锁死。允许"头追着自己的尾巴走"是本作成立的前提。

**胜利条件（★ 已拍板 · 方案 A · 长度归零即胜）**：蛇长度降为 **1** → 完成蜕皮（Fully Shed）。
> 原方案 B 的「蜕出口 `egress`」**降级为纯视觉演出元素**：长度降到 1 时，最后一节原地播放"钻进光缝爆开白光"的收尾动画，但不作为胜负判定条件。**关卡数据不再需要 `egress` 字段，生成器也无需处理终局位置。**

**失败条件（唯一一种）**：**困毙 Entombed** —— 头部的四个正交邻格全部不可进入。
不存在"撞墙输""超时输"等其他判负形式。

**不可移尽的边界情形**：长度 ≤ 2 时应放开"禁止 180° 反向"限制，否则会因为无处可转而误判困毙。

### 3.3 操作与手感

| 输入方式 | 行为 |
|---|---|
| **方向键 ↑↓←→ / WASD** | 触发一步（回合模式下）或改变朝向（流畅模式下） |
| **触屏滑动 Swipe** | 任意方向滑动 ≥ 24px 判定为该方向；支持"按住拖动连续选方向"（手指不抬也能改方向） |
| **点击相邻格** | 直接点选头部四周某一格，一步走过去（新手最友好） |
| **鼠标滚轮 / ±键** | 无（本作无缩放需求） |
| **Z / U · 撤销** | 回退一步（无限，含 ticks 全部状态） |
| **R · 重置** | 回到本关初始态（需二次确认手势，防误触） |

**手感硬指标**

- **输入缓冲 Input Buffering**：深度 2。同一 tick 内最后两次有效方向入队，禁止 180° 反向的**入队时**就拦截（而非执行时），否则会吞掉有效输入。
- **渲染补间 Tile Tween**：每次 tick 的格子位移做 **70–90 ms** 的 `cubic-bezier(.34,.62,.36,1)` 插值。head/tail 关节半径 ≈ tile 的 48 % 形成圆角拐折，视觉上是一条连续的软体而不是一串方块。
- **吞食反馈三连（必须有）**：
  1. **顿帧** 60 ms（`Hit Stop`，让"咬到"有实感）
  2. **脱落粒子**：被吃掉的那几节从尾部剥离，向外飞散并淡出（这是本作的招牌画面）
  3. **舞台呼吸**：整个棋盘容器的外发光半径 & 背景光晕饱和度按 `剩余长度 / 初始长度` 反向插值——蛇越短，画面越松弛越亮。这是本作把抽象压力视觉化的核心手段。
- **降级**：`prefers-reduced-motion` 下补间时长压到 1 ms、取消粒子与舞台呼吸的过渡（仅保留静态亮度映射），**绝不隐藏任何核心交互件**。

### 3.4 模式与内容编排（严禁套路化：本作是纯解谜 → 章节关卡制）

**❌ 明确不做**：无尽冲分模式、连击计分、道具商店、体力系统。这些跟"空间几何清扫解谜"的定位全部相斥，会让这个独一无二的核心乐趣被稀释成又一个贪吃蛇山寨品。

#### ★ 主线：蜕皮纪 · Campaign（5 章 × 8 关 = 40 关）

难度旋钮只有四个：`网格尺寸 W×H` / `初始长度 L` / `每颗丸 delta` / `特殊物件`。
**真正的难度本质只有一个量：`自由格数 = W×H − L − 岩层数`。自由格越少，越逼近"In-the-Box"极限。**

| 章节 | 英文 key | 关卡主题 | 网格 / 初始长度 | 引入的新机制 |
|---|---|---|---|---|
| 1 · **初蜕** | `chapter_1` · First Shed | 纯身体腾挪，教学 | 7×7 → 8×8 / L = 10–18 / delta 2 | 基础规则、追尾合法、撤销 |
| 2 · **岩隙** | `chapter_2` · Rocky Gaps | 外部压缩进入 | 9×9 / L = 22–34 / delta 3 | **岩层 `wall_bedrock`** |
| 3 · **紧咬** | `chapter_3` · Tight Coil | 自由格逼近极限 | 9×9 / L = 36–48 / delta 3–4 | 多段并行岩壁、**巨蜕丸 `pellet_mega`** |
| 4 · **回环** | `chapter_4` · Loopback | 拓扑被打断 | 11×11 / L = 50–70 / delta 4 | **回环门 `portal_pair`**：成对瞬移，打破网格的邻接拓扑，让「看似被自己封死」的局面重新连通 |
| 5 · **无隙** | `chapter_5` · Seamless | 极限 + 混合 + 百节长蛇 | 11×11 → 13×13 / L = 72–**110** / delta 4–6 | 全机制混合，兑现"百节长蛇爬满全屏"的宣传钩子 |

> **第 5 章第 7/8 关建议做两关"百节长蛇"旗舰关（L ≥ 100，13×13 = 169 格，自由格 ≤ 40）**，作为玩家截图/短视频传播的高光时刻。

#### ★ 支线一：残局 · Endgame Puzzles（12 关，手工/半手工精选）
极小局面（6×6 / 7×7），蛇身上好 —— **追求最少步数**。每关标注 `Minimum Steps` 世界纪录位（本地最佳存 localStorage）。这类"看起来简单、实际烧脑"的小残局是社交传播的最佳载体。

#### ★ 支线二：每日一道 · Daily Coil
每天一道随机题，**seed = 当日日期**（确定性 PRNG）。同一个题目所有人同题，比拼完成步数。
*选用理由（不是硬塞）*：本作每一关都是纯状态谜题、单局 30–90 秒、重玩成本极低、且天然有一个可比的客观指标（步数）。这三点让 Daily 在这里是**成立**的，而不是套路。
连续完成可累积 `streak`（连解天数）。**不做奖励，只做记录。**

### 3.5 目标指标与评价体系（不使用"总分"）

| 层级 | 指标 | 说明 |
|---|---|---|
| **主指标** | **步数 Steps** | 本作的唯一度量衡。越少越好。 |
| **过程指标** | **剩余节数 Remaining Coils** | 大數字 HUD，是本游戏的"血条"，但方向是递减。 |
| **评级** | **三星 / Stars** | 3★ = 步数 ≤ Par；2★ = 步数 ≤ Par × 1.15；1★ = 通关即得。**Par 值 = 关卡生成器给出的参考最优步数**。 |
| **通关后解锁** | **最优路线回放 Replay Solution** | 通关后一键播放一条行云流水的"完美蜕皮"路线（60 fps 快速回放）。**这是最好的教学，也是最好的炫耀素材**。不提供局内自动解 Hint——那会毁掉解谜。 |

### 3.6 数学可解性与零死局保证 ★ 本作最关键的一条红线

AGENTS.md §3.2 要求 **100 % 可解**。本作无法用直接随机布置再求解验证（长蛇状态空间爆炸），因此采用**逆向构造 + 回放校验** 双保险：

**A · 逆向生长生成（Reverse Growth）——构造即证明**

定义两个**逆向算子**，从一条**已经通关**的状态出发往回倒推，每一步都在"加长"，直到抵达关卡设计长度 L：

- **逆向移动**：给定当前蛇 `S' = [q₁ … q_L']`，生成上一 tick 的蛇 `S = [q₂ … q_L', x]`，其中 `x` 与尾 `q_L'` 正交相邻、且 `x ∉ S'`。
- **逆向吞食**：同上，但尾巴**一次加 `1 + delta` 节**（连续相邻且空闲），并在 `q₁` 处记录一颗 `{pos: q₁, delta}` 的蜕身丸。

**定理（可解性）**：上述逆向算子生成的状态序列，其正序回放天然是一条合法的通关路径。
*证明要点*：正向执行时，头要进入的格子 `q₁` 不在 `[q₂ … q_L']` 中（蛇身无重复），也不等于新尾巴 `x`（构造时即已约束 `x ∉ S'`），故正向必然合法 → **回放 = 现成的解**。∎

生成器策略：
1. 从长度 1 的蛇开始，**每间隔 D 步（D 随机取自 [3, 9]）插入一次"逆向吞食"**，其余为"逆向移动"，直至长度达到目标 L；
2. 每步随机选择加尾方向，**冲突则回溯重试**；整体失败则**换种子重启**（限次数/超时）；
3. 为使 Par 步数紧凑，加尾方向**优先朝向"远离头部"的自由区域**，并用小规模前瞻避免把自己过早缠死；
4. **终局位置即为 `egress` 蜕出口位置** → 天然满足"最后一节抵达出口"的胜利条件。

**B · 回放校验（Paranoia Check）——测试层证明**

`tests/solvable.test.mjs` 对 `levels.mjs` 中**全部 40 + 12 关**逐关加载随附解序列，喂给**纯净 engine**逐 tick 回放，断言：
- 每一步 `step()` 返回的 action 合法；
- 最终状态恰为 `won`（长度 == 1 且坐标 == egress）；
- 记录步数 == 关卡声明的 Par。

> **这两层缺一不可**：A 保证"存在解"，B 保证"数据没被写坏 / engine 语义与生成器一致"。

**C · 动态刷新不引入不确定性（为什么"逐颗孵化"不会毁掉可解性）**
因为**每颗丸的出现位置与时机全部由逆向构造预先算死并写进关卡数据**，运行时不做任何随机投放 → **动态生成机制不引入任何不确定性**，可解性证明保持完整。

## 4 · 美术风格与视觉氛围

### 4.1 题材与视觉关键词

**「糖果软糖亮场 · Candy Gummy Bright」（★ 已拍板 · 方案 B）**

- 马卡龙糖果 / 果汁软糖（macaron candy gummy）
- 3D 软胶 / 半透明果冻质感（translucent jelly）
- 明亮暖场 + 糖霜光晕（frosted bloom）
- 蜕皮 / 剥离（molting）
- 玩具糖果罐（candy jar console）

**为什么是这一套**：与门户 Poki 薄荷绿亮场一脉相承，货架观感统一；糖果软糖的**高饱和多彩**天然适合表现"蛇身逐节色相流动"（每一节一个糖色，玩家一眼分得清头尾方向）；而"软胶质感"直接延续 `docs/COVER-STYLE.md` 的 3D 软胶封面语言，形成"封面 = 游戏内截图"的强一致感。

**亮场下的"空间松弛"如何表达**（原暗场方案的亮度隐喻需换成等价手段）：
- **背景糖霜浓度**：背景的光斑密度与饱和度跟随 `剩余长度 / 初始长度` 反向插值 —— 蛇越短，背景越"清透"，糖霜颗粒越少越淡。
- **舞台内边距呼吸**：棋盘容器的内发光与外阴影半径随长度递减而收敛，视觉上"舞台越来越宽敞"。
- **网格底纹亮度**：空地格子（未被蛇占据的格子）的底色亮度随剩余长度降低而提升。
- 上述三条全部由 CSS 自定义属性 `--shed-progress`（0→1）驱动，`prefers-reduced-motion` 下去掉过渡只保留终态。
