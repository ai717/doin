# 《数字合成大西瓜》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。



***

## 1・创意概念与核心乐趣



* **游戏名称**：数字合成大西瓜 / Watermelon 2048 / 建议 slug：`watermelon-2048`（候选 `suika-2048`、`melon-merge`）

* **一句话玩法**：把带数字的水果丢进容器，相同数字一碰翻倍合并，一路合成到 **2048 的大西瓜**。

* **核心乐趣与卖点**：


  * **双梗合璧的国民认知**：把两大国民爆款焊在一起 ——2048 的数字合并 + 合成大西瓜的物理掉落；目标 "合成 2048 大西瓜" 本身就是梗，玩家一眼就懂、立刻想冲；

  * **数字即进度的明确感**：每次合并 "2+2=4、512+512=1024"，数字翻倍像进度条 —— 玩家永远知道离大西瓜还差几步，比纯水果版更有冲刺目标；

  * **连锁翻倍的爆发爽感**：一颗落点妙的 8 撞进 8，引发 8→16→32→64 一路翻倍，数字跳字 + 分数狂飙，是 "物理 + 数学" 的双重高潮；

  * **摘下大西瓜的收获感**：终于合出 2048 大西瓜 —— 点一下 "摘瓜"！爆分 + 清空空间继续玩，把 "达成 2048" 从终点变成 "收获 + 再冲刺" 的循环。

* **核心循环**：



```
看数字选落点 → 丢下带数字水果 → 物理滚动、相同数字碰撞翻倍合并 → 连锁升级跳字

&#x20;   ↑\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_↓

合出 2048 大西瓜 → 摘瓜！爆分 + 清场 → 继续合成第二个 → 堆叠超线 = 结算
```

## 2・经典对标与借鉴创新

**经典标杆与成熟参考**：



| 标杆                | 平台 / 来源          | 核心机制                             | 亮点                         | 借鉴                     | 避开               |
| ----------------- | ---------------- | -------------------------------- | -------------------------- | ---------------------- | ---------------- |
| 2048（数字合并鼻祖）      | 全球爆款             | 4×4 网格滑动，相同数字翻倍合并，目标 2048        | **合并得分 = 新数字值**的直觉计分；数字即进度 | 数字链 2→2048、合并计分规则      | 纯网格滑动无物理乐趣       |
| Suika / 合成大西瓜     | 全球爆款             | 水果物理掉落、同类合并、超线即败                 | 物理掉落 + 连锁合并的观看性            | 容器物理、超线结算、掉落预览         | 无数字目标，终局大西瓜占位憋屈  |
| 2048 Suika（物理数字版） | Web（Pokigamez 等） | **物理掉落 + 数字翻倍**，目标合成 2048 块      | 验证了 "物理 + 数字" 混合可行         | 掉落池以 2/4 为主、翻倍合并       | 数字水果样式简陋，无特殊终局机制 |
| 2048 合成大西瓜（国内）    | 移动端              | 数字映射水果（2 = 小西瓜、4 = 青苹果、8 = 紫葡萄…） | 数字 + 水果双重编码亲和力强            | **水果形象 + 数字角标双重编码**    | 限时 / 双人扩展堆砌，冲淡核心 |
| 合成大西瓜魔改版          | 移动端              | 道具（锤子）+ 剧情小剧场                    | 道具缓解 "被大块卡死"               | 需要一个 "主动清障" 手段（我们做成摘瓜） | 道具堆砌、剧情冲淡核心      |

**我们要借鉴什么**：2048 的数字链与 "合并得分 = 新值" 计分、Suika 的容器物理与超线结算、2048 合成大西瓜的 "数字 + 水果" 双重编码、SSRB 系 "下一个掉落物预览"。

**我们的差异化微创新**（不是换皮）：



1. **摘下 2048 大西瓜（核心创新）**：合出 2048 后点击 "摘瓜"—— 爆分 + 清空其占用的空间，然后**继续合成第二个 2048**。把 "2048 达成即终点" 改成 "收获 + 再冲刺"，完美消化 "物理占位 vs 目标达成" 的矛盾，且和 2048 的 "再合一个 2048" 心智无缝衔接；

2. **数字即进度的 HUD 设计**：右侧 "数字合成链图鉴"（2→2048 竖排，已达成级点亮发光），玩家永远知道 "距大西瓜还差几级"—— 这是纯水果版没有的目标牵引；

3. **掉落的数字策略层**：掉落池以 2/4 为主（偶尔 8），对齐 2048"开局给 2" 的直觉，玩家要规划 "小数字靠边、大数字居中" 的堆叠策略；

4. **每日挑战（同日同题）**：同日期同掉落序列，全球同题比 "谁能更快合出 2048 / 更高分"。

**品类排重 / 与《合成泡泡》策划案的关系（重要）**：



* DOIN 现有 15 款无物理合成类，本作填补 "物理合成 / 数字规划" 空白；

* **但本作与已出稿的《合成泡泡》（bubble-merge）共用同一物理掉落骨架**（Suika 品类）。建议制作人二选一定案：


  * 选《数字合成大西瓜》= 数字目标 + 2048 冲刺（目标成就向，本策划案）；

  * 选《合成泡泡》= 虹彩美学 + 戳破宣泄（视觉治愈向）；

  * 或合并为一款游戏双主题模式（泡泡模式 / 数字西瓜模式共享物理层，见拍板项 3）。

## 3・玩法规则与交互说明

### 核心规则



* **场景构成**：


  * 左右封闭、顶部开放的矩形**容器**（物理掉落舞台），底部与侧壁为碰撞边界；

  * **数字水果链（11 级）**：`2 樱桃 → 4 草莓 → 8 葡萄 → 16 柠檬 → 32 橙 → 64 苹果 → 128 蜜桃 → 256 菠萝 → 512 甜瓜 → 1024 半个大西瓜 → 2048 大西瓜`。每级水果形象 + 左上角数字角标（双重编码）；

  * 顶部安全线：堆叠超过即先预警、后结算。

* **玩家合法操作**：

1. **选落点**：鼠标 / 手指拖动显示瞄准线与落点光圈，松手 / 点击释放；

2. **翻倍合并**：两个相同数字水果接触 → 在中点合并为下一个数字的水果（动量平均），连锁判定继续；

3. **摘下 2048 大西瓜**：场上出现 2048 时，点击它 → "摘瓜" 动画（西瓜升起 + 粒子）→ 额外得分 + 清空该瓜占用的空间；

4. 掉落预览：当前待丢水果 + 下一个预览常驻 HUD。

* **胜利与失败条件**：


  * **无尽模式**：合成 2048 大西瓜 = 单局成就达成（可继续玩、继续摘瓜）；堆叠超安全线 = 结算本局；

  * **每日挑战**：固定种子掉落序列，超线结算，比最高分 / 达成 2048 用时。

* **容错与无死局说明**：


  * 纯物理玩法**无逻辑死局**；数字翻倍合并永远 "越合越大、越来越占地方" 是空间压力而非死局；

  * **防秒败**：安全线下方设缓冲预警区，进入即红线脉动 + 音效提示；

  * **主动清障**：摘瓜即清场手段；小数字靠边堆、大数字居中合的策略天然防止 "堵死"。

### 操作与手感



* **鼠标**：移动 = 瞄准线；左键按住拖动 = 微调落点；松开 = 释放；点击 2048 = 摘瓜。

* **触屏**：手指拖动 = 瞄准线；松手 = 释放；点按 2048 = 摘瓜。

* **键盘**（桌面加分项）：左右方向键微调 + 空格释放。

* **手感优化**：


  * 固定步长物理（帧率无关、可重放可测试），滚动带摩擦与弹性；

  * 合并动画：两果 "啵" 挤压 → 膨胀成新果，**数字翻倍跳字**（如 8→16）配涟漪；

  * 摘瓜动画：2048 大西瓜 "长出来"→ 点击后西瓜升起 + 藤蔓星光 + 屏幕微闪光（仪式感）；

  * 误触容错：释放前可取消（拖回顶部 / 右键）。

### 模式与内容递进



* **首选模式：无尽冲分 + 每日挑战**（品类最优解）。

* 难度自然生长：


  * 掉落池前期只出 2 / 4（练手感）；随累计合并数逐步解锁 8 进入掉落池；

  * 空间越堆越高 → 规划压力递增；合出 2048 摘瓜后迎来 "第二回合"（再冲一个 2048）。

* **可选关卡目标制（拍板项）**：每关 "合出第 N 级水果（如 64/256/1024…）即过关"，30 关递进 + 无尽模式解锁。

### 目标与评价



* **计分维度**（建议口径，供开发校准）：


  * `本局得分 = Σ 每次合并得分（含连锁加成） + 摘瓜奖励`；

  * **合并得分 = 新水果数字值**（2048 铁律）：2+2→4 得 4 分、1024+1024→2048 得 2048 分；

  * **连锁加成**：一次掉落引发的连续合并，第 k 次合并得分 ×(1 + 0.5×(k-1))—— 鼓励 "设计落点引爆连锁"；

  * **摘瓜奖励**：点击摘下 2048 = 再得 2048 分（双倍庆祝）+ 清空空间；

  * 满分参照：单局无上限（无尽冲分）；每日挑战记录 "历史最高分 + 最快达成 2048 用时" 双纪录。

* **评价体系**：结算弹窗 "得分 + 最大合成数字 + 最长连锁 + 🏆 新高分 + 已摘西瓜数"；达成 2048 有专属成就徽章。

## 4・美术风格与视觉氛围



* **题材与视觉关键词**：**夏日果园・多汁果色・数字铭牌・丰收派对・明快清新**

  （不做深海静谧、不做写实 3A、不做霓虹暗黑 —— 与《合成泡泡》的 "水族馆静谧" 明确区隔，走阳光热闹路线。）

* **桌面端沉浸游戏舞台设计（≥900px）**：


  * **左主舞台**：容器为 "阳光果园木框"（暖木 + 柔和绿荫背景光晕 drift），水果为 Q 版多汁卡通 + 清晰数字角标，落地带小果香粒子；

  * **右侧信息操作栏（丰收记分牌 HUD）**：


    * 顶部 \*\*"数字合成链图鉴"\*\*：2→2048 竖排水果链，已达成级点亮发光、下一目标级呼吸提醒 ——"距大西瓜还差 X 级" 一目了然；

    * 中部**计分牌卡**：得分 / 最长连锁 / 已摘西瓜数，胶囊徽章化 + bump 跳字；

    * 底部**掉落预览槽**：当前待丢水果 + 下一个，像 "果园传送带";

  * 移动端（≤768px）：单列紧凑，容器自适应屏宽，预览槽贴底。

* **色彩与环境氛围**：


  * 主色：夏日蓝天渐变容器底 `#7EC8E3 → #A8E6CF` + 水果本色（樱桃红 / 草莓粉 / 葡萄紫 / 橙黄 / 西瓜翠绿红瓤）+ 数字角标深褐 `#5C3A21`；

  * 背景：暖阳环境光晕 + 细噪点叶影，仿 "果园午后" 的明媚沉浸感，拒绝死白灰底；

  * 关键动效：


    * **瞄准**：落点光圈 + 虚线轨迹；

    * **合并**：挤压膨胀 + 数字翻倍跳字 + 果香粒子；

    * **连锁**：每级连锁数字放大闪光 + 音调升高；

    * **摘瓜 2048**：西瓜发光 → 点击后升起 + 藤蔓星光 + 全屏丰收金光（仪式感）；

    * **超线预警**：安全线变红脉动 + 低沉警示音；

  * 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

* **封面设计提案**：


  * 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字（**数字 "2048" 属数字文字，封面禁止出现**）；

  * **主体物件**：一颗圆滚滚的软胶大西瓜居中，几颗小樱桃 / 草莓 / 橙子散落环绕作陪衬，像 "果实派对"；

  * **背景色相**：**绯红系**（西瓜瓤红，未被占用；纯明黄作备选），与现有 15 张封面不撞色。

## 5・制作人拍板与开放探讨



1. **与《合成泡泡》的关系（先定这个）**：

* A. **本作独立立项**，《合成泡泡》暂缓或放弃（推荐 ——"数字 + 大西瓜" 国民认知更强、目标感更明确）；

* B. 保留《合成泡泡》，本作暂缓；

* C. **合并成一款游戏双主题模式**：泡泡模式 / 数字西瓜模式共用同一物理骨架（省一次开发，门户上 "一游戏两皮肤"）。

1. **摘瓜机制（核心创新点）**：

* A. **可摘瓜**：合出 2048 点击摘走，爆分 + 清空空间，可继续合第二个（默认推荐 ——"达成即收获，收获即继续"）；

* B. **不可摘**：2048 达成即该局达成成就、留在场上占位（纯经典，稳但憋屈）；

* C. **摘瓜溅射**：摘走时溅出 2 颗 2 级小樱桃（更刺激但更乱）。

1. **模式结构**：

* A. **无尽冲分 + 每日挑战**（默认推荐）；

* B. **关卡目标制**：每关合出第 N 级水果过关，30 关递进 + 无尽解锁；

* C. 混合（关卡制为主线 + 无尽模式）。
