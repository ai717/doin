## 1 · 创意概念与核心乐趣

- **游戏名称**：坦克巷战 / Tank Assault / 建议 slug：`tank`（单单词、零歧义，符合极简命名契约）
- **一句话玩法**：驾驶俯视坦克在街巷迷宫里拆砖开路、借钢壁跳弹打拐角，守住司令部鹰标并全歼来犯装甲。
- **核心乐趣与卖点**：
  - **「射击 × 走位 × 地形」三位一体的老派密度**：这三件事在 1985 年就被《Battle City》焊成了一块，至今仍是网页小游戏里罕见的"同一屏内同时做三件决策"的玩法。你要同时算：我站在哪条巷子、这一炮拆哪块砖开路、敌人从哪条缝钻向我的基地——**一局里的心智密度远超绝大多数单机制小游戏**；
  - **地形是你自己雕出来的战场（Terrain as a Weapon）**：砖墙不是背景板，是可被你和敌人共同改写的规则。拆掉一块砖 = 给敌人开一条路；留着它 = 给自己留一面盾。每一次开炮都在改写地形，每一次改写都在下一秒反噬自己，这种"动一子而全局改"的爽感是三消与推箱子给不了的；
  - **★ 钢壁跳弹（Ricochet）· 本作招牌微创新**：钢墙在原版里只是"吸弹的墙"，本作让它变成**镜子**——子弹以镜面角反弹一次，可以打拐角、打背后、打藏在凹室里的重甲。代价是：**反弹弹同样会打死你自己**。于是钢墙从"障碍物"升级为"需要计算角度的武器"，走位从躲子弹升级为"别站在自己反弹弹的回程线上"，直接把技术天花板抬高一个档位；
  - **★ 升级改变几何（Upgrade Changes Geometry）**：拾满 3 颗星后子弹**直接击碎钢墙、不再反弹**。于是玩家面临一个真实的抉择——**要钢墙当反射镜用，还是打碎它开路？** 同一个物件因玩家状态而性质翻转，这是本作最有味道的策略层；
  - **守基地的持续张力**：与全站所有"清完就赢"的玩法不同，本作有一个必须一直回头看的目标。远处传来履带声、屏幕上只剩最后一辆敌坦克正朝你家开——那是任何分数都换不来的心跳；
  - **道具的赌博感**：闪红敌坦克掉落道具，而它往往出现在离基地最远的角落。**去抢 = 基地裸露，不去 = 火力不足**，原版最精髓的风险抉择本作完整保留。
- **核心循环**：
  ```
  读地形（哪里能拆 / 钢墙在哪） ➔ 走位卡巷口 ➔ 开炮拆砖开路 / 跳弹打拐角
        ↑                                                    ↓
  拾道具（星级改变几何 / 护盾 / 冻结） ← 击杀闪红敌 → 战况（剩余敌军 · 基地耐久）
        ↓
  全歼 20 辆过关 → 三星结算（基地零损 / 限时 / 零阵亡） → 推进下一关 / 刷新最佳
  ```

## 2 · 经典标杆与对标参考

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Battle City（Namco 1985 / FC）** | FC/NES | 13×13 格（26×26 半格）战场；坦克 2×2 半格；每关 20 辆敌坦、同屏上限 4；砖/钢/树丛/水/冰五类地形；6 种道具；鹰标基地一击即毁 | 史上最精炼的"射击+走位+地形"三合一，规则十分钟看懂、一辈子玩不腻 | 半格网格与坦克 2×2 尺寸、砖墙可被逐块剥落、同屏敌人上限、闪红敌掉道具、6 种经典道具、五类地形、每关 20 辆编制 | 基地一击即死的极端惩罚（现代玩家第一关劝退）；敌 AI 偶发呆滞与原地抽搐 |
| **Tank Battalion（Namco 1980 / 街机）** | 街机 | 无道具、无地形的纯对射 | 极简原点 | 保留"同屏敌人上限 4"这个黄金节奏参数 | 单调无成长 |
| **Tank Force（Namco 1991 / 街机）** | 街机 | 纵向卷轴推进、多兵种、Boss 战 | 装甲种类的差异化表达 | 敌人分兵种、重甲多段血、章末"要塞关"概念 | 卷轴与多兵种对单机网页过重 |
| **现代弹幕/几何射击独立作** | PC/Web | 反弹弹、穿甲、蓄力炮 | 让"角度"成为可计算的资源 | **钢壁跳弹**的几何思路与"反弹弹可自伤"的风险设计 | 满屏弹幕遮挡（本作同屏子弹硬上限极低，战场必须始终可读） |

**我们要继承的成熟机制**：
1. **半格网格 + 2×2 坦克**：战场 26×26 半格（每半格 8px 逻辑单位，全盘 208×208），坦克占 2×2 半格；移动以半格为最小单位、转向即时，命中盒与格子严格对齐——这是《Battle City》手感可读的根本；
2. **砖墙逐半格剥落**：一发子弹削掉弹道上第一块半格砖（不是整块"墙"消失），玩家可以精确地"钻洞"，产生"我雕出来的路"的掌控感；
3. **同屏 4 敌上限 + 每关 20 辆编制**：这是原版被验证四十年的节奏参数——同屏 4 辆既压迫又可读，20 辆的关长刚好 2–4 分钟；
4. **闪红敌掉道具（Bonus Tank）**：本关随机一辆敌坦被标记，击杀后掉落道具，位置随机——把"抢还是守"的抉择做成核心张力；
5. **6 种经典道具**：星（三级火力：① 提速 ② 双发 ③ 破钢）、头盔（护盾）、炸弹（全屏清敌）、铁锹（基地钢化 15s）、坦克（加命）、时钟（冻结敌军）；
6. **四类敌坦**：基础型 / 高速型 / 速射型 / 重甲型（4 段血、随血量变色）；AI 采用"朝基地推进 + 定期随机重选方向 + 遇墙转向"的成熟混合状态机。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **★ 钢壁跳弹（Ricochet）**：子弹撞钢墙按镜面角反弹，反弹后仍具杀伤（含对玩家自伤）；**每发子弹最多反弹 1 次**，第二次撞击即湮灭（防止弹幕失控）。钢墙边缘在命中瞬间溅出橙白火花并留下 0.4s 的高温余痕，反弹轨迹有细虚线预示——**几何必须可读，绝不做看不见的暗弹**；
2. **★ 升级翻转几何**：星级 1–2 时钢墙 = 镜面；星级 3 时钢墙 = 可摧毁。同一堵墙在不同局势下性质相反，逼玩家做真实的资源抉择；
3. **★ 基地耐久制（Base Integrity）**：鹰标拥有 **3 点结构耐久**（原版一击即毁）。每被命中 1 次掉 1 点，触发全盘红色警报闪烁 + 低频警笛；归零才判负。**把自己的旧惩罚从"瞬间死亡"改成"三次警告"**，新手不会在第一关 30 秒内劝退，老手依然要为守家负责；
4. **★ 砖块碎屑物理**：砖墙被击碎时溅出 6–8 片带旋转与重力的小碎块，落在地面留下 0.8s 的碎砖残迹，随后被"沙盘清扫"淡出。地形破坏必须看得见、听得见、摸得着；
5. **★ 战术指令槽（Command Orders）**：击杀充能，满一格可发一道指令，三选一轮换——**覆盖炮击**（指定 3×3 区域削砖并伤敌）/ **紧急筑垒**（基地四周砖墙瞬间重建）/ **电子干扰**（冻结 + 施放烟雾，敌军丢失目标 3s）。给纯操作之上加一层"什么时候用"的指挥官决策；
6. **无死局与可读战场的硬约束**：同屏敌弹硬上限 12（含反弹弹），任意敌坦最短开火间隔 ≥ 0.5s，反弹弹在生成瞬间即画出 0.25s 的虚线预示轨迹——**玩家的死亡永远来自判断失误，绝不来自看不见的弹**。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素
- **沙盘盘面（Sand Table Field）**：26×26 半格，逻辑像素 208×208，等比放大渲染（桌面端建议 544×544 显示，2.6× 缩放，像素对齐不模糊）；
- **地形件（Terrain Pieces · 均为 1 半格单位）**：
  - `brick` 砖墙：可破坏，逐半格剥落，挡坦克与子弹；
  - `steel` 钢墙：星 <3 时反弹子弹、不可破；星 =3 时可击碎；
  - `tree` 树丛：不挡任何东西，但**遮蔽其下坦克**（坦克半透明化、AI 丢失玩家目标）；
  - `water` 水面：挡坦克，**不挡子弹**（可隔河对射，经典战术位）；
  - `ice` 冰面：坦克在冰上产生 0.6s 惯性滑行（输入仍即时生效，只是停不住）；
  - `base` 司令部鹰标：位于盘面底部正中，占 2×2 半格，耐久 3 点，四周初始有砖墙护体。
- **我方坦克**：占 2×2 半格，出生在基地左/右两侧；三级火力（单发 → 双发 → 双发+破钢）；
- **敌方坦克**：每关 20 辆编制，同屏上限 4；四类基础型 + 两类本作新增：
  - `scout` 侦察兵（高速、1 血）、`standard` 标准型（1 血）、`rapid` 速射型（1 血、弹速快）、`armor` 重甲型（4 血、随伤害变色）、
  - `sapper` 工兵（**新**：主动拆砖开路，会自己给基地修路，逼玩家优先处理）、`sniper` 狙击手（**新**：与玩家同行/同列时 0.5s 红色预警线后开火，逼玩家避免长时间对齐）；
- **道具（Power-ups）**：星 / 头盔 / 炸弹 / 铁锹 / 坦克（加命）/ 时钟 —— 由闪红敌坦掉落于随机空地，20s 未拾取消失；
- **跳弹**：子弹撞钢墙反弹 1 次，可伤敌、可自伤。

### 3.2 判定与胜负规则
1. **胜利条件**：歼灭本关全部 20 辆敌坦（含已出场与未出场）；
2. **失败条件**：① 基地耐久归零；② 我方命数耗尽（初始 3 条命，每关开始不自动补，加命道具可叠加上限 5）。两条任一成立即本局结束；
3. **自伤与友伤**：自己的反弹弹命中自己 = 掉 1 条命（护盾可挡）；**自己打掉基地 = 基地耐久 −1**（保留原版最辛辣的规则）；
4. **敌人生成**：从盘面顶部 3 个出生点轮换入场，同屏 ≤ 4；出生瞬间有 0.6s 的"空投闪烁"预告（白星闪烁 + 落点提示），绝不静默刷出；
5. **无死局说明（硬性）**：
   - 24 张手编关卡全部为**固定数据、零随机**，出场前跑连通性校验（见开工指令第 3 条）；
   - 死守模式的随机波次走种子 PRNG，生成后校验出生格 3×3 清空且到基地连通，失败即回退重生成；
   - 同屏敌弹硬上限 12、最短开火间隔 0.5s、同屏敌坦上限 4，从参数上保证战场永远可读、永远有解。

### 3.3 手感调优与操作映射（键鼠触全通）
- **移动**：桌面 `↑↓←→` 或 `WASD`；**转向即时、不需先停下**（经典手感）；按住持续行进，**转弯时自动吸附到半格网格**（对齐吸附 ≤ 0.06s，不产生"卡墙角"挫败）；冰面上松开方向后滑行 0.6s；
- **开火**：`空格` / `J`，按住连射（引擎按火力等级节流，绝不做按住瞬发）；单发冷却 0.28s，同屏己方子弹上限 2（3 星后 4）；
- **指令键**：`K` / `Shift` 发动当前充能指令；
- **操作缓冲（Input Buffering）**：转向指令在"卡墙刚通过"的 0.12s 内按下会被缓存并立即执行；开火在冷却结束前 0.1s 内按下自动补发——**绝不吞输入**；
- **触屏**：盘面下方连体的**金属十字方向键（左）+ 开火红钮（右）+ 指令键**，全部为相对固定位置（非跟随手指），带 2px 下沉位移与 60ms 触觉式视觉反馈；
- **移动端避让**：底部严格预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，确保未来底部 Banner 广告绝不遮挡操作台；盘面 `touch-action: none` + `overscroll-behavior: none`；
- **降级**：`@media (prefers-reduced-motion: reduce)` 下去掉爆炸震屏与粒子，**仅保留瞬时状态切换，绝不隐藏任何核心交互件**。

### 3.4 模式编排（为"动作 + 守家"量身定制，拒绝千篇一律）
1. **战役 · 6 章 × 4 关 = 24 关（Campaign · 绝对主轴）**
   - 第 1 章 新兵训练场（纯砖墙，教学：拆砖 / 守家）
   - 第 2 章 钢壁街区（引入钢墙与**跳弹**）
   - 第 3 章 密林伏击（引入树丛与**狙击手**）
   - 第 4 章 冰河渡口（引入冰面与水面的隔河对射）
   - 第 5 章 工兵突袭（引入**工兵**，地形会被敌人主动改写）
   - 第 6 章 铁壁要塞（混合地形 + 重甲集群 + 每章末"要塞关"：敌方 20 辆中重甲占比 50%）
   - 每关三星独立授予：**① 基地零损伤 ② 限时内清场（关卡基准时间）③ 我方零阵亡**；总星数 72 为真正的追求指标。
2. **死守（Last Stand）**
   - 单张盘面无尽波次守基地，波次强度持续爬升，记录**最高坚守波数**与**最长坚守时间**；不是刷分榜，是"你能撑几波"的耐力求证。
3. **残局（Breakthrough）**
   - 手编的 8 张残局盘面：给定地形、限定弹药发数或限定时间，要求全歼或守住——**纯策略解谜**，考验读图。

> 说明：本作**不设每日挑战**——射击手感与守家张力的乐趣在于推进与精进，不在每日解谜。

### 3.5 反馈体系与评价
- **核心指标**：战役总星数（72 星）、单关三星、死守最高波数、命中率、最长连杀链、拆砖数、跳弹命中数（作为专属炫技统计）；
- **连杀链（Combo Chain）**：击杀间隔 < 2.5s 递进 ×1 → ×3（封顶），链断清零；链升级时沙盘边缘黄铜包边亮起暖光 + 音高升半音；
- **结算仪式感**：最后一辆敌坦爆炸 → 全屏 0.5s 慢镜（时间流速 0.35×）→ 沙盘上"残骸烟雾"缓缓飘散 → **电报纸带打出战报**（用时 / 命中率 / 拆砖数 / 跳弹命中 / 基地耐久）→ 三枚星章依次"咔哒"盖印（阶梯 delay）；章末额外授予"战区勋章"，陈列于铭牌条下的勋章轨。

### 3.6 双语核心词汇与数据键名规划（防英文界面夹杂中文）
- **模式**：战役 `campaign` / 死守 `last_stand` / 残局 `breakthrough`

**形态细则**：
1. **顶部黄铜铭牌条**：返回首页（铆钉箭头）、游戏标题（压印体）、音效（**可旋转的圆形旋钮**，转动有刻度感）、语言（**拨杆开关**）、规则（**牛皮纸作战命令信封**，点开摊开作战手册）——**全部熔铸进铭牌条，严禁四角散落**；
2. **中央下沉沙盘**：四周 2–3cm 的凹陷内阴影 + 黄铜包边与铆钉，边缘刻有测量刻度尺；盘面底色为**沙土色微颗粒质感**（Canvas 程序化噪点，非图片）；地形件是"沙盘模型件"——砖墙为红陶砖小方块（顶面受光、侧面压暗、带厚度投影）、钢墙为灰蓝铆接钢板、树丛为军绿绒絮团、水面为半透明树脂蓝（有反光带）、冰面为淡青磨砂玻璃；**基地为中央底部的金属鹰徽圆章，耐久 3 点显示为圆章外围三枚铆钉**；
3. **底部车长操作台（与底盘连体）**：非浮空卡片，是沙盘下方焊死的金属面板——左：十字方向键（金属微浮雕，按下 `translateY(2px)` 下沉）；右：开火大红钮 + 指令键；中：两枚**圆形指针仪表**（左表"剩余敌军"、右表"坦克储备"，指针带阻尼摆动）+ 一排**战利品指示灯**（道具生效中点亮）；
4. **电报纸带**：盘面右下角一条窄纸带滚动打印战报（击毁 / 拾取 / 基地受损），带轻微纸纹与走纸抖动——把反馈做成"沙盘上的事件流"而非弹窗；

6. **质感与反馈**：击杀爆出橙白火花 + 碎片 + 机身 squash 微变形 + 沙盘边框轻微震动（≤2px）；跳弹在钢壁留 0.4s 高温余痕；**所有高亮/预警一律用径向柔光（渐隐至透明）与呼吸脉动，严禁给主体描硬边描边圈**。

### 4.3 立体质感与渲染路线裁决
**Canvas 2D 绘制战场 + 语义 DOM 承载全部 HUD / 仪表 / 按键 / 弹层**。
- 战场需要逐半格剥落、跳弹轨迹、碎屑物理与爆炸粒子 → Canvas 2D 是唯一合理选择，零加载、零发热、稳定 60fps；
- 立体感不靠 3D 引擎：地形件用"顶面亮 + 侧面暗 + 投影偏移"的三段式画法 + 盘面内阴影凹陷 + 黄铜包边渐变，即可做出沙盘模型的实体厚度；
- **不引入 Three.js**：本作为严格俯视 2D 网格玩法，不存在真三维空间变换需求。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化，零音频文件，严禁蜂鸣器）
1. **开火（炮击）**：低频噪声爆破 + 下扫三角波 + 短促金属腔体共振（bandpass 400Hz）→ 厚重的"咚"，绝不是 beep；
2. **砖墙剥落**：短噪声 burst 经高通 + 极快衰减，叠加 3 个随机音高的陶片碎裂泛音 → "咔啦啦"；
3. **★ 钢壁跳弹**：噪声 + 高 Q 带通扫频 + FM 不谐比（ratio 1 : 1.41）金属泛音 → "铛——咻"的跳弹啸叫，本作辨识度最高的声音；
4. **敌坦爆炸**：低频轰鸣（噪声 + lowpass 下扫）+ 0.2s 后的二次碎片爆裂，重甲型额外加一段下沉余音；
5. **拾取道具 / 升级**：FM 马林巴上行三音（温暖木质），升星时叠纯五度双音；
6. **基地受创警报**：两声颤动低频警笛（方波 + 6Hz LFO），与盘面红色闪烁严格同帧；
7. **指令发动 / 过关**：电键"嘀嘀"短音 + 上行大三和弦（下达命令的仪式感）；过关为 8-bit 上行琶音 + 电报走纸声。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，**零文字**；
- **主体构图**：单一居中主体占 64%~70%——一辆**圆润饱满的软胶质感俯视小坦克**（军绿车体 + 深灰履带 + 短粗炮管朝正上方，炮口一小团柔和橙黄火花与极短的白热拖影），车体下方压着两块崩缺的软胶红砖碎块；
- **背景与氛围**：**深青 → 湖绿的平滑径向渐变**（约 165°–185°，全站该色相区尚属富矿），点缀几粒虚焦的暖沙色微粒与远处一枚若隐若现的钢灰色砖墙剪影；
- **色相纪律（开工必做）**：先用 cv2 HSV 圆形均值实测全站封面主色相；主体军绿锁 **110°–140°**、背景青锁 **165°–185°**；若被占用，背景退到 **305°–320° 品红**或 **340°–355° 玫红**，**严禁使用已最拥挤的 200°–225° 天蓝/靛与 25°–40° 暖橙棕**；
- **后处理**：固定 bbox 去除右下角水印 → 缩 640 → webp q90 → `npm run build`。

### 跳弹判定（最终定案，开发端不得改写）
子弹为单点判定（`floor(x), floor(y)` 所在半格），**仅玩家子弹**具备跳弹能力（敌人子弹撞钢墙直接湮灭，保证战场可读）。撞钢墙时按垂直于飞行方向的两个邻格决定去向：
- **两侧都不通**（钢墙片内部 / 死角）→ 子弹湮灭；
- **两侧都通**（孤立钢墙块）→ **原路反弹 180°**（正撞镜面，可能自伤）；
- **仅单侧通**（钢墙片边缘）→ **偏转 90° 擦边飞出**（本作主用法：打拐角）。

每发子弹**最多跳弹 1 次**（`bounced=true` 后再撞任何目标即湮灭）。反弹瞬间引擎必须产出 `ricochet` 事件供渲染画 0.25s 虚线预示轨迹。
