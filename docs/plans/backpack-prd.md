## 1 · 创意概念与核心乐趣

- **游戏名称**：背包竞技场 / **Backpack Arena** / 建议 slug：`backpack`
  - 备选 slug：`pack-arena`、`satchel`
  - **刻意不用** `backpack-battle`：① 平台 slug 契约优先单个简短纯英文单词，双词连字符非必要；② 避免与 Steam《Backpack Battles / 背包乱斗》的联想混淆。中文名同样避开《背包乱斗》《背包英雄》两个已有译名，自立门户。
- **一句话玩法**：把武器防具像俄罗斯方块一样塞进行囊，自动战斗按你的布局结算。
- **核心乐趣与卖点**：
  1. **空间规划的脑洞快感**——同样的三件装备，摆法不同战力差三倍。把"买什么"升级成"怎么塞"，每一格都在压榨收益。
  2. **布局即策略**——相邻联动、行位加成、空位加成、战斗结算合成，背包不是仓库，背包就是战斗构筑本身。
  3. **"看戏"的悬念感**——摆完背包按下开战，两只小冒险者自动互殴、飘字狂跳，胜负由 10 秒前的布局决定；赢了想立刻再开一局验证新脑洞。
  4. **合成升级的收藏爽感**——战斗结算时相邻配方"叮"地合成更强装备，蓝线点亮配方，构筑一步步长成。
  5. **容错友善的试错循环**——卖回全额退款、回合内无限撤销、对手是种子生成的固定 AI，输了立刻知道该改哪里。
- **核心循环**：赚金币选购 ➔ 空间摆放触发联动 ➔ 自动战斗结算 ➔ 合成升级 ➔ 更强的对手 ➔ 重构背包。

## 2 · 经典标杆与对标参考

| 对标 | 借鉴点（具体抄什么） | 避坑点（具体不做什么） |
|---|---|---|
| **《Backpack Battles 背包乱斗》**（PlayWithFurcifer，2024 EA / 2025 正式版，Steam"压倒性好评"，全球销量破百万） | ① **18 回合"商店+战斗"双相位结构**（每回合赚金币 → 选购布置 → 自动战斗 → 战斗结算合成）；② **耐力瓶颈**：武器消耗耐力、每秒回复 1 点、香蕉等食物回耐，耐力才是输出上限；③ **相邻联动**：物品旁邻指定类型获得加成（平底锅旁邻食物加伤）；④ **战斗结算后相邻合成**：配方物品之间显示蓝线提示，不背表；⑤ **职业 × 初始背包双维度开局**；⑥ 赢 10 场晋级 / 输 5 场出局的赛制张力。 | ⛔ 异步 PvP 依赖服务器——本作改为**种子生成的 PVE AI 对手**，纯静态网页零后端可行。⛔ 道具池 300+ 件过于庞大——本作首发压缩至 ~55 件，靠联动规则组合复杂度补深度。⛔ 原作几乎无教学、新手劝退——本作必须做 3 轮机制教学关。 |
| **《Backpack Hero 背包英雄》**（Jaspel，2023） | ① **背包网格即角色构筑**（Inventory Tetris）：物品形状各异、必须旋转填塞；② **行位加成**（顶行加成）；③ **右侧空位加成**（某些武器右边越空越强）；④ 重物下沉 / 轻物上浮的物理趣味。 | ⛔ 回合制手动战斗节奏偏慢、随机地牢爬塔负担重——本作聚焦"布置 → 自动结算"的轻快节奏。⛔ 不做 AP 步数制（回合内消耗点数），改做**耐力**（更直觉、更好看）。 |
| **自走棋品类**（Auto Chess / 金铲铲）与 **Brotato**（Blobfish，2023） | ① 自动战斗的"数值验证"爽感——摆完看它自己打；② 道具按独立冷却自动触发的节奏感（武器自动挥舞、食物定时回血）。 | ⛔ 不做局外肉鸽成长树（体量与门户不符）。⛔ 不做三合一卡牌升星，保持"两件物品一条配方线"的极简合成。 |
| **《Backpack Ascendancy》**（web demo，2025） | ① 验证了"空间背包自走棋"在纯浏览器端交互完全可行；② web 端拖拽/旋转/交换的简化布局范式。 | ⛔ 仅 demo 完成度——我们的目标是完成度拉满的门户作品：教学、双模式、结算报告、存档全齐。 |

- **成熟标杆原型**：2024-2025 年的《Backpack Battles》——"买什么 + 放哪里"双决策 + 自动战斗，是近年独立游戏最成功的机制创新之一，被媒体称为"背包即构筑"。
- **最受玩家认可的核心手感**：
  - **摆放立即可见数值变化**：物品拖到联动位置，边缘亮光 + 预测数值飘字，反馈零延迟。
  - **战斗是 10–20 秒的短演出**：快节奏"看戏"，倍速与跳过齐全。
  - **耐力是全局瓶颈**：不是堆攻击，而是配"攻击 + 回耐 + 保命"的生态平衡。
  - **合成蓝线可视化**：配方不用背表，摆对位置自然触发。
- **本作的独特魅力与微创新**：
  1. **PVE 远征天梯**——无服务器也能"对战"：6 种种子生成的风格 AI 构筑（剑盾流/暴击流/毒药流/燃烧流/铁壁流/传说 Boss），段位越高对手越狠，是原作 PvP 精神的离线化改造。
  2. **布局残局模式**——固定商店 + 固定对手的纯脑洞解谜，30 关三星制：把"空间规划"本身做成第二玩法支柱，这是原作没有的。
  3. **种子远征码**——商店序列与对手构筑完全由种子决定，同一种子可复现、可比拼，离线玩家的公平竞技与传播彩蛋。
  4. **机台化营地舞台**——羊皮纸 + 墨绿呢绒 + 黄铜铆钉的冒险者营地长桌，把背包、货架、HUD 焊成一张桌子，彻底告别网页仪表盘。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**场景构成（单场对战 = 商店回合 + 战斗回合）**
- **你的背包棋盘**：网格布局，初始 20 格（职业不同形状不同：宽横排 / 窄竖排 / 菱形书袋）；可购买"扩容袋"增加格子，格子上限 40。
- **商店货架**：每回合 5 个物品槽 + 2 个扩容袋槽，1 次免费刷新；物品稀有度随回合数解锁（传说后期才出现）。
- **物品**：形状（1×1 / 1×2 / 2×1 / 2×2 / L 形 / 2×3）、类型（武器/防具/盾/食物/奇物/宝石/职业专属）、稀有度（普通/精良/稀有/传说）。
- **战斗舞台**：两名冒险者并立，各自挂血条、耐力条、护甲值、状态图标；物品按冷却自动触发。

**物品六类与作用**
| 类别 | 作用 |
|---|---|
| 武器 | 战斗时按冷却自动挥舞，消耗耐力造成伤害；分近战/远程；有命中、暴击属性 |
| 防具 / 盾 | 提供护甲吸收伤害；盾牌可降低对方耐力回复；部分防具带格挡几率 |
| 食物 / 消耗品 | 定时触发：回血（烤肉）、回耐（香蕉）、短暂增益（辣椒油） |
| 奇物 / 饰品 | 被动：攻速、暴伤、回血光环、相邻武器伤害加成（磨刀石）、幸运（命中+暴击） |
| 宝石 | 三颗同色相邻自动融合为高阶宝石（红=攻击 / 蓝=回耐 / 绿=回复），可装入奇物孔位 |
| 职业专属 | 见 §3.2 |

**空间联动规则（核心深度，全部必做）**
1. **相邻类型联动**：物品标注"亲和类型"，旁邻指定类型物品获得加成——平底锅旁邻任何食物 +2 伤害；油瓶旁邻火系武器，点燃几率翻倍。
2. **行位加成**：指定行位触发——瞄准镜放顶行 +30% 暴击伤害；铁砧放底行，同列物品 +2 护甲。
3. **空位加成**：猎弓右侧每有 1 个空格 +1 伤害（最多 +4）——"把武器放在开阔处"的空间直觉。
4. **合成配方（战斗结算后触发）**：相邻且满足配方的物品在战斗后自动合成为更强物品；可合成物品之间显示**蓝线连线**提示（不背表）。首发 12 条配方：木剑+磨刀石=英雄剑；火杖+油瓶=烈焰杖；烤肉×2=盛宴拼盘；红宝石×3=红宝石王冠等。
5. **重物与轻物**（奇物特性）：沉重物品压住同列下方格子（下方物品失效但获得护甲）；轻盈物品悬浮（同列下方空格越多触发越快）。

**玩家合法操作**
- 鼠标 / 触屏：从货架拖物品入背包；背包内拖动换位；拖出背包边界 = 卖出（**全额退款**）。
- 键盘：方向键 / WASD 移动焦点，Enter 拿起/放置，R 旋转 90°，Esc 放回货架，Z 撤销一步，1/2/3 切换战斗倍速，P 暂停。
- 输入缓冲：快速连拖不丢操作；回合内无限撤销，不消耗金币。

**胜负判定**
- 战斗：一方 HP 归零即负；30 秒后进入**疲劳**（双方每秒受递增伤害），强制终局，杜绝无限拖。
- 远征：**赢 10 场晋级，输 5 场出局**，最多 18 回合；对手按轮次曲线变强，每 3 轮一个"首领"。
- 残局：以给定配置赢下战斗 = 过关；三星见 §3.4。

**容错与无死局保证（数学可解性，硬性要求）**
1. **远征经济保底**：物品卖回 100% 原价；每回合商店保底刷 2 件与当前背包已有类型联动的物品；开局赠送 3 件"万金油启动装备"（任意流派可用的剑 / 盾 / 香蕉）。
2. **战斗强制终局**：疲劳机制保证单场最长约 40 秒，机制上排除"打不死"。
3. **残局关卡可解门禁**：每关上线前必须通过**布局求解器**验证——在全部合法摆放空间中搜索，确认存在至少一种必胜摆法；不达标打回重做。求解器同时输出参考摆法用于提示系统。
4. **确定性战斗**：命中 / 暴击 / 格挡随机全部由可注入种子 PRNG（`mulberry32`）驱动；同一布局 + 同一种子 = 同一战果，测试可复现；另需 ≥1000 步随机游走测试，验证状态机在任意合法操作序列下不抛错、不卡死、不变式不破。
5. **无死局状态**：物品只增不减、金币永不冻结、背包永远可扩容，机制上排除"卡死无法继续"。

### 3.2 职业与开局（3 职业 × 2 款初始背包 = 6 种开局变体）

| 职业 | 专属特性 | 专属物品池（示例） | 初始背包造型 |
|---|---|---|---|
| **狂战士 Berserker** | 受击积攒怒气，怒气提升武器攻速 | 战斧（高伤高耐耗）、巨锤（几率眩晕）、战吼鼓（受击回耐）、铁腕甲（格挡） | 宽横排皮包（武器横陈位） |
| **游侠 Ranger** | 幸运属性：暴击率与命中加成 | 猎弓（右侧空位加成）、三连弩（连射）、瞄准镜（顶行加成）、陷阱夹（开局压制） | 窄长箭囊包（竖排） |
| **火法师 Pyromancer** | 魔力替代耐力：每秒回魔、施法耗魔 | 火杖（点燃）、油瓶（火亲和）、火球卷轴（AOE）、法力药水（回魔） | 法师书袋（菱形分布） |

> 火法师提供与近战 / 远程完全不同的资源逻辑（魔力 vs 耐力），是三流派里策略差异最大的一条线，也是新手理解"资源管理"的最佳教材。

### 3.3 商店与金币经济
- 每回合收入递增（回合 1 的 6 金 → 回合 18 的 20 金），对标原作经济曲线。
- 商店 5 槽 + 1 次免费刷新，扩容袋 2 槽；传说物品后期才刷出。
- 卖回全额退款 → 试错零成本，鼓励玩家大胆实验摆法。

### 3.4 模式与内容编排（依玩法特质定制，严禁套用"无尽+每日"三件套）

**模式一：远征天梯（主线 PVE，本作主模式）**
- 一局远征 = 最多 18 回合：商店 → 布置 → 自动战斗 →（若胜）合成结算 → 下一回合。
- 对手：6 种风格 AI 冒险者按轮次曲线出场，每种风格是种子生成的固定构筑：
  1. **新手剑士**（教学轮 1–3，弱构筑教机制）；
  2. **双刀狂徒**（暴击流，中前期压力源）；
  3. **毒药师**（中毒叠加流，教"净化 / 速杀"对策）；
  4. **火焰修士**（燃烧流，教"护甲 / 回血"对策）；
  5. **铁壁卫**（超高护甲 + 回复，教"破甲 / 真实伤害"对策）；
  6. **传说冒险者**（第 16–18 轮 Boss）：混合高段构筑 + 合成装备，远征终点。
- 每 3 轮一个"首领"，首领战前商店必刷克制类物品（保底可解，不靠运气）。
- 段位系统（长期战绩）：青铜 → 白银 → 黄金 → 铂金 → 大师，用任意职业累计胜场晋级。
- 评价：段位徽章 + 每局战绩（胜场 / 剩余远征生命 / 最长连胜）。

**模式二：布局残局（脑洞解谜，第二支柱）**
- 30 关 × 3 章：① 启蒙（10 关，教联动规则）② 进阶（10 关，引入旋转与合成）③ 大师（10 关，多流派组合残局）。
- 每关给定：固定背包形状 + 固定货架与金币 + 固定对手构筑。玩家唯一的任务 = **摆出一个必胜布局**。
- 三星评级：① 胜利 ② 剩余血量 ≥ 50% ③ 战斗回合 ≤ 12。
- 全关卡由求解器保证存在必胜解；卡关时消耗 1 枚"星币"（过关获得）显示参考摆法。
- 这是"空间规划 × 自动战斗"的纯脑洞精华——不看手速、不看运气，只拼布局理解。

**模式三：无尽镜像（彩蛋模式，可选）**
- 对手 = 你自己上一场的构筑镜像，逐轮 +10% 属性膨胀；看你能撑过几轮镜像。
- 记录：存活轮数 + 最高单场伤害。这是本作唯一的"冲分"场景——"镜像自己"天然适合无限验证构筑。

> 本作**不做**每日挑战：种子远征码（见 §5 开放探讨）已提供可复现的公平竞技，每日随机只会打断构筑记忆。

### 3.5 游戏目标与反馈体系
- **核心指标（不是总分）**：远征段位徽章、残局三星收集（x/90）、无尽存活轮数。
- **仪式反馈**：
  - 摆放：相邻联动物品边缘亮起暖金柔光 + 预测数值飘字（"+2 伤害"）；
  - 合成：蓝线点亮 → 战斗结算"叮"金属声 → 两件物品融为一体 + 金光扩散；
  - 战斗：物品触发图标亮起、飘字（伤害 / 暴击 / 回血 / 点燃），Boss 战全屏压迫演出；
  - 晋级：段位徽章铸造成型动画 + 号角音效；
  - 战败：弹出"败因报告"——本场输出 / 承受 / 耐力缺口三方对比，直接告诉玩家该改哪里（原作 combat log 的轻量版）。
- **沉浸式双语**：全站 i18n（`doin.lang`），中文 / English 双语文案严格对齐。

### 3.6 操作与手感汇总

| 输入 | 行为 |
|---|---|
| 鼠标拖拽 / 触屏拖动 | 移动物品进背包 / 换位 / 卖出 |

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：羊皮纸暖黄、墨绿呢绒、黄铜铆钉、手绘奇幻、冒险者营地。
- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**：
  - **整屏 = 一张冒险者营地的木质长桌**：桌面就是游戏舞台。左半桌摊开你的皮革背包棋盘（主舞台，最大宽度约 640px），右半桌立着商店木柜台与货架（卖品像地摊宝物，约 380px），两翼以营帐布帘、火把光晕收边，桌面下有景深暗角与漂浮火星。
  - **禁止四角浮动按钮**：顶部一条"帐篷檐"状态条内嵌返回首页、静音、语言、暂停、帮助。
  - **禁止右侧机械卡片集群**：HUD 全部焊进桌面道具——金币钱袋、回合刻度盘（18 格小木签）、血量与耐力玻璃管、段位徽章托架，全部是实体物件，不是卡片。
  - **战斗回合**：桌面上方升起"擂台幕布"，两侧冒险者登场自动互殴，飘字与状态图标直接落在幕布上；结束后幕布落下回到商店。
  - **桌面端（≥900px）**：长桌居中（总宽 ≤1100px），两侧营帐布深色虚化 + 火把光晕 + 漂浮火星形成景深；左右边缘与底部边缘**不放置任何操作按钮**，为未来广告安全避让留白。
  - **移动端（≤768px）**：上下堆叠——背包在上、商店柜台在下（半屏切换）；主容器底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，绝不让任何按钮贴底。
- **色彩与环境氛围**：
  - 主色：**羊皮纸米黄 + 墨绿呢绒 + 黄铜金 + 酒红绒布**（刻意避开平台已占用的蓝紫、青绿、天蓝、水色、珊瑚橙、古铜棕；与 sokoban 的暖棕古铜靠"米黄 + 墨绿 + 酒红"组合拉开距离）。
  - 交互反馈：摆放联动亮暖金柔光（**无描边圈**——用径向柔光把物品从格子里"托"出来）；合成金光粒子；暴击震屏 + 火星；按钮 = 黄铜实体微浮雕，悬停上浮 `translateY(-2px)`、按下下沉 `translateY(2px)`，配清脆"咔哒"合成音。
  - 动效统一在 `prefers-reduced-motion: reduce` 下瞬移降级。
- **封面设计提案**（遵循 `docs/COVER-STYLE.md`）：
  - 3D 软胶，单一居中主体（约 65%）：**一只圆滚滚的棕色皮背包玩具，口袋半开，冒出一柄发光的金色小剑与一枚金币，旁边飘着两片羊皮纸卷**。
  - 背景：**蜜金麦黄 → 勃艮第酒红**对角渐变（未占用色相），散布漂浮微光粒子。
  - 无任何文字、无 logo、右下角无水印，640×640 WebP，左上主光、投影短而软。

## 5 · 制作人拍板与开放探讨

1. **开局体量**
   - **A（推荐）· 三职业六开局**：3 职业 × 2 款初始背包，深度足够且首发体量可控（~55 件物品 + 12 条配方）。
   - **B · 三职业单背包**：3 职业 × 1 背包，开发更轻，开局变化少一档。
   - **C · 双职业最小体量**：2 职业 × 1 背包，最快上线，但流派策略宽度明显收窄。

2. **模式组合**
   - **A（推荐）· 双支柱**：远征天梯 + 布局残局 30 关。主模式负责"构筑成长"的爽感，残局负责"空间脑洞"的精华，互为补充。
   - **B · 纯残局**：只做 30 关布局解谜，体量最小、辨识度极高，但失去"买买买"的构筑乐趣。
   - **C · 三模式齐上**：双支柱 + 无尽镜像，内容最全、体量最大。

3. **美术题材**
   - **A（推荐）· 羊皮纸 × 墨绿呢绒 × 黄铜**：手绘奇幻冒险行囊，与"背包"题材天然贴合。
   - **B · 复古像素冒险**：经典像素风，情怀向，但与门户现有像素作品的区分度需再确认。
   - **C · 赛博数据包**：电子装备 / 数据整理题材，视觉差异最大，但"皮背包"的核心意象会弱化。

**开放探讨彩蛋：种子远征码**
远征开始前可输入 / 生成种子码，商店序列与对手构筑完全由种子决定；同一种子可复现、可比拼（离线公平竞技），也可作为"今日种子"彩蛋分享给朋友。建议纳入首发——成本极低（种子 PRNG 本来就已注入），传播价值高。

**默认建议：1A + 2A + 3A + 种子码纳入**——先把"买什么 + 放哪里"的核心脑洞做透，用布局残局立住第二支柱，再用种子码给离线玩家一个可传播的比拼维度。
