# 《连连看》小游戏策划案

> 定位：本策划案由产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

---

## 1 · 创意概念与核心乐趣

- **游戏名称**：连连看 / Pair Link / 建议 slug：`pair-link`（备选 `link-match`、`twin-tiles`）
- **一句话玩法**：点选两枚相同图案，用不超过两折的畅通折线连上即消。
- **核心乐趣与卖点**：
  - **扫视快感**：一眼在乱盘里锁定成对图案，像找茬但立刻有解。
  - **路径顿悟**：看似被围死，绕外圈两折一通，瞬间清空通道。
  - **连消上头**：短间隔连续配对触发连击，线光与粒子叠爆。
  - **解压收尾**：盘面从拥挤到镂空，最后几对“一通到底”特别爽。
- **核心循环**：扫盘找对 ➔ 点选验证路径 ➔ 折线亮起、成对消失 ➔ 通道打开、连击升温 ➔ 清盘过关 / 冲下一关。

## 2 · 经典对标与借鉴创新

- **经典标杆与成熟参考**：
  - **QQ 游戏 / 小游戏站《连连看》**：10×8 左右棋盘、图案成对、最多两折（三线段）、盘外可绕、限时清盘、提示与洗牌。
  - **网页版 LianLianKan / WebGames.fun**：三线原则、连消 Combo、剩余时间与未用道具结算加分。
  - **早期单机连连看**：生命点换洗牌、无解自动换牌、边缘优先消除的心智模型。
- **它们最受认可的机制与手感**：
  - 判定必须“一眼可懂”：直连、一折、两折，禁止斜线。
  - 盘周必须留空一圈，否则两折绕外不可用，手感会“假死”。
  - 选中态清晰、非法配对轻抖即回、合法配对折线先画再消。
  - 死局不惩罚玩家智力：检测无解即洗牌或提示，而不是闷杀。
- **我们要借鉴什么**：
  - 经典三线连通判定（0 / 1 / 2 折）。
  - 外圈虚空通道（棋盘四周各留一圈空格，路径可走盘外）。
  - 提示一对可消、洗牌重排剩余块、连击时间窗。
  - 关卡递进：图案种类↑、盘面变密、时限略收。
- **我们的差异化微创新**：
  - **桌面双栏沉浸舞台**，不做居中小棋盘网页表单。
  - **路径可视化**：合法折线沿格子中线画出，两折拐角有短暂停顿，强化“算路成功”的仪式。
  - **通道呼吸**：消除后空位微光残留一瞬，帮助玩家看见新开口。
  - **主题锁定为“夜市灯牌 / 琉璃瓷片”**，区别于水果贴图与开心消消乐的糖果三消。
- **品类排重**：
  - 已有 `Tile-Matching`（三消交换）、`one-line`（一笔画贯通），本玩法是 **成对 + 折线通路消除**，心智完全不同。
  - 填补门户在“经典连连看 / 配对通路”上的空白，属于高知名度经典 IP，允许落在益智品类。

## 3 · 玩法规则与交互说明

### 核心规则

- **盘面构成**：
  - 默认棋盘 **10 列 × 8 行** 实心格（80 格），四周各扩 1 圈永久空通道，逻辑盘 12×10，外圈不可放块、只供绕线。
  - 图案成对出现，每种数量为 2 的倍数；初期 6 种图案，后期增至 10–12 种。
  - 块只占实心格，空通道与已消除格均可作为折线通道。
- **合法操作**：
  - 先点一枚块为选中，再点第二枚。
  - 两枚图案相同，且存在 **水平/垂直折线、转弯 ≤ 2 次、途经格全空** 的路径，则消除。
  - 禁止对角线；路径可走外圈空通道。
  - 再点已选中块、点空白、或点不同且无法连通的块：取消选中 / 第二枚轻抖后保持第一枚选中（便于连点试探）。
- **胜利与失败**：
  - 胜：限时内清空全部实心块。
  - 负：倒计时归零且盘面未清空。
  - 无“步数用尽失败”；洗牌次数用尽且当前无解时，本关失败（见无死局策略，默认应极少触发）。
- **无死局说明**：
  1. **成对生成**：只放置成对图案，总量偶数。
  2. **可解校验**：开局与每次消除后扫描是否存在至少一对合法连通；若无，自动洗牌剩余块（不扣关卡评价的“主动洗牌”次数），直至存在可消对或判定无法重排（极端情况才失败）。
  3. **洗牌约束**：只打乱剩余块位置，不改变种类计数。
  4. 不采用纯随机无校验的死胡同盘。

### 操作与手感

- **鼠标 / 触控**：单击选中与配对；拖出棋盘松手视为取消。
- **键盘**：方向键或 WASD 移动焦点格，Enter / Space 选中或配对，Esc 取消选中，H 提示，R 洗牌（若本关仍有次数）。
- **容错**：
  - 非法第二击不清除第一击（试探友好）。
  - 连击窗口内允许“选中下一块”与上一消动画重叠，不卡手。
  - 提示高亮一对可消，不直接代消。

### 模式与内容递进

- **首选模式：关卡制 36 关**（3 章 × 12 关），通关解锁下一章。
  - 第 1–12 关：6–8 种图案，时限宽松，盘面约 70–80% 填充。
  - 第 13–24 关：8–10 种图案，时限收紧，出现“边角死锁型”布局（仍保证可解）。
  - 第 25–36 关：10–12 种图案，满盘开局，连击成为拿三星的关键。
- **次模式（拍板项）**：无尽冲分（同一难度池循环，清盘立即补一整盘并累加倍率）或每日一盘（同日同种子）。
- **新元素引入节奏**（只做视觉/规则层，不做技术模块规定）：
  - 中期可引入 **冰封块**（需先被相邻成功消除“震碎外壳”才能被选，拍板可选）。
  - 后期可引入 **单向挡板**（某条格边不可穿越，拍板可选）。默认首发可以不做特殊块，先把经典三线打磨顺。

### 目标与评价

- **计分**：
  - 基础分：每对 +100。
  - 连击：3 秒内再消一对，连击 +1，额外 +50 × 连击数。
  - 折线奖励：直连 +0，一折 +10，两折 +30（鼓励绕路破局）。
  - 剩余时间：每秒 +10；未用提示 / 未用主动洗牌各 +80。
- **星级**（每关 1–3 星）：
  - 1 星：通关。
  - 2 星：剩余时间 ≥ 25% 且主动洗牌 ≤ 1。
  - 3 星：剩余时间 ≥ 40%、零主动洗牌、连击峰值 ≥ 4。
- **局内道具**（每关限额，不回满到无限）：
  - 提示 ×3，洗牌 ×2。自动防死局洗牌不消耗次数。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：夜市灯牌、琉璃瓷片、暖铜描边、深墨底、折线霓虹。
- **桌面端沉浸游戏舞台设计**：
  - **拒绝**单列居中小棋盘 + 白底网页按钮。
  - **≥900px**：左/中 **主舞台**（深色木纹或墨地灯箱上的瓷片棋盘，外圈通道用极淡网格暗示可绕）；右侧 **侧栏**（关卡匾额、倒计时沙漏、连击灯牌、提示/洗牌印章按钮、星级槽）。
  - **≤768px**：棋盘占上 70%，底栏收纳计时与道具，取消侧栏装饰文案。
- **色彩与环境氛围**：
  - 主色：**暖铜 + 绯红灯丝**，底色深墨褐（避开门户已饱和的蓝紫、青绿、玫瑰粉、暖橙金大面积块）。
  - 选中：瓷片外圈铜线呼吸；非法配对：短促朱红抖动。
  - 合法消除：折线按 0/1/2 折依次点亮，瓷片碎成琉璃粒子向折线中点收束。
  - 连击 ≥3：侧栏灯牌闪一次，棋盘边缘一圈暖光。
- **封面设计提案**：
  - 3D 软胶质感，单一居中主体：**两枚相同琉璃瓷片被一道两折霓虹线穿起**，线的拐角挂一滴铜光。
  - 背景色相：深墨底 + 绯红灯晕（与现有封面墙错色）。

## 5 · 制作人拍板与开放探讨

1. **特殊块要不要首发？**
   - A. 纯经典：只有普通瓷片，36 关全靠密度、种类与时限拉难度（上线快、规则零学习成本）。
   - B. 中后期加 1 种“冰封壳”（先震碎再连），关卡叙事更有层次。
2. **次模式选哪条？**
   - A. 无尽补盘冲分（连击倍率跨盘继承，适合刷纪录）。
   - B. 每日一盘同种子（适合门户“今日挑战”入口）。
3. **图案题材定哪套？**
   - A. 夜市灯牌图标（包子、灯笼、糖葫芦、收音机等，偏市井）。
   - B. 抽象琉璃几何（圆、菱、回纹、云纹，更耐看、少文化过载）。

默认建议：**1A + 2A + 3B**——先把经典三线手感做透，用抽象琉璃保证桌面质感，无尽模式提供回访。

## 6 · 拍板结果（已落地）

| # | 议题 | 拍板 | 落地说明 |
|---|------|------|----------|
| 1 | 特殊块要不要首发 | **B · 冰封壳首发** | 第 1 章纯经典（0 枚）；第 2 章 4/5/6 枚；第 3 章 8/10/12 枚，随小关递增。带壳瓷片点不动，需先消掉其 8 邻域（含斜向）一圈瓷片把壳震碎。 |
| 2 | 次模式选哪条 | **B · 每日一盘** | 门户「今日一盘」入口。同一日期全服同一副盘面（`dateKey` 派生关卡 + 种子），只记录当日最佳，**不占用主线进度**。无尽冲分保留为第三模式。 |
| 3 | 图案题材定哪套 | **B · 抽象琉璃几何** | 12 种母题（水滴 / 回纹 / 云纹 / 菱 / 圆 等），纯 SVG 路径，零外链。 |

### 落地要点

- **冰封壳编码**：棋盘值 `v ∈ [1,12]` 为裸值，`v + 12 ∈ [13,24]` 表示带壳。好处：「非 0 即有块」判定零改动、洗牌置换值数组时壳自动跟随、无需平行数组。读母题走 `motifOf()`，判壳走 `isFrozenValue()`。
- **可解性不变量不变**：`findAnyPair` 跳过带壳块；死盘兜底顺序为「洗牌 → 若仍无解且有壳则融壳 → 再洗牌」，**绝不把死盘交给玩家**（`resolveDeadlock` 返回 `melted` 标记）。
- **每日一盘与主线解耦**：`dailyLevelIndex(key)` 挑关、`dailySeed(key)` 出种子；结算只写 `progress.daily`，`unlocked` / `levels` / `lastLevel` 一律不动（存档 VERSION 保持 1，老档不丢）。
- **无障碍**：带壳格的 `aria-label` 追加「冰封」，`cursor: not-allowed`；震碎 / 融壳均有播报与提示。
