## 1 · 创意概念与核心乐趣

- **游戏名称**：每日猜词 / Wordle（副标：六次机会 · 逐字反馈 · 每日一词）/ 建议 slug：`wordle`
- **一句话玩法**：每天一个词（或一个成语），六次机会逐字猜——绿色=位字俱对、黄色=字对位错、灰色=不在词中，猜中即胜。
- **核心乐趣与卖点**：
  - **六次机会的推理快感（Six-Shot Deduction）**：每次反馈都是信息增量——绿黄灰三色把词库逐轮收窄，推理链条清晰可见，"差一点就中"与"一杆进洞"同样刺激；
  - **每日一词的仪式复玩（Daily Ritual · 用户点名）**：每天一个词、全球/全站同题、错过不补——稀缺性制造仪式感，天然驱动日复一日回访；**日期种子确定性选取**契合平台"确定性种子每日同题"传统，可测、可背、可分享；
  - **中英双轨（Bilingual Tracks · 用户点名）**：英文轨 = 经典 5 字母单词；中文轨 = **四字成语逐字反馈**——同一套六次机会与三色反馈，两种语言两套思维，玩家自由切换；
  - **逐字母反馈的即时顿悟（Letter-by-Letter Reveal）**：每个字母翻转揭晓的那一刻，是排字、推敲与恍然大悟的三段式节奏；
  - **全站唯一文字品类（Word Gap · 用户点名）**：DOIN 67 款游戏零文字品类，本作以每日猜词补位唯一空白——规则成熟、10 秒上手、零加载纯静态。
- **核心循环**：
  ```
  看今日词（日期种子）➔ 输入猜测词（逐字母铅字上版）➔ 逐字母三色反馈（绿/黄/灰）
       ↑                                                    ↓
  反馈收窄词库（推理）← 词不在库提示（不耗机会）← 非法词（不在词库）
       ↓（机会 -1 · 六次内）
  猜中 = 胜利（步数统计）｜六次未中 = 揭晓答案 → 步数分布/连胜天数更新 ➔ 明日再来
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Wordle（Josh Wardle 2021）** | Web（后被 NYT 收购） | 六次猜 5 字母词、绿黄灰逐字母反馈、每日一词 | 2022 全球现象级爆款，社交分享与每日仪式开创者 | 六次机会、三色反馈算法（含重复字母配额）、每日一词与步数分布统计 | 英文单一语言（本作加中文成语轨） |
| **汉兜 HanDol / 成语 Wordle（中文爆款）** | Web/移动 | 猜四字词/成语，声母韵母或逐字反馈 | 中文 Wordle 的成熟本土化范式 | 四字成语逐字反馈、六次机会 | 声母韵母反馈过深（本作逐字三色，10 秒上手） |
| **Terminal / 字母推理类（Bulls and Cows 变体）** | 全平台 | 逐位反馈的数字/字母推理 | 推理博弈的经典算法 | 反馈驱动词库收窄的推理结构 | 无每日仪式与统计（本作继承） |
| **Quordle / 多词变体** | Web | 同屏多词并行猜 | 单日内容扩充 | 步数分布与连胜统计 | 同屏多词过重（本作保持单词专注 + 双人对抗可选） |

**我们要继承的成熟机制**：
1. **六次机会 + 三色反馈（Six Chances & Tri-Color Feedback）**：绿=位字俱对、黄=字对位错、灰=不在词中；**重复字母按标准配额算法**（只对答案中实际出现的次数给黄/绿）——Wordle 验证过的公平反馈；
2. **每日一词与步数统计（Daily Word & Guess Stats）**：每日同题、错过不补；统计 = 胜率 / 步数分布（1–6）/ 连胜天数——社交与复玩的引擎；
3. **合法词校验（Valid Guess Check）**：输入必须在词库内才可提交，词不在库提示不耗机会——规则透明无惩罚性挫败；
4. **词库双轨（Dual Wordlists）**：英文 5 字母常用词库 + 中文四字成语词库，全部人工精选、无重复、确定性种子选取；
5. **固定步长确定性逻辑（Deterministic Logic）**：120Hz 纯函数帧步进、日期种子每日同题、种子注入、同种子重放一致（本策划案的核心契约）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **中英双轨同题（Bilingual Dual Track · 用户点名）**：同一界面双轨自由切换——英文轨 5 字母、中文轨四字成语，两套词库两套思维，一套反馈逻辑统一驱动（纯静态零加载）；
2. **老式印刷社铅字排印视窗（Letterpress Printshop）**：今日词是"今日头条"——逐字母铅字上版，油墨绿/待改黄/弃字灰三色（软光无描边），输入用实体铅字键盘，统计写在排印工作单上；全站无同款视窗；
3. **日期种子每日同题契约（Seeded Daily Word）**：`mulberry32(hash(YYYYMMDD)) % 词库长度` 确定性选取——与平台确定性种子传统对齐，全站同日同题、可测可背、可分享；
4. **双人同词对抗（可选）**：同屏双栏、同一每日词，各自六次机会，比谁先猜中/更少步数——把独乐乐变成派对局（见拍板项 3）；
5. **色盲友好反馈（Accessible Feedback）**：三色反馈外提供图形标记（✓/●/✕）开关，绿黄灰之外不依赖色觉——无障碍红线与玩法机制兼顾。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（铅字排印台，桌面 2D + DOM 键盘）
- **今日词条（Daily Word）**：每日一词——英文轨为 5 字母单词、中文轨为四字成语；由日期种子确定性选取（全站同日同题）；
- **猜测区（Guess Board）**：6 行 ×（5 格或 4 格）铅字排印格，当前行逐字输入、提交后逐字翻转揭晓三色反馈；
- **铅字键盘（Type Case）**：金属铅字实体键盘（英文 26 键 / 中文 20+ 常用字候选键 + 拼音输入辅助），键位随反馈变色（绿/黄/灰），可用物理键盘直打；
- **排印工作单（Work Sheet）**：统计牌——今日胜率、步数分布（1–6 柱）、连胜天数、双轨切换；
- **词库（Wordlists）**：`js/wordlists.mjs` 独立数据文件——英文答案词库（约 2000 常用词）+ 英文合法猜测词库（约 4000）+ 中文成语词库（约 800 常用四字成语），人工精选、无重复。

### 3.2 判定与反馈规则（核心契约：六次机会 + 三色反馈）
1. **输入**：英文轨逐字母输入 5 位；中文轨四字成语——支持拼音候选选择（输入拼音 → 候选成语 → 上版），或逐字从常用字盘选字；
2. **提交校验**：满位后提交——**词必须在对应词库内**；不在词库 → 提示"词不在库"（行内提示，不消耗机会，无 `alert()`）；在词库 → 锁定该行并逐字揭晓反馈；
3. **逐字反馈（标准 Wordle 算法，含重复配额）**：
   - **绿（位字俱对）**：该字在答案中且位置相同；
   - **黄（字对位错）**：该字在答案中但位置不同；
   - **灰（不在词中）**：该字不在答案中；
   - **重复字配额**：答案中某字出现 k 次，则所有猜测行中该字最多计 k 次绿/黄（其余标灰）——与 Wordle 标准一致，可测可断言；
4. **胜负判定**：
   - **胜利**：任意一行全绿 → 本局胜，记录步数（1–6）；
   - **失败**：六行用尽未猜中 → 揭晓答案，本局负；
5. **统计（Statistics）**：最近 7 日胜率、步数分布柱（1/2/3/4/5/6）、当前连胜天数；本地存档 `doin.wordle.v1`（集中 try/catch 降级内存）；
6. **双轨同题**：英文轨与中文轨各自独立每日词（同一日期种子、各自词库），切换互不干扰、进度各自保存。

### 3.3 模式与内容编排（每日解密品类 → 每日模式天然适配，绝不硬塞三件套）
- **每日一题（Daily，核心模式）**：今天一个词/成语、六次机会、错过不补——稀缺性制造每日仪式复玩；**即开即玩**：打开直接载入今日词盘面，无前置遮罩；常驻"模式/语言轨"入口随时切换；
- **练习场（Practice）**：随机词/成语（确定性种子可指定，便于练习与测试），不限次数，用于熟悉词库与推理节奏；
- **同屏双人对抗（2P Duel，可选）**：同一每日词，同屏双栏各自六次机会，轮流输入、比谁先猜中（同步数则先手胜）或更少步数（见拍板项 3）；
- **统计面板（Stats）**：胜率/步数分布/连胜天数 + 分享文本（纯文本分享今日战绩，不接外部网络）。

### 3.4 无死局与公平保证（数学可解性）
1. **每日同题确定性**：每日词 = `mulberry32(hash(YYYYMMDD)) % 词库长度`——同日期必同词、跨日期必不同（词库够大且种子哈希散列），测试断言覆盖；
2. **反馈算法公平性**：三色反馈（含重复字配额）为纯函数确定性算法，无随机、无歧义；任意合法猜测都有且仅有一个确定反馈；
3. **词库公平性**：答案词库全部为**人人可猜的常用词/常用成语**（人工精选、无生僻冷门）；合法猜测 = 词库内任意词，规则透明；
4. **无死局保证**：猜词推理天然存在最优解路径（每次反馈将候选集收窄至非空，六次机会内始终存在可穷举的推理空间）；练习场随机词同样种子可测；
5. **确定性契约**：词库、日期种子、练习场随机种子全部确定性；≥1000 步随机输入游走（合法/非法词混合，状态机不崩、机会数守恒、反馈算法断言、终局判定正确）。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **桌面鼠标（主路径）**：
  - **英文轨**：点击铅字键盘键位逐字输入；`Backspace` 退格、`Enter` 提交；物理键盘可直打（字母键 + `Enter`/`Backspace`）；
  - **中文轨**：拼音输入辅助——输入拼音字母出候选成语列表，点击候选上版；或点击常用字盘逐字选字；`Enter` 提交、`Backspace` 退格；
  - Input Buffer：提交/退格 60ms 窗口接受，连点不吞指令；
- **键盘**：字母/拼音键直打，`Enter` = 提交，`Backspace` = 退格，`1/2` = 切换英文/中文轨（不打断当前局），`Esc` = 暂停/退回弹层；
- **移动端（触控）**：屏幕铅字键盘输入（英文全键盘 / 中文拼音键盘 + 候选条）；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡键盘区；
- **手感调优**：逐字上版"咔哒"；提交后逐字翻转揭晓"咔—嗒"（机械翻转）；全绿通关排印机"叮铃" + 大七和弦；词不在库行内温和提示（软光，禁 alert）；键盘键位随反馈变色（无边界径向柔光）。

### 3.6 双语核心词汇与数据键名规划（防英文界面夹杂中文）

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词
**老式印刷社铅字排印台（Letterpress Printshop）**、金属铅字、油墨绿、红木字架、排印工作单、暖琥珀灯、油墨纸屑微尘。

### 4.2 专属视窗物理隐喻（严禁左右双翼模版）
本作不是"网页里嵌个文字输入框"，而是一方**老式印刷社的铅字排印台**：

```
+---------------------------------------------------------------------------------------+
|  印刷社暖琥珀灯·油墨微尘  [🏠] [每日猜词 WORDLE] [🔊][🌐][❓] [中/EN]                    |
+---------------------------------------------------------------------------------------+
|                                                                                       |
|   ╭────────────── 今日头条·铅字排印工作单 ──────────────╮                               |
```

1. **排印台即全部**：今日词是"今日头条"——猜测区是铅字排印格、输入是金属铅字键盘、统计写在排印工作单上，**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **三色反馈即油墨**：绿=油墨定版、黄=待改字、灰=弃字——反馈色与印刷社题材同构，且采用**无边界径向柔光**（禁硬边描边圈），另提供图形标记（✓/●/✕）色盲友好开关；
3. **红木字架与铅字键盘**：键盘键位随反馈染上三色墨迹，猜测区逐字翻转如铅字压印；
4. **环境氛围**：印刷社暖琥珀灯 + 油墨/纸屑微尘粒子，拒绝死黑/死白大平铺；返回、音效、语言轨收纳进排印台顶框一体化状态条；
5. **移动端（≤768px）**：猜测区全宽撑满、铅字键盘置底，底部严格预留广告安全避让区，绝不遮挡键盘区。

### 4.3 立体质感与渲染路线裁决
- **裁决：纯 Canvas 2D 猜测区 + DOM/CSS 3D 铅字排印台框体**（不做 Three.js）：
  - 猜测区、铅字块、三色反馈翻转、墨迹粒子 → Canvas 2D（铅字浮雕 + 无边界径向柔光），120fps 秒开零发热；
  - 排印台立体感（红木字架、铅字键盘键帽、排印工作单、印刷社光晕）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/统计/弹层全部严格留在 DOM 层；
  - 理由：文字网格为平面二维结构，无真 3D 视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **键入字母（Key Press）** | 金属铅字敲击"咔哒" | 短噪声 + 金属/木质共振，键位不同微调音高 |
| 2 | **提交上版（Submit）** | 铅字上版"咚" | 低频木响 + 短促噪声瞬态 |
| 3 | **反馈翻转（Reveal Flip）** | 每个字母翻转的机械"咔—嗒" | 双段噪声脉冲（翻转 + 落定），随反馈色微变调 |
| 4 | **全绿通关（Win）** | 排印机"叮铃" + 大七和弦 | FM 编钟上行琶音 + 高频铃音 |
| 5 | **词不在库 / 失败（Not-in-List / Lose）** | 词不在库短促"嘟"；失败低鸣下滑 | 词不在库=短带通脉冲；失败=失谐双振荡器下滑 |
| 6 | **印刷社氛围（Ambient）** | 暖光低嗡 + 纸页微响 | 失谐锯齿波 + LFO + 噪声滤波微响，轻微 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，**零文字**；
- **主体构图**：单一居中主体，占画面 65%~70%——**三枚 3D 软胶方块**（油墨绿 / 待改黄 / 弃字灰三色柔光）从一小堆铅字方块中弹出悬空，方块表面为柔和圆角无文字纹理，传递"三色反馈"的游戏气质；
- **背景与氛围**：深墨绿至暖琥珀的平滑径向渐变背景 + 油墨微尘与虚焦光斑，软胶质感饱满温润——一眼传达"每日猜词 · 三色反馈"（零文字亦成立）。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：中文轨形态？
- **选项 A（四字成语逐字反馈 · 推荐）**：每天一个四字成语，逐字三色反馈——中文 Wordle 最经典形态，10 秒上手；
- **选项 B（二字/三字常用词）**：更短更易的词（二字词/三字词），上手更轻但推理空间小；
- **选项 C（汉兜式深度反馈）**：成语 + 声母/韵母/声调多维度反馈，推理最深但学习成本高。

### 拍板项 2：模式配比？
- **选项 A（每日一题 + 练习场 + 双人对抗三轨 · 推荐）**：每日一题（双轨同题）为核心，练习场与同屏双人对抗为附加——仪式复玩、自由练习、派对博弈三种乐趣齐备；
- **选项 B（每日一题 + 练习场）**：只做每日一题与练习场，最聚焦；
- **选项 C（纯每日一题）**：最纯净的每日仪式，无练习无双人。

### 拍板项 3：同屏双人形态？
- **选项 A（同词双板对抗 · 推荐）**：同一每日词、同屏双栏、各自六次机会轮流输入，比谁先猜中（同步数先手胜）或更少步数；
- **选项 B（共享机会轮流猜）**：同一块猜测区、共享六次机会，两人轮流输入（合作向）；
- **选项 C（不做双人）**：纯单人每日体验。
