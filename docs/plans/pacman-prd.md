## 1 · 创意概念与核心乐趣

- **游戏名称**：霓虹吃豆 / Neon Chomp / 建议 slug：`pacman`（单单词、零歧义，符合极简命名契约）
- **一句话玩法**：在霓虹迷宫里吞光所有豆，避开四色幽灵，吃下能量豆反身追捕。
- **核心乐趣与卖点**：
  - **★ 全站唯一的正统幽灵 AI 状态机**：`lantern-maze` 是提灯探索，`devil-run` 是无脑追逃——**没有一款是真正在跑 1980 年那套四幽灵差异化 target 规则**。Blinky 直取、Pinky 抄前路、Inky 借 Blinky 做向量反射诡谲包抄、Clyde 靠近就怯场——这四套性格在同一个 Scatter/Chase 节拍下合奏出来的"被围堵感"，是四十年来被反复验证却从未被网页小游戏认真复刻的东西。**本作把它做成头号卖点**；
  - **★ 把隐藏的 AI 变成可读的语言（招牌创新）**：原版玩家的成长曲线是"背板"——死一百次才隐约摸出 Pinky 会抄前路。本作让**每一只幽灵的眼睛恒指向它当前的真实 target 格**，脚下的同色柔光环按状态改变形态（Scatter 呼吸散环 / Chase 收紧并拉出指向箭头 / Frightened 断续虚线急闪 / Eaten 只剩一双眼睛 + 细线导回巢）。玩家从"背版"变成"读 AI"，**第一次死亡就看得懂自己是怎么被算死的**；
  - **★ 节拍器（Metronome）：隐藏计时器变成可听可感的节奏**：Scatter/Chase 切换前 3 秒，屏幕外框的电流脉冲开始加速闪烁、低频心跳"咚-咚"渐强；切换瞬间一次全频电流扫过。底部节拍轨实时显示当前是 Scatter（青）还是 Chase（红）及剩余秒数。于是玩家能踩着节拍决策——"还有 3 秒进 Chase，现在该回收右下角那串豆了"；
  - **★ 豆链（Pellet Chain）：让路线规划的乐趣从第一颗豆就存在**：连续吃豆 1.2s 内不断链，每 10 颗升一级（×1 → ×1.5 → ×2 → ×3），吃豆音随链级升半音、脚下拖影变长。原版只有在"只剩最后 20 颗"时才有路线规划的乐趣，本作从第一颗豆就在奖励**连贯的走位**；被幽灵贴近（<4 格）时链不重置但增速减半——风险回报立得住；
  - **★ 巢压（Den Suppression）：把"吃豆"和"压制幽灵"接成一条正反馈链**：被吃掉的幽灵回巢后需在巢内**充能**一段时间才出巢（巢口是一枚逐渐充能的光核 + 剩余秒数环）。**玩家每吃 10 颗豆，可延后所有待出巢幽灵 0.5s（单次上限 3s）**。于是"闷头吃豆"直接等价于"压制幽灵"，两个原本割裂的行为第一次被焊在一起；
  - **★ 转角预输入（Cornering）：把高手技巧变成可教学的基本功**：路口前 0.15s 内按下的转向被缓冲，到达路口瞬间自动转向且**不减速**；预输入生效时路口亮起该方向的短箭头（教学期可见，设置可关）。这是原版高手靠肌肉记忆才能掌握的技巧，本作直接给你；
  - **7 张主题迷宫，每张一个新机关**：不是换皮换色，是逐张引入单向风道 / 潮汐闸门 / 糖浆区 / 冰面 / 第二幽灵巢，**每张都在改写玩家的走位语法**。
- **核心循环**：
  ```
  读节拍轨（现在是 Scatter 还是 Chase） ➔ 规划一条连贯吃豆路线（豆链不断）
        ↑                                                    ↓
  被围堵 → 看幽灵眼睛与意图环判断谁在锁我 → 拐进回路 / 钻隧道甩开      ↓
        ↑                                                    ↓
  吃能量豆 → 电网过载（幽灵变蓝闪烁）→ 反身连吃（200/400/800/1600）→ 巢压延长安全期
        ↓
  清盘 → 灯管波扫点亮 → 结算翻转牌（用时 / 豆链最高级 / 连吃数）→ 三星 → 推进下一张迷宫
  ```

**我们要继承的成熟机制**：
1. **28×31 格、8px 逻辑单位的黄金网格**：原版参数，放大 2.5× 渲染不模糊；这是所有"迷宫可记忆、走位可精算"的地基；
2. **四幽灵差异化 target 规则**（见开工指令第 2 条），一条不改；
3. **禁止 180° 反向 + 路口取到 target 欧氏距离最小**：这条决定了幽灵"像有脑子"而不是"像随机游走"；
4. **Scatter/Chase 节拍表 + dot counter 出巢 + Cruising Elroy**：三个参数共同制造"越到后面越紧张"的曲线，被验证四十年；
5. **隧道 wrap + 隧道内幽灵减速 50%**：隧道是原版的"保命通道"，必须保留；
6. **200 / 400 / 800 / 1600 的四连吃分**：游戏史上最优雅的风险递增设计。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **★ AI 意图可视化**：幽灵眼睛恒指向真实 target 格 + 状态柔光环 + 巢内充能倒计时，把 1980 年的黑箱状态机翻译成玩家看得懂的语言（可在设置里关闭，硬核玩家随时退回纯背板）；
2. **★ 节拍器**：Scatter/Chase 切换前 3 秒的脉冲闪烁与心跳音 + 底部节拍轨，让隐藏计时器成为可踩的决策节奏；
3. **★ 豆链**：连续吃豆升倍率 ×1 / ×1.5 / ×2 / ×3，音高随链级升，被贴近时增速减半；
4. **★ 巢压**：吃豆延后幽灵出巢（每 10 颗延后 0.5s，上限 3s），把清盘行为与压制行为接成一条链；
5. **★ 转角预输入 + 路口箭头**：0.15s 输入缓冲、转向不减速，把高手技巧教学化；
6. **★ 7 张主题迷宫 + 6 个新机关**：单向风道 / 潮汐闸门 / 糖浆区（玩家减速 25%、区内豆分 ×2）/ 冰面（松手滑到格心）/ 第二幽灵巢（打破背板）/ 终局全机关混合且幽灵永不 scatter；
7. **★ 霓虹灯管世界观**：Frightened 不是简单的"变蓝"，而是**灯管接触不良的蓝色闪烁 + 全盘压暗一档**——视觉与题材自洽，不是给幽灵套个蓝色滤镜。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素
- **迷宫盘面（Grid）**：28 列 × 31 行，逻辑格 8px（全盘 224×248）；桌面端等比放大约 2.5×（约 560×620），像素对齐不模糊。
- **格类型（数据层字符矩阵，零中文）**：
  - `#` 霓虹灯管墙（挡人挡鬼）／ `.` 豆 pellet（10 分）／ `o` 能量豆 power_pellet（50 分，盘面四角附近各 1 枚）
  - ` ` 空通道（已吃或无豆）／ `-` 幽灵巢门（仅幽灵可穿）／ `T` 隧道格（左右边缘 wrap）
  - `>` 单向风道（**仅可顺箭头方向通过**，逆向撞上被弹回并停顿 0.15s）
  - `G` 潮汐闸门（每 6s 开合一次，关闭时人鬼皆不可穿；开合前 1s 有闪烁预告）
  - `~` 糖浆区（玩家速度 ×0.75，幽灵不变；**区内豆分 ×2**）
  - `*` 冰面（松手后继续滑行至格心才停，转向输入仍即时生效）
  - `H` 幽灵巢（主巢在盘面中部；第 6 张起有 `H2` 第二巢）
- **玩家（Chomper）**：柠檬黄霓虹"张合嘴"，占 1 格，速度 **8.8 格/秒**。
- **四幽灵**：草莓红 `blinky` / 蜜桃粉 `pinky` / 薄荷青 `inky` / 香橙 `clyde`，速度 **8.4 格/秒**（略慢于玩家，经典平衡）；隧道内 ×0.5；Frightened 时 ×0.5；Eaten 回巢时 ×2.5。
- **水果（Fruit）**：每迷宫吃到 70 颗与 170 颗豆时，在巢口下方出现一次，停留 9s；分数随迷宫递增（100 → 5000），数据层用 `fruit_cherry` / `fruit_strawberry` 等 key。
- **命数**：初始 3（HUD 表现为 CREDIT 灯 3 盏）；每 10000 分 +1，上限 5。

### 3.2 判定与胜负规则
1. **胜利条件**：吃光盘面全部豆与能量豆（清盘）；残局模式另有 `clear` / `escape` / `chain` 三类目标；
2. **失败条件**：命数耗尽；残局模式叠加"超时 / 超步数"判定；
3. **碰撞**：与 `scatter` / `chase` 态幽灵同格 → 掉 1 命，全盘复位（幽灵回巢、节拍计时重置，豆的进度保留）；与 `frightened` 态幽灵同格 → 吃掉（200/400/800/1600 递增），幽灵转 `eaten` 回巢；
4. **Frightened 时长**：街机无尽模式按关数递减（L1 6s → L19+ 0s，0s 时能量豆仍给分但幽灵不进入 frightened），战役模式固定 6s；**连吃期间 Frightened 计时暂停**（鼓励清盘式连吃）；
5. **无死局说明（硬性）**：7 张迷宫与 10 张残局均为固定数据、零随机，出场前跑 BFS 校验（见开工指令第 4 条）；街机无尽为 7 张迷宫轮换 + 固定速度曲线，同样零随机；**单向风道的方向约束必须纳入可达性校验**，任何一颗豆不可达即判定关卡数据不合格。

### 3.3 手感调优与操作映射（键鼠触全通）
- **移动**：桌面 `↑↓←→` 或 `WASD`；按住持续行进；**转角预输入窗口 0.15s**——在到达路口前按下转向会被缓存，到达瞬间执行且不减速；
- **暂停 / 重开**：`空格` 暂停、`R` 重开本迷宫；
- **操作缓冲（Input Buffering）**：转向指令在"贴墙无法通过"的 0.12s 内按下会被缓存，脱离墙面立即执行；**绝不吞输入**；
- **触屏**：**霓虹四向拨盘（固定位置，不跟随手指）** 为主输入；可选切换为 **swipe 滑动手势**（移动端走位的正解，设置项）；两枚糖果色圆钮（暂停 / 重开）在拨盘右侧；
- **移动端避让**：底部严格预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`；盘面 `touch-action: none` + `overscroll-behavior: none`；
- **降级**：`@media (prefers-reduced-motion: reduce)` 下去掉辉光脉动与震屏，**仅保留瞬时状态切换，绝不隐藏任何核心交互件**。

### 3.4 模式编排（为"读 AI + 走位"量身定制，拒绝千篇一律）
1. **战役 · 7 张主题迷宫（Campaign · 绝对主轴）**
   - `maze_1` 经典巷（教学：双侧隧道 + 4 能量豆，无新机关）
   - `maze_2` 霓虹回廊（引入 **单向风道**）
   - `maze_3` 潮汐管廊（引入 **潮汐闸门**）
   - `maze_4` 糖浆工坊（引入 **糖浆区**：减速换双倍分）
   - `maze_5` 霜冷冰库（引入 **冰面滑行**）
   - `maze_6` 双巢回路（引入 **第二幽灵巢**，两只幽灵从另一角出巢夹击，背板彻底失效）
   - `maze_7` 终局霓虹（全机关混合 + **幽灵永不进入 scatter**，Blinky 全程 Elroy）
   - 每迷宫三星独立授予：**① 清盘 ② 限时内清盘（关卡基准时间）③ 零死亡**；总星数 21 为真正的追求指标。
2. **街机无尽（Arcade Endless）**
   - 7 张迷宫轮换，关数递增 → 玩家速度 +、幽灵速度 +、Frightened 时长递减（L1 6s → L19+ 0s）、Elroy 提前触发；记录**最高关数**与**最高分**（不是刷分榜，是"你能撑到第几关"）。
3. **残局 · 10 张手编（Set Pieces）**
   - 给定剩余豆、幽灵精确位置与状态、能量豆位置，要求在限定时间 / 步数内达成三类目标之一：
     - `clear`：清空指定区域的全部豆（考路线规划）
     - `escape`：从起点安全抵达指定出口格（纯考读 AI 与走位）
     - `chain`：在不死的前提下连吃全部 4 只幽灵（考能量豆时机与追捕路线）
   - 这是**把"读 AI"从肌肉记忆提纯成解谜**的模式，也是本作最有深度的部分。

> 说明：本作**不设每日挑战**——迷宫追逐的乐趣在于精进与推进，不在每日解谜。

### 3.5 反馈体系与评价
- **核心指标**：战役总星数（21 星）、街机最高关数与最高分、残局完成数、**豆链最高等级**、**四连吃达成次数**、无伤清盘次数；

- **结算仪式感**：最后一颗豆被吃掉 → 全盘霓虹灯管**依次点亮一圈**（0.6s 波扫，从玩家位置向外扩散）→ 迷宫短暂过载白闪 → 底部 **翻转数字计分牌**逐位 flip 出「用时 / 豆链最高级 / 连吃数 / 三星」→ 三枚星章依次"咔哒"点亮；

### 4.2 专属视窗物理隐喻（严禁左右双翼 + 机顶木梁旧模版）

>

**形态细则**：
1. **顶部压印铭牌条**：返回首页（铆钉箭头）、游戏标题（霓虹压印体，带极缓的辉光呼吸）、音效（**实体闸刀开关**，扳动有金属咔哒）、语言（**拨牌开关**）、规则（**挂在铜挂钩上的一张卡片**，点开摊开）——**全部熔铸进铭牌条，严禁四角散落**；
2. **中央霓虹招牌**：圆角钢制框 + **深青亚克力背板**（约 185°–192° 深青墨色，带细微噪点、四角辉光与边缘反光带，绝不用纯黑）；迷宫墙 = **弯制霓虹灯管**（三层画法：外层大 `shadowBlur` 光晕 + 中层饱和管壁色 + 内层近白亮芯，玻璃管带顶部反光条）；豆 = 灯管之间排布的**暖白小灯泡**（径向柔光，吃掉即熄灭，但通道地面保留极淡的灯管反射光，盘面不会越吃越黑）；能量豆 = **大功率闪灯**（脉动呼吸 + 大光晕）；幽灵 = **四团半透明彩色霓虹光云**（草莓红 / 蜜桃粉 / 薄荷青 / 香橙，带辉光拖尾，眼睛是两枚白炽亮点并恒指向真实 target 格）；玩家 = **柠檬黄霓虹张合嘴**（上下两片圆弧灯管随移动开合）；
3. **Frightened 的题材自洽表达**：不是套蓝色滤镜，而是**幽灵灯管变蓝并开始接触不良的闪烁** + 全盘灯管亮度压暗一档 + 镇流器发出慌张的 5.5Hz 颤动嗡鸣——视觉、听觉、世界观三者一致；
4. **底部镇流器控制台（与钢架连体）**：非浮空卡片，是招牌下方焊死的深色金属面板——左：**霓虹四向拨盘**（软胶球形拉线头，拨动有物理倾角与回弹）；中：**两枚数码管计分窗**（`1UP` / `HIGH SCORE`，红橙数码管）+ **节拍轨**（一条发光进度条，Scatter 青 / Chase 红，实时显示剩余秒数）+ **CREDIT 灯**（命数 = 亮着的灯数）；右：**启动 / 暂停**两枚糖果色圆钮（微浮雕，按下 `translateY(2px)`）；
5. **移动端**：铭牌条收折为顶部细条，控制台收折为底部连体金属条（四向拨盘左、暂停右），底部严格预留广告安全避让；
6. **质感与反馈**：吃豆 = 灯泡"啪"地熄灭 + 一圈微光收缩；被吃幽灵 = 光云爆散成彩光碎片；死亡 = 玩家灯管张嘴合不上 → 缩成一团 → 熄灭（见音效）；**所有高亮/预警一律用径向柔光与呼吸脉动，严禁给主体描硬边描边圈**。

### 4.3 立体质感与渲染路线裁决
**Canvas 2D 绘制迷宫灯管 / 豆 / 幽灵光云 / 吃豆人 + 语义 DOM 承载全部 HUD / 计分窗 / 节拍轨 / 拨盘 / 弹层**。
- 霓虹辉光必须靠 Canvas 的多层合成（大 `shadowBlur` 光晕层 + 管壁层 + 亮芯层），DOM/CSS 做不到这种层叠发光质量；
- 立体感不靠 3D 引擎：灯管用"管壁渐变（上亮下暗）+ 内侧投影 + 背板内阴影凹陷 + 钢框金属渐变"即可做出真实的玻璃管厚度与招牌实体感；
- **不引入 Three.js**：本作为严格俯视 2D 网格玩法，不存在真三维空间变换需求。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化，零音频文件，严禁蜂鸣器）
1. **吃豆（waka）**：极短噪声 burst 经 bandpass（中心频率随**豆链等级**每升一级升半音）+ 一薄层三角波体，两音交替 → 软糖般的"呲-呲"，绝不是 beep；
2. **★ 能量豆 · 电网过载**：镇流器启动的低频"嗡——"（锯齿 + lowpass 扫频上行）+ 一声**日光灯启辉器的"啪"**（高频 click + 短混响）；Frightened 期间背景叠一层 5.5Hz 颤动的 pad（灯管接触不良的慌张感）；
3. **吃幽灵**：失谐双振荡器上行滑音 + 高频霓虹爆碎（噪声 + 高通 + 极快衰减）；连吃 4 只音高逐级升高，第 4 只额外叠一记厚重低音 Kick；
4. **★ 节拍心跳（Metronome）**：Chase 切换前 3s 起低频"咚-咚"（60Hz 正弦 + 快速包络，叠镇流器底噪），随切换临近加快；切换瞬间一次全频电流脉冲（噪声 burst + bandpass 扫频）；
5. **幽灵出巢**：FM 金属"叮"（启辉器 / 小编钟），带回响尾；巢内充能时有一声极轻的电流"滋滋"渐强；
6. **死亡**：玩家灯管"熄灭"——pitch 下扫 + lowpass 关闭 + 一声泄气的噪声尾巴（"呲——呜"），与全盘灯管渐暗严格同帧；
7. **拉线开关 / 开局**：机械"咔哒"（金属弹簧 + 硬币 click 质感）+ 镇流器预热的嗡鸣上行——开机的仪式感；
8. **清盘 / 过关**：全盘灯管依次点亮对应的上行音阶（每点亮一段升一个音级）+ 结尾一个明亮大三和弦 + 翻转计分牌的机械 flip 声。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，**零文字**；
- **主体构图**：单一居中主体占 64%~70%——一枚**柠檬黄软胶质感的吃豆人**（圆润饱满、嘴向右张开、表面平涂无渐变、上下倒角 + 深投影做出软胶厚度），嘴的正前方飘着一颗将落未落的小豆，身后留一道极短的暖黄拖影；

- **★ 色相纪律（2026-09-28 全站 59 张封面 cv2 HSV 圆形均值实测结论）**：
  - **主体锁 55°–62° 柠檬黄**（实测空白区：上游 `mow` 42.8 / `winmine` 48.6 / `pinball` 52.9，下游 `snake-orchard` 73.0）
