## 1 · 创意概念与核心乐趣

- **游戏名称**：魔塔 50 层 / 50-Floor Magic Tower / 建议 slug：`mtower`（备选 `tower50`）
- **一句话玩法**：零随机经典固定数值算步 RPG：严密规划每一把钥匙、每一颗宝石与攻防临界值，无伤清怪、收集神装、直抵 50 层击破魔王！
- **核心乐趣与卖点**：
  - **殿堂级硬核数值解谜（Peak Deterministic Logic RPG）**：
    没有概率暴击、没有未命中闪避、没有刷怪练级。怪物的血量、攻防、金币与经验完全公开透明。每一个数值提升都是精密的解谜钥匙——“先加 4 点防御把石头人战损压到 0，还是先提 8 点攻击少挨吸血鬼一刀？”玩家凭借极致的步数计算与资源调度，体验多省 1 点血即可盘活全局的顶级智力心流；
  - **经典 50 层五大区域巅峰格局（5 大 Zone 渐进式史诗感）**：
    从 1~10F 铁剑铁盾新手区、11~20F 银剑银盾中阶区、21~30F 骑士剑盾高阶区、31~40F 圣剑圣盾宗师区，到 41~50F 挑战远古魔龙、大法师与真魔王的决战区。圣水翻倍血量、十字架全属性增幅、地震卷轴破壁、暗道下行电梯，神兵法宝环环相扣；
  - **现代 Web 时代的绝妙体验重构（彻底终结老版废档噩梦）**：
    保留纯粹硬核数值内核，全面赋能现代人机工程学：
    1. **悬停战损与攻防临界值智能解析（Smart Damage & Threshold Hover）**：光标移至怪物上方不仅显示确切战损，更直接贴心提示“防御再+X可降战损至0”、“攻击再+Y可减少1回合”；
    2. **无限撤销与楼层时光锚点（Infinite Undo & Floor Tree）**：支持【Z】键无限步回溯，每层踏入初始瞬间自动存档，关键节点秒回退，告别一走错即浪费数小时的远古挫败；
    3. **全塔资源透视小地图（Global Resource Radar）**：已探索楼层的残留钥匙、血瓶与宝石一目了然，结合瞬时飞行器自由上下楼，杜绝枯燥无意义跑图；
  - **填补平台硬核数值 RPG 空白**：
    作为兼具童年白月光情怀与顶级复玩性的硬核神作，是硬核玩家反复刷榜、追求“最高通关剩余血量”的最佳载体。
- **核心循环**：
  ```
  巡视当前楼层怪物与资源分布 → 悬停查阅战损与临界攻防加点收益
       ↑                                                      ↓
  踏上楼梯挺进更高区域 / 决战魔王 ← 击杀 Boss 获得专属神装/法宝 ← 收集红蓝宝石、血瓶与三色钥匙
       ↓ (加点路线失误导致战损过高/卡死)
  随时一键【Z】撤销 / 回退楼层快照，重组最优路线，无损破局
  ```

**我们要继承的核心机制**：
1. **经典绝对确定性伤害公式**：
   - 勇者每击伤害：$D_{hero} = \max(1, \text{HeroAtk} - \text{MonsterDef})$（若 $\text{HeroAtk} \le \text{MonsterDef}$ 则无法破防，禁止战斗）；
   - 怪物每击伤害：$D_{mon} = \max(0, \text{MonsterAtk} - \text{HeroDef})$；
   - 击杀总回合数：$Turns = \lceil \text{MonsterHp} / D_{hero} \rceil$；
   - 勇者承受总战损：$\text{TotalDamage} = (Turns - 1) \times D_{mon}$（勇者先攻，一击必杀则 0 战损）；
   - 特殊怪物机制：先攻怪（怪物先打一击）、吸血怪（开战前按勇者当前生命固定比例抽血）、坚固怪（防御力极高）；
2. **全套经典法宝与特殊机制**：
   - **圣水（Holy Water）**：使用后勇者当前生命值直接 $\times 2$（极其考验玩家何时喝收益最大）；
   - **神圣十字架（Holy Cross）**：拾取后勇者基础生命、攻击、防御永久提升 1/3；
   - **屠龙匕首（Dragon Slayer）**：对巨龙造成 2 倍绝对伤害；
   - **地震卷轴（Earthquake Scroll）**：瞬间震碎当前楼层的所有普通石墙；
   - **破墙镐（Pickaxe）**：凿穿任意一堵石墙；
   - **上下楼飞行器（Wings）**：在已探索楼层间瞬间穿梭。

**本作的差异化微创新（拒绝无聊照搬与机械折磨）**：
1. **临界值悬停算盘（Critical Threshold Overlay）**：
   - 鼠标悬停在怪物上方，不仅显示扣血点数，更显示一行直观的数学推演小字：
     - *“攻 +4 ➔ 击杀少 1 回合，省 160 HP”*；
     - *“防 +2 ➔ 怪物破防降为 0，零伤秒杀”*；
     - 彻底解脱玩家拿出实体计算器狂按的机械痛苦，让纯逻辑决策变得无比丝滑优雅；
2. **无限撤销与时光树（Infinite Undo & Time Anchors）**：
   - 支持【Z】键无限步回撤，自动记录“初入楼层快照”与“Boss战前自动快照”，玩家可随时在左侧楼层树上跳回历史节点重新规划，试错零代价；
3. **黑曜石微缩地牢机台美学（Obsidian Diorama Arcade）**：
   - 11×11 经典地牢网格，搭配动态火把光影与细腻的 2.5D 微浮雕石板，左侧展开牛皮纸勇者属性轴与法宝袋，右侧展开全楼层魔物图鉴与临界值算盘。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与楼层架构**：
  - **11 × 11 经典地牢网格**：每层正方舞台，包含石墙、黄/蓝/红门、铁门、暗墙、楼梯、宝石、血瓶、法宝与魔物；
  - **经典 50 层五大区域划分（Zone 1 ~ Zone 5）**：
    - **第一区（1~10F · 幽暗地牢）**：绿/红/黑史莱姆、骷髅、小蝙蝠；获取铁剑（+10攻）与铁盾（+10防），解救小偷；10F 决战骷髅队长；
    - **第二区（11~20F · 坚石回廊）**：兽人、大蝙蝠、初中级法师、金卫士；获取银剑（+20攻）与银盾（+20防）；20F 迎击吸血鬼假头目；
    - **第三区（21~30F · 钢铁要塞）**：双手剑士、高级巫师、近卫骑士；获取骑士剑（+40攻）与骑士盾（+40防）；开启中枢金币商店加点；
    - **第四区（31~40F · 熔岩深渊）**：红衣大法师、幽灵骑士、炎魔；寻获圣剑（+80攻）与圣盾（+80防），获取神圣十字架与屠龙匕首；
    - **第五区（41~50F · 魔塔之巅）**：决战魔龙、挑战假魔王；寻回神圣之剑与神圣之盾；49F 封印假魔王，揭晓暗黑地下隐藏层，50F 迎战真·终极魔王！
- **玩家合法操作**：
  1. **移动走位**：
     - 方向键【↑ ↓ ← →】或【W A S D】，触屏轻按或拖拽；
     - 支持**点击空地自动寻路（A* 智能寻路）**，快速走过已清理区域；
  2. **交互与撞击战斗**：
     - 撞击同色门：若有钥匙自动扣除 1 把并开启；若无钥匙发出顿挫拒止声；
     - 撞击宝物/宝石/药水：立即拾取，属性即时增加并弹出浮动数字（例：`ATK +3`、`HP +200`）；
     - 撞击怪物：进行战损判定。若当前生命值足以击杀怪物，瞬时完成战斗（播放 0.12s 兵刃斩击火花动画与音效），扣除对应战损，勇者占领怪物格子，收割金币与经验；若无法击杀，发出警告蜂鸣，勇者停在原位，杜绝误触暴毙；
  3. **时光回溯（Undo & Rewind）**：
     - 按键【Z】或点击界面“撤销”：无限制连续单步回退；
     - 点击右翼“楼层快照”：随时跳回本层或上一层的初入瞬间；
  4. **楼层瞬移（Wings）**：
     - 拾取飞行羽毛后，可在已探索楼层间无缝跳跃切换。
- **胜利与失败条件**：
  - **胜利（Victory）**：踏上 50 层魔塔神殿，击败真·终极魔王，解开魔塔千年封印，救出公主！
  - **失败（Game Over）**：在无路可走且生命值不足以击杀任何阻挡通路的怪物、且所有存留资源已消耗完毕（理论死锁）。玩家可随时利用楼层快照或单步撤销调整路线。
- **数学可解性与 100% 确定性保证**：
  - 关卡地图、怪物数值、钥匙投放、攻防临界点完全基于 50 层魔塔经典数学模型构建，严禁任何随机掉落与概率暴击；
  - 存在明确的官方理论最优通关路线与极限通关血量纪录。

### 操作与手感细节

- **全端极速响应**：
  - **桌面端**：WASD / 方向键丝滑连续移动（带 100ms 输入缓冲防粘滞）；鼠标单击任意地块自动寻路；
  - **移动端**：屏幕下半部预留虚拟十字微浮雕按键，支持触屏直点地块。
- **视听爽感与打击反馈**：
  - 拾取红宝石（攻击上升）：清脆激昂的“锵！”金属升调音效；
  - 拾取蓝宝石（防御上升）：沉稳坚固的“嗡”重盾音效；
  - 拾取圣水：空灵的圣泉涌动与回响声；
  - 斩杀小怪：干脆利落的刀剑切入微音效；
  - 决战 Boss：激昂经典的复古 8-bit / 16-bit FM 合成器战斗乐。

### 关卡模式编排

1. **经典 50 层通天战役（Classic 50 Floors · 核心史诗）**：
   - 完整的 1~50 层无删减原汁原味推演，包含地下隐藏 1~3 层与真假魔王多结局；
   - 通关后根据通关剩余生命值、通关步数与耗时授予“魔塔段位”（从【地牢卫兵】到【封神剑圣】）；
2. **凝练精选 25 层速通赛制（5/5/5/4/5 · 节奏精编版）**：
   - 针对现代 Web 玩家 20~30 分钟一局的诉求，将 50 层中最精华的攻防抉择浓缩为 25 层快节奏算步局，五区各 5 层（第 4 区 4 层 + 终章 5 层），数值模型独立重构，短小精悍。

## 4 · 美术风格与视觉氛围（黑曜石地牢机台，拒绝网页仪表盘）

- **题材与视觉关键词**：**经典怀旧 · 黑曜石机台 · 羊皮纸属性轴 · 罗马钟表微光 · 细腻像素重绘**
  （不做单调惨白的白底网页，不做粗糙拉伸的简陋平铺；呈现为置身于一台高分辨率复古暗黑地牢掌机前的把玩感）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（11×11 Dungeon Arena）**：
    - 正中嵌在玄武岩暗青色机台中的 11×11 地牢，地砖带有温润的古旧石质纹理；
    - 场景四周墙体带有柔和阴影，火把释放出温暖的橙红微光；
    - 顶框内嵌精雕合金铭牌：收纳【返回首页】、【无限撤销】、【怪物手册】、【音效】与【语言】；
  - **左侧状态翼栏（HUD Left Wing · 勇者行囊）**：
    - 牛皮纸卷轴展示：
      - 当前楼层刻度（例：`50F · 魔塔之巅`）；
      - 生命值条（红槽大字显示）、攻击力、防御力、金币袋；
      - 黄/蓝/红三色钥匙槽与持有数量；
      - 特殊法宝格（十字架、圣水、屠龙剑、破墙镐、飞行羽毛）；
  - **右侧情报翼栏（HUD Right Wing · 魔物雷达与临界值算盘）**：
    - 实时罗列当前楼层出现的怪物图鉴；
    - 核心杀手锏：**悬停实时战损与临界攻防小算盘**（直接显示加多少攻防可跨越下个质变点）；
    - 楼层时光树：已走过的楼层快照一键跳转；
  - **移动端适配**：
    - 左右翼核心数值收缩为舞台上方一体化悬挂铜牌，下方设置紧凑的虚拟十字键与撤销/手册辅助功能。

- **色彩与材质**：
  - **背景机台**：深邃玄武岩 `#13161c → #0d0f14` 渐变；
  - **地牢石砖**：沉稳深灰 `#2b303c` 搭配青苔与石纹；
  - **道具高亮**：红宝石 `#ff4757`、蓝宝石 `#2ed573`、黄钥匙 `#ffa502`、圣水 `#70a1ff`；
  - **动效降级**：在 `prefers-reduced-motion` 开启时，火把光斑静止，人物与战斗采用瞬间切帧。

- **封面设计提案（assets/covers/mtower.webp）**：
