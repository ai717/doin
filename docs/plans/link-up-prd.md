# 《连连看》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

## 1・创意概念与核心乐趣



* **游戏名称**：连连看 / Link Link / 建议 slug：`link-up`（候选 `pair-path`、`lianliankan`）

* **一句话玩法**：点击两个相同图案，用最多拐两个弯的通路把它们连起来消除，清空整盘。

* **核心乐趣与卖点**：


  * **顿悟感**：一眼锁定配对、看穿 "出界绕行" 路径的那一刻，是连连看独有的 "我懂了" 快感；

  * **解压的秩序感**：杂乱的盘面被一条条流光路径理清，像收拾房间一样越玩越清爽；

  * **手感丝滑的连线动画**：消除不是 "啪一下消失"，而是 "金色路径画出→两端点亮→图案飞散成粒子" 的仪式感 ——**连线本身即美学**。

* **核心循环**：



```
观察盘面 → 锁定一对 → 点击选中（高亮）→ 点击匹配（合法？路径动画+消除）

&#x20;   ↑\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_↓

卡壳？→ 提示道具点亮一对 / 洗牌重排 → 继续配对 → 清盘 = 过关
```

**我们要借鉴什么**：出界绕行的经典规则、Onet 的关卡递进节奏、Monster Duo 的消除特效仪式感、麻将牌的 "符号一眼可辨"。

**我们的差异化微创新**：



1. **中国民俗吉祥题材**（红双喜 / 铜钱 / 锦鲤 / 灯笼 / 福字 / 祥云 / 剪纸生肖）——web 端配对消除全是欧美萌宠、食物、万圣节，民俗符号墙在同类里独一份，还自带 "喜庆解压" 情绪；

2. **异形棋盘关卡**：不只是矩形，中后期出现去角、缺洞、心形 / 葫芦形棋盘 —— 改变 "哪些对能连" 的地形逻辑，制造新顿悟；

3. **连线路径即美学**：金色流光描出折线路径再消除，把 "路径不能被阻挡" 这个规则直接变成视觉表演；

4. **每日挑战（同日同题）**：DOIN 生态特色，每天一张固定布局，全球同题比步数。

**品类排重**：现有 15 款无配对消除类。与 one-line（一笔画，路径覆盖全盘）目标不同；与 Tile-Matching（三消交换）操作不同；填补 "配对 + 路径规划" 的轻中度益智空白，且是唯一 "民俗年味" 题材。

## 3・玩法规则与交互说明

### 核心规则



* **盘面构成**：


  * 关卡制棋盘：从 6×6 到 10×8 递进；中后期出现**异形棋盘**（去角、缺口、对称异形）；

  * 图案：每关 4–12 种民俗符号，每种符号恰好 2 块（部分进阶关 4 块同图，制造 "四连" 变体）；

  * 初始状态：符号随机铺满全部格子，保证每种偶数个。

* **玩家合法操作**：

1. 点击一个符号 → 高亮选中；

2. 点击另一个符号 → 判定：① 图案相同；② 二者之间可用**水平 / 垂直线段**连接，**拐点 ≤ 2**（即最多 3 段直线）；③ 路径经过的所有格子必须为空（两个端点除外）；④ **允许路径从棋盘外侧绕行**（经典特性）；

3. 判定通过 → 金色路径动画 → 两符号消除；判定失败 → 选中切换 / 轻微抖动，绝不吞操作。

* **胜利与失败条件**：


  * **胜利**：清空棋盘（唯一通关态）；

  * **失败**：无硬性失败 —— 时间宽松，卡壳靠洗牌，本作设计为 "只赢不输" 的放松体验（每日挑战为冲分有倒计时，超时结算当前分）。

* **容错与无死局说明（杜绝死胡同）**：


  * **生成保证**：关卡采用 "反向构建"—— 从空盘开始逐对回填，每回填一对都确保 "当前局面下这对可连通"，因此生成出的局面**必然存在一条完整消除序列，100% 可解**；

  * **运行时兜底**：若场上确实找不到任何可消除对（极端盘面），自动提示并允许**洗牌**（重排后仍按可解原则生成），配**提示道具**点亮一对可消除项，玩家永远不会被卡死。

### 操作与手感



* **鼠标**：左键点选 → 左键点第二块；悬停符号轻微浮起提示可点。

* **触屏**：轻点选第一块 → 轻点第二块；选中块放大 + 呼吸光效。

* **键盘**：方向键移动焦点 + 回车确认（桌面玩家加分项）。

* **误触容错**：点错已消除格无反应；点已选中块 = 取消选中；连点过快有 80ms 输入缓冲防吞。

### 模式与内容递进



* **首选模式：关卡制 50 关（5 章 × 10 关）+ 每日挑战**。

* 难度递进（波浪式，章内起伏、整体上升）：


  * **第 1 章「初识」**：6×6，4 种符号 —— 教学，路径基本直线 / 单拐；

  * **第 2 章「绕行」**：7×7，6 种 —— 引入出界绕行，玩家第一次发现 "能从外面绕" 的惊喜；

  * **第 3 章「地形」**：8×8，8 种 —— 引入去角异形棋盘；

  * **第 4 章「四连」**：9×8，10 种 —— 同图 4 块变体，连锁感增强；

  * **第 5 章「大师」**：10×8，12 种 + 缺口地形 —— 布局密度与路径规划巅峰。

* **每日挑战**：同日期同题（固定种子生成一张中高难度布局），通关额外奖励，冲 "最少步数 / 最快时间" 双榜（本机）。

### 目标与评价



* **计分维度**（建议口径，供开发校准）：


  * `单关得分 = 基础分 + 连击加成 + 时间分`；

  * 基础分随关卡递增（第 1 关 200 起，逐章 +40 左右）；

  * **连击**：不洗牌、不超时地连续消除，形成 combo 链，第 2 连起每连 +10 递增 —— 鼓励 "规划一串消除" 而不是见一对点一对；

  * 时间分：宽松满分时长（随棋盘变大而放宽），提前完成有奖、超时保底，**绝不制造倒计时焦虑**；

  * 满分参照：单关满分 800（对齐门户惯例），选关页显示历史最高分。

* **评价体系**：通关弹窗 "得分 X/800 + 步数 + 最长连击 + 🏆 新高分"；无星级，简洁明快。

## 4・美术风格与视觉氛围



* **题材与视觉关键词**：**民俗年味・暖木牌桌・喜庆绯红・金色流光・剪纸质感**

  （不做欧美萌宠、不做麻将牌实拍、不做赛博霓虹 —— 与站内现有题材全部拉开。）

* **桌面端沉浸游戏舞台设计（≥900px）**：


  * **左主舞台**：棋盘置于暖木纹理面板中央，符号为绯红 / 金 / 藏青配色的民俗剪纸造型，格线是淡淡的木纹接缝；

  * **右侧信息操作栏（牌匾式 HUD）**：


    * 顶部 "关卡匾额"：本章名 + 第 X/50 关，朱红匾额 + 金色描边；

    * 中部 "计分牌卡"：得分 / 步数 / 连击 ×N，胶囊徽章化，数值变化带 bump 跳字；

    * 底部 "工具台"：提示、洗牌两枚实体质感按钮（悬停微浮起、点击物理下沉）；

  * 移动端（≤768px）：单列紧凑，棋盘自适应屏宽，按钮横排底栏。

* **色彩与环境氛围**：


  * 主色：暖棕古木底 `#8A5A3B` 系 + 绯红 `#D94F4F` 图案 + 金色 `#E8B64C` 连线流光；

  * 背景：暖棕环境光晕缓慢 drift + 细噪点布纹，仿 "午后木桌上一局牌" 的沉浸感，拒绝白灰死板底；

  * 关键动效：


    * **选中**：符号浮起 + 呼吸金光；

    * **连线**：金色流光从 A 画到 B（拐点处微微转弧），路径上撒细小金星；

    * **消除**：图案化作绯红 / 金色粒子飞散 + 一声轻快的 "叮咚"；

    * **通关**：全盘粒子汇聚成一颗红灯笼升起的仪式感动效；

  * 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

* **封面设计提案**：


  * 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字；

  * **主体物件**：一块被金色折线路径连接的一对 "红双喜 / 铜钱" 软胶方块（视为一个整体组合）；

  * **背景色相**：**绯红系**（未被占用；暖棕 / 古铜作备选），与 "年味" 主题天然契合，且与现有 15 张封面不撞色。

## 5・制作人拍板与开放探讨



1. **视觉题材**：

* A. **民俗年味**（红双喜 / 铜钱 / 锦鲤 / 剪纸，暖木 + 绯红，默认推荐 —— 辨识度最高、站内唯一）；

* B. **明黄阳光乐园**（柠檬 / 太阳 / 汽水符号，现代明快，撞 Tile-Matching 糖果区风险）；

* C. 其他题材（可提出：萌宠、美食、星空…）。

1. **节奏与压力**：

* A. **宽松放松流**（关卡制不设倒计时，只计步数 + 连击，卡壳靠洗牌 ——"只赢不输"，默认推荐，契合解压定位）；

* B. **经典限时流**（每关有倒计时，超时结算，更刺激但制造焦虑）；

* C. 混合（关卡制放松 + 每日挑战限时冲分）。

1. **特殊变体（v1.1 或首发选一）**：

* A. 纯经典，做深手感（默认推荐首发）；

* B. 引入 "连锁"：一次消除若又自然露出一对已连通组合，自动连消 + 高分（网易验证过的好玩法）；

* C. 引入 "四连块"：同图 4 块，需两两消除。
