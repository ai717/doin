## 1 · 创意概念与核心乐趣

- **游戏名称**：深海吞噬 / **Deep Devour** / 建议 slug：`deep-devour`
  - 备选 slug：`abyss-feed`、`reef-devour`、`chomp-sea`（**不要**用 `fish-frenzy`，与 Feeding Frenzy 商标过近）
- **一句话玩法**：吃掉比你小的，躲开比你大的，一口一口长成海里的霸主。
- **核心乐趣与卖点**：
  - **反转的复仇快感**：上一秒追着你跑的凶鱼，三分钟后是你的点心。这一句就是整个品类的灵魂，必须做透。
  - **"再吃一条就升级"的贴身张力**：成长条永远差一点点，而屏幕上正好有三条小鱼，后面跟着一张大嘴。
  - **鱼群同行的陪伴感**（本作核心微创新）：攒够三条同种小鱼，它们就跟你走，替你挡一次大鱼的嘴。收集 + 护盾 + 视觉排面，三合一。
  - **狂暴连锁的节奏爆发**：连续吞食触发倍率狂潮，屏幕转烫、音乐升调、数字狂跳——把"吃"这件事做出打击感。
  - **被吃也不摔手柄**：被吃掉扣一心、退一阶体型、无敌两秒，立刻能翻身，不做"重开一整关"的挫败。
- **核心循环**：观察食物链 ➔ 游动走位 ➔ 吞食小鱼涨成长条 ➔ 体型升级解锁新猎物 ➔ 攒鱼群 / 追狂暴 ➔ 达成关卡目标 ➔ 下一片海域新机制。

## 2 · 经典标杆与对标参考

| 对标 | 借鉴点（具体抄什么） | 避坑点（具体不做什么） |
|---|---|---|
| **PopCap / Sprout《Feeding Frenzy》**（2004 首秀，2006 PC/Xbox） | ① 鼠标跟随式游动，零学习成本；② 精确体型等级食物链（原作用 size 1–20 分 7 阶）；③ **狂暴连锁**：短时连续吞食触发 Frenzy → Double Frenzy 提升得分倍率；④ 增益泡泡体系（闪电 / 眩晕 / 双倍 / 加命 / 珍珠成长）；⑤ 危险物体系（水雷、水母、毒鱼、河豚、贝壳）；⑥ 章节海域 + 最终 Boss。 | ⛔ 原作的致命伤是**重复**：IGN 6.6/10、Eurogamer 3/10 都直指"机制太浅、每关只是同一件事"、TeamXbox 说"更适合小孩"。**我们必须让每一片海域带来新规则**，而不只是换背景。⛔ 不做"右键吸水"（原作狮子鱼之后才有的鸡肋能力，手感争议大）。⛔ 不做摄像头操作。 |
| **Poki《Fish Eat Fish》**（Indiesoft Games，web 热门） | ① **头顶标数值**的极简可食判定——"我的数 > 你的数就能吃"，一眼看懂；② 难度由关卡曲线自然上升。 | ⛔ 它是**本地 3 人同屏**（WASD / 方向键 / 鼠标），我们是单人。⛔ 不采用"无上限成长"——那会摧毁"体型分级"的策略意义。 |
| **《Piranha Feeding》**（Funcraft Games，2024 Steam 抢先体验） | ① **鱼群同伴**概念：领队鱼带着鱼群一起捕食，这是"吃"之外的第二层乐趣来源；② 一轮一轮的"进食回合"节奏。 | ⛔ 不做 roguelite 能力构筑（体量与平台不符）。⛔ 不做 4 键操作（我们要更少按键、更直觉的游动）。 |
| **《Hungry Shark》系列**（移动端） | ① 连续吞食的爽快节奏编排；② 体型成长带来的"地图解锁"感。 | ⛔ 不做血腥夸张的表现（撕咬、血雾）；⛔ 不做写实 3A 渲染，与门户软胶玩具风割裂。 |
| **本作定位** | 在 20 年前那个"机制很浅"的经典骨架上，补上**逐章递进的新机制**、**鱼群同伴**与**容错友好的受击设计**——把一个"童年回忆"做成"真的耐玩"。 | — |

- **成熟标杆原型**：2004 年 Sprout Games 开发、PopCap 发行的《Feeding Frenzy》（中文俗名即"大鱼吃小鱼/吞食鱼"）——玩家操控小鱼吞食更小的海洋生物成长，躲避大鱼与危险物，横跨 5 片海域共 40 关，最终用虎鲸挑战大白鲨"鲨鱼王"。
- **最受玩家认可的核心手感**：
  - 游动跟手、吞食判定宽容——"擦边就算吃到"比"严丝合缝"更爽。
  - 成长是**连续可见的**：鱼真的在变大，而不是换个数字。
  - **狂暴连锁**是同类里最成功的正反馈设计——它把"吃"从动作变成节奏游戏。
  - 加命、加速、格挡这类增益泡泡，提供了短时的"无敌期"作为情绪释放阀。
- **我们要继承的成熟机制**：鼠标/手指跟随游动；精确体型分级与可食提示；狂暴连锁（Frenzy → 双重狂暴）；增益泡泡；危险生物体系；五海域分章推进；体型成长 + 章节解锁。
- **本作的独特魅力与微创新**：
  1. **鱼群同行（Shoal）**——攒够三条同种小鱼即结成随行鱼群，最多三尾，替你挡一次掠食者的嘴，也会帮你自动吞掉更小的猎物。把"吃"变成"收编"。
  2. **逐章解锁新规则**——不是加怪换皮，而是每片海域引入一条全新的玩法规则（见 §3 编排表）。
  3. **受击宽容设计**——被吃 = 扣心 + 退一阶 + 2 秒无敌，永不复位整关。这是对原作"太浅/太苛刻"两点差评的直接回应。
  4. **潜水舱舷窗舞台**——用黄铜舷窗 + 潜水仪表把 HUD 全部焊进框体，彻底告别网页仪表盘。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**场景构成**
- 2D 侧视海域舞台，重力无关，全向游动；海域有上下边界（水面 / 海床）。
- 物件：玩家鱼（唯一操控对象）、可食小鱼（多鱼种）、掠食者（大鱼）、危险物（水母 / 海胆 / 水雷 / 渔网）、增益泡泡、随行鱼群。
- 鱼的真实尺寸决定可食关系，**不看颜色看大小**。

**体型与食物链（唯一判定权威）**
- 全海域共 **7 阶体型**（T1 最小 → T7 霸主），玩家每关从指定阶起手。
- 每条鱼带一个体型阶 `tier`。规则一句话：**`tier(猎物) < tier(玩家)` 可吃；`tier(猎物) > tier(玩家)` 被吃；同级互不相犯**。
- 可食提示（必须做，否则玩家瞎猜）：**可食目标描一圈暖绿微光**；**危险目标描一圈珊瑚红警示纹**；同级目标无标记。玩家自己的鱼永远有一条高亮轮廓。
- 成长条：吞食可食目标累积成长值，满条 → 体型 +1 阶，**伴随一次可见的膨胀动画与音效升调**。阶数越高，升级所需成长值越多。

**玩家合法操作**
- 鼠标：鱼朝指针方向持续游动（有转向惯性，不是瞬移贴指针）。
- 触屏：手指按住拖动，鱼追手指；松手鱼减速漂移。
- 键盘：`↑↓←→` / `WASD` 八向直接操控，`空格` 冲刺。
- 冲刺：短时加速（约 0.5 秒），消耗"气泡能量"，能量自动回充。用于抢食、逃命、撞破渔网。
- 暂停 / 重开：`P` / `R`。移动端为舷窗上两颗实体按钮。

**胜负判定**
- **胜**：达成该关目标（多为"成长到指定体型"，也可以是"限时内吃够 N 条"/"河床清场"/"击败掠食者"），立即结算。
- **负**：心数归零，或被吃次数超过容错上限。
- **被吃掉不是终局**：扣 1 心 + 体型回退一阶（不低于本关起始阶）+ 2 秒无敌闪烁 + 原位短暂硬直抵抗。**禁止复位整关**。

**容错 / 手感细节**
- 吞食判定半径略大于视觉鱼嘴（约 1.15 倍），"擦边算吃到"。
- 转向有惯性上限，**保留"重"的感觉**——这是危险的来源，也是操作技巧的空间。
- 输入缓冲：冲刺指令在落地前 150ms 内登记，连招不丢键。
- 靠近掠食者时有**轻微时间减速 + 暗角收缩**（危险感知），不改变物理。

**数学可解性与"成长可达性"保证**（本作无解密要素，核心保证是"目标一定可达"）
1. **开局保护**：出生点半径内 3 秒不生成高于玩家阶的目标；开局 2 秒无敌。
2. **可食目标下限**：场上任意时刻保证 ≥ 6 条可食目标；低于阈值立即从屏幕边缘补刷（不在玩家正前方 1 个体长内刷大鱼）。
3. **成长曲线可验证**：每关目标体型必须在时限内可达——开发期需用贪心 AI 自动跑 **≥1000 次/关**，达成率 ≥ 95% 才准上线；不达标就调刷新率或放宽时限。
4. **确定性与可测**：所有随机采用可注入种子 PRNG（`mulberry32`），测试可复现；另需 ≥1000 步随机游走测试，验证状态机在任意合法操作序列下不抛错、不卡死。
5. **无不可能三角**：不允许出现"场上只剩比你大的鱼且永不补刷"的死局状态——补刷规则从机制上排除了它。

### 3.2 逐章解锁的新规则（拒绝换皮式重复）

- **① 珊瑚浅滩**：基础课。只教三件事——游动跟手、吃小鱼长大、躲开大鱼。无危险物。
- **② 海藻密林**：引入**狂暴连锁**与**毒鱼**。海藻丛遮蔽视野（可穿行但看不见内部），毒鱼吃了短暂左右反向。
- **③ 水母迷阵**：引入**鱼群同行**与**麻痹系危险物**。水母、海胆首次登场；攒鱼群成为主要策略。
- **④ 沉船海沟**：引入**深渊压强**与**换气**。海域分浅/中/深三带，越深猎物成长值越高（×1.5 / ×2），但压强条上涨；压强满则持续掉成长值并减速，必须回浅层换气。沉船残骸里藏着宝箱（开出增益泡泡）与渔网（缠住扣心）。
- **⑤ 深渊王座**：引入**掠食者反转关**。部分关卡开局你就是这一片的顶级猎手，但场上有更快、会协同包抄的精英掠食者，需要在限定时间内清场或咬退它们的尾巴（咬尾 3 次使其降阶，参考原作梭鱼机制）；章末为 **Boss 交锋**。

### 3.3 危险物与增益物

| 类别 | 物件 | 效果 |
|---|---|---|
| 危险 | 掠食者（鲨鱼 / 虎鲸 / 梭鱼 / 巨型石斑） | 被你吃 → 扣心、退阶、无敌 2 秒 |
| 危险 | 水母 | 碰到麻痹 1.5 秒，不可食用，可绕行 |
| 危险 | 海胆 / 珊瑚尖刺 | 碰到扣心，静止障碍，可逼停走位 |
| 危险 | 水雷 | 缓慢上浮，碰到扣心，冲刺可撞爆（有短冷却） |
| 危险 | 毒鱼（绿纹） | 吃了短暂左右方向反向 2 秒 |
| 危险 | 渔网（沉船章） | 缠住减速，挣扎脱身或冲刺撞破 |
| 增益 | 珍珠 | 直接补一大段成长值 |
| 增益 | 闪电泡泡 | 5 秒内冲刺无冷却 |
| 增益 | 狂暴泡泡 | 立即点燃狂暴连锁 |
| 增益 | 鱼群泡泡 | 立即获得 3 尾随行鱼 |
| 增益 | 心 | +1 心（稀有，海域末关必出） |

### 3.4 狂暴连锁（本作节奏核心）

- 吞食后 **1.2 秒内**再吞食则连击延续；累计 **5 连**点燃 **狂暴**：得分倍率 ×2、游速上限微增、背景转暖、音乐加一层。
- 狂暴中继续不断链，达到 **12 连**升级为 **双重狂暴**：倍率 ×3、屏幕上缘出现"吞噬狂热"横幅（参考原作 FRENZY 的屏幕字符表现）。
- **2 秒**不吞食则狂暴衰减归零。**刻意做成易点燃、易断**——这是玩家主动追节奏的动力。

### 3.5 模式与内容编排（依玩法特质定制，不套"无尽+每日"三件套）

**主线：5 片海域 × 8 关 = 40 关**（首发体量）
- 每片海域第 1 关为新机制教学关（无失败、纯引导），第 8 关为海域压力关。
- 每片海域章末（第 8 关）为该海域的难度峰值关。
- **海域解锁**：累计珍珠数达标即解锁下一片海域（建议第 2 片起，每片门槛约为上一片满额珍珠的 50%）。

**深渊模式（无尽下潜）**：通关第 2 片海域后解锁。
- 单局无尽：一直往下游，越深鱼越大越多，成长值越肥，屏幕越暗，逐渐只剩自己的一束探照光。
- 记录两项成绩：**最深米数** 与 **最高分**。这是本作唯一的"冲分"模式，因为"越深越强"的成长幻想天然适合无限延伸。

**掠食者试炼（限时 Boss 挑战）**：通关第 5 片海域后解锁。
- 8 场一对一的精英掠食者对决，限时内咬退对方或存活到底。纯技巧检验。

> 本作**不做**"每日挑战"——成长类动作游戏的乐趣来自稳定可控的节奏，随每日变盘会打断肌肉记忆，得不偿失。

### 3.6 游戏目标与反馈体系

- **核心指标（不是总分）**：
  - 主线每关 **三颗珍珠评级（0–3）**：
    1. 通关（达成关卡目标）；
    2. 全程未被吃掉（0 次被吃）；
    3. 达成隐藏效率目标（限时关看用时 / 生存关看点数 / 其余看是否拉满狂暴或满编鱼群）。
  - 每个海域显示 **珍珠进度 x/24**；全站总计 x/120。
  - 深渊模式：**最深米数 + 最高分**，本机保存。
- **仪式反馈**：
  - 升级：鱼身膨胀一圈 + 白光环扩散 + 音调上扬三度。
  - 狂暴点燃：屏幕边缘暖色脉冲 + 数字放大跳动。
  - 攒满鱼群：三条小鱼"唰"地入列到身后，排队形。
  - 通关：舷窗内海水转亮、珊瑚摆动、三颗珍珠依次落盘。
  - 被吃：短暂黑屏一圈 + 心形碎裂，立刻重生（不打断节奏）。
- **沉浸式双语**：全站 i18n（`doin.lang`），中文 / English 双语文案严格对齐。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：明亮珊瑚礁、软胶玩具鱼、黄铜潜水舷窗、光柱与气泡、纸雕海浪。
- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**：
  - **整屏是一扇巨大的黄铜潜水舷窗**：游戏海域就是舷窗外的那片珊瑚礁。舷窗的铜框就是天然舞台边框。
  - **禁止四角浮动按钮**：返回首页、静音、语言、暂停、重开，全部收进舷窗**顶部一条窄黄铜状态条**（上面刻着海域名与关号）。
  - **禁止右侧 SaaS 卡片堆**：所有 HUD 直接焊进舷窗框——
    - 框左上方：**深度计**（指示当前海域/关卡）；
    - 框右上方：**心数仪表**（三颗贝壳）；
    - 框底部正中：**狂暴倍率表**（一个会随连击转动的铜制罗盘）与**成长条**（一条发光的玻璃管）。
  - **桌面端（≥900px）**：舷窗居中（宽度上限约 1100px），两侧是深海水色虚化 + 缓慢摆动的光柱 + 漂浮气泡与浮游生物，形成景深。左右边缘与底部边缘**不放置任何操作按钮**，为未来侧栏 / 通栏留白。
  - **移动端（≤768px）**：舷窗竖向撑满宽度，铜框变窄，仪表压缩为顶部一条；主容器底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，绝不让任何按钮贴底。
- **色彩与环境氛围**：
  - 主色：**珊瑚橙 + 蜜黄 + 青绿海水**；深水区过渡到宝蓝，但**绝不做全屏暗蓝**（会与深海合珠 / 合成泡泡撞色，且丢失明亮基调）。
  - 水域做**上下三段式渐变**（浅青绿 → 中碧蓝 → 深宝蓝），配合顶部斜射光柱与缓慢上浮的气泡串。
  - 玩家鱼：暖橙金带白肚，永远最亮、永远有高光轮廓，在深水里也一眼可辨。
  - 可食目标描暖绿微光、危险目标描珊瑚红警示纹——这是核心可读性设计，不是装饰。
  - 按钮质感：黄铜实体微浮雕，悬停上浮 `translateY(-2px)`、按下扎实下沉 `translateY(2px)`，配清脆合成"咔哒"声。
  - 动效统一在 `prefers-reduced-motion: reduce` 下瞬移降级。
- **封面设计提案**（遵循 `docs/COVER-STYLE.md`）：
  - 3D 软胶，单一居中主体：**一条圆滚滚的橙金条纹小鱼，张着圆嘴，正要把一颗发光的小鱼/珍珠吞下去**；周围三两枚气泡与一粒小海星陪衬。
  - 背景：**珊瑚橙红 → 暖粉**对角渐变（属未占用色相，**刻意避开已被蓝紫、青绿、天蓝占满的水色**），散布漂浮光点。
  - 无任何文字、无 logo、右下角无水印，640×640 WebP。
  - 主体占比约 65%，左上主光、投影短而软。

## 5 · 制作人拍板与开放探讨

1. **核心微创新的取舍**
   - **A（推荐）· 双核**：鱼群同行（第 3 海域）＋ 深渊压强换气（第 4 海域）。两条新规则各承担一片海域，递进清晰，是本作区别于原作的招牌。
   - **B · 单核**：只做鱼群同行，压强换成简单的水雷/渔网障碍。开发更轻，但第 4 海域会偏弱。
   - **C · 加码**：双核之外再加"进化分支"（章末三选一：速度型 / 咬合型 / 护甲型），深度最高但体量明显变大。

2. **被吃掉的惩罚力度**
   - **A（推荐）· 有张力**：扣心 + 体型回退一阶 + 2 秒无敌。成长有得失，翻身也快。
   - **B · 更轻松**：只扣心，体型保留。更休闲，但大鱼失去威胁感。

3. **第三模式选哪个**
   - **A（推荐）· 深渊无尽**：越深越大越凶，冲最深米数与最高分——最贴合"越吃越强"的核心幻想。
   - **B · 每日深渊**：每日同一种子，全世界同一片海，比谁潜得深。公平竞技，但需要确定性生成与每日重置逻辑。
   - **C · 掠食者试炼**：8 场限时 Boss 对决，纯技巧。体量小、辨识度高。

**默认建议：1A + 2A + 3A**——先把"吃/躲/长大"的手感打磨到极致，再用鱼群与压强两条新规则证明"我们不是 20 年前那个换皮游戏"，最后用深渊无尽头把成长幻想推到极限。
