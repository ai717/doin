## 1 · 创意概念与核心乐趣

- **游戏名称**：光束折射镜 / Laser Reflect / slug：`laser-reflect`（专有名词双词连字符，语义唯一、无歧义）
- **一句话玩法**：在实验台上摆放平面镜、分光棱镜与滤色片，把一束白光折射、分离成多路彩色光，精准点亮所有感光核。
- **核心乐趣与卖点**：
  - **零手速、纯脑力的几何顿悟**：不靠反应，只靠空间推理。光束在格子里直线传播、45° 折返、分光、滤色，玩家每一次转动元件都会瞬间重算整条光路，看见自己"摆对了"的那一刻，光线像蛛网般铺满盘面、所有感光核同时亮起——这是解谜游戏最纯粹的**"啊哈"顿悟爽感**。
  - **确定性闭环，无挫败**：40 关全部纯手工编排、100% 可解、无随机死局。玩家永远面对"想出来就能过"的题目，而非"看运气"的翻牌。配合可无代价撤销/重置，鼓励大胆试错。
  - **科技桌面美学**：光学实验台 + 真实分光物理（白光→RGB 三原色），把课本里的"棱镜分光实验"做成可玩的玩具，兼具**智力成就**与**视觉治愈**双重满足。
- **核心循环**：观察靶位与颜色 ➔ 转动/摆放光学元件 ➔ 光束实时重算、部分靶点亮起 ➔ 修正路线直至全亮 ➔ 三星评级驱动重玩挑战最优步数。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **Laser Maze**（经典益智玩具 + web 热门作）：45° 平面镜、分光器、滤色片、颜色靶的机制几乎成为品类范式；"用更少元件拿更多星"的评级思路清晰。
  - **Refract**（Vibe Arcade web 作）：**只转动、不摆位**的交互（元件固定，玩家仅旋转朝向），par 步数三星评级，Ctrl+Z 撤销，光束实时重算。
  - **PrismTie**（Google Play）：**棱镜分光（白光→RGB 三原色）** + 颜色靶必须同色命中的进阶机制，是"分光"玩法的标杆。
- **我们要继承的成熟机制**：
  - **光束实时重算**：任何一次转动后整条光路从发射器重新追踪（纯函数），所见即所得，无增量更新错误；
  - **只转不摆**：元件位置由关卡固定，玩家仅旋转朝向，交互极简、误触少、移动端友好；
  - **par 步数三星评级**：以"最少转动次数"为唯一评价口径，鼓励最优解而非单纯通关；
  - **颜色靶 + 滤色片**：白光经棱镜/滤片分离成 R/G/B，靶只认自己的颜色——"先想颜色再想几何"。
- **本作的独特魅力与微创新**：
  - **分光棱镜作为主角（而非边缘机制）**：多数同类把分光器当作后期插件，本作从早期关卡就让"白光→三原色"成为核心体验，放大"一束光被拆成彩虹"的视觉奇观；
  - **科技实验台视窗隐喻**：拒绝网格换皮，把盘面做成**光学实验台 + 遮光罩暗房**，营造"实验室里调激光"的沉浸感；
  - **确定性关卡与最优解数学闭环**：40 关手工编排并逐关跑求解器验证"可解 + 存在 par 内解 + 答案不泛滥"，杜绝闭门造车的死局。

## 3 · 玩法规则与交互说明

### 核心规则

**盘面构成**（网格，桌面 8×8，移动端可缩放显示）：
- **激光发射器（Emitter）**：固定于网格边缘，发出单束白光，方向固定；
- **平面镜（Mirror）**：45° 斜置，把入射光反射 90°。两态（`/` 与 `\`），玩家可旋转；
- **分光棱镜（Splitter / Prism）**：入射白光一分为二——一路直行、一路垂直偏转；彩色光则穿透/偏转各依规则。可将一束白光拆成多路，是本作核心；
- **滤色片（Filter）**：固定或可转的彩色片，只让**匹配颜色**的光通过（红光过红片，其余被吸收）；
- **分色棱镜（Spectro-Prism，进阶）**：把白光分解为 R/G/B 三束不同方向的光（对标 PrismTie 的棱镜），是后期"彩色靶"关卡的关键；
- **感光核 / 靶（Target / Receiver）**：环形靶位，只被**同色光**点亮（无色靶可被任意光点亮）；
- **遮光墙（Wall）**：固定障碍，光撞上即停。

**玩家合法操作**：
- 点击 / 轻触一个**可旋转元件**（镜、分光器、滤片、分色棱镜）使其**顺时针转 90°**；
- 元件位置固定，玩家**不摆位、只转朝向**（对齐 Refract 的极简交互）。

**胜利 / 失败条件**：
- **唯一胜利条件**：盘面上**所有感光核同时被各自匹配颜色的光点亮**；
- **无失败条件**：无时间、无生命、无步数上限，玩家可无限试错，不产生挫败死局。

**容错与无死局说明**：
- 40 关全部**手工编排 + 逐关确定性求解器验证**，保证：① 每关至少一解；② 每关存在 par 步数内的解；③ 答案数量不过度泛滥（避免乱转也能蒙对）。无任何随机生成，杜绝纯运气死胡同。

### 操作与手感

- **鼠标 / 触控**：点击元件 = 顺转 90°；右键或再次点击循环；桌面支持滚轮悬停旋转；触屏单点即转；
- **键盘快捷键**：`R` 旋转当前悬停/选中的元件，`Ctrl+Z` / `Cmd+Z` 撤销，`Esc` 或 `Backspace` 重置本关；
- **误触容错与缓冲**：撤销**零代价**（不计入步数、不惩罚星级），重置不罚星；光束每次转动后实时重算，反馈即时。

### 模式与内容编排（章节关卡制，非套路三件套）

本作是**纯确定性解谜**，天然契合**精心编排的章节关卡制**，共 **40 关**，分 4 章，每章引入一种新机制：

| 章节 | 关卡 | 引入机制 | 关卡主题（中/英） |
|---|---|---|---|
| 第 1 章 · 单束之光 | 1–8 | 平面镜反射 | Single Beam / 单束之光 |
| 第 2 章 · 一分为二 | 9–18 | 分光棱镜（白光→两路） | Split Light / 一分为二 |
| 第 3 章 · 滤色甄别 | 19–28 | 滤色片 + 颜色靶 | Filter & Color / 滤色甄别 |
| 第 4 章 · 彩虹矩阵 | 29–40 | 分色棱镜（白光→RGB 三原色） | Rainbow Matrix / 彩虹矩阵 |

- **关卡解锁**：顺序解锁，通关即解锁下一关；
- **星级评级（唯一目标指标）**：以**转动次数**为口径——`≤ par` 三星、`≤ 2×par` 二星、其余一星；星级持久保存，鼓励回刷最优解；
- **章节完章仪式**：集齐整章三星时，实验台爆发出整片光谱粒子（彩虹光带扫过），给予完章成就感；
- **不设每日挑战、不设无尽冲分**——核心乐趣是"想通"，而非"刷分"。

### 游戏目标与反馈体系

- **核心目标指标**：**最少转动步数**（非得分！），以 par 星级呈现；
- **局内反馈**：光束实时重算 + 靶点亮起时逐颗微震与光晕扩散；点亮最后一颗靶时全盘光路瞬间"通电"亮起，配合成功音与粒子；
- **胜利仪式**：全靶点亮 → 光谱粒子从靶位喷发 + 光路定格高亮 + 星级结算弹层（步数 / par / 三星）。

### 双语核心词汇与数据键名规划（防英文界面夹杂中文）

- **模式/章节**：第 1 章·单束之光 `chapter_1_single_beam`、第 2 章·一分为二 `chapter_2_split_light`、第 3 章·滤色甄别 `chapter_3_filter_color`、第 4 章·彩虹矩阵 `chapter_4_rainbow_matrix`；
- **元件**：激光发射器 `emitter` / 平面镜 `mirror` / 分光棱镜 `splitter` / 滤色片 `filter` / 分色棱镜 `spectro_prism` / 感光核 `target` / 遮光墙 `wall`；
- **状态/评级**：三星 `stars` / 标准步数 `par` / 撤销 `undo` / 重置 `reset` / 已解锁 `unlocked` / 已通关 `cleared`；
- **颜色**：白 `white` / 红 `red` / 绿 `green` / 蓝 `blue`；
- **数据层约束**：关卡、元件、颜色全部用字符串 key（如 `level_1`、`mirror`、`color_red`），展示文本统一由 i18n 获取，**严禁在 `levels.mjs` / `data.mjs` 中裸写中文**。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：光学实验台 / 暗房遮光罩 / 赛博霓虹实验室 / 精密仪器台 / 悬浮微粒微光。
- **专属视窗物理隐喻（严禁无脑套用左右双翼模版）**：
  - **整体形态 = 一台俯视的光学实验台（Optical Bench）**：盘面并非裸露网格，而是嵌在一块**深色防反光实验台面上**，四周包一圈**金属遮光罩**，营造"关灯做实验"的暗房沉浸感；
  - **左侧 = 立式光学元件托盘**（物理抽屉式），按"镜 / 分光 / 滤色 / 棱镜"分类收纳，选中即高亮，像从实验台上抽取元件；
  - **顶部 = 精密仪表条**：细窄的"光学读数条"，显示当前关卡、转动步数 / par、星级，做成仪器表盘刻度样式，而非右侧白底 SaaS 卡片；
  - **盘面光路**：光束以**发光霓虹细线**实时渲染，白光冷白、红光暖红、绿光青绿、蓝光电蓝；分光瞬间迸发**彩虹粒子**；感光核点亮时环形光晕扩散；
  - **环境氛围**：深蓝紫渐变背景 + 缓慢漂浮的尘埃微粒（营造暗房光柱中的浮尘），拒绝死黑/死白大平铺；
  - **系统控制**（撤销 / 重置 / 返回）内嵌于**实验台右下角的仪器按钮组**（拨杆 + 旋钮质感），绝不四角散落浮动按钮。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：
  1. **转动元件**：金属精密旋钮的**咔哒微响**——短促噪声缓冲 + 带通滤波，模拟镜架卡入定位槽；
  2. **光束命中感光核**：FM 调频合成**温润水滴玻音 / 马林巴**，随点亮靶数音高逐级抬升（五声音阶上行）；
  3. **分光瞬间**：失谐双振荡器 + 快速滑音包络的**清脆"绽开"声**，似光线迸散成彩虹；
  4. **全靶点亮（胜利）**：五声阶琶音上行 + 低音下潜 Kick，营造"整台机器通电"的仪式感；
  5. **滤色吸收（错误路径）**：短促**低通滤波"闷响"**，似光束被吞没，用于提示颜色不匹配；
  6. **撤销 / 重置**：轻柔**纸页/机械回卷微响**（噪声滤波），不刺耳。
- **封面设计提案**：
  - 3D 软胶质感，单一居中主体：**一枚发光的半透明三棱镜**，正把一束白光拆成红绿蓝三色光带；深蓝紫渐变背景，漂浮光谱微粒，**零文字**，640×640 WebP。

## 5 · 制作人拍板与开放探讨

1. **分色棱镜是否纳入（核心机制取舍）**：本作差异化亮点是"白光→RGB 三原色"的彩虹矩阵。
   - **方案 A（推荐）**：完整纳入分色棱镜，第 4 章主打三原色彩虹，视觉奇观最强、差异化最足；
   - **方案 B**：仅保留"滤色片染色"（白光过红片变红光），去掉三原色分光，机制更简洁、实现更轻，但奇观感略降。
2. **交互粒度：只转 vs 可摆位**：
   - **方案 A（推荐，对齐 Refract）**：元件位置固定、玩家只转朝向，极简、误触少、移动端友好；
   - **方案 B**：玩家可从元件托盘**自由摆放**元件到空格（对齐 Laser Maze），自由度更高但关卡设计难度与移动端误触成本上升。
3. **关卡体量**：
   - **方案 A（推荐）**：40 关 / 4 章，机制渐进、体量精悍；
   - **方案 B**：60 关 / 6 章，加入"多发射器同时入射"等更复杂组合，适合重度解谜玩家。
