## 1 · 创意概念与核心乐趣

- **游戏名称**：极简泡泡堂·水泡大作战 / Bubble Arena Lite / 建议 slug：`bubble`（单个简短纯英文单词，符合极简命名契约）
- **一句话玩法**：网格放水泡困住对手再戳破淘汰
- **核心乐趣与卖点**：
  - **困敌的紧张感与戳破的爽感分离**：与炸弹人“爆风即死”不同，本作把击杀拆成两步——十字水柱先把人困进透明水泡，玩家必须在数秒内冲过去用针戳破才算淘汰。困住对手那一刻的围观起哄、冲刺补刀的肾上腺素、被困者拼命摇杆挣扎的喜剧感，是泡泡堂 4399 时代最经典的社交记忆。
  - **踢泡走位博弈**：吃到踢泡道具后可把水泡踢向对手或踢开自救，位置计算比单纯拼手速更有策略；十字水柱的长短、放泡上限、移速三维成长让每局节奏自然加速。
  - **10 秒上手、30 秒见爽点**：方向移动 + 一个放泡键，新手第一局就能困住 AI 一次；老玩家则享受连环困、守株待兔、假放泡逼走位的心理战。
- **核心循环**：网格走位抢道具 ➔ 预判对手落点放水泡 ➔ 十字水柱扩散困敌 ➔ 冲刺戳破/踢泡补刀 ➔ 地图收缩或回合结算 ➔ 再开一局复仇。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **泡泡堂 BnB（Crazy Arcade）**：网格放水泡、十字水柱、困泡后戳破淘汰、道具成长（水泡数/水柱长/移速/踢泡/针）、地图障碍与草丛视野。最受认可的是“困≠死”的两段式击杀与多人同屏围观感。
  - **Bomberman（炸弹人系列）**：经典网格炸弹、十字爆风炸砖开路、踢弹、连环爆。最成熟的是格子化移动手感、放弹冷却与爆风预警（炸弹闪烁）。
- **我们要继承的成熟机制**：
  - 格子化四向移动 + 输入缓冲（转向不卡墙角，允许提前 120ms 预输入）；
  - 水泡延时爆裂（约 2.2 秒）+ 爆前膨胀闪烁预警；
  - 十字水柱被硬墙截断、被软砖吸收一格后消失；
  - 道具三维成长：泡数上限、水柱长度、移动速度，另加踢泡、针（戳破/自救）、盾（挡一次水柱）；
  - 回合制短局（90–120 秒）+ 地图后期收缩逼战。
- **本作的独特魅力与微创新（Twist）**：
  - **两段式击杀为核心**：水柱命中只把角色困进水泡（漂浮、无法移动、可用摇杆/按键挣扎缩短困泡时间），必须由对手（或队友误伤规则下由任意角色）走到泡旁“戳破”才淘汰；困泡超时（约 6 秒）自动脱困但掉 1 点体力。这一 Twist 彻底区别于爆风即死。
  - **踢泡十字水柱对决**：踢出的水泡沿直线滑行、撞墙停住，仍按十字扩散，可用来远程封路或把自困泡踢离险地。
  - **单人对 AI 为主、同屏双人可选**：纯静态无联机，AI 分三档（巡逻/追击/预判放泡），双人同键盘分左右键位，满足宿舍同桌对决。
  - 极简清爽画风 + 软胶角色，弱化原作的复杂商城与联机，回归一局 2 分钟的纯对决。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：
  - 与站内 **`bomber`（炸弹人，序号 81）** 的差异：`bomber` 核心是十字爆风炸砖开路、爆风触身即伤/即死，爽点在连环爆与开图；本作核心是**水泡困敌再戳破**，水柱本身不直接淘汰，击杀必须完成“困住→补刀”两步，地图以水池/浮岛障碍为主、软砖只产道具不主打开路，心流是围困与救援而非爆破清图。规则模型、胜负判定、道具语义均不同，绝非换皮。
  - 与站内 **`bobble`（泡泡射手，序号 78）** 的差异：`bobble` 是自下而上发射彩泡、凑色消除的射击消除；本作是俯视角网格实时对战，无发射台、无颜色消除，泡是延时十字水柱的载体。
  - 与站内 `bubble-merge` / `bubble-bloom` / `cloud-merge` 等合成类差异：本作无掉落合成、无物理堆叠，属实时网格对战品类。
  - 结论：与 100 款底表逐一比对，无规则几乎一模一样的存量游戏；与最接近的 `bomber` 共享“网格+十字”大类，但核心机制 Twist 明确（困泡两段式击杀），符合“只堵换皮、同品类带 Twist 可立项”口径。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - **盘面/场景构成**：俯视角网格地图（推荐 13×11 格起步，随关卡变体 15×13），格子分四类：硬墙（不可破坏、截断水柱）、软砖/浮木（可被水柱冲散、概率掉道具）、草丛/浅滩（可通行、半遮角色）、空地。角色占 1 格，出生点在四角/对角。
  - **玩家合法操作**：四向移动；放水泡（受当前泡数上限与冷却约束，泡在脚下生成、角色可离开该格、离开后该格对所有人变障碍）；踢泡（拥有踢泡道具时，走向水泡将其沿该方向踢出滑行）；戳破（走到困敌水泡相邻格自动/按键戳破）；挣扎（被困时连按方向键缩短困泡时间）。
  - **水泡与水柱判定**：水泡放置后约 2.2 秒爆裂，沿上下左右四向扩散水柱（长度 = 当前水柱等级），遇硬墙截断、遇软砖冲散该砖后该向停止、遇另一水泡触发连环爆（延迟 80ms 逐个）。水柱格对角色的判定为“困泡”而非击杀；已在泡中的角色不再重复判定。
  - **胜利条件与失败条件**：单人对 AI 模式下，淘汰全部 AI（戳破其困泡）即胜；玩家被戳破淘汰即负；回合计时结束时按存活体力+困敌数判胜负（平局则加时 15 秒地图收缩决胜）。同屏双人模式先淘汰对方者胜（可设三局两胜）。
  - **容错与无死局说明**：地图为手工编排 + 对称随机镜像（软砖位置左右/上下对称生成，保证双方资源公平）；出生点周围 2 格必为空地，保证开局可移动；软砖密度设上限且保证至少一条通路连通所有出生点（生成后做连通性校验，不通过则重掷），杜绝出生即被封死。AI 放泡遵循“放泡后必留逃生格”规则，避免 AI 自困死局；玩家自困时可用针自救或等超时脱困，不存在无解死局。
- **操作与手感**：
  - **鼠标/触控**：移动端虚拟方向盘（左下）+ 放泡大按钮（右下），支持滑动转向；桌面端以键盘为主，鼠标可点选关/模式/暂停。
  - **键盘快捷键**：玩家 1：WASD 移动、空格/回车放泡、Shift 踢泡（或自动踢）；玩家 2（同屏双人）：方向键移动、Enter/小键盘 0 放泡。通用：`P`/`Esc` 暂停。
  - **随时可暂停与失焦保护机制（实时性游戏必选）**：
    - *暂停/继续实体按钮*：顶栏常驻醒目的「暂停 / 继续」（Pause / Resume）按钮；
    - *暂停快捷键*：`P` 键或 `Esc` 键即时切换暂停与继续（空格为放泡主动作，不作暂停键以免误触）；
    - *暂停视觉反馈*：暂停时主舞台画面冻结并展示轻量半透明覆盖层（显示「已暂停 / PAUSED」，提供「继续」、「重新开始」入口），水泡倒计时、AI、回合计时全部冻结；
    - *切后台自动暂停（Visibility Auto-Pause）*：监听 `visibilitychange`，切标签页、最小化或失焦时自动静默暂停主循环与计时器，冻结音效；
    - *静态解谜自适应*：本作是实时对战，不适用静态豁免，暂停为强制项。
  - **误触容错与操作缓冲**：方向输入缓冲 120ms，贴墙转向自动吸附格线；放泡键连按只在冷却结束时生效一次，防误放连环自困。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - **首屏秒进对局**：打开直接进入第 1 关（新手村水池图）就绪盘面，角色已在出生点、AI 已就位，按方向键即可走、空格即可放泡，**严禁全屏选关/模式遮罩**；
  - **常驻显眼选关入口**：顶栏常驻「选关」/「模式」按钮，点击以轻量抽屉展示地图与模式（单人对 AI / 同屏双人 / 阶梯挑战）；结算面板提供「再来一局」「下一关」「选关」；
  - 记忆本地进度（已解锁地图与 AI 难度），下次打开直接续上次模式。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **单人对 AI 阶梯挑战**：8 张地图（水池、浮岛、冰面、熔岩边等主题）× 3 档 AI（新手巡逻、熟手追击、大师预判放泡），逐图解锁；
  - **同屏双人对决**：同键盘 1v1，三局两胜，地图任选已解锁图；
  - **生存围困（可选变体）**：1 玩家对 3 AI 混战，最后存活者胜。
  - **严禁无脑套用“无尽冲分 + 每日挑战”**：本作以回合对决与阶梯挑战为核心，不设无尽冲分与每日挑战。
- **游戏目标与反馈体系**：
  - 核心指标：胜场、困敌数、戳破数、最快淘汰用时、连困次数；阶梯挑战按地图星级（1–3 星：胜场/用时/无伤）评级，而非单一总分；
  - 胜利反馈：困泡戳破时水花爆开 + 角色弹飞喜剧动画，回合结算展示本局战绩卡。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 模式名：单人对 AI Solo vs AI / 同屏双人 Local 2P / 阶梯挑战 Ladder Challenge / 生存围困 Survival Clash；
  - 地图名：第 1 关·新手水池 Level 1: Rookie Pool / 浮岛 Float Isles / 冰面滑道 Ice Slide Pool（数据 key 如 `level_1`、`map_float`）；
  - 道具名：水泡+1 Bubble +1 / 水柱+1 Splash +1 / 疾行 Boots / 踢泡 Kick / 针 Needle / 护盾 Shield（数据 key 如 `item_bubble`、`item_kick`）；
  - AI 等级：新手 Novice / 熟手 Skilled / 大师 Master；
  - 数据层约束：所有地图、道具、难度数据一律用字符串 key/id（如 `level_1`、`item_needle`），展示层通过 i18n 获取文本，严禁在数据文件中裸写中文；语言切换原地热更新，严禁 `location.reload()`。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：夏日水上乐园、软胶水泡、清爽水池、浮岛格子、童年对决。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 视窗形态：**水上乐园俯视泳池盘面**——主舞台是一块带瓷砖格纹的泳池台面，四周是池边防滑砖与排水沟边框，顶栏是泳池计分牌（回合计时/存活头像），底部是操作托盘（虚拟方向盘+放泡按钮，桌面端显示键位提示条）。信息全部贴在泳池边框上，不做左右双翼卡片。
  - 严禁照搬“左翼卡片+中间视窗+右翼卡片”三栏套路，严禁四角散落浮动按钮，严禁右侧堆叠 SaaS 表单卡片；保持全站沉浸暗色底蕴，但泳池区用清爽蓝绿高光形成题材反差。
- **立体质感与渲染路线裁决**：
  - 裁决：**DOM + CSS 3D 或 Canvas 2D**（95% 优先路线）。网格盘面用 Canvas 2D 绘制水泡膨胀、水柱扩散与角色软胶动画，UI/HUD 用 DOM；水泡用径向渐变+高光点做出果冻立体感，无需真 3D。
  - 不采用 Three.js：本作无真三维空间翻转/视角需求；若后续版本确需 3D 泳池视角，必须守三条红线（零外部 3D 模型纯代码生成几何体、轻量低开销着色防发烫、所有 UI/HUD 严格在 DOM 层隔离）。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 5 种专属材质音效——
  1. 放水泡：果冻落地的低频“噗”声（噪声滤波+正弦下潜）；
  2. 水柱爆裂：水花四溅的宽频噪声 burst + 高频水滴 FM；
  3. 困泡成功：泡泡膜绷紧的“啵”声 + 轻微失谐铃音；
  4. 戳破水泡：针扎气球的脆响（短噪声+高频瞬态）；
  5. 吃道具/踢泡：滑行摩擦声（滤波噪声扫频）+ 拾取的清脆木鱼音。
  - 拒绝单振荡器 beep 与 C-E-G-C 琶音。
- **封面设计提案**：640×640 软胶质感，单一居中主体（一个困在透明水泡里的软胶小角色，旁边一根针），占画面 60–75%、无文字，鲜艳蓝绿渐变背景带水花点缀。

## 5 · 战绩留存与会话流转规划（通用且平台无关）

- **通用战绩图（可选，平台无关）**：
  - 触发时机：赢下回合、通过阶梯挑战地图或刷新最快淘汰纪录时；
  - 呈现形式：Canvas 绘制战绩卡（游戏标题、地图/模式、胜场、困敌/戳破数、用时、`doin.win` 链接），中英双语自适应。
- **会话流转与后置推荐（Next Up Circulation）**（只能从 100 款底表选真实 slug）：
  - `bomber`（炸弹人）：同为网格十字对决，玩完水泡困敌可去体验爆风炸砖的另一种爽感；
  - `airpuck`（双人霓虹气垫球）：同屏双人反应对决，延续同桌对战氛围；
  - `volley`（隔山打牛）：双人物理对战，适合双人局后换口味。

## 6 · 制作人拍板与开放探讨

列出 3 个选项，供制作人（用户）快速拍板决断：
1. **选项一（困泡超时规则）**：困泡超时自动脱困但掉 1 点体力（方案 A，节奏宽容、适合单人对 AI） vs 超时直接淘汰（方案 B，节奏高压、更接近原作淘汰感）。
2. **选项二（同屏双人键位）**：同键盘左右分键（方案 A，零外设、宿舍友好） vs 单人为主、双人仅作隐藏模式（方案 B，首版更聚焦 AI 阶梯）。
3. **选项三（地图规模）**：8 张主题地图阶梯解锁（方案 A，内容饱满） vs 4 张地图 + 随机镜像变体（方案 B，首版更快上线、靠随机保新鲜）。
