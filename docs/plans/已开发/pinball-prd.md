## 1 · 创意概念与核心乐趣

- **游戏名称**：霓虹弹珠台 / Pinball Breaker（副标：打砖×弹珠混合机台）/ 建议 slug：`pinball`
- **一句话玩法**：拉簧发射弹珠，双挡板兜底救球，在布满砖墙与机关的弹珠台里轰碎砖块、连击爆发、触发机关特效！
- **核心乐趣与卖点**：
  - **双挡板救球的实体手感（Flipper Catch & Shoot）**：这是弹珠台最原始的肾上腺素——左右两枚软胶挡板分控短打，极限捞起即将漏入死亡通道的弹珠，反手一击把它"勺"回砖墙中央。每一次兜底救球都是反射神经的即时奖励，高手还能用挡板尖角"勺球（Scoop）"打出刁钻切角弹道；
  - **打砖×弹珠的弹道博弈（Brick-Trail Ballistics）**：上层不是普通打砖块那种整面死墙，而是**由砖块砌成的弹珠台地形**——砖与砖之间的"空白区"就是天然弹道。打碎哪块砖、先打哪一簇，会永久改写弹珠的下落路径：可能开出直落死亡通道的险道，也可能留出一排砖当反弹跳板，把球"雕刻"进机关密集区。技术与策略并存；
  - **连击×机关互点燃的心流（Combo-Fuse Fever）**：连击计数与机关特效互相引爆——5 连击点燃侧弹射器、10 连击降下砖块风暴、特定机关触发双球乱舞。连击越高音阶越爬升、挡板边缘火花越旺，全场进入目不暇接的高潮段；
  - **经典机台的机关奇观（Mechanism Spectacle）**：弹跳缓冲（Pop Bumper）迸射、可翻倒靶（Drop Target）齐倒、斜坡通道吞球、转盘加速……每一个机关都是可点亮的"特效按钮"，让清砖过程充满变量与惊喜；
  - **章节关卡制的成长主线（Star Campaign）**：3 大章节 × 10 关，逐章引入新砖种与新机关，三星评级（剩余弹珠 / 通关用时 / 最高连击）驱动反复精进——绝不做无脑无尽刷分三件套。
- **核心循环**：
  ```
  拉簧发射弹珠 ➔ 双挡板接球/短打弹射 ➔ 轰碎砖块+点亮机关（连击攀爬）
       ↑                                                     ↓
  弹珠沿打砖撕开的空白区弹道回流 ← 机关特效/砖块风暴改变地形（节奏升温）
       ↓ (漏入 outlane 或中央 drain)
  失去一颗弹珠（剩余球 -1）➔ 三星评级结算 ➔ 解锁下一关/挑战更高连击
  ```

**我们要继承的成熟机制**：
1. **双挡板分控短打（Twin Flipper Tap）**：左右挡板独立短打，输入缓冲（100ms 命令窗口）保证连点不吞指令；挡板快抬快落、撞点决定出射角（板头勺球出锐角，板根推球出直射）；
2. **分级砖块破坏（Tiered Bricks）**：玻璃砖 1 击碎、钢铁砖 2 击碎、黄金砖 3 击碎，碎砖粒子迸溅、音效音阶递升；
3. **经典机关四件套（Classic Mechanisms）**：弹跳缓冲（Pop Bumper）、可翻倒靶（Drop Target）、侧弹射器（Sling Shot）、滚道感应器（Rollover Lane），为清砖主线注入变量；
4. **限球制与危机区（Ball Limit & Outlanes）**：每关 3 颗弹珠；两侧 outlane 与中央挡板间隙（drain）是空白区陷阱，漏球即扣球——这是弹珠台与打砖块差异化的"技术兜底"核心；
5. **确定性物理（Deterministic Physics）**：固定步长纯函数帧步进、可注入种子、同种子可重放，高速球 CCD 子步进防穿模（此契约开发端必须严格遵守）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **打砖重塑弹道（Brick-Trail Dynamic Field）**：砖墙不是静态靶子——每打碎一块砖，就永久打开一处新的"空白区弹道"，弹珠之后的滚动路线随之改变。玩家通过选择"先打哪块砖"来雕刻自己的弹道：开险道速通、留砖做跳板、拆墙直通机关区。这是本作策略深度的灵魂；
2. **连击×机关联动熔断（Combo-Fuse Mechanisms）**：连击数与机关特效互相点燃（5 连击点燃侧弹射器、10 连击触发砖块风暴、清空砖簇随机奖励、滚道感应开启双球乱舞），形成"越打越燃"的节奏放大器；
3. **章节三星制主线（Star-Staged Campaign）**：弹珠台少见地采用 3 章 × 10 关的关卡制，每章引入新砖种/新机关，三星评级（剩余弹珠+通关用时+最高连击）——彻底跳出"无尽冲分"的套路段子。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素（物理世界 9:16 竖版机台）
- **弹珠机舞台（Pinball Cabinet）**：竖版 9:16 物理世界，桌面端居中机台呈现，带轻微倾斜透视；四壁与顶部为弹性挡墙；
- **弹珠（Steel Ball）**：霓虹金属光球，固定半径与质量；发射自底部拉簧轨，速度有上限钳制；
- **双挡板（Twin Flippers）**：左右下角各一枚软胶挡板，绕轴在 0°~60° 间快抬快落，板身有碰撞长度与弹性，板尖可勺球；
- **砖块墙（Brick Wall）**：上层至中层的砖墙地形，含三种砖：
  - **玻璃砖**：1 击即碎，通透发光，基础分；
  - **钢铁砖**：2 击碎裂，拉丝质感，2 倍分；
  - **黄金砖**：3 击碎裂，鎏金质感，3 倍分 + 必定触发小特效（火花/加速）；
  - 砖墙布局预留**初始空白区弹道**（空位通道），保证发球后弹珠天然可达全部砖簇；
- **机关（Mechanisms）**：
  - 弹跳缓冲（Pop Bumper）：被碰即迸射弹珠 + 计分 + 计入连击；
  - 可翻倒靶（Drop Target）：全部翻倒触发全靶奖励 + 随机特效；
  - 侧弹射器（Sling Shot）：把弹珠横向踢飞，连击 5 段后点燃（踢出速度 ×1.5）；
  - 滚道感应器（Rollover Lane）：弹珠滚过触发特效转盘（双球乱舞 / 砖块风暴 / 缓冲狂潮 / 救球罩）；
  - 斜坡通道（Ramp）：弹珠冲上斜坡吞入即得大分 + 恢复 1 颗弹珠（每关限 1 次）；
- **危险空白区（Danger Gaps）**：两侧 outlane 斜槽 + 中央挡板间隙（drain）——弹珠落入即失去当前这颗弹珠；空白区同时也是打砖开出的新弹道，风险与路线一体。

### 3.2 判定与胜负规则
1. **发球**：底部拉簧轨蓄力发射（按住蓄力/松开弹出），弹珠初速决定第一落点；每关 3 颗弹珠；
2. **计分与连击**：
   - 每击碎一块砖：`砖分值 × 连击倍率`；
   - **连击定义**：弹珠连续击中砖块或机关（每次命中间隔 < 3 秒）期间未触碰任何挡板与两侧墙壁，即连击 +1；倍率 = 1 + 连击 × 0.5（封顶 ×10）；
   - 触碰挡板/侧墙：连击重置为 0（挡板救球是策略代价，不是惩罚）；
3. **机关特效触发规则**：
   - 连击达 5：点燃侧弹射器（踢速 ×1.5）；
   - 连击达 10：触发**砖块风暴**——全场新增一层脆化玻璃砖（可再清，分翻倍）；
   - 清空某一砖簇：随机奖励（连击 +3 / 挡板伸长 20% / 弹珠速度上限 +10%）；
   - 滚道感应：转动特效转盘（双球乱舞：追加一颗弹珠；缓冲狂潮：5 秒内缓冲分 ×2；救球罩：本次漏球不扣球，每关限 1 次）；
4. **胜负判定（章节关卡制）**：
   - **通关**：清完全部砖块（含风暴砖）即过关；结算按三星评级——☆ 剩余弹珠 ≥ 1，☆☆ 通关用时 ≤ 关卡目标，☆☆☆ 最高连击 ≥ 关卡目标；
   - **失败**：3 颗弹珠全部漏入 outlane/drain 则本关失败，可立即重试（保留已解锁进度）；
   - **街机生存模式**：无关卡目标，无限清砖，弹珠速度随清砖数逐级爬升，目标=最高连击与总分榜；
5. **无死局保证（数学可解性）**：
   - 弹珠台物理天然无死局：任何时刻弹珠必被重力带回挡板区，挡板抬升角度与双板覆盖范围保证全场可达；
   - 关卡布局采用**可解性校验**：每关生成后校验"所有砖簇与机关均位于弹珠可达区域、发射初速与挡板抬升能力的可达包络覆盖全场"，不满足即重排布局——绝不出现打不到的角落砖（死砖）。

### 3.3 物理确定性契约（用户点名：固定步长可测，开发硬约束）
- **固定物理步长**：物理以恒定 dt（120Hz）步进，纯函数 `stepFrame(state, dt)` 推进，状态完全由「输入序列 + 随机种子」决定；
- **可重放**：同一种子 + 同一输入序列必然得到逐帧一致的结果，支持录像回放与确定性测试；
- **防穿模**：高速弹珠与砖块/挡板碰撞采用子步进（CCD 连续碰撞检测），无论多快都不穿砖穿板；
- **能量守恒与钳制**：弹珠速度有上下限与衰减阻尼，物理量守恒，禁止能量异常增长；
- **随机注入**：机关转盘、砖块风暴、发球抖动等全部随机走确定性种子 PRNG（可注入，便于测试）；
- **自动化测试契约**：≥1000 步随机合法操作游走测试状态机不崩、不变式不破；同种子重放逐帧一致测试；碰撞不穿透测试；三砖分级计分测试。

### 3.4 手感调优与操作映射（键鼠触全通）
- **挡板手感**：按下命令 100ms 缓冲窗内即生效；挡板 0°→60° 约 80ms 快抬，释放后 150ms 自然回落；连点不吞指令；
- **撞点出射角**：撞挡板根=直推，撞板头=锐角勺球，出射角由撞点与挡板瞬时角速度共同决定（带切向摩擦，高手可搓出侧旋）；
- **摇机（Nudge）**：每颗弹珠限 3 次，屏幕微位移 + 弹珠横向加冲量，用于紧急救球；
- **桌面键盘**：`A`/`←` = 左挡板，`D`/`→` = 右挡板，`空格` = 发射蓄力，`S`/`↓` = 摇机；
- **桌面鼠标**：按住左键 = 左挡板、右键 = 右挡板（或点击舞台左/右半区），点击发射轨蓄力；
- **移动端**：左下/右下双触控区 = 左右挡板，向下滑动 = 摇机，发射轨上滑蓄力；底部预留广告安全避让区。

### 4.3 音效规划（WebAudio 纯程序化合成，零外部音频文件）

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：机关特效的口味倾向？
- **选项 A（高能爆发流 · 推荐默认）**：机关特效全开——弹跳缓冲/可翻倒靶/侧弹射器/滚道转盘/斜坡/双球乱舞/砖块风暴全数登场，节奏最燃、奇观最足，最能体现"触发机关特效"的立项初衷；
- **选项 B（经典扎实流）**：只保留弹跳缓冲、可翻倒靶、侧弹射器三个经典机关，去掉双球与砖块风暴，更贴近传统实体弹珠台的克制手感；
- **选项 C（精简硬核流）**：机关全部砍掉，只留砖块 + 双挡板 + 空白区弹道，纯拼打砖选路与兜底手感，最硬核最极简。

### 拍板项 2：内容编排主线？
- **选项 A（章节三星制优先 · 推荐）**：3 章 × 10 关章节关卡制为主（每章引入新砖种/新机关，三星评级），街机生存为附加模式，成长线最清晰；
- **选项 B（街机生存优先）**：以无尽生存清砖冲分为主打，章节制后置，更偏街机厅的"投币就玩"气质；
- **选项 C（双轨并进）**：章节制与街机生存同步上线，内容量最大（开发量也最大）。

### 拍板项 3：弹道策略深度？
- **选项 A（打砖重塑弹道 · 推荐）**：打碎砖块会永久开辟新的空白区弹道，玩家通过选砖"雕刻"弹珠路线（留砖做跳板/拆墙直通机关），策略深度拉满；
- **选项 B（固定砖墙靶场）**：砖块只当静态靶子，打碎后不留地形改变，弹道固定简单直接，上手门槛更低。
