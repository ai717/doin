## 1 · 创意概念与核心乐趣

- **游戏名称**：雷电·极简纵向弹幕 / Raiden Lite / slug `raiden`
- **一句话玩法**：竖版战机纵向卷轴，蓄力激光加保险清屏。
- **核心乐趣与卖点**：极简纵向弹幕的纯粹爽感。战机一路向上推进，敌弹如雨时靠小判定点擦弹走位，蓄满激光一发清屏，保险（Bomb）留到绝境保命。画面极简几何风，敌弹清晰可读，节奏是「推进—擦弹—蓄力—清屏」的循环。
- **核心循环**：纵向卷轴推进 ➔ 击毁敌机拾取强化 ➔ 蓄力激光打精英/Boss ➔ 保险清屏保命 ➔ 通关一面进入下一面。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **Raiden 雷电（街机纵版射击经典）**：纵向卷轴、敌机波次、道具强化（散射/激光）、Boss 战。手感顺滑在移动跟手、敌弹速度分级、强化道具掉落节奏。
  - **Cave 纵版弹幕（怒首领蜂等）**：小判定点、擦弹、保险清屏、弹幕图案化。手感顺滑在低速精确移动（按住减速）、弹幕可读性。
- **我们要继承的成熟机制**：纵向自动卷轴、敌机波次编排、主武器强化拾取、蓄力激光、保险清屏、小判定点、低速精确移动。
- **本作的独特魅力与微创新（Twist）**：极简几何风纵向弹幕。微创新点：蓄力激光可穿透一列敌人，蓄力时战机减速换取高伤；擦弹积攒保险能量（擦弹越多保险回得越快）；每面 Boss 弹幕图案极简几何化（圆环、扇形、螺旋），可读性拉满。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：对照 `GEM_INSTRUCTION-4.md` 第二节 100 款底表逐款核对：
  - 与 `space-defender`（太空防御者：横向几何弹幕+擦弹充能）不同：space-defender 是横向推进，本作是纵向卷轴推进，方向与敌机波次循环完全不同；本作核心武器是蓄力激光+保险，space-defender 是擦弹充能。
  - 与 `invaders`（舷窗防线：固定底部打横移敌群）不同：invaders 是固定炮台打横移敌阵，本作是战机纵向推进、自由走位、波次+Boss。
  - 与 `tank`（坦克巷战：地面射击）不同：tank 是地面巷战，本作是空中纵向弹幕。
  - 结论：射击大类可共存，但推进方向、武器循环、弹幕形态完全不同，不存在换皮风险。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - 盘面/场景构成：竖版舞台（窄长比例），背景纵向自动卷轴，敌机从顶部波次进入，玩家战机在舞台内自由移动。关卡为手工波次编排，非随机生成。
  - 玩家合法操作：移动战机、主武器自动/按住射击、蓄力激光（按住蓄力松开释放）、保险清屏（消耗保险次数清除全屏敌弹并重创敌人）。
  - 胜利条件：击毁本面 Boss 后进入下一面；通关全部面数后通关。
  - 失败条件：战机判定点被敌弹/敌机击中损失 1 条命；命数为 0 游戏结束。擦弹（判定点外围擦过敌弹）不受伤并积攒保险能量。
  - 容错与无死局说明：波次手工编排保证弹幕密度有可走位缝隙；保险清屏可随时保命；被击后短时无敌；提供重开本面按钮。无随机生成死局风险。
- **操作与手感**：
  - 鼠标/触控：触屏拖动战机移动（相对拖动，手指不遮判定点）、自动射击、双击保险；桌面键盘方向键/WASD 移动、Z 射击、X 蓄力激光、C 保险、Shift 低速精确移动。
  - **随时可暂停与失焦保护机制（实时性游戏必选）**：
    - 暂停/继续实体按钮：顶栏常驻「暂停 / 继续」（Pause / Resume）按钮；
    - 暂停快捷键：`P` 键、`Esc` 键、`Space`（非主动作时）即时切换；
    - 暂停视觉反馈：画面冻结，半透明覆盖层显示「已暂停 / PAUSED」，提供「继续」「重新开始」；
    - 切后台自动暂停（Visibility Auto-Pause）：监听 `visibilitychange`，切标签页/最小化自动暂停主循环、卷轴与音效；
    - 输入缓冲：蓄力与保险支持输入缓冲，绝境时按保险不丢指令。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - 首屏秒进对局：打开直接进入第 1 面（或记忆进度面数）就绪舞台，战机可直接移动射击，**严禁首屏全屏选关遮罩**；
  - 常驻显眼选关入口：顶栏常驻「选关 / Stages」按钮，点击以轻量抽屉展示面数网格；通关结算面板提供「下一面」与「选关」；
  - 严禁强制全屏遮罩阻塞首屏。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **严禁无脑套用“无尽冲分 + 每日挑战”**；
  - 采用面数关卡制：共 6 面（云层、峡谷、都市、太空站、极光、母舰），每面引入新敌机与新弹幕图案，面末 Boss。三星评级（无伤/无保险/擦弹数）；
  - 另设「弹幕训练」模式：单面弹幕图案练习，服务于擦弹与蓄力手感，非无脑无尽。
- **游戏目标与反馈体系**：
  - 核心目标：击毁 Boss 通关本面；指标为擦弹数、无伤通关、保险使用次数；
  - 反馈仪式：蓄力激光释放时屏幕光束+敌机连环爆炸；Boss 击毁时大爆炸+星级结算。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 模式名：闯关模式 Stage Mode / 弹幕训练 Bullet Training；
  - 关卡名示例：第 1 面·云层 Stage 1: Cloud Layer；第 4 面·太空站 Stage 4: Space Station；
  - 核心实体：蓄力激光 Charge Laser / 保险 Bomb / 擦弹 Graze；
  - 数据层约束：关卡与敌机一律用 key（如 `stage_1`、`enemy_drone`），展示层走 i18n，严禁在数据文件中裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：极简几何、霓虹线条、竖版街机柜、太空纵深。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 视窗形态：**竖版街机柜舷窗**——整体是单栏竖版机台，中央是窄长纵向舞台（舷窗视角），顶部是状态栏（命数/保险/蓄力条），底部是操作托盘。不是左右双翼三栏，也不是横版舞台。
  - 保持全站沉浸暗色底蕴，舞台内是深空渐变+几何敌机/弹幕高对比。
- **立体质感与渲染路线裁决**：
  - 裁决：**Canvas 2D** 为主渲染（卷轴背景、战机、敌机、弹幕粒子），DOM 仅做 HUD/按钮/暂停层。95% 路线，秒开零发热；
  - 不使用 Three.js：本作是 2D 纵向射击，无真三维空间需求；
  - 若未来尝试真 3D，必须守三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层）。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 6 种专属音效，拒绝单音蜂鸣：
  1. 主武器射击声：短促失谐方波脉冲（街机打击感，非单音蜂鸣）；
  2. 蓄力声：FM 合成上行音高+能量嗡鸣，蓄满时清脆提示音；
  3. 激光释放声：低音下潜 Kick+高频光束嘶鸣（失谐多振荡器）；
  4. 敌机爆炸声：噪声爆破+金属碎裂（噪声滤波合成）；
  5. 擦弹声：极短高频「叮」声（玻音 FM），连续擦弹连成节奏；
  6. 保险清屏声：厚重低频冲击+全屏静默一瞬的压迫感。
- **封面设计提案**：3D 软胶质感，单一居中主体（极简几何战机+激光束，60-75% 无文字），鲜艳深空渐变背景，霓虹弹幕点缀。
