## 1 · 创意概念与核心乐趣

- **游戏名称**：符文塔防 / 极简符文塔防 / Rune Tower / 建议 slug：`rune-tower`
- **一句话玩法**：在单条回廊沿途唤醒远古符文石，每波击退魔物后三选一遗物卡（分裂/减速/连锁引爆），5 分钟组出割草流派保卫核心水晶。
- **核心乐趣与卖点**：
  - **填补全站唯一的轻肉鸽塔防空白（Zero-to-Hero Roguelite TD）**：
    DOIN 现有库涵盖了解谜、棋牌、弹球与动作，但尚无一款真正具有战略厚度的塔防策略游戏。本作摒弃所有繁琐耗时的局外数值养成，将经典的塔防策略浓缩为一局 5–8 分钟的极致纯粹心流——开局只有两座平平无奇的小石塔，20 波后凭借流派连锁化身雷火湮灭风暴；
  - **立竿见影的“三选一”流派质变感（Relic Draft Dopamine）**：
    对标 2026 年 itch.io 热门轻肉鸽 TD，每一次波次防守结束后的神龛三选一卡牌，绝不是无聊的“攻击力 +5%”，而是**直接改变弹道物理与反应机制的质变级遗物**：
    - *分裂多重箭*：单体奥术飞弹直接裂解为 4 枚追踪碎片；
    - *极寒霜爆*：被减速 50% 的敌人死亡时发生冰爆，冻结周围群体；
    - *超导过载*：雷击命中燃烧中的敌人触发全屏电弧连锁；
    玩家能清晰感受到每一张卡牌注入后，回廊战场瞬间发生肉眼可见的质变；
  - **高密度策略克制与阵型调配（Chokepoint Strategy）**：
    单条蜿蜒回廊拥有天然的“入弯点”、“内圈十字交汇区”与“末段守门点”。在有限法力下，究竟是把重火力集中在前段打范围压制，还是在中段做冰霜减速漏斗，或是后段放单体斩杀，考验玩家对怪物类型（自爆虫潮、重甲傀儡、疾行暗影、虚空领主）的战术预判；
  - **纯正的“神装清屏”终局释放**：
    当核心遗物凑齐（如“冰霜减速 + 燃烧传导 + 碎冰引爆 + 连锁飞弹”），回廊魔物瞬间化为漫天元素微粒，带来极为震撼且解压的视听盛宴。
- **核心循环**：
  ```
  观察下波魔物预警（数量·抗性·移速） ➔ 规划回廊基座部署/升级符文 ➔ 开启波次战斗（走位微调·集火标记）
         ↑                                                                            ↓
  重构流派卡组 / 战术微调  ◄── 三选一远古神龛遗物（质变机制卡） ◄── 波次结算（水晶零损/法力收益）
         ↓
  突破第 5/10/15/20 波领主 Boss ➔ 20 波全通大胜 / 获封符文贤者勋章 / 登榜星盘纪录
  ```

**我们要继承的成熟机制**：
1. **纯粹的四系符文基石（Four Primal Runes）**：
   - **奥术符文（Arcane）**：高频连射、自动索敌、单体 DPS 标杆；
   - **烈焰符文（Flame）**：范围灼烧、爆裂溅射、持续 DOT 压制；
   - **冰霜符文（Frost）**：大范围减速力场、极寒冰冻、战场控场核心；
   - **雷霆符文（Storm）**：贯穿电弧、连锁跳跃、破盾破甲先锋；
2. **元素双相反应机制（Elemental Reactions）**：
   借鉴成熟 RPG 的元素组合，两两碰撞产生乘算质变：
   - *烈焰 + 冰霜 = 融甲碎冰*（解除减速但瞬间爆发 250% 破甲物理伤害）；
   - *烈焰 + 雷霆 = 过载引爆*（产生大范围 AOE 击退冲击波）；
   - *冰霜 + 雷霆 = 超导深冻*（使目标承受所有后续伤害 +40%）；
   - *奥术 + 任意 = 纯粹共鸣*（提升对应反应发生率与射程 30%）；
3. **固定步长与纯逻辑战斗计算**：
   回廊路径采用贝塞尔曲线插值点阵，敌人沿 `progress (0.0 -> 1.0)` 推进。塔的攻击检测、弹道速度、范围判定均在标准物理帧内结算，保证重放无误差与 100% 确定性。

**本作的差异化微创新（拒绝千篇一律）**：
1. **“单次回廊闭环”的紧凑战场（Compact Winding Corridor）**：
   不搞无脑的多路线分流与迷宫造墙。全场仅一条精妙设计的**双 S 型回廊（带 2 处天然集火盲盒与交叉打击重合区）**，总长恰好满足 18–25 秒通过时间。玩家能在有限的 10–12 个符文石座上打出极限集火空间；
2. **三选一无废卡设计（Guaranteed Build Synergy）**：
   遗物池分类为 `[弹道质变] / [元素反应] / [战术经济]`。卡池内置智能伪随机（Smart PRNG Drafting），根据玩家场上已部署的符文偏向加权出卡，确保玩家每局必定能稳定成型 1–2 种成熟流派，绝不出现三张全废的废弃选择；
3. **首领破盾倒戈机制（Boss Stagger & Discharge）**：
   每 5 波的领主 Boss 拥有坚固护盾。当玩家通过元素反应削空其护盾时，Boss 会陷入 3 秒硬直（Stagger）并向周围所有小怪反向释放一次“符文过载脉冲”，将战术破盾转化为战局逆转的大招时刻；
4. **全局 0 垃圾时间（Fast Forward & Wave Rush）**：
   支持随时空格切换 1x / 2x / 3x 速，且在当前波怪物未死绝时可按下“提前召怪（Rush Wave）”，立即获取额外法力利息，兼顾休闲玩家与速通高手的爽感。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素

- **核心水晶（Sanctum Crystal）**：
  位于回廊终点，初始拥有 **20 点核心生命（HP）**。普通怪物逃脱扣除 1 点，精英怪扣除 2 点，领主扣除 5 点。生命归零则防守失败；
- **回廊石径（Runic Pathway）**：
  暗青色板岩铺就的蜿蜒小径，魔物自左上方传送门（Abyssal Portal）涌出，沿着既定轨迹向右下方核心水晶移动；
- **符文石基（Runic Pedestals）**：
  回廊沿途固定分布的 **10 个远古石基**。玩家消耗局内法力（Mana）在空石基上唤醒符文，或对已有符文进行阶位突破（I阶 ➔ II阶 ➔ III阶）；
- **魔物体系（The Swarm）**：
  - *影行者（Crawler）*：数量极多、低血高移速，考验群体减速与范围溅射；
  - *晶岩魔像（Golem）*：超高生命、重甲减伤，考验雷电破甲与单体奥术爆发；
  - *灵体女妖（Banshee）*：免疫纯物理/减速，漂浮行进，考验元素反应与奥术追踪；
  - *自爆甲虫（Boom Beetle）*：死亡时对周围 80px 内所有魔物加速，必须优先单点击杀；
  - *四方天灾领主（Chapter Bosses）*：
    - Wave 5: **巨石领主（Titanus）**——召唤石傀护卫，蓄力砸地；
    - Wave 10: **霜火双子（Twin Phantoms）**——周期性切换火抗与冰抗护盾；
    - Wave 15: **虚空织行者（Void Weaver）**——在回廊中释放虚空黑雾遮蔽索敌；
    - Wave 20: **湮灭始祖（Oblivion Prime）**——终极领主，三阶段形态转换。

### 3.2 判定与胜负规则

1. **单波胜负**：当前波次怪物全部被歼灭（或死亡+逃脱清空）➔ 判定本波胜利；
2. **战役胜利**：成功防守完全部 20 波魔物攻势，核心水晶生命 > 0 ➔ 获封“远古符文大师”，弹出战役终局星盘与流派结算证书；
3. **战役失败**：核心水晶生命扣减至 0 ➔ 战役终止，根据当前到达波次与击杀数计算功勋评级；
4. **无死局与数学可解性保证（Hard Balance Law）**：
   - **DPS 基准线与法力回填**：每一波怪物的总生命值总量严格按照幂函数拟合：$HP_{total} = Base \times Wave^{1.35}$。系统保证玩家哪怕仅用基础符文合理升级，其基础 DPS 也能覆盖当波 110% 的生命总需求；
   - **重抽保底（Relic Reroll）**：每场战役初始赋予玩家 **2 次遗物刷新机会（Reroll）**；若本波三张卡均不满意，可重抽一次；
   - **防卡关补正（Mercy Mana）**：若在第 5/10/15 波前一波水晶受损，神龛三选一卡池必保底出现一张“紧急整备/水晶修复（+3 HP）”或“范围清场陷阱”支援卡，杜绝连环雪崩。

### 3.3 手感调优与操作映射（键鼠触全通）

- **部署与升级**：
  - 鼠标左键点击空基座 ➔ 弹出四系符文环形选择盘（奥/火/冰/雷），点击即刻唤醒（仅需 0.05s 无感过渡）；
  - 再次点击已建符文 ➔ 显示攻击射程柔光范围、当前击杀统计、升级与分解返还（分解全额返还 75% 法力）；
- **集火指令（Priority Targeting）**：
  - 点击回廊上的任意魔物 ➔ 标记为“星芒集火目标”，全场射程内所有符文优先攻击该目标；再次点击取消；
- **全键盘快捷操作（Power-User Keyboard Mapping）**：
  - `1` / `2` / `3` / `4`：快速选定四系符文；
  - `Space`：切换战斗速度（1x ➔ 2x ➔ 3x 循环）；
  - `R`：提前召唤下一波魔物（Rush Wave，赚取早发金币）；
  - `U`：快速升级选中的符文；`X`：快速分解选中的符文；
  - `Esc`：关闭选中面板 / 暂停游戏；
- **操作缓冲与误触防护**：
  - 在卡牌三选一结算期间，后台物理战斗完全冻结；
  - 移动端支持大尺寸指尖热区（石座周围 48px 点击判定半径），触控体验顺滑。

### 3.4 模式与内容编排（深度契合轻肉鸽，拒绝套路化）

1. **核心模式：远征试炼（Ascension Expedition）**：
   - 标准 20 波战役，分为四大章节（1–5 远古林地、6–10 熔岩裂隙、11–15 极寒冻土、16–20 虚空王座）；
   - 通关后解锁更高难度词条（如“魔物移速 +20%”、“基座数量减少 2 个”、“领主血量翻倍”），为硬核玩家提供反复挑战的流派深度；
2. **速通残局：领主大试炼（Boss Trials）**：
   - 专为深度策略玩家设计：跳过前期杂兵，直面 5 波高压精英领主连打！
   - 开局直接赋予 800 法力与初始 5 张自选遗物卡，考验玩家在极限构筑下的秒伤与抗压能力；
3. **每日星盘：天体共鸣（Daily Constellation）**：
   - 每日由全网统一日期种子生成（如 `2026-09-22`）；
   - 固定回廊曲线、固定魔物出兵顺序与固定卡牌池，玩家比拼通关后“核心剩余生命 + 最短用时 + 剩余法力”的综合大师分。

## 4 · 美术风格与桌面美学规划

### 4.1 题材风格与关键词
- **视觉风格**：**“黑曜石祭坛 × 发光远古符文 × 极简街机机台”**；
- **色调配比**：
  - 背景基底：深色黑曜石青黑渐变（`#0d1117` ➔ `#161b22`），带微弱的星尘微粒与石砖裂纹暗纹；
  - 奥术：翡翠幽绿（`#00f5d4`）；
  - 烈焰：炽金熔火（`#ff5400` / `#ff9e00`）；
  - 冰霜：极地晶蓝（`#00bbf9` / `#48cae4`）；
  - 雷霆：紫电霓光（`#9d4edd` / `#c77dff`）；
- **可读性标记禁用描边圈（硬性铁律）**：
  - 防御塔射程、选中高亮、首领警戒光环，**绝对禁止画成带边框的圆圈**！
  - 必须使用 `createRadialGradient` 绘制：从塔底中心高亮（`rgba(0, 245, 212, 0.25)`）平滑羽化至边缘完全透明（`rgba(0, 0, 0, 0)`），配以缓慢的 2.5s 柔和呼吸起伏，营造出神秘的魔法力场质感。

### 4.2 桌面端双栏沉浸舞台规划（≥900px）
绝不搞单一网页拉伸，桌面端呈现为一套古朴精致的**“魔导炼金台机台（Runic Altar Stage）”**：

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个关乎核心手感与玩法走向的关键点进行定夺：

### 拍板项 1：符文塔的索敌与战术交互策略
- **方案 A（经典智能索敌 · 推荐）**：符文塔默认优先攻击“最靠前（First）”魔物，玩家可全局一键切换“血量最高（Strongest）”或点击指定单体进行“全军集火标记”。操作最优雅且门槛低。
- **方案 B（全自主主动技能槽）**：除被动索敌外，四系符文在积攒能量后，玩家可手动点击回廊任意位置释放一次主动技能（如“奥术轰炸”、“冰霜风暴”）。策略更主动，但单局微操频次变高。

### 拍板项 2：三选一遗物卡的出现时机与经济分配
- **方案 A（纯波次神龛三选一 · 推荐）**：严格每防守住 1 波，神龛弹出一次三选一（共 19 次选卡机会），局内法力只用于建造与升级塔本身。构筑纯粹，节奏明快，新手完全不卡手。
- **方案 B（轻卡牌商店混合制）**：波次结束获得随机法力与神龛点数，玩家既可以在三选一中拿卡，也可以用多余法力去“封印/刷新”卡池。流派上限更高，但稍微增加了 UI 界面复杂度。

### 拍板项 3：单局长度与章节波次规模
- **方案 A（20 波极速轻肉鸽 · 推荐）**：共 20 波，4 个章节（每 5 波一个 Boss），每局实测 5–7 分钟。快节奏、高成型、午休摸鱼与碎片化游玩最佳。
- **方案 B（30 波史诗深度远征）**：共 30 波，6 个章节，每局 10–12 分钟。中后期可以叠加多达 15+ 遗物词条，场面更加恢弘震撼，但局时相对偏长。
