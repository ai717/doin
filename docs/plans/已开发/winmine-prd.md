## 1 · 创意概念与核心乐趣

### 游戏名称
- **中文名**：经典扫雷（副标题「WinMine 原版复刻」）
- **英文名**：Classic Minesweeper / WinMine
- **建议 slug**：`winmine`（取自原版扫雷可执行文件名 `winmine.exe`，历史准确、单词简短；候选 `classic-minesweeper`）

### 一句话玩法
在一个灰色浮雕网格里推理避雷：左键翻格子、右键插红旗，把雷全部标记、把安全格全部翻完——踩雷即炸。

### 核心乐趣与卖点
- **逻辑推理的顿悟感**：数字+旗帜的约束，像在做一道即兴的数独，每次"这格必是雷"的推理命中都极爽。
- **连锁翻开的扩散爽感**：翻开空白格时"唰——"地一片连锁翻开，是扫雷最上瘾的瞬间。
- **极限竞速的心跳**：盯着 LED 计时器冲"最快纪录"，是 WinMine 时代一代人的肌肉记忆。
- **50/50 赌命的心跳**：面对最后两格必有一雷、只能靠猜的生死一瞬——这是**原版扫雷不可分割的情绪**（详见 §3.4 与拍板项 1）。
- **纯粹的怀旧**：灰底、凸起格、红色 LED 计数、黄色笑脸，一眼把你拉回 90 年代的计算机课。

### 核心循环
```
观察数字与旗 → 推理下一格是否安全 → 左键翻开 / 右键插旗
   ↑                                      ↓
   │                          翻开连锁扩散 / 旗数联动
   └────────── 冲最快时间 · 或踩雷重开 ← 计时推进
```

## 2 · 经典标杆与对标参考

### 2.1 成熟标杆原型（唯一对标）
**Microsoft Minesweeper（WinMine）**，1990 年随 Microsoft Entertainment Pack 1 诞生、1992 年随 Windows 3.1 内置、Windows 95 时代广泛流传。这是扫雷的"元祖"，本作即它的 1:1 复刻。

### 2.2 我们要继承的"原版机制"（复刻清单）
- **三档标准难度**：初级 9×9（10 雷）、中级 16×16（40 雷）、高级 30×16（99 雷），外加**自定义**（宽 9–30、高 9–24、雷数 10–(宽-1)×(高-1)）。
- **双键操作模型**：左键翻格（含空白格连锁 flood-fill 扩散）、右键循环插旗（旗 → 问号 → 恢复，原版右键可在旗与问号间循环）、**双键齐按的和弦 chord**（数字上方旗数与数字相等时，同时按左右键快速翻开周围安全格）。
- **LED 数字计数器**：左上"剩余雷数"（= 雷总数 − 已插旗数，可为负，显示 -1/-2…），右上"计时器"（0–999 秒，首击后启动），黑底红字 7 段数码管质感。
- **黄色笑脸按钮**：🙂 常态 / 😮 按下左键时 / 😵 踩雷死亡 / 😎 通关，点击即可重开。
- **数字配色**：1 蓝 · 2 绿 · 3 红 · 4 深蓝 · 5 深红 · 6 青 · 7 黑 · 8 灰（原版经典配色，逐字对齐）。
- **死亡与胜利状态**：踩中的雷红底高亮、误插旗处显示"雷+红叉"、其余雷全部亮出；通关时所有雷自动插旗、计时停摆、笑脸戴墨镜。
- **窗口菜单栏**：游戏(G)〔新游戏 F2 / 初级 / 中级 / 高级 / 自定义 / 最佳时间〕、帮助(H)〔规则 / 关于〕，还原为可点的拟真菜单。

### 2.3 本作与门户现有 `minesweeper` 的关系（互斥而不冲突）
| 维度 | 已上架 minesweeper | 本作 winmine |
|---|---|---|
| 定位 | 现代改良版 | 复古原教旨复刻 |
| 核心卖点 | 无猜保证、首击安全、死局透视 | 1:1 复刻原版手感与怀旧视觉 |
| 运气成分 | 彻底排除（逻辑完全可解） | **保留原版运气**（见拍板项 1） |
| 视觉 | 现代化配色 | Win95 灰底浮雕 + 红 LED + 笑脸 |
| 评价体系 | 依现代版而定 | 三档各记"最快通关时间"，无分数无星级 |

两者吸引不同人群：前者是"想安静推理不碰运气"的玩家，后者是"想重玩计算机课那个味道"的怀旧党。**无需为避同而别扭改动本作**——本作的全部价值就在于"原味复刻"。

## 3 · 玩法规则与交互说明

### 3.1 核心规则
- **盘面构成**：`rows × cols` 网格，每格有固定状态机：
  `未翻开(凸起) → 翻开(凹陷) → 数字1-8 / 空白` ；未翻开格上可叠加 `旗 / 问号`。
- **胜利判定**：所有**非雷格**均被翻开（无论旗插得对不对都算通关，通关时系统自动把所有雷补插成旗）。
- **失败判定**：左键翻开任意**地雷格**，立即失败，游戏终止，全场亮雷。
- **合法操作**：左键翻开未翻格；右键在未翻格上循环 旗→问号→无；双键和弦翻开数字格周围（须周围旗数 = 该数字）。
- **容错**：翻到数字/空白、插错旗都可继续；和弦旗数不匹配时 no-op 并给轻量闪动反馈，**不报错、不 alert**。

### 3.2 操作与手感（对"高度复刻"至关重要）
- **左键按下**：该格实时凹陷（sunken），笑脸变 😮；**松开**：翻开并恢复 🙂。这个"按下即陷、松开即判"的即时感是原版手感的核心。
- **空白连锁扩散**：翻开 0 → 以 BFS/flood-fill 扩散翻开相邻格，直到被数字格包围，一次性"唰"开一片。
- **键盘**：`F2` 新游戏、`Z`/`Ctrl+Z` 暂无撤销（原版没有 undo，为保持纯粹不引入）、方向键可选焦点移动（v1.1）。
- **触屏**：单指 = 左键翻开；长按 300ms = 插旗；长按数字格 = 和弦。移动端完全可用（详见 §4）。
- **误触容错**：首击翻格、插旗在 `mouseup`/`touchend` 才判定，拖出去可取消，避免误翻。

### 3.3 模式与内容编排（依"竞速经典"特质定制，非套用）
- **三档标准难度 + 自定义**：完全对齐 WinMine，不做"章节关卡"，不做"无尽冲分"，不做"每日挑战"——扫雷的天然递进就是**难度阶梯**。
- **评价体系 = 最快通关时间**：初级 / 中级 / 高级各维护一条（或多条）本地"最快时间"记录（仿原版"最快时间"成绩框，可带"请输入名字"的破纪录弹窗，纯情怀、零后端）。
- **单一指标**：只有"用时（秒）"，**没有分数、没有星级、没有金币**——这是对"评价体系须专属化"最忠实的执行。

### 3.4 数学可解性与无死局说明（★ 立项分歧点，请务必拍板）
> DOIN 铁律之一：扫雷"必须延后布雷（首击安全展开）+ 逻辑求解器，杜绝靠运气猜雷"。
> 但**原版 WinMine 恰恰不是这样的**：早期版本（Windows 3.1/95）首次点击就可能踩雷，且全程允许出现只能靠猜的 50/50 局面。这是"原版扫雷"不可分割的一部分，也正是"高度复刻"与 DOIN 无死局红线之间的根本张力。
>
> 因此本作存在三条可选路线（见 §5 拍板项 1），需制作人定夺：
> - **路线 A（原教旨复刻）**：完全还原最早版——雷预埋、首击可踩雷、保留猜雷运气。**违反 DOIN 无死局红线**，需在落地时作为"用户明确批准的例外"写进 `AGENTS.md` 或验收备注。
> - **路线 B（90s 手感 + 官方后期特性）**：视觉/手感 100% 复刻，但引擎采用**延后布雷（首击必安全）**——这其实是 **Windows 2000 之后官方扫雷就有的特性**，无损"原版感"；猜雷局面仍可能出现（官方从不保证全程无猜）。**满足"首击安全"，部分满足红线的务实推荐**。
> - **路线 C（B + 无猜开关）**：在 B 基础上，额外内置一个可开/关的"无猜模式"（生成时保证全程逻辑可解），默认关闭。既守红线又留原味，代价是生成器复杂度略升。

**推荐：路线 B（默认）**，作为"复刻度与平台红线的最优平衡点"，并在拍板时请制作人就 A/B/C 明确二选一/三选一。

## 4 · 美术风格与视觉氛围

### 4.1 题材与视觉关键词
`Win95 拟真怀旧` · `灰底浮雕` · `红色 LED 数码` · `彩 CRT 桌面` · `复古像素亮丽`

### 4.2 沉浸舞台规划（游戏机台化，拒绝老套网页病）
**整体"机台" = 一台 90 年代 CRT 显示器 + Win95 桌面场景**：
- **环境背景**：Win95 标志性的**青色桌面 `#008080`**（彩色、非灰非白，天然符合 DOIN"禁死灰白") —— 上面铺一层极淡的 CRT 辉光、四角暗角、漂浮灰尘粒子构成的暖色回忆氛围；桌面角落可点缀极简的"回收站/我的电脑"剪影作为怀旧彩蛋。
- **核心舞台**：正中央是一扇拟真的 **WinMine 游戏窗口**——原生标题栏「扫雷」+ 菜单栏（游戏(G)/帮助(H)）+ 状态条（红色 LED 雷数 + 黄色笑脸 + LED 计时）+ 灰色浮雕雷区，原尺寸等比、桌面居中，四周留待广告位安全边距。
- **左右两翼**（桌面端 ≥900px）：不堆 SaaS 卡片，而是把"难度选择"与"最快时间"做成两扇 **Win95 对话框样式的小窗**，一左一右像桌面上停着的两张窗口，随主窗口构成"一个打开的桌面"，视线自然、信息不散。
- **移动端**（≤768px）：单列，雷区占屏宽，菜单/难度选择收纳为窗口底部的一体化掌机式操作条，底部预留广告安全留白。

### 4.3 色彩与实体质感
| 角色 | 色值/材质 |
|---|---|
| 环境桌面 | `#008080` Win95 青 + CRT 辉光 + 暗角 |
| 窗口/雷区底 | 经典灰 `#C0C0C0` |
| 凸起未翻格 | 高光 `#FFFFFF`/阴影 `#808080` 双凸边（3D bevel），按下变凹陷 |
| 翻开格 | `#C0C0C0` 单边凹陷 |
| 数字 | 1蓝 2绿 3红 4深蓝 5深红 6青 7黑 8灰（原版配色） |
| LED 计数器 | 黑底 + 红色 7 段数码字 |
| 笑脸 | 黄底黑线，四态表情 |
| 旗帜 | 红旗 + 黑杆 |

- **实体按键质感**：凸起格用 `border-style: outset` 式的双色浮雕（内高光外阴影）实现"可压"体感；笑脸/菜单项同样有浮雕与按下位移。
- **交互反馈**：翻空白格连锁扩散带轻微"板擦"动效；插旗/翻雷有清脆合成音；计时 LED 随秒数滚动跳字；死亡瞬间炸弹震动 + 笑脸 😵。

### 4.4 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **主体**：一只巨大的 3D 软胶**黄色笑脸**（WinMine 那枚，带墨镜 😎 或标准 🙂），旁边躺一枚黑色尖刺**小地雷**。
- **背景色系**：**明黄**（未被占用的空色相，与笑脸天然契合，避开已上架 minesweeper 的"蓝"）。
- **Prompt 草案**：
