## 1 · 创意概念与核心乐趣

- **游戏名称**：盲盒记忆牌 / Memory Flip；建议 slug：**`memory-flip`**（与站内 `memory-duel` 形成 *Memory* 系列 `_duel` vs `_flip` 后缀分行，玩家一眼可辨"对抗 vs 解谜"）。
- **一句话玩法**：翻开两张盲盒找配对，**配不中时四周相邻的盒子会"咯哒"一声顺时针轮转一格**——记死位置在这里行不通。
- **核心乐趣与卖点**：
  1. **「位置在变」打破记忆翻牌的平庸底盘（核心创新）**：传统翻牌一旦记下盘子坐标就稳赢，本作让翻错引发 **4 邻盖牌顺时针轮转 1 格**——记住了一对的方位，下一手翻错时它俩可能已被推走；玩家被迫从"位置记忆"升级&#x4E3A;**"动态短期记忆 + 实时追踪"**；
  2. **配对的爽感没丢，错配的代价也有了戏**：配对成功仍然 = 一对潮玩入袋 + 连击木琴和弦；错配不是"盖回就当无事发生"，而是**娱乐圈盘活起来**——你越错，盘子越乱，但也越接近"以乱破乱"的破局爽感；
  3. **章节递进引入新位移规则**：5 章从纯记忆入门，逐章递进 4 邻轮转 → 8 邻轮转 → **盘面齿轮弯曲**（部分托盘四象限旋转）→ **限定翻错次数的解谜残局**，让"动态位移"这一招真的能撑起 22 关；
  4. **零误翻三星评价，鼓励"看穿后再出手"**：与"动态位移 = 逼你记位置"反向拉扯——评分体系奖励**少错**而非快翻，形成"先靠记忆压缩位移、再靠位移考验记忆"的双重张力。
- **核心循环**：
  ```
  翻第 1 张 → 记住图腾 → 翻第 2 张 → 配对？
       ├ 是 → 收入集藏册 + 连击木琴 → 升段再战
       └ 否 → 两张盖回原位 → 触发"咯哒轮转"（邻位顺时针 1 格）
                  → 盘面位移 → 玩家重新追踪 → 章末三星结算
  ```

## 3 · 玩法规则与交互说明

### 3.1 核心规则（动态位移翻牌）

**盘面构成**

- 单人共享牌桌网格，成对**潮玩图腾**（图腾集 8–15 种类 × 2 张）。
- 第 1 章 4×4 = 16 张（8 对）→ 第 2 章 4×5 = 20 张（10 对）→ 第 3 章 5×6 = 30 张（15 对）→ 第 4 章 4×5 网格（含齿轮子盘）→ 第 5 章 4×4 ~ 5×6 复用 + 残局限定。
- 初始洗牌采用**无不动点打乱（Derangement）**：任一张牌都不落在原始索引位，避免"位置记忆捷径"残存。
- **成对图腾分布保证**：成对图腾避免落在彼此正相邻位（生成器拒绝此类分布），保证第一手合理探索至少需要 1 次试错，避免"开局即送对"的游戏 shortcuts。

**回合结构**

- 玩家**每回合 = 1 次翻牌尝试**（翻 1 张 → 翻第 2 张 → 判定 → 结算）。
- **配对成功**：图腾入集藏册 → 该两格变**空槽**（不补牌）→ 玩家**保留连击权**（可继续翻）；
- **配对失败**：两牌盖回原位 → **触发"咯哒轮转"**（见下）→ 连击断 → 回合结束。

**「咯哒轮转」位移规则（核心机制，精确定义）**

- **触发**：仅"翻牌失败"事件触发，配对成功不触发；
- **范围**：以**两次翻错位置为中心**，各取其**4 邻（上下左右）盖牌**——已翻开过的牌、已配对空槽、参与轮转中心牌自身不轮转；
- **方向**：4 张邻牌在该 2×2 邻接块内**顺时针旋转 1 格**（位旋转，图腾不变）：
  - 即 上 → 右 → 下 → 左 → 上，每个邻位上的盖牌按此顺序各前进一格；
- **边界处理**：邻位越界则该方向跳过（盘面不回绕，不补位）；
- **去重**：两次错配位置若邻接块重叠，重叠格上的牌只参与一次旋转（按第一次错配位置为主计算）；
- **可解性保证**：位移只改变位置不改变图腾分布，对子总数守恒，**盘面永远是同种图腾偶数张**，因此 100% 终局可解，**无死局、无纯运气死胡同**。

**章节递进规则（5 章新机制层叠解锁）**

| 章              | 关数 | 新机制                                        | 体验意图                 |
| -------------- | -- | ------------------------------------------ | -------------------- |
| 第 1 章 **初识盲盒** | 4  | 纯经典翻牌，无位移                                  | 入门熟悉底盘与图腾集           |
| 第 2 章 **咯哒咯哒** | 4  | 触发 **4 邻顺时针轮转 1 格**（本作主机制）                 | 让玩家认知"位置在变"，被迫实时追踪   |
| 第 3 章 **大转盘**  | 5  | 触发范围扩为 **8 邻**（含四角）一并顺时针轮转                 | 失败代价更高，看穿后必须果断出手     |
| 第 4 章 **盘面齿轮** | 4  | 盘面分为 **2×2 四象限子盘**，每次错配额外让**目标象限整体旋转 90°** | 项目级空间暴击，玩家要在四象限内重定位  |
| 第 5 章 **大师残局** | 5  | **预置残局 + 限定翻错次数**（如最多 2 次错配）；用满必败，零错即三星    | 把动态位移推到解谜题面，每关一道独立谜题 |

**胜负判定（唯一终止条件）**

- **胜利**：盘面所有图腾对全部配对完成（清空）；
- **失败**：仅在"第 5 章残局"模式下存在——**翻错次数用尽且仍有未配对图腾**；前 4 章为"开放通关"，翻错次数不限（按错数计星）；
- 无时间限制（解谜向鼓励"想清楚再翻"）。

**无死局与可解性硬约束（生成器必须满足）**

1. 任何时刻盘面上每对图腾仍偶数张存在（位移不改变图腾类，对子守恒）；
2. **白盒可解性**：每关生成后用 BFS 验证存在至少一条零错通关路径（玩家在不知道位置时无法零错通关，但数学可解，作为保证）；
3. **第 5 章残局限定翻错次数 ≥ BFS 最优解的翻错下限**（否则必败关卡不会生成）；
4. 随机关卡走**确定性种子 PRNG (mulberry32)**，同一关卡/每日题面完全可复现；
5.

### 3.2 操作与手感

- **鼠标 / 触控**：点击盒子——翻开盒盖动画（约 320ms，3D Y 轴翻转 + 盒盖弹性回弹），点击瞬间已锁定图腾，不等动画完成就响应下一张点击输入；
- **键盘**：方向键移动光标 + 回车翻开；数字键 1–6 直达当前行第 N 列（盘面 ≤ 6 列），便于资深玩家键盘速通；
- **输入缓冲**：连击翻牌间 200ms 缓冲防连点误翻；翻牌动画期间忽略对**已翻开位**的点击；翻第一张后再点同一张 = 取消翻回（容错）；
- **手感细节**：
  - 配对成功：盒子微微震动 + 集藏册对应位 Bump 跳动 + 木琴和弦音；
  - 错配：盒盖合上"啪"声 + 邻牌"咯哒"轮转音 + 位移粒子轨迹；
  - **移动动画使用平移 + 短缓动**（200ms ease-out），不允许翻转，让玩家看清"谁去了哪"——位移动画若过快会让玩家失去追踪支点，破坏体验浸入；
  - 终局：集藏册全开 + 全场纸屑庆祝粒子 + 风铃旋律；
  - 全部判定静默处理，**严禁 `alert()` 报错**；`prefers-reduced-motion: reduce` 下位移瞬移降级。

### 3.3 模式与内容编排（**单人解谜向，拒绝"无尽冲分 + 每日"三件套**）

1. **盲盒闯关（Blind Box Campaign）**：**22 关 / 5 章**，章节递进按上表引入新机制。每关三星可累计：★ 总星数。本作核心单线模式，每章末"机制加深关"比每章首关难度跳 30%。
2. **每日盲盒（Daily Pop）**：每日固定种子生成 1 道残局，零错翻底线挑战（**全球同题比谁最少错**，本机纪录最少错数与用时）；与 `orbit-sort`、`jigsaw` 站内已有的"每日"调性相符。
3. **沙盒模式（Sandbox）**：起始即开放，自选行/列盘面（4×4 ~ 6×6）、自选位移强度（4 邻 / 8 邻 / 齿轮）、自选图腾集子集——**鼓励先到沙盒练手探机制，再进闯关冲星**；也适合好友轮流挑战自定盘面。
4. **不做**：无尽冲分、排行榜每日刷分、养成抽卡——单人解谜本就该有"想清楚再翻"的从容。

### 3.4 目标与评价体系（奖励"少错"，而非"快翻"）

- **三星评级（关卡结算）**：
  - ★ 错配 ≤ 1 次（前 4 章为"几乎零错"，第 5 章为"用满限定翻错次数内通关"）；
  - ★ 用时 ≤ 关卡阈值（前 4 章按 8/9/12/10 分钟，第 5 章每关独立阈值）；
  - ★ 连击 ≥ 2 次（≥ 1 次成功翻对后再次直接翻对）；
- **集藏册（Codex）**：每关结算解锁本章图腾（共 ~30 种潮玩公仔，配名称 + 简短设定），是本作唯一长线"收集"驱动，与"动态位移 = 短期记忆挑战"互补。
- **不计分**：不设"总分数排行榜"—解谜密度不能压缩为单维分数。
- **反馈仪式**：达标三星 = 集藏册翻页全开 + 风铃清音 + 纸屑庆祝；零错通关额外彩蛋"工坊大师印章"。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词

**潮玩盲盒工坊 · 咯哒车间**——糖果白 + 樱粉 / 治愈蜡笔 / 纸塑质感 / 木质传送带。

### 4.2 专属视窗物理隐喻（严禁套用左右双翼模版）

- **物理承载形态**：一张**潮玩工坊的木质传送带车间工作台**——
  - **主舞台 = 中央传送带卡牌区**：4×4 ~ 5×6 的盒子整齐排在工作台的卡位上；底部木板两侧有**滚轮导轨**视觉延伸（暗示"位置可推"），玩家翻错时邻位牌"咯哒"滑动一格，导轨微震；
  - **顶部状态栏 = 工坊操作台横梁**：内嵌"未配对图腾列表"（条形进度 + 当前章节名 + 关卡指示）+ 三个木质小按钮（暂停 / 重开 / 音效），不外置四角；
  - **左侧 = 集藏册 Codex 木抽屉**：抽屉挂在工作台侧板上，已配对的图腾从中央飞入抽屉对应位；抽屉伪 3D 推拉感，**不复用 duel 的"战利品宝箱 + SP 计量"**（亦不写 duel 的暗紫鎏金）；
  - **右侧 = 工坊日志小卡**：贴在工作台右侧的便签纸，记录本章新机制提示 + 当前错配次数 + 限定翻错预算（仅第 5 章显示），纸张折角微动；
  - **底部 = 移动端展示收纳的工坊车档**，桌面端为额外装饰花盆，确保**移动端 ≥68px 安全区**（`padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`）。
- **环境氛围**：动态米白 → 樱粉 → 嫩绿的暖色渐变背景，工坊梁上挂微动纸藤，**漂浮粒子是浮尘纸碎屑**（不是符文/星点，与 duel 区分）；舞台有微景深暗角，无死白大平铺。
- **盒子与图腾设计**：
  - 盒身：纸塑软胶质感、糖果色卡位（每对图腾卡的盒身色不同可选，但配对图腾同色），盒盖为可翻盖；
  - 盒内：~30 种潮玩公仔图腾，配对成对（章鱼博士、河狸弟、辣妹猫、积木哥、啃饭团的小恶魔…），软胶 Q 版造型；
  - **配对成功高亮禁止硬边描边圈**：用**无边界径向柔光**（樱粉 → 鹅黄 → 米白三段径向渐隐）脉动一次后入集藏册，与 duel 的鎏金径向光不撞色。
- **封面提案**（640×640，3D 软胶、零文字）：中央一只大号樱粉色盲盒半开盒盖，盒口探出一只章鱼博士 Q 版头与一只辣妹猫 Q 版耳朵（明显是要抢配对的两个图腾，互相张望）；盒侧一只工坊木质滚轮顺势转动；背景糖果米白 → 樱粉径向渐变 + 漂浮的纸碎屑粒子。

### 4.3 声效风格与材质音色规划（严禁千篇一律蜂鸣器）

| 事件          | 音色设计                                                    | 物理隐喻        |
| ----------- | ------------------------------------------------------- | ----------- |
| 翻开盒盖        | 短脉冲白噪 + BiquadFilter 高通 + 包络快速衰减（约 90ms）                | 纸盒盖弹开摩擦声    |
| 配对成功        | FM 三振荡器（4 倍频 + 5 倍频 + 主频）+ 慢 Attack 包络 + 木琴音色，每连击 +1 半音 | 治愈木琴"叮"     |

| **咯哒轮转**    | 4 邻每个邻位错位 30ms 的木质"咯哒"声，按顺时针方向依次响起，连成一串 4 声短踢           | 传送带齿轮推进的木格声 |
