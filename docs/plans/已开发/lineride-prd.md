## 1 · 创意概念与核心乐趣

- **游戏名称**：线之骑士 / **Line Ride** / 建议 slug：`lineride`
- **一句话玩法**：拿起蜡笔画出轨道，看雪橇小人在你画的山谷、回环与跳台上飞驰——每一笔都是你自己的过山车。
- **核心乐趣与卖点**：
  - **创造即游玩**：不需要传统游戏的目标与分数。画完线、按下播放、看着小人沿着你亲手画的轨道滑行、飞跃、翻滚——这个过程本身就是最纯粹的乐趣。玩家不是"闯关者"，玩家是"滑雪场设计师 + 第一观众"。
  - **物理沙盒的惊喜感**：重力、惯性、坡度、速度——全部实时模拟。你永远不知道下一笔会让小人是飞上天空还是摔进雪堆。正是这种"试试看会发生什么"的好奇心，驱动着无数玩家一画就是几个小时。
  - **从玩具到游戏的双模式**：纯创意沙盒（自由画布）满足无限想象力；拼图模式（修复残轨）则给需要目标的玩家一个"我必须让他安全抵达"的解谜驱动力。
  - **分享与炫耀**：完成一条惊艳的轨道后，截图或重播回放本身就是社交资本。Line Rider 在 2006 年靠 YouTube 传播获得 1500 万次观看——"看我画的轨道"是人类本能级别的分享冲动。
- **核心循环**：选择画笔 ➔ 在画布上绘制轨道 ➔ 按下播放 ➔ 观察物理滑行结果 ➔ 回到画布调整/完善 ➔ 满意后截图分享或挑战下一关。

- **成熟标杆原型**：2006 年斯洛文尼亚学生 Boštjan Čadež 创作的 Flash 物理沙盒 Line Rider——用鼠标画线，小人(Bosh)沿线条雪橇滑行，纯粹的重力+惯性物理模拟，无目标、无分数、无终点。上线 24 小时获 1 万次观看，数月内 YouTube 相关视频累计 1500 万次播放，被《Time》杂志报道，催生了 Wii/DS/PC 主机重制版和无数致敬作。
- **最受玩家认可的核心手感**：
  - 画线即轨道——任何年龄层都能在 3 秒内上手，10 秒内看到结果。
  - 物理反馈清晰可读——速度、惯性、抛物线的每一次变化都肉眼可见，不需要数字 UI。
  - 失败本身也是乐趣——小人飞出去、摔下来、"脸刹"都是笑点，不存在传统意义上的"Game Over 挫败感"。
- **我们要继承的成熟机制**：鼠标画线即轨道；重力+惯性+摩擦的简化但准确的物理模拟；多线型（蓝/红/绿/景）；播放/暂停/逐帧步进控制；撤销与擦除。
- **本作的独特魅力与微创新**：
  1. **冬日极光沉浸舞台**：原作是死白背景 + 黑线——在那个年代够用，但在 2026 年的 27 寸桌面上是灾难。我们采用**深蓝到紫罗兰的极光渐变背景、飘雪粒子浮动、松林剪影远景点缀**，让画布本身就是一个让人想待着的冬日世界。
  2. **拼图解谜模式**：30 关手工编排的"残轨谜题"——每一关给定一条不完整的轨道（有断裂缺口），玩家用有限画笔补全缺口，让小人安全抵达终点旗帜。这给了"需要目标"的玩家一个清爽的解谜驱动力，也是原作和所有竞品都没做透的空白。
  3. **融合式游戏机台 HUD**：把画笔切换、播放控制、关卡进度收纳进**一体化雪松木滑雪小屋面板**——不是网页的浮动按钮，而是一块嵌入画面的北欧风木质控制台。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**场景构成**
- 2D 侧视画布（横向无限滚动或固定宽幅），镜头跟随小人或静止全览。
- 画布默认尺寸：桌面端约 2400×1200 像素的虚拟滑雪场（画面视口约 1200×700 可滚动画布，支持缩放）。
- 物件：轨道线条（玩家绘制）、雪橇小人 Bosh（唯一运动主体）、起点旗帜、终点旗帜（拼图模式）、收集星标（可选）、布景线（纯装饰）。

**物理模型（简化但准确的刚体滑行）**

小人是一个在 2D 重力场中沿线条滑行的质点（带雪橇朝向旋转）：
- **重力**：恒定向下加速度 `g = 980 px/s²`。
- **线碰撞**：逐帧检测小人与轨道线段的最近距离，若 ≤ 接触阈值（8px，简化宽容判定），小人吸附到线上。
- **线上滑行**：速度沿线段切线方向分量保留，法向分量（垂直撞线）被吸收；沿切线方向的加速度由 `g·sin(θ)` 驱动（θ 为线段与水平面的夹角）——向下坡加速，上坡减速。
- **摩擦**：普通线摩擦系数 μ = 0.05；减速线（绿）μ = 0.25；加速线（红）额外施加一个沿切线方向的恒定推力。
- **空中阶段**：小人不接触任何线时，仅受重力——标准抛物线运动。
- **落地检测**：每帧检测小人与线的碰撞，若速度方向与线夹角过大（超过 80°），判定为"摔落"——小人翻滚脱落，播放跌倒动画，然后重置回最近安全点。
- **速度上限**：钳制最大速度防止穿模（约 2000 px/s）。

**线型系统**

| 线型 | 颜色 | 物理学特性 |
|---|---|---|
| 普通线 | 钴蓝 #4A90D9 | 标准摩擦 μ=0.05，可碰撞 |
| 加速线 | 暖橙 #E8734A | 标准摩擦 + 50 px/s² 额外推力 |
| 减速线 | 冰绿 #6BC4A6 | 高摩擦 μ=0.25，可碰撞 |
| 布景线 | 雪白半透明 rgba(255,255,255,0.35) | 无碰撞，纯装饰（画树、山、小屋） |

**玩家合法操作**
- **鼠标**：点击并拖动画线（按住左键画线，松开停止）；右键或点击已画线段选中后按 Delete/退格 擦除；滚轮缩放画布；中键拖拽平移画布。
- **触屏**：单指画线，双指缩放/平移。
- **键盘**：`1/2/3/4` 切换线型，`Space` 播放/暂停，`← →` 逐帧步进（暂停时），`Ctrl+Z` 撤销最后一笔，`Delete` 擦除选中线段，`R` 重置小人到起点，`+/-` 缩放。

**播放控制**
- **播放**：小人从画布上最近一次设置的"起点标记"出发（默认画布左上第一段线的起点），开始物理模拟。
- **暂停**：冻结物理，但保留画线能力——玩家可以在暂停时修轨道，再继续播放。
- **逐帧步进**：暂停后按 `← →` 单帧推进（固定步长 1/60 秒），供玩家精调轨道曲线。
- **重置**：小人回到起点，但轨道保留不变。
- **循环模式**：可选开关——小人滑出画布底部/边缘后自动回到起点重新出发（方便调试大回环轨道）。

**失败与容错**
- 小人摔落、飞出画布边界、或卡死在无法继续的轨道上 → 轻量"哎呀"反馈（小人翻个跟头爬起来），自动回到最近的安全接触点，或手动按 R 重置。
- **没有"Game Over"**：本作不存在失败画面或关卡重开——这是玩具，不是挑战。

### 3.2 操作与手感

- **画线手感**：线条采用 Catmull-Rom 或二次贝塞尔平滑，鼠标轨迹自动转为平滑曲线（采样间距约 8-12px），**绝不显示原始鼠标抖动的锯齿折线**。这是原作被玩家爱不释手的核心原因——蜡笔般顺滑。
- **线型切换视觉反馈**：切换画笔时，光标变为对应颜色的蜡笔/粉笔样式，当前选中线型的面板按钮高亮发光。
- **撤销**：Ctrl+Z 支持多步撤销（最多 50 步），撤销的是"上一段连续的画笔笔画"，而非单个点。
- **擦除精度**：橡皮擦光标是一个圆形区域（直径约 20px），擦除该区域内与光标相交的线段。
- **缩放与平移**：滚动缩放以鼠标位置为中心，平滑过渡。

### 3.3 模式与内容编排

Line Ride 的本质是创意玩具，**严禁套用"无尽冲分 + 每日挑战"**。我们只设两个模式：

**模式一：自由画布（Freestyle）**
- 无限画布，无目标，无计时，无分数。
- 默认提供四种画笔 + 橡皮擦 + 缩放平移。
- 支持保存草稿到 localStorage（自动保存 + 手动另存），最多保留 5 个画布槽位。
- 导出为 JSON 字符串（复制到剪贴板），方便分享。
- 导入 JSON 字符串恢复画布。
- 这是游戏的主体——让玩家沉浸在创作中，而不是被目标驱赶。

**模式二：拼图挑战（Puzzle）**
- 50 关手工编排的残轨谜题，每关展示一条不完整的轨道——有明显的断裂缺口，小人在缺口处会脱轨坠落。
- 关卡按难度递进五章，每章 10 关，新机制逐章解锁：
  - 第 1-10 关（新手坡道）：单一缺口，只需画一段补全线，熟悉基本画线操作。
  - 第 11-20 关（山间小径）：多缺口，需规划坡度与速度节奏。
  - 第 21-30 关（冰峰雪岭）：引入加速/减速线限制——有的缺口只能用指定线型。
  - 第 31-40 关（峡谷飞跃）：需要制造"空中抛物线"跨越无轨道区域。
  - 第 41-50 关（极光之巅）：大师级综合——大跨度飞行、精确落地、回环与多重翻转、线型组合。
- **评价**：每关三星评级——⭐ 安全抵达终点 / ⭐⭐ 收集全部星标 / ⭐⭐⭐ 在步数限制内完成（画笔笔画的段数）。
- 拼图模式中画笔有"可用线段总长度"限制（类似墨水配额），用完即止——迫使玩家精打细算。
- 通关后解锁下一关，已通关卡可重复挑战刷星。

### 3.4 游戏目标与反馈体系

- **自由画布**：无目标，无评价。唯一的"成就"是画出一条让自己满意的轨道。潜在的满足感来自：轨道越来越复杂、小人完成一次完美的大回环、截一张漂亮的图。
- **拼图模式**：三星通关 + 总星数收集。50 关 × 3 星 = 150 星，集齐一定数量解锁隐藏画笔皮肤（复古粉笔、霓虹笔、彩虹渐变笔——纯视觉彩蛋，不影响游戏性）。
- **胜利/达成瞬间反馈**：
  - 拼图通关：终点旗帜爆出彩色纸屑粒子 + 小人高举双手 + 星级弹入动效 + 清脆叮咚音效。
  - 自由画布：没有"胜利"——但第一次画出一个完美回环并看到小人平稳通过时，那种自我满足感比任何分数都真实。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：**北欧冬日极光**、**手绘蜡笔质感**、**松木滑雪小屋**、**温暖烛光风雪夜**。
- **游戏机台/沉浸舞台规划（严禁老旧网页排版病）**：

  **桌面端（≥900px）——极光滑雪场 + 松木控制台**
  - 核心画布占据屏幕中央约 75% 空间，边缘带柔和的暗角渐隐（vignette），让视线自然聚焦到画布中心。
  - 背景不是死白/死黑，而是一层**动态极光渐变**：深靛蓝（#1a1a3e）→ 紫罗兰（#2d1b69）→ 深松绿（#0d1b2a）自左上到右下渐变，带缓慢微动的极光光带波动（CSS 动画大背景层）。
  - 飘雪粒子：白色半透明圆点从画面上方缓缓飘落，大小不一，速度有快有慢，营造冬日雪夜氛围。
  - 画布底部：低多边形风格的松林剪影（深绿到墨绿），远处雪山轮廓——这些是纯布景，不在画布内，而是画布下方的环境装饰层。
  - **工具与播放控制台**：收纳在画布上方的一条**雪松木纹理横条**内——从左到右依次是：线型选择（四色粉笔图标按钮，当前选中带暖光高亮）、撤销/橡皮擦、播放/暂停/重置、缩放滑块、拼图模式关卡号与星级。不是浮动按钮，而是一整块有厚度、有木纹、有阴影的实体横条，像滑雪小屋墙上的工具架。
  - **右侧不堆卡片**：画布右侧不放置独立的"得分/信息/下一步"卡片。拼图模式的墨水配额与星标进度以**左上角小挂牌**（木质挂牌挂在画布左上角内）展示。自由画布模式右侧完全留空，让画布延伸到边缘。

  **移动端（≤768px）——掌上滑雪笔记本**
