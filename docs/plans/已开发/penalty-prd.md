## 1 · 创意概念与核心乐趣

- **游戏名称**：双人点球大战 / Penalty Shootout · Two-Player Penalty Duel / slug：`penalty`（单个简短纯英文单词）
- **一句话玩法**：双人攻防轮换射点球，预判扑救五轮定胜负。（19 字）
- **核心乐趣与卖点**：
  - **心理博弈的攻防轮换**：一方选角度抽射、一方预判扑救——射手在想「我往左下角射，他多半扑右边」，守门员在想「他上次射了左边，这次会不会还射左边」。每轮攻防互换，猜心思的乐趣远大于操作本身；
  - **五轮定胜负的仪式感**：照搬真实点球大战的五轮赛制，轮次越往后越紧张，决胜轮全场屏息，胜负一瞬间揭晓；
  - **角度+力度双选的抽射手感**：射手不只是选方向，还要选力度——大力抽射快但易飞出门框，轻推稳但易被扑，风险与收益自己拿捏。
- **核心循环**：射手选角度与力度 ➔ 守门员预判扑救方向 ➔ 射门动画揭晓（进球/扑出/打偏）➔ 攻防轮换 ➔ 五轮后进球多者胜 ➔ 再来一局。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **真实足球点球大战**：五轮轮换、突然死亡的赛制本身就是成熟到不需要解释的规则，玩家天然懂；
  - **FIFA 系列点球玩法**：成熟之处在于射手视角的瞄准圈+力度条、守门员的预判扑救、以及射门瞬间的镜头与音效仪式感。
- **我们要继承的成熟机制**：
  - 继承五轮轮换赛制：每方各射五轮（同屏双人时双方轮流当射手与守门员），五轮后进球多者胜，平局进入突然死亡；
  - 继承 FIFA 式瞄准模型：射手选角度（九宫格落点或自由瞄准）+ 力度条，守门员选扑救方向；
  - 继承揭晓仪式：射门动画、球网颤动、扑救飞身、比分牌更新。
- **本作的独特魅力与微创新（Twist）**：
  - **攻防轮换+心理博弈**：同一玩家一轮射门下一轮守门，刚才射手的心思立刻变成守门员的预判依据，博弈在两个人之间来回翻转；
  - **力度风险机制**：力度越大球速越快、守门员越难扑，但超出安全区有概率打偏出门框；力度越小越稳，但球速慢、守门员扑对方向必扑出；
  - **同屏双人保密选择**：同屏模式下射手与守门员先后选方向（选择阶段对方不可见、选完锁定），再同时揭晓，避免后选者占便宜。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：按查重底表（`GEM_INSTRUCTION-4.md` 第二节 100 款已上架清单，idiom 至 volley，储备清零）核对，与最接近的两款同属双人对战大类，但核心机制完全不同：
  - vs `pong`（街机乒乓）：`pong` 是挡板对攻的实时反应对战，核心是挡板移动拦截；本作是回合制攻防轮换+心理博弈，无挡板、无实时拦截，每轮一次射门一次扑救，节奏与胜负判定都不同；
  - vs `volley`（隔山打牛）：`volley` 是抛物轰炸堡垒，核心是抛物线角度与破坏；本作无抛物轰炸、无堡垒破坏，是点球九宫格落点预判，射手与守门员各选一次方向同时揭晓；
  - 只堵规则几乎一模一样的换皮，本作规则模型不同，可以立项。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - 盘面构成：一座球门正视图——门框、球网、守门员站位、点球点与足球；球门区域按九宫格划分为 9 个落点区（左上/中上/右上/左中/中中/右中/左下/中下/右下）；
  - 合法操作（每轮两步）：第一步射手选落点区（点选九宫格之一）并蓄力选力度（力度条三档：轻推/抽射/爆射，爆射有打偏概率）；第二步守门员选扑救方向（左/中/右三方向，或九宫格扑救区，见拍板项）；双方选择互不可见（同屏双人时先后选、选完锁定遮蔽），选完后同时揭晓，播放射门动画；
  - 判定规则：射门落点区与守门员扑救区重合（或扑救方向覆盖落点）且球速不超守门员扑救上限 → 扑出；落点区未被扑救覆盖 → 进球；爆射力度触发打偏 → 球飞出门框，不进球也不算扑出；轻推力度球速慢，守门员扑对方向必扑出、扑错方向必进球；
  - 胜利条件：五轮（每方各射五轮）结束后进球多者胜；平局进入突然死亡：一轮一射，先进球而对方未进者立即获胜；
  - 失败条件：五轮后进球少者负；突然死亡中对方进球而本方未进则负；
  - 容错与无死局说明：本作无随机生成关卡，赛制固定、判定规则全确定性（爆射打偏概率为固定数值且界面明示），不存在死局；平局有突然死亡兜底，保证每局必有胜负。
- **操作与手感**：
  - 鼠标/触控：点选九宫格落点区，按住射门键蓄力、松手定力度；守门员点选扑救方向区；
  - 键盘支持：数字键 1–9 对应九宫格落点，空格按住蓄力松手定力度，方向键选扑救方向，Enter 确认；
  - **随时可暂停与失焦保护机制（回合制但含射门动画计时，须有暂停/冻结）**：
    - *暂停/继续实体按钮*：顶栏常驻醒目的「暂停 / 继续」（Pause / Resume）按钮；
    - *暂停快捷键*：`P` 键、`Esc` 键即时切换暂停与继续；
    - *暂停视觉反馈*：选择阶段暂停时冻结选择计时（如有）并展示轻量半透明覆盖层（显示「已暂停 / PAUSED」，提供「继续」「重新开局」入口）；射门动画播放中暂停则动画冻结在当前帧（球与守门员定格），继续后从冻结帧续播，不跳帧、不重播；
    - *切后台自动暂停（Visibility Auto-Pause）*：切标签页、最小化窗口或失焦时自动静默暂停——选择阶段冻结、动画阶段定格，回来继续，不会偷偷射完一轮；
  - 误触容错与操作缓冲：选择阶段选定后有 0.5 秒确认窗可改选，锁定后不可更改；动画播放中屏蔽一切输入防误触；同屏双人时先选者锁定后选择内容自动遮蔽，后选者看不到。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - **首屏秒进对局**：初次打开直接呈现就绪盘面——默认单人对 AI（新手档）开局，球门与点球点已就绪、轮到玩家射第一轮，无需前置点击即可选落点抽射；
  - **常驻显眼模式入口**：界面显眼处常驻醒目的「模式」按钮（单人对 AI 三档 / 同屏双人），点击以轻量抽屉或非阻塞弹层切换；结算面板提供「再来一局」与「模式」；
  - **严禁强制全屏遮罩阻塞首屏**：不可设计一进网页就弹全屏选模式大遮罩的反直觉流程。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **严禁无脑套用“无尽冲分 + 每日挑战”**：本作不设无尽冲分、不设每日挑战，模式只服务于点球对决本身；
  - 模式一「单人对 AI」：三档难度——新手（AI 扑救随机、射门落点集中）、进阶（AI 会记玩家习惯落点并偏向扑救）、大师（AI 扑救近乎预判、射门落点刁钻且力度多变）；玩家每轮攻防轮换，先后手可选；
  - 模式二「同屏双人」：两人同屏轮流当射手与守门员，先后保密选择、同时揭晓，五轮定胜负，适合当面心理战；
  - 赛制固定五轮+突然死亡，不做关卡制、不做积分榜。
- **游戏目标与反馈体系**：
  - 核心目标指标：五轮进球数（比分牌实时更新，进球圆点/扑出叉号逐轮点亮），不看总分；
  - 胜利/阶段达成时的沉浸反馈仪式：决胜轮进球时球网剧烈颤动、全场欢呼音效、比分牌定格、胜者横幅升起；扑出决胜球时守门员飞身扑救定格慢动作，结算面板显示逐轮结果与胜者。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 核心模式名中英对照：单人对 AI Solo vs AI / 同屏双人 Two Players (Same Screen)；
  - 难度名中英对照：新手 Novice / 进阶 Skilled / 大师 Master；
  - 核心实体中英对照：射手 Shooter / 守门员 Goalkeeper / 落点区 Target Zone / 力度 Power / 轻推 Tap / 抽射 Drive / 爆射 Blast / 扑救 Save / 进球 Goal / 打偏 Wide / 突然死亡 Sudden Death；
  - 数据层设计约束：所有模式、难度、落点区数据一律使用字符串 key 或 id（如 `mode_solo`、`ai_novice`、`zone_top_left`），展示层通过 `i18n` 获取文本，严禁在数据文件中裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：球门正视图、点球点、球网颤动、夜场灯光、决胜屏息。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 物理承载形态：一座夜场球门正视图——盘面就是从点球点望向球门的视角，门框与球网占满舞台，守门员站在门线中央，点球点与足球在画面下方前景；整个游戏就是「站在点球点前看球门」，视窗即射手视角本身；
  - **严禁直接照搬已有游戏结构**：绝对禁止不分题材一律机械切成“左翼卡片 + 中间视窗 + 右翼卡片”的三栏套路；本作是单座球门一体舞台，比分牌与轮次收进球门上方的横梁托盘，无左右双翼；
  - 严禁四角散落浮动按钮；严禁右侧机械堆叠白底/灰底 SaaS 表单卡片；
  - 保持全站一致的沉浸暗色底蕴与实体微质感：夜场暗色背景衬球门灯光，草皮与球网质感做足，不过分花里胡哨。
- **立体质感与渲染路线裁决**：
  - 裁决：DOM + CSS 3D 为主、Canvas 2D 辅助（95% 优先路线）。球门、守门员、足球用 DOM 语义元素 + CSS 3D 透视实现射手视角纵深，射门动画与球网颤动用 Canvas 2D 或 CSS 动画；秒开、零加载、零发热；
  - 本作不尝试 Three.js：固定射手视角无需真三维空间自由翻转，不触发三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层）相关裁决；UI/HUD 全部在 DOM 层。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 6 种有材质感的声音，拒绝单音蜂鸣：
  1. **助跑脚步声**（射手起脚前）：草皮上的短促脚步噪声；
  2. **抽射击球声**（射门瞬间）：皮球被脚背抽中的闷响，低频冲击 + 皮革质感；
  3. **球网颤动声**（进球）：球撞进网窝的网绳摩擦声 + 网体晃动余音；
  4. **扑救拍球声**（扑出）：手套拍中皮球的脆响 + 球被拍飞的呼啸；
  5. **打偏呼啸声**（爆射打偏）：球擦过门框飞向看台的呼啸声；
  6. **全场欢呼/叹息声**（决胜揭晓）：进球时欢呼声浪、扑出时叹息声浪，噪声滤波合成人群声。
- **封面设计提案**：
  - 遵循 3D 软胶质感、单一居中主体（60-75% 无文字）、鲜艳渐变背景：一只软胶质感的足球正飞向球门左上角、守门员飞身扑救，背景为夜场深蓝到草绿的渐变。

## 6 · 制作人拍板与开放探讨

列出 3 个关于玩法变体、关卡节奏或美术特色的好玩选项，供制作人（用户）快速拍板决断：

1. **守门员扑救粒度**：方案 A 九宫格扑救区（推荐，与射手落点一一对应、预判更细）；方案 B 左/中/右三方向扑救（更简单好懂，但中路落点几乎必被扑、博弈变粗）。
2. **射手瞄准方式**：方案 A 九宫格点选落点（推荐，与扑救区对齐、判定最清晰）；方案 B 自由瞄准圈+力度条（FIFA 味更浓，但判定边界模糊、同屏保密更难做）。
3. **AI 难度档位**：方案 A 三档（新手/进阶/大师，推荐，阶梯完整）；方案 B 两档（简单/困难，开发量小，但中间档玩家无处安放）。
