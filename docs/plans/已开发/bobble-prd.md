## 1 · 创意概念与核心乐趣

- **游戏名称**：泡泡射手 / Aurora Ice · Bobble / 建议 slug：`bobble`（备选 `bubble-shooter`）
- **一句话玩法**：操控冰窟底部的棱镜炮台，把彩泡打上层层冻结的冰盖，凑齐同色三连爆开、斩断支撑柱让整片冰塔雪崩坠落，在冰层压到冰封线之前凿穿全部关卡！
- **核心乐趣与卖点**：
  - **打不准的乐趣，一半在"算"（Geometry Puzzle）**：炮台只能转角度、不能调力度——这唯一的约束把简单的配色消除变成了几何题。直线打不进去的位置，就要靠侧墙镜面反弹绕进凹角；这是本作最硬核也最上瘾的技巧。
  - **打支撑，不打表面（Cut the Stem）**：新手消正面，高手消"柱子"。识别那一颗托着一大片的支撑泡，把它打掉，二十多颗泡瞬间失联坠落——一颗子弹换半屏清空，是这个品类最大的爽点爆发，本作把它做成核心教程与核心计分。
  - **雪崩连锁（Avalanche Chain）**：单次射击造成的「爆开 + 坠落」合并计一次连锁，连锁数越多，坠落分按几何级数飙升，屏幕震、冰屑飞、音效逐级升调，形成"越打越上头"的正反馈。
  - **冰层下压的窒息感（Creeping Freeze）**：每发射若干颗，顶部冰盖整体下沉一行，低频"咔哒"金属音 + 全屏微震。玩家能亲眼看见死亡线一点点逼近，而浪费的每一发都会把冰盖再压低一格——失误的成本是可见、可感、复利累积的。
  - **残局式解谜（One-Shot Puzzle）**：除了闯关与无尽，本作提供"限定 1~3 发必须凿穿"的残局题板，把品类从"休闲消消乐"抬升到"一击断柱"的纯智力挑战。
- **核心循环**：
  ```
  读盘面（找支撑柱 / 找同色堆 / 找反弹通道）
      ➔ 转炮台（鼠标拖拽 / 方向键微调 / 触屏划动）+ 预测线预览落点
      ➔ 发射：飞泡撞墙反弹 → 吸附落格
           ├─ 凑齐三连 → 爆开 → 悬空簇雪崩坠落 → 连锁计分 + 震屏
           └─ 未凑齐 → 泡留在盘上（盘面变大，浪费一发）
      ↑                                                      ↓
  每 N 发冰盖下压一行（现存颜色越少下压越快）  ←  危险：任一颗泡触及冰封线
      ↓ (清光全盘 / 凿穿目标 / 冰层触线)
  星级结算（按用弹数评三星）➔ 解锁下一关 / 刷新记录
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Puzzle Bobble / Bust-A-Move (Taito 1994)** | 街机/主机 | 8 列错位六边形、底炮旋转、三连消、悬空坠落、天花板按发数下压 | 定义了整个品类；"打支撑柱"是史上最优雅的爽点设计之一；无时钟压力，压力全靠发数计数器 | 错位六边形网格、镜面反弹、悬空簇坠落计分（20/40/80 翻倍）、按发数下压、下一颗预览 | 原版像素风过于复古；8 色后期过难；无落点预测线（新手门槛高） |
| **Bust-A-Move 现代版 / Puzzle Bobble 3D** | 主机/手游 | 加入彩虹泡、炸弹泡、双人对战送泡 | 特殊泡给解围手段，降低挫败 | 彩虹泡（万能色）与炸弹泡作为救急道具 | 对战送泡模式在单人网页端无意义，不做 |
| **Arkadium / Silvergames 系现代网页泡泡龙** | Web | 完整虚线瞄准轨迹、过关目标多样、连击特效 | 预测线极大降低门槛；关卡目标（救小动物 / 限时 / 限步）丰富 | **完整反弹预测线 + 落点幽灵泡**（本作保留并可分级关闭）；多样化关卡目标 | 弹窗广告与体力限制；盘面配色刺眼廉价 |
| **祖玛 Zuma（平台内 `zuma` 对照）** | 街机/PC | 轨道推进、同色三连、倒退奖励 | 连锁手感 | 连锁计分与音效升调的表现手法 | **二者本质不同**：祖玛是轨道推进 + 时间压力；本作是自底向上抛物反弹 + 发数压力，**不做时间条** |
| **Sea Bubble Pirates / Hex Candy Crackle** | Web | 结构化盘面（有弱点的形状）、六边形邻接 | 盘面形状设计本身就是关卡设计 | 手工设计"有结构弱点"的盘面（双塔、拱桥、倒锥、悬垂柱） | 纯随机均匀墙缺乏设计感 |

**我们要继承的成熟机制**：
1. **错位六边形网格（Offset Hex Grid）**：8 列，奇数行 8 格、偶数行 7 格并右移半格；相邻关系为经典 6 邻域。这是品类 30 年验证过的手感基石，**不自创网格**。
2. **镜面反弹（Mirror Bank Shot）**：左右内壁完美反射，可连续反弹（上限 8 次防极端死循环），顶部冰盖为吸附面不反弹。
3. **悬空簇坠落（Orphan Drop）**：每次消除后从顶行做一次连通性 flood fill，凡无法回溯到顶行的泡整簇坠落，并按几何级数计分（远高于直接消除分）。
4. **按发数下压 + 颜色数联动（Color-Linked Press）**：基础每 8 发下压一行，场上现存每消失一种颜色，间隔减 1 发（最低 4 发）——这是原版隐藏的精妙平衡：盘面越干净压迫越快，鼓励玩家速战速决。
5. **颜色抽取保证（No Dead Color）**：发射泡颜色**只从场上仍存在的颜色中抽取**，盘面清空某色后该色不再出现。这条是品类"绝不发死牌"的黄金规则，直接杜绝死局。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **三档瞄准辅助（Aim Assist Tiers）**：
   - *Classic*：仅显示短虚线（约 40% 长度），还原街机原味；
   - *Extended（默认）*：完整轨迹 + 1~2 次反弹 + 落点处显示半透明"幽灵泡"预览，新手 10 秒上手；
   - *Pro*：完全关闭预测线，仅保留炮口方向指示，通关结算带 **×1.15 硬核加成**。
   预测线不是"降低难度"，而是"让几何思考可视化"——这是本作对现代网页版最重要的继承与升级。
2. **冰镐弹（Ice Pick）限量化穿透道具**：
   - 每关限量 1~2 发，发射后沿轨迹直线穿透 3 格，凿碎路径上的泡（不计消除、不掉落），专门用于**打开被封死的反弹通道**。它不帮你得分，只帮你"开路"，是策略资源而非数值外挂。
3. **断柱残局模式（One-Shot Puzzle）**：
   - 固定题板 + 限定 1~3 发，目标不是清盘而是"斩断指定支撑柱，让标记冰晶坠落"。这是把品类核心技巧（打支撑 + 反弹）提炼成纯解谜关卡，市面上网页版几乎不做，是本作最鲜明的记忆点。
4. **冰层叙事化的压迫机制**：
   - 下压的不是抽象天花板，而是**冰盖（Ice Sheet）**；危险线是**冰封线（Freeze Line）**，越接近时冰面越亮、霜纹从两侧向中间蔓延（径向柔光渐隐，禁用描边圈），配合低频"咔哒"与轻微画面抖动，把"还剩几发就死"变成看得见的生理紧张。
5. **竖版对称机台的双舷窗布局**（见 §4.2）：不照搬网页版"中间一堆 + 右上角小图标"，而是做成潜水/科考舱的左右舷窗信息面板，舞台居中。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素
- **冰窟舞台（Ice Chamber）**：竖版 9:16 舞台，8 列错位六边形网格，可见 11 行 + 顶部冰盖。
- **棱镜炮台（Prism Cannon）**：舞台底部中央，可左右旋转（角度范围 ±80°，即不朝下打），炮身随角度微微俯仰，发射瞬间有后坐下沉与冰晶口焰。
- **当前泡 / 待发射泡（Loaded / Next）**：炮口内为当前泡，炮台右侧槽位显示下一颗（可交换）。
- **冰盖与冰封线（Ice Sheet / Freeze Line）**：顶部冰盖整体代表"已下压行数"，舞台下方 1 行处为红色柔光冰封线，任一颗泡吸附后触及即判负。
- **发数计数器（Shot Counter）**：显示"距下次下压还有 N 发"，数字随倒数递减，≤2 时冰盖泛起裂纹预警。
- **特殊泡**：
  - *棱镜泡 Prism Bubble*（万能色，可充当任意颜色完成三连）；
  - *冰镐弹 Ice Pick*（穿透凿路，限量）；
  - 二者均不计入常规颜色池，不影响"现存颜色数"判定。

### 3.2 基本规则
1. **发射与吸附**：发射后泡沿直线飞行，撞左右内壁镜面反弹（最多 8 次），触碰任意已存在泡或顶部冰盖时停止，并吸附到**离碰撞点最近的空格位**。
2. **三连消除**：吸附后若与同色相邻泡连通成 ≥3 颗，整组爆开（每颗 10 分）；组越大分越高、爆开特效越夸张。
3. **雪崩坠落**：消除后从顶行做连通性判定，所有无法连回顶行的泡整簇坠落。坠落计分沿用经典几何级数：第 1 颗 20 分，之后每颗翻倍（2 颗 40、3 颗 80……设置单发上限封顶，避免分数爆炸失衡）。
4. **连锁（Chain）**：单次射击「爆开数 + 坠落数」合计 ≥5 触发 *AVALANCHE* 播报与强震屏；连续多发射击均有消除累积 *Combo Streak* 倍率（×1.2 → ×1.5 → ×2.0，上限 ×3），落空清空倍率。
5. **冰盖下压**：每累计 N 发（N = 8 − 已消失颜色数，下限 4）冰盖下压一行，顶部补入新行；下压瞬间全屏微震 + 低频咔哒。
6. **失败判定**：任一颗泡在吸附/下压后触及冰封线 → 本局结束（闯关模式可原地重试，不惩罚）。
7. **胜利判定**：
   - 闯关：清空全盘 / 达成关卡目标（见 §3.3）；
   - 无尽：撑到冰层触线，比拼生存发数与最大连锁；
   - 残局：在限定发数内斩断目标支撑柱。

### 3.3 模式编排（拒绝千篇一律的"无尽冲分 + 每日挑战"套娃）

1. **冰层攀登（Ice Ascent · 核心闯关，30 关）**：
   - 3 章 × 10 关：*浅冰层 Shallow Ice*（4~5 色，教学断柱与反弹）→ *深蓝渊 Deep Blue*（5~6 色，结构盘面）→ *极光核 Aurora Core*（6 色 + 限量道具 + 复杂空心结构）；
   - 每关给定**目标发数**，按实际用弹数评星：≤ 目标 = ★★★，≤ 目标 + 4 = ★★，通关 = ★；
   - 每章第 10 关为 **Boss 盘面**：巨大悬垂冰塔（如倒锥、双塔连桥、环形拱），必须靠 2 次以上反弹或精准断柱才能拆掉，通关解锁下一章。
2. **断柱残局（One-Shot Puzzle · 差异化招牌模式）**：
   - 固定题板 + 限定 1~3 发，目标为"斩断标记支撑柱，让目标冰晶坠落"；
   - 手工设计 24 题，难度递进（第 1~8 题教反弹，第 9~16 题教断柱，第 17~24 题为复合双段反弹）；
   - 无计分、无下压，纯智力解谜，通关记录以"解锁题数"呈现。
3. **无尽寒潮（Deep Freeze · 生存模式）**：
   - 单盘无尽，起始 6 行 4 色，每 8 发下压一行并顶部补行，颜色数随进度递增至 6 色；
   - 不比分数比**生存发数（Shots Survived）**与**最大连锁（Max Chain）**，本地记录两项个人最佳；
   - 濒死救援：冰层触线前最后 1 行自动补发一颗棱镜泡作为"绝境补给"，保证局面永远有解，杜绝纯运气死。
4. **每日残局（Daily Board · 每日固定题板）**：
   - 以当日日期为 PRNG 种子生成唯一题板（全球同一盘面），比拼**通关用弹数**与**最大连锁**；
   - 同一天可无限重试，只记录当日最佳；**不做体力、不做连续打卡奖励**。

### 3.4 计分体系（唯一口径）
- 爆开：10 分/颗；坠落：20 × 2^(n−1)（单发封顶 ×1024 档位，防止数值失控）；
- Combo Streak 倍率 ×1.2 / ×1.5 / ×2.0 / ×3.0（上限）作用于本发总分；
- Pro 瞄准档全局 ×1.15 硬核加成；
- **闯关模式评价体系为星级（用弹数），不是分数**——分数只在无尽与每日残局中作为辅助展示。

### 3.5 手感调优与操作映射（键鼠触全通）
- **鼠标（桌面主操作）**：鼠标在舞台内移动，炮口实时跟随指向（带轻微阻尼，禁止瞬移抖动）；左键发射，右键换弹（Swap）。
- **键盘**：`←` / `→` 每次 ±1° 微调，`Shift` + 方向键 ±0.2° 精调，`空格` / `↑` 发射，`S` 换弹，`P` 暂停，`R` 重开本关。
- **触屏（移动主操作）**：手指在舞台任意位置拖拽，炮台实时跟随手指方向并同步显示完整预测线，**抬起手指即发射**；拖到舞台外（取消区）松手则取消本次瞄准；无需精细点击，手感与鼠标一致。
- **Swap 换弹**：当前泡与待发射泡交换，无限次可用（现代休闲友好），但仅能交换已给出的两颗，不改变随机序列。
- **输入缓冲**：飞泡在途时禁止再次发射，但允许预输入（记录瞄准角度与换弹意图，落地后立即生效）；飞泡最长飞行时间设上限（1.2s）超时强制吸附，杜绝卡帧。
- **发射物理**：固定速度 + 固定子步长（1/120s）推进，逐步做圆-圆碰撞与墙面检测，杜绝高速穿模。

### 3.6 无死局与可解性保证（硬性）
1. **颜色池约束**：发射泡颜色**只从场上仍存在的颜色中抽取**；某色清空后从池中移除。永远不会出现"给你一颗场上没有的颜色"。
2. **盘面生成校验**：闯关/每日题板采用「手工形状模板（柱、塔、拱、锥、环）× 种子化配色」生成，生成后立即跑**启发式求解器**验证：枚举全角度采样（每 1°）× 落点模拟，做深度 3 步的贪心搜索，若在「目标发数 + 宽容值」内可达成目标则通过；不通过则换种子重试（上限 200 次），仍失败则回落到**人工验证过的静态盘面**。
3. **下压不会制造必死**：下压只补顶行，不压缩已有泡；若下压后最低泡已触及冰封线，则先触发"绝境补给"（棱镜泡）并延后一发判定，给玩家一次翻盘窗口。
4. **随机游走验证**：开发端须跑 ≥1000 步随机合法射击，断言状态机不抛错、不卡死、不变式守恒（泡总数 = 盘面 + 在途 + 待发射；颜色池 ⊆ 盘面色集合）。

## 4 · 美术风格与视觉氛围

### 4.1 题材与视觉关键词
- **主推题材：极光冰窟（Aurora Ice）** —— 冰洞、极光帷幕、霜纹、悬浮冰晶微粒；
- 泡泡本体是**冻结在冰层里的气泡 / 冰晶球**：软胶高光 + 内部通透折射 + 底部内发光，六色标准盘：冰蓝（Ice Blue）、极光绿（Aurora Green）、珊瑚橙（Coral）、紫晶（Amethyst）、柠黄（Citrus）、玫粉（Rose）——**六色必须色盲可辨（形状辅助：每种色配一个内部微符号，可在无障碍开关中开启）**；
- 发射器是**棱镜炮台 / 冰镐探测器**，基座为黄铜+冰晶混搭的科考机械；
- 环境：深靛蓝 → 墨蓝的垂直渐变，顶部缓慢流动的极光帷幕（低频正弦位移），舞台内缓慢上浮的细小气泡微粒，两侧冰壁的柔光反射。

### 4.3 音效规划（WebAudio 纯程序化合成，零外部音频文件）
- **发射**：短促上滑正弦（Peoo），带轻微气声；
- **撞墙反弹**：清脆高频短音（Tick），音高随反弹次数递减；
- **吸附落位**：柔和的低频"啵"（Pop-lock）；
- **三连爆开**：明亮琶音，音高随连锁数逐级升半音（连击越高越亢奋）；
- **雪崩坠落**：下滑扫频 + 冰碎白噪音（Crash），坠落泡数越多尾音越长；

- **失败**：冰层封冻的下行三音；
- **过关三星**：极光风格的大三和弦琶音。

### 4.4 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体占画面 65%~70%——一枚悬浮的通透冰晶软胶气泡（青绿主色 + 紫晶折射高光），正从下方黄铜棱镜炮口被射出，尾部拖着半透明冰晶轨迹；
- **背景与氛围**：墨蓝 → 极光紫的平滑径向渐变，顶部一抹极光帷幕，四周漂浮细小冰晶微粒与虚焦光斑；
- **色相选择**：极光紫青（平台内尚未占用），与 `bubble-merge` / `bubble-bloom` 的暖色系明确区分。

### 4.5 无障碍与降级
- `@media (prefers-reduced-motion: reduce)`：所有粒子、震屏、下压缓动改为瞬移或极短过渡，**游戏功能本体全部保留**；
- 色盲辅助开关：六色泡泡内部叠加可选微符号（圆点 / 三角 / 方 / 星 / 环 / 十字）；
- 舞台声明 `touch-action: none` 与 `overscroll-behavior: none`，防拖拽误触页面滚动。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 项进行拍板定夺：

### 拍板项 1：模式组合的主次（决定开发量）
- **选项 A（推荐）**：「冰层攀登 30 关闯关」为绝对核心 + 「断柱残局 24 题」为差异化招牌 + 「无尽寒潮」与「每日残局」各占一小块入口。四个模式共用同一套引擎，开发量可控且内容厚实。
- **选项 B（精简）**：只做「冰层攀登 30 关」+「无尽寒潮」，砍掉残局与每日模式，最快上线。
- **选项 C（解谜向）**：以「断柱残局」为主（60 题纯解谜），闯关只做 12 关教学，把品类做成硬核解谜作。

### 拍板项 2：瞄准辅助的默认档位
- **选项 A（推荐）**：默认 *Extended*（完整轨迹 + 反弹 + 落点幽灵泡），保留 *Classic* 与 *Pro* 可切换，Pro 档给 ×1.15 加成。新手 10 秒上手，硬核玩家有加成分。
- **选项 B（街机原味）**：默认 *Classic*（短虚线），强化原版"自己算"的乐趣，但移动端新玩家流失率会明显上升。

### 拍板项 3：美术题材与 slug 定名
- **题材 A（推荐）**：**极光冰窟 Aurora Ice** —— 冷色系 + 极光帷幕，色相在平台内未被占用，与已有的 `bubble-merge` / `bubble-bloom` 暖色系完全区分，软胶通透质感最强。
- **题材 B**：**深海霓虹 Abyss Glow** —— 深蓝 + 水母荧光，氛围更梦幻，但与 `deep-devour`（深海题材）有轻微调性重叠。
- **slug A（推荐）**：**`bobble`** —— 单词、简短、致敬 Puzzle Bobble，不与 `bubble-merge` / `bubble-bloom` 混淆。
- **slug B**：**`bubble-shooter`** —— 品类直白、SEO 友好，但为双词连字符，与平台"优先单词"命名契约略有出入。
