## 1 · 创意概念与核心乐趣

- **游戏名称**：拧螺丝解谜 / Screw Jam / 建议 slug：`screw`（备选 `screw-jam`）
- **一句话玩法**：转出固定面板的彩色螺栓送入对应零件盒，让交错重叠的亚克力板在重力下痛快滑落，拆空整个机械装置！
- **核心乐趣与卖点**：
  - **2024~2026 全球超休闲顶级现象级品类（Top Global Hyper-Casual Hit）**：
    同类海外标杆作品安装量破千万、评分 4.8 霸榜全球。机制全站零覆盖！这是现代休闲玩家最无法抗拒的“拆卸解压 + 配色归位”双重多巴胺风暴；
  - **骨牌般的物理重力连锁坠落（Gravity Falling Chain Reaction）**：
    当最后一把螺栓被拧出，失去支撑的透明板材瞬间“呼啦”一声在真实重力加速度下倾泻坠出屏幕，露出原本被死死遮挡的底层螺孔与核心装置，带来无与伦比的视觉解压与爽快感；
  - **★ 纯净零广告重构，彻底剔除逼氪买孔痛点（Zero Ads Pure Craftsmanship）**：
    商业手游版最令人厌恶的痛点就是“故意设计死局逼玩家看 30 秒广告买额外孔位”。本作坚持纯粹的数学解谜本质——所有关卡均经过严密的拓扑排序校验，100% 逻辑可解，零广告、零体力限制、清爽通关；
  - **极度舒适的 ASMR 螺纹手感与单手操作（Acoustic ASMR Screwing）**：
    指尖轻点即可完成螺栓的高速旋转退出（发出细密真实的“滋滋——咔哒”螺纹咬合声），飞入收纳盒发出清脆塑料碰撞音，天然契合移动端单手操作，桌面端光标点选行云流水。
- **核心循环**：
  ```
  观察交错面板的固定螺栓与当前收纳盒颜色 → 点击未被遮挡的可用螺栓
       ↑                                                      ↓
  下一关卡 / 拆空整个装置 ← 对应板材失去固定在重力下脱落坠下 ← 螺栓旋转飞入匹配收纳盒 / 备用孔暂存
       ↓ (备用孔位被占满且无对应收纳盒)
  死锁卡住 → 随时【Z】键无限步撤销 / 0.1s 极速重试当前关卡
  ```

**我们要借鉴的成熟机制**：
1. **拓扑层级遮挡不变量（Z-Index Occlusion Invariant）**：
   - 每块面板具有空间几何轮廓与 Z 轴深度；
   - 螺栓只有在**不被任何更高层面板完全遮挡螺帽**时，才处于“可点击激活态”；部分被遮挡或被夹在两层中间的螺栓处于锁定半透明态，必须先拆除上层面板才能露出；
2. **三色收纳盒传送带（3-Slot Color Box Conveyor）**：
   - 顶部常驻当前等待收集的颜色收纳盒（每盒需收集 3 颗同色螺栓）；
   - 满足 3 颗后，收纳盒打包装箱滑出，传送带平滑推入下一个颜色的新盒子；
3. **有限备用暂存孔（Buffer Slots）**：
   - 台面上设置 3~4 个空螺孔作为调度中转站。玩家可将暂时无对应盒子的螺栓拧下放入中转孔，解开上方压着的面板；中转孔中的螺栓在匹配盒子出现时会自动吸入。

**本作的差异化微创新（拒绝无聊与逼氪）**：
1. **真实物理单摆动态铰链（Physics Hinge Pendulum）**：
   - 当一块板原先被两颗螺栓固定时保持绝对静止；一旦其中一颗被拧下，该板**瞬间化作以剩下的那颗螺栓为支点的单摆**，在重力与角动量作用下自然下垂晃动，不仅极具玩具质感，更能因摆动而意外露出原本被盖住的死角螺孔！
2. **21 关五大主题工坊篇章（4/5/4/5/3 梯度结构）**：
   - 从原木拼图、彩虹亚克力、工业金属板，到精巧的霓虹发光齿轮与立体艺术悬挂件，每一章都拥有独特的材质碰撞质感；
3. **桌面微缩五金工坊美学（Diorama Hardware Workshop）**：
   - 将整面拆解墙置于一张深色五金匠人工作台上，螺栓带有清晰的十字槽与金属反光，掉落的板材撞在底座海绵垫上发出真实的碰撞闷响。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与物理构成**：
  - **背景安装背板（Pegboard）**：固定有若干打孔位，作为螺栓的旋入锚点；
  - **悬挂面板组件（Plates）**：
    - 具有不同形状（长条形、L形、十字形、齿轮形）与材质（木纹、亚克力、铝合金）；
    - 面板上开有固定孔，螺栓穿过孔洞旋入背板；
  - **彩色螺栓（Screws）**：
    - 区分颜色（红、黄、蓝、绿、紫等）；
    - 状态机：【紧固锁定】➔【旋转旋出】➔【飞入收纳盒】或【移入备用孔】；
  - **顶部收纳盒传送带（Top Toolboxes）**：
    - 展示当前正在收集的收纳盒（带当前颜色与剩余空位，如 `红: 1/3`）；
  - **底部备用中转孔（Buffer Holes）**：
    - 固定配置 3 个空螺栓插槽（可升级关卡为 4 个）。
- **玩家合法操作**：
  1. **点击拧下螺栓（Tap to Unscrew）**：
     - 点击任何未被遮挡的螺栓：
       - 若顶部当前收纳盒有其同色空位：螺栓瞬间高速旋转拔出，划出弧线飞入盒子，槽位 +1；
       - 若无对应盒子，但底部备用孔有空位：螺栓飞入备用孔旋紧暂存；
       - 若备用孔全满且无对应盒子：螺栓轻微晃动并发出“阻抗拒止”声，不可操作；
  2. **备用孔自动清算（Auto Box Inflow）**：
     - 当收纳盒换入新颜色时，底部备用孔中若有匹配颜色的螺栓，立即自动依次飞入收纳盒；
  3. **无限悔棋撤销（Instant Undo）**：
     - 按键【Z】或点击左侧“撤销”按钮：无限制单步倒退，螺栓飞回原孔，面板重新挂起，试错零成本；
  4. **面板物理脱落判定**：
     - 当固定某块面板的最后一颗螺栓被拧走，该面板瞬间脱离约束，重力加速度 $g = 1200\text{ px/s}^2$ 驱动其向下倾泻跌落出屏幕，伴随撞击与清场动效。
- **胜利与失败判定**：
  - **通关胜利（Clear）**：全场所有螺栓全部归位入箱，所有挂板全部脱落清空！弹出过关礼花；
  - **单局失败（Fail）**：底部备用孔全部被占满，且台面上所有裸露螺栓均无法放入当前顶部收纳盒（陷入死锁）。玩家可按【Z】回退或一键秒重开。
- **数学可解性与 100% 确定性保证**：
  - 所有关卡数据由拓扑排序求解器（DAG Solver）严格验证，在给定的备用孔容量下，**保证至少存在一条完全通畅的最优解路径**，绝无数学死胡同。

### 操作与手感细节

- **ASMR 声学微雕（WebAudio Procedural Acoustics）**：
  - 螺栓拧出：细密高频的“滋滋——咔哒”螺纹摩擦与拔出声；
  - 螺栓装箱：实木或硬塑料材质的清脆“啪嗒”入盒声；
  - 面板单摆晃动：铰链转动的轻微金属轻响；
  - 面板脱落掉落：板材之间撞击并滑出屏幕的爽脆“哗啦——哐当”倾泻声；
  - 满箱封盖：木箱盖“啪”合上并伴随传送带滑动的链条音。

### 关卡模式编排（21 关五大工坊篇章：4/5/4/5/3）

1. **第一工坊：原木积木篇（Wood Workshop · 4关）**：
   - 基础教学：双色螺栓，简单双孔长条木板，熟悉螺丝拔出与板材直落下坠；
2. **第二工坊：彩虹亚克力（Acrylic Rainbow · 5关）**：
   - 多层遮挡：半透明彩色亚克力板，三色螺栓，初涉备用孔位的周转与腾挪；
3. **第三工坊：机械金属板（Metallic Hinges · 4关）**：
   - 动态物理单摆：长条金属板由双螺栓固定，解开一端后板材发生大幅物理旋转摆动，露出隐藏死角孔位；
4. **第四工坊：霓虹电子齿轮（Neon Gearbox · 5关）**：
   - 复杂轮廓联动：齿轮板、异形网孔板与多重十字交叉，考验深层拓扑预判；
5. **第五工坊：大师悬挂艺术（Master Sculpture · 3关）**：
   - 终极微缩机械装置大挑战：庞大精巧的多层联动装置，行云流水一拆到底，通关荣登“拆解大宗师”！

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **单螺栓留存时的物理表现（核心手感定调）**：
   - **方案 A（真实物理重力单摆旋转，强烈推荐）**：拔掉一颗螺栓后，面板立刻以另一颗为圆心在重力下自然摆动下垂，玩具物理感拉满，且摆动能露出死角螺孔，手感最生动；
   - **方案 B（静态悬挂无摆动）**：单螺栓时板材保持原位不动，直到最后一颗螺栓拔出才直接下坠脱落。逻辑更简单直接，但缺少物理动态趣味。

2. **备用中转孔位数量配置**：
   - **方案 A（动态递增 3~4 个，推荐）**：前两章提供 4 个宽裕备用孔，中后期高难度关卡压缩为 3 个孔，容错与策略博弈并存；
   - **方案 B（全关卡恒定 3 个孔）**：始终保持 3 孔严谨解谜。

3. **辅助脱困工具（磁吸螺丝刀）**：
   - **方案 A（提供 1 次无惩罚自选脱困，推荐）**：每关允许免费使用 1 次“磁铁”，强行吸走一颗暂无空位安放的棘手阻路螺栓，极大降低新手挫败感；
   - **方案 B（绝对纯逻辑硬解）**：不设任何外部道具，完全凭纯逻辑顺序拆解。
