## 1 · 创意概念与核心乐趣

- **游戏名称**：拆毛线解压 / Unravel Yarn / slug `unravel`
- **一句话玩法**：按颜色点线盘收线，槽位有限，解开缠绕毛线。
- **核心乐趣与卖点**：解压收线的心流。缠绕的毛线物件（毛衣、围巾、毛线团）一根根被收走，画面从乱到整齐，配上沙沙收线音效非常治愈。槽位有限带来轻策略：先收哪根、留哪个槽位，规划感刚刚好，不烧脑。
- **核心循环**：观察缠绕结构 ➔ 点线盘收同色线 ➔ 槽位满时同色合成清空 ➔ 逐步解开物件 ➔ 全部收完过关。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **Wool Craze（海外热门拆毛线）**：点线盘按颜色收线，槽位满 3 个同色合成，收完所有线过关。手感顺滑在收线动画流畅、槽位反馈清晰。
  - **微信拆毛线类小程序**：物件造型多样（毛衣、玩偶），关卡递进靠颜色数与缠绕层数。
- **我们要继承的成熟机制**：点线盘触发收线、有限槽位（5-7 格）、同色 3 个合成清空、线头被压住时不可收的遮挡规则、收线动画与音效反馈。
- **本作的独特魅力与微创新（Twist）**：颜色收线解缠+槽位规划。微创新点：线有「压线关系」——上层线压住下层线，必须先收上层；部分线带结扣，需先解结才能收；收完一色触发「毛线球滚落」小动画奖励。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：对照 `GEM_INSTRUCTION-4.md` 第二节 100 款底表逐款核对：
  - 与 `screw`（拧螺丝解谜：拧螺栓让面板坠落）不同：screw 是拧螺丝、面板掉落、重力物理，本作是点线盘收线、颜色合成、槽位规划，无螺丝无坠落，规则模型完全不同。
  - 与 `tidy`（沉浸收纳达人：物件归位收纳）不同：tidy 是拖拽归位，本作是颜色收线+槽位合成。
  - 与 `water-sort`（色彩排序：倒水排序）不同：water-sort 是试管倒水，本作是线盘收线+遮挡解缠。
  - 与 `tilestack`（千层瓦片叠叠消：三消）不同：tilestack 是点瓦片三消，本作是收线解缠。
  - 结论：解压解谜大类可共存，但核心循环与心流截然不同，不存在换皮风险。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - 盘面/场景构成：中央是缠绕毛线物件（由多根不同颜色线交叠构成），周围/下方是线盘（每根线对应一个线盘头），底部是有限槽位栏（5-7 格）。
  - 玩家合法操作：点击可收的线盘头，该颜色线被收入槽位；槽位中集齐 3 个同色自动合成清空并腾出格子。
  - 胜利条件：所有毛线被收完，物件完全解开。
  - 失败条件：槽位全满且无同色可合成（无空格可继续收线），判定失败，可重开本关。
  - 容错与无死局说明（100% 可解保证）：采用**逆向生成**——先生成可解的收线顺序，再反向缠绕成初始盘面，保证至少存在一条合法解法路径；生成后用求解器校验可解性，不合格则重生成。遮挡关系由生成顺序决定，保证上层线先收、下层线后收的顺序合法。另提供「撤销一步」与「提示一根可收线」兜底。
- **操作与手感**：
  - 鼠标/触控：点击线盘头收线；触屏点按即可，无拖拽负担。
  - 键盘：数字键 1-7 对应线盘、U 撤销、H 提示（桌面端辅助）。
  - **暂停机制（本作自适应说明）**：本作是无时间压力的纯静态解谜，天然静止，无需强制常驻暂停按钮；但带用时计时器的模式下，呼出选关/菜单时冻结计时。仍提供顶栏菜单入口，符合「静态解谜自适应」规范。失焦时自动冻结计时器（`visibilitychange`），回来继续。
  - 误触容错：不可收的线盘头点击时轻微抖动+提示音，不扣槽位。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - 首屏秒进对局：打开直接呈现第 1 关（或记忆进度关卡）的缠绕盘面与空槽位，可直接点线收线，**严禁首屏全屏选关遮罩**；
  - 常驻显眼选关入口：顶栏常驻「选关 / Levels」按钮，点击以轻量抽屉展示关卡网格；通关结算面板提供「下一关」与「选关」；
  - 严禁强制全屏遮罩阻塞首屏。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **严禁无脑套用“无尽冲分 + 每日挑战”**；
  - 采用章节关卡制：共 40 关，分 4 章（毛线团、毛衣围巾、毛线玩偶、毛线花园），每章引入新机制（结扣线、双色线、压线层数增加）。三星评级（用时+撤销次数+槽位峰值）；
  - 另设「解压自由拆」模式：无槽位失败判定，纯收线解压，服务于治愈心流。
- **游戏目标与反馈体系**：
  - 核心目标：收完所有毛线；指标为用时、撤销次数、槽位占用峰值；
  - 反馈仪式：每收完一色毛线球滚落动画；过关时物件完全展开+毛线球整齐排列。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 模式名：闯关模式 Level Mode / 解压自由拆 Relax Mode；
  - 关卡名示例：第 1 关·毛线团 Level 1: Yarn Ball；第 11 关·毛衣围巾 Level 11: Sweater & Scarf；
  - 核心实体：线盘 Yarn Spool / 槽位 Slot / 结扣 Knot；
  - 数据层约束：关卡与颜色一律用 key（如 `level_1`、`color_red`），展示层走 i18n，严禁在数据文件中裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：毛线工坊、针织质感、暖色台灯、治愈手作。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 视窗形态：**毛线工坊木桌**——整体是单栏木桌台面，中央是毛线物件盘，线盘头环绕物件下方排成弧形，底部是槽位木格栏。不是左右双翼三栏，也不是 SaaS 白卡堆叠。
  - 保持全站沉浸暗色底蕴，台面是暖木色，毛线带针织纹理高光。
- **立体质感与渲染路线裁决**：
  - 裁决：**DOM + CSS 3D** 为主（线盘、槽位、物件用 DOM+CSS 拟真针织质感），收线动画用 CSS transform/Canvas 2D 辅助。95% 路线，秒开零发热；
  - 不使用 Three.js：本作是 2D 解谜，无真三维空间需求；
  - 若未来尝试真 3D，必须守三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层）。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 5 种专属音效，拒绝单音蜂鸣：
  1. 收线声：细线摩擦的「沙沙」声（噪声带通滤波），随收线进度略升调；
  2. 线盘转动声：木质线盘轻转的咔哒声（短促木质碰撞）；
  3. 同色合成声：温润马林巴短音+毛线团落筐的闷响；
  4. 不可收提示声：柔和的低频「噗」声（非蜂鸣），带抖动反馈；
  5. 过关展开声：针织物展开的摩擦声+清脆编钟上行（非 C-E-G-C 套路）。
- **封面设计提案**：3D 软胶质感，单一居中主体（彩色毛线团+线盘，60-75% 无文字），鲜艳暖色渐变背景，针织纹理点缀。
