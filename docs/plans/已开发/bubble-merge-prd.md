# 《深海合珠》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。



***

## 1・创意概念与核心乐趣



* **游戏名称**：深海合珠 / Bubble Merge / 建议 slug：`bubble-merge`（候选 `bubble-pop`、`pearl-merge`）

* **一句话玩法**：把泡泡丢进容器，同色同级的泡泡一碰就 "啵" 地合成更大的泡泡，堆到超线前合出最大号泡泡并戳破它。

* **核心乐趣与卖点**：


  * **连锁合成的爆发感**：一颗泡泡落点妙，引发 "啵啵啵" 连环升级 —— 一次掉落清出一片空间，是 Suika 品类最上头的时刻；

  * **戳破终极泡泡的宣泄感**：费尽心思合成的大泡泡，**点一下 "啪" 地华丽破裂**，爆出高分还清空一大片空间 —— 泡泡题材独有的奖励时刻，水果玩法给不了；

  * **解压的物理观看性**：泡泡比水果更弹、更滑、更剔透，滚动、挤压、反弹本身就是治愈系表演。

* **核心循环**：



```
预判落点 → 丢下泡泡 → 滚动弹跳、同类碰撞合并 → 连锁升级 → 清出空间/累积分数

&#x20;   ↑\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_↓

合成出最大号"终极泡泡" → 戳破！爆分 + 清场 → 继续丢 → 堆叠超线 = 结算
```

**我们要借鉴什么**：Suika 的合并物理与三角数计分、SSRB 的掉落预览、Kawaii 的目标节奏可选。

**我们的差异化微创新**（不是换皮，是 "题材带物性" 的机制创新）：



1. **戳破终极泡泡（核心创新）**：合成到最高级 "终极泡泡" 后可以点击戳破 —— 华丽爆裂、获得巨额分、**清空所占空间**。把 Suika 里 "大西瓜是负资产" 的终局，变成 "攒大招→释放" 的正反馈循环；"泡泡就是用来戳的" 是天然直觉，零学习成本；

2. **泡泡专属物性手感**：比水果更弹、更滑 —— 滚动距离长、碰撞弹跳高、半透明碰撞时有 "挤压变形" 动画。物理手感即差异化；

3. **虹彩玻璃美学**：半透明渐变 + 高光折射 + 涟漪，与水果写实风完全区分，视觉治愈力拉满；

4. **每日挑战（同日同题）**：同日期同掉落序列（确定性种子），全球同题比谁能合到更大级、更高分。

**品类排重**：现有 15 款无 "掉落物理合成" 类。与 Gravity-Echoes（弹道精准）目标不同 —— 那是 "瞄准打靶"，这是 "布局规划 + 连锁合成"；与 gold-miner（钩爪时机）不同。填补 "物理合成 / 规划类" 空白，且是唯一 "气泡水美学" 题材。

## 3・玩法规则与交互说明

### 核心规则



* **场景构成**：


  * 一个左右封闭、顶部开放的矩形**容器**，底部与侧壁为碰撞边界；

  * **泡泡等级链**：共 10 级，从小水泡（L1）逐级合成到终极泡泡（L10）。每级大小、颜色、透明度递进（如 L1 微光小泡 → … → L9 大球 → L10 虹彩终极泡泡）；

  * 顶部画一条**安全线**：泡泡堆叠超过它即触发结算（先预警、后结算，不秒败）。

* **玩家合法操作**：

1. **选择落点**：鼠标移动 / 手指拖动显示落点瞄准线（虚线 + 落点光圈），松手 / 点击释放当前泡泡；

2. **合并判定**：两个同级泡泡接触 → 在接触中点合并为高一级泡泡，动量平均，产生连锁判定（新泡泡再与同级接触继续合并）；

3. **戳破终极泡泡（L10）**：点击场上任意 L10 泡泡 → 华丽爆裂动画 → 巨额分 + 清空其占用的空间区域；

4. 掉落序列：由 "当前待丢泡泡 + 下一个预览" 组成（借鉴 SSRB），玩家可预判规划。

* **胜利与失败条件**：


  * **无尽模式无失败线外的 "通关"**：目标是把泡泡合得更高、分数冲得更高；堆叠超过安全线 → 结算本局得分；

  * **每日挑战**：固定种子掉落序列，超线结算，比最高分 / 最大合成等级。

* **容错与无死局说明**：


  * 纯物理玩法**无逻辑死局**（不存在 "合法操作被吞"）；

  * **防秒败**：安全线下方设 "缓冲预警区"，泡泡进入该区时红线闪烁 + 音效提示，玩家有充足时间靠连锁 / 戳破清场；

  * **主动清障**：终极泡泡戳破即清场手段；若玩家始终合不出 L10，场上小泡泡也可靠物理滚动自然腾挪，永不 "堵死"。

### 操作与手感



* **鼠标**：移动 = 瞄准线；左键按下拖动 = 微调落点；松开 = 释放。

* **触屏**：手指拖动 = 瞄准线；松手 = 释放；点按 L10 泡泡 = 戳破。

* **键盘**（桌面加分项）：左右方向键微调落点 + 空格释放。

* **手感优化**：


  * 物理采用固定步长模拟（帧率无关、可重放可测试），泡泡滚动带轻微摩擦与弹性系数；

  * 合并动画：两泡 "啵" 一声挤压→膨胀成新泡，配涟漪扩散；

  * 掉落预览常驻 HUD（下一个是什么泡泡）；

  * 误触容错：释放前可随时取消（拖回顶部 / 右键取消）。

### 模式与内容递进



* **首选模式：无尽冲分 + 每日挑战**（Suika 品类最优解，重复可玩性来自 "每局布局不同"）。

* 难度自然生长（无需人工关卡）：


  * 开局阶段只出现 L1–L4（低风险，练手感）；

  * 随合成进度，掉落池逐步开放更高级泡泡（规划要求升高）；

  * 泡泡总量越堆越高 → 空间管理压力递增。

* **可选关卡制（拍板项）**：目标合成制 —— 每关 "合成到第 N 级即过关"，30 关递进（参考 Kawaii Fruits 3D）。

### 目标与评价



* **计分维度**（建议口径，供开发校准）：


  * `本局得分 = Σ 每次合成得分 + 连锁加成 + 破灭奖励`；

  * 合成得分：**三角数制**—— 合成出第 N 级泡泡得 `N(N+1)/2` 分（对齐 Suika 验证过的数值），如 L1→L2 得 3 分、L4→L5 得 15 分、L9→L10 得 55 分；

  * **连锁加成**：一次掉落引发连续 ≥2 次合并，每多一级 ×1.5 倍率 —— 鼓励 "落点设计" 而非乱丢；

  * **戳破奖励**：L10 破灭 = 100 分 + 清空空间（分数与清场双收益）；

  * 满分参照：单局无上限（无尽冲分）；每日挑战展示 "历史最高分 + 最大合成等级" 双纪录。

* **评价体系**：结算弹窗 "得分 + 最大合成等级 + 最长连锁 + 🏆 新高分"；无星级，记录本机最高分与最大等级。

## 4・美术风格与视觉氛围



* **题材与视觉关键词**：**深海气泡水・虹彩玻璃珠・梦幻高光・静谧水族馆・柔软弹性**

  （不做水果写实、不做数字泡泡、不做霓虹暗黑 —— 与站内全部题材拉开，治愈系颜值担当。）

* **桌面端沉浸游戏舞台设计（≥900px）**：


  * **左主舞台**：容器为 "深青玻璃水缸"，背景慢速光斑漂移（仿水下光柱），容器壁带微微水波反射；泡泡为半透明渐变玻璃珠，顶部高光点 + 边缘虹彩描边；

  * **右侧信息操作栏（水族馆铭牌式 HUD）**：


    * 顶部 "合成图鉴"：10 级泡泡链竖排展示，已合成级点亮、当前目标级发光 —— 玩家一眼看到 "离终极泡泡还差几级"；

    * 中部 "计分牌卡"：得分 / 最长连锁 / 最大合成级，胶囊徽章化 + bump 跳字；

    * 底部 "预览槽"：当前待丢泡泡 + 下一个预览，像 "池边的下一颗珍珠"；

  * 移动端（≤768px）：单列紧凑，容器自适应屏宽，预览槽贴底。

* **色彩与环境氛围**：


  * 主色：深青底 `#0E3B4D` → 靛蓝 `#1B4F72` 渐变水缸 + 泡泡虹彩（粉 `#FF9EB5` / 青 `#6FE3E1` / 黄 `#FFD66B` / 紫 `#B39DDB` 半透明）；

  * 背景：深青环境光晕缓慢 drift + 细噪点水纹，仿 "深夜水族馆一角" 的沉浸静谧感，拒绝死白灰底；

  * 关键动效：


    * **瞄准**：落点光圈呼吸 + 虚线轨迹；

    * **合并**："啵" 挤压膨胀 + 水面涟漪 + 轻微屏幕 shake（1px）；

    * **连锁**：每次连锁升级在泡泡上迸出小水花；

    * **戳破终极泡泡**：虹彩爆裂 + 粒子四溅 + 水波荡漾 + 金色闪光（全屏仪式感）；

    * **超线预警**：安全线变红脉动 + 低沉警示音；

  * 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

* **封面设计提案**：


  * 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字；

  * **主体物件**：一颗超大虹彩玻璃泡泡（中央），左右各一颗小泡泡正要 "啵" 进它身体里，合成瞬间的定格；

  * **背景色相**：**靛蓝 / 深青系**（未被占用，水感契合；纯明黄作备选），与现有 15 张封面不撞色。

## 5・制作人拍板与开放探讨



1. **终极泡泡机制（核心创新点，定生死）**：

* A. **可戳破**：合成 L10 后点击破灭，爆分 + 清空空间（默认推荐 —— 泡泡题材独有，把 "终局负资产" 变 "大招"）；

* B. **不可破**：L10 留在场上当终局障碍（纯经典 Suika 逻辑，稳但憋屈）；

* C. **破灭溅射**：L10 破灭时溅出 2–3 颗随机小泡泡（更刺激但更乱）。

1. **模式结构**：

* A. **无尽冲分 + 每日挑战**（默认推荐，品类最优解）；

* B. **关卡目标制**：每关 "合成到第 N 级" 过关，30 关递进 + 每日挑战；

* C. 混合：关卡制为主线 + 无尽模式解锁。

1. **物理手感取向**：

* A. **高弹滑爽快**：泡泡滚动远、弹跳高、更 "皮"（贴合 "泡泡" 物性，观赏性强，默认推荐）；

* B. **沉稳可控**：摩擦大、弹跳低，新手更好规划落点，但失去泡泡特色。
