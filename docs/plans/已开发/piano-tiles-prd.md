# 《别踩白块儿》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

---

## 1 · 创意概念与核心乐趣

- **游戏名称**：别踩白块儿 / Piano Tiles / 建议 slug：`piano-tiles`（候选 `no-white-tiles`、`tap-black`）
- **一句话玩法**：四列黑白格从屏幕上方滚落，只准点黑色格，碰到白格或漏掉黑格就掉血——速度越来越快，看你能撑多久。
- **核心乐趣与卖点**：
  - **手速与专注的极限挑战**：规则一眼懂、上限无限高，从"轻松跟拍"到"指尖残影"的成长曲线是品类横扫全球的根——**手速即段位**；
  - **点击即演奏（核心创新）**：黑块不只是要点的目标，每个黑块对应一个合成音阶——点对就"叮"一声，连续点对就是一段旋律。玩家在冲分的同时**亲手弹了一首曲子**，这是纯"反应游戏"给不了的成就感；
  - **节奏与心跳同步**：黑块下落与合成节拍绑定，进入状态后手指跟着拍子走，产生"人机合一"的沉浸感；
  - **三次容错的新手友好**：不搞"一次失误白玩"，三次失误机会让新手敢试、老手敢浪（web 端已验证的趋势）。
- **核心循环**：
  ```
  看准下落的黑块 → 精准点下 → "叮"一声得分 + 连击 +1 → 速度爬升
      ↑_________________________________________________↓
  点白格 / 漏黑格 → 掉一次失误（共 3 次）→ 继续 → 失误耗尽 = 结算段位
  ```

## 2 · 经典对标与借鉴创新

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴 | 避开 |
|---|---|---|---|---|---|
| Piano Tiles（品类鼻祖） | 移动端爆款 | 4 列黑块下落，点黑避白，速度递增 | 极简规则 + 音乐联动 | 核心规则、速度爬升曲线 | 一次失误即死的挫败感 |
| 钢琴块 2（官方续作） | 移动端 | 经典/街机/禅/极速/接力/彩色滑块 6 模式 | 模式矩阵成熟；连击特效 | **模式细分思路**（按玩法节奏拆） | 曲库版权依赖，我们零版权 |
| 别踩白块儿 3 | 移动端 | **PERFECT 判定 + 连击倍率 + 三星评价** | 精准判定制造"大神/菜鸟"分界 | **精准时机判定（PERFECT）** | 三星评价与"手速"品类不搭 |
| Key Rush（web 新作） | Web | **三次失误容错 + 每日固定种子轨道** | 容错友好；每日同题竞技 | **三次容错 + 每日固定轨道**（与 DOIN 每日挑战同思路） | — |
| Akousa Piano Tiles | Web | 键盘 1-4 / D-F-J-K 支持 | 桌面键盘手感验证 | 键盘映射支持 | — |

**我们要借鉴什么**：核心规则与速度曲线、精准时机判定、三次容错、每日固定轨道、键盘映射。

**我们的差异化微创新**（不是换皮）：
1. **点击即演奏（Beat Play）**：内置 3 首**合成旋律**（零版权），黑块位置 = 音符位置，BGM 节拍 = 下落节奏；点对发声、连续点对成曲。把"反应考验"升级为"用反应演奏"，是本作记忆点；
2. **段位徽章体系**：不评星级、不算无聊总分——按**最长连击**授段位（连击 10=新秀 / 25=快手 / 50=手速大师 / 100=指尖传说），段位是手速玩家的荣誉语言；
3. **三次容错**：新手不因一次误触白玩，节奏体验更完整；
4. **每日轨道（同日同题）**：固定种子生成每日黑块轨道，全球同题比最高分与最长连击。

**品类排重**：DOIN 现有 15 款无节奏点击类，填补"反应/手速街机"空白；与 gold-miner（时机）、snake-orchard（方向反应）体验不同——这是**纯粹的指尖节奏街机**，站内唯一"音乐反应"玩法。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景构成**：
  - **4 列轨道**（竖屏核心，黑格从顶部匀速下落），黑白格高对比，黑格间距随速度变化；
  - 底部判定线：黑格触达判定线仍未点击 = 漏格；
  - 玩家 **3 次失误**（点白格 或 漏黑格各计 1 次），失误耗尽即结算。
- **玩家合法操作**：
  1. **点击黑格**（点中即消 + 得分 + 连击 +1）；
  2. **精准时机**：在判定线 ± 窄窗口内点中 = PERFECT（得分 ×2，连击视为有效），其余 = GOOD（×1）；
  3. 触屏多指、桌面鼠标点击或键盘 1-4 / D-F-J-K（左到右四列）；
  4. 暂停 / 重开随时可用（零惩罚）。
- **胜利与失败条件**：
  - **单局失败**：失误耗尽（3 次）→ 结算段位与纪录；
  - **无传统"胜利"**：目标是冲最长连击 / 最高分 / 最高段位；经典模式额外提供"完成 50/100/200 块"的冲刺目标。
- **容错与无死局说明**：
  - 纯反应玩法**无逻辑死局**（没有"合法操作被吞"）；
  - 三次容错 + 随时重开 = 挫败感上限可控；
  - 黑块生成规则保证**同一时刻可点的黑块不重叠**（避免"两个黑块同时到线"必死局），这是生成器的硬约束。

### 操作与手感

- **鼠标**：左键点击轨道 = 判定该列。
- **触屏**：任意手指点轨道；多指并行；命中时方块"下沉+碎裂"反馈。
- **键盘**（桌面加分项）：1-4 / D-F-J-K 对应四列，回车暂停。
- **手感优化**：
  - 命中判定窗口宽容（约 ±120ms），入门不挫败、高手有深度；
  - 黑块命中 = 清脆"叮"（音阶随进度爬升）；白块误触 = 走调"哔"（明确区别）；
  - 连击 10 起屏幕边缘微光脉冲 + 数字 bump，连击 50 起火花粒子；
  - 点击反馈与视觉严格同步（输入缓冲 80ms 防连点误判）。

### 模式与内容递进（专属编排，不套通用三件套）

- **经典冲刺（Classic Rush）**：速度随连击递增（最高约 3 倍速），冲最长连击与段位——核心模式；
- **节拍演奏（Beat Play · 核心创新）**：内置 3 首合成旋律曲目（BPM 从 90→120→150 阶梯），黑块轨道 = 音符谱面，点对发声、连点成曲；每曲有"完整演奏"通关判定（一首不漏 + 三星级"演奏评级"）；
- **每日轨道（Daily Track）**：每日固定种子生成一条中高速轨道，全球同题，比最高分与最长连击（本机纪录）；
- **禅放松（Zen）**：无失误惩罚、速度恒定，纯跟拍放松（v1.1 可选）。
- **难度递进**：轨道速度、黑块密度、双连黑块（相邻两列同线）随进度引入；节拍模式以 BPM 阶梯为难度轴。

### 目标与评价（专属化评价体系）

- **段位徽章**：按单局最长连击授予——`新秀 10 / 快手 25 / 手速大师 50 / 指尖传说 100`，结算弹窗展示段位 + 徽章动画；
- **双纪录**：最高分 + 最长连击（本机存储）；
- **节拍演奏评级**：每首曲目按"漏键 + 非 PERFECT 数"评 1-3 星（演奏向，与手速段位分开）；
- **计分口径**：`单局得分 = Σ(命中得分 × 连击倍率)`；命中得分 GOOD=1 / PERFECT=2；连击倍率 10 连 ×1.5、25 连 ×2、50 连 ×3（封顶）——倍率是手速的直观奖励，不做复杂三维公式（本作不是解谜，得分就该纯粹）。

## 4 · 美术风格与视觉氛围（街机掌机化，严禁网页仪表盘）

- **题材与视觉关键词**：**黑白琴键 · 街机掌机 · 微光律动 · 专注舞台 · 电子音浪**
  （不做霓虹紫绿网吧风、不做死白网页、不做暗黑压抑——黑白高对比是品类识别度，配柔和光晕避免死黑。）

- **整体舞台造型（≥900px 宽屏 / 移动端竖屏一以贯之）**：把整局游戏做成**一台"黑白街机掌机"**，拒绝"左侧玩法 + 右侧卡片列"的仪表盘式排版：
  - **中央主舞台**：4 列黑白轨道下落的"屏幕区"，屏幕外框为掌机机身（圆角机身 + 实体按键边缘 + 顶部内嵌紧凑状态栏）；
  - **顶部内嵌状态栏**：返回 / 音效 / 语言 / 规则说明收纳为机身顶栏一体挂件（不散落四角）；
  - **两侧机身面板（对称翼）**：左侧嵌"连击 + 段位徽章"（像掌机副屏），右侧嵌"得分 + 剩余失误"（失误以"3 颗小心形"呈现）；面板为机身同材质（深灰磨砂 + 微光描边），非独立白卡片；
  - **底部操作台**：暂停 / 重开 / 模式切换做成掌机实体键（悬停微浮起、按下机械下沉 + 清脆键音），嵌入机身底缘，不是漂浮按钮；
  - 移动端：机身随屏宽等比缩放，轨道区自适应高度，操作键贴底拇指热区。

- **色彩与环境氛围**：
  - 主色：机身炭灰 `#3A3F4A → #23262E` 渐变（**避免纯黑**）+ 轨道白格 `#F4F2ED` / 黑格 `#1B1D22` + 微光蓝 `#7FD8FF` 点缀（判定线 / 连击光效）；
  - 背景：机身周围深靛蓝环境光晕缓慢 drift + 细噪点，仿"机厅一角"的聚焦感，杜绝单调大平铺；
  - 关键动效：
    - **命中**：黑格"下沉碎裂"成细粒 + 微光脉冲；
    - **PERFECT**：金色"PERFECT"跳字 + 判定线光晕；
    - **失误**：红框微闪 + 走调音 + 心形碎裂一枚；
    - **段位晋升**：徽章弹出 + 全屏微震 + 粒子喷发；
    - **连击光环**：连击 50 起轨道两侧泛起音浪波纹；
  - 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

- **封面设计提案**：
  - 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字；
  - **主体物件**：一排软胶黑白琴键（黑键白键交错，微微翘起如被点击瞬间），顶部浮起一个小音符粒子；
  - **背景色相**：**紫红系**（未被占用且未在策划案中使用；暖棕/古铜作备选），与黑白琴键对比强烈、视觉醒目。

## 5 · 制作人拍板与开放探讨

1. **容错设计（新手体验定生死）**：
   - A. **三次失误容错**（默认推荐——web 端已验证趋势，新手敢玩）；
   - B. **一次失误即死**（最原教旨的"别踩白块"，硬核但挫败感强）；
   - C. 按模式区分：经典/节拍一次失误，每日/禅三次容错。

2. **核心创新验证（节拍演奏）**：
   - A. **首发即含节拍演奏模式**（3 首合成曲目，零版权；"点击即演奏"是本作记忆点，默认推荐）；
   - B. 首发只做经典冲刺，节拍演奏留 v1.1（先把核心手感做透）。

3. **段位与评价**：
   - A. **段位徽章制**（按最长连击授段位：新秀→指尖传说，默认推荐，手速玩家的荣誉语言）；
   - B. 简单最高分制（无段位）；
   - C. 段位 + 每日挑战"今日段位冲刺"加成。
