## 1 · 创意概念与核心乐趣

- **游戏名称**：积木爆破 / Block Blast（副标：8×8 拖放拼块 · 满行列消除）/ 建议 slug：`blockblast`
- **一句话玩法**：把随机拼块拖进 8×8 网格，填满任意整行整列就爆破消除——放不下了，本局结束。
- **核心乐趣与卖点**：
  - **10 秒上手的国民级规则（Instant Mastery）**：拖、放、满行消除——没有计时、没有道具、没有新手教程负担。全球下载第一（约 3.68 亿次）、2026 年 1–2 月仍居下载榜首的爆款内核，规则就是全部；
  - **行列双维的空间规划（Row & Column Chess）**：一块拼进对角，可能同时补完一条横线**和**一条竖线——十字共鸣是这游戏最性感的瞬间；留缝、预判下一块、保护关键空位，每一步都是双维推演；
  - **无压力的节奏心流（Pressure-Free Flow）**：无计时、无惩罚，唯一的敌人是"空间不够"——随时拿起来玩一局，随时放下，解压与策略并存；
  - **爆破消除的即时反馈（Blast Feedback）**：满行瞬间玻璃碎裂 + 彩纸迸发 + 霓虹管闪亮，多行同爆时连击彩纸翻倍——爆款的即时多巴胺；
  - **与 hexfit 完全错位的网格形态（Square ≠ Hex · 用户点名）**：8×8 **方格 + 行列双轴**消除，与 `hexfit` 的三轴六边蜂巢完全错位；DOIN 62 款中无方格填放消除品类，本作以最经典形态补位（纯静态实现，秒开零加载）。
- **核心循环**：
  ```
  看三块拼块与棋盘空位 ➔ 拖放拼块（旋转可选）➔ 行列满行检测（横/竖双轴）
       ↑                                                    ↓
  新拼块入队（确定性 bag）← 消除（彩纸·霓虹·音阶）← 满行 N 行（N 行同爆连击）
       ↓（无任何块可放置）
  本局结束（消除数/最高连击/总分）➔ 章节星级 / 双人胜负 ➔ 再来一局
  ```

**经典标杆与成熟参考**：

|---|---|---|---|---|---|

| **Blockudoku（2018）** | 移动/Web | 8×8 网格 + 3×3 宫格双维消除 | 行列+宫格双判定的拼图深度 | 行列双轴判定、残局空间规划 | 宫格判定复杂（本作纯行列，保持 10 秒上手） |

**我们要继承的成熟机制**：
1. **8×8 网格 + 行列双轴消除（8×8 Row & Column Clear）**：填满任意整行或整列即消除，行与列可同爆——Block Blast 的国民级核心；
2. **三块队列（Triple Queue）**：同屏展示 3 块拼块，玩家自由选择放置顺序，规划感来自"先放哪块"；
3. **无计时无道具（No Timer, No Items）**：纯自由放置，唯一终局条件是"无块可放"——10 秒上手的关键；
4. **拼块形状池（Piece Pool）**：1~5 格小形状（单格、双格、三连、L 形、四连等），队列用确定性 bag 均衡分布；
5. **固定步长确定性逻辑（Deterministic Logic）**：120Hz 纯函数帧步进、种子注入、同种子重放一致、格数守恒可断言（本策划案的核心契约）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **章节目标制（Staged Objectives）**：爆款纯无尽，本作追加**章节挑战**（给定拼块序列 + 目标消除行数/十字共鸣次数/连击），配 solver 可解性校验——可背板、可测、有成长线，同时保留经典生存原味；
2. **十字共鸣连击（Cross Resonance）**：一次放置同时补完行+列触发"十字爆破"——双轴同爆的彩纸翻倍演出，把爆款最爽的瞬间命名化、可计数；
3. **同屏双人共享棋盘（Shared-Board Duel）**：同一 8×8 盘轮流放置，占位即博弈——你占的格就是对手缺的位，攻防一体（见拍板项 3）；
4. **霓虹积木工坊原生视窗（Neon Block Workshop）**：糖果色霓虹软胶拼块 + 街机玻璃展示柜 + LED 计分牌——与 `hexfit` 的暖蜜蜂巢在题材、色彩、网格形态上完全错位；
5. **即开即玩零门槛（Instant Play）**：首屏直接载入可玩盘面，无前置遮罩，选关入口常驻——平台最新契约与本作"10 秒上手"气质天然契合。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（8×8 网格，俯视 2D）
- **拼块板（Board）**：**8×8 网格（64 格）**，每格为正方形积木位，行/列双轴（横 8 行 + 竖 8 列）；
- **拼块（Pieces）**：由 1~5 格组成的糖果色软胶方块形状（单格、二连横/竖、三连直线、L 形/弯角、四连方形/长条/ T 形等，10~14 种形状）；
- **三块队列（Triple Queue）**：板面右侧（桌面端）或顶部（移动端）常驻展示 **3 块**当前可用拼块，放置后补充；队列由确定性 bag 生成（形状分布均衡、种子可注入）；
- **LED 计分牌（Scoreboard）**：玻璃柜顶部 LED 计分牌显示总分、最高连击、章节目标进度；
- **玻璃展示柜（Glass Cabinet）**：整块拼块板嵌在街机玻璃展示柜中，消除时玻璃碎裂 + 彩纸迸发。

### 3.2 判定与计分规则
1. **放置（Place）**：从三块队列取一块，拖到网格任意位置（可旋转 90°），必须全部落在空位且不越界，否则不可放置（非法位置松手回弹队列，不消耗）；
2. **行列满行消除（Row & Column Clear）**：每次放置后检测——任意**整行**或**整列**填满即消除（该行/列 8 格清空）；行与列可同时消除（十字共鸣）；
3. **计分（用户可选原味/翻倍两档，见拍板项 2）**：
   - **经典原味（推荐）**：每放置 1 格 +1 分；每消除 1 行（或列）+10 分；十字共鸣（同行+同列同爆）+额外 +25 分——与全球爆款口径一致，纯粹直接；
   - **连击翻倍档**：一次放置消除 N 行/列，本波倍率 2^(N−1)（2 行 ×2、3 行 ×4、4 行 ×8），上限 2⁸=256 倍——与 `hexfit` 同语言体系的进阶口味；
4. **连击（Combo）**：连续"放置即消"连击 +1，连击中断（放置未消）清零；连击驱动彩纸密度与音阶上行；
5. **终局判定（Game Over）**：三块队列中**无任何一块**存在合法放置位置 → 本局结束；结算 = 总分 + 消除数 + 最高连击；
6. **胜负与评级**：
   - **经典生存（Classic）**：无尽自由放置，结算三项指标；
   - **章节挑战（Campaign）**：每关给定拼块序列与目标（累计消除 ≥ N 行 / 触发 ≥ 2 次十字共鸣 / 达成连击 ≥ 3），拼块耗尽未达成 = 失败可重试；
   - **同屏双人（2P Duel）**：共享棋盘轮流放置，消除为自己计分，先达目标分（或对手放不下）者胜。

### 3.3 模式与内容编排（拒绝套路化三件套）
- **章节挑战（Block Campaign，主打成长线）**：**4 章 × 6 关 = 24 关**，评价体系 = 星级（目标达成 / 剩余拼块 / 最高连击），绝不做无尽冲分：
  - 第 1 章·行云流水：基础行列消除，目标累计消除 12 行；
  - 第 2 章·十字共鸣：目标单局触发 ≥ 2 次十字共鸣（行+列同爆），学双轴读盘；
  - 第 3 章·连击节奏：目标达成连击 ≥ 3 且连续 3 次放置即消，学留缝保节奏；
  - 第 4 章·极限封锁：目标在 64 格盘上消除 ≥ 40 行（高强度空间管理），收官演出；
- **经典生存（Classic，爆款原味）**：无限拼块队列、纯自由放置冲分，三块队列永续——最忠实爆款内核的模式；
- **同屏双人共享棋盘（2P Duel）**：轮流放置，占位即博弈（见拍板项 3）。

### 3.4 无死局与公平保证（数学可解性）
1. **拼块队列公平性**：确定性 bag 生成，形状分布均衡（每袋含各形状 1~2 个），杜绝连续大块堵盘的运气死局；
2. **章节可解性校验**：每关目标跑 **solver 确定性搜索**——断言存在合法放置序列达成目标（含行列消除），不满足即重新生成关卡；solver 结果写入测试断言，每次重跑复核；
3. **终局判定确定性**：无合法落位判定为纯函数穷举（对 3 块 × 全部位置 × 旋转逐一校验），无随机终局；
4. **确定性契约**：拼块队列、彩纸粒子、机关触发全部走确定性种子；同种子 + 同输入序列逐帧一致，支持自动化验证；逻辑引擎测试包含 ≥1000 步随机放置游走（状态机不崩、格数守恒、行列检测正确、终局判定正确）。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **桌面鼠标（主路径）**：
  - **取块**：点击队列中的拼块 = 拾起（跟随鼠标预览，合法位柔光、非法位变暗）；**拖动** = 移动预览；**右键 / 滚轮** = 旋转 90°；
  - **放置**：松开左键在合法空位 = 落子吸附（0.15s 软胶吸附动画）；非法位置松手 = 回弹队列（不消耗、不计失误）；Input Buffer：落子 60ms 窗口接受，连点不吞指令；
- **键盘**：`1/2/3` 直接取队列三块，`←/→`（或 `A/D`）与 `↑/↓`（或 `W/S`）移动预览，`R` = 旋转 90°，`空格` = 放置，`Esc` = 取消拾块/暂停/退回弹层；
- **移动端（触控）**：点队列块拾起、拖动到网格放置、双指旋转或点旋转钮 90°；非法落位回弹；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡放置区；
- **手感调优**：拼块"嗒"的软胶吸附；满行瞬间玻璃碎裂 + 彩纸迸发 + 霓虹管闪亮；连击每 +1 彩纸更密、音阶上行；十字共鸣专用"双爆"演出；破纪录 LED 计分牌爆闪。

1. **展示柜即全部**：8×8 拼块板嵌在深夜游戏厅的玻璃展示柜里，三块队列、LED 计分牌、操作条全部是柜体原生元素（玻璃反光、霓虹管、糖果色软胶拼块），**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **爆破消除奇观**：满行/满列不是"行消失"——玻璃碎裂 + 彩纸迸发 + 霓虹管闪亮，十字共鸣时双轴彩纸交汇成"双爆"，与 `hexfit` 的暖蜜流在色彩语言上完全错位；
3. **霓虹氛围**：深夜游戏厅青蓝/品红霓虹光晕 + 微尘粒子，拒绝死黑/死白大平铺；返回、音效、语言收纳进展示柜顶框一体化状态条；
4. **移动端（≤768px）**：展示柜压缩为竖持视角，三块队列移置顶部、操作条收折为柜下木质工具条，底部严格预留广告安全避让区，绝不遮挡放置区。

### 4.3 立体质感与渲染路线裁决
- **裁决：纯 Canvas 2D 拼块板舞台 + DOM/CSS 3D 街机玻璃柜框体**（不做 Three.js）：
  - 8×8 网格、糖果色霓虹拼块、彩纸粒子、行列高亮 → Canvas 2D（网格绘制 + 无边界径向柔光），120fps 秒开零发热；
  - 展示柜立体感（玻璃反光、霓虹管、LED 计分牌、柜体厚度）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/记分/弹层全部严格留在 DOM 层；
  - 理由：方格网格为平面二维结构，俯视 2D 即可完整表达，无真 3D 视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **拼块吸附（Snap）** | 软胶"嗒"——糖果块落位，温润清脆 | FM 短音 + 噪声瞬态，软质包络 |
| 2 | **满行消除（Line Clear）** | 玻璃碎裂"哗啦" + 彩纸沙沙 | 噪声串 + 高频扫频（shatter），多行时密度翻倍 |
| 3 | **十字共鸣（Cross Blast）** | 双轴同爆的"嘭—哗"双段 | 失谐双振荡器下潜 + 噪声爆发，比单行更厚 |
| 4 | **连击音阶（Combo Scale）** | 连击每 +1 音阶上行 | FM 木琴五声音阶逐级上行 |
| 5 | **霓虹氛围（Ambient）** | 深夜游戏厅低嗡，随连击强度微升调 | 失谐锯齿波 + LFO 抖动，轻微 |
| 6 | **破纪录/终局（Record & Over）** | 破纪录明亮琶音；终局低音下潜 + 彩纸尾声 | 上行琶音（FM）；低音下滑 + 噪声收束 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体，占画面 65%~70%——一堆**3D 软胶糖果色拼块**堆成 8×8 小方阵，其中一行正被抽走、化为彩纸迸发与霓虹光点；
- **背景与氛围**：深青蓝至品红的平滑径向渐变背景 + 霓虹光斑与微尘粒子，糖果拼块软胶质感饱满温润、高光闪亮——一眼传达"拖放拼块、满行爆破"的街机快感。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：模式配比？
- **选项 A（章节挑战 + 经典生存 + 双人三轨 · 推荐）**：章节挑战（4 章 × 6 关 = 24 关）为成长线，经典生存（爆款原味）与同屏双人共享棋盘为附加——目标成长、无尽冲分、派对博弈三种乐趣齐备；
- **选项 B（章节 + 生存双轨）**：只做章节挑战与经典生存，最聚焦、开发量适中；
- **选项 C（纯经典生存）**：最忠实爆款原味，只做无尽自由放置。

### 拍板项 2：计分口味？
- **选项 A（经典原味 · 推荐）**：每格 +1、每行/列 +10、十字共鸣 +25——与全球爆款口径一致，纯粹直接；
- **选项 B（连击翻倍档）**：一次放置消 N 行/列倍率 2^(N−1)（上限 2⁸=256）——与 `hexfit` 同语言的进阶口味；
- **选项 C（原味 + 双爆加码）**：经典原味基础上，仅对十字共鸣额外翻倍奖励。

### 拍板项 3：同屏双人形态？
- **选项 A（共享棋盘轮流放置 · 推荐）**：同一 8×8 盘轮流放置，占位即博弈——你占的格就是对手缺的位，攻防一体；
- **选项 B（各自棋盘竞速）**：双人各一张同种子棋盘，比谁先达成目标消除数，纯竞速无干扰；
- **选项 C（不做双人）**：纯单人体验。
