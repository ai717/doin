## 1 · 创意概念与核心乐趣

- **游戏名称**：千层瓦片 · 叠叠消 / TileStack · Layered Tile Match / 建议 slug：`tilestack`（单个简短纯英文单词，符合 slug 极简契约；“千层”即层层堆叠之意，无歧义）
- **一句话玩法**：点取多层堆叠的瓦片放进 7 格槽，凑齐三张相同即消，清空整叠过关。
- **核心乐趣与卖点**：
- 挖宝式层层剥开：瓦片叠成一座小塔，每消一层就露出下一层藏着什么，天然有“拆礼物”的期待感；
- 三消的即时爽感：三张一凑“叮”一声消失，连消还有上扬音阶，节奏轻快不拖沓；
- 槽位管理的轻度策略：7 格槽看着宽裕，乱点两下就满，什么时候该点、什么时候该留，越到后面越考验规划；
- 每局必有解：逆向算法生成，绝不出现“明明没点错却死局”的憋屈，输只输在自己手滑。
- **核心循环**：观察顶层可取牌 ➔ 点入槽位 ➔ 凑三消 ➔ 解锁下层 ➔ 清空整叠 ➔ 下一关 / 冲三星。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
- **Tile Match: Triple Puzzle Game（LinkDesks，5900 万安装）**：三消瓦片品类的量级标杆。最受认可的机制是“7 格槽 + 槽满即败”——槽位既是收纳也是倒计时，紧张感全从这里来；以及“点牌即入槽、凑三自动消”的零学习成本操作。
- **Match Triple 3D（LIHUHU，2600 万安装）**：把三消做成立体小物件（水果、玩具、动物），证明了“立体感 + 三消”在手机上极受欢迎；槽位、提示、连消反馈都已是成熟套路。
- **麻将接龙 Shanghai（Activision，1986）**：瓦片堆叠玩法的祖师爷。“自由牌”规则（上层无压、左右至少一侧空）是所有堆叠消除的母本；现代 web 版（如 PlayVersusAI）用“从完整金字塔倒推配牌”的逆向生成保证每局可解，这是本作可解性的直接出处。
- **我们要继承的成熟机制**：
- 7 格槽 + 三消自动清除 + 槽满即败（状态机清晰，胜负一目了然）；
- 自由牌规则：只有顶层、无遮挡的牌可点，被压住的牌置灰不可点；
- 逆向生成保可解：从空盘倒推配牌，至少留一条通关路径。
- **本作的独特魅力与微创新（Twist）**：
- 平台完全空白的赛道：站内尚无堆叠三消类，7 格槽三消是经过数千万安装验证的大众玩法；
- “千层塔”而非“平面一堆”：瓦片按层堆叠成塔，层与层之间有高度差与阴影，剥开的过程本身就是视觉奖励；
- 逆向算法写进规则：不是“随缘可解”，而是生成时就保证 100% 数学可解，并在关卡说明里明说，让玩家敢放手规划；
- 主题皮肤按章轮换：青花瓷、点心铺、麻将牌、花草集，皮肤只换皮相不换机制，坚决杜绝换皮式重复立项。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：与站内消除类同属大类，但规则模型截然不同——本作是“堆叠取牌 + 槽位三消”，不是连线消除、不是掉落消除；胜负不靠连锁反应，靠槽位规划与剥层顺序，坚决杜绝换皮。

## 3 · 玩法规则与交互说明

- **核心规则**：
- **盘面构成**：多层堆叠的瓦片塔（3~5 层，按关卡递增），每层为矩形阵列，上层瓦片居中错位压住下层；塔下是一条 7 格木托槽位；侧边显示剩余层数与剩余牌数。
- **玩家合法操作**：点按任意“自由牌”（上方无牌压住、左右至少一侧空），该牌飞入槽位；槽内集齐 3 张相同牌自动消除；点错的牌不可直接取回，只能用悔棋。
- **胜利条件与失败条件**：清空全部瓦片即过关；槽位塞满 7 格且无三消可成时本局失败，可悔棋续玩或重开本关。
- **容错与无死局说明**：关卡由逆向算法生成——从空盘出发，按可解顺序反向放置三张一组，保证至少一条通关路径；另设“提示”（高亮一组当前可消的牌，每关限 3 次）与“悔棋”（不限次，退回上一步）。
- **数值（初版建议，开发时可微调）**：每关瓦片 24~60 张；三消得 100 分，连消（3 秒内再消）每连 +50%；剩余步数奖励按未用提示与悔棋次数折算；三星线写在关卡配置里（三星 = 不用提示且悔棋 ≤2）。
- **操作与手感**：
- 鼠标点按取牌，触屏同理；空格键悔棋，H 键提示，P / Esc 暂停（仅计时模式）；
- 点牌有 0.15 秒飞入槽位的动画，三消有碎裂粒子 + 清脆提示音；槽位将满（剩 1 格）时槽边泛红预警；
- 误触容错：点错一张牌可立即悔棋，不扣次数；提示与悔棋按钮常驻，不藏进二级菜单。
- **随时可暂停与失焦保护机制**：本作基础模式为静态解谜，无倒计时压力，不强制常驻暂停键；计时挑战关（见模式）顶栏常驻醒目的「暂停 / 继续」按钮与 P / Esc / 空格快捷键，暂停时冻结计时并显示轻量半透明遮罩（继续 / 重新开始）；切标签页或最小化时自动静默暂停，回来后局势原样不动。
- **即开即玩与平滑选关设计**：初次打开直接进入第 1 关，瓦片塔与槽位直接就绪，无需前置点击；顶栏常驻醒目的「选关」按钮，点击以轻量抽屉展示章节关卡网格；结算面板提供「下一关」与「选关」。
- **模式与内容编排（依玩法特质定制，不套无尽冲分）**：
- **章节关卡制（默认）**：40 关，5 章，每章引入一个新元素——第 1 章纯三消、第 2 章锁牌（须先消掉钥匙牌）、第 3 章冰冻牌（须消两次）、第 4 章彩虹万能牌（可当任意牌凑三）、第 5 章计时挑战关（限时清空）；
- **三星评级**：每关按提示用量与悔棋次数评一至三星，集满一章三星解锁该章主题皮肤；
- **挑战关**：每章最后一关为限时关（90 秒），限时只出现在这里，基础关卡不限时。
- **游戏目标与反馈体系**：核心指标不是总分，而是**最少步数**与**三星收集**；过关结算展示“剥层进度”（塔从满到空的缩时动画），三星时塔顶亮起一枚小星。
- **双语核心词汇与数据键名规划**：
- 模式：章节关卡 Level Mode / 挑战关 Challenge / 提示 Hint / 悔棋 Undo；
- 实体：瓦片 Tile / 槽位 Tray / 锁牌 Locked Tile / 冰冻牌 Frozen Tile / 万能牌 Wild Tile；
- 数据层约束：所有关卡、皮肤、难度数据一律用字符串 key 或 id（如 `level_12`、`skin_porcelain`），展示层通过 `i18n` 获取文本，严禁在数据文件里裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：青花瓷、茶桌、层层剥开、从容手速、清雅。
- **专属视窗物理隐喻**：**“摆在茶桌上的一座瓦片塔”**——整个界面就是一张原木茶桌：瓦片塔立在桌中央，七格木托槽位是桌边的一条凹槽，剩余层数是一盏小茶盏里的水位（层越少水越浅）。拒绝左右双翼三栏套路，塔居中、信息围着塔走。
- **立体质感与渲染路线裁决**：纯 DOM + CSS 3D 为主（瓦片厚度用 CSS 3D transform 叠层，层间阴影显高度；入槽飞行动画用 CSS transition），Canvas 2D 只做三消碎裂粒子。**不采用 Three.js**——瓦片是固定视角的层叠平面，无真三维空间翻转需求，CSS 3D 已足够且秒开零发热。
- **声效风格与材质音色规划（4~6 种，拒绝单音蜂鸣器）**：
- 点牌取牌：木质轻叩（物理噪声滤波）；
- 入槽：短促的“笃”一声（失谐多振荡器轻敲）；
- 三消：清脆编钟“叮”（FM 合成）；
- 连消：上扬琶音（每连高一度）；
- 槽位将满：低鸣预警（低频正弦 + 噪声）；
- 过关：古琴拨弦 + 茶盏轻碰。
- **封面设计提案**：3D 软胶质感、单一居中主体（一座青花瓦片小塔，占 60~75%，无文字）、鲜艳渐变背景（青花蓝到米白的茶桌晨光）。

## 6 · 制作人拍板与开放探讨

1. **槽位：7 格经典 vs 9 格宽松**——方案 A：7 格（贴合品类标杆，紧张感足，策略味浓）；方案 B：9 格（更休闲，但槽位压力小、规划味淡）。推荐 A。
2. **限时：基础关不限时 vs 全关限时**——方案 A：基础关不限时（放松解谜，贴合“千层”慢剥体验），限时只放在每章最后一关挑战关；方案 B：全部关卡限时（加压，但容易把休闲玩家劝退）。推荐 A。
3. **美术题材：青花瓷 vs 点心铺**——方案 A：青花瓷（蓝白清雅，瓦片感最强）；方案 B：点心铺（色彩暖、更适合家庭同屏）。推荐 A，B 可作后续章节皮肤。
