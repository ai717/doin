## 1 · 创意概念与核心乐趣

- **游戏名称**：雪人兄弟·滚雪球 / Snowball Bros / slug `snowball`
- **一句话玩法**：把小怪冻成雪球滚大推出，沿途撞倒一片敌人。
- **核心乐趣与卖点**：全站唯一滚雪球清场手感。先把敌人喷成雪球、再推着滚大、最后推出去一串撞飞，节奏是「抓—滚—撞」三段爽感。雪球越滚越大、越滚越快，沿途碾过小怪、撞墙反弹、砸碎道具的连锁反馈非常解压，老玩家对雪人兄弟的童年记忆瞬间回来。
- **核心循环**：移动跳跃躲敌 ➔ 喷雪冻住小怪 ➔ 推动雪球滚大 ➔ 推出清场连锁 ➔ 清空本层过关 ➔ 进入下一层。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **Snow Bros 雪人兄弟（街机经典）**：核心机制是喷雪把敌人包成雪球、推动雪球滚动撞击其他敌人。手感顺滑在喷雪有冷却、雪球可变大、推出后可反弹清场。
  - **4399 Flash 平台动作合集**：单屏多层平台、左右移动+跳跃、清怪过关的关卡制结构，10 秒上手。
- **我们要继承的成熟机制**：喷雪蓄力（按住喷、松开停）、雪球可推可滚、雪球撞墙反弹、敌人被冻后短时挣扎逃脱的紧迫感、单屏多层平台跳跃、掉落道具拾取。
- **本作的独特魅力与微创新（Twist）**：全站唯一滚雪球清场手感。微创新点：雪球滚动时带雪粒拖尾与加速音效，连续撞倒 3 个以上敌人触发「连锁雪崩」加分与屏幕轻微震动；大雪球可砸碎冰砖露出隐藏道具；每关末层有小 Boss 需用大雪球多次撞击。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：对照 `GEM_INSTRUCTION-4.md` 第二节 100 款底表逐款核对：
  - 与 `bomber`（炸弹人：十字爆风炸砖清敌）不同：bomber 靠放炸弹延时爆炸、十字火力范围，本作靠实时喷雪冻人、推雪球滚动清场，无炸弹、无十字火力。
  - 与 `brawler`（操场大乱斗：横版格斗连招）不同：brawler 是拳脚连招打怪，本作无近战攻击，唯一武器是雪球，核心是冻—滚—撞的物理连锁。
  - 与 `shaft`（深渊百层：向下平台跳跃）不同：shaft 是下落生存，本作是单屏多层平台清怪过关。
  - 与 `fire-ice`（森林冰火人：双人合作解谜平台）不同：fire-ice 是解谜闯关，本作是单人街机清场。
  - 结论：平台动作大类可共存，但规则模型与心流完全不同，不存在换皮风险。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - 盘面/场景构成：单屏 4-5 层平台（砖块+木板混合），玩家在底部出生，敌人分布在各层巡逻。关卡为手工编排，非随机生成。
  - 玩家合法操作：左右移动、跳跃、喷雪（按住持续喷）、推雪球（靠近雪球推动）、推出雪球（推到边缘自动滚下或松开推出）。
  - 胜利条件：本层所有敌人被消灭（雪球撞死或推出画面）后进入下一关。
  - 失败条件：玩家被敌人碰到或被敌方投射物击中损失 1 条命；命数为 0 游戏结束。
  - 容错与无死局说明：关卡手工设计保证每层都有可达平台与可推雪球路线；雪球滚出画面自动消失不会卡死；敌人被冻超时会挣脱变回原形，不会永久卡住；提供重开本关按钮。
- **操作与手感**：
  - 鼠标/触控：触屏虚拟摇杆+喷雪键+跳跃键；桌面键盘左右移动、Z 喷雪、X 跳跃（可重映射）。
  - **随时可暂停与失焦保护机制（实时性游戏必选）**：
    - 暂停/继续实体按钮：顶栏常驻「暂停 / 继续」（Pause / Resume）按钮；
    - 暂停快捷键：`P` 键、`Esc` 键、`Space`（非主动作时）即时切换；
    - 暂停视觉反馈：画面冻结，半透明覆盖层显示「已暂停 / PAUSED」，提供「继续」「重新开始」；
    - 切后台自动暂停（Visibility Auto-Pause）：监听 `visibilitychange`，切标签页/最小化自动暂停主循环、计时与音效；
    - 输入缓冲：喷雪与跳跃支持 100ms 输入缓冲，落地瞬间跳跃不丢指令。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - 首屏秒进对局：打开直接进入第 1 关（或记忆进度关卡）就绪盘面，可直接移动喷雪，**严禁首屏全屏选关遮罩**；
  - 常驻显眼选关入口：顶栏常驻「选关 / Levels」按钮，点击以轻量抽屉展示关卡网格；通关结算面板提供「下一关」与「选关」；
  - 严禁强制全屏遮罩阻塞首屏。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **严禁无脑套用“无尽冲分 + 每日挑战”**；
  - 采用章节关卡制：共 30 关，分 3 章（雪原村庄、冰晶洞穴、极光峰顶），每章引入新敌人（飞行怪、投掷怪、重甲怪）与新地形（冰面滑行、弹簧板）。三星评级（通关时间+无伤+连锁数）；
  - 另设「雪崩冲刺」限时模式：90 秒内滚雪球清最多敌人，服务于滚雪球爽感，非无脑无尽。
- **游戏目标与反馈体系**：
  - 核心目标：清空本层敌人过关；指标为通关时间、连锁击倒数、无伤通关星级；
  - 反馈仪式：雪球撞敌时雪花粒子爆开+连锁数字跳动；过关时雪人举手庆祝动画。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 模式名：闯关模式 Level Mode / 雪崩冲刺 Avalanche Rush；
  - 关卡名示例：第 1 关·雪原村庄 Level 1: Snow Village；第 11 关·冰晶洞穴 Level 11: Crystal Cave；
  - 核心实体：雪球 Snowball / 喷雪 Snow Spray / 连锁雪崩 Chain Avalanche；
  - 数据层约束：关卡与敌人一律用 key（如 `level_1`、`enemy_patrol`），展示层走 i18n，严禁在数据文件中裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：冬日雪原村庄、软胶雪人、冰晶反光、童年街机柜。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 视窗形态：**雪地街机柜**——整体是单栏一体机台，顶部是弧形雪檐，中间是单屏多层平台舞台，底部是操作托盘（虚拟摇杆+喷雪/跳跃键）。不是左右双翼三栏，也不是四角散落按钮。
  - 保持全站沉浸暗色底蕴，舞台内是雪原蓝白渐变，平台带积雪高光。
- **立体质感与渲染路线裁决**：
  - 裁决：**Canvas 2D** 为主渲染（平台、角色、雪球粒子），DOM 仅做 HUD/按钮/暂停层。95% 路线，秒开零发热；
  - 不使用 Three.js：本作是 2D 平台动作，无真三维空间需求；
  - 若未来尝试真 3D，必须守三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层）。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 5 种专属音效，拒绝单音蜂鸣：
  1. 喷雪声：白噪声低通滤波的「沙沙」喷气声，带颗粒感；
  2. 雪球滚动声：低频滚动摩擦+雪粒沙沙，速度越快音调略升；
  3. 雪球撞敌声：厚重闷响+雪花爆开的高频粒子声（失谐多振荡器）；
  4. 跳跃/落地声：软胶弹跳的短促 FM 水滴音，落地带雪地闷响；
  5. 过关庆祝声：温润马林巴上行琶音（非 C-E-G-C 套路，带雪铃高频）。
- **封面设计提案**：3D 软胶质感，单一居中主体（雪人推大雪球，60-75% 无文字），鲜艳蓝白渐变背景，雪花粒子点缀。
