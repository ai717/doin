## 1 · 创意概念与核心乐趣

### 游戏名称
- **中文名**：数织（副标题「像素画谜」）
- **英文名**：Picross
- **建议 slug**：`picross`（单一纯英文单词，与 `sudoku`、`klotski`、`freecell` 同族同风格；候选 `nonogram`）

### 一句话玩法
看行列两排数字提示，推理哪些格子该涂黑、哪些该打叉，涂着涂着，一幅隐藏像素画自己浮出来。

### 核心乐趣与卖点
- **数独同族的确定性推理快感**：每一个落笔都建立在"这格已被逻辑证明"之上，命中即顿悟，永不靠猜。
- **像素画揭晓的收集快感**：从一片空白里"长"出一只猫、一艘火箭、一朵樱花——每解开一关就收一枚像素印章。
- **"唰"地一排落定的爽感**：用重叠法锁死一行、整行刷黑/刷叉的瞬间，是数织最上瘾的手感。
- **从容纠错的安全感**：错误计数 + 无限撤销 + 只提示"逻辑可证格"的智能提示，错了随时回头，零挫败。
- **数字与图画的浪漫**：明明只有 0 和 1 的布尔世界，却能拼出整个画册——这就是"数织"二字的魅力。

### 核心循环
```
读行列提示 → 推理：涂黑 / 标叉 → 行列达标自动划线 → 像素画渐进浮现
   ↑                                            ↓
   └────────── 解锁新章 → 印章收集成册 ← 通关评星（无错三星）
```

## 2 · 经典标杆与对标参考

### 2.1 成熟标杆原型（历史与现状）
- **历史源头**：数织（Nonogram / Griddler / Hanjie / お絵かきロジック）诞生于 **1988 年前的日本**，由 Non Ishida 与西尾徹也等人独立发明，是"行列数字串描述连续涂块"的日式图画逻辑谜题；1995 年任天堂推出《Mario's Picross》（GB），使其成为掌机经典，其后 Picross 系列（含 Switch《PICROSS S》系列）延续至今。
- **Web 常青树**：Nonogram Square（2000+ 免费谜题、5×5→25×25 五档难度、完成画廊、撤销/重做）、PlayPicross（零干扰极简体验）、Puzzle Madness（每日挑战 + "Hardest Picross"系列）等，证明该品类在网页端长盛不衰。
- **移动端金标准**：Nonograms Katana，被硬核玩家公认为标杆——按"所需解题技巧"筛选谜题（重叠法/边界法/矛盾法/递归法），提示系统只揭示逻辑可证格。

### 2.2 对标借鉴与避坑清单
| 对标对象 | 借鉴点（要抄什么） | 避坑点（不要重复什么） |
|---|---|---|
| Nonogram Square | 完成图案进**画廊**收藏；撤销/重做；5×5→25×25 难度递进 | 不做海量无主题拼凑谜题库，DOIN 版要有章节叙事与主题编排 |
| Nonograms Katana | 提示只揭示**逻辑可证格**、按技巧分层设计难度 | 不做"矛盾法/递归法"级硬核门槛，DOIN 版面向大众手感 |
| Puzzle Madness | 每日一题的仪式感可借鉴为"今日印章"彩蛋 | 不照搬"无尽冲分 + 每日挑战"三件套，章节关卡才是本作主干 |
| 门户自家 sudoku | 难度阶梯、双语纯净、关卡制评价体系的成熟范式 | 不做纯数字抽象，数织的差异化在"解出的是画" |

### 2.3 本作的独特魅力与微创新
1. **印章画册（核心差异化）**：每关解开的不是抽象图案，而是一枚**像素印章**——通关即盖章入册，画册随章节推进越来越满，收藏欲驱动再玩一关。
2. **章节主题叙事**：从"水果田园"到"萌宠星球"再到"星际遨游"，每章一个主题世界观，关卡间有微弱的图案剧情连贯（如第一章集齐水果，第二章开始出现抱着水果的小动物）。
3. **双确认涂格体系 + 容错**：涂黑与打叉双键分工明确，即时错误计数、整行划线删除、无限撤销——比多数网页版"点错只能继续"的手感更从容。
4. **章节三星评价**：无错 = 三星勋章，每章集齐三星点亮章节徽章——评价体系专属"干净度 + 用时"，绝不算"总分"。

## 3 · 玩法规则与交互说明

### 3.1 核心规则
- **盘面构成**：`rows × cols` 网格（5×5 起步，章节推进至 10×10 / 15×15）；每格三态状态机：`空 → 涂黑 / 标叉`，可再次点击循环回退。
- **行列提示**：每行左侧、每列上方标注数字串，如 `3 1` = 该行有"一段连续 3 格"与"一段连续 1 格"两个涂块，**块与块之间至少隔 1 个空格**；数字顺序即涂块从上/左到下的顺序；无数字的行列表示整行全空。
- **胜利判定**：盘面所有格子与唯一解完全一致（即隐藏像素画完整呈现）——**判定交给引擎对照标准解，不靠玩家自报**。
- **失败判定**：数织无"死亡"概念，涂错不炸——采用**错误计数 + 可撤销**的从容模式；错误数计入评价。
- **容错与无死局说明（★ 核心红线）**：
  - 关卡全部来自"**先画后题**"素材管线：策划/程序先定目标像素画 → 由画推导行列提示 → **回溯求解器逐关校验解数恰为 1**，多解或矛盾盘面一律拒绝发布；
  - 玩家侧永远 100% 可解：只要按照逻辑推，全程无猜、无死胡同、无需运气。

### 3.2 操作与手感（键鼠触全通）
- **鼠标**：左键涂黑、右键标叉；按住拖拽可连续涂整段；在已涂格上再次左键循环 `黑 → 叉 → 空`。
- **触屏**：底部工具条切换「涂黑笔 / 打叉笔」，单指点按、拖动连续涂；长按任意格切回另一工具；双指或按钮撤销。
- **键盘**：方向键移动焦点格，`Space` 涂黑，`X` 标叉，`Z`/`Ctrl+Z` 撤销，`H` 智能提示，`R` 重开本关。
- **误触容错**：判定在 `mouseup`/`touchend` 才落笔，拖出目标格可取消；撤销栈无限深度。
- **智能提示（不剧透）**：`H` 只揭示**当前局面下逻辑可证**的格子（如重叠法可锁定的必然格），绝不给出需要猜测的格——与 Katana 同一原则。

### 3.3 模式与内容编排（依"逻辑解谜"特质定制，非套用）
- **章节关卡制**（主干，约 40–50 关）：
  | 章节 | 主题 | 尺寸递进 | 关卡数 |
  |---|---|---|---|
  | 序章・入门 | 基础教学（重叠法/边界法手把手） | 5×5 | 4 |
  | 第一章・水果田园 | 苹果、樱桃、西瓜… | 5×5 → 10×10 | 8 |
  | 第二章・萌宠星球 | 小猫、小兔、企鹅… | 10×10 | 10 |
  | 第三章・神话传说 | 龙、凤凰、月兔… | 10×10 → 15×15 | 10 |
  | 第四章・星际遨游 | 火箭、行星、宇航员… | 15×15 | 8+ |
  - 难度递进维度：尺寸变大 + 线索分段变多 + 空块变碎（高级技巧自然引入），不做"卡死人的硬核门槛"。
- **评价体系（专属化）**：每关 **三星**（无错通关 = 3★ / 错误 ≤ 3 = 2★ / 通关 = 1★）+ 通关用时记录；无"总分"，无金币。每章集齐全部三星点亮**章节徽章**。
- **彩蛋（可选，见拍板项 1）**：全章节通关后解锁"**自定义画板**"——玩家自由涂一幅像素画，系统自动出题并校验唯一解后生成可挑战关卡，并可将画存入画册。
- **不做**：无尽冲分、每日强制挑战、排行榜联机——数织的乐趣在"一章章解、一册册收"。

## 4 · 美术风格与视觉氛围

### 4.1 题材与视觉关键词
`复古掌机像素` · `霓虹微光` · `软胶玩具质感` · `印章工坊`

### 4.2 沉浸舞台规划（游戏机台化，拒绝老套网页病）
**整体"机台" = 一台复古像素掌机 / 数织印章工坊工作台**：
- **环境背景**：深空墨蓝 → 靛紫的径向渐变底，漂浮着缓慢上浮的**像素微粒**，四角暗角收光——沉浸、不刺眼，天然规避"死白/死灰大平铺"。
- **中央主舞台**：数织画板本体（网格 + 行左/列上提示区），外裹一层**掌机框体**——上缘内嵌紧凑状态条（返回、音效、语言、规则收进框体边缘小托盘，**绝不四角散落**），两侧是行/列提示数字的自然延伸，形成"一台完整的游戏机"。
- **桌面端两翼（≥900px）**：
  - **左翼 = 印章画册**：一本实体印章簿造型，已解锁印章以软胶徽章排列展示，当前章进度点亮——收藏感拉满，不是卡片列表；
  - **右翼 = 操作面板**：一体化机台面板（撤销、重开、智能提示、错误计数、计时器、章节徽章），按钮是实体浮雕键，非 SaaS 卡片堆。
- **移动端（≤768px）**：单列，画板占屏宽；工具条与撤销收纳为**底部一体掌机操作台**，操作台下方预留 `≥68px` 底部安全缓冲（广告位避让红线）。

### 4.3 色彩与实体质感
| 角色 | 色值/材质 |
|---|---|
| 环境背景 | 墨蓝 `#0F172A` → 靛紫 `#312E81` 径向渐变 + 像素微粒 + 暗角 |
| 画板底 | 深空灰 `#1E293B`，格线 `#334155` |
| 涂黑格 | 软胶浮雕黑 `#0B0F19` + 边缘高光，按下有"盖章"沉感 |
| 打叉格 | 淡红小叉印记 `#F87171`，半透明可见底图 |
| 行列提示 | 达标自动划线划除（变暗 + 删除线动效），未达标高亮当前候选行/列 |
| 印章 | 软胶彩色徽章，解锁时"盖章"弹性落地 + 粒子迸发 |
| 实体按键 | 微浮雕 + 悬停轻浮起（-2px）+ 按下机械下沉（2px）+ 清脆合成音 |

- **交互反馈**：涂黑瞬间"嗒"的盖章音 + 格子微压；一行/列达标时轻划线划除音；通关瞬间**像素画点亮**——整幅图案从灰暗中亮起、色相绽放 + 印章落地粒子 + 章节徽章闪耀；`prefers-reduced-motion` 下全部动效瞬移降级。

### 4.4 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **主体**：一只巨大的 3D 软胶**像素方块笔刷头**（带小表情），旁边立一枚**像素印章**（顶部小把手），方块表面是 3×3 数织格纹——一眼读懂"数织/像素画"。
- **背景色系**：**橙 → 紫渐变**（暖色相，未被门户现有益智游戏占用）。
- **Prompt 草案**：

## 5 · 制作人拍板与开放探讨

**请制作人（用户）对以下 3 项拍板：**

1. **★ 内容编排**——纯章节关卡制（推荐，40–50 关 + 印章画册）？
   - **方案 A**（推荐）：章节关卡制 + 全通后解锁「自定义画板」彩蛋（自己画图 → 自动出题校验唯一解 → 生成挑战关并入画册）。收集与再玩双驱动，工程量小幅增加。
   - **方案 B**：纯章节关卡制，不做自定义画板，最精简，聚焦打磨主线手感。

2. **★ 错误策略**——涂错怎么处理？
   - **方案 A**（推荐）：**严格三星**——无错通关才给三星，错误计数入评价；涂错即时轻提示（格微闪）但不拦截，可撤销。挑战与从容兼得。
   - **方案 B**：**宽容模式**——可开关"错误自动纠错"（填错格自动弹回），默认关；新手友好，代价是硬核对玩家略失挑战感。

3. **美术路线**——哪种味道？
   - **方案 A**（推荐）：**复古掌机像素 + 霓虹微光**（深空墨蓝环境、软胶涂块、印章画册），冷色沉浸、与 `sudoku` 视觉区隔明显。
   - **方案 B**：**清新绘本马卡龙**（浅粉/薄荷环境、糖果色涂块），更休闲可爱，适合亲子向，但环境色偏亮，需小心规避"死白大平铺"红线。
