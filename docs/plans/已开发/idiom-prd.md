## 1 · 创意概念与核心乐趣

- **游戏名称**：成语纵横榜 · 典故图鉴 / Idiom Cross · Allusion Atlas / 建议 slug：`idiom`（单个简短纯英文单词，符合 slug 极简契约；即“成语”品类名，无歧义）
- **一句话玩法**：纵横交叉的网格里补全四字成语，集齐典故解锁图鉴。
- **核心乐趣与卖点**：
- 填对成语的“啊哈”顿悟：横竖交叉处一字双关，灵光一闪整行点亮；
- 集齐典故图鉴的收集欲：每条成语背后都有一个故事，填对就解锁一张典故卡，集满一榜像集邮；
- 中华文化的亲近感：玩的是游戏，顺手就把成语和典故温习了一遍，玩完还能讲给别人听；
- 双语真切换：英文模式整套换成 Word Crossword，不是把中文成语机翻成英文，两种语言各有各的题库。
- **核心循环**：看提示（释义 / 典故线索）➔ 在纵横网格里填字 ➔ 成语成行成列点亮 ➔ 解锁典故卡 ➔ 集满一榜。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
- **成语填填字（Kerun Games，4.9 星）**：成语填字品类的口碑标杆。最受认可的机制是“纵横空格 + 下方字库点选填字”（不用打字，点一点就行）与“古风词典界面”（释义、典故随手可查）；以及“按教育部成语词典取词”的选词可信度。
- **成语接龙-填填看（KINGFORMATION，55000 关）**：每关 12~16 道填空、按提示或相邻词句填答案，证明了“填字 + 接龙”可以做成海量关卡；以及“中粤双语朗读”的学习向加分项。
- **Crossword（puzzling.com，30000+ 谜面，10 种模式）**：英文纵横填字的量级标杆。最受认可的是“每日主题谜 + 巨型纵横 + 暗号填字”的多模式编排，以及“填对整词发光、积分攒星”的反馈体系。
- **我们要继承的成熟机制**：
- 纵横交叉网格 + 释义提示 + 字库点选填字（零打字门槛）；
- 按榜单 / 主题分章编排（每榜一个主题，循序渐进）；
- 填对整词发光 + 积分攒星的反馈。
- **本作的独特魅力与微创新（Twist）**：
- 平台完全空白的赛道：站内尚无成语 / 文字填字类，中文填字是经过市场验证的大众玩法；
- “典故图鉴”而非“只填字”：每条成语填对后解锁一张典故卡（出处、故事、例句），集齐成册可翻阅可分享，玩完有“带走的东西”；
- 英文模式真切换：英文模式整套换成 Word Crossword（英文单词纵横题 + 英文释义），两种语言各有独立题库，绝非机翻凑数；
- “纵横榜”按主题分榜：历史典故、山水田园、动物成趣、人物风骨……每榜 10 关，榜榜有主题。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：与站内文字 / 益智类同属大类，但规则模型截然不同——本作是“纵横交叉填字 + 典故收集”，不是连线成词、不是消字消除；胜负不靠手速与连锁，靠词汇量与交叉推理，坚决杜绝换皮。

## 3 · 玩法规则与交互说明

- **核心规则**：
- **盘面构成**：一张纵横交叉网格（5×5 起步，随章节渐增至 9×9），横竖成语在交叉格共用一字；格边给释义提示；下方是字库条（本关所需字 + 2~3 个干扰字）。
- **玩家合法操作**：点格子选中一条成语（再点切换横 / 竖），点字库把字填进空格；键盘可直接输入汉字；Backspace 擦除；H 键提示（揭开一个字）。
- **胜利条件与失败条件**：填满网格且全部成语正确即过关；本作无失败判定——错字可随时擦除重填，提示每关限 3 次，用完只能靠自己。
- **容错与无死局说明**：网格由成语库逆向生成——先选一组能纵横交叉成词的成语，再挖空成题，保证唯一解；字库只含本关所需字与少量干扰字，绝不会出现“缺字填不上”的死局。
- **数值（初版建议，开发时可微调）**：8 榜 × 10 关 = 80 关；每关成语 4~8 条；提示每关限 3 次；评级按提示用量与用时（一星 = 用提示 ≥2，二星 = 用提示 1 次，三星 = 零提示）。
- **操作与手感**：
- 鼠标点格选词、点字库填字，触屏同理；键盘直接输入汉字，Backspace 擦除，H 键提示；
- 落字有毛笔轻点的墨迹动画，整条成语填对时整行泛金光 + 编钟一声；错字填入时格子轻晃，不锁死；
- 误触容错：点错格子随时可换选，错字随时可擦；提示用完后按钮置灰，不扣分。
- **随时可暂停与失焦保护机制**：本作是纯静态填字，无倒计时压力，不强制常驻暂停键；带用时计时器的模式在菜单呼出时冻结计时；切标签页不影响局势（静态盘面天然静止）。
- **即开即玩与平滑选关设计**：初次打开直接进入第 1 关（历史典故榜第 1 题），网格与字库直接就绪，无需前置点击；顶栏常驻醒目的「榜单」按钮，点击以轻量抽屉展示 8 个主题榜与关卡网格；结算面板提供「下一关」与「选榜」。
- **模式与内容编排（依玩法特质定制，不套无尽冲分）**：
- **主题榜单制（默认）**：8 榜 × 10 关，每榜一个主题——历史典故、山水田园、动物成趣、人物风骨、数字成趣、身体部位、颜色成趣、器物雅玩；每榜前 3 关给足提示词，后 7 关只给释义；
- **典故图鉴**：每条成语填对即解锁典故卡（出处、故事梗概、例句），图鉴按榜归档，可随时翻阅；集满一榜解锁该榜“榜首金卡”；
- **英文模式**：整套切换为 Word Crossword（英文单词纵横题 + 英文释义 + 英文词源小卡），题库独立，不与中文成语混用。
- **游戏目标与反馈体系**：核心指标不是总分，而是**图鉴收集进度**与**三星收集**；集满一榜时结算展示“本榜典故册”翻页动画，可一键生成分享卡。
- **双语核心词汇与数据键名规划**：
- 模式：主题榜单 Theme Board / 典故图鉴 Allusion Atlas / 提示 Hint / 选榜 Board Select；
- 实体：成语 Idiom / 释义 Definition / 典故 Allusion / 字库 Tile Rack；
- 数据层约束：所有榜单、关卡、成语、典故数据一律用字符串 key 或 id（如 `board_history`、`level_03`、`idiom_001`），展示层通过 `i18n` 获取文本，严禁在数据文件里裸写中文；英文题库另建独立数据文件，不与中文成语混表。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：线装书、宣纸、典故、竖排、古雅。
- **专属视窗物理隐喻**：**“一册摊开的线装典故书”**——整个界面就是一本竖排线装书：网格印在书页上，字库是一排书签条，释义提示写在页边小注里；典故卡就是书里的插页，解锁时像翻书一样展开。拒绝左右双翼三栏套路，书页居中、信息围着书页走。
- **立体质感与渲染路线裁决**：纯 DOM 为主（汉字网格天然适合 DOM，宣纸纹理用 CSS 渐变模拟），Canvas 2D 只做点亮时的金光粒子。**不采用 Three.js**——填字是平面文字交互，无真三维空间翻转需求，DOM 已足够且秒开零发热。
- **声效风格与材质音色规划（4~6 种，拒绝单音蜂鸣器）**：
- 落字：毛笔轻点宣纸（物理噪声滤波）；
- 成语点亮：编钟一声（FM 合成）；
- 图鉴解锁：翻书沙沙声（物理噪声）；
- 错字：轻叩木鱼（失谐多振荡器轻敲）；
- 通关：古琴拨弦三声。
- **封面设计提案**：3D 软胶质感、单一居中主体（一本线装书 + 一枚“成语”印章，占 60~75%，无文字）、鲜艳渐变背景（宣纸米白到朱砂红）。

## 5 · 战绩留存与会话流转规划（通用且平台无关）

- **通用战绩图（可选，平台无关）**：通关结算时可生成一张战绩卡（Canvas 绘制）：游戏标题、榜单、关卡、用时、提示数、星级、`doin.win` 链接，中英双语自适应，便于玩家截图留存与分享；集满一榜可生成“本榜典故册”分享卡。

## 6 · 制作人拍板与开放探讨

1. **英文模式：Word Crossword 全套切换 vs 仅界面翻译**——方案 A：全套切换（英文单词纵横题 + 英文释义，真正双语游戏）；方案 B：仅界面翻译（成语仍中文，英文玩家玩不了）。推荐 A。
2. **提示：每关限 3 次揭字 vs 无限提示但扣评级**——方案 A：限 3 次（保持挑战，提示是稀缺资源）；方案 B：无限但扣星（更宽松）。推荐 A。
3. **图鉴：典故卡只收藏 vs 典故卡可分享**——方案 A：可生成分享卡（传播点，玩完能发朋友圈）；方案 B：只收藏。推荐 A。
