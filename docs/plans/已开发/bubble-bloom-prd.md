# 《合成泡泡》小游戏策划案

> 定位：本策划案由产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

---

## 1 · 创意概念与核心乐趣

- **游戏名称**：合成泡泡 / **Bubble Bloom** / 建议 slug：`bubble-bloom`
  - 备选：`bubble-forge`（更强调工坊感）、`bubble-orbit`（不推荐，容易与站内星轨调度混淆）。
- **一句话玩法**：把同阶彩泡投入玻璃合成舱；它们一碰就膨胀合成，堆出一次次意外的大连锁。
- **品类定位**：以真实碰撞与空间堆叠为核心的轻物理合成游戏；不是 2048 的格子滑动，也不是三消/连连看的平面配对，而是“落点决定后续整盘命运”的可观看、可复盘、可分享型爽游。
- **玩家情绪曲线**：
  1. 先用一个小泡找落点，期待它滚进同类旁边；
  2. 碰撞发生、两个泡膨胀成更大的一颗，得到即时满足；
  3. 大泡挤动整舱，连续触发 2～5 次自动合成，迎来惊喜爆点；
  4. 泡堆逼近警戒线时，在“再赌一手”与“稳住局面”间做轻策略抉择；
  5. 制作出稀有顶阶泡，获得图鉴、成就和个人纪录。
- **核心卖点**：
  - **一碰变大，规则零门槛**：玩家无需背组合表，同外观、同纹样就是可合成对象。
  - **物理带来的偶发大爽点**：合成后体积改变、挤压与滚动会自然制造链式碰撞；玩家做的是“布阵”，而不是机械点击。
  - **可控而非纯赌**：当前泡 + 下一泡双预览、有限救场工具、清晰危险线，让每次失败都能看懂原因。
  - **成熟但不撞车**：补上 DOIN 目前缺失的“连续物理堆叠合成”空位；与《2048》的离散滑动合并、与《开心消消乐》的交换三消、与《祖玛传奇》的轨道射击消除形成明确区隔。
- **核心循环**：观察当前/下一颗 ➔ 选择横向落点 ➔ 泡泡落下、滚动、碰撞 ➔ 同阶融合并结算连锁 ➔ 腾出或挤占空间 ➔ 冲击更高阶泡与更高分 ➔ 破纪录/再开一局。

## 2 · 经典对标与借鉴创新

### 2.1 标杆调研结论

| 成熟标杆 | 被验证的核心机制 | 我们具体借鉴 | 明确避坑 |
|---|---|---|---|
| **《Suika Game / 西瓜游戏》**（Aladdin X） | 玩家将物件投进容器，同类接触后升级；容器溢出形成易懂的压力线。 | “单轴选落点 + 下落碰撞 + 同阶进化 + 顶部危险线”的低学习成本骨架；当前与下一颗预览、合成瞬间的强反馈。 | 不复制水果谱系、容器画面、命名或数值；不把“随机来什么”做成无从预判的挫败源。 |
| **《Puyo Puyo / 魔法气泡》**（SEGA） | 简单规则之上，连锁比单次消除更能形成高手追求；堆叠接近顶部时压力陡增。 | 使用可读的连锁计数、分段音效和“本次连锁”结算，让自然触发的连续融合也有可识别的高潮。 | 不做格子棋盘、四连即消、对战垃圾泡或旋转双球，避免落入经典落块消除的既有范式。 |
| **《2048》**（站内已有） | 同值合并与指数成长让目标直观，玩家愿意追逐“再升一级”。 | 用固定、视觉可辨的十阶成长链与稀有顶阶目标承接长期驱动力。 | 不使用方格移动、四方向滑动、数值文本作为主识别；玩法重心必须是连续碰撞物理与空间布局。 |

**调研依据（2026-09-13）**：任天堂对《Suika Game》的公开介绍明确其“防止容器溢出、让同类水果碰撞”的基本目标；SEGA 的《Puyo Puyo》教学将同色连锁与堆至顶线压力作为核心乐趣。这说明“清晰的危险边界 + 强连锁可视化”是可直接迁移的成熟手感原则，但本案会用无角色、无水果的泡泡炼金题材与连续物理碰撞完成差异化。

### 2.2 差异化：从“水果堆叠”升级为“泡泡炼金连锁”

1. **独有视觉语义——不是换皮水果**：每一阶是不同内部纹样与折射效果的“炼金彩泡”，从微粒泡到极光泡，玩家通过轮廓、环带、光核一眼识别等级；不出现水果、蔬菜或西瓜。
2. **“压力连锁”而非只看总分**：当一次投放引发连续两次以上融合，进入本次 **Pressure Chain**。连锁中的后续合成会逐级提高倍率，并以由低到高的音阶、涟漪和镜头微震传达“整舱被带活”的快感。
3. **轻策略的双预览**：始终展示“手中泡 + 下一泡”。它不把游戏变成复杂规划题，却给玩家一个明确的提前布局点，能在“铺小泡等待配对”与“保留低位空间”之间作判断。
4. **温和救场，不替玩家自动玩**：每局仅有少量“潮汐脉冲”，可让静止泡堆产生一次轻微横向扰动，帮助分离卡缝或促成接触；它有冷却/次数限制，只是修正坏落点，不可直接合成或清空盘面。
5. **顶阶泡不是终点**：顶阶“极光王泡”仍可作为大体积障碍存在，鼓励玩家决定是稳住场面、维持纪录，还是尝试让两枚王泡相撞触发一次全舱烟花式的“彩虹绽放”高风险大奖。

## 3 · 玩法规则与交互说明

### 3.1 场景与成长链

- **主场景**：竖向圆角玻璃合成舱。顶部为投放轨道，中下部是受重力影响、可滚动挤压的合成空间；上沿设有醒目的半透明警戒线。
- **基础物件**：
  - 彩泡共有 **10 阶**，初局只会投放 1～4 阶；随着玩家自行合成，场上逐步出现更高阶。
  - 建议成长链：**微粒泡 → 露珠泡 → 珠光泡 → 彩糖泡 → 月晕泡 → 星屑泡 → 云团泡 → 虹膜泡 → 极光泡 → 极光王泡**。
  - 每阶同时改变尺寸、中心纹样、外环光泽与声音音高；色彩变化服务于识别，不要求玩家仅靠文字或数字分级。
- **入场队列**：当前泡居中停在投放轨道；下一泡以小型预览显示。基础候选池严格限制在低阶范围，后续等级只由玩家合成产生。

### 3.2 核心规则与状态判定

1. **投放**：玩家在投放轨道内选择横向位置，点击/松手释放当前泡。泡泡入舱后受重力、边界和其他泡的碰撞影响而滚动、堆叠。
2. **同阶合成**：两颗同阶泡发生有效碰撞后，短暂停顿并在两者接触中心生成一颗下一阶泡；原泡消失，新泡以可见的“膨胀—稳定”动画进入物理环境。
3. **连锁结算**：新泡挤开相邻泡并继续参与碰撞。若由同一次投放带来连续融合，则连续计入 Pressure Chain，直到舱内静止或无新的有效合成为止。
4. **高阶双王奖励**：两颗第 10 阶极光王泡碰撞时，不再升级为不可识别的第 11 阶，而是触发“彩虹绽放”：清晰可见的大型特效、一次高额奖励和显著腾空效果。这是可选高风险目标，不是通关硬门槛。
5. **失败条件**：任一泡持续越过警戒线达到短暂缓冲时长后，本局结算。缓冲的意义是允许合成动画或自然回落完成，避免“刚碰到线就被冤判”。
6. **终局边界**：结算后不再接受投放、潮汐脉冲或重复合成；只能重开、查看结果或返回主页，避免错误状态继续变化。

### 3.3 公平性、可解释性与“无死局”口径

本作的标准舱是**可失败的分数挑战**，不是要求每一盘必然通关的关卡谜题；危险线带来的空间管理压力是玩法本身。因此“不承诺每局获胜”，但必须杜绝由随机队列或物理状态错误导致的伪死局：

- **确定性公平队列**：每局由同一粒度的候选袋轮转生成；任何连续窗口都保留足够的低阶重复项，避免长串单个孤儿等级让玩家根本等不到配对机会。每日试验使用固定种子，保证同日同序列、可复盘。
- **没有不可操作状态**：只要未结算，玩家永远可以投放当前泡，且泡泡落定、合成、警戒线检测按稳定顺序处理；不允许“泡在半空冻结”“同阶重叠却永不判合成”“卡进容器外”等状态。
- **合成一次只结算一次**：同一对泡被锁定为合成对象后，不得被多次计分或重复生成；连锁以稳定帧结束为唯一结算点，保证结果可解释。
- **救场为有限选择而非随机赦免**：潮汐脉冲有明确次数和冷却，玩家可预判其效果范围；它不改变队列、不生成免费高阶泡、不偷偷清盘。
- **每日模式不设“必须达成才算成功”的随机目标**：同种子下比较的是分数、最高阶和最长连锁；玩家即使提前溢出也能获得完整结果，避免因不可控初始随机而被判失败。

### 3.4 操作与手感

- **鼠标**：移动指针控制投放横坐标；单击投放。按住时显示淡淡的垂直投放丝线和当前泡半透明轮廓，松开才释放，避免误点。
- **触屏**：在轨道区域左右拖动，松手投放；静止区单击不触发多余滚动。目标是 390px 宽度下一只手也能精准落泡。
- **键盘**：左右方向键小幅移动投放点；`Space` / `Enter` 投放；`T` 使用潮汐脉冲；`P` 暂停；`R` 重新开始。首次打开的帮助层要同时说明这些键位。
- **输入容错**：泡尚未释放、合成结算中或暂停时，重复投放意图静默忽略；当前一颗未离开投放轨道前绝不允许第二颗叠出。所有合法投放必须立即生效，绝不弹窗报错。
- **关键手感指标（供制作校准）**：落点跟手、泡的反弹轻而不飘、合成有约 100–160ms 的可感知吸附感、链式融合之间留有能看清的节奏；不追求混乱高速的台球感。

### 3.5 模式、内容递进与长期目标

- **首发主模式：标准舱（默认）**
  - 单局无时间限制，围绕最高分、最高阶、最长连锁挑战自我纪录。
  - 前 3 次投放以易合成的低阶配对作为无文字教学；之后进入完整候选袋节奏。
  - 最适合“再来一局”的轻度、可观看体验。
- **每日试验（首发推荐）**
  - 每个自然日固定种子、固定前段序列，所有玩家面对同一开局；本地保存当天最佳分、最高阶与最长连锁。
  - 采用“每日档案”式结果卡，而非服务器排行，不引入在线依赖。
- **成长图鉴（首发轻量）**
  - 首次合成各等级彩泡即点亮图鉴；达成 3 连锁、首次极光王、首次彩虹绽放等获得徽章。
  - 图鉴只提供收集与审美目标，不把核心玩法锁在重复任务后。
- **v1 不做**：多人实时对战、付费复活、广告奖励、复杂角色养成、强制每日签到。先把“单局掉落—碰撞—连锁”的手感做深。

### 3.6 计分与结算

- **基础分**：每次合成按新生成泡的阶级指数上升；小泡合成可见但不刷屏，高阶合成必须显著值钱。
- **连锁倍率**：同一次投放产生第 2 次融合开始递增，建议 2 连 ×1.25、3 连 ×1.6、4 连及以上 ×2.0 封顶；封顶避免一次偶发连锁压倒整局策略。
- **空间奖励**：彩虹绽放获得固定大额奖励与“舱内净空”提示；不额外赋予随机抽卡类收益。
- **结果面板**：显示总分、最高阶泡、最长连锁、投放次数、是否新纪录；并用一张小型泡堆快照式构图承接分享欲（本地，不要求社交平台接入）。
- **评价口径**：不采用“得分大于总分”的伪满分表达；以“本次称号”表现成绩，例如「试管学徒 / 折光大师 / 极光炼金师」。

## 4 · 美术风格与视觉氛围

### 4.1 题材与关键词

**深海炼金玻璃、虹彩折射、液态光泽、古铜仪器、安静实验室。**

不是常见的糖果果汁或卡通水果盘，而是一座沉在深海里的古老泡泡实验室：玩家向厚玻璃合成舱送入带有光核的炼金彩泡，看它们在蓝黑水压与铜金仪表之间聚散生长。整体要“高级、安静、治愈”，连锁爆发时才突然璀璨。

### 4.2 桌面端沉浸舞台（≥900px）

- **左侧主舞台（约 62–68%）**：
  - 深色环境中居中放置高挑的玻璃合成舱；合成舱占据视口高度核心，不做小棋盘塞在白卡片中央。
  - 投放轨道、警戒线和玻璃折射均融入器皿本身；泡堆是绝对视觉主角。
  - 舱外漂浮极淡海洋微粒、气泡上升和暖金测量刻度，营造“可呼吸的深海工作台”。
- **右侧 HUD / 控制台（约 32–38%）**：
  - 顶部为古铜铭牌式“标准舱 / 每日试验”切换与当前局状态；
  - 中部是一组玻璃胶囊徽章：总分、最高阶、连锁、纪录；数值变化有短促 bump；
  - 当前泡与下一泡以两个“小型标本舱”展示，大小、纹样与真实物件一致；
  - 底部是实体质感工具台：潮汐脉冲、暂停、重开、规则说明。按钮有悬停微浮起、按下微下沉，而非扁平网页按钮。
- **移动端（≤768px）**：玻璃舱置顶且以可视高度优先；当前/下一泡压缩为舱上细条；分数、脉冲、暂停收进紧凑底栏。禁止把桌面右栏简单挤成过长单列。

### 4.3 色彩、材质与反馈

- **主背景**：近黑靛蓝 `#101A33` 到深海蓝 `#173A56` 的纵深渐变，配合低频流光和极淡颗粒纹；借此避开站内偏亮的糖果三消与暖木连连看。
- **器皿与仪器**：透明冷白玻璃边缘、古铜 `#B7793C` 标尺、微暖金色仪表文字；不使用大面积霓虹紫，以免接近站内赛博与星轨题材。
- **彩泡**：低阶为半透明珊瑚红 / 琥珀 / 湖蓝混合，越高阶越出现珠光、多环折射和极光色带；确保色觉差异玩家也能从中心符号与外环数量辨认等级。
- **动效节奏**：
  - 投放：轨道光点随指针滑动，落下有一瞬柔和拖影；
  - 碰撞：软弹性压缩与极小水波，不做硬邦邦钢球；
  - 合成：双泡短暂被吸向中心、膨胀、爆出细小光屑，再让新泡自然落座；
  - 连锁：HUD 连锁数字逐级点亮、音阶升高、舱壁闪过压力环；
  - 结算：深海微粒向上聚成一枚巨大虹彩泡，结果卡从仪器面板浮现。
- **动效与无障碍**：所有漂浮、镜头震动、光屑与数字 bump 均受 `prefers-reduced-motion` 控制；降级后保留状态颜色、数字和静态轮廓变化，不把“连锁发生了什么”只交给动画传达。

### 4.4 门户封面提案

- **封面主体**：一枚占画面约 65% 的、带三层虹彩折射环与星屑光核的“极光王泡”，下方托着一个小一号同纹样泡，暗示二者即将合成；两者作为一个居中主体构图。
- **风格约束**：640×640 WebP、3D 软胶 / 玻璃混合质感、单一中心主体、深靛蓝到海蓝渐变背景、少量漂浮微泡、**零文字**。
- **排重理由**：深靛蓝深海底配古铜暖点，与现有蓝紫赛博块、草绿果园、亮青柠拼图、暖橙矿工、绯红民俗牌桌均有明显材质与题材差异。

## 5 · 制作人拍板与开放探讨

1. **首发节奏（推荐 A）**
   - **A. 静水解压 + 高分挑战（推荐）**：标准舱不设倒计时，危险线是唯一压力；让玩家慢慢观察、追逐自然连锁。
   - **B. 90 秒极速实验**：投放节奏更快，适合动作玩家，但会削弱“看物理连锁”的治愈感。
   - **C. 两者都有**：首发同时做标准舱和极速实验，内容更全但会分散首轮打磨重心。

2. **潮汐脉冲的力度（推荐 A）**
   - **A. 每局 2 次轻推（推荐）**：只做微幅扰动，作为可学习的救场工具，不改变“落点第一”的核心。
   - **B. 每局 3 次强推**：爽感更高，易出现人为强制连锁，风险是稀释物理布局的价值。
   - **C. 完全不做**：最纯粹的经典落泡体验，但新手坏局更容易直接弃局。

3. **顶阶双王的终局表达（推荐 A）**
   - **A. 彩虹绽放后继续玩（推荐）**：高额奖励 + 腾空空间，适合高分局与反复分享。
   - **B. 双王即“完美合成”结局**：仪式感强、目标明确，但会缩短高手局的续航。
   - **C. 双王仅普通合成**：规则最简，但会浪费游戏最难出现的一刻。

## 6 · 推荐立项结论与下一步

**推荐立项：`bubble-bloom`，采用“静水解压 + 标准舱高分挑战 + 每日固定种子 + 每局 2 次轻潮汐脉冲 + 双王彩虹绽放后继续玩”的 A/A/A 组合。**

这个组合保留同类泡泡碰撞变大的原始直觉，以成熟的容器压力与连锁反馈保证上手即爽，又用深海炼金、美术语义、双预览、轻度救场和双王奖励把它做成不等同于水果合成或 2048 的 DOIN 独立作品。首轮制作应优先验证：**落点跟手、碰撞不飘、合成瞬间、连锁节奏与危险线公平性**；这五点一旦成立，图鉴与每日试验都能自然承接长期可玩性。
