## 1 · 创意概念与核心乐趣

- **游戏名称**：操场大乱斗 · 放学别走 / Schoolyard Brawl / 建议 slug：`brawler`（单个简短纯英文单词，符合 slug 极简契约；即“清版动作”品类名，无歧义）
- **一句话玩法**：横版清版动作，轻重拳连招加投掷物，把一波波对手打飞出屏幕，闯过放学路。
- **核心乐趣与卖点**：
- 拳拳到肉的打击感：轻拳三连节奏明快，重拳一记闷响，对手应声倒地，反馈干净利落；
- 一拳击飞的解压爽感：重拳与必杀能把对手打飞出屏幕边缘，带抛物线与尘土，烦心事跟着一起飞出去；
- 连招爆发的节奏感：轻拳接重拳接跳踢，连上了有伤害加成，手感越打越顺；
- 放学路的童年共鸣：操场、篮球架、双杠、沙坑，谁没在放学路上跟人“约过架”（卡通化点到为止，绝无写实暴力）。
- **核心循环**：走进场景 ➔ 敌人涌上 ➔ 连招 + 投掷清场 ➔ 捡道具回血 ➔ 打 Boss ➔ 下一关。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
- **Streets of Rage 2（世嘉，1992）**：清版动作的教科书。最受认可的机制是“轻拳连打 + 抓取背摔 + 必杀耗血”的三层战斗系统，以及“双人合作打配合”的社交属性；连招流畅、判定宽松、绝无廉价死亡，是“易上手难精通”的典范。
- **Double Dragon（Technōs，1987）**：腰带卷轴清版动作的开山作，定义了“双人合作 + 连续卷轴推进”的品类格式；场景道具可捡可扔，是本作投掷物的直接出处。
- **Iron Snout / Bacon May Die（Poki 热门格斗）**：网页端清版动作的现代标杆，证明了“快节奏反应窗口 + 击飞爽感”在浏览器里极受欢迎，单局 2~3 分钟、随时能开一局。
- **我们要继承的成熟机制**：
- 轻拳三连 + 重拳击飞 + 跳踢的连招骨架（状态机清晰，连招可练）；
- 靠近自动抓取 + 背摔（对付包围的神技）；
- 场景道具可捡可扔（书包、篮球、扫把都是武器）；
- 必杀耗血换爆发（关键时刻的翻盘按钮）。
- **本作的独特魅力与微创新（Twist）**：
- 平台完全空白的赛道：站内尚无横版清版动作类，街机格斗是经过三十年验证的大众玩法；
- “击飞”做成核心爽点：不只打倒，更要打飞——重拳与必杀把敌人打飞出屏幕边缘，带抛物线、旋转与尘土，击飞数单独计分；
- 操场题材全套场景化：篮球架、双杠、沙坑、单杠既是布景也是武器来源，敌人是“高年级小霸王”“体育委员”等卡通化对手，点到为止绝无写实暴力；
- 同屏双人首发：一台设备两个人面对面打，放学路就该两个人一起走。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：与站内动作类同属大类，但规则模型截然不同——本作是“横版卷轴清版格斗”，不是平台跳跃、不是单挑格斗；胜负不靠跳跃躲坑，靠连招清场与击飞计数，坚决杜绝换皮。

## 3 · 玩法规则与交互说明

- **核心规则**：
- **盘面构成**：横版卷轴操场（跑道、篮球架、双杠、沙坑分段出现），每关 3 波小怪 + 1 个 Boss；血条在顶栏，击飞计数在角落。
- **玩家合法操作**：轻拳（J）三连、重拳（K）击飞、跳（Space）+ 拳 = 跳踢、靠近自动抓取后按 K 背摔、拾取场景道具（L）后按 L 投掷、必杀（U）耗 10% 血清屏小怪。
- **胜利条件与失败条件**：清掉当前波次全部敌人才能向前推进，打倒 Boss 即过关；血条见底则输，可续关（每关 3 次续关机会，续关后满血重打当前波次）。
- **容错与无死局说明**：本作无随机关卡，敌人波次与 Boss 招式均为关卡配置表固定；被围攻时抓取背摔自带短暂无敌帧；续关兜底，任何一关都不会卡死。
- **数值（初版建议，开发时可微调）**：玩家血量 100；轻拳每击 6 点、重拳 15 点并击飞、跳踢 10 点、背摔 20 点、投掷物 12 点、必杀对小怪 40 点；小怪血量 20~40，Boss 血量 200~300；每关 3 波（3/4/5 人）+ Boss。
- **操作与手感**：
- 键盘 WASD 移动，J 轻拳，K 重拳，Space 跳，L 拾取 / 投掷，U 必杀；P / Esc 暂停；触屏虚拟摇杆 + 按钮；
- 出拳有 0.1 秒前摇 + 命中顿帧（0.05 秒），重拳命中带屏幕轻震，击飞带抛物线 + 尘土粒子；
- 误触容错：必杀发动前有 0.3 秒蓄力可取消（再按 U 取消）；投掷物捡起后 5 秒不用自动放回原地。
- **随时可暂停与失焦保护机制**：本作是实时性动作玩法，必须配备顶栏常驻醒目的「暂停 / 继续」按钮与 P / Esc / 空格快捷键，暂停时冻结主循环与敌人行动并显示轻量半透明遮罩（继续 / 重新开始）；切标签页或最小化时自动静默暂停，回来后局势原样不动。
- **即开即玩与平滑选关设计**：初次打开直接进入第 1 关（操场跑道），角色与第一波敌人直接就绪，无需前置点击；顶栏常驻醒目的「选关」按钮，点击以轻量抽屉展示章节关卡网格；结算面板提供「下一关」与「选关」。
- **模式与内容编排（依玩法特质定制，不套无尽冲分）**：
- **章节关卡制（默认）**：12 关，4 章（操场跑道、篮球场、小卖部后巷、教学楼天台），每 3 关一个 Boss（体育委员、篮球队长、小卖部老板、天台学长）；
- **同屏双人**：P1 用 WASD + FGH，P2 用方向键 + 小键盘 123，合力清场，击飞数分开计；
- **街机模式**：限时 3 分钟连打，击飞数即得分，分数只作本局记录，不设全站排行；
- **评级**：每关按用时与剩余血量评一至三星。
- **游戏目标与反馈体系**：核心指标不是总分，而是**击飞数**与**过关评级**；Boss 战胜利结算播放“夕阳下两人击掌”的小动画，击飞满 10 次触发“满天星”彩蛋。
- **双语核心词汇与数据键名规划**：
- 模式：章节关卡 Level Mode / 同屏双人 Local 2P / 街机模式 Arcade Mode；
- 实体：轻拳 Light Punch / 重拳 Heavy Punch / 背摔 Suplex / 必杀 Special / 投掷物 Throwable / 小怪 Grunt / Boss；
- 数据层约束：所有关卡、敌人、道具数据一律用字符串 key 或 id（如 `level_04`、`enemy_senior`、`item_basketball`），展示层通过 `i18n` 获取文本，严禁在数据文件里裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：放学、黄昏操场、卡通格斗、解压、热血。
- **专属视窗物理隐喻**：**“放学后的操场”**——整个画面就是一片黄昏操场：跑道在脚下，篮球架与双杠立在两侧，沙坑在远端；HUD 是一条粉笔字黑板条（血条画成粉笔线，击飞数写在黑板角）。拒绝左右双翼三栏套路，战场居中、信息压在上下两条。
- **立体质感与渲染路线裁决**：纯 DOM + CSS 3D 为主（角色与场景用 CSS 造型 + 位移动画，击飞用 CSS 抛物线），Canvas 2D 只做尘土与星星粒子。**不采用 Three.js**——横版 2D 动作无真三维空间翻转需求，CSS 3D 已足够且秒开零发热。
- **声效风格与材质音色规划（4~6 种，拒绝单音蜂鸣器）**：
- 轻拳：短促“啪”声（物理噪声滤波）；
- 重拳：闷响 + 低频下潜（失谐多振荡器）；
- 击飞：呼啸风声（噪声扫频）；
- 落地尘土：沙沙声（物理噪声）；
- 捡道具：清脆“叮”（FM 合成）；
- Boss 登场：小鼓点三连（打击乐采样感合成）。
- **封面设计提案**：3D 软胶质感、单一居中主体（一个挥拳的卡通学生，占 60~75%，无文字）、鲜艳渐变背景（黄昏橙到操场绿）。

## 6 · 制作人拍板与开放探讨

1. **双人：同屏双人首发 vs 先单人后补双人**——方案 A：首发即含同屏双人（操场题材最适合面对面一起打）；方案 B：先单人，双人后续补。推荐 A。
2. **难度曲线：敌人种类递增 vs 敌人数量递增**——方案 A：种类递增（新敌人带新招式，更有新鲜感）；方案 B：数量递增（同种敌人越堆越多）。推荐 A。
3. **画风：扁平卡通 vs 像素复古**——方案 A：扁平卡通（清爽、贴合操场题材）；方案 B：像素复古（街机味浓）。推荐 A。
