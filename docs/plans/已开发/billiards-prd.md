## 1・创意概念与核心乐趣



* **游戏名称**：绿呢桌球 / Billiards: Felt & Cue（副标：8-Ball 经典落袋撞球）/ 建议 slug：`billiards`

* **一句话玩法**：俯视绿呢球台拉杆瞄准，以动量守恒物理击打母球，把本方花色球逐一落袋，最后合法击入黑八 —— 同时小心别让母球与黑八误入袋口。

* **核心乐趣与卖点**：


  * **拉杆击球的实体手感（Cue Pull & Strike）**：瞄准不是点一下完事 —— 母球后方悬着球杆，玩家把杆身**往回拉**、力度条随之深压，松手一记实打实的击球。拉多深、打多偏，直接决定母球下旋、上旋与侧旋的走位，每一杆都是 "手腕上的物理学"；

  * **动量守恒的碰撞美感（Momentum Poetry）**：等质量球的弹性碰撞、库边的低弹响、角度吃满的翻袋、目标球与母球分离角 —— 两颗球一碰，路线像提前写好的剧本一样展开。玩家读得懂台面，就能 "指挥" 一杆之后母球停在哪；

  * **布局解构的策略快感（Table Chess）**：一杆清台不是蒙的 —— 先打哪颗、给母球留什么位、哪颗球是下一杆的 "桥"、要不要做一杆防守，台面就是可以拆解的棋盘；

  * **同屏双人的轮流博弈（Same-Screen Duel）**：同一张球台、同一根球杆，两人轮流上场；你留的刁钻球位就是对手的难题，犯规与母球落袋直接交出手中球 —— 攻防一体的社交桌游感；

  * **英伦复古桌面的高级质感（Gentleman's Club）**：祖母绿台呢、胡桃木库边、黄铜袋角、琥珀吊灯光晕 —— 这是 "极其高级" 的桌面美学，不是廉价换皮。

* **核心循环**：



```
观察台面布局 ➔ 移动瞄准/挑选目标球 ➔ 拉杆蓄力定力度（可选旋转）➔ 击球
     ↑                                                          ↓
母球走位决定下一杆的牌面 ← 目标球落袋（连击+1）/ 未进（换手）← 动量碰撞物理结算
     ↓（单人模式）                                       （双人模式）
限杆数内清台 ➔ 星级/最佳杆数结算 ➔ 挑战更优残局       回合交替 ➔ 对手手中球/自由球
```

**我们要继承的成熟机制**：



1. **俯视瞄准 + 拉杆力度（Aim-Drag Power）**：移动瞄准线选目标球，拉杆回拉蓄力、松手击出；瞄准辅助线仅提示母球直线路径，不代算翻袋，保留读台空间；

2. **开球定组（Break & Group Claim）**：开球进球延续回合但不定组，之后首个合法进球决定本方花色（全色 1–7 / 花色 9–15）；

3. **犯规判罚体系（Foul & Ball-in-Hand）**：母球落袋 / 未先碰本方球 → 对手**手中球**（全台任意摆放母球）；黑八提前落袋或犯规连带黑八 → **直接判负**；

4. **连续进球延续回合（Run & Turn）**：进球继续击球、连击累加，未进球或犯规换手 —— 这是 8 球最核心的节奏引擎；

5. **三档旋转（Follow / Draw / Sidespin）**：继承成熟物理 —— 跟杆（击点偏上）母球随球跟进、刹车（击点偏下）母球回拉、侧旋改变碰库后分离角，但**裁剪为三档点击式**，降低上手门槛。

**本作的差异化微创新（拒绝无聊照搬）**：



1. **英伦绿呢复古桌台美学（Felt & Brass）**：不做网游式 3D 炫光，而是把整张台球桌做成 "可以入画的英伦俱乐部一景"—— 祖母绿台呢纤维质感、胡桃木台帮、黄铜袋角、琥珀吊灯光晕与漂浮尘埃，桌面本身就是高级摆件；

2. **台呢轨迹残留（Felt Trail）**：球在台呢上滚过留下**渐隐的绒毛轨迹**，高手用它读线复盘，新手靠它理解 "球是这么滚的"，物理可视化教学一体；

3. **旋转三档极简化（3-Tap Spin）**：复杂九点旋转盘裁剪为**跟杆 / 刹车 / 侧旋**三档，点击切换、击点可视化，保留旋转深度的 70% 手感、省掉 90% 学习成本；

4. **单人清台试炼 + 同屏双人双模式（Trial & Duel）**：单人不靠对手也能享受 "限杆清台" 的挑战评级（星级 / 最佳杆数），双人则完整继承规则博弈 —— 一个物理引擎服务两种截然不同的乐趣；

5. **固定种子确定性开局（Seeded Rack）**：开球球堆与残局布局全部确定性种子生成，同一种子逐帧一致可背板、可测试、可分享 "同一张台"。

## 3・玩法规则与交互说明

### 3.1 场景构成（标准美式 8 球台，俯视 2D）



* **球台**：台面长宽比 **2:1**（物理单位以 "球直径 D" 为基准：台面 56D × 28D，与标准 9 尺台比例一致）；四边**胡桃木库边**（弹性挡墙）、**六个袋口**（四角 + 两中袋），袋口为内切圆弧，球心进入袋口半径即判落袋；

* **球**：1 颗母球（白）+ 15 颗目标球 —— 全色球（Solids 1–7：纯色带数字环）、花色球（Stripes 9–15：白色底 + 彩色半环带）、黑八（8，纯黑带数字环）；全部等质量、等半径（碰撞遵循动量守恒）；

* **初始球堆（Rack）**：三角架摆放于台尾，顶点对准台面中心；母球置于开球线后方自由区，开球必须从开球线后击出；

* **库边钻石标记（Diamonds）**：台帮内侧按等分镶嵌 3 颗黄铜钻石点，作为翻袋角度参考刻度。

### 3.2 判定与胜负规则（8-Ball 轻量裁剪版）



1. **开球（Break）**：合法开球 = 至少 4 颗目标球碰库或任一球落袋；不合法则对方可接受台面继续或要求重新摆球重开；

2. **定组（Group Claim）**：开球落袋**只延续回合、不定组**；此后双方任一方的**首个合法进球**决定其花色（进全色打全色、进花色打花色）；黑八除外；

3. **回合流转（Turn）**：合法进球 → 继续击球（连击 +1）；未进球 / 犯规 → 换手（连击清零）；

4. **犯规判罚（Foul）**：

* 母球落袋（Scratch）→ 对方**手中球**（全台任意位置摆放母球，摆放后击球）；

* 击球未先接触本方目标球 → 对方**手中球**；

* 击球无任何球落袋且无球碰库 → 对方**手中球**（轻量版：统一并入未中库判罚）；

1. **黑八规则（8-Ball）**：本方 7 颗球全部清完后，合法击入黑八即**获胜**；黑八**提前落袋**、或犯规时连带落袋、或黑八落袋的同时母球落袋 → **直接判负**；

2. **单人清台试炼（Clear the Table）**：无对手，采用同套 8 球规则但**犯规不换手**—— 改为**犯规 +1 杆**并触发手中球；目标是在**限定杆数（par）内清台**，评级三星。

### 3.3 模式与内容编排（拒绝套路化三件套）



* **单人清台试炼（Clear the Table，主打）**：以 "清台" 为唯一目标，评价体系 =**星级 + 最佳杆数**，绝不做无尽冲分：


  * ★ 完成清台；★★ 杆数 ≤ 本局 par；★★★ 全程零犯规；

  * 连续进球（Run）达 3 杆、5 杆有专属连击反馈与音阶爬升，清台瞬间金粉与琥珀光晕爆发；

  * 内容编排按残局布局递进（见拍板项 1）：从 "球堆松散好清" 逐步到 "贴库球、一库解、黑八贴库收官"，每局布局由确定性种子生成、可背板可分享。

* **同屏双人（Same-Screen Duel）**：同一张球台、同一指针轮流击球，完整 8 球规则；回合权用台面上的 "击球权小旗" 醒目提示，犯规立即弹出判罚播报（手中球 / 判负）；记录双方胜场（本次会话内）。

* **练习辅助（Practice Aid）**：任意模式可选开关 "瞄准辅助线"（仅显示母球直线路径）、"旋转击点预览"，通关后可自由开关，避免辅助变成依赖。

### 3.4 无死局与公平保证（数学可解性）



1. **物理开放域**：台球是连续物理空间，不存在 "死格"，任何局面母球都可通过合法击球或手中球改变位置；

2. **开局可解性审计**：每局残局布局生成后跑**模拟器可达性校验**—— 断言台面上存在至少一颗可被合法首击（直线或一库可达）的本方球；母球被完全围死（无任何合法接触角）的局面在生成时直接丢弃重排；

3. **手中球救济（Ball-in-Hand）**：即便对局中演化出极端 "被做死" 局面，犯规即给对方手中球 —— 规则层面保证永不陷入无法出杆的僵局；

4. **确定性契约**：球堆 / 残局种子 + 输入序列唯一决定整局物理演化，支持同种子重放与自动化验证；物理引擎测试包含 ≥1000 步随机合法操作游走（状态机不崩、球数守恒、能量钳制不变式）与 CCD 不穿球断言。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）



* **桌面鼠标（主路径）**：


  * 移动鼠标 = 旋转 / 平移瞄准（瞄准线从母球沿直线指向目标球）；

  * **按住左键向后拖动 = 拉杆蓄力**（杆身真实回拉、力度条深压），**松手 = 击球**；Input Buffer：松手瞬间 60ms 窗口内接受击球指令，快速连点不吞杆；

  * 滚轮 = 微调力度；右键（或按 `F`/`D`）循环切换旋转三档（跟杆 / 刹车 / 侧旋）；点击母球并拖拽 = 手中球摆放；

* **键盘**：`←/→`（或 `A/D`）微调瞄准角，`↑/↓`（或 `W/S`）增减力度，`空格` = 拉杆蓄力（按住）→ 松手击球，`Tab` 或 `Q` = 循环切换旋转档，`Enter` = 确认手中球摆放；`Esc` = 暂停 / 退回弹层；

* **移动端（触控）**：拖动屏幕旋转瞄准 → 母球后方下拉蓄力 → 松手击球；左侧旋转档三键、右侧力度条；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡击球操作区；

* **手感调优**：击球瞬间母球轻微 "顿挫" 反馈（后坐 + 台呢绒毛微溅）；力度条三段色阶（轻推 / 中力 / 大力）配音高渐变提示；瞄准时目标球**进袋路径高亮**（仅当存在直线 / 一库路径时弱提示，翻袋留白给玩家）。

## 4・题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

本作不是 "一张网页里嵌个游戏"，而是一幅**英伦台球俱乐部的横截面静物画**：

1. **桌面即舞台**：整张球台**嵌入胡桃木吧台面**居中呈现，四边台帮承载全部控制件 —— 力度滑杆、旋转三档、操作按钮一律做成**台帮木质嵌入件与黄铜拨杆**，绝无四角散落浮动按钮，绝无右侧白底 SaaS 卡片堆；

2. **顶部氛围层**：墨绿天鹅绒墙面背景 + 一盏琥珀吊灯悬于台面上方，投射出椭圆形光晕与**漂浮尘埃微粒**（微动粒子），拒绝死黑 / 死白大平铺；返回、音效、语言收纳进顶框一体化状态条；

3. **记分板原生形态**：双人回合权用台面上方**悬挂的黄铜翻牌记分板**呈现（当前击球方小旗、比分、连击），犯规播报像俱乐部侍者递上的一张 "判罚卡"；

4. **移动端（≤768px）**：台面缩放至全宽竖持视角，台帮控制件收折为台面下方的木质托盘条，保留完整操作区与底部广告避让间距；

5. **质感细节**：台呢烘焙纤维纹理（Canvas 2D 噪声纹理）+ 球体 3D 软胶质感（径向渐变 + 高光 + 数字环），球的**台呢轨迹残留**渐隐；库边内弧形反光、黄铜袋角在球落袋时闪光；可读性提示一律用**无边界径向柔光**（禁硬边描边圈）。

### 4.3 立体质感与渲染路线裁决



* **裁决：纯 Canvas 2D 物理舞台 + DOM/CSS 3D 桌台框体**（不做 Three.js）：


  * 物理与台面绘制（台呢纹理、球体、轨迹、粒子）→ Canvas 2D，120fps 秒开零发热；

  * 桌台立体感（胡桃木台帮厚度、吊灯投影、黄铜件浮雕）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD / 记分板 / 弹层全部严格留在 DOM 层；

  * 理由：俯视 2D 台球物理天然是平面空间，不存在真 3D 视角需求，Three.js 无必要。

## 5・制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：单人清台试炼的内容编排？



* **选项 A（残局编排制・推荐）**：编排 10\~12 局由易到难的残局试炼（第 1 局松散球堆熟悉手感 → 贴库球 → 一库翻袋解 → 黑八贴库收官），每局独立种子、独立 par 与三星评价，成长线清晰、可反复挑战；

* **选项 B（单一经典清台）**：只做一张标准 8 球台 + 三星评价 + 最佳杆数榜，极简克制，开发量最小；

* **选项 C（清台试炼 + 每日残局）**：在 A 的基础上追加 "每日一局种子残局"（按日期播种，全站同日同台），增加话题性与重复拜访。

### 拍板项 2：旋转系统的手感深度？



* **选项 A（三档极简旋转・推荐）**：跟杆 / 刹车 / 侧旋三档点击切换 + 击点可视化，保留旋转走位 70% 深度、上手零门槛，与 "高级但克制" 的英伦气质一致；

* **选项 B（九点旋转盘）**：完整 9 位置击点 + 精细力度调节，硬核向、走位控制力最强，但操作学习成本高；

* **选项 C（无旋转纯物理）**：只有角度与力度，最纯净的 "读台" 体验，适合极简派。

### 拍板项 3：开球与球堆的确定性策略？



* **选项 A（固定种子可背板・推荐）**：球堆 / 残局全部确定性种子生成，同一种子逐帧一致 —— 可背板、可测试、可分享 "同一张台"，与平台确定性测试契约完全对齐；

* **选项 B（随机洗牌）**：每次开球随机洗牌，新鲜感强但无法背板复盘，测试覆盖难度上升。
