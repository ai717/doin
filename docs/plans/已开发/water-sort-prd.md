# 《色彩排序》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

## 1・创意概念与核心乐趣



* **游戏名称**：色彩排序 / Water Sort / 建议 slug：`water-sort`（候选 `liquid-sort`、`color-tubes`）

* **一句话玩法**：把试管里层层叠叠的彩色液体倒来倒去，同色归同管，直到每根试管只剩一种颜色。

* **核心乐趣与卖点**：


  * **"把混乱理成秩序" 的极致满足**：看一管乱糟糟的混色液体被一步步倒成纯净色带，是水排序品类横扫全球的核心爽感 —— 规则一眼懂、深度无限长；

  * **丝滑倾倒的手感表演**：倾倒动画是本作的灵魂 —— 液体沿管壁流下、颜色段位移、满管清脆收声，把每一次 "倒" 都做成看得见摸得着的小仪式；

  * **零压力纯逻辑**：无计时、无惩罚，卡壳就撤销重来，是 "随手拿起、随时放下" 的安静思考游戏，与站内快节奏街机形成互补；

  * **破局的顿悟**：把堵路的颜色暂时 "借走" 到空管、再迂回归位 —— 水排序的 "借道" 智慧是它最上头的时刻。

* **核心循环**：



```
观察管口颜色 → 选中试管 → 倒向同色顶/空管 → 液体流动动画 → 逼近纯色管

&#x20;   ↑\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_↓

卡壳？撤销一步 / 重开本关 → 继续 → 全部试管纯色 = 过关
```

**经典标杆与成熟参考**：

| ----------------------------- | ------- | ------------------------------ | ------------------------- | --------------------- | -------------------- |
| Water Sort Puzzle（品类鼻祖）       | 全球爆款    | 试管倒液体、只能倒同色顶 / 空管、全纯色过关        | 极简规则 + 深度策略；关卡手工精调        | 核心规则、关卡递进节奏           | 广告过密、数值逼氪            |
| mojgames / zenplay Water Sort | Web     | **无计时无惩罚、每关生成并验证可解、无限重开**      | "always solvable" 承诺是信任基石 | **生成 + 验证可解、无限重开零惩罚** | 纯随机生成关卡良莠不齐          |
| Arealme Water Sort            | Web     | **隐藏层**（底层颜色被遮蔽）+ **撤销限量作为资源** | 信息不全制造策略深度                | 可选 "隐藏层" 变体（拍板项）      | 撤销限量偏硬核，默认给无限        |
| Sortcery                      | 移动端     | 瓶型解锁（细瓶 / 烧瓶 / 罐 / 靴）+ 重力翻转道具  | 异形瓶 = 纯视觉 + 轻微策略双满足       | **异形试管解锁**（拍板项）       | 道具太多冲淡纯粹             |
| Color Water Sort 3D           | 移动端     | 3D 玻璃器皿 + 真实流体                 | 证明 "倾倒画面" 值得打磨            | 液体流动动画的精致度            | 3D 视角反而难判断层深，2D 清晰优先 |

**我们要借鉴什么**：核心 "只倒同色顶 / 空管" 规则、生成 + 验证可解、"无计时无惩罚 + 无限撤销重开" 的信任设计、Sortcery 的异形试管、3D 版的倾倒画面意识。

**我们的差异化微创新**（不是换皮）：



1. **倾倒即表演（核心手感）**：液体流动动画做成本作名片 —— 管口倾斜、液面跟随、颜色段整段滑动、满管收声，配合水彩质感，把 "倒" 这个动作做到 web 端同类最优；

2. **异形试管渐进解锁**：经典试管 → 细颈瓶（倒速略慢、视觉更精致）→ 烧瓶 → 量杯，解锁即视觉奖励，也带来轻微的 "容器宽度" 策略变化；

3. **关卡生成 = 反向构建 + 求解器实算 par**：从完成态反向倒推生成初始盘面，**数学上保证 100% 可解**；par 由求解器实算（启发式搜索），玩家知道 "标准线" 在哪；

4. **每日挑战（同日同题）**：同日期同种子盘面，全球同题比步数；DOIN 生态特色。

**品类排重 / 与《星轨调度大师》（orbit-sort）的关系（重要）**：



* orbit-sort 已上架：把彩色星体调度穿过星核，轨道恢复纯色（球体调度 + 中转轨）；

* 本作：试管液体倒换，只能倒同色顶 / 空管（液体分层 + 倾倒）；

* 二者同属 "颜色分类" 家族，但**操作模型完全不同**（倒液体 vs 调度球体），体验差异大（水排序 "借道空管" vs 星轨 "中转轨道"）。业界也视二者为相邻但独立的品类（Ball Sort 与 Water Sort 长期并存）。本作定位 "纯逻辑放松"，与 orbit-sort 的 "调度操作" 错开，制作人确认后可作为独立立项。

## 3・玩法规则与交互说明

### 核心规则



* **场景构成**：


  * 一排透明试管（每关 N 色 × 每色 4 格容量），含 **2 根空管**作为借道缓冲；

  * 关卡规模：从 2 色 3 管到 12 色 14 管递进（每色恰好装满一根管）；

  * 中期解锁异形试管（细颈瓶 / 烧瓶 / 量杯）—— 容量不变，改变视觉与 "倒速" 节奏。

* **玩家合法操作**：

1. **选中试管** → 高亮（管口光圈 + 轻微上浮）；

2. **倒入目标管** → 判定：目标管为空，**或目标管顶部颜色与源管顶部颜色相同且剩余空间足够**；

3. 一次倒入 = 源管顶部一整段同色液体；

4. 规则唯一、无其他操作 ——**倾倒不合法时目标管抖动提示，绝不吞操作**。

* **胜利与失败条件**：


  * **胜利**：每根试管全为纯色（或空管）—— 唯一通关态；

  * **失败**：无硬性失败；无任何合法操作且未完成（极端卡死）→ 提示 "重开本关"（无限重开，零惩罚）。

* **容错与无死局说明**：


  * **生成保证**：关卡由完成态**反向构建**生成，初始盘面必然存在一条合法倒序序列 → 100% 可解；

  * **运行时兜底**：实时检测 "无合法操作且未完成" 的卡死态，自动提示重开（不影响进度与已得成就）；

  * **撤销**：默认无限撤销（悔一步），重开一键。

### 操作与手感



* **鼠标**：点击试管选中 → 点击目标管倒入；再点选中管 = 取消；右键 = 撤销一步。

* **触屏**：轻点选中 → 轻点目标管倒入；点已选中管 = 取消。

* **键盘**（桌面加分项）：←/→ 切换选中管 + Enter 倒入 + Z 撤销。

* **手感优化**：


  * 倾倒动画：管口倾斜 → 液体沿壁流下 → 顶部色段滑动入位 → 满管轻微晃动收声；

  * 选中 / 取消有 120ms 输入缓冲防连点误操作；

  * 撤销 / 重开零冷却，路径 "先动起来再纠结"。

### 模式与内容递进



* **首选模式：50 关关卡制（5 章 × 10 关）+ 无尽随机 + 每日挑战**。

* 关卡递进（波浪式，章内起伏、整体上升）：


  * **第 1 章「入门」**：2–3 色，空管充足 —— 教学 "借道"；

  * **第 2 章「借道」**：4–5 色，空管收紧 —— 第一次必须借走堵路色；

  * **第 3 章「烧瓶」**：6–7 色 + 解锁异形试管；

  * **第 4 章「缠绕」**：8–9 色，多层缠绕布局（同一色分散在 3+ 管）；

  * **第 5 章「大师」**：10–12 色，空管最少、布局最纠缠；

* **无尽随机**：任意难度参数随机生成（仍走反向构建 + 验证）；

* **每日挑战**：同日期同种子盘面（中高难度），比 "最少步数" 通关，同题竞技。

### 目标与评价



* **计分维度**（建议口径，供开发校准）：


  * `单关得分 = 基础分 + 步数分 + 时间分`（对齐门户三维惯例，但时间分从宽 —— 本作零压力）；

  * **基础分**随关卡递进（第 1 关 200 起，逐章 +40 左右）；

  * **步数分**：par 由求解器实算（最优 / 近优步数），≤par 满分、超步数递减、保底；

  * **时间分**：满分时长宽裕（如 par 步数 × 8 秒），超时每 10 秒 -1、保底 ——**只奖不罚**，绝不制造倒计时焦虑；

  * 满分参照：单关满分 800（对齐门户惯例），选关页显示历史最高分。

* **评价体系**：通关弹窗 "得分 X/800 + 步数 /par + 撤销次数 + 🏆 新高分"；无星级；每日挑战展示 "历史最少步数" 纪录。

## 4・美术风格与视觉氛围



* **题材与视觉关键词**：**水彩玻璃实验室・清透液体质感・柔光工作台・安静治愈・轻微学院风**

  （不做霓虹、不做暗黑、不做糖果 —— 与站内全部题材拉开，走 "清爽专注" 路线。）

* **桌面端沉浸游戏舞台设计（≥900px）**：


  * **左主舞台**：试管阵列置于 "柔光实验台"—— 暖木台面 + 背后柔和水彩光斑 drift；试管为高透玻璃（描边高光 + 底部反光），液体为半透明渐变（带顶部液面弧线 + 微小气泡）；

  * **右侧信息操作栏（实验记录 HUD）**：


    * 顶部 "关卡匾额"：第 X/50 关 + 本章名（如 "借道"），卡片化；

    * 中部 "计分牌卡"：得分 / 步数・par / 撤销次数，胶囊徽章化 + bump 跳字；

    * 底部 "操作台"：撤销、重开、提示三枚实体质感按钮（悬停微浮起、点击物理下沉）；

  * 移动端（≤768px）：单列紧凑，试管自适应屏宽，操作台贴底。

* **色彩与环境氛围**：


  * 主色：暖木台面 `#B98A5E` + 试管液体取 8–10 个高辨色（正红 / 橙 / 明黄 / 翠绿 / 青 / 蓝 / 紫 / 粉 / 棕 / 灰，彼此明度错开）+ 页面底色米白 `#F7F3EC`；

  * 背景：柔光工作台环境光晕 + 细噪点纸纹，仿 "午后实验室一隅" 的安静专注感，拒绝死白灰底；

  * 关键动效：


    * **选中**：管口光圈呼吸 + 试管轻微上浮；

    * **倾倒**：管口倾斜 + 液体沿壁流下 + 色段滑动入位 + 满管轻晃；

    * **通关**：全管逐根点亮纯净色 + 金色粒子 + 轻快叮咚（仪式感）；

    * **非法倾倒**：目标管轻轻抖动（提示性，不弹窗）；

  * 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

* **封面设计提案**：


  * 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字；

  * **主体物件**：一根圆滚滚的软胶试管居中，内里是红黄蓝三段渐变液体（玩具感），两侧各斜靠一支装着单色液体的小试管，像 "分类进行时" 的定格；

  * **背景色相**：**橙红系**（果汁试管感，未被占用且未在策划案中使用；紫红作备选），与现有 15 张封面不撞色。

## 5・制作人拍板与开放探讨



1. **与《星轨调度大师》的定位关系（先定这个）**：

* A. **独立立项**（操作模型、体验节奏差异大：液体倒换 vs 轨道调度，业界视为相邻独立品类；推荐）；

* B. 认为与 orbit-sort 太近，换玩法方向（可提出新方向）。

1. **变体机制（差异化浓度）**：

* A. **异形试管渐进解锁**（细颈瓶 / 烧瓶 / 量杯，纯视觉 + 轻微节奏差异，默认推荐）；

* B. **隐藏层**（部分试管底层颜色遮蔽，信息不全更烧脑，Arealme 式）；

* C. 纯经典试管（做深手感，最简单纯粹）。

1. **模式结构**：

* A. **50 关关卡制 + 无尽随机 + 每日挑战**（默认推荐，内容最完整）；

* B. 纯 50 关关卡制 + 每日挑战；

* C. 纯无尽随机 + 每日挑战。
