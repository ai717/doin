## 1 · 创意概念与核心乐趣

- **游戏名称**：叠叠乐 / Jenga Tower（副标：抽≠堆 · 结构博弈）/ 建议 slug：`jenga`
- **一句话玩法**：从 18 层木塔里抽出承力最轻的木块叠到塔顶，让塔越垒越高——直到某一次抽错或堆歪，整塔轰然倒塌。
- **核心乐趣与卖点**：
  - **读塔的空间直觉（Tower Reading）**：每一块木块都在"承重"——有的被压得死死的、有的悬在边缘摇摇欲坠。高手扫一眼就知道哪块是"安全块"：这是纯空间推理的脑力爽感；
  - **抽≠堆的双轴博弈（Pull ≠ Stack · 用户点名核心）**：**抽块**削的是支撑、伤在塔底；**堆叠**加的是高度与重心、险在塔顶——两个动作是两套完全不同的风险系统。抽错 = 支撑坍塌，堆错 = 重心失衡，每一步都在"拆旧塔"与"垒新塔"之间做权衡；
  - **塔倒判定的临界心跳（Brinkmanship）**：四档判倒（4/4/3/4）让塔永远悬在"差一点就倒"的钢丝上——塔身咯吱、木屑微颤，判危度逼近时连击倍率还在涨，心都提到嗓子眼；
  - **连击封神的指数诱惑（Spire Streak）**：连续成功抽叠连击倍率 **×3 翻叠**，极限 **3¹⁸ = 387,420,489 倍**——一塔封神、木纹流光，极限塔玩家的终极幻象；
  - **品类空白补位（Structural Gap）**：DOIN 62 款游戏中没有结构稳定性博弈——与 `candy-drop`（坠落反应）和摆锤类（摆动物理）完全不同，本作是"结构支撑 + 抽叠决策"的原创品类。
- **核心循环**：
  ```
  读塔找安全块（空间推理）➔ 抽块（削支撑·塔底风险）➔ 上叠选位（移重心·塔顶风险）
       ↑                                                      ↓
  判危度四档审计（4/4/3/4）← 塔身咯吱·木屑微颤 ← 连击 +1 · 倍率 ×3
       ↓（判倒）                                  ↓（稳住）
  塌落演出·本局结算 → 重摆塔再来一局            继续读塔·叠向更高的天际线
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Jenga（Hasbro 1983 实体桌游）** | 实体 | 正交交错 54 块木塔、轮流抽块上叠、塔倒即输 | 半个世纪的空间博弈经典，规则简单深度无限 | 正交交错堆叠（3 块/层 × 18 层）、端头抽块、塔倒判负 | 实体摆塔繁琐、无连击反馈 |
| **Timber! / 木质塔手机爆款** | 移动 | 抽木块塔、手指点抽、比谁撑得久 | 数字化的抽塔手感与"再抽一根"的成瘾节律 | 单指抽块交互、塔倒的紧张演出 | 纯反应无策略、随机感重 |
| **Stack / 叠叠高街机小游戏** | 移动/Web | 精准落块对齐、越叠越高 | "堆叠"乐趣的极致简洁 | 堆叠落位的精准反馈、高度成长感 | 无"抽"的支撑博弈（本作异质） |
| **Block Blast / 俄罗斯方块结构类** | 移动 | 方块放置与消行 | 结构容错与连击设计 | 连击倍率与阶段反馈 | 消行逻辑与塔式博弈无关（仅借鉴反馈） |

**我们要继承的成熟机制**：
1. **正交交错塔结构（Orthogonal Interlock）**：每层 3 块、层间 90° 交错（偶层纵、奇层横），抽走一块后上层由下方另两块承托——Jenga 半个世纪的机构内核；
2. **端头抽块（End-Pull Only）**：只有端头露出的块可被抽取（夹在中间的块无法下爪），保留"读塔找端头"的空间推理；
3. **塔倒判负的临界张力（Collapse-Lose）**：谁抽/堆导致塔倒谁输——回合博弈的经典负反馈；
4. **连击倍率反馈（Streak Multiplier）**：连续成功操作倍率爬升，峰值前最后一次操作的心跳感是数字 Jenga 的爽点；
5. **固定步长确定性物理（Deterministic Physics）**：120Hz 纯函数帧步进、种子注入、同种子重放一致、四档判倒可逐档断言（本策划案的核心契约）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **抽≠堆双轴博弈（Pull vs Stack · 用户点名）**：把"抽块"与"堆叠"拆成两个独立决策——抽 = 支撑博弈（塔底失稳），堆 = 重心博弈（塔顶失衡）；玩家永远在"拆旧塔"与"垒新塔"两条风险轴上做权衡，这是对经典 Jenga"只有抽"的机制升维；
2. **四档判倒模型（4/4/3/4 塔倒判定 · 用户点名）**：支撑采样 4 点 / 基座 4 角 / 倾角 3° / 悬臂 40%——四项确定性判据逐帧审计，塔的生死由可测物理决定，杜绝玄学；
3. **连击翻叠 3¹⁸ 封神（Spire Streak 3¹⁸）**：连续成功抽叠连击倍率 ×3，极限 **3¹⁸ = 387,420,489 倍**——触达触发"木塔封神"金标演出（塔顶金标 + 全塔木纹流光），指数级诱惑贯穿全程；
4. **判危度可视化（Danger Meter）**：四档判倒的"最接近命中项"以塔身微颤强度 + 木屑下落频率暗示（弱提示，不剧透），把物理紧张感变成可读的氛围语言；
5. **木匠工作台原生视窗（Carpenter's Bench）**：木塔立在老木匠工作台塔垫上，工具槽、粉笔黑板、墨斗线全部原生——全站无同款视窗。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（标准 Jenga 塔，等轴 2.5D 视角）
- **木塔（Tower）**：标准 **54 块**（3×18 层：每层 3 块、层间 90° 正交交错，偶层纵向/奇层横向）；木块为温润胡桃木色长方体，端头圆角；
- **工作台（Bench）**：木塔立于橡木工作台中央的圆形塔垫上；周围墨斗线、铅笔、游标卡尺为装饰性原生元素；
- **塔垫（Pad）**：塔的落地基座，四角为判倒基准（档 2 质心投影判据）；
- **操作台（Tool Tray）**：台面边缘木质工具槽收纳全部操作（抽块、堆叠槽位、连击倍率表、重开）；
- **记分黑板（Chalkboard）**：墙上粉笔黑板记录双方比分与连击。

### 3.2 判定与计分规则（核心契约：塔倒判定 4/4/3/4 + 连击翻叠 3¹⁸）
1. **回合动作（抽≠堆）**：
   - **抽块（Pull）**：仅可选择**端头露出**的木块（纵向层露出前后端、横向层露出左右端）；点击目标块执行抽出（滑动抽出动画 0.5s）；
   - **堆叠（Stack）**：抽出的块必须**上叠**到塔顶——选择塔顶新层的左/中/右槽位落位（自动与下层正交），落位改变整体质心；
   - 块数守恒：抽出 1 块必叠 1 块，塔的总块数恒定 54（层数随游戏升高）；
2. **塔倒判定（用户点名四档判倒模型 4/4/3/4）**：每次抽/叠后逐帧执行四项审计，**任一命中即判倒**：
   - **档 1（支撑采样 4 点）**：每块底部 4 角采样支撑接触，支撑角 < 2（悬空过半）且无相邻块托底 → 判危；
   - **档 2（质心投影 4 角基座）**：整塔质心投影越出塔垫 4 角包围盒 → 判倒；
   - **档 3（静平衡 3°）**：整体倾角 ≥ 3° 且 1 帧内质心无回落趋势 → 判倒；
   - **档 4（悬臂 40%）**：任一块悬空长度 > 自身长度 40% 且上方压重 < 2 块 → 判倒；
3. **塌落演出（Collapse Cascade）**：判倒后进入固定步长塌落松弛——失去支撑的块逐块下落、翻滚、碰撞，木块碰撞串音 + 木屑尘埃，不可再操作；结算后重摆塔；
4. **连击与倍率（Spire Streak）**：
   - 连续成功"抽+叠"（未判倒）连击 +1，倍率 **×3^n**（第 n 次成功 ×3^n）；
   - 基础分 10/块；单次得分 = `10 × 3^n`；
   - **极限封顶 3¹⁸ = 387,420,489 倍**（"318"金标）——触达触发**木塔封神**演出（塔顶金标 + 全塔木纹流光 + 大七和弦）；
   - 塔倒或换手 → 连击清零、倍率归 1；
5. **胜负与评级（单人极限塔章节制）**：
   - **通关目标**：每关设定目标（连续抽叠 ≥ N 块 / 塔高达到 N 层 / 特定机关下生存 N 抽）；
   - **失败**：塔倒即本局失败（可重试，保留已解锁进度）；
   - **三星评级**：★ 达成目标；★★ 剩余容错（未判危次数）≥ par；★★★ 本关出现过连击 ≥ 3（×27 倍）或触发封神金标。

### 3.3 模式与内容编排（拒绝套路化三件套）
- **单人极限塔（Solo Spire，主打）**：**4 章 × 6 关 = 24 关**，评价体系 = 星级 + 最高层数 + 最高连击，绝不做无尽冲分：
  - 第 1 章·入门抽块：标准 18 层塔，学读塔找端头安全块；目标连续抽叠 10 块不塌；
  - 第 2 章·重心博弈：解锁**堆叠选位**（左/中/右槽位影响质心），目标塔高达到 24 层；
  - 第 3 章·结构微操：解锁**承重块标记**（特定块被抽必倒，考验绕行）与**阵风机**（每 5 秒一阵侧风，塔身微晃、判倒阈值收紧 10%）；目标在阵风中抽叠 12 块；
  - 第 4 章·通天塔：目标 30+ 层 + 触发一次 ×27 倍以上连击，收官演出；
- **同屏双人对决（2P Duel）**：经典 Jenga 回合制——玩家轮流"抽+叠"，塔倒者输掉本局；**三局两胜**，每局重摆塔；同一指针轮流操作，回合权用台面小旗提示；
- **残局解谜（Safety Riddle，附加）**：给定塔局，高亮问"哪一块可以安全抽出？"——正确 +1、错误计失误；10 题/关的"脑洞"推理关，纯空间判断（见拍板项 1 是否纳入）。

### 3.4 无死局与公平保证（数学可解性）
1. **可抽性保证**：标准塔每层 3 块正交交错，任意时刻至少存在 1 块端头露出的可抽块；抽块后支撑图重算，上层由下方另两块承托，结构天然自洽；
2. **判倒确定性**：四档判倒（4/4/3/4）全部为逐帧可测的几何/物理判据，无随机判倒；判危度可计算、可断言；
3. **极限连击可达性**：3¹⁸ 封神不依赖运气——官方提供"木匠试手台"（标准塔 + 承重块标记关闭）验证在最优读塔下连击 ≥ 3（×27 倍）确定性可复现；3¹⁸ 为理论上限（纯算法可达成，不保证人力达成，作为封神幻想存在）；
4. **确定性契约**：初始塔摆放、阵风扰动、机关触发全部走确定性种子；同种子 + 同输入序列逐帧一致，支持自动化验证；物理引擎测试包含 ≥1000 步随机抽叠游走（状态机不崩、块数守恒、四档判倒逐档断言、倍率恒为 3 的幂次且 ≤ 3¹⁸）。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **桌面鼠标（主路径）**：
  - **视角**：按住右键（或中键）拖动 = 旋转等轴视角（全维度读塔）；滚轮 = 拉近拉远；
  - **抽块**：左键点击端头露出的块 = 执行抽出（悬停时块端头高亮柔光）；抽出后自动进入堆叠选位；
  - **堆叠**：塔顶出现左/中/右三个槽位，左键点击 = 落位；Input Buffer：落位点击 60ms 窗口接受，连点不吞指令；
  - **取消**：右键 = 取消当前选块（不消耗连击）；
- **键盘**：`←/→`（或 `A/D`）旋转视角，`↑/↓`（或 `W/S`）缩放，`1/2/3` = 塔顶左/中/右槽位，`空格` = 确认抽块/落位，`Esc` = 取消/暂停/退回弹层；
- **移动端（触控）**：单指拖动 = 旋转视角，双指捏合 = 缩放；点击端头块 = 抽块，点击槽位 = 落位；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡抽块操作区；
- **手感调优**：抽块滑动 0.5s 木质摩擦"嘎—咔"；落位"笃"；判危度逼近时塔身微颤 + 木屑下落频率升高（无边界径向柔光，禁硬边描边圈）；连击每 +1 木纹流光增强、音阶上行；塔倒慢镜 + 崩落 + 尘埃。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词
**老木匠工作台（Carpenter's Bench）**、温润胡桃木、橡木台面、琥珀台灯、粉笔黑板、木屑微尘、暖光书房。

### 4.2 专属视窗物理隐喻（严禁左右双翼模版）
本作不是"网页里嵌个 3D 方块"，而是一方**老木匠的工作台**：

```
+---------------------------------------------------------------------------------------+
|  暖琥珀书房环境光·木屑微尘  [🏠] [叠叠乐 JENGA TOWER] [🔊][🌐][❓]                      |
+---------------------------------------------------------------------------------------+
|                                                                                       |
|         ╭────────── 墙面粉笔黑板（比分 · 连击 · 最高层数）──────────╮                    |
|         │   P1 ▍▍▍  P2 ▍       连击 ×N    最高 27 层             │                    |
|         ╰──────────────────────────────────────────────────────╯                    |
|                                                                                       |
|   ╭──────────────────────────────────────────────────────────────────╮                |
|   │   [ 等轴 2.5D 木塔舞台 · 可旋转视角 ]                              │                |
|   │      ╭───────────╮      ▲ 塔顶（堆叠槽位 左/中/右）               │                |
|   │      │ ▓▓ ▓▓ ▓▓  │      ▓ 端头抽块高亮柔光                        │                |
|   │      │ ▓▓▓ ▓▓▓   │      ▓▓ 木纹块（正交交错）                     │                |
|   │      │ ▓▓ ▓▓ ▓▓  │      ▓▓▓ 判危时塔身微颤 · 木屑下坠              │                |
|   │      ╰─┬──┬──┬───╯      ▓▓▓▓ 塔垫（质心 4 角基座基准）             │                |
|   │        ○ 塔垫 · 橡木台面 ○                                        │                |
|   ╰──────────────────────────────────────────────────────────────────╯                |
|   [ 木匠工具槽：抽块 · 堆叠槽位 1/2/3 · 连击倍率表 · 重摆塔 ]  ← 原生机壳控制区           |
+---------------------------------------------------------------------------------------+
```

1. **工作台即全部**：木塔立在橡木工作台中央塔垫上，工具槽、墨斗线、铅笔、游标卡尺是台面的原生装饰；**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **粉笔黑板记分**：双方比分、连击倍率、最高层数写在墙上粉笔黑板上，塔倒时粉笔灰微落；
3. **判危氛围语言**：塔身微颤强度 + 木屑下落频率随四档判倒接近度升高（弱提示，不剧透判据），把物理紧张感读成氛围；
4. **环境氛围**：暖琥珀台灯光晕 + 木屑微尘粒子 + 橡木纹理环境，拒绝死黑/死白大平铺；返回、音效、语言收纳进工作台顶框一体化状态条；
5. **移动端（≤768px）**：木塔舞台全宽撑满，工具槽收折为台面下木质工具条，底部严格预留广告安全避让区，绝不遮挡抽块区。

### 4.3 立体质感与渲染路线裁决
- **裁决：Canvas 2D 等轴 2.5D 木塔舞台 + DOM/CSS 3D 木匠工作台框体**（不做 Three.js）：
  - 木塔（54 块长方体三面可见 + 深度排序 + 旋转视角重投影 + 塌落粒子）→ Canvas 2D 等轴投影，120fps 秒开零发热；
  - 工作台立体感（橡木台面厚度、工具槽、粉笔黑板、琥珀台灯）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/记分/弹层全部严格留在 DOM 层；
  - 理由：木塔为轴对齐正交网格结构，等轴 2.5D 投影即可完整表达三维空间关系（可旋转视角覆盖全维度读塔），无真 3D 自由视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **抽块滑出（Block Slide）** | 木质摩擦"嘎——咔"（滑出瞬间收束） | 噪声缓冲 + 低频带通 sweep（摩擦质感），末端短促木咔 |
| 2 | **块与块轻碰（Wood Clack）** | 温润木块互碰"嗒" | FM 木琴短音（600Hz 起，80ms 衰减），音高随块尺寸微调 |
| 3 | **堆叠落位（Stack Place）** | 木块落顶的沉稳"笃" | 低频正弦 + 短促噪声瞬态，稳而厚 |
| 4 | **塔体咯吱（Tower Creak）** | 判危逼近时的低频"咯吱" | 失谐锯齿波 + LFO 抖动，强度随判危度爬升 |
| 5 | **塔倒（Collapse）** | 崩落爆发——木块连续碰撞"哗啦崩" | 噪声串 + 低频冲击序列（多枚短促正弦渐强）+ 尘埃噪声 |
| 6 | **连击/封神（Streak & Spire）** | 连击音阶上行（木琴五声音阶）；3¹⁸ 封神大七和弦 | FM 木琴琶音逐级上行；封神 = 大七和弦 + 木纹流光垫底 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体，占画面 65%~70%——一座**3D 软胶胡桃木塔**（圆角软胶质感、木纹高光）微微倾斜立在软胶塔垫上，最上层一块正被抽出、悬在半空带柔和滑动轨迹；
- **背景与氛围**：暖琥珀至深胡桃木的平滑径向渐变背景 + 木屑微尘与虚焦光斑，木纹软胶质感饱满温润——一眼传达"老木匠工作台上的一局叠叠乐"。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：模式配比？
- **选项 A（极限塔 + 双人对决 + 残局解谜三轨 · 推荐）**：单人极限塔（4 章 × 6 关 = 24 关）为主打，同屏双人对决（三局两胜）与残局"安全块"解谜为附加——单人成长、派对博弈、纯脑洞三种乐趣齐备；
- **选项 B（极限塔 + 双人对决双轨）**：只做单人极限塔与同屏双人对决，最聚焦、开发量适中；
- **选项 C（纯单人极限塔）**：只做单人章节，最轻量。

### 拍板项 2：视角与抽块交互？
- **选项 A（可旋转等轴视角 · 推荐）**：按住右键/单指拖动旋转视角，全维度读塔，空间推理最完整；
- **选项 B（固定等轴视角）**：固定 2.5D 视角 + 点击抽块，最简直接，后侧端头块不可见（需绕行策略）；
- **选项 C（四向切换视角）**：N/E/S/W 四向快速切换（数字键/滑动切角），折中方案。

### 拍板项 3：机关编排？
- **选项 A（逐章引入 · 推荐）**：承重块标记 → 堆叠选位 → 阵风机 → 通天塔，每章一个新变量，学习曲线最顺；
- **选项 B（纯标准塔）**：无机关、无标记，最经典克制的 Jenga 体验；
- **选项 C（机关全开）**：承重块、阵风、地震波（每 10 抽一次小震动）、限时抽块并存，内容最满、压力最大。
