## 1 · 创意概念与核心乐趣

- **游戏名称**：暴力摩托 / Road Bash / 建议 slug：`road-bash`（备选 `moto-brawl`、`rash-ride`）
- **一句话玩法**：骑着玩具摩托在落日公路上狂飙，一边超车一边挥拳把对手打下车——先冲过终点的人赢。
- **核心乐趣与卖点**：
  - **竞速与格斗叠在同一秒里**：这不是“开完再打”的两段式，而是 120 码并排时出拳、踢腿、抢棍子的公路群殴。超车不只靠油门，也可以靠把前车打进护栏；
  - **出拳命中的肉体打击感**：擦肩而过的瞬间挥出一记，对手头盔一歪、车把一晃、人车分离在沥青上打滚——这是品类 30 年来没被替代的爽点。格斗必须**简单**（一键出拳、方向改招），但命中要**扎实**（顿帧、屏幕微震、清脆合成打击音）；
  - **华丽摔车的喜剧快感**：撞树、撞牛、撞对向卡车不是单纯惩罚，而是表演。人飞出去、摩托滑行、自己一路小跑把车捡回来——摔得越夸张，玩家越想再来一把。复古趣味的灵魂不在像素点，而在“摔得很惨但很好笑”；
  - **地下联赛的成长瘾**：从生锈老鼠车打到落日超级摩托，五条风景公路、四个段位。每一场都是“保名次换奖金、奖金换更快的车、更快的车去打更狠的对手”。
- **核心循环**：
  ```
  油门冲出起跑线 → 贴上对手挥拳 / 绕开卡车与护栏 → 把人打下车抢位
       ↑                                                              ↓
  奖金换更好的车 / 下一场更狠的对手  ← 冲过终点（保名次通关 / 冲冠军三星）
       ↓（体力耗尽或高速撞障）
  华丽摔车 → 爬起来追自己的摩托 → 重新加速追赶（时间惩罚，不是直接 Game Over）
  ```

## 2 · 经典标杆与对标参考

**成熟标杆原型**：1991 年 EA《Road Rash》（世嘉 MD，中文玩家口中的「暴力摩托」）是本玩法的绝对鼻祖——非法公路赛 + 徒手/棍棒近战 + 对向车辆与路边障碍 + 摔下车跑步捡车。它的现代精神续作是《Road Redemption》（2017），把格斗做成格挡/武器树/肉鸽，但把经典的“一拳打飞”稀释成了重型动作游戏。网页端几乎没有真正把「竞速 + 近身格斗」做扎实的作品：多数挂着 Road Rash 名字的浏览器游戏其实只是躲避交通的时间赛，没有挥拳。

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Road Rash**（1991 / 1994） | 世嘉 MD / 3DO | 第三人称伪 3D 公路；加速/刹车/左右；贴身出拳、踢腿、抢棍子；体力条打空即摔；车子有损毁条 | **并排挥拳的公路群殴**；摔车后跑步捡车的喜剧节奏；加州风景公路与地下联赛买车 | 伪 3D 车尾视角；一键近战 + 方向改招；体力/车损双条；保名次晋级；棍子可抢 | 14 人同场过密；破产即永久 Game Over；警察逮捕过虐；操作说明冗长 |
| **Hang-On / OutRun** | 世嘉街机 | 伪 3D 公路透视、坡度起伏、左右重心 | 公路向前“吞没”玩家的速度幻觉；坡顶盲区的心跳 | 伪 3D 路面透视 + 起伏坡；街机仪表盘 HUD | 纯竞速无格斗；弯道过“模拟” |
| **Road Redemption** | PC/主机 | 近战+枪械+格挡；肉鸽升级；多种事件 | 用环境杀人（踢进对向车流）的战术快感 | **把对手踢进障碍/车流**的环境击杀；命中顿帧 | 枪械/C4/技能树过重；手感发飘；不适合网页小游戏 |
| **Bash Moto**（2026 独立作） | Steam 新作 | 2D 引导式公路 + 近战；修车/保释金经济 | 证明“简化视角、保住挥拳”仍有市场 | 范围可控、聚焦站位与出拳 | 纯侧视会丢掉“我在公路上飞”的标志性体感 |
| 网页 “Moto Road Rash 3D” 一类 | Poki/GamePix | 第一人称躲车流、计时赛 | — | — | **只有竞速没有格斗**，是挂名空壳，绝不能做成这样 |

**我们要继承的成熟机制**：
1. **贴身即战场**：攻击只对并排近距对手生效。玩家的核心决策永远是“现在超、现在打、还是先躲车”；
2. **一键近战、方向改招**：默认出拳打最近的人；按方向可改成反手或踢腿。抢到棍子后同一键变砸击。格斗必须简单，绝不做成连段格斗游戏；
3. **双条资源**：骑士体力（被打空 = 摔车）+ 摩托损毁（摔太多次 = 本场退赛）。摔车不是死亡，是“表演 + 时间惩罚”；
4. **保名次晋级的地下联赛**：不是无尽冲分。每场有录取名次（如前 4 / 前 3 / 领奖台 / 必须第一），奖金买车，车辆性能决定下一档的上限。

**本作的独特魅力与微创新**（经典之上，不做换皮）：
1. **软胶玩具 × 90 年代公路街机**：不做写实暴力，不做暗黑末世。骑士、摩托、被打飞的小人全是 Q 弹软胶手办，摔车像玩具被弹开而不是血肉横飞——复古趣味保留，门户调性不破；
2. **「一拳超车」的可读反馈**：每次有效击倒都有明确的战术回报（对手失去 2–4 秒 + 你借机超车），并计入本场「击倒数」。让格斗不是花絮，而是第二条取胜路径；
3. **三种服务核心乐趣的模式，绝不套无尽冲分**：
   - **地下联赛**（主线）：5 条风景公路 × 4 段位 = 20 场，保名次、赚奖金、换车；
   - **公路群殴**：以击倒配额为主、名次为辅的格斗关；
   - **亡命冲刺**：警察在后，活着冲过终点，格斗对象变成条子。

## 3 · 玩法规则与交互说明

### 场景构成

- **视角**：经典车尾第三人称**伪 3D 公路**（Road Rash / Hang-On 那一套：路面透视向前延伸，左右是路肩与护栏，远景是天空与地平线）。这是「暴力摩托」的视觉身份证，不做纯侧视、不做上帝俯视。
- **赛道是一条有宽度的公路带**，不是封闭赛道：
  - 可行驶路面约 3 个虚拟车道宽（含对向来车的危险）；
  - 路肩：沙石减速；再外侧是护栏、树、路牌、偶发的奶牛/仙人掌等喜剧障碍；
  - 公路有缓坡起伏（坡顶会短暂挡住前方视野，制造心跳）；
  - 沿途有对向汽车、同向慢车、偶尔的警车。
- **同场角色**：玩家 1 + AI 骑士 6 人（网页可读上限；经典 14 人过密）。每场有 1–2 名持棍对手、1 名速度型、2 名好斗型、其余普通。
- **双条 HUD（机车仪表，不是网页血条）**：
  - **体力**（骑士）：被击中下降，短暂不挨打会回一点；打空 = 摔下车；
  - **车况**（摩托）：每次摔车/撞障扣一截；扣尽 = 本场车辆报废，判定退赛（可立即重开本场，不毁存档）。
- **五条风景公路（联赛共用，群殴/冲刺按主题选用）**：

  | 公路 | 气质 | 教学点 |
  |---|---|---|
  | 海岸落日 | 缓弯、视野好、车流稀 | 油门、并排出拳、路肩惩罚 |
  | 沙漠直道 | 高速、对向卡车多 | 用踢腿把人送进车流；近失加分 |
  | 盘山弯道 | 连续弯、护栏近 | 刹车入弯、反超、别在弯心硬刚 |
  | 霓虹夜城 | 车流密、警察出没 | 穿梭、被目击后条子追击 |
  | 峡谷落日 | 起伏大、混合障碍 | 终章：坡顶盲区 + 持棍对手 + 对向车 |

### 玩家合法操作

所有下列操作在比赛进行中（未终局）均必须执行；无效意图（空打、已报废还加油）静默忽略。

1. **加速 / 减速**：按住油门加速至当前车辆极速；松开自然滑行；刹车快速降速。入弯前减速是有意识的操作，不是自动辅助；
2. **左右变道**：在路面宽度内平移。贴路肩会擦火花并掉速；撞护栏/树/牛 = 摔车；
3. **出拳（默认近战）**：近距并排时，对最近对手打出一记。命中扣对方体力，自己有短暂后摇（不能无限连打）；
4. **方向改招**：
   - 朝对手方向 + 出拳 = 直拳（快、伤低）；
   - 朝反方向 + 出拳 = 反手抽击（稍慢、伤高、更容易打掉对方手里的棍子）；
   - 向下/踢键 = 侧踢（距离略远，容易把人踢向路肩或对向车道）；
5. **抢械**：对方挥棍落空的瞬间，出拳可把棍子抢过来。棍子持续 4–6 次有效砸击后甩飞，变回拳头。场上同时最多一把“被持有的棍子”，保证可读；
6. **被打 / 反击**：挨打时有短暂硬直但仍能转向。体力打空或高速撞障 = 摔车。摔车后玩家变成“跑步捡车”：朝自己滑行的摩托跑，摸到即重新上车（保留当前名次惩罚后的位置）。**摔车不是失败**，除非车况条扣尽；
7. **暂停 / 重开本场 / 返回车库**：随时可用，零惩罚（重开本场不扣奖金、不毁车）。

移动端额外提供 **自动巡航油门**（默认开启，可关）：松开即巡航中速，按住油门超车，点刹车入弯。保证拇指能同时转向 + 出拳。

### 胜利、失败与录取

- **地下联赛（主线）**：冲过终点线时名次 ≤ 本场录取名次即为通关。录取随段位收紧：

  | 段位 | 录取 | 对手攻击性 | 车流 |
  |---|---|---|---|
  | 老鼠帮 | 前 4 | 偶发出拳 | 稀 |
  | 街头 | 前 3 | 主动贴身打 | 中 |
  | 飞车党 | 领奖台（前 3，奖金按名次） | 持棍、会反击 | 密 |
  | 落日王 | 必须第 1 | 围殴、警察 | 密 + 坡顶盲区 |

  未进录取 / 车况报废 / 被警察逮住（仅夜城与落日王部分场次）= 本场失败，可立即重开。**没有生涯破产、没有存档抹除。**

- **公路群殴**：在终点前打出指定击倒数（如 4 / 6 / 8）且自己仍在车上冲线。名次只影响星级，不决定成败。
- **亡命冲刺**：警车从后方追来。被贴停且被铐住 = 失败；自己摔车后条子会减速“等你上车再抓”，给喜剧容错。冲过终点即胜。

### 公平保证（无死局）

本作不是解谜，但仍必须保证**技能可胜、不靠纯运气卡死**：

1. **路面永远有缝**：对向车与同向慢车的生成有密度上限和最小间距，任何时刻至少有一条可钻的空档；不会出现三车道同时封死的“必死墙”；
2. **AI 不围成人墙**：对手在横向占位上互相避让，最多两人同时贴玩家；不会 6 人并排把路堵死；
3. **摔车必可恢复**：只要车况未尽，摩托停在可到达处，跑步捡车必成功。不存在“车掉进虚空/卡进碰撞体”；
4. **录取可达成**：每场用当前段位的最低合法车辆，存在一条“合格走法”（少打、少摔、合理超车）能进录取。高手用拳头开路可以冲冠军，新手保名次也能过——这是双路径，不是二选一的死门；
5. **棍子不是抽奖**：每场至少 1 名持棍对手，其出现路段固定或由确定性种子决定，保证可预判、可抢；
6. **警察不是随机死刑**：夜城/落日王的条子有预警（警灯与后视镜剪影），被抓需要“长时间贴停”，擦肩而过只加警觉值。

随机交通与对手攻击节奏使用确定性种子，同一场重开是可重放的，便于测试。

### 操作与手感（键鼠触全通）

- **桌面键盘（主推荐）**：
  - `W` / `↑` 加油，`S` / `↓` 刹车，`A D` / `← →` 转向；
  - `J` / 空格 出拳（方向 + 出拳 = 改招）；
  - `K` 踢腿；`P` 暂停；`R` 重开本场。
- **鼠标**：点击舞台也可作为“出拳”热区（给不想双手键盘的人一条退路）；转向仍建议键盘。
- **触屏（横屏优先，竖屏把公路舞台缩成掌机屏）**：
  - 左下虚拟方向盘（左右为主，上油下刹）；
  - 右下大号「拳」键 + 稍小的「踢」键；
  - 默认自动巡航油门，降低“三指同时按”的负担。
- **手感调校（对标经典，拒绝发飘）**：
  - 出拳有 6–8 帧挥击、命中 **2–3 帧顿帧 + 屏幕微震**，空挥有清脆挥空音；
  - 击倒：对手做夸张的软胶抛飞，摩托独自滑行，玩家耳边一声“哐”；
  - 摔车：自己同样抛飞，镜头略跟飞出的小人再拉回公路，强调喜剧而非惩罚；
  - 极速时路面纹理变密、远景拉线，给出“在飞”的速度感；入弯过快会有轮胎尖叫合成音与车身倾斜。

### 模式与内容编排（专属，不套无尽冲分）

**禁止**把本作做成“无尽公路刷分 + 每日挑战 + 一个得分按钮”。暴力摩托的瘾点是**一场一场赢下去、一辆一辆换上去**，以及偶尔专门去打人。

1. **地下联赛 · Underground League（主线，20 场）**
   - 5 公路 × 4 段位，必须按段位解锁（本段 5 场全部录取才开下一段）；
   - 通关一场发奖金（名次越高越多，额外击倒奖金）；
   - 车库用奖金买/解锁 4 档摩托（老鼠车 → 街头车 → 飞车 → 落日机），性能三角为 **极速 / 操控 / 车体耐打**，永远存在取舍（落日机极速最高但摔一次很疼）；
   - **入门车永不锁死**：即使把钱花光，车库永远留着免费老鼠车，绝不破产劝退。

2. **公路群殴 · Road Brawl（格斗关，8 场）**
   - 短赛道，AI 更黏人，目标是打满击倒配额再冲线；
   - 专门服务“我就是来打人的”玩家，也是练习抢棍与环境击杀的靶场。

3. **亡命冲刺 · Getaway（警察关，5 场，对应五条公路的夜/黄昏变体）**
   - 几乎没有并列积分赛的对手，压力来自后方警灯与前方车流；
   - 允许把条子踢下车，但打条子会加速增援——风险收益自己选。

车库是三种模式的枢纽（选车、看奖杯、进场），不是网页菜单列表。

### 目标与评价体系（不是“一个总分”）

- **联赛单场三星**（关卡玩家的语言）：
  - ★ 录取通关；
  - ★★ 领奖台（前 3）；
  - ★★★ 冠军，且本场至少 3 次击倒（证明你又快又狠）。
- **群殴**：完成配额为通关；超额击倒与自身零摔车决定星级。
- **冲刺**：通关；无摔车 + 不被贴停为满星。
- **车库奖杯墙**（持久荣誉，本机保存）：
  - 段位徽章（老鼠帮 → 落日王）；
  - 收藏的摩托剪影；
  - 生涯累计击倒、最远抛飞距离（喜剧纪录）、联赛满星数。
- **单场结算仪式**：冲线后慢动作甩尾定格 → 名次灯牌翻出 → 击倒人头像一个个弹到路边 → 奖金硬币落入车库。失败则是软胶小人坐在路肩上揉头盔，按钮写「再来一次」而不是「Game Over」。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：**90 年代公路街机 · 软胶玩具摩托 · 加州落日 · 喜剧抛飞 · 机车仪表台**
  （不做写实伤痕、不做末世废土、不做死白网页赛道、不做霓虹赛博枪战。趣味是复古的，质感是玩具的。）

- **游戏机台 / 沉浸舞台规划（严禁老套网页病）**：

  整局游戏是一台横放的 **「落日公路机车街机」**，玩家坐在仪表后面看公路往前吞。

  - **中央主舞台（公路视窗）**：圆角 CRT 游戏屏嵌在机身里，屏内是伪 3D 落日公路。屏框有轻微扫描线与圆角暗角，像真街机玻璃。**返回首页 / 音效 / 语言 / 规则**全部收进机身**顶边一条窄状态杠**（像机车后视镜支架），绝不散落四角；
  - **左侧仪表翼（玩家自己）**：与机身连体的 motorbike 仪表罩——速度表、档位感的极速刻度、体力像油压表、车况像引擎温度。当前名次是一只翻牌数字（P1–P7），击倒时指针弹跳；
  - **右侧后视翼（对手与威胁）**：后视镜造型的椭圆窗，显示最近对手的体力、是否持棍、警灯预警。不是一叠白卡片；
  - **底沿操作台**：油门/刹车/拳头做成机身实体键（微浮雕、悬停抬 2px、按下沉 2px + 清脆键音）。移动端这些键落在掌机下沿，并留出底部 68px+ 安全区，不被未来横幅广告挡住；
  - **环境**：机身之外是沉浸式加州黄昏——橙红到深紫的天空渐变缓慢漂移，远处有软胶棕榈与电线杆剪影，偶有飘过的尘粒与虫点。拒绝一张死蓝或死灰平铺。

  桌面 ≥900px：机台居中，总宽不超过约 1100px，左右留广告安全白边。移动端：机台等比缩小，公路屏仍是视觉主体，左右翼收成顶栏下的两枚圆形仪表，不改成卡片列表。

- **色彩与氛围**：
  - 主色：**落日橙红** `#FF6B3D → #FFB15A`（封面与天空），机身烤漆 **暖棕/古铜** `#6B3A2A`，公路沥青 **暖灰** 而非死黑，护栏与头盔点缀 **明黄**、对手皮衣 **青绿/紫红** 以区分阵营；
  - 按钮：铜色微浮雕 + 边缘高光，按下有机械行程；
  - 关键动效：
    - 命中：顿帧 + 一圈橙火花；
    - 击倒：软胶小人抛物线抛飞，落地弹两下；
    - 近失卡车：后视镜闪白、风声呼一下；
    - 冲线：落日镜头光晕爆开、名次翻牌；
    - 摔车：短促慢动作（可在减少动效媒体查询下瞬间跳过）。

- **封面设计提案**（遵循 `docs/COVER-STYLE.md`）：
  - 单一居中主体：一辆 **圆润软胶玩具摩托车**，骑士前倾握车把，另一只手握着一根短棍挥出，后轮扬起一小团软胶尘土；骑士与车连成一个主体，约占画面 65%；
  - 背景：**明亮橙红落日渐变**（整墙尚未占用的橙红色相；避开 gold-miner 的暖橙金、避开已饱和蓝紫/青绿）；
  - 漂浮物：少量软光点、小块沥青碎屑、一两颗圆形火花；
  - **零文字、零号码牌字母、零 UI**；
  - 画布 1:1，640×640 WebP。

## 5 · 制作人拍板与开放探讨

下面三件事会显著改变手感和工期，请制作人拍板。未拍板前，策划默认推荐每项的 **方案 A**。

1. **格斗深度（最影响“简单格斗”四个字）**
   - **A. 经典三招（推荐）**：出拳 / 反手 / 踢腿 + 抢棍子。一键为主、方向改招。对标原版 Road Rash，网页 10 秒能上手；
   - **B. 极简一键**：只保留自动锁定最近对手的一记出拳，踢与抢棍都取消。更casual，但“把人踢进卡车”这条名场面会弱很多；
   - **C. 加格挡**：在 A 的基础上增加短窗口格挡（Road Redemption 味）。深度更高，触屏会变挤，不建议首发。

2. **主线推进结构**
   - **A. 地下联赛买车（推荐）**：20 场保名次 + 奖金换 4 档摩托。这是原作的上瘾结构，也是“再来一场”的理由；
   - **B. 纯章节三星**：20 关固定车辆、不买车，只评星。更像平台其它解谜关，少了“换车”的玩具欲；
   - **C. A + 车库涂装**：联赛买车，另用满星解锁头盔/涂装（纯外观）。内容量略增。

3. **画面复古程度**
   - **A. 软胶玩具 + 街机柜（推荐，贴合 DOIN 封面墙）**：角色是 Q 弹手办，机身是 90 年代公路街机，CRT 暗角点到为止；
   - **B. 16-bit 像素致敬**：更像 MD 版暴力摩托，封面仍做软胶（门户统一），局内改像素。风格记忆点强，但和整站软胶墙会跳；
   - **C. 混合**：软胶角色 + 更重的扫描线/抖动，像“把玩具塞进老电视”。

## 6 · 一页纸摘要（给制作人）

把 90 年代《Road Rash》（暴力摩托）的灵魂做成 DOIN 上的一台落日公路街机：伪 3D 车尾视角，油门超车，一键挥拳把软胶对手打下车，摔了就跑去捡自己的玩具摩托。主线是 5 条风景公路 × 4 段位的地下联赛（保名次、赚奖金、换四档车），另有专门打人的公路群殴和专门逃条子的亡命冲刺。格斗保持简单，摔车做成喜剧，绝不做成无尽刷分，也绝不做成写实血腥。
