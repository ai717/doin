## 1 · 创意概念与核心乐趣

- **游戏名称**：传送门推箱 / Portal Box / 建议 slug：`portalbox`（备选 `portal`）
- **一句话玩法**：借助成对蓝橙传送门折叠空间，将箱子与自身穿梭于隔绝密室之间，巧妙借位将所有能量箱推入归位目标！
- **核心乐趣与卖点**：
  - **超越传统推箱的“非欧空间拓扑折叠”（Non-Euclidean Spatial Folding）**：
    与《sokoban》（纯平面死角搬运）和《ice-slide》（惯性滑行撞停）有着本质维度的差异！本作的核心在**“空间拓扑重塑”**——看似被高墙死死封锁的绝境密室，只要推箱穿过蓝门，箱子瞬间从橙门以折射角度呼啸穿出，直抵深宫腹地；
  - **双向朝向转换与隔空借位（Direction Vector Mapping）**：
    如果蓝门依附在西墙、橙门依附在南墙，向左推箱进蓝门，箱子将**以 90 度转角折射向上喷出橙门**！玩家站在门外，箱子却已穿梭到千百里之外的受力点；人穿门而过，又能瞬间来到箱子身后实施反向推拉，脑洞大开；
  - **100% 数学确定性与 BFS 拓扑求解器保证（Proven Solvability）**：
    虽然包含成对空间折叠，但底层完全建立在严谨的有向拓扑映射图上。每一个关卡均经过自动化 BFS 状态空间搜索验证，确保既具备烧脑的高维度智力挑战，又 100% 具备无死局可解性；
  - **极具辨识度的光圈科技赛博实验室美学**：
    经典标志性的蓝橙双色荧光光圈脉冲、镜面微缩亚克力地砖与粒子虫洞音效，将古老的推箱子游戏升华为一间充满未来极客气质的物理实验室。
- **核心循环**：
  ```
  巡视空间迷宫与蓝橙传送门相对朝向 → 规划人与箱子的穿门折射轨迹
       ↑                                                      ↓
  下一关卡 / 斩获最少步数三星 ← 能量箱全部完美卡入绿色目标点 ← 推箱穿梭虫洞 / 人门互换借位推拉
       ↓ (不慎将箱子推入死角卡死)
  随时按【Z】键无限步平滑撤销，复盘空间折射路线
  ```

**我们要借鉴的成熟机制**：
1. **相对方向变换矩阵（Relative Orientation Matrix）**：
   - 设进入门 A 的局部进入向量为 $\mathbf{d}_{in}$，门 A 挂载墙面的法向量为 $\mathbf{n}_A$，门 B 挂载墙面的法向量为 $\mathbf{n}_B$；
   - 穿出物体在门 B 处的流出向量 $\mathbf{d}_{out}$ 经过旋转变换矩阵计算：
     $$\mathbf{d}_{out} = \mathbf{R}(\theta) \mathbf{d}_{in}$$
     若两门反向平铺，方向守恒；若两门成 90° 直角，推箱轨迹发生 90° 旋转偏转！
2. **出门阻抗与防卡死不变量（Exit Congestion Invariant）**：
   - 当物体（人或箱子）试图穿过门 A 时，系统先探测门 B 正前方的目标格：
     - 若门 B 前方是空格或目标槽，顺利传送并位移；
     - 若门 B 前方恰好被一堵实体墙、另一个箱子、或门 B 处于关闭状态，该门处于“阻抗阻塞态”，拒绝进入，人或箱子停在原地，杜绝任何穿模穿墙 bug；
3. **闭环瞬移阻尼保护（Oscillation Protection）**：
   - 传送完成后，物体在该帧被标记为“已传送态”，防止同一帧内因为反向移动而在两门之间产生无休止的无限瞬移死循环。

**本作的差异化微创新（拒绝死板线框）**：
1. **多色传送门网络（Multi-Color Portal Matrix）**：
   - 前期为经典的【蓝门 ⇄ 橙门】单对传送；
   - 中后期引入第二对【紫门 ⇄ 绿门】，两条独立的虫洞网络在空间中相互交错穿插，创造前所未有的超高维度思维风暴；
2. **隔空垫步与人门置换（Translocation Tactics）**：
   - 玩家可以人不过门，只将箱子推进门中；也可以把箱子推进门作为垫脚石，自己从另一扇门出来踏在箱子前，实现经典推箱子梦寐以求的“反向隔空推”！
3. **20 关空间折叠工坊（4/4/4/4/4 结构）**：
   - 单门折叠 ➔ 转向偏转 ➔ 双色交错 ➔ 隔空换位 ➔ 莫比乌斯环，层层梯度引入机制。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与网格构成**：
  - **视口宽 840px、高 560px 的赛博空间实验室**；
  - **实验台网格**：$12 \times 10$ 标准地砖矩阵；
  - **地形元素**：
    - 绝缘黑钢墙壁（不可穿越）；
    - 能量箱（Energy Crates）：标有醒目能量核心的重力箱；
    - 目标槽位（Target Slots）：地面上带有绿色荧光四角卡槽；
    - 传送门对（Portal Pairs）：依附在特定墙面上的发光椭圆环（主门对：蓝/橙；副门对：紫/绿）。
- **玩家合法操作**：
  1. **移动与推箱（Move & Push）**：
     - 方向键【↑ / ↓ / ← / →】或【W / A / S / D】：
     - 向空格移动 1 格；
     - 推动面前的 1 颗箱子向前移动 1 格（经典推箱不拉箱规则，不能同时推 2 颗箱子）；
  2. **穿门规则（Portal Traversal）**：
     - 人走向传送门：从配对的另一扇门走出，方向根据门朝向自动转换；
     - 推动箱子进门：箱子从另一扇门穿出，人留在门外原位（或人跟着一起进门）；
  3. **全时无限撤销（Instant Undo）**：
     - 按键【Z】或点击界面“撤销”：无限制倒退回上一步，人与箱子瞬间退回前一帧状态；
  4. **一键重开（Reset）**：随时按【R】秒级复位当前关卡。
- **胜利判定与关卡目标**：
  - **通关胜利（Clear）**：全场所有能量箱**全部稳稳推入发光的绿色目标槽位**！
  - **终局仪式感**：
    - 所有能量箱激活共振，全场传送门发出欢快的过载充能微光，空间裂缝缓缓愈合；
    - 弹出通关报告卡，展示本关实际用步数与官方最优步数比对。
- **数学可解性与 100% 确定性保证**：
  - 关卡地图与门对映射构成一个标准的有限状态自动机（FSM）；
  - 全 20 关均通过带传送门扩展的广度优先搜索求解器（Portal-BFS Solver）验算，保证 100% 存在通关路径，杜绝不可解死局。

### 操作与手感细节

- **视听爽感与声学微雕**：
  - 穿门瞬间：极具科幻感的空间折叠吸入音效“呜嗡——哧！” + 传送门边缘粒子向内收缩微动效；
  - 箱子推动：重型合金与亚克力地砖摩擦的沉闷阻尼声“嗤啦”；
  - 撞墙/阻抗：低沉的机械撞击闷响；
  - 目标归位：能量箱滑入槽位发出清脆解压的“嗒！铛——”锁定声，槽位亮起耀眼翠绿光辉。

### 关卡模式编排（20 关五大拓扑篇章：4/4/4/4/4）

1. **第一卷：单对虫洞（Single Wormhole · 4关）**：
   - 基础教学：蓝橙单门对，平行反向放置，熟悉直线穿梭与隔空运箱；
2. **第二卷：方向扭曲（Vector Twist · 4关）**：
   - 90 度直角传送门：进门向右、出门向上，体验推箱方向被非欧空间扭转的奇妙脑洞；
3. **第三卷：双色交织（Dual Conjugation · 4关）**：
   - 引入紫绿第二门对：两条独立的传送通道在空间中交叉穿插，考验分流调度；
4. **第四卷：隔空换位（Translocation Vault · 4关）**：
   - 巧妙利用门的位置，实现“人从箱子前瞬间穿梭到箱子后”的逆向推位，破解看似死角的死胡同；
5. **第五卷：莫比乌斯环（Mobius Infinity · 4关）**：
   - 终极非欧拓扑大考验：复合双对门、循环折叠迷宫，通关荣登“空间拓扑大宗师”！

## 4 · 美术风格与视觉氛围（光圈科技实验室，拒绝网页仪表盘）

- **题材与视觉关键词**：**光圈科技 · 蓝橙荧光门 · 镜面亚克力地砖 · 极客优雅 · 空间折叠**
  （不做单调惨白的白底网页，不做粗糙简陋的远古 8-bit 方块；呈现为置身于一座充满未来极简主义的非欧几何物理测试舱前）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Chamber Arena）**：

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **推箱穿门时的人随门入规则（核心交互定调）**：
   - **方案 A（推箱人留在门外，除非单独走进去，强烈推荐）**：推箱进门后，箱子穿出另一扇门，人依然停在原门前。这样玩家可以“隔空远程推箱”，也能选择自己穿门过去，策略自由度最高；
   - **方案 B（推箱人强制跟着一起穿门）**：只要推箱进门，人随箱子一同瞬间穿出到另一端。逻辑稍显单一，推荐方案 A。

2. **单门被堵时的处理规则**：
   - **方案 A（严格物理阻抗拒止，推荐）**：若出口门正前方有障碍物挡死，入口门暂时“硬化”不可进入，符合真实物理常识；
   - **方案 B（强行挤出）**：若出口被堵，推入门的箱子强行将出口外的障碍物向前顶出 1 格。

3. **最少步数三星评价体系**：
   - **方案 A（官方最优步数 +3 步内三星，推荐）**：给玩家微小的试错容错空间，既能追求极限优化，又不会因为多走 1 步而过度挫败；
   - **方案 B（绝对严苛唯一最优解）**：只有 1 步不多才能得三星。
