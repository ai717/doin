## 1 · 创意概念与核心乐趣

- **游戏名称**：太空防御者 / Space Defender / 建议 slug：`space-defender`
- **一句话玩法**：驾驶复古战机左右穿梭，在几何弹幕的缝隙里精准点射，擦弹充能、夺回被俘僚机双机合体，一路反打至敌方母舰。
- **核心乐趣与卖点**：
  - **街机原初的射击爽感（Arcade Fire dopamine）**：这是电子游戏史上最古老也最上瘾的手感之一——左右横移、扣下扳机、敌阵成排炸开。命中反馈必须是"打在肉上"的：敌机中弹瞬间爆出橙白火花与碎片，音浪短促扎实，屏幕微微一震，手指立刻想要再来一次；
  - **擦弹走位的高手上限（Graze & Overload）**：本作最核心的微创新。子弹**擦过**（而非命中）机身外圈 14px 的"擦弹环"时，会溅出蓝色火花并充能 `OVERLOAD` 槽。贴着弹幕边缘飞行是极高风险的自愿行为，换取的是倍率与护盾——把"躲弹"从被动的恐惧变成主动的炫技，这是弹幕类游戏最上瘾的分层设计；
  - **夺回僚机 · 双机合体（Dual Fighter Fusion）**：旗舰敌机（皇蜂）会发射牵引光束捕获本机；此时不慌不逃，反手击落**正在牵引的那艘**敌机，即可救回僚机，两机并翼、火力翻倍（双管齐射 + 弹宽提升）。这是极少数"被抓住反而是机会"的正反馈设计，紧张感与反转的爽感拉满；
  - **连击链的节奏压迫（Combo Chain）**：连续击杀（间隔 < 1.2s）层层累进倍率 ×1 → ×8，链断则清零。玩家不再只是"清完一排"，而是主动规划击杀顺序以维持链不断，心智负担与爽度同步提升；
  - **星区推进的章节感**：不是无止境地刷分，而是 5 个星区 × 6 波 = 30 波的编排战役，每区引入一种新敌机与新弹幕语汇，区末一场母舰 Boss 战。玩家的动力是"再推一个星区、把这关打成三星"。
- **核心循环**：
  ```
  观察敌阵与弹幕几何 ➔ 横移走位（贴弹擦弹充能） ➔ 点射/连射清排（维持连击链）
        ↑                                                        ↓
  拾取能量浮游炮 / 夺回僚机合体 ← 清空一波 → 波次结算（命中率·无伤·用时 → 星级）
        ↓
  星区推进（新敌机 / 新弹幕 / 母舰 Boss） ➔ 战役通关勋章 / 刷新个人最佳
  ```

## 2 · 经典标杆与对标参考

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Space Invaders（Taito 1978）** | 街机 | 敌阵整体横移、逐排下压、越打越快；掩体块可被逐层削掉 | 压迫感来自"敌阵逼近"这一空间威胁，节奏自然加速无需读表 | 敌阵编队整体漂移 + 边界折返下压；速度随剩余数量递增（幸存者加速）；顶部警戒线判定 | 单调的单发直落弹与固定节奏，现代玩家会觉得拖沓 |
| **Galaga（Namco 1981）** | 街机 | 皇蜂牵引光束俘获战机 → 击落俘获者夺回 → 双机合体火力翻倍；挑战关卡（Challenging Stage） | 招牌的"被俘—反打—合体"反转体验，是射击游戏史上最优雅的风险激励 | 双机合体机制、编队俯冲（Dive）攻击、连击计分 | 原版容错极低，一碰即死，新手上手挫败 |
| **Galaxian（Namco 1979）** | 街机 | 敌机脱离编队单独俯冲轰炸 | 编队与俯冲两种威胁交替，画面不再静止 | 俯冲编队（Dive Squad）行为：脱离阵型 → 弧线俯冲 → 归位 | 俯冲轨迹过于固定可背板 |
| **Gradius（Konami 1985）** | 街机 | 击落红机掉落能量胶囊 → 自选升级槽（速度/导弹/浮游炮/护盾） | 浮游炮（Option/Multiple）跟随本机同步开火，成长感明确 | 能量浮游炮：最多 2 枚跟随僚机，随本机同步开火并可覆盖侧翼 | 胶囊选择菜单操作复杂，网页小游戏里太重 |
| **现代弹幕/擦弹系（东方 Project、Danmaku 独立作）** | PC/同人 | 极小判定点 + 擦弹（Graze）计分 + 资源化 | 把"贴着死神跳舞"变成可量化的技术深度 | 擦弹环充能 `OVERLOAD`、本机判定点小于外形的公平性设计 | 满屏子弹遮挡视线（本作走"几何可读弹幕"，绝不做视觉污染） |

**我们要继承的成熟机制**：
1. **敌阵整体漂移 + 折返下压 + 幸存者加速**：敌阵作为整体左右横移，触边即下降一格并折返；剩余数量越少，横移与开火频率越高（形成经典的"最后一只能跑全场"紧张高潮）；
2. **俯冲编队状态机**：敌机按 `编队巡航 → 脱离 → 贝塞尔弧线俯冲 → 投弹/撞击 → 拉升归位` 的显式状态机运作，俯冲数量与波次挂钩（有上限，绝不出现全员同时俯冲的不可解局面）；
3. **双机合体（Galaga Capture Rescue）**：母舰级敌机发射牵引光束，命中本机则进入"被俘"状态；被俘期间本机不死亡，而是挂在敌机下方；击落该敌机 → 僚机归队 → 双机合体（火力 ×2、弹宽 +60%），合体状态仅 1 次容错（被击中退化合体、不死亡）；
4. **本机判定点小于外形（Shmup Hitbox Fairness）**：视觉机身约 34px 宽，真实受击判定仅中心 12px 的"核心光点"；外圈用于擦弹充能。这是弹幕游戏"让不可能看起来公平"的行业标准做法；
5. **固定步长物理 + 确定性随机**：战斗推进走固定步长纯函数，敌人生成、弹幕相位、掉落均由种子 PRNG 决定，保证可回放、可单元测试。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **几何可读弹幕（Readable Geometry）**：所有敌弹都是清晰的几何语汇——`扇形齐射 / 环形轮转 / 螺旋渐开 / 十字点射`，弹体统一为高对比的发光菱形与圆环，绝不堆叠到满屏糊成一片。每波弹幕密度设硬上限（同屏敌弹 ≤ 90）；难度来自**形状与节奏**，不来自数量；
2. **擦弹充能 → 主动过载（Graze → Overload）**：擦弹满槽后自动（或手动按键）进入 2.5 秒 `OVERLOAD`：射速翻倍、敌弹时间流速降至 60%（子弹视觉变蓝变慢）、得分 ×2，结束后清空槽位。一个"高风险换高回报"的窗口按钮，把走位技术直接兑换成火力；
3. **无死局保证的安全走廊（Safe Corridor Guarantee）**：每一波敌阵的开火序列在生成时即做校验——任意时刻战场上必须存在至少一条宽度 ≥ 本机宽度 ×1.6 的连续横向逃生通道。敌机俯冲数量上限、同屏弹幕上限与最小开火间隔共同保障"永远有解"，玩家死亡永远是操作失误而非运气；
4. **能量浮游炮（Orbital Drones）**：击落带能量核心的敌机掉落橙色胶囊，拾取后挂载 1 枚浮游炮（最多 2 枚），浮游炮随本机横向镜像位移并同步开火，覆盖侧翼，形成"火力编织"的成形快感；
5. **波次三星评价**：每波结算按 `命中率 ≥ 70%` / `全程未被击中` / `限时内清空` 三条独立授予金星，战役总星数成为真正的追求指标（而非单纯刷总分）。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素
- **作战舷窗（Combat Viewport）**：竖版 3:4 比例的深空舷窗（逻辑坐标 540 × 720），桌面端居中于街机框体内，等比缩放不拉伸；
- **本机（ Defender ）**：位于底部上方 60px 的横向移动带，不可上下移动（坚守经典固定射击的纯粹）；机身三角形霓虹战机，中心一颗亮点为核心判定；
- **敌阵（Swarm）**：5 行 × 9 列编队起手，按类型分层（前排速射蜂 / 中排俯冲隼 / 后排重甲蟹 / 旗舰皇蜂）；
- **母舰（Mothership）**：星区末波的 Boss，横向巡航 + 三种弹幕相位轮转，带可击破的能量核心与双侧炮塔；
- **掩体星礁（Barrier Reefs）**：底部 3 座可逐层被削的软胶护盾礁（敌弹与自机弹都能削），提供战术掩体；
- **弹幕**：自机弹为青色光针，敌弹为橙红发光菱形/圆环（擦弹环内触发蓝色火花）；
- **掉落物**：橙色能量胶囊（浮游炮）、银色护盾芯片（+1 层护盾，上限 3）。

### 3.2 判定与胜负规则
1. **胜利条件**：清空当前波次全部敌机（母舰波为击破母舰核心）→ 进入下一波；完成第 5 星区第 6 波（共 30 波）即战役通关；
2. **失败条件**：护盾层数归零后，核心判定点被敌弹/敌机撞击命中 → 本机损毁；战役模式共 3 条命（每星区开始补 1 条，上限 3）；命数耗尽即战役失败（保留当前星数进度，可从本星区重打）；
3. **侵入判定**：敌阵下压至底部警戒线（本机上方 40px）时触发"防线失守"——不立即死亡，而是每 2 秒强制扣除 1 层护盾，逼迫玩家加速清场（比原版直接 Game Over 更宽容、更可读）；
4. **被俘与合体**：皇蜂牵引光束命中本机 → 本机被吊起（不可移动、不可开火，持续 3 秒判定窗口）；在此期间击落该皇蜂 → 僚机归队 → **双机合体**；若 3 秒内未击落 → 直接损失 1 条命（合体失败）；
5. **无死局说明（硬性）**：
   - 敌机俯冲同屏上限 = `min(2 + floor(wave/8), 5)`，且俯冲前必先播 0.35s 的蓄势抖动预警；
   - 同屏敌弹硬上限 90；任意敌机的最短开火间隔 ≥ 0.45s；
   - 波次生成后跑"安全走廊校验"：沿战场纵向切分 18 条通道，校验任一时刻至少 1 条通道的敌弹占位为 0；不满足则回退该波随机种子重生成（最多 8 次，务必在测试中覆盖）。

### 3.3 手感调优与操作映射（键鼠触全通）
- **移动**：桌面 `←/→` 或 `A/D` 横移（带 0.08s 加减速惯性，绝非瞬移）；鼠标在舷窗内横向拖动 / 移动即跟随；移动端手指在舷窗下半区**相对拖动**（手指移动 1px 本机移动 1px，手指不遮挡机身）；
- **开火**：桌面 `空格/ J` 按住连射（射速上限由武器等级决定，长按自动节流）；移动端固定右下角实体**发射键**（按住连射）；也提供"自动开火"开关（默认开启，照顾休闲玩家）；
- **过载**：`K` / `Shift` 或点击右下角 `OVERLOAD` 徽章手动引爆（槽满时）；
- **操作缓冲（Input Buffering）**：开火按键在射速冷却结束前 0.12s 内按下会被缓存，冷却结束立刻发射；移动输入在暂停/结算面板关闭后自动恢复，绝不吞输入；
- **容错**：复活后 1.6s 无敌闪烁 + 清屏（将场上敌弹柔化为得分粒子），杜绝"复活即再死"；擦弹环与核心判定分离，判定宽容度偏向玩家。

### 3.4 模式编排（为动作射击量身定制，拒绝千篇一律）
1. **星区战役（Sector Campaign · 核心模式）**：
   - 5 个星区 × 6 波 = **30 波编排战役**，每波三星评价，总星数 90；
   - 星区递进：① 新兵星区（基础速射蜂）② 隼群星区（引入俯冲）③ 蟹甲星区（重甲敌 + 分裂碎甲）④ 皇蜂星区（牵引俘获，鼓励主动合体）⑤ 母舰星区（Boss 连战）；
   - 每区末一场母舰 Boss 战，击破有专属的核爆慢镜演出。
2. **母舰突袭（Mothership Rush · 限时挑战）**：
   - 直奔 Boss，5 分钟内连打 5 场母舰，主打"总用时最短"排行，适合碎片时间爽一把。
3. **生存狂潮（Survival Onslaught · 街机刷分）**：
   - 单命无尽波次，敌阵强度随波数持续爬升，记录个人最高波数与最高连击链；作为战役之外的街机补充（**不是主轴**）。

> 说明：本作**不设每日挑战**——固定射击的乐趣在于手感与推进，不在每日解谜。

### 3.5 反馈体系与评价
- **核心指标**：战役总星数（90 星制）、单波三星、命中率、最长连击链、擦弹次数、母舰击破用时；
- **连击链（Combo Chain）**：击杀间隔 < 1.2s 递进 ×1→×8，链断清零；链每升一级，HUD 连锁计数器 bump 跳动 + 音高升半音；
- **结算仪式感**：母舰击破触发慢镜核爆（时间流速 0.35× 持续 0.8s）→ 碎片四散 → 战报卷轴展开（本波命中率/连击/擦弹/用时）→ 金星逐颗点亮（阶梯 delay）；战役通关额外授予"星区勋章"徽章陈列墙。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 项核心设计进行拍板定夺：

### 拍板项 1：招牌特色机制走哪条路线？
- **选项 A（双机合体 · 推荐）**：延续 Galaga 的"牵引俘获 → 反打夺回 → 双机合体"，被抓是机会不是惩罚，反转爽感最强、辨识度最高；
- **选项 B（纯浮游炮成长）**：延续 Gradius 路线，靠击破掉落胶囊持续挂载僚机（最多 4 枚），走"火力越滚越大"的成长爽感，风险更低、更休闲。

### 拍板项 2：是否保留"擦弹 OVERLOAD"硬核系统？
- **选项 A（保留 · 推荐）**：擦弹充能 + 手动过载（射速翻倍 + 敌弹减速 + 得分翻倍），给高手明确的技术上限与炫技空间；
- **选项 B（简化）**：擦弹只累计得分倍率与统计，不做手动过载，整体节奏更轻、更容易上手。

### 拍板项 3：模式主轴如何编排？
- **选项 A（战役为主 · 推荐）**：30 波 / 5 星区编排战役 + 母舰突袭（限时）+ 生存狂潮（补充），三星评价为追求指标；
- **选项 B（街机生存为主）**：主打单命无尽生存与高分榜，战役只做精简 12 波教学关。
