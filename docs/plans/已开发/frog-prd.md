## 1 · 创意概念与核心乐趣

### 游戏名称
- **中文名**：青蛙过河
- **英文名**：Frogger / Leap Frog
- **建议 slug**：`frog`（单个简短纯英文单词，符合平台 slug 极简契约；候选 `frogger`——更直白、历史名，但贴近物文案商标，故首选 `frog`）

### 一句话玩法
操控小青蛙在车流与流水间逐格蹦跳，穿越马路、踩浮木渡河，把青蛙一只只安全送进对岸的家。

### 核心乐趣与卖点
- **"读秒一秒"的心跳**：盯着车流找缝隙、掐着浮木漂来的节奏起跳——每次成功穿过的"贴脸躲过"瞬间，肾上腺素飙升。
- **顺水漂流的节奏感**：跳上浮木随水漂移、再借下一根木头的空隙跃出，形成一段段"踩点跳跃"的律动，像在打一支水上节拍。
- **归巢的连锁成就感**：每安全送一只青蛙进家，都落下一块"勋章"；填满 5 个家的收官瞬间仪式感拉满。
- **渐进竞速的复玩冲动**：同一关反复挑战"更快通关用时"，是经典街机的天然复玩钩子。

### 核心循环
```
观察车流缝隙 / 浮木节奏 → 找准时机四向跳跃 → 前进或随木漂移
        ↑                                 ↓
        │                       安全穿过 / 落水被撞重生
        └────── 送蛙归巢 → 填满 5 家 → 下一关更快更难 ←── 计时推进
```

## 2 · 经典标杆与对标参考

### 2.1 成熟标杆原型
- **Konami《Frogger》(1981)**：街机元祖，本作即是它的"现代致敬"。网格逐格跳跃、车道多向车流、河流浮木/乌龟承载、5 个归巢槽填充、限时与限命，是最被玩家记住的完整机制。
- **Hipster Whale《Crossy Road》(2014)**：现代移动版致敬，把 Frogger 做成了"无尽头往前跳 + 可爱软胶/像素角色 + 一撞即死"的爽快节奏。它证明了这个玩法跨越 40 年依旧耐玩。

### 2.2 我们要继承的成熟机制
- **网格逐格四向跳跃**：青蛙一次跳满一格（一格即一次输入），路面/河面都严格对齐网格——这是 Frogger 手感的核心。
- **车道多向车流异构速度**：左/右行车道、轿车/卡车/赛车多车型、多档速度，构成"要读的交通流"。
- **河流浮木/乌龟承载**：跳上会漂移的浮木随水移动；乌龟成组漂移、套路性地周期性下潜，站在下潜乌龟上会落水。
- **归巢填充制 + 时限**：5 个家槽逐只填充；每只青蛙带倒计时，逼迫你不磨蹭、往前冲。
- **限命制度**：死亡消耗生命，命尽重开本关，已填满的家保留。

### 2.3 本作的独特魅力与微创新
- **节奏可视化预判**：把"车流缝隙 / 浮木漂移 / 乌龟下潜周期"做成**可读的节拍暗示**（呼吸脉动、柔光预告），让"精准时机"从纯反应升级为"半反应半预判"的可习得韵律——这是经典留给现代玩家的改良礼物。
- **章节关卡制的深度编排**：不做"一屏循环加速"的单调，而是分章节引入**卡车、赛车、下潜乌龟、夜行迷雾**等新障碍，每章一次机制翻新。
- **竞速基因强化**：每关记录"最快通关用时"，把街机的"冲纪录"冲动做成本机排行榜，而非机械的"得分按钮"。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**盘面构成**（俯视网格，经典 13 列宽 × 上下分层）：
- **顶部归巢区**：5 个"家槽"横向排开，间隔设"凹墙"（跳错到槽间或边缘即 death）。
- **河流区**（约 5 行）：左右漂移的**浮木**（1–3 格长、不同速度/方向）与**乌龟组**（成组漂移、会周期性下潜），部分关卡点缀静止**荷叶**落脚点。
- **中央安全岛**：一条灌木缓坡，是马路与河流之间的安全过渡带。
- **马路区**（约 5 行）：轿车（1 格）、卡车（2 格）、赛车（1 格高速）多向车道，速度各异。
- **底部起点草地**：青蛙初始出生位。

**玩家合法操作**：四向逐格跳跃（上/下/左/右各一格）。跳跃必须落满一格；除中央安全岛外，河流区只有在浮木/乌龟/荷叶上才安全。

**判定规则**：
- 被车撞 → 死亡；落水（河流区落在空水域、或被下潜乌龟带下水）→ 死亡；跳到屏幕左/右边缘 → 死亡。
- 抵达空的家槽 → 归巢成功（+1 只），从起点刷新新青蛙；跳上已占用家槽或槽间凹墙 → 死亡。
- 5 个家槽全部填满 → **过关**。
- 命数为 3 条（可依关卡调整）；命尽 → 本关失败重开，**已填满的家保留**。
- 每只青蛙有独立倒计时，归零 → 死亡。

**无死局 / 可解性保证（映射算法铁律）**：
- **交通流公平**：车道车辆间距保证永远存在可穿越的安全时隙，绝不生成"密不透风的车墙"；随关卡推进收紧的是"时隙窗口"，而非堵死通路。
- **浮木链可承载**：浮木/乌龟漂移周期保证任意时刻都存在一条**时间上连续、可一步步跳跃推进**的承载链路（生成器做可达性校验），不出现"无木可踩"的死水墙。
- **确定性可复现**：交通与浮木生成注入确定性种子 PRNG（`mulberry32`），每关局面固定、可复现、可单测；大步数随机游走测试保证任意合法跳跃序列不抛错、不变式不破。

### 3.2 操作与手感
- **键盘**：方向键 / `WASD` 四向跳跃。
- **鼠标**：点击青蛙相邻格即向其跳跃（网格吸附，点击即落格）。
- **触屏**：四向滑动跳跃 + 底部一体式方向键盘（掌机面板内嵌，非悬浮散落）。
- **误触容错与输入缓冲**：连续快速按压方向时**跳跃排队执行**（Input Buffering），绝不丢操作；跳跃是"离散一格"的原子动作，无惯性、无可取消，手感干脆。
- **逆流手感**：浮木上随木漂移是"被动移动"，玩家只需在正确时机主动跳到下一安全点，形成"主动跃 + 被动漂"的节拍感。

### 3.3 模式与内容编排（依"时机闯关竞速"特质定制，拒绝套路化）

> 不做"无尽冲分 + 每日挑战 + 得分按钮"三件套。本作的天然递进是**章节关卡 + 竞速用时**。

- **章节关卡制（主线）**：5 章、每章 8 关，共 **40 关**，逐章引入新机制：
  - **第 1 章「湿地清晨」**：慢车、单段浮木、无乌龟，纯入门。
  - **第 2 章「都市环路」**：卡车（2 格）加入、车流提速、多向汇流。
  - **第 3 章「湍流河谷」**：**下潜乌龟**登场、长浮木+荷叶组合、浮木漂速提升。
  - **第 4 章「夜行高速」**：赛车（高速）加入、夜间霓虹、视野光晕收窄（专注感 gimmick）。
  - **终章「传奇桥梁」**：极窄时隙 + 高频下潜 + 最短时限的"一命通关"挑战关。
- **评价体系 = 通关星级 + 最快通关用时**：
  - 每关 1–3 星，依"剩余命数 + 通关用时 + 归巢 bonus"综合评定；
  - 每关独立维护一条本机"最快通关用时"，过关时若破纪录弹出轻量破纪录仪式；通关总用时即玩家的核心追求指标，**有星级、有时长，无"总分"、无金币**。

### 3.4 计分（局内辅助反馈，非评价核心）
- 每次朝向河对岸前进一格 `+10`（贴近经典 Frogger）。
- 成功归巢 `+50`，且按剩余倒计时折算时间 bonus。
- 吃中随机出现在空家槽的**飞虫/萤火虫** bonus `+200`。
- 分数仅作局内即时爽感反馈，评价以上文"星级 + 最快用时"为准。

## 4 · 美术风格与视觉氛围

### 4.1 题材与视觉关键词（建议：软胶玩具方向）
`软胶玩具桌面戏剧台` · `俯视微缩布景` · `毛毡水面` · `卡纸马路` · `温暖落日光`

### 4.2 沉浸舞台规划（游戏机台化，拒绝老套网页病）
- **整体"机台" = 一盒精致的桌面玩具布景（Diorama）**：整块游戏棋盘像摆在木质小桌上的**微缩公路＋河流 diorama**，四周是暖色调的景深光晕与漂浮光尘，营造"把玩一盒精装桌游"的氛围，绝非苍白网页表单。
- **核心舞台**：居中俯视棋盘，上下分层（归巢 → 河流 → 安全岛 → 马路 → 起点）清晰可读，棋盘四周保留广告位安全边距（桌面端舞台宽不超过约 1100px）。
- **左右两翼**（桌面端 ≥900px）：不堆 SaaS 白卡，而是做成**木质挂牌 / 卷轴样式**两翼——左翼为"关卡章节目录"（星球/木牌关卡点，已过关亮金边），右翼为"最快用时 + 剩余命"的软胶小招牌，与棋盘构成完整玩具台。
- **移动端**（≤768px）：单列，棋盘占屏宽；操作方向键盘嵌入底部掌机面板，底部预留 ≥68px 广告安全留白。

### 4.3 色彩与实体质感
| 角色 | 色值/材质 |
|---|---|
| 环境 | 暖木桌 + 落日橙黄光晕 + 四角暗角 |
| 草地/安全岛 | 柔绿毛毡质感 |
| 马路 | 深沥青卡纸 + 白色虚线车行道 |
| 河流 | 半透明蓝色水面 + 波光微动 |
| 浮木 | 圆木积木，棕黄木纹 |
| 乌龟 | 软胶小龟，壳背微凸 |
| 车辆 | 玩具小轿车 / 卡车 / 赛车，哑光糖果色 |
| 青蛙 | 3D 软胶绿青蛙，圆润高光 |

- **实体按键质感**：方向键盘为掌机实体键（微浮雕、按下机械下沉）；关卡木牌可点、悬停轻浮。
- **交互反馈**：跳跃落地轻微弹性 squash；归巢成功有"啪"的软胶到位音 + 家槽点亮仪式；死亡有短促震动 + 灵动水花/车鸣反馈；时限最后几秒倒计时脉冲 + 紧迫提示音。
- **辨识度硬性红线**：浮木/乌龟/危险车辆**不用描边圈**标记，改用**无边界径向柔光（安全落脚点静态柔光）+ 呼吸脉动（危险物/即将下潜乌龟）**，配合明暗对比把主体"托"出来。

### 4.4 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **主体**：一只正脸卖萌的 **3D 软胶绿青蛙**居中坐镇（60–75% 占比），脚下踩一根小圆木/一片荷叶。
- **背景色系**：**暖橙渐变**（落日公路暖调，避开已上架游戏的相色冲突）。

## 5 · 制作人拍板与开放探讨

**请制作人（用户）对以下 3 项拍板：**

1. **★ 视觉方向（最关键）**——走哪种审美？

   - **保留原版硬核**（推荐）：乌龟周期性下潜、站上去会落水——第 3 章起引入，制造紧张。

3. **命数设计**：固定 3 命（经典）vs 关卡内可获"续命"（如吃奖金飞虫偶得 1 命，容错更高、更友好）？
