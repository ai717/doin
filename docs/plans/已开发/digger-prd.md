## 1 · 创意概念与核心乐趣

- **游戏名称**：挖掘者 / Digger / 建议 slug：`digger`（备选 `digdug`）
- **一句话玩法**：在地质剖面中自由挖洞开凿隧道，用气筒给古怪地底生物充气爆破，巧用悬空巨石一砸成名！
- **核心乐趣与卖点**：
  - **自由开凿改变地形的纯粹爽快感（Dynamic Tunnel Sculpting）**：
    与《gold-miner》（机械爪定点抓取）和《shaft》（垂直深渊自由落体）截然不同！本作的核心魅力在于**“用走位在泥土中亲手雕刻隧道”**。玩家走过的每一格泥土都会永久化为通途，地形的阻隔、迂回与贯通完全由玩家的下铲路径决定；
  - **经典殿堂级充气爆破与落石诱杀（Pump Inflate & Rock Drop）**：
    原汁原味致敬 Namco 1982 年街机神作《Dig Dug》的两大神级机制：
    1. **打气爆破**：射出气管钩中敌人，连点打气让敌人像气球一样胀得圆滚滚直至“嘭！”一声爆裂；
    2. **落石陷阱**：挖空悬空古生物巨石下方的泥土，巨石晃动 1 秒后轰然砸落，将追赶而来的成群怪物一次性砸扁，战术爽感爆棚；
  - **题材微创新：自然博物馆“考古地层剖面”（Archaeological Strata Excavation）**：
    彻底摒弃压抑陈旧的黑黢黢地下矿坑！将舞台重塑为一座明亮典雅的**微缩地质年代沉积岩标本箱**。从表层腐殖土、侏罗纪恐龙骨骼层、古埃及金字塔陶片层，一路挖到寒武纪三叶虫化石层，边玩边收集绝美古生物化石标本；
  - **20 关考古探险史诗（4/4/4/4/4 结构）**：
    关卡层层递进，从熟悉单怪充气到诱敌聚歼于巨石之下，兼具单手触屏友好度与键盘极限微操。
- **核心循环**：
  ```
  观察地质剖面中怪物与悬空落石位置 → 挖掘泥土开辟战术隧道
       ↑                                                      ↓
  下一地层 / 展出考古新标本 ← 全场地底魔物全清通关 ← 钩住怪物连续打气爆炸 / 诱敌至落石下方砸碎
       ↓ (被怪物幽灵形态追上碰撞 / 被落石误砸)
  生命 -1 (共 3 条命) → 原地脱险复活，调整走位隧道破局
  ```

**我们要借鉴的成熟机制**：
1. **地质网格与隧道挖空状态机（Grid Tunneling Invariant）**：
   - 地下为 $16 \times 14$ 网格，每格大小 $36 \times 36\text{px}$；
   - 泥土（Dirt）网格具有平滑过渡边缘，主角只要向该方向行进，瞬间将泥土清除并生成平滑连通的隧道；
2. **气动充气三阶段爆破（Inflation States）**：
   - 射出打气钩（射程约 3 格）：命中怪物后进入牵制状态，怪物无法移动；
   - 每次按键注入一泵空气，怪物经历【微胀 ➔ 鼓胀 ➔ 极限半透明 ➔ 爆炸】四态；
   - 若停止打气，怪物以每秒 1 级的速度缓慢漏气缩小并恢复移动，考验玩家在多敌逼近时的“分段打气控场”；
3. **悬空化石落石物理（Fossil Rock Physics）**：
   - 巨石静止在泥土上；
   - 一旦巨石正下方的泥土被挖空，巨石进入**【1秒悬停颤抖警报】**；
   - 随后进入**【高速下落压路机状态】**，沿垂直隧道以 $V = 400\text{ px/s}$ 坠落，碾碎沿途一切生物（包括主角！）；触碰未挖泥土或底边缘碎裂为小碎片。

**本作的差异化微创新（拒绝无聊深渊地牢）**：
1. **自然历史博物馆“沉积地质剖面”（Museum Stratigraphy）**：
   - 将整面墙重塑为一件陈列在玻璃标本箱中的真实地质剖面：
     - 表层：浅黄腐殖土与青草；
     - 中层：砖红侏罗纪红砂岩，隐约可见霸王龙牙齿与腕龙椎骨；
     - 深层：深黛古生代页岩与紫晶洞；
2. **化石碎片顺路发掘（Fossil Showcase）**：
   - 挖开特定泥土可顺路收集完整的“三叶虫”、“始祖鸟羽毛”化石，点亮侧边展柜，通关后生成你的“私人地质发掘报告”；
3. **幽灵气化与喷火双怪生态**：
   - 红色小土龙（只能在已有隧道中巡逻，追击速度极快）；
   - 黄色鬼面虫（在地底会间歇性气化为半透明眼球穿透坚固泥土突袭，逼迫玩家时刻警惕）。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与网格构成**：
  - **视口宽 840px、高 560px 的微缩地层标本箱**；
  - **地表露天区（Top Sky）**：顶部 2 行高度为阳光草地，主角的初始安全大本营；
  - **地下沉积层（Underground Grid）**：$16 \times 14$ 网格，分布着泥土、预置隧道、悬空巨石、化石碎片与沉睡的怪物；
  - **双方角色与怪物**：
    - 主角（Archaeologist）：穿工装裤、戴防尘镜，配备手摇气泵；
    - 呆萌红怪（Pooka）：戴护目镜的红色圆球怪，偶尔可幽灵化穿土；
    - 喷火绿龙（Fygar）：绿色小喷火龙，每隔 5 秒会停下两脚站立蓄力，向左右喷出长达 3 格的烈焰。
- **玩家合法操作**：
  1. **移动与挖掘（Move & Dig）**：
     - 方向键【↑ / ↓ / ← / →】或【W / A / S / D】：
     - 向任意方向走动，迎面撞击泥土自动挖出通道，伴随泥沙飞溅；
  2. **发射气泵与充气（Pump Action）**：
     - 键盘【空格键 (Space)】或触屏大号【PUMP】按钮：
     - 向当前面朝方向射出一道带倒钩的气管；
     - 命中敌人后，快速连续敲击空格键为敌人充气，敲击 3 次引爆！
  3. **利用落石诱杀（Trap with Rock）**：
     - 走到巨石正下方把土挖空，迅速横向溜走；
     - 巨石晃动 1 秒后坠落，将追在身后的怪物一网打尽。
- **胜利判定与关卡目标**：
  - **通关胜利（Clear）**：消灭当前地层中的**所有地底怪物**（若只剩最后一只怪，怪物会惊慌失措试图挖洞逃回地表，将其在逃跑途中阻截爆破更添戏剧性）；
  - **失败判定（Game Over）**：
    - 主角被怪物正面触碰；
    - 主角被绿龙的喷火烧中；
    - 主角被自己挖空的悬空巨石砸扁；
    - 初始拥有 3 条命，命数耗尽结算本关。
- **数学可解性与 100% 确定性保证**：
  - 怪物 AI 的寻路基于严格的网格曼哈顿距离与状态机时序（每隔 8 秒尝试一次穿土，持续 2.5 秒）；
  - 关卡初始怪物的出生点与隧道完全隔开，给玩家预留充足的挖土布局时间，绝不存在开局秒杀死局。

### 操作与手感细节

- **视听爽感与声学微雕**：
  - 挖土脚步：轻柔酥脆的泥沙翻动“沙沙、沙沙”白噪音；
  - 气筒射击：弹簧伸展的“飕——啪！”清脆钩中声；
  - 怪物充气：如同气球吹气般的升调尖啸“滋、滋、滋——”；
  - 怪物引爆：滑稽清脆的爆米花炸裂“嘭！” + 飞溅的软胶彩色碎片；
  - 巨石晃动：低沉危险的石块摩擦咯吱声，随后“轰隆隆”砸地激起大片扬尘；
  - 喷火吐息：烈火喷射的“呼——”呼啸声。

### 关卡模式编排（20 关五大考古地层：4/4/4/4/4）

1. **第一卷：浅层近现代遗迹（Modern Strata · 4关）**：
   - 浅黄色沙土层，初识开挖隧道、单只红怪充气与落石基础教学；
2. **第二卷：青铜与陶片地层（Bronze Age · 4关）**：
   - 砖红黏土层，引入喷火绿龙，考验避开横向火焰轴线；
3. **第三卷：侏罗纪骨骼页岩（Jurassic Fossils · 4关）**：
   - 深棕色页岩层，巨石密集，练习“一石砸死双怪”的高阶诱敌操作；
4. **第四卷：寒武纪三叶虫层（Cambrian Matrix · 4关）**：
   - 墨绿凝灰岩层，怪物穿墙频率提升，考验迷宫死胡同设计；
5. **第五卷：太古紫晶地幔（Precambrian Core · 4关）**：
   - 幽蓝紫晶层，复合多龙喷火阵与高速红怪，终极发掘登顶成为“皇家首席地质学家”！

## 4 · 美术风格与视觉氛围（博物馆标本箱，拒绝网页仪表盘）

- **题材与视觉关键词**：**自然博物馆 · 地层沉积剖面 · 羊皮纸手账 · 软胶化石 · 怀旧街机质感**
  （不做单调惨白的白底网页，不做粗糙简陋的现代贴图；呈现为如同置身于大英自然历史博物馆中，透过厚玻璃凝视一块微缩发掘标本剖面）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Strata Showcase）**：

  - **右侧策略翼栏（HUD Right Wing · 化石图鉴台）**：

    - 浅层：温暖燕麦黄 `#f5cd79`；

    - 深层：石青页岩 `#4a69bd`；
    - 地幔：紫晶玄武岩 `#6c5ce7`；

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **怪物穿墙（气化形态）的频率与威胁度**：
   - **方案 A（经典周期性气化，强烈推荐）**：怪物每隔 8 秒可以变成半透明幽灵穿过泥土 2~3 秒，逼迫玩家不断挖新隧道防被抄后路，战术紧张感最纯正；
   - **方案 B（只能在挖开的隧道中移动）**：怪物绝不穿墙，纯走玩家挖好的通道，更休闲温和。

2. **化石收集与三星评级关联**：
   - **方案 A（全清怪必过关 + 顺路挖化石奖三星，推荐）**：消灭全部怪物即可通关（保底友好），顺路挖出地层中隐藏的 3 枚化石可得三星，满足强迫症玩家的扫盘乐趣；
   - **方案 B（纯看通关耗时）**：不设化石，仅按清怪速度评星。

3. **落石砸死怪物的额外收益**：
   - **方案 A（落石击杀双倍积分大赏，推荐）**：用打气筒爆破得基础分，成功用落石砸死怪物奖励 3 倍巨额积分，鼓励玩家秀出“巨石天降”骚操作；
   - **方案 B（两种击杀方式等同）**：纯物理手段，得分一致。
