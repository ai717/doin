## 1 · 创意概念与核心乐趣

- **游戏名称**：深夜拉面屋 / **Midnight Ramen** / 建议 slug：`ramen-idle`（制作人口径，保留"idle"品类识别度；备选单词汇 `ramen`）
- **一句话玩法**：深夜街角开拉面摊，备料出餐自动赚钱，扩店解锁配方滚雪球。
- **核心乐趣与卖点**：
  1. **放置滚雪球的数字膨胀爽感**——街边小摊一碗一碗卖出，逐步变成自动化流水线、连锁分店，营业额从个位数飙到百万日元；离线回来收一大笔，再投进去翻倍，是放置品类最纯粹的"越挂越强"。
  2. **备料→出餐双链供给的经营脑**——原料要备、汤头要熬、面要煮、客要接，四环环环相扣；断料会掉产，逼玩家布局自动化而非干等——比单链放置多一层"铺流水线"的策略感。
  3. **深夜食堂式治愈叙事**——12 位有故事的常客（加班族、代驾司机、失眠老人……）在深夜时段来访，喂对口味的菜解锁他们的故事与隐藏配方；经营的不只是钱，还有人情味。
  4. **配方图鉴的收集欲**——满足隐藏条件研制新菜品，图鉴一格一格点亮；扩店不只是数值翻倍，更是菜单变厚的过程。
  5. **离线收益的"温情收账"**——回归时不是干巴巴的数字，而是常客留言："昨晚的豚骨汤让我想起老家的冬天。"暖光灯笼把收益数字一盏盏点亮。
- **核心循环**：备料（采购原料维持库存）➔ 出餐（炉台自动烹饪、点击冲刺）➔ 扩店（升级工位/雇帮工/开分店）➔ 解锁配方（研制新菜、点亮图鉴）➔ 收益回流 ➔ 再投入扩大产能。

> 品类占位：经核对 `games/` 目录现有 46 款作品全部为解谜 / 动作 / 纸牌 / 消除 / 合并类，**放置经营（Idle Tycoon）与模拟养成是平台空白品类**，本作是唯一候选，题材与《猫咪深夜食堂》等猫咖作品刻意错开。

- **成熟标杆原型**：放置品类 30 年沉淀出的"指数成本 + 点击/自动双轨 + 自动化雇佣 + 离线结算 + 转生倍率"五件套是成熟到不能再成熟的经济模型；拉面 + 深夜食堂题材是 2025–2026 被市场反复验证的治愈向热点。
- **我们要继承的成熟机制**：指数成本曲线、帮工自动化、离线收益弹窗结算、转生（翻新）永久倍率、确定性配方解锁（零抽卡）。
- **本作的独特魅力与微创新**：
  1. **深夜营业时间轴（Night Cycle）**——营业按"晚 18:00 → 凌晨 04:00"运转，5 个时段食客群不同（加班族 / 下班族 / 夜跑族 / 代驾与失眠者 / 黎明酒客），时段影响小费倍率与点单偏好，玩家要决策"今晚主攻哪个时段"。
  2. **备料→出餐双链供给**——原料库存前置，断料降产但不破产；把放置的单链产出升级为"采购-备料-熬煮-出餐"四环流水线，铺设自动化本身就是策略。
  3. **客流高峰 Rush Hour**——凌晨 0:00–1:00 限时 60 秒点击冲刺，收入 ×2，给放置节奏一个手动爆发的爽点。
  4. **离线收益温情结算**——回归弹窗以常客留言呈现，收益数字由灯笼一盏盏点亮，治愈感拉满。
  5. **机台化深夜街角舞台**——拉面屋剖面从左到右就是生产链实体：备料台→炉台→吧台→客席，升级工位 = 店内实景变精致。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**场景构成（深夜街角拉面屋，剖面舞台 = 生产链实体化）**
- **四环生产链**（从左到右对应店内实体工位，每环可雇帮工自动化）：
  | 环节 | 工位 | 基础产出 | 帮工（自动化） |
  |---|---|---|---|
  | N1 备料 | 备料台（原料库存：面粉 / 豚骨 / 叉烧 / 溏心蛋 / 葱 / 笋干） | 2 元/秒 | 备料学徒 Prep Apprentice |
  | N2 熬煮 | 炉台（汤底熬制 + 面条煮制） | 4 元/秒 | 拉面师傅 Ramen Master |
  | N3 出餐 | 吧台（成品交付 + 收银） | 8 元/秒 | 跑堂小二 Server |
  | N4 客席 | 客席与店面（周转 + 声誉积累） | 16 元/秒 | 店长 Manager |
- **资源**：日元（货币）、四种原料库存（每款配方消耗固定组合）、声誉值（解锁配方与店铺阶段）、配方图鉴（收集向）。
- **配方**（首发 8 款，`data.mjs` 只存 key，文案走 i18n）：`recipe_shoyu` 酱油清汤 / `recipe_tonkotsu` 豚骨白汤 / `recipe_miso` 味噌拉面 / `recipe_shio` 盐味拉面 / `recipe_tsukemen` 沾面 / `recipe_spicy` 辛口辣味 / `recipe_oyaji` 深夜特制 / `recipe_legend` 传说之面（隐藏：失眠老人故事线解锁）。

**玩家合法操作**
- 点击"拉面碗"冲刺出餐：每次点击按当前每秒营业额 ×0.5 即时入账（放置品类标准点击双轨）；Rush Hour 时段 ×2。
- 购买 / 升级四环工位与帮工；研发配方（满足确定性条件后一键研制）；扩建店铺（声誉达标后升级阶段）。
- 领取离线收益（回归弹窗，常客留言 + 灯笼计数）。

**胜负判定与容错（无死局保证，硬性要求）**
1. **无失败条件**：店铺永不倒闭、不催不赶——放置品类天然无 Game Over，机制上排除"卡死"。
2. **断料只降产不破产**：任一原料耗尽该配方停产，自动采购兜底恢复；金币永不冻结。
3. **配方确定性解锁**：所有配方由"声誉等级 + 常客故事进度 + 累计研制次数"确定性达成，**零抽卡零随机**，不存在"刷不出"。
4. **离线收益有上限**：离线时长上限 8h 起步、声誉每级 +8h、封顶 48h，防无限离线爆金币。
5. **确定性经济**：成本/产出/离线全部纯函数计算，PRNG（`mulberry32`）仅用于时段食客的排队演出（不影响收益）；需 ≥1000 步随机游走测试验证状态机在任意合法操作序列下不抛错、不卡死、不变式不破。

### 3.2 数值骨架（离线收益 4/4/4/4/218，制作人口径）

- **成本曲线**：`cost = base × 1.15^owned`（每环独立计数，指数涨价、线性增产）。
- **每秒营业额**：`Σ(各环产出 × 帮工倍率(×1.5/级) × 声誉倍率 × 时段倍率)`。
- **离线收益公式**：`离线收益 = 每秒营业额 × 离线秒数 × 离线效率 × 档位倍率`
  - 离线效率：初始 50%，购买"打烊留灯"升级后 100%。
  - **五档离线倍率里程碑（即 4/4/4/4/218）**：

  | 档位 | 倍率 | 达成里程碑 |
  |---|---|---|
  | 第 1 档 | ×4 | 全自动流水线（四环全部雇到帮工） |
  | 第 2 档 | ×4 | 首家分店（完成首次扩店） |
  | 第 3 档 | ×4 | 配方图鉴点亮 5 款 |
  | 第 4 档 | ×4 | 声誉达到"深夜名店" |
  | 终局档 | ×218 | 达成"传说食堂"（声誉 5 级 + 全配方） |

  - 五档叠加后**离线收益封顶倍率 = 4 × 4 × 4 × 4 × 218 = 55,808×**——与"单晚破百万日元"的终局数值膨胀匹配；此口径来自制作人原始需求（`4/4/4/4/218`），具体绑定里程碑待拍板确认（见 §5）。
- **店铺阶段（声誉 5 级）**：街角摊 Corner Stall → 小面馆 Tiny Shop → 人气食堂 Local Favorite → 深夜名店 Famous Midnight Spot → 传说食堂 Legendary Kitchen。
- **翻新转生（轻量 Prestige）**：达成传说食堂后可"翻新重装"——重置产线，保留配方图鉴 / 常客图鉴，获得永久 ×2 声誉倍率，可重复（每次 ×2）。

### 3.3 模式与内容编排（依放置特质定制，严禁套用"无尽+每日"三件套）

**模式一：深夜章节制（主线，一晚 = 一章节）**
- 游戏内一晚 = 18:00 → 04:00 五个时段，每时段约 6 分钟，一晚约 30 分钟可完整游玩。
- 每晚一张"深夜心愿清单"（2–3 个目标：如"接待 30 位食客""研发出豚骨白汤""单晚流水破 10 万日元"），完成即推进章节与声誉；未完成可继续挂机（无失败、不重置）。
- 章节即成长：每章引入新时段食客、新配方、新工位升级。

**模式二：客流高峰 Rush Hour（限时冲刺挑战）**
- 凌晨 0:00–1:00 时段触发，限时 60 秒：点击出餐收入 ×2，屏幕微震 + 蒸汽爆发粒子。
- 记录"单场高峰流水"与"历史最高 60 秒流水"——放置游戏里唯一的实时手速爽点，不做无尽冲分排行榜。

**模式三：常客图鉴（治愈支线，收集向）**
- 12 位常客各有口味偏好与背景故事（加班程序员 / 代驾司机 / 夜跑少女 / 失眠老人 / 黎明前的酒客……）。
- 喂对口味的菜 → 解锁图鉴页 + 永久小费加成；集齐某类常客触发隐藏配方线索（如失眠老人故事线 → `recipe_legend`）。

**模式四：配方图鉴（终极收集目标）**
- 8 款配方点亮图鉴；研制成功有"菜单更新"卷轴动画 + 食客排队换新菜演出。
- 全图鉴 + 声誉 5 级 = 传说食堂终局成就，解锁第 5 档离线倍率。

> **明确不做**：每日挑战（单机网页门户无每日刷新意义）、无尽冲分排行榜、失败惩罚（放置品类无败局）。

### 3.4 游戏目标与反馈体系

- **核心指标（不是总分）**：店铺声誉等级、配方图鉴收集度（8/8）、常客图鉴完成度（x/12）、累计营业额（日元计数）。
- **仪式反馈**：
  - 出餐：蒸汽粒子升腾 + 硬币"叮"声 + 收入数字弹性 Bump；
  - 扩店：深夜钟声 + 灯笼逐盏点亮 + 店面实景变精致（新桌、新招牌）；
  - 研制配方：菜单卷轴展开动画 + 食客排队换新菜 + "多谢款待"鞠躬；
  - 离线回归：常客留言卡片 + 灯笼数字滚动结算，暖光粒子；
  - Rush Hour：屏幕微震 + 蒸汽爆发 + 时段霓虹招牌闪烁。
- **沉浸式双语**：全站 i18n（`doin.lang`），中英文案严格对齐。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：昭和暖黄怀旧、深夜治愈、灯笼微光、木质拉面屋剖面、蒸汽粒子。
- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**：
  - **整屏 = 深夜街角的一间拉面屋**：左主舞台是拉面屋剖面（备料台 → 炉台 → 吧台 → 客席，从左到右正是生产链实体），窗外是夜色渐变街景、远处城市灯火虚化、飘雪与蒸汽粒子浮动；右侧一体化为"营业账本 + 灯笼牌匾"造型 HUD（今日流水、声誉等级徽章、生产链状态、离线收益横幅），操作按钮做成实体道具键（"出餐"是拉面碗、"研发"是菜单卷轴、"扩建"是工具锤），全部焊进舞台，不是卡片集群。
  - **禁止四角浮动按钮**：顶部一条"门帘檐"状态条内嵌返回首页、音效、语言、规则说明。
  - **桌面端（≥900px）**：主舞台居中（总宽 ≤1100px），两侧深色夜色虚化 + 灯笼光晕 + 蒸汽粒子形成景深；左右边缘与底部边缘不放置任何操作按钮，为广告安全避让留白。
  - **移动端（≤768px）**：一体化掌机框体——剖面舞台在上、操作台嵌底部面板；主容器底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，绝不让任何按钮贴底。
- **色彩与环境氛围**：
  - 主色：**墨夜靛蓝夜色 + 暖橙灯笼光 + 木棕 + 蒸汽白**（暖橙为视觉主角；深蓝夜色与平台现有太空题材靠"暖橙暖木"拉开距离，不占用蓝紫 / 青绿 / 天蓝 / 水色 / 珊瑚橙 / 古铜棕主色位）。

## 5 · 制作人拍板与开放探讨

1. **昼夜节奏**
   - **A · 游戏内"每晚"章节制（推荐）**：一晚 5 时段 ≈ 30 分钟可玩章节，离线收益按现实时间结算；有明确章节推进感，放置挂机两不误。
   - **B · 现实时间映射**：营业 = 在线时长、打烊 = 离线结算；更"真实"，但章节推进感弱、在线挂机体验平。
2. **离线收益口径确认（4/4/4/4/218）**
   - **A · 五档离线倍率里程碑（推荐，本案 §3.2 采用）**：×4 → ×4 → ×4 → ×4 → ×218，叠加封顶 55,808×，绑定五阶段成就。

   - **A · 昭和暖黄怀旧（推荐）**：木质、灯笼、浮世绘纹样点缀，深夜治愈向，与题材天然贴合。
