## 1 · 创意概念与核心乐趣

- **游戏名称**：推币机 / Coin Pusher（副标：投币推落 · 边缘连锁翻倍）/ 建议 slug：`coin-pusher`（沿用 `gold-miner` 双词先例）
- **一句话玩法**：投币入台，往复推板把满台金币推向边缘，连锁掉落、倍率翻倍，金卡极限爆出 2¹⁸ 倍！
- **核心乐趣与卖点**：
  - **投币落点的即时博弈（Insert & Aim）**：从投币口把金币"甩"向台面不同位置——落点决定它是去推板正面吃满推力，还是溜到边缘搭桥、还是卡进稀有币堆引发坍塌。每一次投币都是一次台面力学预判；
  - **往复推板的机械韵律（Pusher Rhythm）**：推板一进一退是台面的"呼吸"。高手踩着推板回程把币送到深处，等它下一个推程把整排金币顶出边缘——时机感与节拍感并存；
  - **边缘连锁翻倍的爆金时刻（Edge Cascade Doubling · 用户点名核心）**：金币越过边缘连锁掉落，**每多掉 1 枚倍率翻倍**——单枚 10 分 → 连锁 4 枚 ×8 → 极限 **2¹⁸ = 262144 倍金卡**，机箱爆响、金币喷泉，一杆翻盘的全部幻想都在这条指数曲线上；
  - **奖励物与机关的多巴胺装置（Token & Mechanism Play）**：稀有币、奖励卡、弹射器、磁吸金块、金塔——台面上永远有"下一件大事"在勾引你继续投币；
  - **街机物理品类空白补位（Arcade Physics Gap）**：DOIN 62 款游戏中没有推币机，本作以最纯粹的"物理机关+爆金反馈"补位，且全机台都是可测的固定步长物理。
- **核心循环**：
  ```
  投币（选落点/力度）➔ 推板往复推动金币堆 ➔ 边缘悬垂/连锁掉落（倍率翻倍×2）
       ↑                                                      ↓
  稀有币/奖励卡/金塔机关触发（多巴胺峰值）← 金币落入托盘计分 ← 推程把奖励物推向边缘
       ↓（剩余投币 -1）
  目标达成/连锁金卡 ➔ 三星结算/双人夺宝比分 ➔ 再来一局
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Money Money（Data East 1984）** | 街机 | 往复推板 + 投币推落金币，最早的推币机 | 街机推币的原始范式 | 推板往复、边缘落袋、投币入口 | 纯赌性无目标，缺内容编排 |

| **Pachinko / 弹珠机** | 街机/Web | 钢珠下落撞钉、奖励轨道 | 物理下落与奖励轨道的爽感 | 奖励轨道、连锁反馈的节奏设计 | 纯随机占比高、无推板主动博弈 |

**我们要继承的成熟机制**：
1. **往复推板（Reciprocating Pusher）**：推程前推台面金币、回程退让，玩家借回程投币入深处的"借力"节奏——街机推币半个世纪的核心机构；
2. **边缘悬垂与落袋（Overhang & Drop）**：金币堆叠出边缘悬垂，球心越过边缘线即掉落——物理直观、人人秒懂；
3. **奖励令牌与集卡（Token & Collection）**：稀有币、奖励卡作为台面上的"诱饵"，推动玩家为收集目标持续投币；
4. **投币滑轨手感（Coin Flick）**：投币可调落点与力度（轻甩/重掷），上手极快、深度在时机；
5. **固定步长确定性物理（Deterministic Physics）**：120Hz 纯函数帧步进、种子注入、同种子重放一致、CCD 防穿模（本策划案的核心契约，用户点名"固定步长可测"）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **边缘连锁翻倍（Edge Cascade Doubling · 用户点名）**：落袋不再是"一枚一枚加 10 分"——同一波边缘连锁内**每多掉 1 枚，本波总倍率 ×2**：第 1 枚 ×1、第 2 枚 ×2、第 3 枚 ×4、第 4 枚 ×8……四档常规翻倍后进入**疯狂翻倍**，**极限 2¹⁸ = 262144 倍金卡**（"4/4/4/4 → 2¹⁸"档位表见 3.2），单枚金币最高爆出 262 万分——这是本作区别于一切"推币机换皮"的签名机制；
2. **章节机关编排（Staged Mechanisms）**：推币机少见地采用章节挑战制，每章引入一种新机关（稀有币 → 奖励卡 → 弹簧弹射/磁吸金块 → 金塔终章），内容可编排、可背板、可测；
3. **同屏双人夺宝（2P Split-Tray Duel）**：同一机台左右分色托盘，轮流投币，掉入自己一侧的币归自己——物理共享、收益分流，天然派对博弈；
4. **街机投币机箱原生视窗（Arcade Cabinet）**：游戏本身就是一台街机投币机——霓虹招牌、玻璃窗、投币滑轨、木托盘全原生，全站无同款视窗；
5. **金卡极限演出（Jackpot 2¹⁸）**：触达 2¹⁸ 倍触发机箱爆响 + 金币喷泉 + 全场爆闪——"现象级爆金时刻"是推币机的灵魂。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（俯视 2D 推币台）
- **台面**：标准推币机台面（物理单位以"金币直径 D"为基准，约 36D × 20D），四侧为木质挡墙，**前端为落币边缘线**（越过即落袋）；
- **推板（Pusher）**：台面中后部一条金属推板，沿纵向往复（推程/回程），把台面金币推向边缘；推程末端与边缘间留满币区；
- **金币（Coins）**：等质量圆盘刚体——普通金币（基础分 10）、黄金币（×5 分）、宝石币（×10 分）；初始台面铺 3 层金币（确定性种子摆放）；
- **投币口（Insert Slot）**：台面顶部滑轨，玩家从投币口"甩"出金币，落点与力度可调；
- **奖励物（Tokens）**：黄金币/宝石币 + **奖励卡**（跨越即触发 3 秒增益：双倍掉落 / 推板加速 / 磁吸吸附）+ **金塔**（终章堆叠奖励物，推倒即清场大奖）；
- **托盘（Tray）**：边缘下方左右分色托盘（双人夺宝按落点分账），落入即计分结算。

### 3.2 判定与计分规则（核心契约：边缘连锁翻倍 4/4/4/4 → 2¹⁸）
1. **投币**：每关限投币数（如 30 枚）；投币后金币从滑轨落入台面，与台面金币发生弹性碰撞；
2. **推板**：固定周期往复（推程 1.2s / 回程 1.2s），推板接触金币即施力推挤；金币堆叠采用 2D 挤压模型（圆盘互碰 + 台面摩擦），可形成边缘悬垂；
3. **边缘落袋**：任意金币球心越过边缘线即落入托盘——普通币 +10，黄金币 +50，宝石币 +100（落入对应玩家托盘时计入其分账）；
4. **边缘连锁翻倍（用户点名，公式固定）**：
   - 同一次推板波次内，金币连续掉落形成**连锁波**（相邻两次落袋间隔 < 1.5s 视为同一波）；
   - 波内倍率 = **2^(波内已落袋枚数 − 1)**：第 1 枚 ×1、第 2 枚 ×2、第 3 枚 ×4、第 4 枚 ×8……第 m 枚得 `基础分 × 2^(m−1)`；
   - **四档常规档位表（4/4/4/4）**：每累积 4 枚连锁，倍率再升一档（×4 → ×8 → ×16 → ×32），四档后进入**疯狂翻倍**；
   - **极限金卡（2¹⁸）**：单波连锁达到 **18 枚**即封顶 `2^18 = 262144` 倍——该波最后一枚基础 10 分爆出 **2621440 分**，触发**金卡演出**（机箱爆响 + 金币喷泉 + 全场爆闪）；
   - 连锁中断（间隔 ≥ 1.5s 或波次结束）倍率归 1，重新累计；
5. **奖励卡**：金币跨过奖励卡即触发其增益（双倍掉落：本波连锁基础分 ×2；推板加速：推程 +50% 速度 3s；磁吸吸附：台面金币向推板中轴线聚拢 3s）；增益效果确定性种子可测；
6. **胜负与评级（章节挑战制）**：
   - **通关目标**：每关设定目标（达到目标分 / 收集指定奖励卡数 / 推倒金塔清场）；
   - **失败**：投币数耗尽且未达目标 → 本关失败可重试（保留已解锁进度）；
   - **三星评级**：★ 达成目标；★★ 剩余投币 ≥ par；★★★ 本关出现过连锁 ≥ 8 枚（或触达金卡档位）。

### 3.3 模式与内容编排（拒绝套路化三件套）
- **单人章节挑战（Coin Campaign，主打）**：**4 章 × 6 关 = 24 关**，评价体系 = 星级 + 剩余投币 + 最高连锁，绝不做无尽冲分：
  - 第 1 章·新手台：标准推板 + 普通金币，目标分数，学投币落点与推板节拍；
  - 第 2 章·稀有币与奖励卡：黄金币/宝石币登场，目标集卡（奖励卡 N 张），学连锁翻倍抢倍率；
  - 第 3 章·机关台：弹簧弹射器（金币碰触弹射入高空随机落点）、磁吸金块（吸住金币形成大堆），目标分数 + 机关利用；
  - 第 4 章·金塔终章：中央金塔（堆叠奖励物），目标推倒金塔清场，收官演出。
- **同屏双人夺宝（2P Split-Tray Duel）**：同一机台、同一推板，左右分色托盘；玩家轮流投币，落袋金币按落点分账给对应玩家；**先集满 30 分（或夺 3 张奖励卡）者胜**——物理共享、收益分流，攻防一体；
- **经典街机试手（Arcade Try）**：无限投币、纯刷连锁翻倍的练习台（不计入星级），用于体验 2¹⁸ 金卡的爽感。

### 3.4 无死局与公平保证（数学可解性）
1. **物理开放域**：推币台是连续物理空间，不存在"死格"；任何投币落点都有物理响应，金币守恒（台面 + 托盘 + 已落袋总数恒定）；
2. **机关触发可达性**：每关生成后跑**模拟器可达性校验**——断言奖励卡/金塔位于推板推程 + 弹射器（若启用）的物理可达包络内，绝不出现"永远推不到的大奖"；
3. **金卡可达成性**：极限 2¹⁸ 倍不依赖运气堆叠——官方提供"金卡试手台"（机关台 + 磁吸金块聚拢 + 推板加速连发）验证 18 连连锁在最优物理操作下**确定性可复现**（测试断言一局内存在合法操作序列达成连锁 ≥ 18）；
4. **确定性契约**：台面初始摆放、投币抖动、奖励物、机关触发全部走确定性种子；同种子 + 同输入序列逐帧一致，支持自动化验证；物理引擎测试包含 ≥1000 步随机投币游走（状态机不崩、金币数守恒、倍率恒为 2 的幂次且 ≤ 2¹⁸、分数 clamp 无溢出）。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **桌面鼠标（主路径）**：
  - 在投币口滑轨上**按住左键左右拖动 = 选落点**，**向后拖 = 蓄力**（力度条深压），**松手 = 甩出金币**；Input Buffer：松手 60ms 窗口内接受投币指令，连点不吞币；
  - 滚轮 = 微调力度；`R` = 快速重投同落点；点击台面任意位置 = 直接在该列投币（默认力度）；
- **键盘**：`←/→`（或 `A/D`）移动落点瞄准，`↑/↓`（或 `W/S`）增减力度，`空格` = 投币（按住蓄力，松手甩出），`Esc` = 暂停/退回弹层；
- **移动端（触控）**：在投币口下滑 = 选落点 + 蓄力一体（拖得越远力度越大），松手投出；点台面 = 快捷投币；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区，绝不遮挡投币操作区；
- **手感调优**：投币瞬间金币"叮"的入台反馈 + 台面轻微涟漪；推板推程低鸣、回程轻吸声；连锁掉落每枚"叮"音高上行、倍率徽章随波次放大跳动（无边界径向柔光，禁硬边描边圈）；金卡触发慢镜 + 喷泉演出。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词
**复古街机投币机箱（Retro Arcade Cabinet）**、霓虹招牌、玻璃观察窗、金属滑轨、胡桃木机壳、金币喷泉、街机厅暗光微尘。

### 4.2 专属视窗物理隐喻（严禁左右双翼模版）
本作不是"网页里嵌个物理沙盒"，而是一台**真实可感的街机投币机**：

```
+---------------------------------------------------------------------------------------+
|  街机厅暗紫红环境光·悬浮微尘  [🏠] [推币机 COIN PUSHER] [🔊][🌐][❓]                   |
+---------------------------------------------------------------------------------------+
|                                                                                       |
|   ╭──────────────────────────── 霓虹招牌 MARQUEE ────────────────────────────╮        |
|   │   [得分 SCORE]   [连锁倍率 ×N]   [剩余投币 ●●●○]   [金卡 JACKPOT 2¹⁸ 灯] │        |
|   ╰───────────────────────────────────────────────────────────────────────────╯        |
|                                                                                       |
|   投币滑轨 ───────┐        ╭─────────── 玻璃观察窗（物理舞台） ───────────╮        │ 奖品陈列柜 |
|   [投币口 ▾] 力度 ▁▂▃▄     │   [投币滑轨/落点瞄准 ◀◀◀]                    │   (稀有币·奖励卡·金塔)|
|   投币计数灯 ●●○            │   [ 推板 ════ 往复 ]    ●● ●● ●●            │   ┌─────────┐ |

|                            │   ●● ●● ●●                                 │   │ ◆宝石币   │ |

|                            │   [左托盘 P1] [右托盘 P2]                    │   │ ◆金塔    │ |
|                            ╰───────────────────────────────────────────────╯   └─────────┘ |
|   [ 木制操作托盘：投币按钮 · 力度滑杆 · 倍率金卡槽 · 重开 ]  ← 原生机壳控制区                |
+---------------------------------------------------------------------------------------+
```

1. **机箱即全部**：整局游戏是一台街机投币机——顶部霓虹招牌（得分/连锁倍率/金卡灯）、中部玻璃观察窗（Canvas 2D 物理舞台）、左侧投币滑轨与计数灯、右侧奖品陈列柜（**非对称**，展示稀有币/奖励卡/金塔）、底部木制操作托盘（投币/力度/重开），**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **玻璃窗物理舞台**：观察窗内金币、推板、奖励物带真实光影——金属币高光、玻璃反光扫掠、台面木纹；金币堆边缘悬垂处微微颤动，落袋瞬间黄铜袋口闪光；
3. **金卡演出**：触达 2¹⁸ 倍时霓虹招牌爆闪"JACKPOT"、机箱微震、金币喷泉从托盘涌出——现象级爆金时刻；
4. **环境氛围**：街机厅暗紫红环境光 + 微尘粒子 + 霓虹光晕，拒绝死黑/死白大平铺；返回、音效、语言收纳进机箱顶框一体化状态条；
5. **移动端（≤768px）**：机箱压缩为竖持视角，投币滑轨与操作托盘收折为玻璃窗下木质工具条，底部严格预留广告安全避让区，绝不遮挡投币区。

### 4.3 立体质感与渲染路线裁决
- **裁决：纯 Canvas 2D 玻璃窗物理舞台 + DOM/CSS 3D 街机机箱框体**（不做 Three.js）：
  - 观察窗内（金币、推板、奖励物、落袋、喷泉粒子）→ Canvas 2D，120fps 秒开零发热；
  - 机箱立体感（胡桃木厚度、霓虹招牌、玻璃反光、金属滑轨、木托盘）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/记分/弹层全部严格留在 DOM 层；
  - 理由：俯视 2D 推币物理天然是平面空间，无真 3D 视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **投币入台（Coin Insert）** | 金属币落入投币口的清脆"叮——" | FM 金属音 + 噪声瞬态，短促下滑滑音（像币滚入） |
| 2 | **推板往复（Pusher Stroke）** | 机械液压"呼——咔"，推程低鸣回程轻吸 | 低频噪声滤波 + 短促金属咔，响度随推速 |
| 3 | **金币碰撞（Coin Clink）** | 金属币互碰的"哗啦"，密度越高越密 | 多短噪声脉冲串 + 高频金属共振，音量随碰撞密度 |
| 4 | **连锁掉落（Cascade Drop）** | 每枚掉落"叮！"音高随连锁等级上行 | FM 编钟式短音，音阶逐枚爬升（4/4/4/4 档位升调） |
| 5 | **奖励触发（Bonus Token）** | 稀有币/奖励卡"咚啷" | 失谐双振荡器 + 金币琶音，明亮有厚度 |
| 6 | **金卡极限（Jackpot 2¹⁸）** | 机箱爆响——大 Kick + 金币喷泉琶音 + 高频火花 | 失谐双振荡器下潜 Kick + 上行琶音 + 噪声高频扫频 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体，占画面 65%~70%——一枚**3D 软胶金黄大金币**正从街机玻璃窗中弹出，金币上稳稳压着一小摞 2~3 枚小金币，后方隐约露出霓虹招牌光晕与推板剪影；
- **背景与氛围**：暗紫红至深蓝的平滑径向渐变背景 + 霓虹光斑与悬浮微尘，金币软胶质感饱满温润、边缘高光闪亮——一眼传达"投币、推落、爆金"的街机快感。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：模式配比？
- **选项 A（章节挑战 + 双人夺宝双轨 · 推荐）**：单人章节挑战（4 章 × 6 关 = 24 关，机关逐章引入）为主打，同屏双人夺宝为附加，内容量完整、单人与派对两种乐趣都被体验；
- **选项 B（纯章节挑战）**：只做单人章节挑战 24 关，最聚焦，开发量最小；
- **选项 C（章节 + 街机限时）**：章节挑战之外追加"90 秒无限投币连锁狂潮"（街机生存向），刷倍率党的最爱。

### 拍板项 2：机关引入节奏？
- **选项 A（逐章引入 · 推荐）**：稀有币 → 奖励卡 → 弹簧弹射器/磁吸金块 → 金塔终章，每章一个新玩具，学习曲线最顺、内容最有期待感；
- **选项 B（极简基础台）**：只做标准推板 + 稀有币，最贴经典街机推币的克制手感；
- **选项 C（机关全开）**：全部机关同台上线（弹射/磁吸/金塔并存），内容最满、演出最狂。

### 拍板项 3：同屏双人夺宝形态？
- **选项 A（左右分色夺宝 · 推荐）**：同一机台左右分色托盘，轮流投币、落袋分账，先满 30 分（或 3 张奖励卡）者胜——物理共享、收益分流，博弈最足；
- **选项 B（轮流比总分）**：同一托盘，轮流投币、比单局总分，规则最简；
- **选项 C（不做双人）**：纯单人章节，聚焦单人体验。
