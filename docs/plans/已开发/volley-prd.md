## 1 · 创意概念与核心乐趣

- **游戏名称**：双人抛物轰炸 · 隔山打牛 / Volley Bombard / 建议 slug：`volley`（单个简短纯英文单词，符合 slug 极简契约；即“抛物对轰”品类名，无歧义）
- **一句话玩法**：回合制调仰角与蓄力、看风向，隔山炮轰对手的积木堡垒，谁先轰塌对方堡垒谁赢。
- **核心乐趣与卖点**：
- 抛物线预判的“算中了”爽感：仰角、力度、风向三者一合，炮弹划出一道弧线正中目标，比直瞄命中满足十倍；
- 积木堡垒哗啦倒塌的破坏快感：炮弹不只看命中，还看结构破坏——轰掉承重块，整层垮下来，物理反馈拉满；
- 同屏对轰的社交乐趣：一台设备两个人轮流开火，上一秒还在算角度，下一秒就被对方一发入魂，面对面玩才有那味儿；
- “隔山”的地形智慧：中间一座山挡着，直瞄打不到，必须抛物线越过去，地形本身就是谜题的一部分。
- **核心循环**：看风向 ➔ 调仰角蓄力 ➔ 开火 ➔ 看弹道与落点 ➔ 调整参数 ➔ 轰塌堡垒。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
- **Worms（Team17，1995）**：回合制炮术的祖师爷。最受认可的机制是“角度 + 力度双参数瞄准 + 风力每回合变化”——风力 0~10 级，顺风借力、逆风修正，读风本身就是一半的游戏；以及“地形可破坏，炸出的坑就是新掩体”的动态战场。
- **Pocket Tanks（Blitwise，2001）**：一对一炮术的轻量标杆。最受认可的是“10 回合计分 + 角度力度 + 风速/变化三档可调”的干净规则，以及“145 种武器各有明确用途”的武器生态（少而精的反面教材：武器一多，新手反而不知道用哪个）。
- **我们要继承的成熟机制**：
- 角度 + 力度双参数瞄准（状态机清晰，命中与否一目了然）；
- 风力每回合变化，风向风速双指示；
- 抛物线弹道 + 落点反馈（打偏了也能看到落点，下一发好修正）；
- 回合制轮流开火（节奏从容，适合同屏双人）。
- **本作的独特魅力与微创新（Twist）**：
- 平台完全空白的赛道：站内尚无抛物炮术类，角度力度加风力的玩法经过三十年验证；
- “堡垒是积木搭的”：炮弹不只打伤害，更打结构——积木受物理重力影响，轰掉承重块整层垮塌，破坏反馈比单纯扣血直观得多；
- “隔山”地形：中间一座山挡着，直瞄永远打不到，逼玩家练抛物线，地形本身就是关卡设计；
- 武器少而精：只做 6 种，每种有明确用途（石弹、爆裂弹、分裂弹、粘性弹、钻地弹、气球炸弹），拒绝 145 种大杂烩。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：与站内对战类同属大类，但规则模型截然不同——本作是“回合制抛物炮术 + 积木结构破坏”，不是即时格斗、不是棋盘对弈；胜负不靠连招手速，靠弹道预判与结构破坏，坚决杜绝换皮。

## 3 · 玩法规则与交互说明

- **核心规则**：
- **盘面构成**：一张沙盘桌，左右各一座积木堡垒（3 层，每层 4~6 块积木 + 顶部旗帜），中间隔一座山（矮丘 / 高峰 / 双峰三选一）；山顶有风旗，顶栏显示风向风速。
- **玩家合法操作**：轮到自己时调仰角（0~90°）与蓄力（0~100%），选一种武器，开火；每回合限开一炮；炮弹飞行期间不可操作。
- **胜利条件与失败条件**：对方堡垒旗帜倒地，或全部积木倒塌，即获胜；10 回合无人倒塌，按双方剩余积木数判胜（多者胜，平局算和棋可重开）。
- **容错与无死局说明**：本作无随机关卡死局问题——地形与堡垒布局由设计表固定 + 随机种子微调，风力只影响弹道不影响可胜性；双方武器相同，无运气碾压；打偏的炮弹会炸出弹坑，不会卡死局势。
- **武器（初版 6 种，开发时可微调）**：石弹（标准伤害 20）、爆裂弹（范围伤害 15，波及相邻块）、分裂弹（空中裂成 3 枚小弹，各 8 点）、粘性弹（粘住 2 秒后爆炸，可粘山体反弹）、钻地弹（穿透一层积木再爆）、气球炸弹（慢速飘浮，可越过高山）。
- **数值（初版建议，开发时可微调）**：每块积木耐久 20；旗帜耐久 10（倒地即败）；风力每回合随机 -5~+5；重力恒定；AI 三档：新手（角度误差 ±8°）、进阶（±4°）、大师（±1°，且会针对承重块）。
- **操作与手感**：
- 鼠标拖动调仰角，拉动蓄力条或按住空格蓄力，松开发射；键盘 ↑↓ 调角，←→ 微调力度，Space 蓄力发射，数字键 1~6 选武器；P / Esc 暂停；
- 开火有 0.5 秒炮口火光 + 炮弹呼啸，命中积木有碎裂粒子 + 闷响，整层倒塌有连续哗啦声；弹道用虚线轨迹预演（仅显示无风轨迹，风偏靠玩家自己算）；
- 误触容错：蓄力中松开鼠标即取消（不发射）；发射前可无限次调整角度与力度。
- **随时可暂停与失焦保护机制**：本作是回合制静态对轰，无倒计时压力，但 AI 回合有思考与开火动画——顶栏常驻醒目的「暂停 / 继续」按钮与 P / Esc / 空格快捷键，暂停时冻结 AI 回合与一切动画并显示轻量半透明遮罩（继续 / 重新开始）；切标签页或最小化时自动静默暂停，回来后局势原样不动。
- **即开即玩与平滑选关设计**：初次打开直接进入同屏双人第 1 局（矮丘地形），双方堡垒与山体直接就绪，无需前置点击；顶栏常驻醒目的「模式」按钮，点击以轻量抽屉展示模式与山形；结算面板提供「再来一局」与「换模式」。
- **模式与内容编排（依玩法特质定制，不套无尽冲分）**：
- **同屏双人（默认）**：两人轮流开火，一台设备面对面玩，10 回合定胜负；
- **单人挑战 AI**：新手 / 进阶 / 大师三档，AI 按固定公式算角 + 难度误差，打满 10 回合按剩余积木判胜；
- **自定义山体**：矮丘（易越过）、高峰（须大仰角）、双峰（须算两次抛物线）三选一；
- **武器轮换**：每局开始前双方各选 3 种武器带入战场（6 选 3），增加开局策略。
- **游戏目标与反馈体系**：核心指标不是总分，而是**命中率**与**最高单发伤害**；胜利结算播放“对方堡垒哗啦倒塌”的全景动画，败方旗帜缓缓倒下。
- **双语核心词汇与数据键名规划**：
- 模式：同屏双人 Local 2P / 单人挑战 AI Challenge / 自定义山体 Terrain Select；
- 实体：堡垒 Fortress / 积木 Block / 旗帜 Flag / 风力 Wind / 石弹 Stone Shell / 爆裂弹 Blast Shell / 分裂弹 Split Shell / 粘性弹 Sticky Shell / 钻地弹 Drill Shell / 气球炸弹 Balloon Bomb；
- 数据层约束：所有地形、武器、AI 难度数据一律用字符串 key 或 id（如 `terrain_hill`、`weapon_blast`、`ai_master`），展示层通过 `i18n` 获取文本，严禁在数据文件里裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：沙盘、积木、隔山、风旗、对轰。
- **专属视窗物理隐喻**：**“两座积木堡垒隔山对峙的沙盘”**——整个界面就是一张沙盘桌：中间一座小山，山顶风旗飘动方向即风向；两边积木堡垒像沙盘模型一样立着，炮弹划出的抛物线是沙盘上的一道弧。拒绝左右双翼三栏套路，沙盘居中、信息压在上下两条。
- **立体质感与渲染路线裁决**：纯 DOM + CSS 3D 为主（积木块用 CSS 3D，倒塌用 CSS 位移 + 旋转动画；山体用 CSS 渐变堆叠），Canvas 2D 只做弹道轨迹线与爆炸粒子。**不采用 Three.js**——抛物线是 2D 平面弹道，无真三维空间翻转需求，CSS 3D 已足够且秒开零发热。
- **声效风格与材质音色规划（4~6 种，拒绝单音蜂鸣器）**：
- 蓄力拉弦：绷紧的弦音（FM 合成上行）；
- 开炮轰鸣：低频炮声（失谐多振荡器 + 噪声）；
- 炮弹呼啸：风声扫频（物理噪声滤波）；
- 积木倒塌：哗啦连响（多块木质碰撞叠奏）；
- 命中闷响：短促低鸣；
- 胜利号角：小号上行（FM 合成）。
- **封面设计提案**：3D 软胶质感、单一居中主体（一座积木堡垒 + 一枚抛物线炮弹，占 60~75%，无文字）、鲜艳渐变背景（沙盘黄到天空蓝）。

## 6 · 制作人拍板与开放探讨

1. **堡垒结构：固定 3 层 vs 赛前自搭**——方案 A：固定 3 层（上手快，对轰公平，开局即打）；方案 B：赛前自搭（策略深，但拖时间、新手容易搭出必败局）。推荐 A，自搭作后续模式。
2. **武器：6 种少而精 vs 12 种大杂烩**——方案 A：6 种（每种有明确用途，新手记得住）；方案 B：12 种（选择多，但容易沦为数值堆砌）。推荐 A。
3. **AI：3 档难度 vs 只有 1 档**——方案 A：3 档（新手练手、进阶热身、大师挑战）；方案 B：1 档。推荐 A。
