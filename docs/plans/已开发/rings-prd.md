## 1 · 创意概念与核心乐趣

- **游戏名称**：古代九连环·连环相扣 / Nine Rings Puzzle / 建议 slug：`rings`（单个简短纯英文单词，符合极简命名契约）
- **一句话玩法**：按口诀上下环解开九连环
- **核心乐趣与卖点**：
  - **口诀解扣的顿悟感**：九连环的魅力不在手速，而在“上环、下环”口诀背后的递归逻辑——第一环可随意上下、第二环需第一环在上、其余环需前一环在上且再前一环在下。玩家从乱点乱试到突然悟出规律、手指开始行云流水连环解扣，那一刻的成就感极强。
  - **文化情怀与手感冥想**：铜环叮当、木柄温润，解环过程本身像指尖冥想；解开全部九环的仪式感（剑形柄完全抽出）适合截图留存。
  - **步数最优挑战**：标准最优解 341 步（9 环全解），玩家可挑战最少步数与最短用时，天然适合重复挑战与传播战绩。
- **核心循环**：观察环位状态 ➔ 按口诀判断当前可动环 ➔ 上/下环操作 ➔ 环位变化反馈 ➔ 逐步解开/装回 ➔ 通关结算与步数评级 ➔ 挑战更少步数。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **传统九连环（中国古代益智玩具，宋明以降流传）**：九个铜环套在剑形柄上，按口诀上下环最终将柄抽出。最受认可的是其蕴含的递归与格雷码逻辑，以及“解环/装环”双向可玩。
  - **格雷码解环（Binary/Gray Code 数学模型）**：九连环状态可映射为二进制/格雷码序列，最优解路径唯一确定，是经典的算法启蒙题。成熟的 web 解环模拟器多提供步数计数与提示。
- **我们要继承的成熟机制**：
  - 严格的合法环判定：1 号环任意时刻可上/下；2 号环当且仅当 1 号环在上时可动；n 号环（n≥3）当且仅当 n-1 号环在上且 n-2 号环在下时可动；
  - 上环/下环双向操作与动画（环沿柄滑动、绕过柄头）；
  - 步数计数、用时计时、撤销一步、重置；
  - 提示系统：高亮当前所有可动环（新手友好），进阶可关闭提示自测。
- **本作的独特魅力与微创新（Twist）**：
  - **2D 环扣序列逻辑可视化**：把实物九连环的 3D 套环抽象为清晰的 2D 环位序列（每环“在上/在下”二态），配口诀面板与状态条，让玩家看懂“为什么这个环动不了”，降低实物玩具的上手门槛，又保留逻辑内核。
  - **分级环数关卡**：从 3 环入门、5 环进阶、7 环挑战到 9 环完全体，逐级引入递归深度，而非一上来就 341 步劝退；
  - **解环与装环双模式**：既可“解开九连环”（全上→全下抽柄），也可“装回九连环”（全下→全上），同一套逻辑双向练。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：
  - 与站内 **`luban`（巧解鲁班锁·榫卯拆解，序号 4）** 的差异：`luban` 是 3D 空间榫卯抽动、靠空间想象与视角旋转拆解木块；本作是 **2D 环扣序列逻辑**，无空间旋转、无木块抽拉，核心是二态序列与递归口诀，心流完全不同（空间 vs 序列）。
  - 与站内 **`klotski`（华容道，序号 46）** 的差异：`klotski` 是滑块在棋盘空格中平移、靠布局腾挪救曹操；本作无棋盘、无滑块平移，每环只有上/下二态与严格前置条件，解法是唯一递归序列而非布局搜索。
  - 与站内 `cube`（魔方）差异：魔方是 3D 面旋转还原颜色，本作无颜色还原、无面旋转。
  - 结论：与 100 款底表比对，无规则几乎一模一样的存量游戏；同属“中国传统益智”大类但机制模型截然不同，符合 Twist 立项口径。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - **盘面/场景构成**：一根剑形柄（横向或纵向）上依次套着 N 个环（关卡决定 N=3/5/7/9），每环状态为“在上（套在柄上）/在下（已解下）”；旁置口诀面板与状态条（每环一个指示灯）。
  - **玩家合法操作**：点击某个环执行上环或下环（方向由该环当前状态决定：已在下则上环、已在上则下环）；仅当该环满足前置条件时操作合法——1 号环恒合法；2 号环需 1 号环在上；n 号环（n≥3）需 n-1 号环在上且 n-2 号环在下。不合法点击只给出抖动提示与原因文案（如“需先上第 3 环”），不改变状态、不计步。
  - **胜利条件与失败条件**：解环模式下全部环解下（柄可抽出）即胜；装环模式下全部环装上即胜。本作是纯逻辑解谜，**无失败条件**（无时间惩罚、无步数上限淘汰），步数与用时只作评级。
  - **容错与无死局说明（100% 可解保证）**：九连环状态图是连通的——任意合法状态均可按标准解法序列（格雷码递归）到达全解/全装，**不存在死局**；关卡初始状态均取自标准解法路径上的合法状态（如从全上状态按最优解走 k 步得到的中途残局），保证有解且解法步数可预知。提供“撤销一步”与“重置关卡”，误操作可完全回退。
- **操作与手感**：
  - **鼠标/触控**：点击环即可上/下环，环沿柄滑动动画约 220ms；支持连续快速点击不同环（动画可打断排队，状态判定以逻辑为准）；
  - **键盘快捷键**：数字键 1–9 直接操作对应环；`Z` 撤销、`R` 重置、`H` 开关提示高亮；
  - **随时可暂停与失焦保护机制**：本作是**纯静态无时间压力的逻辑解谜**，天然静止，**无需强制常驻暂停按钮**；但带用时计时器时，呼出选关/模式菜单须**冻结计时**，关闭菜单后恢复；切标签页/失焦时计时同样自动冻结（监听 `visibilitychange`），回来不跳秒。菜单覆盖层为轻量非阻塞抽屉，不遮挡环位状态条。
  - **误触容错与操作缓冲**：非法环点击不计步只提示；连点同一环按状态机串行处理，防动画竞态导致状态错乱。
- **即开即玩与平滑选关设计（Instant Play，核心体验）**：
  - **首屏秒进对局**：打开直接呈现第 1 关（3 环入门、全上初始态）就绪盘面，环可立即点击，**严禁全屏选关遮罩**；
  - **常驻显眼选关入口**：顶栏常驻「选关」/「模式」按钮，点击以轻量抽屉展示环数关卡（3/5/7/9 环）与模式（解环/装环）；结算面板提供「下一关」与「选关」；
  - 记忆本地进度（已通关环数与最佳步数），下次打开直接续上次关卡。
- **模式与内容编排（严禁套路化，依游戏特质定制）**：
  - **章节关卡制**：按环数分四章（3 环入门、5 环进阶、7 环挑战、9 环完全体），每章含全解关 + 2–3 个中途残局关（从标准解路径取点）；
  - **双模式**：解环模式（全上→全下）与装环模式（全下→全上）；
  - **提示分级**：新手提示开（高亮可动环）、进阶提示关（自测口诀）；
  - **严禁无脑套用“无尽冲分 + 每日挑战”**：本作以环数递进与步数最优为核心，不设无尽与每日。
- **游戏目标与反馈体系**：
  - 核心指标：步数（与最优步数对比）、用时、撤销次数；每关三星评级（通关 1 星、步数 ≤ 最优×1.5 得 2 星、步数 = 最优得 3 星）；
  - 胜利反馈：最后一环解下时剑形柄缓缓抽出 + 铜环齐鸣，结算展示步数与最优对比。
- **双语核心词汇与数据键名规划（防英文界面夹杂中文）**：
  - 模式名：解环模式 Unlink Mode / 装环模式 Link Mode；
  - 关卡名：第 1 关·三环入门 Level 1: Three Rings / 五环进阶 Five Rings / 七环挑战 Seven Rings / 九环完全体 Nine Rings（数据 key 如 `level_3rings`、`level_9rings`）；
  - 核心词：上环 Link Up / 下环 Unlink / 步数 Moves / 最优步数 Optimal Moves / 提示 Hint / 撤销 Undo；
  - 口诀文案走 i18n key（如 `rule_ring1`、`rule_ring_n`），数据层只存环数与初始状态数组（如 `rings: [1,1,1]`），严禁裸写中文；语言切换原地热更新，严禁 `location.reload()`。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：铜环木柄、书房案几、宣纸口诀、指尖冥想、国风极简。
- **专属视窗物理隐喻（严禁连环参考老项目，拒绝左右双翼套路）**：
  - 视窗形态：**书房案几上的一套九连环实物**——主舞台是一张深色木质案几俯视图，剑形柄横置中央、铜环依次套挂，柄下是一张摊开的宣纸（口诀与状态条写在宣纸上），顶栏是案几边缘的计步木牌。布局为上下结构（案几盘面 + 宣纸口诀区），不做左右双翼卡片。
  - 严禁照搬三栏套路，严禁四角散落浮动按钮，严禁右侧堆叠 SaaS 表单卡片；保持全站沉浸暗色底蕴，铜环用暖金高光、宣纸用米白形成题材反差。
- **立体质感与渲染路线裁决**：
  - 裁决：**DOM + CSS 3D**（95% 优先路线）。铜环用 CSS 3D 透视 + 渐变高光做出金属圆环立体感，环沿柄滑动用 transform 动画；无真三维空间旋转需求（与 `luban` 的 3D 榫卯明确区分，本作刻意走 2D 序列呈现）。
  - 不采用 Three.js；若后续确需 3D 实物视角，必须守三条红线（零外部 3D 模型纯代码生成几何体、轻量低开销着色防发烫、所有 UI/HUD 严格在 DOM 层隔离）。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：规划 5 种专属材质音效——
  1. 上环：铜环滑过木柄的轻摩擦 + 落位“叮”声（FM 金属合成）；
  2. 下环：铜环脱柄的清脆“当”声（失谐金属振荡）；
  3. 非法操作：木柄轻敲的闷响（低频噪声滤波）；
  4. 撤销/重置：纸张翻动的沙沙声（噪声高通滤波）；
  5. 通关抽柄：九环齐鸣的编钟和弦 + 木柄抽出的长摩擦声。
  - 拒绝单振荡器 beep 与 C-E-G-C 琶音。
- **封面设计提案**：640×640 软胶质感，单一居中主体（一套铜色九连环套在剑形柄上），占画面 60–75%、无文字，深木色渐变背景带暖金光晕。

## 6 · 制作人拍板与开放探讨

列出 3 个选项，供制作人（用户）快速拍板决断：
1. **选项一（提示默认）**：新手关默认高亮可动环（方案 A，上手友好） vs 全程无提示、靠口诀面板自悟（方案 B，更硬核原汁原味）。
2. **选项二（关卡编排）**：3/5/7/9 环四章 + 中途残局关（方案 A，内容饱满） vs 只做 9 环完全体单关 + 步数挑战（方案 B，首版极简、直奔经典）。
3. **选项三（柄的方向）**：剑形柄横置、环左右滑动（方案 A，横屏友好） vs 纵置、环上下滑动（方案 B，更贴实物手持感、竖屏友好）。
