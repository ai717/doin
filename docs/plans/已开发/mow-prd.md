## 1 · 创意概念与核心乐趣

- **游戏名称**：割草！ / Mow! / 建议 slug：`mow`
- **一句话玩法**：操控一台软胶小割草机，在花田里自动旋转刀片收割虫潮——边躲边走位、升级三选一构筑流派，8 分钟内杀穿虫潮、迎战园丁巨人。
- **核心乐趣与卖点**：
  - **割草即战斗的物理化快感（Mow = Kill）**：这是把"幸存者割草"品类的比喻**做成字面**的一次设计。击杀不是"敌人消失"，而是真的**割**——虫潮被刀盘卷进草屑与花瓣的迸溅里，"唰唰"刀声 + "噼啪"收割声 + 满地花蜜光点，把品类最强的解压爽感放到最大。玩家视角里：我不是在躲怪，我是在**收割一座会涌动的花园**；
  - **一杯茶时间的一局肉鸽（8-Minute Roguelite）**：Vampire Survivors 的一局 30 分钟对网页碎片场景太奢侈。本作把整条节奏曲线**压缩进 8 分钟**：2 分钟上手、4 分钟成型、6 分钟满屏虫潮、7:30 园丁巨人 Boss 终局——每一局都有明确开始与漂亮收尾，与移动端割草爆款"约十分钟一局"的碎片化趋势同频；
  - **三选一构筑的密集滚雪球（Dense Build Drafting）**：每 25~30 秒一次升级三选一，一局约 15~18 次抉择；武器 + 被动 + **进化合成**（刀盘 × 钢制刀盘 → 黄金割草盘）层层叠加。构筑感密集到"每一局都在赶一场小拍卖会"，8 分钟内能完整体验从"割草小车"到"花田风暴"的成长弧线；
  - **走位即操作的全部（Movement-Only Mastery）**：自动攻击扛下全部瞄准负担，玩家唯一的操作就是走位——绕圈聚怪、贴边风筝、卡住花蜜光点扫过、在虫潮缝隙里钻出逃生走廊。上限全在脚下，深度全在"往哪走、停在哪"；
  - **割草连击 → 花粉爆发（Mow Streak → Overbloom）**：连续收割（间隔 < 0.9s）累积"割草槽"，满槽手动引爆**全屏花粉爆发**（清场 AOE + 短暂得分倍率）。把被动收割变成主动节奏决策——是憋着等虫潮聚满再爆，还是遇险立刻脱身，玩家自己说了算；
  - **数学公平的生存承诺（Fair-by-Design Survival）**：怪永远从视野外出生、被彻底围死时自动触发免费脱困、Boss 战前清场补给——**死亡永远是操作失误，绝不可能是运气**。这是对"割草肉鸽"最容易被骂的"被围必死"的正面回应。
- **核心循环**：
  ```
  走位引怪聚堆 ➔ 自动武器收割（连击涨割草槽） ➔ 拾取花蜜升级 ➔ 三选一构筑 / 进化合成
        ↑                                                          ↓
  更强更密的收割 ◄ 花粉爆发清屏 ◄ 割草槽满 ◄ 继续引怪、走位、收割
        ↓
  倒计时 7:30 清场补给 → 园丁巨人 Boss（3 阶段）→ 击破通关评级（星级 / 击杀 / 连击）
  ```

## 2 · 经典标杆与对标参考

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Vampire Survivors（Luca Galante 2022）** | PC/移动 | 全武器自动索敌开火，玩家仅操控移动；击杀掉落经验宝石，拾取升级，每次升级三选一（新武器/被动/强化）；主武器满 8 级 + 匹配被动 + 开宝箱 = **进化超武**；一局 30 分钟 | 品类开创者，把"自动攻击 + 移动走位 + 构筑滚雪球"做成了教科书；进化的力量飙升是最大高光时刻 | 自动索敌武器模型、经验宝石 + 三选一、武器 × 被动进化合成、6 武器槽上限 | 30 分钟单局过长、后期数值溢出后失去目标（本作 8 分钟 + Boss 终局收口） |
| **Brotato（2022）** | PC/移动/网页 | 土豆拿 6 把武器自动开火；波次制每波 20~90 秒；局间商店用材料买武器/属性；40+ 差异化角色 | 短波次节奏干净利落；角色差异化开局极大拉长重玩寿命 | 6 武器槽位、差异化角色开局（割草机/花洒/瓢虫）、短局节奏 | 局间商店打断战斗心流（本作全程连续时间轴，不做商店暂停） |
| **弹壳特攻队 Survivor.io（2022）** | 移动 | 竖屏单手虚拟摇杆走位 + 全自动攻击；升级三选一技能；同武器叠加合成"超武"；每局约 10 分钟 | 验证了"短局 + 单手自动攻击"在碎片时间的巨大需求，割草手感爽快 | 单手摇杆 + 自动攻击的极简操作、约 10 分钟短局时长、技能合成超武 | 局外装备养成的长线数值深坑（本作纯单局肉鸽，图鉴解锁只扩池不增强） |
| **20 Minutes Till Dawn（2023）** | PC | 限时生存 + 明确终局；build 成型后迎战收尾 | "跑完一局有交代"的倒计时终局设计 | 明确倒计时 + Boss 终局的"一局完整性" | 手动瞄准的瞄准负担（本作全自动） |

**我们要继承的成熟机制**：
1. **自动索敌武器（VS 成熟模型）**：每把武器独立冷却与索敌规则（环绕、扇形、追踪、区域、使魔），玩家零瞄准负担，操作注意力 100% 留给走位；
2. **经验宝石 → 升级三选一（VS）**：击杀掉落"花蜜"光点，花蜜自动被磁性吸引（拾取范围可升级）；升级条满 → **游戏暂停**弹出三选一（暂停选择在网页端是必须的容错，绝不手忙脚乱）；
3. **武器进化合成（VS 精髓）**：主武器满级 + 对应被动到手 → 下一次拾取"进化宝箱"（精英/Boss 掉落）直接进化为超武，伤害与形态质变，是 8 分钟里 1~2 次的最高光时刻；
4. **差异化角色开局（Brotato）**：不同初始武器与属性面板，决定每局节奏走向；
5. **固定步长物理 + 种子 PRNG**：战斗推进走纯函数固定步长，敌人出生、掉落、升级池均由可注入种子决定，可回放、可单测（平台铁律）。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **割草连击 → 花粉爆发（Mow Streak → Overbloom）**：连杀涨"割草槽"，满槽手动引爆全屏花粉爆发 + 得分倍率窗口。被动收割第一次获得**主动节奏决策权**——憋大招还是保命，玩家自己权衡；
2. **8 分钟压缩时间轴（The 8-Minute Arc）**：经验曲线、怪潮密度、进化时机全部按 8 分钟标定，并埋 4 个"节奏检查点"（2:00 首把武器满级前 / 4:00 首次进化窗口 / 6:00 强度峰值 / 7:30 Boss 登场），保证每局都是"完整的迷你弧线"；
3. **数学公平的生存承诺（Fair-by-Design）**：怪从视野外环带出生（绝不贴脸刷怪）、每 2s 逃生走廊校验（被 360° 围死时自动免费花粉脱困 + 1.5s 无敌）、Boss 战前清场满血——把"无死局保证"从解谜类游戏扩展到动作生存类；
4. **花田生态叙事（Garden Ecosystem）**：敌人不是抽象怪，而是一套花园害虫生态（毛毛虫 / 甲虫 / 野蜂 / 毒蘑菇 / 荆棘团），Boss 是"被虫潮惹怒的园丁巨人"——题材与机制咬合，割草有世界观可讲。

## 3 · 玩法规则与交互说明

### 3.1 场景构成与元素
- **花田竞技场（Meadow Arena）**：有限方形场地（逻辑坐标 1280 × 720），四周一圈软胶花篱为边界（可见、可读、杜绝无限地图迷失感），场地内散布静态花丛与喷泉装饰（纯视觉层）；
- **玩家（割草机 Mower）**：一台软胶小割草机，8 方向自由移动，受击判定为机身中心半径 14px 的圆（视觉约 24px，判定宽容偏向玩家）；
- **敌人生态（Pests）**：
  - **毛毛虫 Caterpillar**：慢速直冲，最基础的虫海主力；
  - **甲虫 Beetle**：中速，数量大，喜欢扎堆（聚怪收割的诱饵）；
  - **野蜂 Wasp**：快速小体积，绕行包抄侧翼，考验走位精度；
  - **毒蘑菇 Toadstool**：慢速厚血，死亡后原地爆炸溅射一圈毒液（需要拉开收割距离）；
  - **荆棘团 Thornball**：弹性冲撞、路径不可预判，中后期干扰走位节奏；
  - **精英·巨型甲虫 Elite Beetle**：血厚、体型大，击杀必掉**进化宝箱**（词缀随机：厚皮 / 加速光环 / 召唤幼虫）；
  - **Boss·园丁巨人 The Gardener**：7:30 登场，三阶段（① 洒水壶扇形弹幕 → ② 召唤虫群 → ③ 践踏冲锋 + 全屏水雾），击破即通关；
- **掉落物**：花蜜（经验光点，自动磁性吸引）、玫瑰花（回血）、四叶草（短暂幸运/得分）、进化宝箱（触发武器进化）。

### 3.2 判定与胜负规则
1. **胜利条件**：撑过 8:00 倒计时 → 击破园丁巨人 → 通关结算；
2. **失败条件**：生命值归零 → 本局失败，立即结算（保留已达成星级与图鉴收集，随时可再开一局）；
3. **伤害规则**：敌人触碰玩家即造成接触伤害（基础怪 1 点，精英 2 点，Boss 3 点），受击后玩家 0.8s 无敌闪烁（不叠乘）；血条上限可由被动"陶瓷花盆"提升；
4. **升级三选一**：花蜜经验条满 → 游戏暂停 → 从当前武器/被动池随机 3 项中选择 1 项（新武器、已有武器 +1 级、新被动、已有被动 +1 级）；**同一项被重复抽到时升级价值自动+20%**（防废签）；已满级/已持有满的项不出现在候选池；
5. **进化合成**：主武器满级 + 对应被动至少 1 级 → 拾取进化宝箱 → 武器进化为超武（形态质变，占用同槽位）；
6. **割草槽（Mow Meter）**：击杀间隔 < 0.9s 视为连杀，连杀涨槽（基础怪 1 格 / 精英 5 格 / Boss 20 格）；槽满后可手动引爆（见 3.3）；
7. **无死局保证（硬性，测试必覆盖）**：
   - 怪物出生一律在玩家视野外环带（距玩家 ≥ 480 逻辑像素或竞技场边缘），出生后 0.5s 淡入且不造成伤害；
   - 每 2s 执行"逃生走廊校验"：玩家 8 方向中至少存在 1 个 120° 锥形区域无敌方单位占据；若全部被围 → 自动触发一次免费"花粉应急爆发"（清空玩家周围 300px 半径全部敌人）+ 1.5s 无敌；
   - Boss 战前（7:30）全屏清场 + 玩家满血补给，杜绝"残血进 Boss 必死"；
   - 结论：玩家死亡只可能是走位失误，绝不可能是刷怪运气。

### 3.3 手感调优与操作映射（键鼠触全通）
- **移动**：桌面 `WASD / 方向键` 8 方向移动（带 0.1s 加减速惯性曲线，绝非瞬移；移动端虚拟摇杆，摇杆回中即停）；
- **花粉爆发**：桌面 `空格 / Shift`；移动端右下角实体**花粉键**（可按住蓄力 0.4s 放大爆发范围 30%，松手引爆——给高手一个操作深度）；
- **升级三选一**：桌面 `1/2/3` 或鼠标点选；移动端直接点选卡片（选择期间游戏已暂停，零时间压力）；
- **操作缓冲（Input Buffering）**：花粉爆发在冷却结束前 0.15s 内按下会被缓存、冷却结束立即引爆；暂停/结算面板关闭后移动输入自动恢复，绝不吞输入；
- **容错**：受击 0.8s 无敌 + 屏幕边缘柔光提示"危险方向"（径向柔光，非描边）；Boss 登场前 2s 全局慢镜预警。

### 3.4 模式编排（为生存肉鸽量身定制，拒绝千篇一律）
1. **标准一局（Standard Run · 核心模式）**：
   - 8 分钟倒计时生存 + 最终 Boss 的完整一局弧线；节奏检查点：2:00 首把武器应接近满级、4:00 首次进化窗口、6:00 强度峰值、7:30 Boss 登场；
   - 4 名角色差异化开局：**割草机**（均衡，初始旋转刀片）/ **花洒**（高射速低伤，初始花粉喷射）/ **瓢虫**（高移速低血，初始弹跳豆荚）/ **圆锯兔**（解锁角色，近战爆发，初始地刺藤蔓 + 高伤害低攻速）；
   - 评价：单局结算星级（1~3 星：击破 Boss 且达成击杀/连击阈值）、花园图鉴收集进度。
2. **无尽深渊（Endless Pit · 通关后解锁）**：
   - 无倒计时，怪潮强度随时间持续爬升，记录最高存活时间与击杀数；作为标准一局之外的街机补充（**不是主轴**）。
3. **花园图鉴（Gardener's Codex · 收集系统）**：
   - 角色 / 武器 / 被动 / 进化配方全收集进度；**只扩池、不增强**——图鉴解锁新角色与新武器池选项，绝不做局外数值养成（杜绝弹壳式深坑）。

> 说明：每日种子挑战（日期种子同题比击杀）列为可选拍板项（见第 5 章），默认不进首版。

### 3.5 反馈体系与评价
- **核心指标**：单局星级（1~3 星）、总击杀数、最高连击、割草槽引爆次数、通关用时、图鉴收集率；
- **割草连击（Mow Streak）**：连杀每 +5 级，HUD 计数器 bump 跳动 + 音高升半音；连击峰值计入结算评级；
- **结算仪式感**：Boss 击破触发慢镜"花粉风暴"（时间流速 0.35× 持续 0.8s）→ 全屏花瓣旋涡 → 战报卷轴展开（击杀/连击/引爆数/用时）→ 星级逐颗点亮（阶梯 delay）→ 图鉴新条目"叮"一声点亮。

## 4 · 美术风格与视觉氛围

- **风格关键词**：**糖果花园软胶**、**奶油色草地**、**花粉粒子风暴**、**玩具割草机**；
- 主色调：草地奶油绿 → 花粉明黄 → 玫瑰珊瑚红强对比；远景柔焦花丛 + 漂浮花瓣 + 缓慢流动的光斑，虫潮用高饱和的"害虫配色"（甲虫墨绿、野蜂琥珀、毒蘑菇紫斑）与玩家机身的奶白色拉开明暗对比。

### 4.3 音效规划（WebAudio 纯程序化合成，零外部音频文件）
- **刀盘旋转**：持续低频"嗡嗡"刀片声，转速随武器等级升高音调微升；
- **收割**：短促"唰-噼"双段音（草屑撕裂 + 甲壳脆裂），音高随连击逐级上升；
- **花蜜拾取**：清脆上扬短铃（Ping），批量吸收时形成琶音；
- **升级三选一**：翻牌"咔嗒"声 + 选定后的上扬和弦；
- **进化**：低沉轰鸣 + 号角式上行琶音 + 屏幕闪光音；
- **花粉爆发**：低频轰鸣 + 全屏"呼——"席卷声，结束时一声释放音；
- **Boss 登场**：低音鼓点 + 草地震颤嗡鸣，三阶段切换各有主题动机。

### 4.4 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体占画面 65%~70%——一台**温润饱满的软胶质感奶白小割草机**（草绿机身 + 橙色旋转刀盘 + 开心圆眼睛），刀盘四周溅起的花瓣与草屑残影，机顶落着一只小瓢虫；
- **背景与氛围**：草地奶油绿至花粉明黄的平滑径向渐变，点缀虚焦的花丛光斑与飘浮花瓣，光感通透、质感软糯。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 项核心设计进行拍板定夺：

### 拍板项 1：题材路线走哪条？
- **选项 A（花园割草机 · 推荐）**：把"割草"做成字面意义——软胶小割草机收割花田虫潮，可爱软萌 + 品类双关，完美贴合 DOIN 门户的玩具美学与 3D 软胶封面规范；
- **选项 B（暗黑末世幸存者）**：贴近 Vampire Survivors / 弹壳特攻队的阴郁末世氛围，暗色霓虹 + 血腥感，受众更"硬核"，但与门户软胶画风适配度较低。

### 拍板项 2：模式主轴如何编排？
- **选项 A（标准一局 + 无尽深渊 · 推荐）**：8 分钟标准一局为绝对主轴（完整弧线 + Boss 终局 + 星级评价），通关解锁无尽深渊作为补充——最聚焦、最契合"一杯茶一局"的定位；
- **选项 B（加入每日种子挑战）**：在 A 基础上追加"每日种子"模式（日期做种子、同天同题比击杀数），利用肉鸽种子机制做轻量社交竞技；
- **选项 C（纯无尽冲分）**：只做无尽模式与本地击杀榜，一局制 Boss 战役砍掉——不推荐，会丢掉"跑完有交代"的终局爽感。

### 拍板项 3：进化系统深度如何取舍？
- **选项 A（武器 × 被动进化合成 · 推荐）**：保留 VS 精髓——主武器满级 + 匹配被动 → 进化超武，8 分钟内制造 1~2 次质变高光，构筑目标感极强；
- **选项 B（无进化、纯叠加）**：只做武器/被动等级叠加，无合成质变——更轻更简单，但失去肉鸽最上头的"配方期待"。
