## 1 · 创意概念与核心乐趣

- **游戏名称**：魔方工坊 / Cube / 建议 slug：`cube`（备选 `rubik`）
- **一句话玩法**：单指或鼠标在 3D 空间丝滑翻转并滑动旋转面层，挑战二阶极速还原与三阶每日竞速，重温世界第一智力玩具的纯粹心流！
- **核心乐趣与卖点**：
  - **平台唯一真三维品类，合规准入的 3D 视觉突破（The Exclusive True-3D Masterpiece）**：
    精准契合 `AGENTS.md` 5.2 节中极少数（<5%）真 3D 准入窗口——“对于天然依赖真三维立体空间变换（如魔方翻转）允许引入轻量 Three.js”。为 DOIN 平台填补三维立体空间解谜的绝对空白；
  - **磁吸顺滑的拟真机械速拧手感（Magnetic Speedcubing Feel）**：
    彻底告别网页 3D 魔方常见的“卡顿、转错层、判定粘滞”。本作采用高精度空间射线拾取与切向速度投影，无论从哪个角度滑动，都能在 15 毫秒内精准识别目标旋转层，并带有 90 度机械磁吸回弹（Magnetic Snapping）与清脆卡扣音效；
  - **二阶破冰 + 三阶竞速的双轨梯度（2×2 Pocket & 3×3 Classic）**：
    先做 2×2 二阶口袋魔方（仅 8 个角块，打乱仅需 8~12 步，1 分钟即可通关），彻底打消普通玩家对魔方的畏难情绪；在此基础上开放国际 WCA 标准的 3×3 经典三阶与每日固定种子竞速挑战；
  - **100% 确定性求解器与每日同题竞技（Guaranteed Solvable & Daily Seed）**：
    所有打乱序列严格从还原态出发进行合法反向旋转生成，拒绝死局。结合毫秒级 WCA 竞速计时器（观察期 ➔ 极速还原 ➔ 自动停表），全球玩家同题比拼用时与最少步数（FMC）。
- **核心循环**：
  ```
  观察当前打乱魔方的六面色块布局 (整体空间自由旋转视角)
       ↑                                                      ↓
  通关狂喜 / 刷新个人最快纪录 ← 最后一层咔哒对齐，六面完全归色 ← 手指/光标在魔方表面滑动，带动面层 90° 旋转
       ↓ (卡壳或遗忘公式)
  一键查阅【魔方学院】层先法口诀秘籍 / 开启智能单步提示求解
  ```

## 2 · 经典标杆与对标参考

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴要素 | 避开要素 |
|---|---|---|---|---|---|
| **Rubik's Cube**（鲁比克魔方 1974） | 实体玩具鼻祖 | 六轴机械旋转、空间置换群论、标准六色 | 全球最畅销玩具；极佳的指尖触感；终极智力象征 | 国际标准配色（白顶黄底、绿前蓝后、红右橙左）、六轴旋转拓扑模型 | 实体魔方容易弹簧松动或被硬拧散架 |
| **Google Doodle Rubik's Cube**（谷歌魔方涂鸦） | Web / Google 2014 | 纯前端 WebGL 渲染、轻量快捷键支持 | 极轻开销秒开；丝滑的键盘与滑动映射 | 射线拾取法线切向投影算法、键盘 U/D/L/R/F/B 映射 | 纯展示玩具，缺乏系统化的每日挑战、计时器与教学体系 |
| **csTimer / CubeDesk** | Web 专业速拧站 | 专业 WCA 打乱生成、毫秒计时器、FMC 统计 | 专业速拧选手的必备工具；极高的数据专业度 | 国际标准打乱公式（Scramble Formula）与 WCA 计时规范 | 纯工具性质缺乏游戏化包装与 3D 动态沉浸感 |
| **DOIN 平台全站现有游戏** | 全站 70+ 款游戏 | 纯 2D / CSS 3D 微缩机台 | 零加载等待、低发热、高帧率 | 严格的 Plain 分层与全量语义化 DOM 契约 | **全站此前无任何真三维空间旋转游戏**，本作带来全新视觉多样性 |

**我们要借鉴的成熟机制**：
1. **严格遵循 AGENTS.md 准入三条硬性红线**：
   - **零外部模型/纹理**：严禁加载 `.gltf` / `.obj` 或外部图片贴图，全代码通过基础 `BoxGeometry`（带有倒角材质）生成；
   - **超轻量开销与低发热**：仅限 `MeshLambertMaterial` / `MeshBasicMaterial`，关闭动态阴影贴图，移动端 120fps 满帧运行且不发烫；
   - **纯粹舞台隔离**：Canvas 仅作为底层纯视觉视窗，所有 HUD、计时器、打乱公式、关卡列表均严格留在上层语义化 DOM 结构中；
2. **高容错面层手势识别算法（Face Normal & Tangent Dragging）**：
   - 鼠标/触控按下时，射线命中某个小立方体的特定面（法向量 $\mathbf{n}$）；
   - 滑动位移矢量 $\mathbf{\Delta}$ 投影到该面的二维切空间，取模最大分量确定旋转轴与旋转层；
   - 旋转过程跟随光标微动，释放时光标位移 $> 15\text{px}$ 自动缓动对齐最近的 $90^\circ$ 刻度，并触发“咔哒”磁吸音；
3. **空间全局旋转与面层旋转的完美解耦**：
   - 在魔方外部空白区域拖拽 ➔ 自由旋转观察全盘视角（Orbit View）；
   - 在魔方表面滑动 ➔ 锁定面层旋转（Layer Twist）。

**本作的差异化微创新（拒绝无聊死板）**：
1. **二阶先行破冰（2×2 Pocket Cube Entry）**：
   - 首屏默认提供 2×2 口袋魔方，仅需 8~12 步即可复原，让即使从来没拼好过魔方的普通小白，也能在 2 分钟内享受一次完整的通关狂喜；
2. **每日打乱同题挑战（Daily Seeded Scramble）**：
   - 每日基于统一日期种子生成全球唯一的 20 步打乱序列，记录本机当日最快还原耗时与步数；
3. **魔方学院 19 关分步残局（Cube Academy · 19 关精选）**：
   - 将复杂的 CFOP / 层先法拆解为 19 道精美的手绘残局（底层白色十字 ➔ 底层角块 ➔ 中层棱块 ➔ 顶面黄色十字 ➔ 顶角归位），手把手把普通玩家培养成速拧高手！

## 3 · 玩法规则与交互说明

### 核心规则

- **魔方几何与空间坐标**：
  - **二阶魔方（2×2×2）**：8 个角块立方体组成；
  - **三阶魔方（3×3×3）**：26 个立方体组成（6 个中心块、12 个棱块、8 个角块）；
  - **国际标准配色（Standard Color Scheme）**：
    - 上面（Up）：白色 `#FFFFFF`
    - 下面（Down）：黄色 `#FFD32A`
    - 前面（Front）：绿色 `#2ED573`
    - 后面（Back）：蓝色 `#1E90FF`
    - 右面（Right）：红色 `#FF4757`
    - 左面（Left）：橙色 `#FFA502`
- **玩家合法操作**：
  1. **面层旋转（Twist Layer）**：
     - 在魔方表面任意小块上按下并向邻近方向滑动：对应层顺畅旋转 $90^\circ$；
     - 旋转带平滑动画（120ms 弹性平滑缓动）；
  2. **全局视角旋转（Orbit View）**：
     - 在魔方外侧空白区域拖拽：以三维球形轨迹平滑旋转魔方整体，观察各个面；
     - 桌面端支持按住【鼠标右键】或【按住 Alt + 左键】直接旋转视角；
  3. **国际标准键盘记法（桌面速拧专属）**：
     - 支持国际速拧按键：【U】上面、【D】下面、【L】左面、【R】右面、【F】前面、【B】后面（按住 Shift 为逆时针）；
  4. **计时器操控（WCA Timer）**：
     - 点击【打乱 (Scramble)】：机器人在 1 秒内执行打乱序列；
     - 按住【空格键】0.5 秒准备（指示灯变绿），松开瞬间计时器起跑！还原完成瞬间自动毫秒级锁止计时。
- **胜利判定与完工仪式**：
  - **通关胜利（Clear）**：魔方六个面的所有小方块颜色完全一致，各归其位！
  - **终局仪式感**：
    - 计时器锁定绿色高亮，全场魔方外圈迸发出金色微光波纹；
    - 弹出成绩单卡片，展示本次通关耗时（例：`00:42.58`）、总旋转步数与 TPS（每秒转数）。
- **数学可解性与 100% 确定性保证**：
  - 严禁任何随机赋予面颜色的伪打乱！所有打乱序列必须且仅能通过从完全还原态出发的合法旋转序列（随机生成 15~22 步合法动作）生成；
  - 内置轻量还原求解器状态机，保证 100% 存在有限步数学最优解。

### 操作与手感细节

- **视听爽感与声学微雕**：
  - 面层旋转中：细腻低频的塑料滑轨摩擦声；
  - 90 度对齐卡扣：清脆解压的磁吸“咔哒”声；
  - 整体空间视角旋转：轻微柔和的空气微风呼啸；
  - 通关那一刻：编钟纯阳和弦奏响，魔方自转展示胜利姿态。

### 关卡模式编排（19 关魔方学院 + 自由双模式）

1. **模式一：二阶口袋魔方（2×2 Pocket Cube）**：
   - 快速打乱与还原，适合碎片化 1 分钟解压；
2. **模式二：三阶经典魔方（3×3 Classic Cube）**：
   - 完整 WCA 竞速体验，每日打乱种子同题竞技；
3. **模式三：魔方学院教学残局（Cube Academy · 19 关精选）**：
   - 按照 **4 / 5 / 4 / 3 / 3** 结构分为五大学习章节：
     - **第一章：白色十字架（4关）**：初识棱块归位；
     - **第二章：底层大圆满（5关）**：角块复原与一层归位；
     - **第三章：中层腰带（4关）**：中层棱块左右转入公式；
     - **第四章：顶面黄光（3关）**：顶面十字与小鱼公式；
     - **第五章：六面归一（3关）**：顶角顶棱终极归位，通关荣登“魔方大师”！

## 4 · 美术风格与视觉氛围（深色极客机械工坊，拒绝网页仪表盘）

- **题材与视觉关键词**：**深色极客工坊 · 软胶磨砂微雕 · 机械磁吸 · 极简 WCA 竞速 · 纯净三维**
  （不做单调惨白的白底网页，不做粗糙简陋的现代贴图；呈现为置身于暗调专业速拧工作室中，面对一块打磨极致的顶级磁吸机械魔方）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（3D Cube Arena）**：
    - 底层为轻量 Three.js 纯视窗 Canvas，微缩魔方悬浮在柔和的聚光灯下，具有圆角倒角与微弱内陷贴片质感；
    - 魔方周围带有极浅的环境微尘光斑，背景为深邃雅致的黑曜石渐变；
    - 顶框内嵌精雕合金挂牌：收纳【返回首页】、【阶数切换 2x2/3x3】、【魔方学院】、【音效】与【语言】；
  - **左侧状态翼栏（HUD Left Wing · WCA 竞速秒表）**：
    - 经典大号等宽数码管计时器（例：`00:38.42`）；
    - 旋转总步数（Turn: 42）与 TPS 速率；
    - 本机个人最佳单次（PB）与平均成绩（Ao5）；
  - **右侧策略翼栏（HUD Right Wing · 打乱秘谱与学院）**：
    - 当前打乱公式序列条（例：`R U R' U' F2 D L'`）；
    - 魔方学院口诀小贴纸（一目了然的下一步公式提示）；
  - **移动端适配**：
    - 竖屏自适应：中央 3D 魔方全屏呈现，手指在魔方上滑动转层，在空白处滑动转视角，上方悬浮半透明微缩计时条。

- **色彩与材质（严格代码内建）**：
  - **背景机台**：深邃玄黑金属 `#101318 → #080a0d`；
  - **魔方内芯骨架**：哑光纯黑软胶 `#1e2024`，倒角圆润；
  - **六色贴片材质**：代码生成的纯色磨砂材质（微弱高光，无外部贴图依赖）；
  - **动效降级**：在 `prefers-reduced-motion` 开启时，面层旋转动画缩短至 20ms 瞬间对齐，环境微粒关闭。

- **封面设计提案（assets/covers/cube.webp）**：
  - 严格遵循 3D 软胶质感、单一居中主体（60-75% 无文字）、彩色渐变背景、漂浮微粒标准；
  - **主体物件**：一个微微倾斜悬空的圆角 3D 软胶三阶魔方，顶层的一层正在向右旋转出 $45^\circ$ 的动态半开姿态，露出内芯精巧的纯黑软胶球形轴承，外层红、黄、蓝、绿的软胶色块散发着微弱温润的光泽，接触缝隙中爆出一圈细碎的软胶方块小微粒；
  - **背景基底**：深邃极客靛蓝至冷青色的高级斜向渐变，四周浮动着几颗彩色微缩软胶小方块。

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **首发阶数开放节奏**：
   - **方案 A（首发同时提供 2×2 与 3×3，强烈推荐）**：顶栏一键切换，2×2 负责 1 分钟破冰新手体验，3×3 负责专业深度与每日竞速，受众覆盖最广；
   - **方案 B（纯 2×2 极简先行）**：先做二阶验证手感，后续小版本再升级三阶。

2. **魔方学院教学口诀辅助的呈现形式**：
   - **方案 A（19 关分步残局 + 实时公式气泡，推荐）**：既有系统化的 19 关教学通关模式，自由模式中又能在右上角随时点开公式锦囊，最实用；
   - **方案 B（纯自由练习，不设教学关）**：仅提供专业打乱与计时，适合纯熟练玩家。

3. **键盘标准记法（U/D/L/R/F/B）支持**：
   - **方案 A（默认全局支持键盘快捷记法，推荐）**：方便桌面端专业魔方老饕盲打速拧，兼顾触屏滑动手势；
   - **方案 B（仅限纯鼠标/触屏拖拽）**：不设键盘快捷键，避免按键误触。
