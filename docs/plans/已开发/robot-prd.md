## 1 · 创意概念与核心乐趣

- **游戏名称**：编程机器人 / Robot Lab / 建议 slug：`robot`（备选 `robo`）
- **一句话玩法**：用有限的图元指令卡带编排行动序列，驱动呆萌机器人走位、跳台阶、推箱开门并点亮全场能源灯砖！
- **核心乐趣与卖点**：
  - **全站首款“指令编程与自动化”智力神作（The First Programming Puzzle）**：
    DOIN 现有 70+ 款游戏涵盖消除、棋盘、反应与物理，但**全站此前在“指令序列编程与自动化算法”领域仍是零覆盖**！本作将为平台开辟极客益智的全新版图；
  - **天生 100% 满足平台无死局与重放铁律（Pure Deterministic Automata）**：
    指令序列是离散、纯粹的逻辑映射，每一关的执行过程均可 100% 精确重放。状态机天然杜绝玄学随机穿模，所有关卡均可用 BFS/DFS 求解器进行严格的数学可解性自动化断言；
  - **从菜鸟到极客的“优雅代码高尔夫”心流（Code Golf Elegance）**：
    普通玩家只要能拼出指令让机器人跌跌撞撞点亮灯砖即能通关；硬核玩家则享受**“用极短的代码槽位 + Proc1 递归调用”**优雅解开繁复走廊的智力高潮，追求极致的“最少指令数（Code Golf）”三星皇冠；
  - **可视化的单步调试与极速重放（Step-by-Step Debugger）**：
    彻底告别代码报错的枯燥。配备现代 IDE 般直观的调试器：当前执行指令带有发光行指针，支持单步【Step】步进看机器人的每一步转向与传感器判定，方便快速找 Bug；支持 4x 极速跳过验证。
- **核心循环**：
  ```
  观察 2.5D 场景中的高低台阶与目标蓝灯位置 → 拖拽图元指令 (前进/转向/跳跃/点亮/子程序)
       ↑                                                      ↓
  下一关卡 / 斩获最简代码三星 ← 机器人严格按指令点亮全场灯砖 ← 点击【RUN 运行】或【STEP 单步调试】
       ↓ (指令出现逻辑错误撞墙或步数耗尽)
  机器人挠头困惑停下 → 发光指针停在出错指令处 → 0.1s 快速拔插微调指令槽
  ```

**经典标杆与成熟参考**：

| **Cargo-Bot**（货运机器人） | iPad / Web | 机械吊臂搬运货物、色彩条件分支指令 | 极简色彩条件分支设计；移动端极佳触控 | 颜色修饰符（只在红/蓝砖上执行该指令）机制 | 纯横版吊臂移动受限（本作采用 2.5D 立体网格） |
| **RoboZZle** | Web 社区神作 | 递归走迷宫、吃星星 | 递归思维的极限展现 | 递归调用（Proc1 调用 Proc1）的空间压缩感 | 过于硬核且界面简陋 |

**我们要借鉴的成熟机制**：
1. **直觉易懂的图元指令集（Iconic Instruction Set）**：
   - ⬆️ **前进（Move Forward）**：沿当前朝向向前走 1 格（同高度）；
   - ↩️ **左转（Turn Left）**：原地逆时针旋转 90 度；
   - ↪️ **右转（Turn Right）**：原地顺时针旋转 90 度；
   - 🦘 **跳跃/攀爬（Jump）**：向上跃升 1 层台阶，或从高处向前跃下 1 层台阶；
   - 💡 **点亮/交互（Light / Push）**：若脚下是蓝色能量灯砖，将其点亮激活；若前方是能量箱，向前推动 1 格；
   - 🔁 **子程序调用（Proc 1 / Proc 2）**：将当前控制权跳转到子程序槽位，执行完毕后返回主流程；
   - 🎨 **条件修饰色块（Color Condition）**：给指令涂上红/蓝/绿底色，只有当机器人脚踩同色地砖时，该指令才会被执行，否则静默跳过；
2. **严格的内存槽位限制（Memory Slot Constraints）**：
   - `MAIN` 主程序通常限定 8~12 个指令槽，`PROC 1` 限定 4~8 个指令槽，逼迫玩家提炼出重复模式进行模块化编程；
3. **单步调试与全速执行系统（Integrated Debugger）**：
   - 【RUN 全速执行】（支持 1x / 2x / 4x 速度切换）；
   - 【STEP 单步调试】（点一下走一步，代码指针清晰高亮当前指令）；
   - 【RESET 重置】（一键让机器人秒回起点，指令保持原样）。

**本作的差异化微创新（拒绝枯燥代码黑屏）**：
1. **微缩复古极客工坊（Diorama Cyber Workshop）**：
   - 场景不是生硬的灰色方块，而是一座嵌在深黑金属台面上的 2.5D 发光微缩实验台。地砖带有细腻倒角与网孔，能量灯砖被点亮时散发出幽雅的荧光蓝晕；
2. **实体磁贴卡带手感（Magnetic Cartridge Tape）**：
   - 指令不是死板的文本列表，而是带有微浮雕的软胶磁贴。拖入卡带槽位伴随清脆磁吸“咔哒”声，支持随手拖拽调换顺序；
3. **推箱机关与空间升降（Box & Switch Mechanics）**：
   - 不仅是点亮灯砖，高阶关卡融入“推箱压住重力开关升降激光门”等物理机关，让编程与经典推箱子谜题完美共鸣。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与空间构成**：
  - **2.5D 等轴测微缩浮岛（Isometric Grid）**：$8 \times 8$ 网格范围，支持 0~3 层不同高度的石质台阶；
  - **机器人（Bot）**：占 1 格，具有当前坐标 $(X, Y, Z)$ 与四向朝向（东、南、西、北），头顶有一盏小指示灯；
  - **目标物**：
    - 蓝色能量灯砖（暗态）：机器人站立其上并执行【💡点亮】指令后变为金黄常亮态；
    - 能量箱（Energy Crate）：平地可推动障碍物；
    - 压力开关与激光门：箱子或机器人站上去可降下挡路激光门。
- **玩家合法操作**：
  1. **编排指令（Compose Code）**：
     - 点击或拖拽下方的指令磁贴，按顺序填入 `MAIN` 或 `PROC 1` 卡带槽位；
     - 随时可点击槽位中的指令进行删除、替换或长按拖拽重新排序；
     - 为指令附加条件色块（长按指令弹出红/蓝调色盘）；
  2. **执行调试（Execution Controls）**：
     - 点击【▶️ RUN】：机器人开始按指令卡带依次执行；
     - 点击【⏭️ STEP】：单步单步执行，观察当前指针位置；
     - 点击【⏸️ PAUSE】：中途暂停执行；
     - 点击【🔁 RESET】：瞬间复位回到起点，场景机关重置，代码保留；
  3. **倍速切换**：随时切换 1x / 2x / 4x 执行速度。
- **胜利判定与终局规则**：
  - **通关胜利（Clear）**：执行序列结束后（或执行途中），关卡内**所有蓝色能量灯砖全部被点亮**！
  - **终局仪式感**：
    - 全场灯砖爆发出耀眼的金光回路，机器人原地转圈跳起胜利机械舞，头顶小灯泡欢快闪烁；
    - 弹出通关终端屏，展示使用的指令总行数与执行总步数；
  - **执行中止判定**：
    - 若指令序列全部执行完毕但仍有灯砖未被点亮；
    - 若机器人试图向前直行却撞上高耸墙壁或深渊（机器人停下原地挠头，指令指针亮红报错）。
- **数学可解性与 100% 确定性保证**：
  - 机器人的转移方程完全由离散纯函数确定（`nextState = stepInstruction(state, instruction)`）；
  - 全 21 关均配有官方验证的最简指令解（Gold Standard Solution），经 BFS/DFS 求解器验算，100% 逻辑可解。

### 操作与手感细节

- **视听爽感与声学微雕**：
  - 磁贴装配：清脆沉稳的磁石吸附声“咔哒”；
  - 机器人移动：微型伺服电机转动的清脆“滋滋——步进”声；
  - 机器人跳跃：弹簧气动活塞的轻柔“哧——嗒”声；
  - 点亮灯砖：空灵纯净的水晶泛音高调“叮——！”；
  - 撞墙/报错：短促温和的电子蜂鸣故障声“哔啵”，毫无挫败感。

### 关卡模式编排（21 关五大进阶工坊：4/5/4/5/3）

1. **第一卷：初级工蜂（Novice Assembly · 4关）**：
   - 基础教学：前进、转向、点亮灯砖，建立三维空间几何与朝向感；
2. **第二卷：高度跃迁（Vertical Stride · 5关）**：
   - 引入高度层级：跳跃攀爬台阶、从高台向下俯冲跃迁；
3. **第三卷：循环子程序（Subroutine Loops · 4关）**：
   - 引入 `PROC 1` 子函数：槽位大幅压缩，逼迫将重复的“直行点亮”提炼为子程序并实现循环；
4. **第四卷：色彩条件分支（Conditional Logic · 5关）**：
   - 引入颜色修饰符：根据地砖颜色执行不同动作，以极简代码解决分叉十字路口抉择；
5. **第五卷：图灵总装线（Turing Finales · 3关）**：
   - 终极复合大挑战：推箱压开关、递归子程序与条件分支融合，通关荣登“首席自动化架构师”！

## 4 · 美术风格与视觉氛围（复古微缩极客工坊，拒绝网页仪表盘）

- **题材与视觉关键词**：**复古极客 · 2.5D等轴测微缩 · 实体软胶磁贴 · 温暖指示灯 · 极客优雅**
  （不做单调惨白的网页，不做生硬冰冷的死黑代码框；呈现为置身于一台带有复古 CRT 绿显风格与黄铜机械零件的微缩极客工作台前）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Isometric Grid Arena）**：
    - 正中是一块带有细腻倒角的 2.5D 等轴测微缩浮岛，地砖带有微弱的高温散热网孔与柔和阴影；
    - 呆萌的发光小机器人立于台上，双眼是明亮的点阵 LED；
    - 顶框内嵌精雕金属挂牌：收纳【返回首页】、【关卡选择】、【音效】与【语言】；
  - **右侧控制台翼栏（HUD Right Wing · 指令编程卡带机）**：
    - 实体磁贴卡带插槽：`MAIN` 矩阵与 `PROC 1` 矩阵清晰分列；
    - 执行时带有明亮的流光发光行指针，清晰指示当前执行指令；
    - 底部集成运行控制器：【▶️ RUN】、【⏭️ STEP】、【1x/2x/4x】、【🔁 RESET】；
  - **左侧状态翼栏（HUD Left Wing · 极客日志）**：
    - 终端风格羊皮纸：展示当前关卡目标与已点亮灯砖计数（例：`ENERGY: 2/4`）；
    - Code Golf 挑战记录（当前代码行数 vs 关卡最优金牌行数）；
  - **移动端适配**：
    - 竖屏自适应：上方为 2.5D 舞台，下方为大号图元指令磁贴托盘与卡带槽，拇指拖拽点选极其精准。

  - **指令磁贴颜色**：
    - 移动指令：活力亮绿 `#2ed573`；

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **指令输入的交互体验**：
   - **方案 A（点击快速填入 + 拖拽重排双轨，强烈推荐）**：点击下方指令磁贴直接顺延填入下一个空格，长按已填指令可拖动调整位置，在触屏与电脑端均最顺手极速；
   - **方案 B（纯拖拽放置）**：必须从工具栏拖入卡带槽位，对触屏略微繁琐。

2. **推箱子机关的融入度**：
   - **方案 A（适度融入，推荐）**：前三章专注于纯点亮灯砖与子程序循环，第四、五章引入推箱子压开关开门，玩法纵深更广，极具综合大工坊成就感；
   - **方案 B（纯粹原汁点亮灯砖）**：全 21 关只有台阶与灯砖，没有任何可推动箱子，对标纯粹的《Lightbot》。

3. **最简代码（Code Golf）星级评定的容错度**：
   - **方案 A（双轨宽松星级，推荐）**：★ 通关即得，★★ 指令数在官方最优 +2 步内即给，★★★ 达成绝对极限最优。兼顾普通玩家与极限极客；
   - **方案 B（严苛单轨）**：必须达成唯一绝对最优行数才能获得二星三星。
