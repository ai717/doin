## 1 · 创意概念与核心乐趣

- **游戏名称**：神偷手臂 / Thief Puzzle / 建议 slug：`thief`（备选 `rubber-thief`）
- **一句话玩法**：拖拽神偷的橡胶长臂，借助立柱巧妙绕桩避开激光电网与恶犬，精准勾走宝物并原路弹射收回！
- **核心乐趣与卖点**：
  - **Poki / 全球超休闲榜单绝对霸榜常客（Global Top Chart Phenomenon）**：
    同类益智解谜全球累计游玩破数亿次，拥有无与伦比的天然吸引力与滑稽魔性。机制全站零覆盖！这是现代休闲玩家最喜闻乐见的“偷感十足 + 脑洞大开”解密精品；
  - **与画轨滑雪（lineride）本质截然不同：“受限关节链绕桩”（Constrained Pivot Wrapping）**：
    不同于自由涂鸦画线，本作考验的是**严密的物理拓扑空间几何**——手臂是一根具有张力的橡胶多关节链条。玩家必须精准利用场景中的吊灯、石柱、雕像作为锚点进行“缠绕借角（Wrap）”，让手臂折出精妙的折线，在几厘米的缝隙中贴边擦过激光；
  - **★ 纯净零广告重构，彻底剔除低俗与弹窗（Zero Ads Pure Slapstick）**：
    原版商业小游戏充斥着粗陋 Flash 贴图、每过一关看 30 秒垃圾广告的恶劣体验。本作重构为**高品位美漫微缩怪盗喜剧**，画面温润精致，零弹窗、零打扰，全心沉浸于解谜心流；
  - **爆笑夸张的滑稽正负反馈（Hilarious Slapstick Reactions）**：
    偷窃得手瞬间，神偷手舞足蹈发出得意的“嘿嘿嘿”贼笑，手臂“嗖——”一声带起残影原路弹回；若不慎碰上电网，整个人骨骼透视焦黑冒烟，若被恶犬咬住则裤子被扯下抱头痛哭，充满法式荒诞幽默。
- **核心循环**：
  ```
  观察场景中的目标宝物、固定立柱与致命机关 (激光/电网/恶犬)
       ↑                                                      ↓
  下一关卡 / 展出被盗珍宝相册 ← 宝物得手！手臂高速弹力原路收缩回弹 ← 拖拽长手，借助立柱折线绕开障碍
       ↓ (手臂触碰激光 / 触碰电网 / 惊动巡逻犬)
  神偷滑稽触电焦黑 / 警报大作 → 0.2s 瞬时秒重开本关，重新推演绕桩路线
  ```

**我们要借鉴的成熟机制**：
1. **多关节链条绕桩与解绑算法（Pivot Wrapping/Unwrapping Algorithm）**：
   - 设当前手臂折线为点集 $P_0 (\text{肩部}), P_1, P_2, \dots, P_k (\text{手掌})$；
   - 当手掌拖拽位移导致线段 $P_{k-1}P_k$ 与场景中的某个圆柱支点 $C_i$ 发生几何交叉时，在切点处插入新的折点 $P_{new}$，手臂被“挂在柱子上”；
   - 当手掌往回拉拽，导致夹角张开且视线无阻挡时，该折点自动弹出解绑（Unwrap），手臂重新拉直；
2. **多重危险相交检测（Obstacle Collision Matrix）**：
   - 不仅是手掌，整条手臂的所有线段均实时检测与激光束（线段相交）、电网（矩形相交）、巡逻警卫视锥的碰撞；
   - 只要任何一段手臂触碰危险，瞬间触发触电报警，杜绝穿模作弊；
3. **两段式机关解密（Two-Stage Thievery）**：
   - 高阶关卡中，目标宝物被高压激光笼罩；玩家必须先操控手臂绕桩触碰红色【关闭电闸】按钮，随后再迂回穿行抓走宝物。

**本作的差异化微创新（拒绝粗制滥造）**：
1. **美漫复古怪盗微缩剧场（Diorama Heist Theater）**：
   - 彻底告别白底粗线条火柴人！将场景重塑为一座带有复古装饰风艺术（Art Deco）的贵族豪宅与卢浮宫展厅，主角是戴着小高帽、穿燕尾服的狡黠绅士怪盗；
2. **20 关怪盗奇妙夜史诗（4/4/4/4/4 结构）**：
   - 豪宅厨房（偷刚出炉的苹果派）➔ 密室金库（偷蓝宝石戒指）➔ 皇家博物馆（偷蒙娜丽莎）➔ 激光科技馆（偷反重力飞靴）➔ 钟楼秘殿（偷时间怀表）；
3. **真弹性回缩手感（Spring Retraction Haptics）**：
   - 触碰到宝物的瞬间，手臂不是死板消失，而是化作一条紧绷弹簧“嗖！”带着宝物飞旋收缩，伴随真实的弹性回响。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与几何元素构成**：
  - **视口宽 840px、高 560px 的微缩盗窃舞台**；
  - **神偷本体（Thief Origin）**：位于场景边缘（如窗台、通风管、吊顶），伸出橡胶手臂；
  - **目标宝物（Target Loot）**：带有闪亮金色星芒的物品（钻石、名画、王冠、小猫）；
  - **固定绕桩立柱（Pivots）**：石柱、雕像底座、挂画钉，允许手臂平滑缠绕；
  - **致命障碍物（Hazards）**：
    - 红外激光线（触碰即断开报警）；
    - 带电铁丝网（触碰瞬间触电）；
    - 睡着的恶犬（手臂如果从其头部 40px 内穿过会被咬住惊醒）；
    - 机关开关（必须用手臂轻触按下才能开启铁闸门）。
- **玩家合法操作**：
  1. **拖拽长臂（Drag Hand）**：
     - 鼠标左键按住神偷手掌并拖动 / 触屏按住手掌滑动：
     - 手臂随着拖拽平滑伸展变长，经过立柱时自动缠绕折叠；
  2. **回拉解绑（Retract / Pull Back）**：
     - 将手掌往回拖动：手臂自然收缩变短，若绕过的立柱不再处于受力折角，自动平滑脱开；
  3. **抓取判定（Grab on Contact）**：
     - 当手掌碰撞盒触碰到目标宝物的一瞬间，控制权锁定；
     - 宝物被抓取固定在掌心，整条手臂以 3 倍极速沿原折线原路回弹缩回神偷怀中！
  4. **全时重置（Instant Reset）**：随时按【R】或点击界面“重试”，零等待秒重开。
- **胜利判定与关卡目标**：
  - **通关胜利（Clear）**：成功将目标宝物安全带回神偷手中，神偷露出滑稽胜利笑脸；
  - **失败判定（Game Over）**：
    - 手臂或手掌触碰到红外激光线；
    - 手臂触碰高压带电物，神偷触电骨骼闪烁焦黑；
    - 惊动巡逻警卫或被恶犬扑咬。
- **数学可解性与 100% 确定性保证**：
  - 几何绕桩算法基于离散切线计算，全 20 关场景障碍布局经过严格的折线可达性验证，保证至少存在一条完全安全的偷窃拓扑折线，绝无几何死胡同。

### 操作与手感细节

- **视听爽感与声学微雕**：
  - 手臂拉长：如同拉力绳紧绷的细微“吱——吱——”橡胶拉扯音；
  - 绕过立柱：碰撞并挂住立柱时发出清脆利落的“咔哒”锚定声；
  - 得手收缩：弹力释放的空灵破空声“嗖——啪！”；
  - 触电失败：搞笑滑稽的卡通交流电蜂鸣“滋滋滋——” + 神偷惨叫；
  - 胜利欢呼：吹口哨与神偷得意的经典轻笑声。

### 关卡模式编排（20 关五大怪盗篇章：4/4/4/4/4）

1. **第一卷：见习小贼（Novice Burglar · 4关）**：
   - 基础教学：单柱绕桩、从沙发后偷甜甜圈、避开打呼噜的胖管家；
2. **第二卷：密室激光（Laser Vault · 4关）**：
   - 引入静态红外激光：利用两根大理石柱进行“Z字形”精准折射绕桩，偷走保险箱黄金；
3. **第三卷：恶犬与开关（Hound & Lever · 4关）**：
   - 引入两段式机关：先绕桩拉下电闸关掉激光，再折返取走钥匙；
4. **第四卷：动态探照灯（Sweeping Spotlights · 4关）**：
   - 引入缓慢摆动的探照灯光锥，考验不仅要绕桩、还要抓准时机的复合操作；
5. **第五卷：卢浮宫绝密（The Louvre Heist · 4关）**：
   - 终极试炼：多重立柱复合长链折叠、高密度交错激光、万无一失取走传世名画！

## 4 · 美术风格与视觉氛围（复古怪盗美漫，拒绝网页仪表盘）

- **题材与视觉关键词**：**法式怪盗 · 复古美漫风 · 夸张橡胶拉伸 · 幽默滑稽 · 暖调豪宅**
  （不做单调惨白的白底网页，不做粗糙简陋的劣质火柴人；呈现为置身于一本画风优雅幽默的法式彩色侦探漫画中）。

- **桌面端双栏沉浸舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Heist Arena）**：

    - 场景中的立柱带有立体微阴影，激光呈现明亮炽热的荧光红芒；
    - 神偷露出半个身子探在窗口，表情丰富生动（拉长手臂时瞪大眼睛龇牙咧嘴）；
    - 顶框内嵌复古铜质挂牌：收纳【返回首页】、【关卡相册】、【瞬时重开】、【音效】与【语言】；

    - 展开的羊皮纸任务清单：
      - 当前目标物图鉴与名称（例：`TARGET: 罗马金冠`）；

  - **豪宅背景底色**：温暖典雅勃艮第红 `#2c1e21` 搭配复古墨绿壁纸 `#1e272e`；

  - **橡胶手臂**：富有弹性光泽的明亮黑色，伴随拉长自然产生粗细渐变；
  - **红外激光**：高亮荧光霓虹红 `#ff3838`；
  - **宝物高光**：金光璀璨纯金黄 `#fbc531`，周围带有漂浮的软胶星星；

- **封面设计提案（assets/covers/thief.webp）**：
  - 严格遵循 3D 软胶质感、单一居中主体（60-75% 无文字）、彩色渐变背景、漂浮微粒标准；
  - **主体物件**：一个戴着黑色眼罩、露出狡黠笑容的圆润软胶小神偷，正从左侧探出半个身子，他的右手臂像一根红黑相间的软胶长弹簧一样，在空中绕过一根立体的白色大理石柱，手掌正一把稳稳抓住一颗散发着耀眼金光的软胶大钻石，接触点爆出一圈清脆可爱的金色小星星微粒；

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下 3 大核心设计点定夺：

1. **手臂长度限制（核心解谜定调）**：
   - **方案 A（无限长度，专注纯空间绕桩，强烈推荐）**：手臂可以无限伸长，解谜核心完全聚焦于“如何巧妙绕过所有障碍物”，心流最轻松愉悦、上手零挫败；
   - **方案 B（有限弹性长度管）**：右上角有一根黄色弹性极限槽，手臂每拉长 1 米槽位减少，必须寻找距离最短的几何绕桩路线，更硬核但对新手略有压迫。

2. **动态巡逻敌人的处理方式**：
   - **方案 A（静态机关为主 + 少数慢速探照灯，推荐）**：90% 为静态激光、电网与固定睡犬，仅第 4、5 章引入规律摆动的探照灯，主打纯空间解谜；
   - **方案 B（大量动态巡逻警卫）**：融入重度动作时机要素。

3. **两段式开关解谜比重**：
   - **方案 A（占 30% 关卡，推荐）**：中后期关卡必须“先绕桩碰开关解除激光，再拐弯偷宝物”，提升复合解谜成就感；
   - **方案 B（100% 直取宝物）**：所有关卡目标唯一，无需触碰开关。
