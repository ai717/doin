## 1 · 创意概念与核心乐趣

- **游戏名称**：高压洗车屋·解压清洁 / Jet Wash House / slug `jetwash`
- **一句话玩法**：高压水枪冲掉污渍，把脏车脏家具洗回全新（≤30 字）
- **核心乐趣与卖点**：污渍一层层剥落、脏色一点点退成亮色的视觉爽感；水柱扫过之处立刻干净的即时正反馈；无失败、无时间压力的治愈心流。玩家为什么好玩——不是解谜烧脑，而是“亲手把世界洗干净”的掌控感与成就感，脏污越厚、洗净对比越强，越上头。
- **核心循环**：选工具（水枪/刷子/泡沫）➔ 按住拖动冲刷脏面 ➔ 污渍分层变薄、泡沫带走灰尘、亮色露出 ➔ 清洁度百分比上涨、区域闪亮提示 ➔ 整件洗净 100% 触发闪光仪式 ➔ 下一件脏物/下一关。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **PowerWash Simulator（高压清洗模拟器）**：第一人称高压水枪洗车、洗房、洗院子，核心是“污渍覆盖率清零”的治愈循环；最受认可的是水柱扫过即干净的即时反馈、污渍分层（浮灰→油渍→顽渍）需换喷头/洗涤剂的层次感。
  - **抖音/小红书解压清洁短视频与同类手游（地毯清洗、家具翻新类）**：核心是强对比视觉——脏→净的瞬间反转、泡沫绵密、刮水器一刮亮一片；最受认可的是“看脏东西被洗掉”的解压满足感与 ASMR 水声。
- **我们要继承的成熟机制**：污渍覆盖率判定（洗到 100% 过关）、分层污渍（不同工具对不同层效率不同）、水柱/刷子按住拖动的连续操作手感、洗净区域高亮闪烁的正反馈、整件完成时的闪光+音效仪式。
- **本作的独特魅力与微创新（Twist）**：
  - **分层剥落可视化**：污渍做三层（浮灰层→油渍层→顽渍层），每层颜色/质感不同，冲一遍薄一层，玩家肉眼可见“洗到第几层”，比单层变淡更有成就感。
  - **工具分工但零惩罚**：水枪冲浮灰最快、泡沫软化油渍、刷子刮顽渍；用错工具只是慢、绝不扣分不失败，保持纯解压心流。
  - **家具+车辆双题材轮换**：洗车、洗沙发、洗地毯、洗灶台轮换，避免单一物件洗腻。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：
  - 按 `GEM_INSTRUCTION-4.md` 第二节 100 款已上架清单（`idiom` 至 `volley`）核对：**全站无清洁类游戏**，本作是全新品类空白，不存在规则一模一样的换皮风险。
  - 与最接近的存量游戏 **`tidy`《沉浸收纳达人》** 的机制差异：`tidy` 是“把物品拖到正确位置对齐收纳”的空间逻辑解谜，有对错、有目标位置；本作是“按住冲刷、污渍按覆盖率分层剥落”的连续操作解压，无对错、无摆放逻辑，核心判定是覆盖率而非位置匹配。两者题材都偏治愈生活流，但规则模型完全不同。
  - 与 **`screw`《拧螺丝解谜》** 的差异：`screw` 有解谜目标与失败判定；本作无失败、无解谜，纯清洁度推进。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - **盘面/场景构成**：单件脏物居中大特写（汽车侧面/沙发/地毯/灶台等 2D 侧视或俯视图），表面覆盖三层污渍贴图（浮灰浅灰、油渍深褐、顽渍黑斑）；底部工具托盘（高压水枪、泡沫喷壶、刷子、刮水器）；顶部清洁度进度条（百分比）与关卡名。
  - **玩家合法操作**：点选工具后，按住鼠标/手指在脏面上拖动，工具作用半径内污渍逐层变薄；水枪可调喷头宽窄（宽扇面扫大面、细柱攻顽渍）；泡沫先喷后冲效率翻倍。
  - **胜利条件与失败条件**：清洁度达到 100%（污渍覆盖率清零）即过关，触发闪光仪式；**无失败条件**，无时间限制（默认解压模式）；可选计时模式仅记录用时、不淘汰。
  - **容错与无死局说明**：污渍生成保证 100% 可洗净——每层污渍都有对应工具可完全清除，不存在洗不掉的死角；覆盖率判定按像素/网格采样计算，边角缝隙作用半径可达；玩家中途可随时换工具、可重洗本关，不会卡死。随机脏污分布只影响位置与厚度，不影响可洗净性。
- **操作与手感**：
  - 鼠标/触控：按住拖动冲刷，松开停水；工具切换点选托盘图标；滚轮/双指可缩放查看细节（可选）。
  - 键盘快捷键：数字键 1–4 切工具；`P`/`Esc`/`Space`（非主动作时）暂停/继续；`R` 重洗本关。
  - **随时可暂停与失焦保护机制**：默认解压模式无倒计时、天然静止，无需强制常驻暂停；但**计时模式必须常驻实体「暂停/继续」按钮 + 快捷键 P/Esc/Space**，暂停时冻结计时与水流动画、展示轻量半透明覆盖层（「已暂停 / PAUSED」+继续/重玩）；切标签页/最小化（`visibilitychange`）自动暂停计时与音效。无计时模式下呼出菜单同样冻结动画。
  - 误触容错：拖出脏面区域自动停水不惩罚；工具切换即时生效无冷却。
- **即开即玩与平滑选关设计（Instant Play）**：
  - **首屏秒进对局**：打开直接呈现第 1 关脏车就绪盘面，水枪默认选中，按住即可冲，严禁全屏选关/模式遮罩。
  - **常驻显眼选关入口**：顶栏常驻「选关」/「模式」按钮，点击以轻量抽屉展示关卡网格（车辆/家具分组）；通关结算面板提供「下一件」与「选关」。
  - **严禁强制全屏遮罩阻塞首屏**。
- **模式与内容编排（严禁套路化）**：
  - **解压清洁模式（默认）**：章节制关卡，如「洗车屋」（轿车→越野车→餐车）、「家居翻新」（沙发→地毯→灶台→浴缸），每章引入新污渍类型与新工具；评级用清洁度星级（洗净即三星基底，细致度加分）而非总分。
  - **计时冲洗模式（可选）**：同关卡限时洗净比用时，带暂停机制，服务于想挑战速度的玩家；**不设每日挑战、不设无尽冲分**，避免套路化。
  - 内容递进靠污渍层数与物件复杂度，不靠堆倒计时压力。
- **游戏目标与反馈体系**：
  - 核心指标：清洁度百分比（0–100%）+ 用时（计时模式）；不看总分。
  - 阶段反馈：每洗净一个区域，该区域闪一下亮光+清脆水声；整件 100% 时全屏闪光扫过+完成音效+前后对比图（脏/净并排）。
- **双语核心词汇与数据键名规划**：
  - 模式：解压清洁模式 Relax Wash / 计时冲洗模式 Time Wash
  - 关卡：如 第1关·小轿车 Level 1: Sedan；第2关·布艺沙发 Level 2: Sofa
  - 工具：高压水枪 Jet Gun / 泡沫喷壶 Foam Sprayer / 刷子 Brush / 刮水器 Squeegee
  - 污渍：浮灰 Dust / 油渍 Grease / 顽渍 Stubborn Stain
  - 数据层约束：关卡、工具、污渍一律用字符串 key（如 `level_sedan`、`tool_jet`、`stain_dust`），展示层走 i18n，严禁裸写中文；语言切换原地热更新，严禁 `location.reload()`。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：洗车屋水雾、泡沫绵密、瓷砖墙面、湿润反光、治愈明亮
- **专属视窗物理隐喻**：**单件脏物居中大特写 + 底部工具托盘 + 顶部清洁度进度条**的“洗车工位”形态——像站在洗车屋工位前面对一辆车/一件家具。严禁左右双翼三栏套路，严禁四角散落浮动按钮，严禁右侧 SaaS 表单卡片堆叠。背景是洗车屋瓷砖墙+水雾氛围，工具托盘是工位台面，整体是一个完整工位场景而非卡片拼贴。
- **立体质感与渲染路线裁决**：**Canvas 2D**（脏物贴图+污渍层擦除+水柱粒子+泡沫粒子），UI 层用 DOM。95% 路线内，不上 Three.js——本作是平面冲刷玩法，不需要真 3D 空间翻转。若未来要做 360° 旋转洗车，必须锁死三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层），本期不启用。
- **声效风格与材质音色规划（4–6 种，拒绝单音蜂鸣）**：
  1. 高压水柱冲击声：宽带噪声滤波 + 随拖动速度变调的“滋滋”水声（核心音，持续型）
  2. 泡沫喷壶声：短促气溶胶“呲”声 + 泡沫落下细碎泡泡声
  3. 刷子摩擦声：粗糙噪声刮擦，带刷毛颗粒感
  4. 刮水器滑过声：橡胶刮过湿面的一声“哧溜”
  5. 区域洗净提示音：清脆水滴玻音（FM 合成）单声
  6. 整件完成音：水花绽放 + 轻柔马林巴上行（治愈向，非琶音套路）
- **封面设计提案**：3D 软胶质感，单一居中主体——一辆半脏半净的小轿车（左半泥污右半亮蓝），高压水柱从右上扫过，泡沫点缀；鲜艳蓝白渐变背景；主体占 60–75%，无文字。

## 6 · 制作人拍板与开放探讨

1. **选项一（关卡节奏）**：方案 A 每关单件大特写、关卡多而短（2–3 分钟一件） vs 方案 B 每关多件组合（如一辆车+四轮胎分段洗）、单关更长更沉浸。推荐 A，更贴合碎片化解压。
2. **选项二（计时模式）**：方案 A 首期只做无计时解压模式，计时模式二期再加 vs 方案 B 首期双模式齐发。推荐 A，先把解压手感做扎实。
3. **选项三（题材配比）**：方案 A 洗车为主（70% 车辆关卡） vs 方案 B 车辆与家具对半。推荐 B，题材轮换防腻。
