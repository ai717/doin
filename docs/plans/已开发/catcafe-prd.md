## 1 · 创意概念与核心乐趣

- **游戏名称**：迷你猫咖掌柜 / **Cat Cafe** / 建议 slug：`catcafe`（已确认，见 §5 拍板项）
- **一句话玩法**：开一间治愈系猫咖，操控喵掌柜在吧台、客席、外卖窗之间穿梭冲咖啡、端盘子、擦桌子、收金币。
- **核心乐趣与卖点**：
  1. **喵掌柜的多任务并行快感**——猫爪按下"冲咖啡"立刻冲到萃取机，等咖啡时拐去擦桌收小费，咖啡好了端给客人——像 Diner Dash 又比 Diner Dash 轻：猫爪的操作是软糯连续的、不会"卡手"。
  2. **站在工位上 = 自动执行**——像 Monkey Mart 但更简化：站在咖啡机旁自动萃、站在收银旁自动收钱；移动 + 站位 = 全部操作语言。
  3. **离线收益的"被想念感"**——离开 3 小时回店，吧台上堆满了喵咪们（NPC 猫）帮你收的"待结算小费桶"，每开一个桶配一句喵咪留言："橘猫阿橘今天帮 8 位客人送咖啡～"——离线回来不是干巴巴数字，是"猫咖小剧场"。
  4. **咖啡工艺链的实体化升级感**——豆子→烘焙机→研磨机→萃取机→拉花杯，每升一级不是 +5% 数值，而是工位本身变精致：旧烘焙机换成红铜大炮、新萃取机带木把手、猫爪印徽章。
  5. **喵咪图鉴的收集治愈**——12 位常客喵咪各有偏好的咖啡口味与背景故事（加班程序员猫要黑咖啡、失眠作家猫要燕麦拿铁、退休老猫要点"夕阳特调"），喂对口味的咖啡解锁它们的故事。
  6. **窗口扩张的运营快感**——从单吧台 → 外带窗口 → 露台卡座 → 屋顶花园区，每开一窗营业额飙一档，是经营最直接的爽感。
- **核心循环**：解锁工位（豆罐/烘焙机/研磨机/萃取机/拉花杯）→ 自动产线 → 顾客排队 → 端盘送咖啡收小费 → 买新喵咪帮手 / 解锁新窗口 → 离线收益 → 回店领"想念桶" → 投入再扩店。

> **品类占位**：DOIN 现有 50+ 款作品以解谜/纸牌/消除/下落/动作为主，仅 `ramen-idle` 一款放置经营（深夜拉面）。本作是**全站第二款 Arcade Idle**，但题材、视窗、操作语言、收集叙事全部差异化：拉面是深夜治愈、咖啡是午后治愈；拉面是观感生产链、咖啡是工匠感吧台；拉面是帮工流水线、咖啡是喵咪伙伴养成。两者共筑 DOIN 治愈经营品类双壁。

## 2 · 经典标杆与对标参考

| 对标 | 借鉴点（具体抄什么） | 避坑点（具体不做什么） |
|---|---|---|
| **《Monkey Mart》（Poki Arcade Idle 标杆）** | ① **移动 + 站位 = 全部操作语言**：WASD 移动到工位旁，自动执行采摘/上架/收银，无按钮；这是 Arcade Idle 最朴素的"操作预算"——玩家不被按钮淹没，全凭动线规划。② **三件套帮工体系**：收银员 / 上架员 / 厨师，每个帮工有独立升级树（速度 / 体力 / 容量），合起来把玩家从手动中解放出来。③ **市场迭代**：6 个市场从香蕉 → 巧克力 → 椰子水，每开一个新市场自动继承老市场的产线，是个"层层叠叠"的成长仪式感。④ **升级菜单收敛为三种属性**（Stamina / Stack / Speed），玩家学一次记一辈子。 | ⛔ 不做 6 个市场的连开——本作体量做 4 个扩张阶段（吧台/外带窗/露台/花园），每个扩张阶段是同一吧台的演进而非新地图。⛔ 不做"工人在干活时睡着"的负反馈——猫咖的猫咪帮手"打瞌睡"是被允许的治愈演出，**绝对不会卡住产线**。⛔ 不做引导箭头锁定"下一步必买"——本作给玩家自由选择先扩哪一环的权力。 |
| **《Diner Dash》（多任务管理经典）** | ① **多任务并行 + 心情系统**：Flo 同时处理"接单→上菜→收桌"，顾客头顶爱心随等待时间下降；本作用"客人耐心气泡"做同样张力。② **Combo 链式奖励**：连续同种操作得分倍率翻倍；本作用"连续上对客人偏好的咖啡"触发金币加成。③ **升级餐厅装潢**：从破旧小馆到高档餐厅，每升级一次是视觉享受。 | ⛔ 不做"lose stars" 失败机制——猫咖永不赶走客人，耐心归零只是损失该客人小费，不影响产线不丢命。⛔ 不做 50 关卡 + Endless Shift 的二元模式——本作以"扩张阶段 + 离线收益 + 图鉴收集"三轴驱动，不需要关卡 + 无尽。⛔ 不做拖拽接单——本作咖啡自动化冲制，不需要手动点单（客人自带需求）。 |
| **《Cat Cafe Manager》《猫咪咖啡厅》（猫咖题材专项参考）** | ① **猫咪角色图鉴 + 故事**：常客猫咪各有姓名/性格/口味偏好（参考 Cat Cafe Manager 的 12 喵图鉴）；② **猫咪互动演出**：闲置时猫咪会自己蹭杯垫、跳上吧台睡觉、整理围裙——是"活的咖啡馆"质感；③ **菜单研制**：口味组合（燕麦/燕麦 + 焦糖/燕麦 + 焦糖 + 肉桂）解锁新饮品。 | ⛔ 不做复杂菜单工程（10×10 配方表）——本作做"8 款核心咖啡 + 12 只常客图鉴"，体量轻；⛔ 不做时间加速 / 跳过等待的氪金点——本作离线收益本身就是"跳过等待"的免费实现。 |
| **`ramen-idle`（DOIN 站内对照）** | ① **离线收益温情结算弹窗**（灯笼 / 喵咪留言二选一叙事载体）；② **指数成本曲线 `cost = base × 1.15^owned`**（放置经济心脏）；③ **常客图鉴 + 配方图鉴双轨**。 | ⛔ 不做深夜时段切换（18:00–04:00）——本作是午后猫咖，不切时段；⛔ 不做"备料→熬煮→出餐"四环供给链（拉面的核心机制）——本作是"豆→烘→磨→萃→拉"五环工艺链，但**自动化优先，玩家基本不在主循环里点链**，更像 Monkey Mart 的"站位"而非拉面"管库存"。⛔ 不做"Rush Hour 限时冲刺"——本作纯放置，无手速爆发需求。 |

- **成熟标杆原型**：Monkey Mart 的"移动 + 站位"操作语言 + Diner Dash 的"多任务并行 + 心情张力" + Cat Cafe Manager 的"图鉴 + 菜单研制" + Cookie Clicker 的"指数成本 + 离线收益"——四源融合的成熟配方，不是闭门造车。
- **我们要继承的成熟机制**：移动=操作预算、站位=自动执行、指数成本曲线、帮工自动产线、离线结算弹窗、确定性配方解锁（零抽卡）。
- **本作的独特魅力与微创新**：
  1. **多猫掌柜轮值**——玩家可养 3 只喵掌柜（橘猫/三花/英短）轮班，每只猫有专属技能（橘猫 = 大力端盘/三花 = 敏捷擦桌/英短 = 咖啡大师），用金币或离线收益解锁下一只。
  2. **咖啡工艺链的实体化**：豆罐 → 烘焙机 → 研磨机 → 萃取机 → 拉花杯，五环工位都是吧台上的实体物件，每升一级工位本身变精致（金属锈蚀→红铜抛光→黄铜雕花），数值在其次、视觉在先。
  3. **窗口扩张而非市场迭代**：与 Monkey Mart 的"开新地图"不同，本作是"同一吧台 + 新窗口"的演进，扩张阶段 = 吧台物理形态生长（单吧台 → 外带窗 → 露台卡座 → 屋顶花园），玩家看着自己的店从一张桌长成一座咖啡馆。
  4. **喵咪"打盹演出"治愈细节**——助手猫咪在 30% 时间会"打盹"，但**永远不卡产线**：打盹期间工位自动降速到 50%，玩家可以花一个"小铃铛"（离线收益结算赠送）摇醒它恢复 100%——这种"被允许的懈怠"是治愈感核心。
  5. **离线收益的"想念桶"叙事**——回归弹窗不是金额数字，而是 3–5 个小木桶，每个桶代表"一只猫咪帮你收的小费"，点击木桶展开该猫的当日留言（"三花今天帮 3 位客人补了水～"），治愈感远胜数字本身。

## 3 · 玩法规则与交互说明

### 3.1 核心规则

**场景构成（猫咖吧台剖面舞台）**
- **五环生产链**（从左到右对应吧台实体工位，每环可雇猫猫自动化）：
  | 环节 | 工位 | 基础产出 | 帮工（猫掌柜） |
  |---|---|---|---|
  | N1 烘焙 | 烘焙机（咖啡豆烘焙） | 2 金/秒 | 烘焙学徒 Roasting Apprentice（橘猫专属） |
  | N2 研磨 | 研磨机（豆→粉） | 4 金/秒 | 研磨师傅 Grinder Master（三花专属） |
  | N3 萃取 | 萃取机（粉→浓缩） | 8 金/秒 | 萃取大师 Espresso Master（英短专属） |
  | N4 拉花 | 拉花杯（浓缩→成品） | 16 金/秒 | 拉花师 Latte Artist（解锁第 4 只猫时开放） |
  | N5 出杯 | 出杯窗（成品交付 + 收银） | 32 金/秒 | 收银员 Cashier Cat |
- **资源**：金币（货币）、咖啡豆库存（基础原料）、星标（解锁新喵咪的硬通货，由离线收益赠送）、猫粮（解锁新窗口的辅助资源）。
- **咖啡菜单**（首发 8 款，`data.mjs` 只存 key）：
  `drink_espresso` 浓缩 / `drink_americano` 美式 / `drink_latte` 拿铁 / `drink_cappuccino` 卡布奇诺 / `drink_mocha` 摩卡 / `drink_macchiato` 玛奇朵 / `drink_matcha` 抹茶拿铁 / `drink_sunset` 夕阳特调（隐藏：退休老猫解锁）。

**玩家合法操作**
- **移动 + 站位**（WASD / 方向键 / 触屏拖拽）：走到工位旁 = 自动执行该工位任务。
- **点击冲刺**：在拉花杯旁点一下 = 单次快速拉花（额外 +0.5×当前秒产）。
- **购买 / 升级工位**：金币足够时工位上方出现金色"+"按钮，点一下升级。
- **解锁猫掌柜**：星标足够时猫窝旁显示"领养"按钮。
- **领取离线收益**：回店弹窗，点击想念桶逐个领取。
- **解锁新窗口**：声誉达标时屋檐下出现新窗口的轮廓（金色光辉），点击投入金币展开。

**胜负判定与容错（无死局保证，硬性要求）**
1. **无失败条件**：客人永不"被赶走"，耐心归零只是损失当次小费；玩家永不破产。
2. **咖啡豆耗尽自动采购兜底**：任一原料不足，自动从金币扣 1% 补库存，**永不断产**。
3. **配方确定性解锁**：8 款饮品由"声誉等级 + 常客故事进度 + 累计研制次数"确定性达成，**零抽卡**。
4. **离线收益有上限**：初始 4h，声誉每级 +4h，封顶 24h。
5. **确定性经济**：成本/产出/离线全部纯函数计算；PRNG（`mulberry32`）仅用于客人排队演出（不影响收益）；需 ≥1000 步随机游走测试验证状态机在任意合法操作序列下不抛错、不卡死、不变式不破。

### 3.2 数值骨架（线下测试调整起点，制作人拍板终版）

- **成本曲线**：`cost = base × 1.15^owned`（每环独立计数，指数涨价、线性增产）。
- **每秒营业额**：`Σ(各环产出 × 帮工倍率 × 声誉倍率 × 窗口倍率)`。
- **离线收益公式**：`离线收益 = 每秒营业额 × 离线秒数 × 离线效率 × 阶段倍率`
  - 离线效率：初始 50%，购买"常亮招牌"升级后 100%。
  - **四档离线阶段倍率**（扩张阶段挂钩）：

  | 阶段 | 倍率 | 达成里程碑 |
  |---|---|---|
  | 第 1 阶段（单吧台） | ×4 | 全自动流水线（五环全部雇猫猫） |
  | 第 2 阶段（外带窗） | ×4 | 解锁外带窗口 |
  | 第 3 阶段（露台卡座） | ×4 | 解锁露台卡座 + 配方图鉴点亮 5 款 |
  | 终局阶段（屋顶花园） | ×218 | 达成"五星名店"（声誉 5 级 + 全图鉴） |

  - 叠加后**离线收益封顶倍率 = 4 × 4 × 4 × 218 = 13,952×**——与"日入破百万金币"的终局数值匹配。
- **声誉阶段**：街边小店 → 人气咖啡 → 网红打卡 → 城市名店 → 五星名店（5 级）。
- **猫掌柜轮值**：玩家初始领养 1 只橘猫；星标攒够领养第 2 只三花、第 3 只英短；第 4 只布偶猫需完成全图鉴后解锁。每只猫离线时自动上岗，玩家手动操控只能"使用" 1 只（轮换出战）。

### 3.3 模式与内容编排（依 Arcade Idle 特质定制）

**主线模式：扩张阶段制（4 阶段）**
- 单吧台 → 外带窗 → 露台卡座 → 屋顶花园，每阶段约 1–2 小时主动游玩 + 离线累积。
- 每阶段一张"喵掌柜心愿清单"（2–3 个目标，如"接待 50 位客人""解锁一款新咖啡""解锁第 2 只猫咪"），完成即推进阶段；未完成可继续挂机。
- 阶段推进 = 吧台物理形态生长 + 新窗口展开动画（窗框从墙面升起、阳光洒落）。

**支线模式一：常客喵咪图鉴**
- 12 位常客喵咪各有姓名/职业/咖啡偏好（加班程序员猫要黑咖啡 / 失眠作家猫要燕麦拿铁 / 退休老猫要点夕阳特调 / 瑜伽老师猫要抹茶 / 网红博主猫要拉花 / 大学生猫要美式 / 情侣猫要点双人套餐 / 雨天路人猫要点热可可 / 小学生猫要儿童卡布 / 实习医生猫要脱因 / 钢琴家猫要点焦糖玛奇朵 / 流浪汉猫要点免费美式）。
- 喂对口味的咖啡 → 解锁图鉴页 + 永久小费倍率 +1%。

**支线模式二：咖啡菜单图鉴**
- 8 款咖啡点亮图鉴；研制成功有"菜单黑板更新"动画 + 吧台灯光亮起一颗星。
- 全图鉴 + 声誉 5 级 = 五星名店终局成就，解锁屋顶花园终局阶段。

**支线模式三：离线想念桶回归演出**
- 每次回归弹窗 3–5 个木桶，每个桶对应一只猫咪帮手当日的"代班日志"。
- 点击木桶 = 该猫留言 + 桶内小费结算 + 喵咪打盹立绘 → 玩家可以选择"摇铃"（消耗星标）唤醒它恢复 100% 产速，或"让它再睡会儿"（演出治愈 + 产速降 50% 至玩家亲自上线）。

> **明确不做**：每日挑战（单机网页门户无每日刷新意义）、无尽冲分排行榜、失败惩罚（Arcade Idle 无败局）、手速记忆点单（与 Monkey Mart "站位=自动"哲学相悖）。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：午后暖光治愈、木质吧台剖面、喵咪伙伴养成、咖啡工艺实体化、念想桶离线结算。
- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**：
  - **整屏 = 一间猫咖剖面舞台**：左主舞台是从侧面切开的一间猫咖（吧台 → 烘焙区 → 客席 → 窗外露台/花园），玩家看到的是**工位物理形态**而非"格子地图"。吧台是木质的，烘焙机是红铜大炮，研磨机是老式手摇，萃取机带木把手，拉花杯是陶釉杯。窗外是午后暖阳 + 飘落的花瓣 / 落叶 / 雨丝粒子。右侧一体化为"喵掌柜值班表 + 念想桶清单 + 工位状态"造型 HUD（喵咪照片 / 状态图标 / 待办工位 / 离线想念桶横幅），操作按钮做成实体道具键（"升级工位"是木匠锤、"领养新猫"是纸箱、"展开新窗"是木窗框）。
  - **禁止四角浮动按钮**：顶部一条"屋檐门牌"状态条内嵌返回首页、音效、语言、规则说明；底部"咖啡店地垫"展示出战猫的脚印与状态。
  - **桌面端（≥900px）**：主舞台居中（总宽 ≤1100px），两侧午后暖光虚化 + 咖啡蒸汽粒子形成景深；左右边缘与底部边缘不放置任何操作按钮，为广告安全避让留白。
  - **移动端（≤768px）**：一体化掌机框体——吧台剖面在上、工位升级栏嵌底部面板；主容器底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，绝不让任何按钮贴底。
- **色彩与环境氛围**：
  - 主色：**午后奶油暖黄 + 木质咖啡棕 + 喵咪橘白 + 奶泡米白**（暖黄奶油为视觉主角；暖棕与站内 `ramen-idle` 的"墨夜靛蓝 + 暖橙灯笼"靠**日间奶黄 vs 深夜靛蓝**拉开距离，不占用蓝紫 / 青绿 / 天蓝 / 水色 / 珊瑚橙主色位）。
  - 交互反馈：咖啡液面上升 + 蒸汽粒子、收入数字 Bump 弹跳、阶段推进窗框升起、打盹演出猫咪慢镜头；按钮 = 木质实体微浮雕，悬停上浮 `translateY(-2px)`、按下下沉 `translateY(2px)`，配"咕噜"猫喉音合成。
  - 动效统一在 `prefers-reduced-motion: reduce` 下瞬移降级；可读性标记一律用无边界径向柔光，禁用描边圈。
- **声效风格与材质音色规划（严禁千篇一律蜂鸣器）**：
  - **5 种专属音效**（拒绝单振荡器 beep）：
    1. **冲咖啡蒸汽声**：白噪声缓冲 + BiquadFilter 高通（>2kHz）+ 低速 LFO 调制 → 浓缩机嘶嘶声、蒸汽升腾感；
    2. **拉花奶泡细腻声**：粉噪声 + 带通滤波（800Hz–2kHz）+ 快速 Attack → 牛奶倒入的细密泡沫声；
    3. **猫咪呼噜治愈音**：低频正弦 30Hz + 60Hz 双振荡器失谐 + 长 Attack/长 Release → 猫喉音咕噜咕噜（打盹演出专属）；
    4. **金币"叮"声**：FM 调频合成（载波 880Hz，调制 1320Hz，调制深度 200Hz）→ 温润编钟音色；
    5. **窗框展开仪式音**：木块碰撞噪声 + 低通滤波 + 短 Attack → 木窗推开的厚重感；
    6. **想念桶开启音**：陶罐软木塞拔出（粉噪声 + 短包络 + 共鸣腔模拟）→ 治愈回归仪式。
  - **绝不用**千篇一律的 C-E-G-C 琶音；主旋律用五声音阶 + 大七和弦，午后治愈基调。
- **封面设计提案**（遵循 `docs/COVER-STYLE.md`）：
  - 3D 软胶，单一居中主体（约 65%）：**一只橘白喵掌柜戴着咖啡师围裙、双手端着一杯冒着蒸汽的拿铁、尾巴轻轻摇晃**，旁边浮着一颗咖啡豆 + 一颗奶泡；
  - 背景：**午后奶油暖黄 → 烘焙棕**对角渐变，散布漂浮咖啡豆 / 奶泡 / 蒸汽粒子；
  - 无任何文字、无 logo、右下角无水印，640×640 WebP，左上主光、投影短而软。
