## 1 · 创意概念与核心乐趣

- **游戏名称**：切肥皂解压 / Soap Cutting ASMR / slug `soap`
- **一句话玩法**：拖动小刀切削肥皂，听清脆刮擦声解压（≤30 字）
- **核心乐趣与卖点**：刀刃划过肥皂的阻尼手感 + 清脆刮擦 ASMR 音效 + 薄片层层卷落的视觉满足。三重感官同步是核心爽感：手上“切得动”、耳边“沙沙脆”、眼里“片片落”。无目标压力、无失败，纯粹为了切着舒服、听着舒服。
- **核心循环**：选一块肥皂（颜色/造型）➔ 按住拖动刀刃切削 ➔ 薄片卷落、刮擦声随速度/厚度变化 ➔ 肥皂逐渐变薄/露出内芯造型 ➔ 切尽或造型达成触发完成仪式 ➔ 换下一块。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
  - **切肥皂 ASMR 短视频（抖音/B站/YouTube）**：真人用小刀把整块肥皂切成薄片、碎屑，核心是刮擦声与碎屑纷飞的解压感；最受认可的是声音质感（脆、沙、绵密）与“切得干净利落”的视觉节奏。
  - **Soap Cutting 类手游**：程序化网格切削肥皂块，拖动切削、碎屑物理飘落；最受认可的是切削手感（阻尼感、薄片卷起）与完成判定（切尽/切出造型）。
- **我们要继承的成熟机制**：程序化网格切削（刀刃轨迹决定切掉的体积）、碎屑/薄片粒子飘落、刮擦音效随切削速度与厚度实时变调、完成判定（体积切尽百分比 / 内芯造型露出）。
- **本作的独特魅力与微创新（Twist）**：
  - **音效即核心卖点**：刮擦声不是附赠，而是主角——按肥皂材质（硬皂脆、软皂绵、果冻皂弹）分三套音色，切削速度越快声音越密、切得越薄声音越脆，玩家是“用耳朵玩”的。
  - **内芯造型惊喜**：部分肥皂内藏小造型（星星、花朵、小动物轮廓），切到一定深度才露出，把“切尽”变成“开盲盒”。
  - **零解谜纯手感**：不设关卡谜题、不设失败，切得好不好看都行，舒服就行。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：
  - 按 `GEM_INSTRUCTION-4.md` 第二节 100 款已上架清单（`idiom` 至 `volley`）核对：全站无切削/ASMR 类游戏，本作是全新品类空白（调研指令第四节“现代热门机制”中亦将切肥皂列为高价值空白方向）。
  - 与最接近的存量游戏 **`screw`《拧螺丝解谜》** 的机制差异：`screw` 是“按顺序拧下螺丝、解开结构”的解谜，有正确顺序、有失败/卡关判定；本作无解谜目标、无正确顺序、无失败，核心是连续切削的阻尼手感与刮擦音效反馈，判定只有“切尽/造型达成”的完成度。规则模型完全不同。
  - 与 **`cut-the-rope`《割绳子》** 的差异：`cut-the-rope` 是物理解谜（割绳时机决定糖果落点）；本作切割无物理谜题，切削轨迹只影响碎屑与声音。

## 3 · 玩法规则与交互说明

- **核心规则**：
  - **盘面/场景构成**：一块肥皂居中大特写（圆角矩形/造型皂，2D 侧视带厚度感），下方是木质切板；肥皂内部是程序化网格（体素/分层网格），刀刃轨迹扫过的网格被切掉、生成薄片碎屑粒子；顶部完成度（已切百分比/造型露出进度）。
  - **玩家合法操作**：按住鼠标/手指拖动，小刀跟随轨迹切削；可调刀刃角度（倾斜切出卷片、垂直切出碎屑）；可选工具：小刀（薄片）、刮刀（大面积刮）、刨子（均匀薄层）。
  - **胜利条件与失败条件**：切尽（剩余体积低于阈值，如 ≤5%）或内芯造型完全露出即完成，触发完成仪式；**无失败条件**，切歪、切碎都不惩罚。
  - **容错与无死局说明**：随机造型保证可完成——内芯造型按网格预生成、深度可达，不存在切不到的内芯；切尽判定按剩余体积百分比，边角残屑可一键“收尾刮净”或自动吸附清除，不会因几粒碎屑卡住无法完成；玩家可随时换新一块，不会死局。
- **操作与手感**：
  - 鼠标/触控：按住拖动切削，速度决定薄片厚度与声音密度；松开停刀。
  - 键盘快捷键：数字键 1–3 切工具；`P`/`Esc`/`Space` 暂停/继续（本作无倒计时，暂停主要冻结粒子与音效）；`R` 换新一块。
  - **随时可暂停与失焦保护机制**：本作是无时间压力的纯手感玩法，天然静止，无需强制常驻暂停按钮；但仍提供轻量暂停入口（顶栏按钮 + P/Esc/Space），暂停时冻结碎屑粒子与刮擦音效、展示轻量覆盖层；切标签页/最小化（`visibilitychange`）自动静默冻结粒子与音效，回来继续，不丢进度。若未来加计时模式，必须常驻实体暂停按钮并冻结计时。
  - 误触容错：拖出肥皂区域刀刃自动抬起不切空气；快速乱划只产生碎屑不报错。
- **即开即玩与平滑选关设计（Instant Play）**：
  - **首屏秒进对局**：打开直接呈现第 1 块肥皂就绪盘面，小刀默认选中，按住即可切，严禁全屏选关/模式遮罩。
  - **常驻显眼选关入口**：顶栏常驻「选皂」/「模式」按钮，点击以轻量抽屉展示肥皂图鉴（颜色/材质/造型分组）；完成结算面板提供「下一块」与「选皂」。
  - **严禁强制全屏遮罩阻塞首屏**。
- **模式与内容编排（严禁套路化）**：
  - **自由切削模式（默认）**：肥皂图鉴制，如「经典方皂」（白/粉/蓝/绿）、「果冻皂」（半透明弹润）、「造型皂」（内藏星星/花朵/小动物），切尽一块解锁下一块；评级看完成度与切削细腻度（薄片均匀度），不看总分。
  - **造型挑战模式（可选）**：按轮廓提示切出指定造型（如切出心形），有完成判定但无失败惩罚；**不设每日挑战、不设无尽冲分**。
  - 内容递进靠材质手感与内芯造型复杂度，不靠堆倒计时。
- **游戏目标与反馈体系**：
  - 核心指标：已切百分比 + 内芯造型露出进度；不看总分。
  - 阶段反馈：薄片卷落时碎屑飘散+刮擦声；内芯露出时轻闪+提示音；整块完成时碎屑礼花+完成音效+成品展示（造型皂展示完整内芯）。
- **双语核心词汇与数据键名规划**：
  - 模式：自由切削 Free Cut / 造型挑战 Shape Challenge
  - 肥皂：如 经典方皂 Classic Bar；果冻皂 Jelly Soap；星星造型皂 Star Soap
  - 工具：小刀 Knife / 刮刀 Scraper / 刨子 Peeler
  - 材质：硬皂 Hard Soap / 软皂 Soft Soap / 果冻皂 Jelly Soap
  - 数据层约束：肥皂、工具、材质一律用字符串 key（如 `soap_classic`、`tool_knife`、`mat_hard`），展示层走 i18n，严禁裸写中文；语言切换原地热更新，严禁 `location.reload()`。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：木质切板、粉彩肥皂、薄片卷落、清脆刮擦、治愈 ASMR
- **专属视窗物理隐喻**：**单块肥皂居中大特写 + 木质切板承托 + 底部工具托盘**的“切皂台面”形态——像在手工皂台面上对着一块皂下刀。严禁左右双翼三栏套路，严禁四角散落浮动按钮，严禁右侧 SaaS 表单卡片堆叠。背景是柔和浴室/手工台氛围，碎屑落在切板上堆积，整体是一个完整台面场景。
- **立体质感与渲染路线裁决**：**Canvas 2D + CSS 3D 厚度感**（肥皂用 Canvas 网格切削+碎屑粒子，厚度与卷片用 CSS 3D/阴影模拟），UI 层用 DOM。95% 路线内，不上 Three.js——本作是平面切削玩法，不需要真 3D 空间翻转。若未来要做 360° 旋转切皂，必须锁死三条红线（零外部 3D 模型、轻量材质低发热、UI 留 DOM 层），本期不启用。
- **声效风格与材质音色规划（4–6 种，刮擦音是核心卖点，拒绝单音蜂鸣）**：
  1. **刀刃刮擦声（核心音）**：噪声滤波合成的“沙沙脆”刮擦，随切削速度变密、随薄片厚度变脆；硬皂偏脆、软皂偏绵、果冻皂偏弹，三套音色参数
  2. 薄片卷落声：薄片脱离时轻“簌”一声 + 落到切板细碎声
  3. 碎屑洒落声：颗粒噪声短促洒落（刮刀大面积时）
  4. 刀刃入皂声：切入瞬间的轻“咔”阻尼声
  5. 内芯露出提示音：清脆玻音单声（FM 合成）
  6. 整块完成音：碎屑礼花沙沙声 + 轻柔马林巴收尾
  - 明确拒绝单振荡器 beep 与 C-E-G-C 琶音套路；刮擦声必须用物理噪声滤波实时合成、随操作参数连续变化，这是本作的听觉灵魂。
- **封面设计提案**：3D 软胶质感，单一居中主体——一块粉彩圆角肥皂被小刀切出一片卷起的薄片，碎屑点缀；鲜艳粉蓝渐变背景；主体占 60–75%，无文字。

## 6 · 制作人拍板与开放探讨

1. **选项一（音效投入）**：方案 A 刮擦声做满三套材质音色+速度/厚度实时变调（核心卖点拉满） vs 方案 B 先做一套通用刮擦声、二期再分材质。推荐 A，音效是本作命门。
2. **选项二（造型挑战）**：方案 A 首期只做自由切削+内芯惊喜，造型挑战二期再加 vs 方案 B 首期双模式齐发。推荐 A，先把手感与声音做扎实。
3. **选项三（肥皂图鉴规模）**：方案 A 首期 12 块（经典/果冻/造型各 4） vs 方案 B 首期 24 块大图鉴。推荐 A，小而精、每块手感都调过。
