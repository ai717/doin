## 1 · 创意概念与核心乐趣

- **游戏名称**：迷你大富翁 · 掷骰夺城 / Mini Richman · Dice City Duel / 建议 slug：`richman`（单个简短纯英文单词，符合 slug 极简契约；也是华语玩家最熟悉的“大富翁”系列英文名，无歧义）
- **一句话玩法**：掷骰走格、买地收租、用道具坑对手，先让对手破产就赢，5~8 分钟一局。
- **核心乐趣与卖点**：
- 童年共鸣最强的一类棋盘游戏：几乎每个中文玩家都玩过大富翁，规则零学习成本，英文规则也零门槛；
- 爽感来自三层叠加：买下整条街的收集快感、对手踩上你的地交租的报复快感、遥控骰子 + 陷阱道具精准坑人的整活快感；
- 每局 5~8 分钟，节奏快、翻盘点多，输赢不到最后一刻不知道，天然适合“再来一局”。
- **核心循环**：掷骰 ➔ 走格 ➔ 买地 / 交租 / 触发事件 ➔ 集齐同色地块盖屋加租 ➔ 攒钱买道具坑对手 ➔ 对手现金见底破产 ➔ 结算资产战报 ➔ 再来一局 / 挑战更高 AI。

## 2 · 经典标杆与对标参考

- **成熟标杆原型**：
- **经典大富翁 Monopoly / 大富翁 Richman 系列（Softstar）**：掷骰环形棋盘、买地收租、集齐同色建房加租、破产出局，是整个品类的规则母本。最受认可的机制是“同色成套才有质变”（单块地租金平平，成套 + 盖屋后租金翻倍），以及“路过起点领钱”的小确幸循环。
- **Monopoly GO（Scopely，2023 年上线）**：把经典大富翁改造成手机快节奏循环的现代变体——掷骰是核心资源，地块按颜色成组，升级地标推进城市主题棋盘，铁路格触发“关停 / 银行劫案”小游戏，护盾抵挡对手攻击。证明了“大富翁可以压缩成几分钟一局的碎片玩法”，且短局 + 事件格 + 攻防道具是现代玩家接受的形态。
- **我们要继承的成熟机制**：
- 环形棋盘 + 双骰前进 + 同色成套加租（状态机清晰，胜负一目了然）；
- Monopoly GO 的“短局化”思路：不做几小时的长局，每局设回合上限，到点按资产判胜；
- 事件格的“小游戏感”：铁路格 / 机会格触发一次性的小抉择或小事件，打破纯走格的单调。
- **本作的独特魅力与微创新（Twist）**：
- 平台完全空白的赛道：掷骰买地 + 道具陷害 + 资产破产博弈，站内尚无同类；
- “陷害”做成明牌博弈：路障、遥控骰子、查税卡等道具全部可见、可针对、可反制，坑人靠算计不是靠运气；
- 同屏双人 + AI 两种对战：1v1 / 1v2 AI 单人挑战，同屏双人轮流掷骰，一台设备就能面对面玩；
- 资产战报适合截图传播：结算一张图写清“谁的地最多、谁交租最多、哪步翻盘”，天然有分享点。
- **品类差异化定位（类型允许重复，杜绝一模一样）**：与站内棋盘 / 卡牌 / 策略类游戏同属大类，但规则模型截然不同——本作是“经济博弈 + 位置博弈”的掷骰棋盘，不是纯消除、纯卡牌或纯解谜；胜负不靠消除连击，靠资产碾压与破产判定，坚决杜绝换皮。

## 3 · 玩法规则与交互说明

- **核心规则**：
- **盘面构成**：环形棋盘 24 格（见拍板项一，可改为 28 格标准局）。格子分五类：地块格（4 组颜色，每组 3 格，共 12 格）、起点格（路过领钱）、事件格（命运 / 机会，各 2 格）、功能格（道具店、银行、监狱 / 休息站各 1 格）、陷阱格（2 格，踩中按当前陷阱结算）。
- **玩家合法操作**：轮到自己时点“掷骰”按钮（或按空格），棋子按点数前进；落在无主地块可选择购买或放弃；落在自家地块可选择升级（盖屋，限同色成套后）；落在他人地块自动交租；道具在自己的回合开始前使用（每回合限用 1 张）。
- **胜利条件与失败条件**：任一玩家现金 + 地块估值耗尽（交不起租且无地可抵押）即破产，另一方直接获胜；若 30 回合无人破产，按双方总资产（现金 + 地价 + 房屋价值）高低判胜。
- **容错与无死局说明**：本作无随机生成关卡，骰子随机只影响落点，不产生死局；交不起租时可按顺序自动抵押地块（先抵押未成套的低价地），抵押后仍可赎回；30 回合上限兜底，任何一局都不会无限拖局。
- **经济数值（初版建议，开发时可微调）**：初始现金 1500；路过起点领 200；地块价 100~300 按颜色递增；租金 = 地价 × 20% ×（1 + 房屋等级），同色成套后租金翻倍；盖屋 100 / 级，每块地最高 3 级。
- **道具（初版 6 种，道具店购买，每人最多持 3 张）**：路障卡（指定前方 3 格内设障，对手踩中停一回合）、遥控骰子（自选 1~6 点）、查税卡（对手按资产 10% 交税进银行）、均富卡（双方现金拉平取均值）、免租卡（下次免交一次租）、换地卡（与对手交换一块未成套的地）。
- **操作与手感**：
- 鼠标点按掷骰 / 买地 / 道具，触屏同理；空格键掷骰，数字键 1~3 快捷用道具，P / Esc 暂停；
- 掷骰有 0.6 秒滚动动画 + 落点高亮，买地有盖章动效，交租有金币飞入对方钱包的动画，反馈必须一眼看懂；
- 误触容错：买地 / 盖屋 / 用卡前有一次确认浮层（轻量非阻塞），点错可撤销到掷骰前。
- **随时可暂停与失焦保护机制**：本作是回合制静态棋盘，天然无倒计时压力，但 AI 回合有思考动画、骰子有滚动动画——顶栏常驻醒目的「暂停 / 继续」按钮与 P / Esc / 空格快捷键，暂停时冻结 AI 回合与一切动画并显示轻量半透明遮罩（继续 / 重新开始）；切标签页或最小化时自动静默暂停，回来后局势原样不动。
- **即开即玩与平滑选关设计**：初次打开直接进入第 1 局（对手为新手 AI），棋盘与双方资产直接就绪，无需前置点击；顶栏常驻醒目的「模式」按钮，点击以轻量抽屉展示模式与 AI 难度；结算面板提供「再来一局」与「换模式」。
- **模式与内容编排（依玩法特质定制，不套无尽冲分）**：
- **快速对战（默认）**：1v1 AI，5~8 分钟一局；
- **1v2 AI 挑战**：同时打两个 AI，胜负按破产顺序算，更考验运营；
- **同屏双人**：两人轮流掷骰，一台设备面对面玩；
- **AI 阶梯**：新手 / 进阶 / 大师三档——新手随机买地、大师会优先成套、留现金防破产、针对性用卡；胜场解锁下一档。
- **游戏目标与反馈体系**：核心指标不是总分，而是**总资产净值**与**破产用时**；胜场、成套数、单局最高租金三项记入战绩；胜利结算时播放“城市灯光逐格点亮”的仪式动画，失败结算展示“翻盘点复盘”（哪回合开始资产被反超）。
- **双语核心词汇与数据键名规划**：
- 模式：快速对战 Quick Match / 同屏双人 Local 2P / AI 阶梯 AI Ladder；
- 实体：地块 Property / 租金 Rent / 破产 Bankrupt / 道具店 Item Shop / 路障 Roadblock / 遥控骰子 Remote Dice / 查税卡 Tax Card / 均富卡 Equalizer / 免租卡 Rent-Free Card / 换地卡 Swap Card；
- AI 等级：新手 Novice / 进阶 Skilled / 大师 Master；
- 数据层约束：所有地块、道具、难度数据一律用字符串 key 或 id（如 `block_blue_1`、`card_tax`），展示层通过 `i18n` 获取文本，严禁在数据文件里裸写中文。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

- **题材风格关键词**：微缩城市沙盘、地产大亨、桌面棋盘、童年共鸣、明亮轻快。
- **专属视窗物理隐喻**：**“桌面上的微缩城市沙盘”**——整个界面就是一张摆在桌面上的立体城市模型：环形棋盘是微缩街区，地块上立着可升起的小房子（CSS 3D 抬升），中央是城市公园小广场（放骰子与回合信息），顶栏是一条“资产仪表盘”横幅（现金、地块数、净值三项像仪表读数一样排开）。拒绝左右双翼三栏套路，棋盘居中、信息围着棋盘走。
- **立体质感与渲染路线裁决**：纯 DOM + CSS 3D 为主（棋盘格、地块房屋升起、骰子翻滚用 CSS 3D transform），Canvas 2D 只做金币飞溅与胜利礼花粒子。**不采用 Three.js**——棋盘是俯视平面，无真三维空间翻转需求，CSS 3D 已足够且秒开零发热。
- **声效风格与材质音色规划（4~6 种，拒绝单音蜂鸣器）**：
- 掷骰滚动：木质骰子在桌面滚动的闷响（物理噪声滤波）；
- 买地盖章：橡皮图章“嘭”的一声 + 纸面摩擦；
- 收租进账：金属金币叮当落袋（失谐多振荡器轻敲）；
- 陷阱触发：弹簧“嘣” + 滑稽下坠音；
- 破产警报：低沉警铃两声 + 玻璃碎裂轻响；
- 胜利结算：FM 编钟上行琶音 + 礼花噼啪。
- **封面设计提案**：3D 软胶质感、单一居中主体（微缩城市沙盘一角 + 一颗大骰子，占 60~75%，无文字）、鲜艳渐变背景（暖黄到天蓝的城市晨光）。

## 6 · 制作人拍板与开放探讨

1. **棋盘规模：24 格快局 vs 28 格标准局**——方案 A：24 格（12 块地），一局 5~8 分钟，节奏最快，最贴合“迷你”定位；方案 B：28 格（15 块地，多一组颜色），一局 8~12 分钟，运营深度更好，但更拖沓。推荐 A。
2. **陷害道具的强度：全开 vs 新手局先收着**——方案 A：6 种道具全部开放，坑人拉满；方案 B：新手 AI 局默认关闭“均富卡 / 查税卡”这两张最狠的卡，进阶起再开放，避免新手第一局就被翻盘劝退。推荐 B。
3. **美术题材：现代都市沙盘 vs 童话糖果城**——方案 A：现代都市微缩沙盘（写字楼、居民楼、公园），贴合“地产大亨”身份，共鸣直接；方案 B：童话糖果城（姜饼屋、糖果铺），视觉更甜、更适合低龄与家庭同屏。推荐 A，B 可作后续换皮主题。
