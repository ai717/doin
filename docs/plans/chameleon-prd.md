## 1 · 创意概念与核心乐趣

- **游戏名称**：变色躲猫猫 / Chameleon Hide（副标：变色伪装 · 回合博弈）/ 建议 slug：`chameleon`
- **一句话玩法**：变色龙混进萤火丛林集会，不断换色融入环境躲避猎手；猎手睁眼后扫探、圈记、指认——谁先看穿谁？
- **核心乐趣与卖点**：
  - **双盲博弈的压迫感（Blind Trust Duel）**：同屏双人，猎手必须真的"闭眼"——幕布落下、倒计时滴答，变色龙在黑暗里 3 秒内完成移动与换色。揭幕瞬间，猎手扫视全场找那一丝不协调：这是面对面心理战，不是单机找茬；
  - **变色伪装的物理直觉（Camouflage Craft）**：变色龙的变色不是按钮——它的颜色必须向所在区域的"萤光平均色"收敛，收敛要时间、移动会留波纹。藏得越深，动得越少；动得越多，破绽越大。每个选择都是"藏"与"活"的权衡；
  - **猎手的侦探推理（Detective Loop）**：扫探有噪声、指认有代价。相信波纹线索还是信任位置记忆？先圈可疑格再指认，还是孤注一掷？判断力本身就是武器；
  - **现象级"找不同"爆款 DNA（Spot-the-Fake DNA）**：人群里找伪装者——这个一眼懂、人人会上手的认知博弈内核，加上回合轮换与角色扮演，做成"投币就想再来一局"的快节奏派对局；
  - **全站首款"隐藏—发现"博弈**：DOIN 62 款游戏中不存在任何隐藏-发现品类，本作以全新博弈维度补位。
- **核心循环**：
  ```
  回合开始（光相位轮转）➔ 幕布落下·倒计时 ➔ 变色龙移动/换色（留波纹·收敛融合度）
       ↑                                                          ↓
  揭幕·猎手扫探（有限侦察点 + 噪声热度）← 猎手观察全场找破绽 ← 变色龙融入萤光人群
       ↓
  猎手指认：指对=抓获得分（换角色）｜指错=变色龙得分｜放弃=回合继续
       ↓ （6 回合后角色轮换）总比分决胜负 ➔ 再来一局
  ```

**我们要继承的成熟机制**：
1. **闭眼-倒计时-睁眼的三拍节奏（Hider's Countdown）**：继承捉迷藏"闭眼数数"的仪式感——幕布、滴答声、揭幕，天然制造紧张与信任博弈；
2. **有限侦察与限次指认（Bounded Probe & Accuse）**：猎手每回合固定侦察点、指认有代价——继承"找不同"的限次压迫，杜绝无限试错；
3. **角色轮换与比分制（Role Swap & Score）**：变色龙与猎手各打一局、总比分决胜负——继承桌游与社交推理的公平轮换，让两种乐趣都被体验；
4. **确定性种子与数值钳制（Seeded Fairness）**：棋盘、光相位、扫探噪声、AI 决策全走确定性种子，融合度与热度恒在 0–100，杜绝不可测的死局与玄学。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **融合度收敛物理（Blend Convergence）**：变色不是瞬移，而是向所在邻域平均色**逐帧收敛**——收敛要时间、移动会打断，把"藏得好"变成可计算的物理技能而非心理安慰；
2. **移动波纹破绽（Ripple Tell）**：变色龙移动瞬间在起落点留下**渐隐波纹**，睁眼后的前 1.5 秒猎手可见——用"移动破绽"换取"位置灵活"，藏与活永远二选一；
3. **光相位轮转（Light Phase）**：每回合开场全场色彩随萤光相位漂移，变色龙被迫每回合重新校准——天然防止"开局定终身"的站桩，强迫持续博弈；
4. **噪声扫探（Noisy Probe）**：侦察点返回含确定性伪随机噪声的热度值，猎手永远无法靠单点实锤，必须交叉验证——侦探感拉满且可测试；
5. **侦察手账视窗（Field Journal）**：把整局游戏装进一本摊开的牛皮纸侦察手账，放大镜扫探、红蜡笔圈记、标本贴纸记分——"隐藏-发现"的题材原生形态，全站无同款视窗。

## 3 · 玩法规则与交互说明

### 3.1 场景构成（萤火丛林集会，俯视 2D）
- **集会场地**：5×5 格（25 个萤光居民站位），每格一只"萤光居民"（发光小生物装饰，非可操作对象），每只颜色属于 **5 色萤光盘**（暖黄 / 薄荷 / 紫罗兰 / 珊瑚橙 / 冰蓝）；
- **变色龙（Chameleon）**：玩家控制的隐藏者，占据其中一格，同样是一只会变色的居民——但它的颜色由玩家操控，可向邻域平均色收敛；
- **光相位（Light Phase）**：每回合开始，全场居民颜色随相位漂移（同一色盘内的亮度/色相偏移一档），变色龙必须跟随校准，否则融合度自然衰减；
- **侦察手账（HUD 容器）**：上方是摊开的牛皮纸手账页——左侧手绘观察窗（5×5 集会场地实景），右侧侦察工具区（侦察点计数、指认按钮、回合小旗、比分牌），底部是伪装阶段变色盘。

### 3.2 回合流程（6 回合制 · 角色轮换）
1. **揭幕观察（1.5s）**：回合开始，猎手睁眼视角下短暂显示上一回合残留的**移动波纹**（若有，半透明渐隐）——这是猎手的第一信息源；
2. **光相位轮转**：全场颜色漂移一档，融合度低于阈值的变色龙轻微"显形"（亮度闪烁 0.3s）——暗示伪装者在动；
3. **伪装阶段（3s 幕布）**：屏幕落下"侦察员请闭眼"幕布 + 3-2-1 倒计时，变色龙操作：
   - **移动**：向相邻格移动 1 步（每回合限 1 步），移动瞬间在起落点各留一道**波纹**（持续至下回合揭幕后的 1.5s）；
   - **换色**：在 5 色萤光盘上移动 1 档，或选择"精调"（不动则向所在 3×3 邻域平均色收敛 +15% 融合度）；
4. **观察阶段（猎手行动）**：揭幕，猎手自由扫视全场，消耗**侦察点**：
   - **扫探（Scan）**：每回合 2 点。点击一格 = 消耗 1 点，返回该格"异常热度"0–100（含确定性噪声 ±8）——融合度越低热度越高，但噪声让单点不可实锤；
   - **指认（Accuse）**：消耗 1 点，点击目标格指认。**正确 = 抓获**；**错误 = 变色龙 +1 分**，猎手失去本回合剩余侦察点；
   - **放弃（Pass）**：不指认，回合自然结束；
5. **回合结算**：变色龙未被抓获 → 变色龙 +1 存活分；抓获 → 猎手 +3 分并**立即进入下一角色局**；
6. **角色轮换**：6 回合（半局）后互换角色再战 6 回合，**总比分高者胜**；平局进入"突然死亡回合"（第 13 回合，变色龙移动限 1 步、猎手仅 1 侦察点）。

### 3.3 模式与内容编排（拒绝套路化三件套）
- **同屏双人派对局（Chameleon Duel，核心模式）**：上述 6+6 回合角色轮换制；单局约 3–4 分钟，投币式"再来一局"；记录本次会话双方胜场；
- **单人猎手战役（Hunt the Impostor）**：玩家扮演猎手，AI 变色龙按 **5 档智商**递进（侦察新手 → 老练伏击者 → 伪装大师），每档 2 张种子棋盘共 10 关；评价体系 = **星级 + 指认用时**（★★★ = 3 回合内抓获且零误指），不做无尽冲分；
- **练习观察台（Practice Blind）**：无指认压力的纯观察模式——变色龙自己藏、自己找，用于理解融合度/波纹/光相位三机制，新手 1 分钟上手。

### 3.4 无死局与公平保证（数学可解性）
1. **落点可达性**：每张棋盘生成时断言——变色龙初始格与每回合至少存在 1 个相邻可融合格（邻域内存在同色盘 ≥2 只居民），不满足即丢弃重排；
2. **零盲猜死局**：猎手永远可通过"扫探 2 点 + 放弃"度过回合，不存在被迫盲指；噪声 ±8 保证热度排序有真信息但无实锤，侦探永远有事可做；
3. **确定性契约**：棋盘种子、光相位序列、扫探噪声、AI 决策全部注入确定性种子 PRNG——同种子逐帧一致、可重放、可测试；AI 有明确强度上限（伪装大师也不会 100% 无破绽，每回合必留 ≥1 处可被热度排序检出的弱融合格）；
4. **状态守恒**：全程仅 1 只变色龙、居民数恒定、回合数守恒；幕布阶段所有输入锁定（防偷看操作与误触），无 `alert()`，异常输入静默忽略。

### 3.5 操作与手感（键鼠触全通 + 输入缓冲）
- **伪装阶段（变色龙）**：
  - 桌面鼠标：点击相邻格 = 移动；点击变色盘 = 换色档；点击自己 = 精调（原地收敛）；
  - 键盘：`↑↓←→`/`WASD` 移动，`1–5` 直接选色档，`空格` = 精调；
  - 移动端：点击相邻格移动，点变色盘换色，点自己精调；操作窗口 3s 倒计时，输入缓冲 60ms（快速连点不吞指令）；
- **观察阶段（猎手）**：
  - 桌面鼠标：点击任意格 = 扫探（有侦察点时），再次点击同一格 = 指认（有指认点时），右键取消选中；`Esc` = 放弃/暂停；
  - 键盘：`↑↓←→` 移动扫描框，`空格` = 扫探，`Enter` = 指认，`Esc` = 放弃；
  - 移动端：点击 = 选中/扫探，选中的格子上滑 = 指认（防误触）；底部预留 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))` 广告安全避让区；
- **反馈手感**：扫探时放大镜"滴"声 + 热度环形读数弹出；指认瞬间高亮圈锁定；抓获 = 全场红蜡笔圈 + 短促震屏 + 抓捕音爆；伪装阶段幕布 = 牛皮纸遮罩缓缓落下 + 木质三下倒计时敲击。

## 4 · 题材原生视窗隐喻与音色质感（拒绝抄袭雷同）

### 4.1 题材风格关键词
**萤火丛林侦察手账（Firefly Field Journal）**、夜间墨绿丛林、发光蘑菇丛、牛皮纸手绘、红蜡笔圈记、萤火尘埃粒子。

### 4.2 专属视窗物理隐喻（严禁左右双翼模版）
本作不是"网页里嵌个找茬游戏"，而是一本**摊开的野外侦察手账**：

1. **手账即全部**：整局游戏是一本摊开的牛皮纸侦察手账——观察窗、变色盘、侦察点、记分牌、幕布全部是手账上的原生元素（手绘线条、标本贴纸、红蜡笔圈），**绝无四角散落浮动按钮、绝无右侧白底 SaaS 卡片堆**；
2. **幕布伪装仪式**：伪装阶段不是普通倒计时——一张牛皮纸幕布从观察窗上沿"唰"地落下遮住全场，倒计时三下木质敲击；揭幕时幕布上卷，波纹线索已在窗内静静闪烁，仪式感拉满；
3. **记分与回合**：变色龙存活分 = 窗边标本贴纸（一只小变色龙贴纸），猎手抓获 = 红蜡笔打勾；回合权 = 页脚一枚"侦察员小旗"；
4. **环境氛围**：窗外是深墨绿夜间丛林虚化背景，发光蘑菇丛、萤火尘埃微粒漂浮；窗玻璃微反光 + 观察窗边缘黄铜包边；拒绝死黑/死白大平铺；
5. **移动端（≤768px）**：观察窗全宽撑满，变色盘/侦察点收折为窗下木质工具条；底部严格预留广告安全避让区，绝不遮挡指认操作区。

### 4.3 立体质感与渲染路线裁决
- **裁决：纯 Canvas 2D 观察窗场景 + DOM/CSS 3D 手账框体**（不做 Three.js）：
  - 观察窗内（5×5 居民、变色龙、波纹、萤火粒子、光相位）→ Canvas 2D，120fps 秒开零发热；
  - 手账立体感（牛皮纸厚度、装订线、放大镜镜片、蜡笔笔触、幕布）→ 语义 DOM + CSS 3D（`perspective` / `transform`），HUD/记分/弹层全部严格留在 DOM 层；
  - 理由：俯视 2D 格网博弈天然是平面空间，无真 3D 视角需求，Three.js 无必要。

### 4.4 声效风格与材质音色规划（WebAudio 纯程序化合成，零外部音频文件）
| # | 事件 | 材质音色方案 | 合成手法 |
|---|---|---|---|
| 1 | **变色（Recolor）** | 湿润软胶"啵"——变色龙换色的标志音 | FM 调频合成（低频滑音 + 圆润包络），像水珠滴入 |
| 2 | **荧光脉冲（Ambient Pulse）** | 集会场的呼吸氛围音，随光相位微变调 | 柔和三角波 + LFO 慢起伏，大七和弦底色 |
| 3 | **扫探（Scan Probe）** | 放大镜侦察的短促电子"滴" | 带通滤波短脉冲 + 高音瞬态，随热度值音高微升 |
| 4 | **波纹/破绽（Ripple Reveal）** | 波纹渐隐时的"粼粼"细响 | 噪声缓冲 + 高通滤波扫频（sweep），像水面涟漪 |
| 5 | **抓获（Caught）** | 指认成功的瞬间爆发——低音 Kick + 火花 | 失谐双振荡器下潜 + 急促滑音包络，短促震屏配合 |
| 6 | **指错/幕布（Miss & Curtain）** | 指错失望低鸣；幕布落下"唰"声 | 失望=下行双音低鸣；幕布=噪声缓冲宽频 sweep 收束 |

> 严禁单调单振荡器 beep 或 C-E-G-C 琶音；音效全部程序化合成，静音或不支持时静默降级。

### 4.5 封面设计提案（遵循 `docs/COVER-STYLE.md`）
- **尺寸与格式**：640×640 纯 WebP，零文字；
- **主体构图**：单一居中主体，占画面 65%~70%——一只**3D 软胶小变色龙**蹲在发光蘑菇上，身体正从暖黄色渐变为薄荷绿（左右半身两色渐变），尾巴自然卷曲，头顶两粒亮晶晶的眼睛警觉地望向前方；
- **背景与氛围**：深墨绿至紫罗兰的平滑径向渐变背景 + 悬浮萤火粒子与虚焦光斑，蘑菇与苔藓细节温润，3D 软胶质感饱满——一眼传达"夜色丛林里的变色伪装"。

## 5 · 制作人拍板与开放探讨

请制作人（用户）对以下 3 个核心玩法设计进行拍板定夺：

### 拍板项 1：场景主题与视窗形态？
- **选项 A（萤火丛林侦察手账 · 推荐）**：夜间丛林 + 萤光集会 + 牛皮纸侦察手账视窗，题材最贴合"变色伪装"生物学隐喻，手账形态全站无同款；
- **选项 B（荧光派对舞池）**：变色龙混入荧光派对人群，变色由迪斯科灯光相位驱动，更潮更热闹；
- **选项 C（珊瑚礁潜水舷窗）**：变色龙鱼混入鱼群，潜水艇舷窗视窗，深海静谧质感。

### 拍板项 2：回合节奏与局制？
- **选项 A（6+6 轮换双人 + 单人战役双轨 · 推荐）**：同屏双人 6 回合角色轮换为主打，单人猎手战役（5 档 AI × 2 关）为附加，内容量完整、两种乐趣都被体验；
- **选项 B（纯双人快局）**：只做同屏双人 3 回合快局（含突然死亡），派对向最轻量；
- **选项 C（双人 + 单人双角色）**：双人之外，单人战役同时提供"猎手战 AI 变色龙"与"变色龙躲 AI 猎手"两个方向，内容量最大。

### 拍板项 3：伪装机制深度？
- **选项 A（移动波纹 + 融合度收敛 · 推荐）**：移动留波纹破绽、精调收敛融合度，双技能轴，"藏与活二选一"的博弈深度拉满；
- **选项 B（只做融合度）**：只有换色收敛，无波纹破绽，规则最简、上手最快；
- **选项 C（加诱饵技）**：在 A 基础上给变色龙"假波纹"技能（每局限 2 次，可凭空制造诱饵波纹误导猎手），心理战最浓、博弈最脏最爽。
