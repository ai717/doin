## 1 · 创意概念与核心乐趣

- **游戏名称**：割绳子 / Cut the Rope / 建议 slug：`cut-the-rope`（备选 `rope-candy`）
- **一句话玩法**：用指尖或鼠标如利刃划断绳索，利用重力摆动、浮空气泡与弹力机关，让摇摆的糖果收集三星并精准送入小怪兽口中。
- **核心乐趣与卖点**：
  - **优雅的向心摆动与切线切割爽感**：单根绳索是简单的单摆，两根以上绳索则构成受力张力平衡。看准糖果摆至最高点的临界瞬间“咔嚓”一刀切断，看糖果化作优美的切线抛物线飞出，带来极具成就感的物理预判快感；
  - **呆萌生动的怪兽情绪反馈**：蹲在箱底的绿色软胶小怪兽（Nommy）眼神随糖果轨迹灵动转动、张嘴焦急等待、吃到糖果时幸福眯眼吧唧嘴咀嚼，若糖果坠出屏幕则委屈耷拉耳朵，带来无与伦比的情感陪伴感；
  - **机关连锁的“多米诺效应”**：划断绳索 ➔ 糖果坠入气泡漂浮上升 ➔ 收集悬空星星 ➔ 气垫吹风改变航道 ➔ 刺破气泡坠入怪兽之口。步步递进的机关串联，让每道谜题都像一座精巧的鲁布·戈德堡机械玩具；
  - **直觉好懂、上限极高的三星收集**：喂饱怪兽即可通关（基础保障），但在动态抛物线轨迹中完美斩获 3 颗星星才是解谜大师的荣耀追求。
- **核心循环**：
  ```
  观察物理场景与机关布局 → 预判摆动轨迹与时机 → 划线切断绳索 / 戳破气泡
       ↑                                                      ↓
  下一关卡 / 挑战三星全收集 ← 小怪兽欢快咀嚼通关 ← 糖果沿预定轨迹收星并落入怪兽口中
       ↓ (切错时机或被尖刺击碎)
  糖果跌出屏幕 / 碎裂 → 小怪兽难过抱头 → 零惩罚瞬间重试本关
  ```

**我们要借鉴的成熟机制**：
1. **Verlet 积分或质点链绳索模拟**：绳索表现出自然的垂坠、张力拉扯与晃动，不仅是死板的一条线段，具备肉眼可见的物理柔顺感；
2. **划线切割检测（Line-Segment Intersection）**：玩家鼠标/触控拖曳产生的划痕轨迹与绳索线段做瞬时几何相交判定，划过即斩断，手感干脆利落；
3. **经典机关四件套**：
   - **基础悬挂绳索**：提供向心力与重力摆动；
   - **浮力气泡（Bubble）**：包裹糖果后赋予反向重力（平缓上升），点击气泡即可瞬间破裂恢复重力；
   - **吹气皮囊（Air Cushion）**：点击喷出一股锥形风力，推动邻近的糖果或气泡偏转；
   - **尖刺陷阱（Spikes）**：糖果碰触即碎裂，考验避障走位。

**本作的差异化微创新（拒绝无聊照搬）**：
1. **双栏沉浸式“微缩纸盒怪兽工坊”（Diorama Toy Workshop）**：
   - 彻底摒弃传统网页版狭长竖屏两侧死白的粗糙感。将游戏舞台设计为一个带有温润手作质感的**立体微缩瓦楞纸盒场景**；
   - 左侧机身嵌入“怪兽心情图鉴”与“星级收集胶卷”，右侧提供“物理机关透视雷达”与“切割刀痕光效切换”；
2. **关卡模式编排（拒绝无脑无尽化）**：
   - **主线冒险（Cardboard Odyssey · 32关精选）**：分 4 个主题纸盒（新手纸箱、气泡糖屋、弹簧机关谷、尖刺迷宫），每章引入核心新机制；
   - **一刀大师挑战（One-Cut Master · 残局模式）**：特殊解谜模式，限定每关**只能且必须切断一刀**，引发精密的物理连锁使糖果吃满三星入喉，烧脑度拉满；
3. **桌面端高精度切割手感**：
   - 桌面端支持平滑的鼠标刀光拖尾（带柔和发光粒子与“刃风”音效），支持【R】键 0 延迟秒重置当前关卡，让试错心流顺畅无阻。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景与物理元素构成**：
  - **物理重力环境**：固定向下的重力加速度 $g$，所有物理计算基于固定的 60Hz 帧步长（Fixed Timestep `stepFrame`），确保相同操作结果 100% 可重现；
  - **糖果（Candy）**：圆形刚体，具有质量、半径与弹性系数。初始状态被一根或多根绳索系住；
  - **绳索（Ropes）**：由一个固定锚点（木图钉）连接到糖果中心，具备最大张力长度，不可拉伸或轻微微弹性，在空中以单摆或复合摆自然运动；
  - **三颗星星（3 Stars）**：分布在关卡空中的不同悬赏位置，糖果几何重叠即可点亮收集，星星常放置在极限摆动抛物线的顶点或机关背后；
  - **绿色小怪兽（Nommy）**：位于关卡指定受力位置，拥有明确的吞食受力圆口判定区；
  - **障碍与机关**：气泡（浮空）、气囊（气流冲量）、尖刺（致命碰撞体）。
- **玩家合法操作**：
  1. **滑动划线切割（Slash Cut）**：
     - 鼠标左键按下并拖动 / 触控手指滑动：划出一道发光的切割轨迹刀痕；
     - 当切割线段与任意有效绳索发生空间相交时，该绳索即刻断裂，释放对应的张力约束；
  2. **轻点交互（Tap Object）**：
     - 点击包裹糖果的气泡：气泡清脆破裂（“啵！”），糖果重新受重力下落；
     - 点击吹气皮囊：皮囊压缩并向喷口方向喷射瞬时风力推力；
  3. **瞬时重置（Instant Reset）**：
     - 键盘按下【R】键或点击舞台内嵌重置键：当前关卡瞬间恢复初始状态，零等待重来。
- **胜利与失败判定**：
  - **通关胜利（Clear）**：糖果质心进入小怪兽张开的嘴巴判定区 ➔ 小怪兽吞入并满足咀嚼 ➔ 触发过关，结算本关收集的星星数（1~3 星）；
  - **单局失败（Fail）**：
    - 糖果掉落出屏幕视口底边缘；
    - 糖果碰撞到静止尖刺或危险障碍而碎裂；
    - 糖果脱离绳索后停止运动且未进入怪兽口中（静止死锁检测）；
    - 失败后小怪兽做出难过抱头表情，玩家点击屏幕或按 R 即可秒速重开本关。
- **数学可解性与物理确定性保证**：
  - 关卡完全杜绝随机要素！所有关卡的绳长、锚点坐标、星星位置、小怪兽位置均为精心设计的**绝对确定性几何数值**；
  - 每一关均经过自动化物理测试验证存在标准三星解法序列，绝不存在纯凭运气的玄学死局。

### 操作与手感细节

- **手感调校**：
  - **切割刀光拖尾（Blade Trail）**：刀痕带有从亮白渐变到青碧的光辉拖尾，速度越快拖尾越宽，并在断绳点爆发几枚细碎的火花光点；
  - **切断音效**：弦音断裂的清脆“铮/嘣”声，伴随切口绳头轻微收缩回弹；
  - **气泡触感**：气泡包裹糖果后带有柔和的半透明折射与微晃动浮力手感；
  - **怪兽眼神跟踪**：无论糖果在空中何处摆动，怪兽的大眼睛实时注视着糖果坐标，嘴巴根据糖果距离自动由微张到大张，拟真感十足。

### 模式与内容编排（两大模式，层次分明）

1. **纸盒奇遇主线（Cardboard Odyssey · 32关精选）**：
   - **第一章：新手纸箱（8关）**：熟悉重力摆动、单绳切断、双绳时序交替切断、直落下落；
   - **第二章：浮空气泡（8关）**：引入气泡反重力上升、多重气泡接力、在合适高度刺破气泡下落；
   - **第三章：气囊风暴（8关）**：引入方向吹气皮囊，利用风力将摆动糖果推向偏斜高处的星星；
   - **第四章：尖刺迷阵（8关）**：结合固定尖刺与摆动尖刺，考验极限切割时机与轨迹预判。
2. **一刀残局大师（One-Cut Master · 10关烧脑挑战）**：
   - 规则约束：每关**只能划一刀**（但一刀可切断多根绳索），必须依靠切断后的自动物理连锁与向心力惯性，一次性收齐 3 星并入喉！
   - 专为物理益智硬核玩家设计的极限脑力试炼。

### 目标与星级评价体系

- **单关三星标准**：
  - ★ 喂饱怪兽（顺利完成关卡）；
  - ★★ 收集 2 颗以上星星；
  - ★★★ 收集全部 3 颗星星；
- **全三星章节徽章**：单章节全 8 关满星（24 星）可解锁该章节专属的“黄金剪刀”光效与怪兽勋章；
- **存档内容**：本地保存关卡解锁进度、每关最高星级、全关卡累计最快通关时间。

## 4 · 美术风格与视觉氛围（微缩玩具箱，拒绝网页仪表盘）

- **题材与视觉关键词**：**手作微缩 · 瓦楞纸盒 · 软胶萌宠 · 澄澈糖果 · 物理童趣**
  （不做平庸廉价的平面 Flash 风格，不做冰冷赛博金属感；还原如同把玩桌面实体解谜玩具箱的温暖手感）。

- **桌面端双栏微缩舞台规划（≥900px 宽屏 / 移动端竖屏一体化）**：
  - **中央主舞台（Cardboard Arena）**：
    - 视口正中呈现一个精致立体的微缩瓦楞纸盒内部空间，箱壁带有柔和内阴影、折痕纸纹与顶部透射下的温暖聚光灯；
    - 绳索带有麻绳编织微纹理，图钉呈现复古软胶原木色彩，糖果晶莹剔透并带有高光折射；
    - 舞台顶梁内嵌复古木制挂牌：收纳【返回首页】、【关卡选择】、【瞬时重开】、【音效】与【语言】；
  - **左侧数据翼栏（HUD Left Wing · 怪兽日记）**：
    - 嵌合在纸箱侧翼：展示当前章节收集的星级总数（例：`★ 18/24`）、章节专属徽章成就；
    - 实时显示当前关卡目标与已吃到的星星数（3 颗立体的软胶金色五角星图标）；
  - **右侧机关说明翼栏（HUD Right Wing · 物理工具箱）**：
    - 动态解析当前关卡出现的机关特性（如“气泡：反重力悬浮，点击戳破”）；
    - 桌面端快捷键指引：【R】一键重来，【Space】快速选关；
  - **移动端适配**：
    - 左右翼数据收缩为箱顶下方的紧凑吊牌，纸盒视角自适应竖屏宽度，手指划线区域留足视野空间，绝不遮挡下落判定。

- **色彩与环境光晕**：
  - **外部环境背景**：温润深栗色桌面渐变 `#2b211b → #181310`，衬托出中央亮堂温暖的纸盒工坊；
  - **纸箱内壁**：暖米黄瓦楞纸质感 `#EFE3C3` 搭配深色纸板侧边；
  - **主角怪兽**：活力牛油果绿 `#78C236` 软胶体，配纯白大眼睛与黑色灵动瞳孔；
  - **糖果配色**：经典的红黄相间旋涡硬糖或草莓波霸糖，视觉焦点突出；
  - **动效降级**：所有刀光粒子在 `prefers-reduced-motion` 开启时化为纯色切割线，无任何炫目闪烁。

- **封面设计提案（assets/covers/cut-the-rope.webp）**：
  - 严格遵循 3D 软胶质感、单一居中主体（60-75% 无文字）、彩色渐变背景、漂浮粒子标准；
  - **主体物件**：一只软胶小怪兽正憨态可掬地向上张大嘴巴，上方垂着一根刚刚被切断的绳头，一颗晶莹剔透的红黄旋涡糖果正悬停在其上方，几颗金色小五角星在四周漂浮；
  - **背景基底**：暖橙黄色至嫩草绿的明媚活泼渐变，散落微小的软胶星星与纸屑粒子。

## 5 · 制作人拍板与开放探讨

请制作人（用户）审阅并对以下关键设计点定夺：

1. **首发关卡量与模式编排**：
   - **方案 A（精雕细琢，推荐）**：首发推出 **32 关主线关卡（4 大主题纸盒）+ 8 关一刀大师挑战**，内容量充实耐玩，机关机制层层递进；
   - **方案 B（极简验证版）**：首发 16 关主线，聚焦核心绳索与气泡机制，其余关卡留后续迭代；
   - **方案 C（纯主线无挑战）**：只做 40 关线性主线，不设“一刀大师”特殊模式。

2. **核心互动角色设定**：
   - **方案 A（经典软胶萌兽 Nommy，推荐）**：原汁原味致敬经典的绿色贪吃小怪兽，极具亲和力与陪伴感，表情动作极为生动；
   - **方案 B（DOIN 原创太空小熊/软胶小猫）**：替换为宇航头盔软胶小熊或吃鱼干的小猫，增加原创 IP 属性。

3. **桌面端切割操作方式**：
   - **方案 A（鼠标拖拽划线，推荐）**：最符合直觉与物理常识的划线切割，配合刀光光轨手感绝佳；
   - **方案 B（点击绳索直接斩断）**：无需滑动，点击绳索任意位置即断，对触摸板更轻松但削弱了“划切”的动作快感。
