## 1 · 创意概念与核心乐趣

- **游戏名称**：灯笼巷 / **Lantern Lane** / 建议 slug：`lantern-maze`
  - 备选 slug：`glow-muncher`、`shadow-alley`、`paper-maze`
  - ⚠ **命名规避**：游戏内标题、slug、封面均**不得出现** `pacman` / `pac-man` / `吃豆人`（Bandai Namco 注册商标）。门户卡片副标题可写“经典迷宫吞影玩法”，用玩法描述词而非商标词。
- **一句话玩法**：抱火种的小灯笼在夜巷吞光尘，绕开四只影魅，吞下日曜珠就轮到你追它们。
- **核心乐趣与卖点**：
  - **“猎人变猎物”的瞬间反转**：整局 90% 的时间你在逃，日曜珠入口的那 6 秒你在全图追杀——这条情绪反转曲线是这个品类活了四十年的原因，必须做到位：**逃跑时手心里全是汗，反杀时要爽快到底**。
  - **四张截然不同的“坏脸”**：影魅不是四只随机怪物，而是**一个直冲、一个抄你前面、一个绕你侧翼、一个得过且过**。玩家一旦被追死会立刻明白“是那只粉色在下面堵我”，这就是深度的来源，也是老玩家最怀念的部分。
  - **“把鬼引进暗巷”的战术钩子**：暗巷里影魅走路变慢、你不变。第一次成功用一条巷子把三只影魅遛成糖葫芦，是这个游戏最好的“我变聪明了”时刻。
  - **影列收编（本作招牌爽点）**：当影魅被你一路带着排成队伍时吞下日曜珠，**一珠吞四鬼**，倍率按队列长度叠加——把经典的“连吃翻倍”升级成主动运营的成果。
  - **迷宫由你亲手扎出来**（制作人点名需求）：不是附赠的“关卡编辑器玩具”，而是带**硬性可玩性验收**的第二主线——你扎的巷子必须能被影魅巡逻、必须有环路可逃、必须有影子玩家替你跑通，才准拿出去分享给朋友。
- **核心循环**：走位吞光尘 ➔ 读影魅人格并绕行 ➔ 抢日曜珠进入天亮形态反杀 ➔ 影列/连击拉倍率 ➔ 清空整巷点亮纸窗 ➔ 更鼓一响进下一更 ➔ 五更天亮。

- **成熟标杆原型**：《Pac-Man》（1980）确立了“网格迷宫 + 人格化追兵 + 限时反杀”的完整范式：28×31 网格、240 粒豆 + 4 颗能量豆、四只性格迥异的鬼、左右贯通隧道、鬼屋与“只剩眼睛回巢”。它是被反复复刻、参数被完整逆向最多的街机之一（The Pac-Man Dossier）。
- **我们要继承的成熟机制**（逐条落地，不打折）：网格吸附移动；贴角提前转弯与一格输入缓冲；四鬼人格目标点算法；追逐/巡游双态节拍与切换掉头；惊吓态蓝白闪烁倒计时；暗巷双向传送与鬼速衰减；尾盘单鬼提速；吞鬼后眼睛归巢；吞豆轻微减速；连吃翻倍计分；递增水果奖励；死亡后原地重生不清场。
- **本作的独特魅力与微创新**：
  1. **影列收编（Ghost Train → 一串流萤）**：把“遛鬼成队”变成可主动经营的资源，队列越长，一珠吞下的倍率越高，并显示“影列 ×N”的街匾。
  2. **光即资源（灯芯条）**：吞光尘不只加分，还在给你的灯笼**续灯芯**；灯芯亮度决定视野半径与受击后的僵直时长。灯灭即死，把“别停下吃”变成内驱力，而不是靠分数催促。
  3. **扎巷坊 · 可玩性验收的自定义迷宫**：环路数、光尘可达性、影匣出口距离、日曜珠分布、影子玩家跑图通过率——**五道硬验收**，不通过就地高亮问题瓦片。玩家的创造力被机制兜住，不产出死局垃圾图。
  4. **一夜五更的叙事骨架**：关卡推进不是“Level 5”，而是“二更·风起”。每更换一条**新规则**（不是换皮），终点是五更天亮、整条街纸窗亮起。
  5. **影谱可视化辅助**（可读性微创新）：可选开启“目标浮标”，把影魅要去的格子用同色淡纹标出——把原作最不为人知的深度**教给新玩家**，硬核玩家可关掉。

## 3 · 玩法规则与交互说明

### 3.1 场景构成

- **网格**：**19 × 21 瓦片**（含外圈墙），路面瓦片约 170–190 格，桌面与 390px 移动端**共用同一网格**，仅按容器等比缩放（移动 tile ≥ 18px），规则绝不分叉。
- **瓦片类型**：墙（纸屏风）、路、光尘、日曜珠（4 颗，四角）、流明灯位（影匣上下各一处）、暗巷（左右贯通行）、影匣（中央 3×2，四只影魅的巢）、灯灯出生点（下方中路）、影匣门。
- **初始状态**：灯灯在出生点朝左静止 3 秒（期间影魅不出匣，**开局静默演示**，对齐街机传统），四影在匣内排队按节拍放出。
- **物件**：光尘 150–190 粒（每关固定，清完即过更）、日曜珠 4 颗、流明灯每更出现 2 次。
- **对称性**：手作迷宫默认**左右镜像**（继承经典的空间记忆便利），工坊可选非镜像但需通过验收。

### 3.2 四只影魅的人格（唯一权威判定，照抄经典算法）

| 影魅 | 色 | 人格 | 追逐态目标格 | 巡游态角落 |
|---|---|---|---|---|
| **赤影** | 朱红 | 直愣愣地追，永远朝你当前位置扑 | 灯灯所在格 | 右上 |
| **桃影** | 桃粉 | 抄到你前面等你 | 灯灯**前方 4 格**（按朝向；不做原作的向上偏移 bug） | 左上 |
| **青影** | 青碧 | 绕你的侧翼，最难读 | 以**赤影**为起点、过“灯灯前方 2 格”的射线**再延一倍**所得的格 | 右下 |
| **橘影** | 蜜橘 | 怂，贴脸就跑 | 距灯灯 **>8 格**时同赤影直追；**≤8 格**立刻改道回角落 | 左下 |

**通用心智模型（必须实现，这是经典手感的地基）**：
- 影魅**每过一个瓦片中心**才决策一次方向，不可后退掉头（除非模式切换或进入惊吓/恢复）；可选方向按**到目标格的欧氏距离最短**取，同分按 **上 > 左 > 下 > 右** 优先级。
- **影匣上方的两个特定路口禁止向上转**（原作规则）——这是让“抢在鬼前出头”成为可能、避免匣口变绞肉机的关键。
- 状态四型：**匣内排队 → 出匣 → 猎杀（追逐/巡游）→ 惊吓（蓝白，可吞）→ 残瞳归巢**。残瞳以约 2 倍速直线飘回影匣，重新排队出匣。
- 后续更次追加的新影（**只加 3 种，克制**）：
  - **直影**：每 6 秒朝灯灯方向**直线猛冲 3 格**，中途不转向；有 0.8 秒蓄力红纹，可预判。
  - **巡影**：沿固定巡逻环线走动，**不受更漏节拍切换影响**，是雾里唯一可依赖的“路标”。
  - **哑影**：不进目标浮标提示、脚步无音效，纯靠余光发现（第 4 更限定关）。

### 3.3 更漏节拍（模式调度与难度曲线，本作取值即调参基线）

- **猎杀/巡游交替**：出匣后 `追逐 7s → 巡游 20s → 追逐 7s → 巡游 20s → 追逐 5s → 巡游 20s`，此后**进入长追不再巡游**；更次每 +1，前段追逐窗口 +1s、巡游窗口 −2s，长追提前到来。
- **切换瞬间集体掉头**（经典行为，玩家靠它预判）。
- **日曜（惊吓）时长**：一更 6s → 逐更递减（5/4/3/2），末段最后约 1.5s **白闪警告**，闪完立刻恢复猎杀；“**贪最后那半秒**”是本作最刺激的赌博点，闪烁必须清晰可读。
- **赤影尾盘提速**：光尘剩余 ≤20% 时提速约 +5%，≤8% 再 +5%（身体出现热纹）——保证清尾盘不会拖成无聊的遛狗。
- **暗巷衰减**：暗巷行内影魅降至约 50% 速，灯灯保持常速（引鬼入巷的战术根基）。
- **吞豆迟滞**：灯灯每吞一粒光尘有约 5%、1 个渲染帧的微迟滞（经典手感，也是“擦着鬼嘴抢豆”的代价感）。
- **出匣节拍**：`0s / 4s / 12s / 20s`（第 3 只起随被吞次数追加延迟），流明灯出现后重置一次队列。**影列/连吃会拖慢出匣**，给玩家喘息与运营的因果。
- **相对速度**：灯灯恒为 100%，常速影魅 94%、惊吓 55%、暗巷 47%、残瞳 200%。**玩家永远跑得赢单只常速鬼，但永远跑不赢包夹**——这是本品类紧张感的唯一来源，不得改。

### 3.4 玩家合法操作与手感（键鼠触全通）

| 输入 | 行为 |
|---|---|
| `↑↓←→` / `WASD` | 四向移动（网格吸附，不做斜向） |
| 触屏滑动（四向） | 同键盘；滑动即改向 |
| 移动端可选 | 屏底“竹笛摇杆”四向实体键（嵌在灯棚操作台内，非浮屏） |
| `空格` | 提灯（短距爆亮 0.4s，冷却 6s）：逼退半径内影魅半步、并短暂驱散夜雾，**消耗灯芯**，是本作唯一的主动技 |
| `P` / `Esc` | 暂停（纸帘落下） |
| `R` | 重开本更（主线）/ 重置工坊图 |
| `Enter` | 开局 / 下一更 |

- **贴角提前转弯**：允许在到达路口**前一格内**预输入方向，落地即转（经典宽容窗口），绝不出现“按了左却撞墙”。
- **输入缓冲**：常驻保存 1 个待转方向；无效方向静默忽略，不中断当前移动。
- **无效操作绝不报错**：撞墙、被门挡、提灯冷却中再按——一律静默，严禁 `alert()`。
- **误触容错**：反向键在窄巷里等同“继续走”，不做原地急停（防手滑送命）。

### 3.5 胜负判定与容错

- **过更（阶段胜）**：清空本更全部光尘 → 纸窗逐一亮起、更鼓三响，进入下一更。
- **通关（唯一终局胜）**：打完第五更，**天亮大结算**（整街由靛青转暖金的仪式动画 + 星级汇总）。
- **失败**：一夜 **3 盏灯**（命）。被影魅碰到即熄一盏：灯焰“噗”地灭、画面褪色 0.8s，**在出生点原地重生，光尘与影魅状态全部保留、绝不清场重打**（对齐街机传统，也是对玩家最友好的部分）。灯尽则本夜失败，回最近检查点重开（每更起点即检查点）。
- **无死局保证**：手作与工坊迷宫全部通过 §3.8 的验收，机制上排除“无路可逃的死胡同”与“不可达光尘”；**本作没有需要运气猜的路径**——所有威胁都是可见、可预测的确定性 AI。

### 3.6 计分与评价体系（不是只有总分）

| 事件 | 分值 / 效果 |
|---|---|
| 光尘 | 10 分，灯芯 +1 |
| 日曜珠 | 50 分，灯芯 +8，触发天亮形态 |
| 吞影魅 | 200 → 400 → 800 → 1600（同一颗珠内翻倍） |
| **影列收编** | 队列 ≥3 时吞下日曜珠，本次连击基数 ×队列长度（上限 ×4），并打出“一串流萤 ×N”街匾 |
| 流明灯 | 出现两次，价值随更次递增：100/300/500/700/1000/2000/3000/5000 |
| 提灯 | 不加分，冷却 6s，耗灯芯 |
| 一夜清完 | 剩余灯数 ×5000 结算 |

- **额外奖励**：本夜累计 10000 分给一盏“续命灯”（上限 5），沿用原作口径。
- **核心评价指标（星级更签，非唯分数）**：每更 **三枚更签** ——① 清场；② 本更零熄灯；③ 达成效率项（用时 ≤ 标准线 / 或一珠吞 ≥3 影 / 或影列最长 ≥4）。
- **收藏与横向指标**：全站 **更签 x/90**、**工坊图通过数**、**单夜最高分**、**最长影列纪录**，均本机保存。

### 3.7 逐更解锁的新规则（拒绝换皮式重复）

- **一更 · 上灯（1–6）**：只有赤影、无暗巷。教三件事——跟手、贴角转弯、绕着鬼打转。第 3 关引入日曜珠与第一次反杀。
- **二更 · 巡巷（7–12）**：四影齐出（人格全上线）+ 暗巷贯通。**“把鬼引进巷子”** 成为核心战术；引入流明灯。
- **三更 · 风起（13–18）**：**影列收编**与连击倍率、赤影尾盘提速。开始要求玩家**主动经营队形**而非只顾逃。
- **四更 · 雾合（19–24）**：**夜雾**收束视野（灯芯越亮视野越广）+ 新影「巡影 / 直影」。引入提灯（空格）作为应急照明。
- **五更 · 破晓（25–30）**：**双影匣**、六影同夜、日曜珠稀有化（3 颗、刷新更慢）、惊吓时长压到最短。第 30 关是“最长一夜”压力关，通关即天亮。

> 夜雾在第 4 更才登场、且**辅助模式可关**：经典迷宫吞影的乐趣 80% 来自“看清全局后的路线规划”，雾只能作为**后期调味**，绝不能开场就做视野剥夺。

### 3.8 扎巷坊 · 自定义迷宫（制作人点名需求，本作最大差异点）

**编辑体验（不做工程味属性面板，做“纸巷裁铺”）**
- 舞台是一块可放大缩小的**纸巷工作台**：瓦片是纸，墙是剪出来的屏风。笔刷做成实体工具条嵌在台面边：**裁墙 / 铺路 / 撒光尘 / 埋日曜珠 / 放影匣 / 定出生点 / 打通暗巷**。
- **一键镜像**（左右对称自动同步）、**网格辅助线**、**Ctrl+Z 级撤回栈**、**预演**（原地跑 5 秒影子玩家给你看这图“顺不顺”）。
- 提供 3 张纸样模板（经典对称 / 双环 / 回字窄巷）起手，避免面对白纸。

**五道硬性验收（不通过就不准保存 / 分享，逐条高亮问题瓦片）**
1. **连通性**：从灯灯出生点 BFS，**每一粒光尘、每一颗日曜珠、影匣门都必须可达**；孤岛瓦片红色高亮。
2. **环路数 ≥ 3**：迷宫图论环数（`E − V + 1`）必须 ≥3，保证至少三条可绕行的活环。**纯树状迷宫 = 死路陷阱**，直接判定“此巷无退路”。
3. **影魅巡逻可行性**：从影匣门 BFS，到**任意路格**的最短步数 ≤ 45，且四角日曜珠两两距离 ≥ 8 ——否则影魅走不到、或玩家可永久赖在角落。
4. **安全间距**：灯灯出生点距影匣门 ≥ 10 步；四颗日曜珠不得贴墙死角（其所在格的邻接可走方向 ≥ 2，吞珠后要有出路）。
5. **影子玩家试跑**：内置确定性贪吃 AI（带避影权重）在注入种子下自动跑 **8 局**，判据取**平均吃净率**而不是清场率——夜行决意里影魅比提灯人更快，一步贪心的机器注定收不了尾（真人可以），但“大片光尘根本吃不到”一定是巷子在追着人打，属于结构问题。**吃净率 < 55% 直接判红**（此巷过于逼仄 / 日曜珠太易被守），**55%–75% 出黄警**（可保存，但提示“这条巷子偏赶”）。
- 全部随机走图测试同样注入 `mulberry32` 种子：**≥1000 步随机游走**不得抛错、不得越界、不得出现“影魅卡门”不变式破坏。
- 校验器与影子玩家**必须支持从种子字符串完全复现**，保证同一分享码在任何机器上是同一张图、同一条测试结论。

**分享与承载（零网络、零后端）**
- **巷码**：迷宫经 RLE 压成一串大写 base36（`LM1` 前缀 + 尺寸段 + 每 3 字符一个游程「图符 + 两位长度」，再每 12 字符断一次连字符；19×21 手作巷实测 480–620 字符，输入框要按整段换行设计），一键复制、粘贴载入；载入即跑五道验收，**不合法就地拒绝并说明原因**。
- **擂台簿**：本机保存“我在朋友巷码上的成绩”，与自家更签并列展示；不做上传、不做排行榜（平台无账号体系，宁可克制）。
- **工坊图可玩的模式**：主线外的所有限时/生存模式均可指定巷码作为场地（“用你扎的巷子挑战破晓 120 秒”）。

### 3.9 模式与内容编排（依玩法特质定制，不套“无尽冲分 + 每日挑战”三件套）

**主线 · 一夜五更**：**30 张手作迷宫**（每更 6 张），逐更解锁新规则（见 §3.7）。这是主菜，评价用**更签（0–3）与是否见到天亮**，不用总分。

**破晓冲刺（限时模式）**：通关三更后解锁。
- **120 秒连续清巷**：清空一更续 +40 秒，吞影 +2 秒，熄灯 −15 秒；计时归零即结算。迷宫越打越复杂（自动从 8 张预设 + 你自己的巷码里轮换）。
- 记录：**最长连清巷数**与**剩余秒数**。这是吃豆人品类现代标杆（DX+）验证过的最强节奏模式，比“无尽”更有终点感。

**百鬼夜巷（生存模式）**：通关五更后解锁。
- 单张环形大巷，**影魅每 60 秒追加一只**（最多 8 只，含直影/巡影），日曜珠刷新间隔逐轮拉长；记录**撑到第几更**（本模式里“更”= 时间轮次）。

**扎巷坊（创作模式）**：常驻开放。§3.8 的编辑器 + 擂台簿 + 验收。

> 本作**不做“每日挑战”**：迷宫追逐是**肌肉记忆型**玩法，玩家靠固定图反复刷出更优路线；每日换盘会打断这种精进，与本作“手作 + 巷码”的内容供给方式冲突。取而代之的是**巷码挑战**——把“同一张图给大家比”的权力交给玩家自己。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：纸雕夜巷、暖金灯火、靛青夜色、皮影剪影、萤火浮尘。
- **游戏机台 / 沉浸舞台规划（严格避开老套网页排版病）**
  - **整屏是一座“灯笼棚”**：中央是发光的纸巷迷宫本体（迷宫墙就是**会透光的纸屏风**），四周是木棚与屋脊剪影，视线焦点天然收在巷子里。
  - **禁止四角浮动按钮**：返回首页 / 音效 / 语言 / 帮助，统一收进灯棚**顶边一条门匾状态条**（匾上刻“灯笼巷 · 三更”），像一块挂在棚口的木牌。
  - **禁止右侧 SaaS 卡片堆**，HUD 全部实体化为巷中道具：
    - 左翼 —— **更漏**（本更计时与进度）、**三星更签架**（挂签）、**灯芯条**（一条会烧短发暗的灯芯，即视野资源）；
    - 右翼 —— **影谱牌**（四块小木牌，各刻一只影魅的头像与当前状态：匣中 / 猎杀 / 蓝惊 / 归巢；这是把 AI 状态“读出来”的关键界面）、**天亮倒计时环**（日曜剩余）、**提灯冷却钮**（空格的可点替代）；
    - 底部 —— 一条窄木操作台（预演 / 重开 / 下一更），桌面端不贴屏底。
  - **桌面端（≥900px）**：迷宫居中（本体宽 ≤ 640px），**≥1200px 展开左右两翼**成三栏机台；900–1199px 两翼收为贴在迷宫侧缘的窄条。左右屏幕边缘与底部边缘**不放任何关键按钮或核心 HUD**（为未来侧栏/通栏广告留安全区）。
  - **移动端（≤768px）**：转为**竖排掌机灯笼棚**——门匾顶栏 + 迷宫 + 底下一条紧凑操作台（更漏与影谱压成迷宫上方一行小灯）；主容器 `padding-bottom: max(68px, calc(16px + env(safe-area-inset-bottom)))`，绝不让按钮贴底被 Banner 压住。
- **色彩与环境氛围**
  - 主调：**靛青夜色 + 暖金灯光 + 纸白**，四影魅沿用“朱红 / 桃粉 / 青碧 / 蜜橘”的暖冷可辨组合，惊吓态统一转靛蓝并带白瞳。
  - 环境：迷宫外是**缓慢呼吸的景深光晕**、远处纸窗明灭、萤尘粒子斜飘、屋脊视差；禁死黑死白，地面有纸质微纹理与暗角。
  - **最大的视觉爽点：天亮反转**。吞下日曜珠的 0.4 秒内，整条街由冷靛青**轰然转为晨光暖金**，纸窗逐格点亮，影魅缩成蓝影；结束前白闪两次，颜色回冷。
  - 质感：纸屏风墙带厚度与投影、灯灯是半透明带内发光的高光玩具球、影魅是软胶质感；所有按钮有微浮雕（悬停 `translateY(-2px)`、按下扎实 `translateY(2px)`）+ 清脆合成“梆 / 咔”声。
  - **色盲友好**：影魅**不只靠颜色区分**——赤影有直冲尾迹、桃影有粉色前突虚影、青影有拖尾弧线、橘影会周期眨眼；灯灯永远最亮。
  - `prefers-reduced-motion: reduce` 下：粒子静止、天亮反转改为静态色块过渡、取消震屏与闪烁（闪烁改为边框常亮提示）。
- **音效氛围（程序化合成，零素材）**：底噪是夜色虫鸣与远处更鼓；吞光是“叮”的高音阶爬梯；日曜珠=一记锣；吞影=滑音上扬；被捉=灯灭短噗 + 下行三音；清巷=更鼓三响。
- **封面设计提案**（遵循 `docs/COVER-STYLE.md`，并同步登记色相表）
  - 3D 软胶，单一居中主体：**一颗圆滚滚、半透明内发光的暖金小灯笼球，张着圆嘴，正把一只受惊的靛青小影魅吸进去**；四周 3–4 粒光尘与一枚小纸窗剪影陪衬。
  - 背景：**明黄 → 蜜橙**明亮渐变（明黄为封面登记表未占用色相；**避开**蓝紫 / 青绿 / 天蓝 / 绯红 / 玫瑰粉），主体占比约 68%，左上主光、投影短软。
  - 无任何文字 / logo / 角标，640×640 WebP，右下角水印清干净。
  - 若整墙看后偏暖重复，备选**靛蓝/深青**背景 + 同一暖金主体（对比更强，但需确保背景“有色但不暗”）。

## 5 · 制作人拍板与开放探讨

1. **自定义迷宫工坊做多重？**
   - **A（推荐）· 完整版**：笔刷编辑器 + 五道硬验收（含影子玩家 8 局注入种子试跑吃净率）+ 巷码分享 + 擂台簿。这是本作区别于所有网页吃豆人的唯一招牌，验收器也天然满足平台“100% 可解”铁律。
   - **B · 旋钮版**：只给 8 张预设 + 三个滑杆（墙密度 / 日曜数 / 暗巷数）生成图，省掉编辑器 UI，但“自定义”只剩调参，卖点折半。
   - **C · 加码版**：A 之上再开放**影魅人格调参**（自己配四只鬼的算法），深度最高，但体量与测试面显著变大。
2. **夜雾（视野收束）怎么用？**
   - **A（推荐）· 后期调味**：第 4 更才登场，且辅助模式可一键关闭；保留迷宫“看得清”的根本乐趣。
   - **B · 全程氛围**：从一更就有小光圈，氛围与主题最强，但会牺牲路线规划可读性，硬核玩家易反感。
   - **C · 不做雾**：把工时全给影列机制与工坊，视觉靠灯光池与粒子撑。
3. **第三个模式选哪个？**
   - **A（推荐）· 破晓冲刺（限时）**：清巷续时、吞影续时，DX+ 验证过的最强节奏，且和“手作图 + 巷码”无缝复用素材。
   - **B · 百鬼夜巷（生存）**：影魅逐波增援，冲“撑到第几更”，实现最省。
   - **C · 执影（反串）**：**你扮演影魅猎一只 AI 灯灯**，用四鬼人格算法反过来做进攻方。辨识度和话题性极高，且能把 §3.2 的 AI 复用成两处玩法；代价是 AI 目标要做得够“会玩”才不穿帮。

**默认建议：1A + 2A + 3A**——先把“跑/躲/反杀”的贴角手感与四鬼人格做到经得起老玩家检验，再用影列收编提供运营深度，最后用带硬验收的扎巷坊把“迷宫可自定义”从一句需求变成这款游戏的招牌。
