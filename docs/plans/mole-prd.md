# 《莓园打地鼠》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

---

## 1 · 创意概念与核心乐趣

- **游戏名称**：莓园打地鼠 / Berry Bash（建议中文名**《莓园打地鼠》**，英文 **Berry Bash**）
- **建议 slug**：`mole`（候选 `whack`、`berry-bash`）
- **一句话玩法**：草莓园里一群软胶地鼠从土洞探头偷莓——抡起木槌把它们敲回洞里，别让它把草莓叼走，别打错炸弹鼠。
- **核心乐趣与卖点**：
  - **「它在偷东西」带来的取舍快感（核心创新）**：传统打地鼠"漏掉 = 不得分"，惩罚是隐性的、钝的。本作里地鼠冒头后会**冲向莓藤摘莓、再叼着莓横向挪一个洞逃走**——漏掉就是**眼睁睁看着一颗草莓没了**。于是屏幕上同时冒出三只鼠时，玩家必须瞬间判断"先打哪只"，反应游戏第一次有了策略层；
  - **木槌即点即中的实体打击感**：点击瞬间就判定命中（不等挥锤动画），软胶鼠被敲扁成一坨、星星迸溅、木槌"啵"一声——这是品类最爽也最容易做砸的地方，我们把它做成第一优先级；
  - **连击驱动的「莓雨狂热」**：连击攒满触发 4 秒时间减速 + 全场狂潮 + 双倍分，把爽点做成玩家**自己打出来**的节奏爆点，而不是随机触发的施舍；
  - **鼠王 Boss 战**：每章末尾一场多阶段鼠王——戴盔、连续换位、召唤小弟，给"敲打"这件小事一个仪式感的落点。
- **核心循环**：
  ```
  地鼠探头 → 判断优先级（抱莓的先打 / 炸弹的别碰） → 一槌命中 → 连击 +1、莓保住
      ↑______________________________________________↓
  漏掉抱莓鼠 → 莓篮 -1（实质损失） │ 误击炸弹鼠 → 莓篮 -2 + 连击清零
      → 连击攒满 → 莓雨狂热（减速 + 双倍）→ 章节末 → 鼠王战 → 三星评级
  ```

## 2 · 经典对标与借鉴创新

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴 | 避开 |
|---|---|---|---|---|---|
| Whac-A-Mole 街机机台 | 1970s 美国游乐场实体机台 | 多洞气动地鼠 + 橡胶锤 + 限时计分 | 实体打击反馈、限时紧张是品类根 | 核心玩法、多洞并发、限时压迫 | 机械延迟造成的"锤在半空、鼠已缩回"的打空感 |
| Whac-A-Mole Arcade（3D 复刻） | 移动端 | 经典计时 / 无尽双模式 + 金鼠、炸弹鼠特殊鼠种 | 特殊鼠种已是品类共识 | 特殊鼠种体系（金鼠 / 禁打目标） | 换皮 3D，无机制增量 |
| 《消灭小地鼠》 | 移动端 | 出洞间隔 1.2s → 0.35s 递进、限定命中次数通关 | 节奏曲线可量化、关卡化目标清晰 | 速度曲线数值化 + 关卡配额目标 | 误击一次即终止的挫败设计 |
| 《九宫打地鼠》 | 移动端 | 3×3 固定九宫、90 秒固定局时 | 九宫布局与键盘天然契合 | 九宫格舞台 + 桌面键盘映射 | 纯随机、零取舍 |
| 《暴揍地鼠》 | 移动端 | 干扰物（敲闹钟加时、敲猫/蛋扣血）、露头时长逐级缩短 | 干扰项制造判断压力 | "干扰物"思路（我们升级为**禁打目标 + 偷莓优先级**） | RPG 养成、装备合成的冗长 |

**我们要借鉴什么**：多洞并发与限时紧张、可量化的速度曲线、特殊鼠种体系、干扰项制造取舍、九宫格与键盘映射。

**我们的差异化微创新**（不是换皮）：

1. **搬运鼠 = 会跑路的贼（核心创新）**：地鼠不再是"冒头—缩回"的静态靶子。它有三段行为——**探头 → 冲到相邻洞摘莓 → 叼莓钻回**。玩家必须追着打，且要在多只鼠中排序优先级。市面上打地鼠的"漏掉"几乎都只是不得分，**我们是第一个让漏掉产生实质资源损失的**；
2. **木槌即点即中（手感铁律）**：命中判定发生在 `pointerdown` 当帧，挥锤动画纯做视觉补间——正面解决玩家吐槽最多的"锤子还在半空怪物就缩回去了"；
3. **莓雨狂热（连击 → 时间减速）**：不是随机 buff，而是玩家用连击**亲手打出**的 4 秒慢动作狂潮，形成"稳住连击 → 爆发 → 再稳住"的节奏呼吸；
4. **鼠王 Boss 战**：章节末的多阶段 Boss（破盔 → 换位 → 召唤小弟），把"敲"升级为有仪式感的关卡收尾；
5. **三星评级按"守护"而非"总分"**：星级 = 保莓率 + 命中率 + 最长连击三项达标数，评价语言与"菜园守护"题材完全自洽，不套"总分排行榜"。

**品类排重**：DOIN 现有 30+ 款中无"空间多点点击反应"品类——`piano-tiles` 是竖向音乐节奏、`snake-orchard` 是方向操作、`gold-miner` 是单点时机。本作是站内**唯一的"敲打击打手感"游戏**，也是唯一带"禁打目标取舍"的反应作，与已有内容零冲突。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景构成**：
  - **3×4 = 12 个土洞**（桌面端）/ **3×3 = 9 个**（移动端）排列在草地舞台上，洞为厚软泥圈；
  - 舞台上方是**莓篮**（本局草莓总数，如 12 颗）+ 后方莓藤架与木栅栏；
  - 洞中按节奏冒出各类地鼠，玩家用木槌敲打。
- **鼠种与行为**（按章节递进解锁）：

| 鼠种 | 行为 | 命中收益 | 漏掉 / 误击后果 | 解锁 |
|---|---|---|---|---|
| 普通地鼠（褐） | 露头约 0.9s 后缩回 | +1 分 | 无（连击清零） | 第 1 章 |
| **搬运鼠（抱莓）** | 露头 → 横向挪 1 个洞 → 叼莓钻回 | +2 分，**救回 1 颗莓** | **莓篮 −1** | 第 1 章 |
| 铁盔鼠（戴锅盖） | 需打 2 下：第一下掀盔、第二下命中 | +3 分 | 无 | 第 2 章 |
| 金鼠（金光） | 停留极短（约 0.5s）、稀有 | +5 分 | 无 | 第 3 章 |
| **炸弹鼠（引线）** | **禁止击打**，数秒后自行缩回 | — | **莓篮 −2 + 连击清零** | 第 4 章 |
| 跳鼠（弹簧尾） | 露头后随机跳到另一个洞一次，难打 | +2 分 | 无 | 第 5 章 |
| 鼠王（Boss） | 3 段血，每挨一下换一个洞；P2 召唤小弟；P3 戴盔需破甲 | 段数计分 | 时间耗尽 = 关卡失败 | 每章第 6 关 |

- **玩家合法操作**：
  1. **敲击洞口**（命中鼠体 / 洞口矩形，判定区外扩 ~20% 宽容）；
  2. **不敲**（对炸弹鼠的正确操作是"忍住"，这本身就是一个操作）；
  3. 暂停 / 重开随时可用（零惩罚）。
- **胜利与失败条件**：
  - **关卡胜利**：限定时间（60s）内达成"守住 ≥ N 颗莓 + 命中 ≥ M 只鼠"配额；
  - **关卡失败**：莓篮清空（草莓被偷光）或时间耗尽未达配额；
  - **Boss 关胜利**：时间内打光鼠王 3 段血。
- **公平性与"无死局"硬约束**（生成器必须满足）：
  - **任意时刻屏幕上至少有 1 个可打目标**——绝不出现"全场只剩炸弹鼠、玩家被迫挨罚"的必输帧；
  - 同时上头的鼠数上限 3，**同一洞位不重叠**，禁止"两只鼠叠在一个洞"的判定纠纷；
  - **露头时长下限 0.45s**（人类视觉反应中位数约 0.25s），任何难度档不得突破；
  - 相邻两次生成间隔有下限，保证节奏可呼吸；
  - **关卡配额可达性校验**：目标命中数 ≤ 预计出现总数 × 0.75，保证中等发挥即可达标，不设"手速玄学门槛"；
  - 全部随机走**确定性种子 PRNG**，同一关卡/每日题面完全可复现。

### 操作与手感（本作生死线）

- **鼠标**：光标即木槌（软胶锤），点击时锤头下压 + 命中鼠压扁（squash & stretch）。
- **触屏**：多指并行敲击，各指独立判定。
- **键盘**（桌面加分项，九宫天然契合）：`Q/W/E · A/S/D · Z/X/C` 对应 3×3 洞位，3×4 布局追加 `R/F/V`；空格暂停。
- **手感铁律**：
  - `pointerdown` **当帧判定命中**，挥锤动画（约 90ms）纯做视觉补间，**绝不延迟判定**——杜绝品类通病"锤在半空、鼠已缩回"；
  - 命中反馈四件套：软胶压扁 → 星星迸溅粒子 → 木槌闷响"啵" → 连击 8 起屏幕微震；
  - 漏掉反馈：洞口冒灰 + 轻"咻"声（明确、但不刺耳惩罚）；
  - 误击炸弹：爆响 + 红闪 + 莓篮扣减动画（唯一带强负反馈的事件，稀有才有分量）；
  - 输入缓冲 80ms 防连点误判。

### 模式与内容递进（专属编排，不套通用三件套）

- **莓园闯关（Garden Campaign）**——核心模式：**30 关 / 5 章**
  - 第 1 章 春耕园（普通 + 搬运）、第 2 章 晨露园（+ 铁盔）、第 3 章 正午园（+ 金鼠）、第 4 章 暮色园（+ 炸弹）、第 5 章 霜降园（+ 跳鼠）；
  - 每章 5 个普通关 + 第 6 关**鼠王战**；
  - 难度轴：露头时长递减（0.9s → 0.55s）、并发上限递增（1 → 3）、搬运鼠占比递增（20% → 45%）。
- **莓雨狂潮（Frenzy Rush）**——唯一的无尽模式：90 秒、全鼠种、速度持续递增，冲最高分与最长连击（本机纪录）。
- **每日莓园（Daily Patch）**——每日固定种子生成一关特殊题面，全球同题比三星与保莓数（本机纪录）。*（是否首发见第 5 节拍板项 3）*
- **不做**：养成 / 装备 / 抽卡 / 宠物（那是"休闲合成派"的路，会稀释打击手感的纯粹）；不做第二个无尽模式。

### 目标与评价（专属化评价体系）

- **三星评级**（关卡结算，非总分）：
  - ★ 保莓率：剩余莓 / 总莓 ≥ 90%；
  - ★ 命中率：命中数 / 出现数 ≥ 85%；
  - ★ 最长连击 ≥ 关卡阈值（随章节 15 → 40）；
  - 三项各得一星，结算弹窗展示"莓篮结算 + 星星逐颗点亮动画"。
- **计分**：`单关得分 = Σ(鼠种基础分 × 连击倍率)`；连击倍率 8 连 ×1.5 / 16 连 ×2 / 24 连 ×3（封顶），狂热期额外 ×2。
- **纪录**：闯关进度与每关星级、狂潮最高分与最长连击，全部本机保存。

## 4 · 美术风格与视觉氛围（田园机台化，严禁网页仪表盘）

- **题材与视觉关键词**：**软胶地鼠 · 暖阳草莓园 · 木质机台 · 泥土与藤编 · 丰收微光**
  （不做暗黑霓虹、不做写实农场、不做死白网页卡、不做暗黑压抑——傍晚暖阳下的软胶玩具园是识别度。）

- **整体舞台造型（≥900px 宽屏 / 移动端竖屏一以贯之）**：把整局游戏做成**一台"莓园木质游戏机台"**，拒绝"左侧玩法 + 右侧卡片列"的仪表盘式排版：
  - **中央主舞台**：草地土台上的 3×4 土洞阵列，台后立木栅栏与莓藤架（藤上挂草莓，被偷时藤上果实消失一颗）；土台外框为木质机台机身（圆角木框 + 木纹 + 边缘高光）；
  - **顶部木梁（内嵌状态栏）**：返回 / 音效 / 语言 / 规则说明做成**钉在木梁上的四枚小木牌挂件**，一条横梁收纳完毕，绝不四角散落；
  - **左翼藤编篮**："莓篮"HUD——篮中草莓逐颗可见（被偷则消失一颗），配关卡目标小木牌；
  - **右翼木牌 + 玻璃沙漏**：连击数（大字 bump 跳动）、得分、沙漏倒计时；沙漏流沙随剩余时间变化，狂热期沙漏泛金光；
  - **底部木质操作台**：暂停 / 重开 / 模式切换做成木牌拉绳 + 实体木键（悬停微浮起、按下机械下沉 + 木槌键音），嵌入机台底缘，不是漂浮按钮；
  - 移动端：机台随屏宽等比缩放，土洞阵列降为 3×3，底部保留 ≥68px 安全缓冲（广告位避让）。

- **色彩与环境氛围**：
  - 主色：暖阳天空 `#FFE9A8 → 草地 #8CC46B` 渐变（**避免死白与死黑**）+ 泥土棕 `#A9714B` + 莓红 `#E8456B` + 木梁深棕 `#7A4A2E`；
  - 背景：舞台后方**傍晚暖阳光晕缓慢 drift** + 景深虚焦光斑 + 漂浮花粉/绒絮粒子，杜绝单调大平铺；
  - 关键动效：
    - **命中**：软胶压扁 → 回弹 + 星星迸溅 + 土屑飞起；
    - **搬运鼠得手**：它抱着莓"哧溜"钻回洞 + 莓篮里一颗莓碎裂消失（明确损失反馈）；
    - **莓雨狂热**：全屏暖金光晕 + 莓果/花瓣粒子雨 + 时间减速的画面微拖影 + 沙漏泛金；
    - **鼠王登场**：地面隆起、土块崩落、鼠王破土而出的仪式感入场；
    - **三星结算**：星星逐颗弹落进藤篮 + 莓果喷发；
  - 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

- **封面设计提案**：
  - 遵循 3D 软胶质感、单一居中主体（60-75%）、彩色渐变背景、漂浮粒子、零文字、640×640 WebP；
  - **主体物件**：一只抱着红草莓的圆润软胶地鼠，从软泥土洞里探头、一脸得手的表情，洞口边缘软泥厚实、投影短软；
  - **背景色相**：**粉红 / 莓粉系**（`玫瑰粉` 与 `绯红` 已被占用，这里取更亮的泡泡糖粉 → 莓紫粉渐变，整墙核对后确认仍为空位）；备选 **青柠黄绿**（草地质感，若与整墙青绿系过近则回退主案）；
  - 漂浮粒子：细小草莓籽与花粉光点。

## 5 · 制作人拍板与开放探讨

1. **核心机制（决定本作是"又一个打地鼠"还是"有记忆点的打地鼠"）**：
   - A. **搬运鼠偷莓机制**（默认推荐——漏掉有实质损失 + 横向挪洞追打，给反应游戏加上取舍层）；
   - B. **纯经典计分**（地鼠冒头即打、漏掉只是不得分，最原教旨，但记忆点弱）；
   - C. 折中：只有部分关卡启用搬运鼠，其余为经典计分。

2. **模式编排（用户原话"可做多难度"的落地形态）**：
   - A. **30 关 5 章闯关 + 每章鼠王战（默认推荐）**——难度藏在章节递进与鼠种解锁里，有仪式感、有收集感；
   - B. **三档难度无尽（轻松 / 普通 / 疯狂）**——最贴合"多难度"字面，但内容薄、复玩曲线短；
   - C. 闯关为主 + 三档难度开关叠加（工作量最大）。

3. **每日莓园是否首发**：
   - A. **首发含每日固定种子题面**（反应类与每日同题天然契合，推荐）；
   - B. 首发不做，留 v1.1（先把闯关手感做透）。
