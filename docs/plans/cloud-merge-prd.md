# 《云朵合成》小游戏策划案

> 定位：本策划案由 DOIN 产品策划部门产出，旨在明确游戏的核心乐趣、对标参考、玩法规则与视觉风格。
> 供制作人（用户）拍板，随后即可直接交由开发部门（本地主代理端到端开发，或转外包发包）进行技术落地。
> 不包含具体代码、模块架构等技术实现细节（技术规范由开发契约保障）。

---

## 1 · 创意概念与核心乐趣

- **游戏名称**：云朵合成 / Cloud Merge / 建议 slug：`cloud-merge`（候选 `weather-merge`、`sky-merge`）
- **一句话玩法**：把云朵丢进天空，相同云朵一碰合体成更大的云，一路合成到终极"彩虹云"，收集它让天空放晴。
- **核心乐趣与卖点**：
  - **"我在造天气"的掌控感**：亲手把小云朵养大——从一簇白云到积雨云、雷暴云，最后放出彩虹，把抽象天气过程变成看得见摸得着的养成爽感；
  - **下雨清场的自然奇观**：合成雷暴云会自动"下雨"，雨滴清开正下方的拥挤空间——**天气本身就是清障道具**，比"炸弹"这类硬道具更自然、更有画面；
  - **治愈的轻飘飘物理**：云朵比水果/泡泡更"轻"——下落慢、落地弹一下、软绵绵地挤在一起，观看性拉满，休闲解压向；
  - **收集彩虹的仪式感**：终极彩虹云点一下"收集"，天空放晴 + 爆分 + 清空空间，继续造下一道彩虹。
- **核心循环**：
  ```
  选落点丢下云朵 → 轻飘飘下落 → 同类云碰一起合体长大 → 连锁合成
      ↑___________________________________________________↓
  合出雷暴云 → 自动降雨清场 → 继续 → 合出彩虹云 → 收集放晴！→ 超线前持续刷分
  ```

## 2 · 经典对标与借鉴创新

**经典标杆与成熟参考**：

| 标杆 | 平台/来源 | 核心机制 | 亮点 | 借鉴 | 避开 |
|---|---|---|---|---|---|
| Suika / 合成大西瓜 | 全球爆款 | 水果物理掉落、同类合并、超线结算 | 物理掉落 + 连锁合并的成熟手感 | 容器物理、合并判定、掉落预览 | 水果写实风已挤爆 |
| Merge Clouds | Web（Metakidsplay 等） | **云朵合并、连锁反应、风暴与晴空** | 验证了"云朵+天气"题材可行 | 天气视觉联想（风暴/放晴） | 是儿童学习向小站，打磨粗糙、无收藏价值 |
| 云絮归拢（国内） | 移动端 | 聚拢云絮融合、**无时间限制、无失败惩罚** | 纯休闲"零压力"验证：云题材玩家接受度高 | 放松无压的基调 | 无目标无压力 = 无留痕，要保留"冲分"牵引 |
| Cosmic Merge | 移动端 | 11 级天体合成到黑洞 | 天体链有"终点幻想" | 等级链的"终点吸引力"设计 | DOIN 太空题材已有 2 款（orbit-sort/Gravity-Echoes），不做宇宙 |
| sobosuba | Steam | 软体物理 merge、无时间压力、策略冲高分 | 软体"Q 弹"物理的手感价值 | 云朵的软弹形变动画 | 平台门槛高，网页端做轻量版 |

**我们要借鉴什么**：Suika 的物理合并骨架、Merge Clouds 的天气题材验证、云絮归拢的"零压力休闲"基调、sobosuba 的软弹形变手感。

**我们的差异化微创新**（不是换皮，是"题材带机制"）：
1. **下雨清场（核心创新）**：合成到雷暴云后自动降雨，雨滴清开正下方一小片拥挤区域——天气即道具，清障动作自然融入世界观，取代生硬的"炸弹"；
2. **收集彩虹云（终局正反馈）**：终极彩虹云点一下"收集"——放晴动画 + 爆分 + 清空空间，可继续造第二道彩虹；把"大块占位"的终局变成"等一场彩虹"的期待；
3. **轻飘物性**：云朵下落慢、弹跳柔和、互相挤压时变形——节奏比水果版更从容，是"随时拿起来放松一局"的治愈向物理；
4. **每日挑战（同日同题）**：同日期同掉落序列，全球同题比"谁先放出彩虹 / 更高分"。

**品类排重**：DOIN 现有 15 款无物理合成类、无天气题材，填补"物理合成 + 天空治愈"空白。与《合成泡泡》（深海戳破向）、《数字合成大西瓜》（数字冲刺向）同属物理合成骨架——本作走"天空天气 + 零压力治愈"向，三案供制作人择优，避免同骨架双上架（详见拍板项 1）。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景构成**：
  - 左右封闭、顶部开放的**天空容器**（可做成云朵边缘/彩虹拱门造型），底部与侧壁为碰撞边界；
  - **云朵等级链（10 级）**：`L1 小云朵 → L2 棉花云 → L3 积云 → L4 浓积云 → L5 雨云 → L6 大雨云 → L7 积雨云 → L8 雷暴云 → L9 雪云 → L10 彩虹云`。每级云朵变大、颜色由白转灰再转彩；
  - 顶部安全线：堆叠超过先预警、后结算。
- **玩家合法操作**：
  1. **选落点**：鼠标/手指拖动显示瞄准线与落点光圈，松手/点击释放；
  2. **合体判定**：两个同级云朵接触 → 在中点合体为高一级云朵（动量平均），连锁判定继续；
  3. **自动降雨**：场上出现 **L8 雷暴云**时，其下方开始落雨，清开正下方一小片（约 2 格宽）拥挤区域——无需玩家操作，自然发生；
  4. **收集彩虹云**：场上出现 **L10 彩虹云**时，点击它 → "收集"动画（彩虹升起 + 放晴）→ 爆分 + 清空其占用的空间；
  5. 掉落预览：当前待丢云朵 + 下一个预览常驻 HUD。
- **胜利与失败条件**：
  - **无尽模式**：收集彩虹云 = 单局成就达成（可继续玩、继续收集）；堆叠超安全线 = 结算本局；
  - **每日挑战**：固定种子掉落序列，超线结算，比最高分 / 最早放出彩虹。
- **容错与无死局说明**：
  - 纯物理玩法**无逻辑死局**；云朵轻飘、下落慢，玩家反应时间充裕；
  - **防秒败**：安全线下方设缓冲预警区，进入即"天色变暗 + 风声"提示；
  - **主动清障**：雷暴云自动降雨 + 彩虹云收集清场，双保险；云朵软弹滚动自然腾挪，永不"堵死"。

### 操作与手感

- **鼠标**：移动 = 瞄准线；左键按住拖动 = 微调落点；松开 = 释放；点击 L10 彩虹云 = 收集。
- **触屏**：手指拖动 = 瞄准线；松手 = 释放；点按 L10 = 收集。
- **键盘**（桌面加分项）：左右方向键微调 + 空格释放。
- **手感优化**：
  - 固定步长物理（帧率无关、可重放可测试），云朵摩擦小、弹跳柔和、碰撞挤压变形（软体感）；
  - 合并动画：两朵云"啵"挤在一起 → 膨胀成新云，带小水汽粒子；
  - 降雨动画：雨滴斜落 + 清开的云朵化作水花消失 + 轻轻雨声；
  - 收集彩虹动画：彩虹从云中升起横跨容器 + 放晴金光（仪式感）；
  - 误触容错：释放前可取消（拖回顶部/右键）。

### 模式与内容递进

- **首选模式：无尽冲分 + 每日挑战**（品类最优解）。
- 难度自然生长：
  - 掉落池前期只出 L1 / L2（练手感）；随累计合成数逐步解锁 L3 进入掉落池；
  - 云朵越堆越高 → 空间压力递增；雷暴云降雨、彩虹云收集带来"清场喘息"节奏。
- **可选关卡目标制（拍板项）**：每关"合成到第 N 级云（如雨云/雷暴云/彩虹云）即过关"，30 关递进 + 无尽模式解锁。

### 目标与评价

- **计分维度**（建议口径，供开发校准）：
  - `本局得分 = Σ 每次合体得分 + 降雨清场得分 + 连锁加成 + 收集彩虹奖励`；
  - **合体得分**：合成出第 N 级云得 `N×(N+1)/2` 分（三角数，Suika 验证过的直觉数值），如 L2 得 3 分、L8 得 36 分、L10 得 55 分；
  - **降雨清场得分**：雷暴云降雨清开的每朵云 +15 分（清障即得分，鼓励把雷暴云合在拥挤处）；
  - **连锁加成**：一次掉落引发连续 ≥2 次合体，第 k 次合体得分 ×(1 + 0.5×(k-1))；
  - **收集彩虹奖励**：点击收集 L10 = 再得 100 分（"造出一道彩虹"的庆祝分）+ 清空空间；
  - 满分参照：单局无上限（无尽冲分）；每日挑战记录"历史最高分 + 最快放出彩虹"双纪录。
- **评价体系**：结算弹窗"得分 + 最大云级 + 最长连锁 + 收集彩虹数 + 🏆 新高分"；首次放出彩虹有专属成就徽章（"气象大师"）。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：**晴空治愈 · 蓬松棉花云 · 温柔光影 · 天气小剧场 · 轻盈呼吸感**
  （不做深海、不做霓虹、不做写实——与《合成泡泡》的"水族馆静谧"、《数字合成大西瓜》的"果园热闹"明确区隔，走"天空放空"路线。）

- **桌面端沉浸游戏舞台设计（≥900px）**：
  - **左主舞台**：容器为"蓝天云海"——天蓝渐变壁 + 底部软白云朵垫层，背景慢速云影 drift + 柔和光柱；云朵为蓬松 Q 版（多层椭圆叠出棉花感），L5 起带雨滴/闪电/雪晶小元素；
  - **右侧信息操作栏（天气气象台 HUD）**：
    - 顶部**"云层图鉴"**：10 级云链竖排展示，已合成级点亮、下一级目标呼吸提醒（如 L8 旁画小雨滴）——"离彩虹云还差几级"一目了然；
    - 中部**计分牌卡**：得分 / 最长连锁 / 已收集彩虹数，胶囊徽章化 + bump 跳字；
    - 底部**掉落预览槽**：当前待丢云朵 + 下一个，像"气象台的待发射云";
  - 移动端（≤768px）：单列紧凑，容器自适应屏宽，预览槽贴底。

- **色彩与环境氛围**：
  - 主色：晴空天蓝容器底 `#8ED6F0 → #C8F0F5` + 云朵（白 `#FFFFFF` → 灰 `#9AA7B5` → 雷暴深灰 `#5A6472` → 彩虹七色描边）+ 暖阳 `#FFD66B`；
  - 背景：天蓝环境光晕 + 细噪点薄雾，仿"午后躺平看云"的治愈感，拒绝死白灰底；
  - 关键动效：
    - **瞄准**：落点光圈 + 虚线轨迹 + 微风粒子；
    - **合体**：两云挤压膨胀 + 水汽粒子；
    - **降雨清场**：雨丝斜落 + 清开处溅起水花 + 轻雨声；
    - **收集彩虹**：彩虹弧线横跨容器 + 放晴金光 + 云朵镶金边（仪式感）；
    - **超线预警**：天空转暗 + 风声渐强；
  - 全部动效受 `prefers-reduced-motion` 约束降级为瞬移。

- **封面设计提案**：
  - 遵循 3D 软胶质感、单一居中主体、彩色渐变背景、漂浮粒子、零文字；
  - **主体物件**：一朵圆滚滚的软胶彩虹云居中（云身 + 七色彩虹弧），两侧飘两朵小白云正要合体，像"造云时刻"的定格；
  - **背景色相**：**纯明黄系**（阳光晴空，未被占用且未在策划案中使用；靛蓝已被《合成泡泡》策划占用作备选），与现有 15 张封面不撞色。

## 5 · 制作人拍板与开放探讨

1. **主题确认（先定这个）**：
   - A. **云朵天气**（主推——全站零题材、治愈辨识度高、"下雨清场"机制天然契合）；
   - B. **宝石钻石**（掉落宝石合成大钻石，"打磨"得分，闪亮向）；
   - C. **动物萌宠**（掉落小动物合体成大家伙，萌系，但 web 端 Animal Merge 较常见）；
   - D. 其他（可提出）。

2. **下雨清场机制**：
   - A. **雷暴云自动降雨**，清开正下方一小片区域（默认推荐——自然、不打断操作）；
   - B. 降雨清空正下方一整列（更强力，但节奏变化大）；
   - C. 无降雨清场（纯经典合成，靠彩虹收集清障）。

3. **终极彩虹云机制**：
   - A. **点击收集**：爆分 + 放晴动画 + 清空空间，可继续造第二道（默认推荐）；
   - B. **不可收集**：L10 达成即成就、留场占位（纯经典）；
   - C. 自动放晴（无需点击，合出即清场，少一步交互但少仪式感）。
