## 1 · 创意概念与核心乐趣

- **游戏名称**：割绳子 / Candy Drop / 建议 slug：`candy-drop`（备选 `cut-rope`、`sweet-slice`）
- **一句话玩法**：划断绳子，借重力把糖果送进小怪兽嘴里，顺路捞星。
- **核心乐趣与卖点**：
  - **一划即变**：手指/鼠标一刀，摆锤立刻改道，因果清晰到“我割的”。
  - **时机顿悟**：在摆到最高点切断，糖果甩进远处的嘴——物理自己给奖励。
  - **三星强迫症**：喂饱很容易，三条星走完美弧线才过瘾，同一关能玩三遍。
  - **失败不疼**：糖果碎了立刻重来，解谜压力低、实验欲高。
- **核心循环**：观察悬挂与星位 ➔ 划绳 / 点泡 / 吹气 ➔ 看抛物线 ➔ 进嘴过关或重开微调 ➔ 下一关新机关。

## 2 · 经典标杆与对标参考

| 对标 | 借鉴点 | 避坑点 |
|---|---|---|
| ZeptoLab《Cut the Rope》 | 划绳+重力摆锤；气泡上浮可点破；三星收集解锁后续箱；关卡按箱子引入新机关；即时重开 | 不搬 Om Nom 形象与箱子 IP；首发不做蜘蛛偷糖、幽灵变形、反重力按钮等过载机关 |
| CTR 官方 HTML5 / 网页移植 | 鼠标划切在桌面成立；物理要“肉”、不能像刚体乱弹 | 不做需重型引擎才能稳的超多刚体堆叠 |
| 网页仿作 / Slash the Rope 一类 | 一划切断的直白手感、关卡短 | 避免布娃娃乱飞、目标含糊；目标必须是“进嘴”，不是“弄出屏幕” |
| Cut the Rope Magic 等变体 | 章节主题换皮能延长新鲜感 | 首发不加变身法术，先把绳、泡、气、刺做透 |

- **成熟标杆原型**：2010 年《Cut the Rope》——划断悬挂绳，利用重力、弹性与气泡把糖果送进生物嘴里，途中收集最多三颗星。
- **最受认可的机制与手感**：
  - 绳子是摆锤不是装饰，切断位置与时机改变抛射方向。
  - 多绳要有切割顺序；可一刀同时切断数绳。
  - 星是“路线题”不是加分彩蛋：三星往往要求更绕的一条物理路径。
  - 失败即重开，思考成本在观察，不在惩罚。
- **我们要继承的成熟机制**：
  - 划切绳索（单刀多绳）。
  - 普通绳 + 拉长后的弹性绳（拉伸发红，切断弹射）。
  - 气泡（捕获后上浮，点破恢复下落）。
  - 气垫短促吹风（改向，不持续加速到失控）。
  - 尖刺 / 出界碎糖（失败，即时重开）。
  - 自动绳 / 滑动锚点（中后期，作为“第二层绳子机关”）。
  - 每关 3 星，章节用累计星解锁。
- **本作的独特魅力与微创新**：
  - 角色原创：**糯糯**（圆滚蜜色小兽，不是绿Om Nom仿品），嘴大、进糖有一口吞波动画。
  - 舞台做成 **糖锡铁盒街机**：关卡发生在打开的马口铁糖果盒里，不是硬纸箱UI翻版。
  - 桌面划切有 **刀光拖尾 + 绳端回弹**，强化“割”的手感（移动端手指划同样生效）。
  - 首发机关克制，用关卡编排而不是机关堆砌制造深度。

## 3 · 玩法规则与交互说明

### 核心规则

- **场景构成**（每关一张手摆物理题，禁止随机生成关卡）：
  - 固定 2D 侧视盒内舞台：重力向下。
  - 物件：糖果（唯一被运送物）、糯糯（固定或沿短轨道缓动的“嘴”）、绳（两端锚点，一端可系在糖果上）、星 ×3、气泡、气垫、尖刺、自动伸出的绳、滑动锚轨。
  - 开局：糖果被一条或多条绳吊着，可能已套在气泡里。
- **玩家合法操作**：
  - 在绳子上划过一段距离 → 该绳在交点处断开。
  - 一刀轨迹可切断途经的多条绳。
  - 点气泡 → 破裂，糖果失去浮力。
  - 点气垫 → 喷出一股短风（有冷却，避免连点刷飞）。
  - 拖滑动锚 → 自动绳的悬挂点沿轨道移动（先摆位再开割）。
  - 点重开 → 关卡瞬间复位，不扣星、不扣次数。
- **胜利与失败**：
  - 胜：糖果完整进入糯糯开口判定区（含三星与零星通关）。
  - 负：糖果碰尖刺、出盒、或掉到糯糯不可及的盒底静止区超过短时阈值。
  - 通关最低要求是进嘴；零星可过关，但章节大门用累计星锁。
- **无死局说明**：
  - 全部关卡手编，每关附带一条已知解（设计时验证：存在至少一条进嘴路径）。
  - 无随机刷盘、无程序化死锁。
  - 重开无惩罚，鼓励试错。

### 操作与手感

- **鼠标**：按下拖出刀光轨迹，松开完成一刀；单击气泡/气垫；拖滑动块。
- **触控**：同划切；点按点破。
- **键盘**：R 重开，Z / Ctrl+Z 回退上一刀（若该刀后糖果尚未明显位移可回；物理已大幅展开则直接重开更干净——拍板项），空格暂停摆动观察（可选，默认关）。
- **容错**：
  - 划切有最小长度，避免误点成刀。
  - 绳的判定带宽略宽于视觉线，桌面好割。
  - 进嘴判定略大于视觉口腔，避免“擦嘴失败”。
  - 断绳后短输入缓冲：连续两刀可在第一刀动画未完时登记。

### 模式与内容编排

物理解谜，只用 **章节关卡制 + 三星收集**。不做无尽冲分、不做每日随机盘。

- **5 盒 × 8 关 = 40 关**（首发体量）。每盒开头 1–2 关是新机关教程。
  1. **铁盒入门**：单绳下落、双绳选断、摆锤时机、第一颗星。
  2. **糖纸回廊**：三星路线、弹性绳弹射、多刀顺序。
  3. **气泡车间**：上浮、点破时机、泡+摆组合。
  4. **风与刺**：气垫改向、尖刺门缝、自动绳。
  5. **夜灯沙龙**：滑动锚 + 前述机关混编，三星路径刁钻。
- 盒与盒之间用累计星解锁（建议门槛：上一盒至少 12/24 星）。
- 关卡选择画在盒盖内侧：8 个凹槽，通关亮糖，三星亮金箔。

### 游戏目标与反馈体系

- **核心指标不是总分**，是：
  - 本关星数 0–3（糖果碰到即收，不可丢）。
  - 章节完成度（8/8 关、星数 0–24）。
  - 可选展示“本关刀数 / 用时”，只作文案，不参与解锁。
- **仪式**：
  - 进嘴：糯糯双眼亮、一口吞、盒内撒一层糖粉。
  - 三星：盒盖金线走一圈，糯糯满足躺倒。
  - 碎糖：玻璃裂一声，糯糯瘪嘴，重开钮在盒底托盘里弹一下。

## 4 · 美术风格与视觉氛围

- **题材与视觉关键词**：马口铁糖果盒、蜜蜡软糖、夜灯暖黄、铜销绳扣、纸雕剪影。
- **游戏机台 / 沉浸舞台规划**：
  - 整屏是一只打开展示的 **长方形糖锡铁盒**：盒壁是舞台边框，关卡物理发生在盒内绒布底上。
  - **禁止**四角浮动返回/音效胶囊；返回、静音、语言收进 **盒盖顶边一条窄状态条**（关卡名「气泡车间 · 3」、星槽、重开印章）。
  - **禁止**右侧 SaaS 卡片堆；星、刀数、重开全部镶在盒沿与底托盘，不另开栏。
  - 桌面 ≥900px：铁盒水平居中，左右留夜灯虚化桌面（木纹+一盏台灯光晕），不把棋盘拉成通栏。
  - 竖屏：铁盒竖过来，底托盘放大重开与气垫提示。
- **色彩与环境氛围**：
  - 主色：暖蜂蜜黄 + 铁锈红绳 + 深酒红绒布底（避开大面积冷蓝紫）。
  - 绳：麻线/铜丝质感，拉伸变蜜红。
  - 刀光：短亮金线，断口绒毛一抖。
  - 气泡：半透明麦芽糖膜。
- **封面设计提案**：
  - 3D 软胶，单一居中：一颗裹糖纸的软糖被两根细绳吊着，下方一张圆嘴的蜜色小兽（糯糯）仰头，背景蜂蜜渐变，无文字，主体 60–75%。

## 5 · 制作人拍板与开放探讨

1. **首发机关范围**
   - A. 克制包：绳 / 弹性绳 / 星 / 气泡 / 气垫 / 尖刺（自动绳与滑轨放到第 4–5 盒）。推荐，手感好打磨。
   - B. 全开包：再加自动绳、滑轨，40 关机关更密，开发与关卡量都更大。
2. **糯糯会不会动**
   - A. 大多数关固定坐盒底，少数关沿短轨道来回（增加“等它张嘴对齐”的时机题）。
   - B. 全程固定，纯弹道题，阅读更干净。
3. **铁盒主题皮**
   - A. 全 5 盒同一蜜蜡铁盒，只换盒内摆件（开发快、品牌统一）。
   - B. 每盒换绒布色与摆件主题（入门原铁、回廊糖纸、车间玻璃、风刺铜网、沙龙夜灯），章节记忆更强。

默认建议：**1A + 2A + 3B**——机关先少后精，糯糯偶尔走动增加时机，章节靠换皮记住进度。
